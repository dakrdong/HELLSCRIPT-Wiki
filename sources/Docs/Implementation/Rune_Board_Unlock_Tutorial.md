# 룬 보드 해방과 플레이어블 가이드

갱신일: 2026-10-03 · [English](Rune_Board_Unlock_Tutorial.en.md)

균열 15단계를 정상 클리어하면 결과창에서 룬 마스터 **인젤 미르**가 안내한다. 첫 클리어 보상을 받은 뒤 룬 보드 아이콘이 우측 상단 콘텐츠 메뉴로 날아가 등록된다. 기존 5단계 플레이어블 가이드에서 NPC 설명과 직접 플레이를 번갈아 진행한 후 실제 보드를 자유롭게 사용한다.

균열 1~14단계에서는 일반·정예·보스 룬 블럭 보상이 없습니다. `RuneEconomy.MinimumDropStage`가 `ContentUnlocks`의 룬 보드 해방 단계(15)를 읽고, `RuneGrowth`가 실제 균열 단계로 지급을 판정합니다. 이미 해방한 계정의 낮은 단계 반복에도 적용하며, 기존 보유 룬·숙련 경험치·중복 지급 방지 기록은 유지합니다.

## 플레이 흐름

1. 해방 전에는 마을·전투의 콘텐츠 메뉴에서 룬 보드 아이콘을 만들지 않는다.
2. 균열 15단계의 실제 정상 클리어 기록을 확인하고 결과창에서 룬 마스터의 대화를 시작한다. 최고 클리어 수치만 높이거나 훈련·프롤로그를 끝내는 것으로 시작하지 않는다. 자동 반복과 반복 전 정리는 안내 중 멈춘다.
3. 결과창의 **보상 받기**만 선택할 수 있게 표시한다. 수령 거래는 첫 클리어 상자를 지급하고, 그 안의 **룬 블럭 세트**를 열어 G0 한 칸 룬 다섯 종류를 실제 보관함에 넣는다. 다른 첫 클리어 상자는 그대로 보관한다. 숙련 경험치는 지급하지 않는다.
4. 저장 성공 후 룬 보드 인장이 우측 상단으로 날아간다. 착지 상태를 저장한 뒤부터 아이콘을 정상 표시한다. 동작 줄이기 설정은 짧은 착지 연출을 사용한다.
5. 표시된 콘텐츠 아이콘을 눌러 기존 네이티브 룬 보드를 연다. 룬 마스터가 **각 단계의 규칙·조작·목표를 설명한 뒤** 플레이어블 가이드를 진행한다. 직접 목표를 달성해야 **다음**이 열린다.
6. 다섯 단계를 모두 마치면 룬 마스터가 실제 무기별 보드와 저장 방법을 소개하고 **원하는 무기에 자유롭게 룬을 배치해 보세요**라고 안내한다. 튜토리얼을 종료하고 보드를 열린 채로 두며 모든 조작을 풀어 준다.

| 단계 | NPC 설명과 플레이 | 다음 단계 조건 |
| --- | --- | --- |
| 1 | 같은 색 블럭의 한 칸 간격, C자 배치 | 연습 블럭을 유효한 자리에 배치 |
| 2 | 같은 색 기존 블럭 두 개와의 간격, 마름모 배치 | 연습 블럭을 유효한 자리에 배치 |
| 3 | 다른 색과는 맞닿아도 됨, 파란 블럭 배치 | 연습 블럭을 유효한 자리에 배치 |
| 4 | 선택·회전·배치, 같은 색 능력 활성 | 빨간 능력 2칸 활성 |
| 5 | 두 색 블럭을 번갈아 선택·회전·배치 | 각 색 능력 2칸씩 활성 |

대화의 빠른 넘김은 문장만 넘긴다. 필수 가이드에서는 상단 단계 점프·이전·닫기·배경 클릭·뒤로가기로 실습을 건너뛸 수 없다. 실습은 기존 `RunePracticeModel`의 연습 블럭만 사용하므로 지급한 실제 룬·무기 배치·숙련·개방 상태를 바꾸지 않는다. 종료 후 도움말에서 다시 여는 가이드는 기존처럼 자유롭게 탐색·종료할 수 있다. 한국어·영어 대사와 기존 NPC 초상화를 사용한다.

## 소유와 저장

`AccountGuide.runeBoard`가 `Waiting → Reward → Emblem → OpenBoard → Practice → Complete`와 다음 실습 페이지(0~5)를 계정 단위로 저장한다. 지급된 실제 룬 ID도 기록한다. `RuneBoardTutorial`은 진행 판정을, `GameStore.Transact`는 보상과 진행의 원자적 저장을 소유한다. 일회성 요청 ID로 재시도 시 중복 지급·중복 단계 진행을 막으며 저장 실패는 성공 상태를 채택하지 않는다.

`RewardBoxes.json`의 기존 `rune-starter`가 **룬 블럭 세트 / Rune Block Set**이다. 균열 15단계의 첫 클리어 약속에 이 세트를 보존하므로 운영 보상 설정에서도 필수 선물이 빠지지 않는다. 일반 상자 개봉·운영 지급을 해방 보상으로 오인하지 않는다.

UI는 기존 `StoryDialogueWindow`, `PrologueGate`, `TutorialAnchorRing`, `RuneBoardWindow`와 5단계 `RunePracticeModel`을 연결한다. 새로운 창 프레임·배치 검증기·퍼즐을 만들지 않는다. 필수 실습 모드만 완료 조건·탐색 제한·진행 저장을 적용한다. 실제 무기 편집은 기존 `RuneBoardSession`과 `GameStore.CommitRuneBoardState`를 사용한다. [공통 UI 계약](Shared_UI_Contract.md)의 룬 어댑터를 따른다.

재시작하면 저장된 단계부터 재개한다. 수령 후 착지 전 종료되면 인장 연출부터, 가이드 진행 중 종료되면 아직 완료하지 않은 페이지의 NPC 설명·연습부터 다시 시작한다. 이미 완료한 페이지는 반복하지 않는다. 새 상태가 없는 기존 계정 중 이미 룬 콘텐츠가 해방됐거나 최고 클리어가 15 이상인 계정은 기존 접근을 유지하며 새 필수 실습을 반복하지 않는다. 이전 계정도 15단계 이전이며 해방되지 않았다면 새로운 안내를 기다린다.
