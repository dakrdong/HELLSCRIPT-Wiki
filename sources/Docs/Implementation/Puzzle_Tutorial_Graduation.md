# 퍼즐 튜토리얼 졸업 — 8단계

작성 2026-10-07. [English](Puzzle_Tutorial_Graduation.en.md) · [운영 퍼즐](Puzzle_Tutorial_Operations.md) · [검증 수치와 해시](Evidence/Puzzle_Graduation_Matrix.json)

L14·L15를 실제 전투로 구현하고, 15개 레벨의 저장된 첫 클리어 기록을 졸업에 연결했다. 승인된 L4 N09 추가 구현과 9단계 네이티브·최종 검증이 남아 있으므로 전체 튜토리얼 수락 완료로 보고하지 않는다.

## 전투와 학습

L14는 N04/N10 지속 장판, N14 순간 범위, N08/N09 직접 타격이 차례로 나온다. 장판·범위·직접 타격을 각각 항상 회피하고 공격 취소를 허용하며 필요한 경우 이동기를 사용하는 답으로 세 직업 모두 90초 안에 승리했다. 분류 하나를 끄거나 피해 기준 40%를 적용하면 실제 사망한다. 장판의 작은 개별 피해가 누적되는 상황도 실제 위험 판정과 피해로 확인한다. 공격 우선 프리셋과 FINISH를 함께 적용한 오답도 사망했다. FINISH만 바꾼 단일 옵션 검사로 해석하지 않는다.

L15는 실제 B01 보스 패턴과 사제·궁병 세 파를 사용한다. 보스의 예고·분노·타격은 기존 소유 코드를 따른다. 전사는 공격 유지 우선, 다른 직업은 항상 회피를 사용한다. 균형 생존, 위험한 지원형 우선, 넉넉한 물약, 지정 이동기와 공격 취소를 합친 칙령으로 모든 적을 처치한다. 전사의 사제 자가 회복과 궁수의 잦은 취소 때문에 초기 구성이 시간 초과로 끝났으며, 직업별 적 체력을 실제 전투 수치로 조정했다. 승패나 HP를 강제로 바꾸지 않는다.

## 졸업 소유와 저장

`PuzzleTutorial.GraduationReady`는 선택 영웅·튜토리얼 소유자, 15개 준비/승리 기록과 각각의 실제 결과 거래 영수증, 진행 중 균열의 부재를 검사한다. `GameStore.CompleteTutorialRun`은 라이브 시뮬이 없는 재시작 상태에서도 이 기록으로 졸업하며, 실제 금화 1,000과 Lv7 희귀 장비를 한 거래로 지급한다. 같은 요청은 다시 지급하지 않는다. 보상 장비의 자동 장착과 교체품 보관은 기존 `Economy`·`EquipmentRecommendation`·`EquipmentAutomation` 거래를 따른다.

배운 칙령과 스킬 배치를 영웅 기본 설정으로 유지한다. 실제 누적 XP 3,000, Lv7 / 잔여 XP 675와 15쪽을 보존한다. 완료 일지의 각 레벨에서 보상 없는 독립 복습을 연다. 반복 설정은 L13에서 공통 해금 판정에 연결하고, 공유·프리셋은 L15에서 연다. 졸업 후에도 각 레벨에서 배운 옵션을 공통 해금 목록에 남긴다. 첫 마을 안내 C01/F01이 스킬 안내 C05/F06/H07보다 먼저 오도록 추천 우선순위를 조정한다. 최고 균열 0일 때 실제 상점 상한은 3이다.

## 졸업 칙령으로 초반 균열 측정

실제 L1~L15 클리어와 졸업 거래를 거친 세 영웅으로 같은 시드 규칙의 정상 `CombatSimulation`을 실행했다. 졸업 장비·칙령을 유지하고, 실제 물약 준비·입장·상자·전리품 거래와 자연 XP를 사용했다. 별도 스킬 투자·장비 구매·패배 삭제 없이 진행했다. 0.05초 고정 틱의 게임 시간이며 네이티브 입력, 이용자 승률, 실시간 피로도 측정 결과가 아니다.

|---|---|---|---|---|---|
| 전사 | 102.40초 / Lv8 | 104.90초 / Lv9 | 118.60초 / Lv9 | 123.00초 / Lv10 | 139.45초 / Lv10 |
| 궁수 | 123.30초 / Lv8 | 142.00초 / Lv9 | 125.45초 / Lv9 | 251.81초 / Lv10 | 158.76초 / Lv10 |

초기 전사 4단계는 HP 540.1로 생존했지만 보스 HP 500.4를 남겨 시간 초과했다. 사용자는 XP 유지와 전사 진행 보완을 선택했고, 이어 전사의 기본 체력·방어력을 높여 작은 공격은 맞으며 싸우도록 요청했다. XP는 변경하지 않았다. 기본 HP는 300 + 35×(레벨−1)에서 450 + 50×(레벨−1)로 올렸다. 기존 힘 1당 방어도 2와 장비 기여를 보존하고, 전사 기본 방어도 60 + 4×(레벨−1)를 추가했다. 궁수·마법사 수치는 그대로다.

L15 전사는 기존 공격 유지 우선 프리셋을 배워 저장한다. 장판은 항상 피하고, 범위·직접 공격은 실제 방어 적용 후 예상 HP 손실 25%부터 피한다. 균형 생존의 치명적 피해 대응과 물약도 유지한다. 실제 시간 초과가 일반 균열에서 Duration으로 기록되지 않던 공통 소유자도 수정했다. 졸업 전사에게는 결과 화면에서 회피 설정을 열어 취소 기록과 기준을 확인하는 행동을 안내하며 자동으로 설정을 덮지 않는다.

같은 시드 규칙으로 전사는 다섯 균열을 모두 클리어했다. 실제 받은 피해와 물약 사용도 기록했고, 균열별 물약 사용은 8/9/9/8/11회였다. 장비·맵·성장·칙령이 함께 달라지므로 속도 변화를 체력 또는 한 설정만의 효과로 단정하지 않는다. 이전 전사 기록은 before-tank 접두사로 보존했다. 기존 입문 측정의 Lv8과 현재 졸업 영웅의 Lv10은 서로 다른 시작 성장·칙령·시드 경로의 결과다.

## 검증 범위

전사 체력·방어 변경 후 영향을 받는 전사 검사 40개와 새 첫 8레벨 실제 진행 검사 1개를 집중 검증했다. L3의 작은/큰 타격과 L5 첫 일제 공격을 전사별 실제 피해로 재조정해 잘못된 물약 시점·후퇴 조건의 사망을 유지했다. 전체 8단계 집중 결과는 고유 258개 모두 최종 통과다. 실패했던 시도와 보정 결과의 XML·로그를 모두 보존한다.

L14 집중 검사 18개 통과. L15는 궁수·마법사 정답/초기 설정과 전사 수정 후 정답/초기 설정이 실제 결과를 확인했다. 졸업 거래, 공유·보관, 저장 실패, 복습 및 복원과 관련 공통 소유자 검사는 별도 결과로 기록한다. 초기 졸업 검사에서 자동 장착이 교체품을 창고에 보관하는 동작을 가방 증가로만 비교한 검사를 발견했고, 전체 소유 수와 원래 장비 ID 보존으로 바로잡았다. 복원 검사는 HP·자원·위치·난수와 통계 집계를 제외한 전체 실제 시뮬 상태를 정확히 비교한다. Unity의 double 통계 파싱이 마지막 이진 자릿수를 바꾸는 현상을 별도로 기록했다. 집계 통계의 비트 단위 완전 동일성은 증명하지 않는다.

전체 EditMode와 macOS 개발 빌드 스모크는 마지막 코드 및 최신 main 통합 뒤 9단계에서 한 번 실행한다. 물리 모바일·공개 위키 배포는 수행하지 않았다. 작업 브랜치는 PR만 만들며 병합·공개 게시를 하지 않는다. 원본 사용자 변경은 보존한다.
