## 소스·검증 보존

튜토리얼 작업의 검사 XML, 네이티브 로그·스크린샷·합성 세이브, 바이너리 해시·빌드 방법과 작은 Editor 설정을 기본 프로젝트의 `Artifacts/Validation/EdictProgression/` 아래로 옮겼다. 필요한 공개 검증 근거는 [튜토리얼 검증 기록](EdictProgressionEvidence20261004/validation.json)에 함께 보존했다. 원본 프로젝트·에셋·meta·설정·Git 이력·대화·인증·기존 납품본은 보호했다.

관리형 `edict-progression` 워크트리는 Codex의 archive/restore 기능으로 보관했다. 보관 직전에 관련 게임·Unity 프로세스와 작업 디렉터리 참조가 없음을 확인했으며 다른 프로세스를 종료하지 않았다. Unity가 자동 변경한 설정·머티리얼은 해당 변경만 복원했다.
