# 움직이는 보스

작성일: 2026-09-28 · [English](Boss_Movement.en.md)

보스가 제자리에 서서 공격만 하던 것을 바꿔, 공격하면서 움직이게 했다. 보스 5종 모두 1페이즈와 2페이즈에 이동하는 패턴을 하나 이상 가지며, 합계 12종이 도약·돌진·잠행·미끄러지기·순간이동·회전 전진으로 자리를 옮긴 뒤 착지한 곳을 친다. 패턴을 기다리는 동안에도 영웅 주위를 돈다. [다크 고딕 개편](Dark_Gothic_Overhaul_Stage1.md) 2단계의 세 번째 항목이다. 전투 규칙은 [보스 전투 상세](../Design/HELLSCRIPT_Boss_Combat_Detail.md)에 정리했다.

## 바뀐 패턴

| 보스 | 패턴 | 움직임 |
| --- | --- | --- |
| 묘지의 집행자 | 거두기 베기(1페이즈) | 영웅을 지나쳐 최대 7m 돌진(몸에 닿으면 D80%) 후 멈춘 자리에서 220도 베기 |
| 묘지의 집행자 | 처형 도약(2페이즈) | 0.55초 포물선 도약, 착지 순간 반경 3m |
| 묘지의 집행자 | 사슬 회오리(2페이즈) | 예고한 7.5m 길을 회전하며 초속 3m로 전진, 회오리가 보스를 따라다님 |
| 묘지의 집행자 | 무덤 종소리(2페이즈) | 조준선의 세 지점으로 0.4초씩 도약, 착지마다 반경 2m |
| 종말의 합창자 | 만가의 고리(1페이즈) | 영웅에게서 3.2m 떨어진 옆자리로 순간이동 후 고리 |
| 종말의 합창자 | 비탄의 구체(2페이즈) | 영웅 옆 5.5m로 순간이동 후 전방위 구체 |
| 균열의 포식자 | 아가리 물기(1페이즈) | 최대 4m 달려든 뒤 물기 |
| 균열의 포식자 | 균열 찢기(2페이즈) | 최대 12m를 달려 지나간 길에 균열 |
| 사구의 폭군 | 잠행 강습(1페이즈) | 땅속을 초속 9m로 파고들어 영웅 앞에서 솟아오름 |
| 사구의 폭군 | 삼중 분출(2페이즈) | 땅속으로 세 지점을 옮겨 가며 차례로 솟아오름 |
| 혹한의 여사제 | 서리 폭발(1페이즈) | 최대 5m 빙판 미끄러짐 후 주변 폭발 |
| 혹한의 여사제 | 파쇄 부채(2페이즈) | 뒤로 4.5m 순간이동한 뒤 얼음 파편 |

나머지 18종(내려찍기·갈고리·소환·광선·돌진·연속 폭발 등)은 규칙을 그대로 두었다. 기존의 돌진과 갈고리 끌어당김, 탐식의 끌어당김은 이미 보스나 영웅을 움직인다.

## 규칙

- 경로와 착지 지점은 준비를 시작할 때 벽과 장애물을 피해 정하고 저장한다. 보스는 발동 다음 틱부터 움직인다. 착지할 곳이 없으면 그 패턴을 쓰지 않고 1초 뒤 다시 검토한다.
- 예고 게이지는 착지할 곳마다 그곳에 떨어지는 순간 가득 찬다. 몸으로 치는 돌진은 달릴 길도 예고하며, 이 길은 발동 순간 가득 찬다.
- 이동 중에도 보스를 공격할 수 있다. 무력화되면 그 자리에서 멈추고, 이미 만든 장판은 남는다.
- 이동 패턴 중 거리를 좁히는 것은 사거리를 넓혔다. 거두기 베기·아가리 물기 7m, 서리 폭발 6.5m, 사슬 회오리 6m, 만가의 고리 9m다.
- 쓸 수 있는 패턴이 없는 동안 보스는 영웅 주위를 기존 속도의 55%로 돈다. 3초마다 방향을 바꾸고, 같은 시드는 같은 방향으로 돈다.
- 저장 형식은 전투 행동 버전 7이다. 진행 중인 구간 번호와 경과 시간, 보스를 따라가는 회오리 표시를 저장한다. 이전 저장에서 착지 지점 없이 준비 중이던 이동 패턴은 조준 지점에 착지한다.
- 피해 예측은 이동 구간, 돌진 몸통 피해, 따라다니는 회오리의 매 틱을 실제와 같이 계산한다.

## 화면 표현

- 도약은 포물선을 그리며 떠오르고(꼭대기 약 3.7m), 잠행은 바닥 아래로 가라앉아 모래를 튀기며 이동하다 솟구친다.
- 돌진과 미끄러지기는 몸을 앞으로 기울이고 흙먼지나 서리 자국을 남긴다. 사슬 회오리는 몸을 빠르게 돌리며 불티를 흩뿌린다.
- 순간이동은 녹아 사라지면서 어두운 불꽃을 흩고, 새 자리에서 다시 나타난다.
- 2페이즈 보스는 테두리가 붉게 타오르고 발밑에 불꽃이 인다. 포효는 넓은 충격파를 한 번 더 내고 화면을 크게 흔든다.

## 검증

2026-09-28, 복제 프로젝트와 macOS 개발 빌드(최신 main을 합친 `b6f0eadc`)에서 확인했다.

- **Edit Mode 전체 검사**: 4,566개 중 4,519개 통과. 실패 47개는 모두 개편 전 기준선에 있던 것이며 새 실패는 없다. [요약](BossMovementEvidence/editmode-full-summary.txt)
- **`BossMovementTests` 15개**:
  - 보스마다 1·2페이즈에 이동 패턴이 있다.
  - 이동 패턴 12종이 벽과 장애물이 아닌 계획된 땅에 착지한다.
  - 도약·순간이동이 정해진 시간, 돌진·잠행·미끄러지기가 정해진 속도로 이동한다.
  - 회오리가 보스를 따라간다.
  - 기다리는 보스가 영웅 주위를 돌고, 같은 시드는 같은 방향으로 돈다.
- **피해 예측**: 발표된 보스 공격 30종 모두 예측과 실제 피해가 같다(`IncomingForecastTests`).
- **예고 게이지**: 보스 기본 공격·패턴 30종·포효가 게이지를 채우고 착지하는 틱에 완료된다(`TelegraphGaugeTests`).
- **서버 재현**: `AuthoritativeRiftTests`를 통과했다.
- **`-hellscriptBossMotionSmoke` 통과**: 실제 게임에서 이동 패턴 12종이 모두 제자리를 떠나 계획된 끝 지점의 빈 땅에 착지했고, 기다리는 보스가 영웅 주위를 돌았고, 포효가 2페이즈를 열었다. [결과](BossMovementEvidence/runtime-boss-motion-smoke.txt)

## 확인하지 못한 것

- 실기기와 Android 빌드에서 보지 않았다.
- 보스 몸은 아직 기본 도형이다. 도약 높이, 잠행 깊이, 순간이동의 소멸은 모델을 연결할 때 다시 맞춘다.
- 보스 스모크의 재시작 단계(1–3)는 이번 변경 전부터 갈고리 장면에서 멈춘다.
- 이동 패턴이 늘어 보스전 난이도가 달라질 수 있다. 실제 플레이 난이도는 따로 재지 않았다.
- 사람의 눈으로 한 품질 평가가 아니다.
