# 장비 베이스와 외형 확장

갱신일: 2026-09-27 · [English](Equipment_Variants.en.md)

기존 B01–B30과 저장된 장비 수치를 보존하고 B31–B60을 추가한다. 신규 장비는 몬스터 처치·정예·보스가 사용하는 `Economy.CreateRiftItem` → `ItemGenerator.Create`의 후보이며, 상점·보상 상자도 같은 생성기를 사용한다. 별도 지급 버튼이나 테스트 전용 드랍 표로 연결하지 않는다.

## 구성과 선택 기준

- 방패 4종: 소형 원형 방패, 철테 원형 방패, 기사의 연형 방패, 성벽 대형 방패.
- 방어구 20종: 머리·몸통·손·발·허리 각각 천·가죽·철 사슬·판금 4종을 추가한다. 기존 방어구도 유지한다.
- 장신구 6종: 석류석·월석·흑요석 목걸이와 황동 인장·청금석·가시덩굴 반지를 추가한다.

| 재질 | 장점 | 선택할 때 포기하는 성능 |
| --- | --- | --- |
| 천 | 고정 모든 원소 저항이 가장 높다. | 같은 부위에서 방어도가 가장 낮다. |
| 가죽 | 천보다 높은 방어도와 고정 회피 확률 1%p를 얻는다. | 철·판금보다 방어도가 낮고, 천보다 저항이 낮다. |
| 철 사슬 | 가죽보다 높은 방어도와 소량의 저항을 함께 얻는다. | 가죽의 회피 보너스가 없고, 판금보다 방어도가 낮다. |
| 판금 | 같은 부위에서 방어도가 가장 높다. | 고정 저항과 회피 보너스가 없다. |

이동 속도를 깎거나 직업별 착용 제한을 새로 만들지 않는다. 손의 공격 속도, 발의 이동 속도, 허리의 생명력이라는 기존 주 능력치는 유지하고, 손·발·허리의 재질 방어도는 고정 부가 능력치로 적용한다. 머리·몸통은 원래 주 능력치인 방어도 자체를 재질별로 달리한다.

| 방패 | 레벨 1 방어도 | 막기 확률 | 막았을 때 피해 감소 |
| --- | ---: | ---: | ---: |
| B31 소형 원형 방패 | 16 | 24% | 18% |
| B32 철테 원형 방패 | 24 | 20% | 26% |
| B33 기사의 연형 방패 | 32 | 16% | 36% |
| B34 성벽 대형 방패 | 40 | 12% | 50% |

작은 방패는 더 자주 막고, 큰 방패는 더 높은 방어도와 한 번 막을 때의 감소량을 제공한다. 기존 막기·감소 상한과 전투 판정을 공유한다. 방패 계열의 총 추첨 비중을 기존과 같게 유지하고 그 안에서 5개 베이스(B28 및 신규 4종)를 균등하게 고른다. 일반·마법·희귀 등급에서 방패가 나올 수 있으며, 전설 생성의 기존 보조 장비 제외 규칙은 유지한다.

목걸이는 각각 생명력 35, 최대 자원 8, 가시 8을 고정 옵션으로 제공한다. 반지는 각각 공격 속도 1.5%p, 초당 자원 생성 0.6, 회피 확률 1.5%p를 제공한다. 고정 생명력·방어도·가시는 `1 + 0.08 × (아이템 레벨 - 1)`로 성장하고, 비율·자원 보너스는 고정이다. 무작위 접사 수와 재설정 가능 슬롯에는 영향을 주지 않는다.

## 디아블로 참고 범위

[Diablo III 2.0.1 공식 패치 기록](https://news.blizzard.com/en-gb/article/12671560/patch-2-0-1-now-live)의 Loot 2.0, 직업에 맞는 추첨, 방어도·저항·회피·가시 등 서로 다른 능력치 선택을 참고했다. [Diablo IV 2020년 12월 개발 글](https://news.blizzard.com/en-gb/article/23583664/diablo-iv-quarterly-updatedecember-2020)의 베이스 고유 특성, 방패의 막기 특성, 고해상도 장비 아이콘과 무작위 옵션의 구분도 참고했다.

위 문서들은 재질 4종의 보편적인 장단점 표를 제시하지 않는다. 따라서 위 재질 규칙과 숫자는 **HELLSCRIPT용 설계**이며, 디아블로 3·4의 현재 재질 규칙이나 최신 밸런스 수치를 그대로 복사한 것으로 표시하지 않는다. 기존 게임의 피해 계산은 변경하지 않는다. 전체 1–1000단계 장기 밸런스 검증은 별도 범위다.

## 소유권·저장·표시

`ItemCatalog.Bases`가 베이스 ID와 재질·고정 옵션의 단일 기준이다. `ItemBaseBonus.Value`를 `HeroStats`와 `ItemComparison.Properties`가 함께 사용한다. `ItemTooltip`과 기존 `ItemDetailView`/`EquipmentComparisonView`가 재질·고정 능력치와 실제 교체 결과를 표시한다. 표시만으로 장착·저장하지 않는다. 실제 획득·장착·저장은 기존 `CombatSimulation`, `EquipmentSlots`, `GameStore` 경로를 유지한다.

장비 콘텐츠 버전은 6이다. 기존 ID·인덱스·수치는 바꾸지 않으며, 이전 게임이 신규 아이템이 든 저장을 조용히 버리지 않도록 버전 경계에서 읽기를 거부하게 한다. 저장 스키마나 계정 키는 추가하지 않는다. 방패는 보조 손, 양손과의 동시 장착 제한, 활과의 호환 제한을 기존 장착 계획에 맡긴다. 두 반지 위치도 기존 규칙을 따른다.

`EquipmentArt.ForItem`은 원래 고유 장비의 전용 이미지가 있으면 우선하고, 없으면 베이스 이미지를 사용한다. 신규 30종은 `Resources/Art/EquipmentVariants/B31.png`–`B60.png`를 사용한다. B28의 기존 철 방패도 B32의 철테 원형 방패 이미지를 공유한다. 다른 기존 PNG·GUID·아틀라스는 교체하지 않는다.

## 제작 근거와 검증

[제작 목록과 개별 프롬프트](../Art/EquipmentVariants/manifest.json)에 내장 `image_gen` 사용, 실제 모델 미확인(`candidate_model_unknown`), 출시 아트 승인 미완료를 기록했다. `transparent_background=true`로 생성한 원본 PNG의 알파를 그대로 보존한다. 배경 제거·크로마키·색상 치환을 하지 않는다. Unity는 신규 폴더에 한정한 임포터로 최대 512 해상도, 알파 투명도, 비압축, 밉맵 없음 설정을 적용한다.

[원본 알파 검사](EquipmentVariantEvidence/native-art-audit.json)는 30개 파일의 RGBA, 완전 투명·불투명 픽셀, 네 모서리의 투명도, 서로 다른 해시를 확인한다. 희미한 원본 알파도 수정하지 않는다. 외곽 여백은 알파 16 이상인 영역으로 측정하며, 원본에 있는 미세한 알파와 투명 픽셀의 RGB 값도 보고서에 그대로 남긴다. [52픽셀 검수 시트](EquipmentVariantEvidence/icon-scale-preview.png)에서 밝고 어두운 배경의 가장자리를 함께 확인했다.

## 실행 검증과 반영 상태

- [Unity Edit Mode](EquipmentVariantEvidence/editmode.xml): 장비 확장·아이템 생성·공통 이미지·장비 비교·현지화·인벤토리 122개 통과, 실패·건너뜀 0개. 세 직업의 실제 몬스터 사망 보상 경로에서 신규 30종을 모두 추첨하고, 한 번만 획득·저장·복원하는 것을 검사했다. 훈련의 무보상 규칙, 재질별 능력치, 방패 호환, 기존 ID도 확인했다.
- [macOS 개발 빌드](EquipmentVariantEvidence/build-result.txt): Unity 6000.6.0f1, 빌드 성공·오류 0개. 원래 프로젝트의 실행 중인 에디터와 경로가 달라, 기존 Unity 배치 검사·빌드 도구를 별도 작업 폴더에서 사용했다.
- [실행 검사](EquipmentVariantEvidence/equipment-variants-runtime.json): 440×956, 956×440, 1440×810, 1440×900, 1680×720의 5개 크기 × 한국어·영어 × 글자 크기 100·150%, 총 20조합. 실제 uGUI 레이캐스트와 포인터 처리기를 통해 상세·비교를 열고 표시 영역, 이미지, 읽기 전용 상태를 확인했다. 방패 장착 버튼으로 보조 손을 교체한 뒤 막기 수치와 디스크 복원을 확인했다. macOS 합성 입력 검사이며 모바일 실기기 검증은 아니다.
- 큰 글자에서 주 능력치의 비교 증감량이 잘리지 않도록 공통 `ItemDetailView`에서 수치와 증감량을 별도 줄로 표시한다. 계산은 기존 `ItemTooltip.Delta`를 그대로 사용한다. 기존 첫 플레이 검사 문구에서 빠진 영문 키 2개도 보완했다.
- 공통 UI 계약 검사와 9개 계약 검사, 위키 생성·정합성·10개 Python 검사 및 379개 문서·32개 DB·4,209개 상세의 JavaScript 경로 검사를 확인한다. [내장 브라우저 기록](EquipmentVariantEvidence/local-wiki-browser.json)은 로컬 공개 사본에서 새 방패·가죽 장갑의 이미지와 고정 능력치, 쓰기 버튼 0개를 확인한 근거다.

작업 브랜치는 `codex/equipment-variants`다. 원본 작업 폴더의 다른 변경을 포함하지 않는다. 이 문서의 검증은 작업 브랜치 기준이며, `main` 병합이나 [공개 위키](https://dakrdong.github.io/HELLSCRIPT-Wiki/#/tree) 배포 완료를 뜻하지 않는다. 공개 사본은 병합된 `main`에서 갱신한다. 이미지의 실제 생성 모델과 출시 아트 승인은 아직 확인되지 않았다.
