# 사냥 칙령 v0.2 전투 연결 개발 기록

작성일: 2026-09-10 · P0 2단계 · 정기 판단에서 원본을 읽는 경로

## 적용 범위

[저장 연결](Edict_Storage_Expansion.md)로 영웅이 원본을 보관하게 되었으므로, 이 단계는 그 원본을 전투의 정기 판단에서 읽는다. 연결하는 것은 전역 생존 판단과 그 실행이다. 조준·스킬 순서·전역 회수 정책은 아직 연결하지 않는다.

## 사용 여부는 명시적으로 켠다

`HeroSave.useEdict`가 꺼져 있으면 원본을 읽지 않는다. 기본값은 꺼짐이다. 기존 저장에 원본이 새로 생겼다는 이유만으로 영웅의 전투 방식이 달라지면 안 되기 때문이다. 켜기 전까지는 기존 규칙 편집기가 단독으로 행동을 결정한다.

`PrepareEdict`는 전투를 시작할 때와 빌드가 바뀔 때 실행되어 사용 가능 여부를 정한다. 원본이 없거나, 꺼져 있거나, 정규화·수신 검사에 실패하면 사유를 남기고 비활성으로 둔다. 사유는 `EdictInactiveReason`으로 읽을 수 있다.

## 판단 시점

정기 판단은 0.2초마다 돈다. 그 자리에서 먼저 사냥 칙령을 실행하고, 그것이 주 행동을 가져가지 않은 경우에만 기존 규칙 판단을 이어서 실행한다.

| 판단 결과 | 이어지는 처리 |
|---|---|
| 긴급·회피 없음 | 기존 규칙이 평소대로 행동을 정한다. |
| 전투 유지 방침 선택 | 기존 규칙이 공격을 정한다. 사용자가 정한 방침을 그대로 따른다. |
| 생존 스킬·보행 시작 | 이번 판단 회차의 기존 규칙 실행을 건너뛴다. 방금 시작한 생존 행동을 곧바로 덮어쓰지 않기 위해서다. |
| 차단됨 | 기존 규칙이 평소대로 행동을 정한다. |

보행 후퇴의 이동 처리와 중단 처리는 이미 `MoveHero`와 행동·빌드 변경 경로에 연결되어 있었다. 이번에 추가한 것은 판단 호출뿐이다.

## 차단과 중단

`EdictResponseBlock`은 원본의 사용 스킬 네 칸이 현재 전투의 장착 스킬과 다르면 대응을 차단한다. 장착이 어긋난 원본으로 생존 판단을 내리면 없는 스킬을 쓰려 하기 때문이다. 차단 사유는 바뀔 때만 기록에 남긴다. 판단이 초당 다섯 번 돌기 때문이다.

판단 중 예외가 나면 그 판을 끝내지 않고 사냥 칙령만 중단한다. 원본 하나 때문에 진행 중인 균열을 잃게 하지 않는다. 중단 사유는 기록과 `EdictInactiveReason`에 남긴다.

## 검증

전체 Edit Mode 검사 **1,058개**가 통과했다. 이 중 전투 연결 검사는 13개다. 이전 단계까지의 검사 1,045개가 그대로 통과한 것이 기본값 꺼짐이 동작을 바꾸지 않는다는 근거다.

| 검사 | 확인한 결과 |
|---|---|
| 기본 비활성 | 켜지 않은 영웅은 원본을 한 번도 읽지 않는다. |
| 켠 뒤 활성 | 판단 회차가 대응 계획을 만들고 차단 사유가 없다. |
| 꺼짐 결정성 | 세 직업에서 같은 시드의 두 실행이 같은 상태에 도달한다. |
| 켠 뒤 완주 | 세 직업의 훈련 판이 1,200틱을 채우고 길찾기 오류가 없다. |
| 켠 뒤 결정성 | 같은 시드의 두 실행이 같은 상태에 도달한다. 판단을 읽는 것이 난수를 흔들지 않는다. |
| 장착 불일치 | 네 칸이 실제 장착과 다르면 대응을 차단하고 기록에 남긴다. |
| 다른 직업·부재 | 비활성 사유를 남기고 판이 계속 진행된다. |
| 체력 위기 | 후퇴 기준 아래로 내려가면 긴급이 발동하고 대응 판단이 후보를 기록한다. |

체력 위기 검사는 일반 물약과 사냥 칙령 물약을 모두 끈 상태에서 확인했다. 두 경로 모두 판단 시점 전에 최대 HP의 35%를 회복시켜 후퇴 기준을 벗어나게 만들기 때문이다.

`Artifacts/Validation/edict-drive-final-editmode.xml`에 보고서를 보존했다.

## 남은 범위

| 남은 항목 | 내용 |
|---|---|
| 조준 연결 | `PlanEdictAim`을 시전 명령에 전달하는 경로가 없다. 조준은 여전히 기존 규칙이 정한다. |
| 스킬 순서 | 원본의 공통 공격 순서가 공격 선택에 쓰이지 않는다. |
| 전역 정책 | 회수·가방·탐색의 전역 옵션이 연결되지 않았다. 기존 `BuildConfig` 값이 그대로 쓰인다. |
| 켜는 화면 | `useEdict`를 켜는 화면이 없다. 지금은 저장을 직접 고쳐야 한다. P0 4단계에서 만든다. |
| 실제 앱 확인 | macOS 앱에서 켜고 균열을 돌아 본 기록이 없다. |
