# HELLSCRIPT 직접 플레이 안내

작성일: 2026-09-13 · [English](Local_Play_Guide.en.md)

실행본은 프로젝트의 `Builds/macOS-Playable-Build2/HELLSCRIPT.app`이다. Finder에서 해당 앱을 열면 된다. Unity에서는 HELLSCRIPT 프로젝트를 열고 `Assets/HELLSCRIPT/Scenes/Hellscript.unity`를 열고 Play를 누른다. 별도 검사용 실행 옵션을 넣지 않으면 일반 플레이 저장을 사용한다.

## 첫 플레이 순서

1. 성소에서 전사·궁수·마법사 중 하나를 고른다. **성장과 스킬**에서 현재 해금된 스킬과 패시브를 확인한다.
2. **사냥 칙령 v0.2 편집**에서 행동을 설정하고 저장한다. 실제 사용 중인 설정을 확인한 뒤 **균열에 진입**을 누른다. 이동·공격·상자 개봉은 설정에 따라 자동 진행한다.
3. 전투 중에는 일시정지, 설정과 판단 기록을 이용한다. 장비 변경과 소켓 작업은 균열을 마친 뒤 진행한다.
4. 성공하거나 실패하면 결과를 확인한다. 이미 얻은 경험치·장비·재화는 유지된다. **장비 · 대장간 · 창고**에서 장착·비교·판매·분해·강화를 이용하고, 필요하면 설정을 바꾼다.
5. 보석을 얻으면 **보석 보관함**에서 상세 효과와 합성 재료를 확인한다. 희귀 이상 대상 장비에 소켓을 낸 뒤 보석을 장착할 수 있다. 비용은 확정 전에 표시한다.
6. **다시 도전**하거나 반복 사냥의 성공·실패·종료 조건을 설정한다. 가방이나 보석 보관함이 가득 차면 포탈에서 정리한 뒤 **균열 복귀**를 누른다.
7. 플레이를 중단한 뒤 앱을 다시 열면 **진행 중인 균열 이어하기**로 돌아간다. 저장된 반복 결과가 있으면 먼저 결과를 확인하고 명시적으로 이어 간다.

메뉴의 **설정 · 게임 안내**에서 한국어·영어, 글자 크기, 화면 방향·PC 표시, 음량을 바꿀 수 있다. 훈련과 A/B 비교는 실제 장비를 소비하지 않는다. 게임 안에서 결과 수치를 볼 수 있지만, 이번 개발 작업에서 밸런스를 측정하지는 않았다.

## 현재 범위

직접 플레이 가능한 로컬 macOS 개발판이다. 주요 순환은 영웅 선택 → 칙령 설정 → 생성 균열·전투·상자 → 보상 → 장비·보석·룬 성장 → 재도전·반복 → 저장·복원이다. 최소 도형과 임시 모델·소리를 사용한다.

서버 로그인·다른 기기 동기화·실결제와 스토어 배포는 연결하지 않았다. 현재 배속 잠금과 향후 사용권 정책은 기존 기획을 따른다. 모바일 실기기 품질, 출시용 리소스, 세부 밸런스와 장기 파밍 조정은 이 플레이 완성 목표에 포함하지 않는다. 미확정 보관 용량 등 작은 수치는 플레이 후 바꿀 수 있는 기본값으로 두었다.
