# 승인된 균열 승리 그림 가져오기 · 2026-10-24

사용자가 선택한 A 새벽 포털안의 가로/세로 PNG 원본을 지원되는 Claude 대화 첨부의 ‘이미지 저장’ UI로 내보냈다. 앱의 사설 저장소·세션 DB·비공개 API는 사용하지 않았다. 원본 픽셀을 수정하지 않고 기존 승리 화면의 가로/세로 리소스 경로에 연결했다.

| 원본 | 크기 | SHA-256 |
| --- | --- | --- |
| 가로 |1536×1024|417503f65cd895bd66af925ef2b9332447dd334a3dd0b3ace20f1352bd84bc6d|
| 세로 |1024×1536|282179c792b98a858cec4d3912a8e90d1f8a5c953e2022a3c793be84cd8687b4|

원본과 출처는 [manifest](../Art/RiftVictory20261024/manifest.json)에 기록했다. 새 리소스의 고유 meta를 보존하고, 전용 importer는 해당 경로만 단일 FullRect Sprite·불투명 RGB·최대2048·mipmap 없음으로 가져온다. 플랫폼별 압축은 기존 텍스처 예산의 새 경로 분기로 적용한다. 원본 전체 해상도는 범위 안에 남는다.

기존 승리 화면은 카드 비율에 맞는 원본을 골라 cover 방식으로 잘라 채우고 텍스트 대비용 wash를 덧댄다. 그림이 입력을 가로채지 않도록 raycast를 끈다. 기존 popup skin 검사5건이 원본 리소스, 전체 sprite rect, 방향별 선택, cover와 입력 장식을 확인하여 통과했다.

실제 macOS 화면·입력 및 한국어/영어 크기별 캡처는 아직 남아 있다. 이 기록은 그림 출처와 Editor 영향 검증의 근거이며 최종 빌드나 실기기 검증 완료를 뜻하지 않는다.
