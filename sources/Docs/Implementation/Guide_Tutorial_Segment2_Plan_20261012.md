# 안내 튜토리얼 2구간 연결 결과

갱신일: 2026-10-12

[English](Guide_Tutorial_Segment2_Plan_20261012.en.md). 사용자가 전달한 계획을 기존 안내 튜토리얼(흐름 6)에 연결한 구현 기록이다. 원래 계획은 작업 검증 폴더의 `original-segment2-plan.md`에 보존한다. 1구간 대본은 [안내 튜토리얼](Guide_Tutorial_Script_20261011.md)을 따른다.

## 연결한 흐름

회오리로 포위 무리를 처치하면 졸업하지 않고 첫 투기장의 위쪽 문과 꺾인 통로를 지나 긴 회랑으로 걷는다. 회랑 원거리 적 세 마리를 발견하면 벨리나가 플레이어에게 첫 교전 위치를 정하도록 안내한다. 위치 설정을 저장한 뒤 영웅이 걸어서 접근하고, 회오리가 회랑 적에게 처음 적중한 직후 전투 중 위치 수업을 연다. 수업 맺음의 [확인]을 누르면 남은 적과 싸우고, 전멸 후 [3구간](Guide_Tutorial_Segment3_Plan_20261012.md)의 광장으로 이동한다. 마무리 대사와 마을 졸업은 3구간 보스 처치 뒤로 이어진다.

| 단계 | 진행 조건 | 정지 여부 |
| --- | --- | --- |
| Whirlwind (6) | 포위 그룹만 전멸 판정 → Road | 흐름 |
| Road (7) | 위쪽 문 `(30,14)` → `(31,19)` → `(37,23)` → `(40,24)` → 회랑 `(44,24)` → 무덤 아래쪽 `(44,21)`로 짧게 우회. 원거리 적이 12.5m 이내이고 시야가 연결되면 OpeningTalk | 흐름 |
| OpeningTalk (8) | 실제 저장된 `position.engage=APPROACH`를 확인해야 Approach | 정지 |
| Approach (9) | 회랑 그룹을 대상으로 한 실제 W01 피해 기록 → CombatTalk | 흐름 |
| CombatTalk (10) | 실제 저장된 `position.mode=CENTER`를 확인하고 맺음 대사 [확인] → FinalFight | 정지 |
| FinalFight (11) | 남은 적 전멸 → Road3 (12) | 흐름 |

회랑 적은 필드 0의 원거리 슬롯 2 세 마리이며 `(54,21)`, `(57.5,24)`, `(54,27)`에 배치했다. 체력 140, 공격 2로 시작하며 `lastSeenTime=-100`을 사용한다. 첫 적·포위·회랑을 그룹 0·1·2로 분리해 앞 구간의 판정과 추적 갱신이 뒤 구간을 깨우지 않는다. 영웅 체력 0 보호는 유지한다.

## 기존 UI와 저장 연결

- 위치 패널과 칙령 시트를 새로 만들거나 재설계하지 않았다. 기존 `GameUI.EdictSheet`·`GameUI.EdictPosition`·`PrologueGate`·`TutorialAnchorRing`을 사용한다.
- 처음 첫 교전 위치는 **제자리에서 맞이(STAND)**, 접근 방식은 **걷기 이동(WALK)**이다. 새 대사와 안내는 다른 접근 방식을 언급하지 않는다. 기존 패널의 라디오 두 개는 유지한다.
- `GameStore.UnlockGuideEdict(run)`은 실제 안내 튜토리얼의 첫 교전 위치 대화에서 **첫 교전 위치·접근 방식·전투 중 위치 세 옵션만** 거래로 공개한다. 리플레이·분리된 체크포인트·수업이 없는 단계는 거부하며 중복 공개는 거래를 다시 만들지 않는다.
- 첫 교전 위치와 접근 방식은 3구간과 공통인 `GuideTutorial.TaughtOptions` 직접 편집 허용 목록에 추가했다. 미공개 옵션의 검증은 유지하며 Details나 전체 칙령 공개는 졸업 전 부여하지 않는다.
- 공개 거래 후 `Data.guide.tutorialRun`을 살아 있는 런으로 다시 연결한다. 위치 선택은 기존 `SheetApply` → `CommitHuntEdict(..., simulation, true)`로 영웅과 실제 전투에 함께 저장한다.
- 가림막은 매 프레임 실제 저장값으로 다음 목표 하나를 고른다. 사냥 칙령 버튼 → 전투 아이콘 → 필요하면 위치 그룹 → 해당 위치 탭 → 즉시 접근/무리 중심 순서다. 패널 재배치 후 새 버튼을 다시 찾는다.
- 회오리 HUD 수업의 `GuideLessonActive` 의미는 유지하고 수업 종류만 skill/opening/combat으로 구분했다. 전투 중 위치 저장 후 맺음 대사를 보여 준 뒤 [확인]에서 전투를 재개한다.
- 마지막 체크포인트 범위는 흐름 6일 때만 `GuideTutorial.Last=25`로 검사한다. 다른 튜토리얼의 한도와 저장 검증은 유지한다. 앱 중단 후 처음부터 다시 시작하는 기존 정책도 유지한다.
- 벨리나는 플레이어에게 존댓말로 말한다. 1구간 대사와 졸업 처리는 유지하고, 새 문구 19개를 기존 한국어 키/영어 표에 추가했다.

## 검증

최종 통합 후보에서 전체 Edit Mode를 한 번 완료했다: **6,036 통과·0 실패·기존 보류 4**, 3,962초. 이후 실제 화면 검증에서 발견한 스크롤 가림과 설명 카드의 순번 가림을 보완했다. 영향을 받는 GuideTutorialTests·PrologueGateTests **20개**와 UI 계약 회귀 **15개**, UI 갱신 검사(15 바인딩)가 통과했다. 전투·저장·데이터·패키지는 전체 검사 당시와 같으므로 전체 묶음을 반복하지 않았다.

macOS 개발 플레이어의 **10/10** 조합이 통과했다. KO/EN 각각 440×956, 956×440, 1600×900, 1600×1000, 2100×900, 기본 글자 크기다. 가림막 실제 레이캐스트 44번(기술 4·첫 교전 3·전투 중 위치 4·대상 16·보물 9·회수 8), 설명 중 순번, 화면 안 고블린, 직접 닫기, 금화·희귀 장비 지급과 저장 재열기, 졸업 거래 1회를 확인했다. 캡처에서 가려졌던 보물 버튼을 스크롤로 드러내고 설명 카드는 1번 표시를 피하도록 조정했다. 최초 검사 도구의 좌표 조회 오류와 UI 실패 근거는 작업 검증 폴더에 보존한다.
