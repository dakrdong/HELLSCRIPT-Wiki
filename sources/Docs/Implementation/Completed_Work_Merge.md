# 완료 작업과 이미지 리소스 통합

2026-09-22 · [English](Completed_Work_Merge.en.md)

기존 `main`의 위상 각인석·대장간·공통 UI를 기준으로, 남아 있던 스킬 구현·기획과 이미지 제작 결과, 위상 각인석 HTML 시안을 한 통합본으로 합쳤습니다. 원본 작업 폴더와 이미지 제작 폴더의 미커밋 변경은 수정하거나 되돌리지 않았습니다.

로컬 `codex/` 작업 브랜치 33개의 마지막 커밋과 원격 작업 브랜치가 통합본에 포함되는지 확인했습니다. 오래된 원본·검증 폴더에 남은 코드는 기존 병합 기록과 대조했습니다. 최신 기능을 과거 코드로 덮어쓰지 않았습니다.

## 유지한 공개 상태

스킬 구현의 `playerEnabled=false`를 유지합니다. 신규 기술·40레벨 성장·추가 장비는 기존 개발 검증 조건을 따르며, 이번 병합이 일반 플레이 공개나 신규 UI 연결을 활성화하지 않습니다.

이미지 501개는 원본과 제작 후보 상태를 보존했습니다. 생성 모델은 모두 `unknown`이며, 이번 병합은 출시 승인이나 화면 채택을 의미하지 않습니다. 위상 문양은 141개 계획 중 123개가 존재하고 122개가 시각 검수를 통과했습니다. `LM29`는 검수 실패 상태이고 신규 연계 문양 18개는 미제작 상태입니다. 다른 위치의 완료 파일은 없음을 사용자에게 확인했습니다. 자세한 목록은 [제작 인계 기록](../Art/Skill_Resource_Delegation.md)에 있습니다.

## 통합 시 조정한 부분

- 저장 형식 9와 위상 수집·장비 강화·슬롯 성장 상태를 유지하면서 스킬 저장을 연결했습니다. 스킬 저장이 있는 계정을 읽을 때 형식을 과거 버전 7로 낮추지 않습니다.
- 전투 스냅샷·이동 속도·피해 계산에는 위상 레벨과 신규 스킬 효과를 함께 보존했습니다.
- 스킬 기획의 원래 파일 지문은 바꾸지 않았습니다. 검증기는 이미 병합된 슬롯 성장의 유효 스킬 등급 상한 변경과 새 장비 베이스 추가를 구분하며, 기존 수치·정의 변경은 계속 거부합니다.
- 동일한 README 이름을 가진 두 제작 안내의 위키 주소를 구분했습니다. 기존 주소와 문서 이력을 유지합니다.
- 아직 없는 위상 검수 시트의 링크를 제작 대기 표시로 바꾸고, 과거 검증 보고서를 그대로 보존했습니다.
