# 공통 UI 양식 개편: 흑요석·금박

작성일: 2026-09-29 · [English](Ui_Style_Obsidian_Gilt.en.md)

기존 공통 버튼은 두꺼운 검은 외곽선과 돌출 음영을 사용했고, 화면 바탕은 올리브빛을 띠었습니다. 그래서 게임 전체가 투박하고 오래된 인상을 주었습니다. 이번 작업에서는 이전 양식을 모두 걷어 내고 **흑요석·금박(Obsidian & Gilt)** 양식을 새로 만들어 공통 소유자에 적용했습니다. 이어서 화면마다 공통 양식에서 어긋나 있던 부분을 찾아 함께 고쳤습니다.

## 설계 방향

- **바탕**은 따뜻한 흑요석색 단계(`Void`→`Inset`→`Background`→`Panel`→`Raised`→`Hover`)로 구성합니다. 녹색 기운을 없애서 타이틀 원화의 회색 석조·잉걸불과 어울리게 했습니다.
- **선**은 한 가닥의 가는 청동색(`Border`, `Edge`)만 사용합니다. 금색(`Gold`, `GoldBright`)은 선택된 대상과 주요 행동에만 사용합니다.
- **버튼**은 모서리를 깎은 팔각 형태입니다. 한 줄의 테두리, 위에서 아래로 어두워지는 면, 안쪽 위의 가는 빛, 아래에서 올라오는 은은한 빛으로 구성합니다. 검은 외곽선과 돌출 음영은 제거했습니다.
- **탭**은 상자 대신 한 줄의 띠로 읽히게 합니다. 선택된 탭은 금색 밑줄과 가운데 마름모, 위로 번지는 빛으로 표시합니다.
- **창**은 머리글 아래에 양 끝이 사라지는 금박 구분선과 가운데 마름모를 두고, 네 모서리에 금박 꺾쇠를 둡니다.

## 역할별 표시

| 역할 | 평상시 | 선택·강조 |
| --- | --- | --- |
| 일반 행동(`Action`) | 흑요석 면과 청동 테두리 | 마우스를 올리면 금색 테두리와 아래쪽 빛이 나타납니다. |
| 주요 행동(`Primary`) | 호박빛 금 면, 금박 이중선, 양옆 마름모 | 한 화면에서 확정하는 행동 하나에만 사용합니다. |
| 위험 행동(`Destructive`) | 짙은 핏빛 면과 잉걸불색 테두리 | 분해 확정 같은 되돌릴 수 없는 행동에 사용합니다. |
| 선택지(`Option`) | 한 단계 어두운 면 | 선택되면 금색 테두리와 아래쪽 금색 선을 표시합니다. |
| 조용한 버튼(`Quiet`) | 면 없이 흐린 테두리만 표시 | 닫기 `×` 같은 보조 조작에 사용합니다. |
| 탭(`Tab`) | 공통 밑줄만 표시 | 선택되면 금색 밑줄, 마름모와 빛을 표시합니다. |

누름·키보드 초점·사용 불가·순차 잠금의 입력 계약은 [공통 버튼과 탭의 상호작용](Button_UX.md)을 그대로 따릅니다. 이번 작업은 표시만 바꾸었으며 클릭 영역, 레이아웃과 계정 저장 경로를 바꾸지 않았습니다.

## 소유 코드

- `UiTheme`: 흑요석·금박 색 단계와 역할별 버튼 색을 소유합니다. `Tint(hex, alpha)`는 투명도가 필요한 토큰 색을 만듭니다.
- `UiButtonFace`: 팔각 면·테두리·빛·장식을 하나의 벡터 메시로 그립니다. 텍스처와 머티리얼 인스턴스를 만들지 않습니다.
- `UiMesh`: 깎인 사각형의 채움·테두리·높이별 그라데이션·마름모·꺾쇠를 그리는 공통 도형 함수입니다.
- `UiWindowFrame`: `ContentWindowView`의 창틀입니다. 기존 코드가 `Image.color`로 창틀을 숨길 수 있도록 `Image`를 상속합니다.
- `UiHeaderRule`: 자체 머리글 배치를 유지하는 창고·가방·대장간·장비 상인·룬 마스터·사냥 칙령에 같은 금박 구분선을 붙입니다.
- `UiButton`: 새 면이 기존의 사각 바탕 위에 겹치므로 자기 바탕 이미지를 보이지 않게 합니다. 바탕은 계속 레이캐스트를 받으므로 클릭 영역은 그대로입니다. 장비·아이콘처럼 내용이 있는 그래픽은 건드리지 않습니다.

## 공통 양식에서 어긋난 부분의 개선

| 어긋난 부분 | 개선 |
| --- | --- |
| 29개 화면 파일에 바탕·테두리·금색을 16진수 문자열로 직접 적은 340곳 | 가장 가까운 공통 토큰으로 옮겼습니다. 등급·원소·위험·성공·Google 브랜드 같은 의미 색은 유지했습니다. |
| 창 바탕에 실수로 적은 올리브색 12곳(마을 상호작용 카드, 균열 입장·결과, 룬 보드, 칙령 스킬, 이야기 대화창, 훈련장 DPS 패널) | `UiTheme.Tint` 토큰으로 옮겼습니다. 월드 조명(`FieldLook`), 지도, HUD 배치, 타이틀 원화 보정 색은 원화에 맞춘 값이므로 유지했습니다. |
| 위상 각인석 단계·모험 안내·보상 상자 분류가 탭을 주요 행동 버튼으로 그림 | `ContentWindowView.Tab`을 추가하고 탭 역할로 바꾸었습니다. |
| 장비 상인·룬 마스터의 탭이 선택지 칩으로 표시됨 | 탭 역할(`tab-current`/`tab-idle`)로 바꾸었습니다. |
| 보석상의 ‘소켓 관리’가 탭 띠 안에서 일반 버튼으로 표시됨 | 선택되지 않은 탭으로 표시합니다. |
| 닫기 버튼이 `×`·`X`·`닫기`로 제각각 | 머리글의 닫기를 모두 `×` 조용한 버튼으로 통일했습니다. 하단 행동 영역의 ‘닫기’는 명시적 행동이므로 유지했습니다. |
| 타이틀 버튼 위에 타이틀 전용 사각 금테가 덧그려짐 | 버튼에서는 금테를 빼고 공통 면만 사용합니다. 패널 장식은 유지했습니다. |
| 공통 창 제목이 머리글 위쪽에 붙어 있음 | 제목을 머리글 높이의 가운데에 맞추고, 모서리 꺾쇠와 겹치지 않게 옮겼습니다. |

같은 어긋남이 다시 생기지 않도록 `tools/check_ui_contract.py`가 화면 코드에 적은 바탕·테두리·금색·본문색 계열의 16진수 문자열을 오류로 보고합니다. `UiTheme`과 등급 색 소유자는 제외합니다. `tools/test_ui_contract.py`에 위반 주입 검사와 의미 색 허용 검사를 추가했습니다.

## 검증

- 공통 UI 소유 검사가 통과했고, 회귀 검사 11개가 모두 통과했습니다.
- 관련 Unity Edit Mode 28개 묶음 **654개 중 653개가 통과**했습니다. 실패한 `TutorialProgressionTests.EdictAndNewSkillRequireCommittedChangeThenMatchingTrainingAndFreshRift`는 스킬 트리 데이터에서 레벨 3 액티브 스킬을 찾는 검사입니다. 변경 전 `main`에서도 같은 결과로 실패하는 것을 확인했습니다. [검사 XML](UiStyleEvidence/editmode.xml)
- macOS 개발 빌드에서 새 실행 시나리오 `-hellscriptUiStyleSmoke`로 버튼 견본과 창고·가방·장비 상인·대장간·사냥 칙령(요약·스킬)·보석상·위상 각인석·균열 입장·모험 안내·설정·마을·타이틀을 캡처했습니다. `main`의 훈련장을 합친 뒤에는 훈련장 창을 추가해 1440×810 한국어·440×956 영어·1680×720 한국어 150%에서 다시 확인했습니다. 1440×810·1440×900·1680×720·440×956·956×440 × 한국어·영어 × 글자 100%·150%의 **20조합**에서 종료 코드 0으로 끝났습니다. [실행 결과](UiStyleEvidence/runtime.txt)
- 기존 `-hellscriptButtonUxSmoke`는 마우스 올림·누름·밖으로 나가 취소·선택 유지·키보드 초점과 제출·구매 취소·정확한 비용 차감을 통과했습니다. 이후 단계에서는 변경 전 `main`도 실행할 때마다 다른 지점에서 실패합니다. 제가 확인한 원인 하나는 실행 중인 계정의 `lastSeenUtc`가 초 경계를 넘으면서 ‘탐색이 계정을 바꿨다’는 비교가 실패하는 것입니다. 이 시나리오 자체의 시간 의존 문제이며 이번 작업에서 고치지 않았습니다.
- 캡처는 macOS 창에서 재현한 화면 비율입니다. **모바일 실기기 터치와 성능은 확인하지 않았습니다.** 캡처는 화면 표시의 근거이며, 조작과 저장의 근거는 위의 버튼 조작 시나리오와 Edit Mode 검사입니다.
