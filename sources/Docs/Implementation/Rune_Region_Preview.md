# HELLSCRIPT 잠긴 룬 영역 미리보기

작성일: 2026-09-17

## 받은 기획

사용자가 `HELLSCRIPT-RuneBoard-Elite-Preview-v13.zip`을 전달했다. 웹 실행 시안 v12를 갱신한 UI 수정 패키지이며, 지시문은 `CLAUDE-PATCH-v13.md`와 `CHANGE-SPEC-v13.md`에 있다.

요구는 하나다. 잠긴 주변 영역을 눌렀을 때 **그 영역 정중앙 칸의 능력만** 미리 보여 준다. 지시문은 다음을 못박았다.

- 지역 이름으로 여섯 설명을 하드코딩하지 않는다. 선택한 무기와 영역 중앙 좌표로 실제 노드를 찾고, 그 노드가 가리키는 능력을 읽는다.
- 중앙 데이터가 없으면 다른 능력으로 대체하지 않고 확인 불가 문구를 낸다.
- 열람이 슬롯 개방이나 능력 활성으로 이어지지 않는다.
- 개방 조건·비용·연결 규칙·보드 입력 정책은 바꾸지 않는다.
- HTML 자동 검사 결과를 Unity·실기기 검증으로 보고하지 않는다.

## 시안과 게임의 차이

시안과 Unity 게임은 같은 이름의 다른 보드다. 이번 작업 범위를 정하기 위해 먼저 둘을 맞춰 보았다.

| 항목 | 웹 시안 v13 | Unity 게임 (현재) |
|---|---|---|
| 영역 구분 | 맹공·정밀·파급·기교·순환·수호 6개 | 색 등급 G0~G6의 7개 영역 |
| 영역 개방 | 중앙 37칸을 채운 뒤 1곳 선택, 나머지 36칸을 1P씩 구매 | 계정 최고 실클리어 5단계마다 자동 개방, 포인트 없음 |
| 영역 중앙 | `color:"elite"` 전용 능력. 모든 색 룬으로 활성 | `isStart` 시작칸. 그 영역의 색 룬만 활성 |
| 중앙 능력 | 전투 열기·급소 노출·연쇄 붕괴·기술 전승·순환의 핵·불굴의 결계 | 이 작업 당시에는 여섯 무기 모두 공격력. 이후 [엘리트 능력](Rune_Elite_Centres.md)에서 여섯을 넣었다 |
| 자물쇠 | 잠긴 영역은 자물쇠 표식 하나로만 그린다 | 잠긴 영역도 칸을 모두 그린다. 어두울 뿐 누를 수 있다 |
| 능력 아이콘 | 능력마다 `glyph` 심볼 | 룬 보드에는 능력 아이콘이 없다. 테두리 색·점·십자로 구분 |

그래서 시안의 자물쇠 팝업을 그대로 옮길 수 없다. 팝업이 담는 `개방하기` 버튼과 `중앙 1칸 무료 · 나머지 36칸 × 1P` 안내는 Unity에 대응하는 규칙 자체가 없고, 시안이 미리 보여 주는 여섯 엘리트 능력은 시안 자료에 `origin:"new"`, `source:"proposal"`로 표시된 신규 제안이라 Unity 능력 데이터에 없다.

옮길 수 있는 것은 **구조**다. 잠긴 영역을 열기 전에 그 영역 중앙 칸을 실제 데이터로 읽어 보여 주고, 열람이 아무것도 바꾸지 않게 한다.

## 적용

Unity에서 잠긴 영역에 해당하는 조작은 이미 있다. 잠긴 칸을 누르면 `InspectRuneCell`이 아래 선택 정보에 그 칸의 능력과 `잠긴 영역입니다.`를 적는다. 새 팝업을 만들지 않고 이 자리에 중앙 미리보기를 덧붙였다.

잠긴 영역의 칸을 누르면 기존 세 줄 뒤에 두세 줄이 더 붙는다.

```
공격력 +0.4
요구: G1 · 수치 등급 0 · 영역 개방 G1
잠긴 영역입니다.
상아 영역은 계정 최고 실클리어 5단계에서 열립니다.
중앙 시작칸 미리보기 · 공격력 +0.4 · 요구 상아
미리 보기만 합니다. 칸이 열리거나 능력이 켜지지 않습니다.
```

중앙 칸을 직접 누른 경우에는 같은 내용이 두 번 나오지 않도록 미리보기 줄을 생략한다.

조회 순서는 지시문 그대로다.

1. 현재 편집 대상 무기의 보드 `runeEditor.Board`.
2. 누른 칸의 영역 등급 `cell.RegionGrade`.
3. 그 등급의 시작칸 좌표 `Board.TryGetStart(regionGrade, …)`.
4. 그 좌표의 실제 칸 `Board.TryGetCell(…)`.
5. 칸의 `Ability.Meaning`으로 이름을, `Value`·`Unit`으로 수치를, `RequiredRuneGrade`로 요구 색을 읽는다.

가져온 칸이 그 영역의 것이 아니거나 시작칸이 아니면 다른 칸으로 대체하지 않고 `이 영역의 중앙 칸 정보를 확인할 수 없습니다.`를 표시한다.

개방 조건 문구의 단계 수는 `RuneMasteryCatalog.ClearForGrade`가 계산한다. 개방 판정 `UnlockedGrade`가 `최고 실클리어 / 5`이므로 그 역을 바로 옆에 한 줄로 두었다. 두 식이 어긋나면 미리보기가 잘못된 단계를 안내하게 되므로 검사에서 0~6 전 등급을 맞춰 본다.

## 바꾸지 않은 것

능력 데이터, 보드 좌표, 시작칸 강제 규칙, 색 요구 판정, 영역 개방 규칙, 저장 스키마와 저장 키, 룬 배치·회수·회전·드래그, 보관함 필터, 합성, 프리셋, 배치 연습은 그대로다. 보드 그리기(`RuneBoardGraphic`)도 건드리지 않았다. 잠긴 영역은 이미 칸 전체가 그려져 있어 누를 자리가 있으므로 자물쇠 표식을 따로 넣지 않았다.

시안에 있는 `룬 보드 정보`·`개방하기` 두 버튼과 비용 안내는 옮기지 않았다. 대응하는 규칙이 Unity에 없어 옮기면 없는 기능을 있는 것처럼 보이게 된다.

능력 아이콘도 넣지 않았다. 룬 보드의 능력은 스탯 의미(`AttackPower` 등)와 스킬 번호로만 정의되어 있고 그림이 없다. 아이콘을 넣으려면 능력별 그림을 새로 만들어야 하므로 이번 범위 밖이다.

## 검사

Unity Edit Mode, 저장소 사본에서 실행했다.

| 대상 | 결과 |
|---|---|
| `RuneMasteryTests` · `RuneEconomyTests` · `LocalizationTests` | 74 / 74 통과 |

새로 넣은 `EveryLockedRegionCentreIsItsOwnStartSlotOnTheSelectedWeaponBoard`는 여섯 무기 × 일곱 영역에서 다음을 확인한다.

- 각 영역의 중앙이 그 영역의 시작칸이고 요구 색이 그 영역의 색이다.
- 두 영역이 하나의 중앙을 나눠 쓰지 않는다.
- 영역의 모든 칸이 그 중앙에서 반지름 4 안에 있다. 중앙이 실제 정중앙이라는 뜻이다.
- 중앙 능력 이름이 비어 있지 않다.
- `ClearForGrade`가 정한 단계에서 그 영역이 열리고, 한 단계 모자라면 열리지 않는다.

기존 `EveryKoreanLiteralInTheRuntimeHasAnEntry`가 새 문구 네 개의 영어 항목을 확인한다.

macOS 개발 빌드의 런타임 스모크 `-hellscriptRuneSmoke`에 잠긴 영역 열람을 넣었다. 세로 720×1280 한국어와 가로 1280×720 영어에서 영역 1의 중앙이 아닌 칸 (5,-8)을 실제로 눌러 미리보기 여섯 줄이 나오는지 확인하고, 이어서 중앙 (5,-9)을 눌러 미리보기 줄이 되풀이되지 않는지 확인한다. 마지막으로 누르기 전후의 계정 저장 JSON이 같은 바이트인지, 개방 등급과 배치 수가 그대로인지 확인한다. 근거로 [세로 한국어 화면](RuneRegionPreviewEvidence/06-locked-region-preview-ko.png), [가로 영어 화면](RuneRegionPreviewEvidence/07-locked-region-preview-en-landscape.png), [실행 기록](RuneRegionPreviewEvidence/runtime.txt), [스모크 출력](RuneRegionPreviewEvidence/smoke-result.txt)을 남겼다.

**스모크는 실패로 끝난다. 이번 변경 이전부터 있던 실패다.** 화면을 찍을 때마다 전역 관찰 HUD의 `Shield` 라벨 하나가 걸린다. 값이 비어 있는데 칸 높이 9.6이 글꼴 한 줄 높이 12보다 낮다 (글자 크기 140%에서는 13.44 대 16). 이번 변경의 다섯 파일을 모두 HEAD로 되돌린 사본에서 같은 스모크를 다시 빌드해 돌려도 아홉 화면 전부에서 같은 실패가 나온다. 이번 변경이 더한 두 화면도 같은 라벨 하나만 보고한다. 전역 HUD 작업의 것이므로 건드리지 않았다.

검사는 macOS 개발 빌드에서만 돌렸다. 실제 모바일 기기에서는 보지 않았다. 시안 ZIP의 QA 결과는 브라우저 시안에 대한 것이므로 이 구현의 근거로 쓰지 않았다.

## 남은 일

시안의 여섯 엘리트 능력(전투 열기·급소 노출·연쇄 붕괴·기술 전승·순환의 핵·불굴의 결계)은 이 문서를 쓸 당시 게임에 없었다. **같은 날 [룬 영역 중앙의 엘리트 능력](Rune_Elite_Centres.md)에서 여섯을 모두 넣었다.** 이번 미리보기는 코드 한 줄 바꾸지 않고 새 중앙 능력을 그대로 읽는다. 다만 시작칸의 색 요구는 그대로 두었으므로 '모든 색으로 활성'은 옮기지 않았다. 이유는 그 문서에 적었다.

포인트로 슬롯을 사는 개방 방식, 능력별 아이콘, 자물쇠 팝업 형태의 화면은 룬 보드 전체를 시안에 맞추는 별도 작업이다.
