**후속 구현:** 2026-09-12에 [화염구 M01의 네 핵심 옵션](Edict_Fireball_Expansion.md)을 추가로 연결했다. 2026-09-13에는 [눈보라 M02의 다섯 핵심 옵션](Edict_Blizzard_Expansion.md)을 연결했다. 아래 네 스킬 표와 검사 수량은 2026-09-11의 범위를 보존한 기록이다. [English M02 record](Edict_Blizzard_Expansion.en.md).

## 적용 범위

[조준·명중 예측 기록](Edict_Aim_Expansion.md)은 분쇄 일격, 관통 사격, 다중 사격, 연쇄 번개의 조준 계획을 계산하는 `PlanEdictAim`을 만들었지만, 그 결과를 시전에 전달하는 경로는 남겨 두었다. 이 단계가 그 경로다. [전역 정책](Edict_Policy_Expansion.md)과 [공격 순서](Edict_Order_Expansion.md)에 이어 P0 전투 연결의 마지막 조각이다.

## 연결 방식

규칙 판단은 실행 가능한 첫 규칙을 고른다. 이제 실행 가능한 스킬 규칙이 위 네 스킬 가운데 하나이고 사냥 칙령이 켜져 있으면, 고르기 전에 조준 계획을 먼저 묻는다.

| 계획 결과 | 처리 |
|---|---|
| 지원하지 않는 스킬 | 기존대로 진행한다. 다른 스킬은 조준 단계가 없다. |
| 사용 가능 | 계획이 고른 대상과 조준점을 후보에 싣고 그 규칙을 실행한다. |
| 사용 불가 | 그 규칙을 이번 회차에 건너뛰고 다음 실행 가능한 규칙으로 넘어간다. 판단 기록에는 `EDICT_AIM` 코드와 사유를 남긴다. |

“사용 불가”는 쿨타임이나 자원이 아니라 그 스킬에 정한 용도가 지금 충족되지 않는다는 뜻이다. 관통 사격의 “사용할 상황”이 기본값인 정예·보스 또는 두 명 이상이면, 일반 적 한 명에게는 쏘지 않는다. 이것이 핵심 옵션 상세안이 정한 동작이므로, 사냥 칙령을 켠 영웅은 같은 규칙이라도 켜기 전과 다르게 행동할 수 있다.

시전 명령은 그동안 대상의 중심을 조준점으로 삼았다. `StartHeroAction`에 조준점을 따로 넘길 수 있게 하고, 계획이 준 조준점을 그대로 전달한다. 발사 코드는 이미 행동의 조준점에서 방향을 읽고 있었으므로, 분쇄의 부채꼴, 관통·다중 사격의 사선이 계획대로 나간다. 연쇄 번개는 계획이 고른 첫 대상이 그대로 행동의 대상이 된다.

조준 계산 중 예외가 나면 [전투 연결](Edict_Drive_Expansion.md)의 생존 판단과 같은 방식으로 그 판의 사냥 칙령만 중단하고 기존 규칙으로 계속 싸운다. 정책 사본도 함께 내려 꺼진 상태와 같아진다.

## 검증

전체 Edit Mode 검사 **1,111개**가 통과했다. 이 중 조준 연결 검사는 7개다. 모두 조건 없는 규칙 하나와 훈련장의 고정 표적 하나로 구성해 시전 여부가 조준 단계에만 달리게 했다.

| 검사 | 확인한 결과 |
|---|---|
| 꺼진 상태 | 관통 사격이 표적에게 나가고 조준 단계는 한 번도 참조되지 않는다. |
| 기본 용도 | 정예·보스 또는 두 명 이상이 기본값인 관통 사격은 일반 적 한 명에게 400틱 동안 0회 시전되고, 계획은 지원하되 사용 불가로 읽히며 `EDICT_AIM`이 기록된다. |
| 용도 변경 | 한 명부터로 바꾸면 시전되고, 모든 시전이 조준 단계를 거치며, 행동의 대상이 계획의 대상과 같다. |
| 조준 단계 없는 스킬 | 화염구는 영향을 받지 않고 조준 단계를 참조하지 않는다. |
| 연쇄 번개 기본값 | 단독 적도 공격이 기본값이라 한 명에게도 계획을 거쳐 시전된다. |
| 연결 요구 | 연결되는 적 위주로 바꾸면 한 명에게는 시전되지 않고 사유가 기록된다. |
| 결정성 | 같은 설정의 두 실행이 시전 수까지 같다. |

이전 단계의 공격 순서 검사도 그대로 통과했다. 그 검사는 연쇄 번개를 쓰는데, 연쇄 번개의 기본 용도가 한 명에게도 허용되므로 조준 단계를 거쳐도 결과가 같다.

`Artifacts/Validation/edict-aim-wire-editmode.xml`에 보고서를 보존했다.

## P0 전투 연결의 현재 범위

| 원본 항목 | 전투 반영 |
|---|---|
| 전역 생존·회피 | 정기 판단에서 먼저 실행한다. |
| 전역 정책 (대상·위치·물약·전리품·가방·탐색·반복) | 기존 정책 필드로 파생해 읽는다. |
| 공통 행동 우선순위·공통 공격 순서·자동 사용 | 규칙 검사 순서와 검사 여부를 정한다. |
| 네 스킬의 조준·용도 | 시전 전 계획을 묻고 조준점을 전달한다. |
| 나머지 스킬별 핵심 옵션 | 저장·편집되지만 아직 행동을 바꾸지 않는다. 사용할 상황·우선 대상·시점 같은 값은 별도 판단 경로가 필요하다. |
| 회피 규칙 세부·몰이·추적 한도·가방 보호·시간 부족 대응 | 기존 전투에 대응하는 값이 없어 연결하지 않았다. |

## 남은 범위

| 남은 항목 | 내용 |
|---|---|
| 나머지 스킬 옵션 | 위 표의 미반영 항목을 규칙 조건으로 옮기거나 새 판단 경로를 만들어야 한다. |
| 실제 앱 확인 | Edit Mode 검사로만 확인했다. 실제 균열에서 조준점이 바뀐 사선을 관찰한 기록은 없다. |
| 조준 비용 | 조준 계획은 여러 방향을 예측한다. 판단 회차마다 최대 네 스킬을 계산하며, 긴 판의 실제 기기 비용은 측정하지 않았다. |
