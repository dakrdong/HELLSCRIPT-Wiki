## 범위와 시작점

- 사용자 지시에 따라 `23ed052c` (`origin/claude/monster-registry`) 위의 `codex/monster-codex`에서 시작한다. 계획서 4.0의 main 선행 조건을 이번 지시로 대체한다.

- 전투 밸런스 변경은 범위 밖이다. 훈련장과 튜토리얼 리플레이는 집계하지 않고, 실제 튜토리얼·가이드·퍼즐은 집계한다. 아이콘은 사냥 칙령 아래이며 프롤로그에서도 같은 조건으로 보인다.
- 레지스트리 선행 조건은 PR #99가 main에 들어오며 충족됐다. 2026-10-12에 main `0082abdb`를 기존 도감 브랜치에 통합했다. 도감의 main 병합은 최종 통합 검증 뒤 진행한다.

## 진행

1. 저장·처치 기록: 완료. 런 스냅샷에 ID별 카운터와 결산 플래그를 저장하고, 기존 GameStore 저장/튜토리얼 결산 거래에 합산한다. 실패한 디스크 쓰기는 도감 상태와 결산 플래그를 복원한다. 훈련·리플레이·미등록 ID는 제외한다.
2. 목록·가로 상세·문구: 완료. 레지스트리 항목과 필드 탭·분모를 읽고, 미발견 카드는 비활성화한다. EnemyStats와 기존 기술 피해 정의를 공유하며 지속 피해는 실제 틱 간격으로 초당 환산한다. 슬라이더는 드래그 중 본문·트랙을 재생성하지 않는다. 영어의 암흑 두 줄은 Shadow로 맞췄다. 보스 둔화는 현재 코드에서 제압 누적으로 처리하므로 그 동작을 표시한다.
3. 세로 상세·보스 아이콘·포효: 완료. 레지스트리 태그로 기술 칩을 만들고 skills[].icon으로 보스 아이콘을 읽는다. 공통 포효가 두 페이즈 사이에 들어간다. 짧은 안전 영역에서는 고정 조작 줄을 유지하고 본문을 스크롤한다.
4. 독 아이콘·진입점: 완료. 선택한 A PNG의 바이트·알파를 보존하고 공통 메뉴 텍스처 예산을 사용한다. 성소·전투·프롤로그의 사냥 칙령 바로 아래에서 공통 창 호스트로 연다.
5. 최종 통합·검증·캡처·PR: main 통합·충돌 해결·관련 검사 완료. 전체 EditMode·macOS 스모크·실제 KO/EN 캡처·main 병합은 최종 조정 단계에 남아 있다.
