# 장판 조준·추적과 독·서리 세트의 시간 처리

작성일: 2026-09-09 · 단계: D3 진행 중

## 1. 기준과 구현 범위

[장비 상세 명세](../Design/HELLSCRIPT_Itemization_Detail.md)의 LM01·SA 4·SM 4와 [콘텐츠 카탈로그](../Design/HELLSCRIPT_Content_Catalog.md)의 A03·M02 설치 설정을 연결했다. [플레이 완료 기준](../Design/HELLSCRIPT_Gameplay_Completion_Checklist.md)의 CHK-A02 조준 선택과 CHK-S02 효과 복원에 해당한다. 이전 같은 틱 사망·보상 정산은 [정산 개발 기록](Outcome_Expansion.md)을 따른다.

실행 소유자는 기존 `GameController → CombatSimulation`이며 장판·세트 처리를 `CombatSimulation.Areas.cs`에 모았다. 새로운 전투 관리자나 별도 전투 시간을 추가하지 않았다.

## 2. 설치 위치와 LM01 설정

| 선택 | 동작 |
|---|---|
| 목표 위치 | 선택한 유효 목표의 현재 위치에 설치한다. 기존 저장의 기본값이다. |
| 무리 중심 | 감지한 적의 위치와 두 적 사이의 중점을 후보로 삼는다. 실제 장판 반경·벽·사거리 안에서 가장 많은 적을 포함하는 위치를 고른다. 동률은 목표와의 거리, 영웅과의 거리, 좌표 순으로 정한다. 예상 명중 조건도 같은 위치 계산을 사용한다. |
| 자신 아래 | 준비를 시작한 영웅 위치에 설치한다. 적이 없어도 유효 지형이면 비용을 지불하고 시전할 수 있다. 이후 영웅이 걸어가더라도 설치 위치가 함께 움직이지 않는다. |
| 관측한 이동 경로 | 최근 두 번의 정상 관측에서 계산한 이동속도로 0.75초 앞을 조준한다. 0.4초보다 오래된 관측, 처음 본 적, 순간적인 큰 위치 변화, 이동 불가 상태에서는 현재 목표 위치를 사용한다. 예상 경로는 벽 앞에서 멈춘다. |

A03과 M02의 각 행동 규칙에 설치 위치를 둔다. 0.75초 예측과 밀집 후보 계산은 이번 개발의 시험안이며 모든 적 배치를 수학적으로 최적화한 조준이라고 보장하지 않는다. 잘못된 지형이나 사거리 밖의 설치는 비용·CD·준비를 시작하기 전에 차단한다.

LM01을 장착하면 M02 규칙에 ‘목표 추적 / 생성 위치 고정’ 선택지가 나타난다. 이전 LM01의 추적 동작을 보존하기 위해 저장에 선택값이 없으면 추적으로 읽는다. LM01이 없으면 선택값과 무관하게 고정 장판을 만든다. 아이템 설명도 영웅을 따라간다는 과거 문구에서 현재 목표를 추적하는 규칙으로 맞췄다.

설치 위치와 이동 선택은 준비 시작에 저장하고 실제 생성에 사용한다. 전투 중 설정 적용은 기존 계약대로 진행 중 준비를 취소하며 이미 지불한 비용을 돌려주지 않는다. 이미 생성된 장판은 설정 적용 후에도 자신의 위치·추적 여부·지속시간·이동 누적값을 유지한다.

추적 장판은 현재 감지 가능한 목표를 향해 초당 1m, 총 4m까지 이동한다. 목표가 죽으면 다음 의사결정에서 새 목표를 고를 때까지 멈추고, 감지 밖의 적을 추적하지 않는다. 이동으로 6초 수명이나 대상의 노출 시간을 다시 시작하지 않는다. 자기 눈보라는 최대 두 개이며 세 번째 생성 시 가장 오래된 자기 장판을 교체한다.

## 3. 피해·노출·갱신의 시간 계약

| 효과 | 처리 규칙 |
|---|---|
| M02 생성과 수명 | 생성 이전의 시간을 피해·이동·노출에 포함하지 않는다. 지연 종료와 수명 만료가 한 틱의 중간에 있으면 실제 활성 구간만 사용한다. 정상 6초 장판은 0.5초 간격으로 12번 피해를 준다. |
| 겹친 M02 피해 | 대상별 0.5초 주기를 공유한다. 같은 시간에 겹친 장판 중 생성 당시 공격력·가산 보너스·냉기 보너스를 적용한 공격값이 가장 큰 장판만 피해를 준다. 강한 장판이 먼저 끝나면 남은 약한 장판이 기존 주기를 이어받는다. 영역이 끊기면 미완성 주기는 다시 0.5초부터 시작한다. |
| M02 감속 | 피해를 제공하는 장판과 별도로 가장 강한 유효 감속을 적용한다. 같은 장판의 감속 발생 ID는 유지한다. 떠나거나 장판이 끝나면 그 장판에 연결된 감속을 제거한다. 보스 제압 적립은 지연·부분 면역·만료 구간에서 실제 적용된 최강 감속을 적분한다. |
| SA 4 생성 | 자기 A03 또는 LA03 중독이 있는 살아 있는 적에게 A01의 원 직접 타격이 적중하면 별도의 3초 독 효과를 만든다. 대상당 한 개이며 생성 1초 뒤부터 D80% 피해를 세 번 적용한다. 익명·다른 시전자·세트 독은 자기 덫 중독 조건을 대신하지 않는다. 잔영 사격도 생성하지 않는다. |
| SA 4 갱신 | 재적중은 남은 시간을 3초로 늘린다. 다음 피해까지 남은 시간은 유지한다. 기존보다 강한 공격값일 때만 공격 스냅샷과 원 공격을 교체한다. 만료 후 다시 생성하면 새 발생 ID와 1초 주기를 사용한다. 부분 만료 때문에 가상의 추가 피해를 주지 않는다. |
| SA 4 연쇄 제한 | 별도 독은 치명타를 추첨하지 않으며 덫 중독 태그·A06·LA04·자기 효과를 만들지 않는다. 원 덫의 지속 피해와는 공존한다. |
| SM 4 누적 | 자기 M02 안에서 연속 2초 노출되면 대상별 4초 표식을 생성한다. 장판이 겹쳐도 같은 시간을 한 번만 센다. 표식 완성 전 영역이 끊기면 누적을 지우고, 이미 완성한 표식은 영역 밖에서도 남은 시간 동안 유지한다. |
| SM 4 소모 | 다음 M01 원 폭발이 각 대상의 자기 표식을 한 번 소모하고 D100% 냉기 추가 피해를 준다. 보스도 적용한다. 원 폭발로 이미 사망한 적의 표식은 소비하지만 사체에 추가 피해 사건을 만들지 않는다. LM02 후속 폭발은 표식 소비 경로를 사용하지 않는다. |
| SM 4 재생성 | 소비 시 대상별 3초 CD를 시작한다. CD 또는 기존 표식이 남아 있는 동안 다음 노출을 미리 쌓지 않는다. 틱 중간에 제한이 끝나면 끝난 뒤의 활성 영역 시간만 새로 누적한다. |
| 사망과 효과 제거 | 같은 틱 사망 정산에서 독 스냅샷·표식·미완성 노출·대기시간을 제거한다. 해당 세트 효과를 잃는 합법적인 설정 경로에서도 남은 상태를 정리한다. |

전투는 기존 0.05초 고정 간격을 사용한다. 장판 안팎과 시야는 각 처리 단계의 위치 표본으로 판단하며, 시간 구간은 지연·수명·표식·CD 경계에서 나눈다. 한 틱 사이에 움직이는 두 원의 연속 교차 궤적을 해석하는 방식은 아니다. 이 한계를 모바일의 물리 프레임률 차이와 혼동하지 않도록 같은 고정 간격으로 저장·복원한다.

LM02 손 장비는 SM 손 부위와 경쟁하므로 SM 4와 동시에 장착하는 정상 빌드로 제시하지 않는다. 실제 조합 검증은 LM01 무기+SM 4, LA01 무기+SA 4를 사용한다.

## 4. 저장과 화면

효과 버전은 4, 행동 규칙 버전은 2다. 이전 규칙의 OR/AND 묶음·순서·ID를 보존하면서 새 선택값의 기본값을 적용한다. 더 새로운 버전의 규칙·효과는 기존 보호 경계에서 거절한다. 계정·지도·행동 동작 버전은 바꾸지 않았다.

효과 버전 3 이하에서 남은 세트 독·서리 표식·눈보라에 현재 영웅 출처를 연결한다. 출처가 없던 서리 표식에는 한 번만 발생 ID를 만들고, 원 공격이 일치하는 구형 M02 감속은 장판 ID와 연결한다. 이 변환은 이미 발생한 피해나 보상을 재실행하지 않는다. 감지 기록에는 관측 위치·시각 외에 속도와 유효 표본 여부를 저장한다.

전투 효과 상세 화면에서 눈보라별 고정/추적·남은 수명·총 이동거리를 확인한다. 대상별 서리 누적·완성 표식·재생성 대기, 세트 독의 남은 수명·다음 피해까지 남은 시간도 보여 준다. 화면을 확인하거나 설정을 편집하는 동안 전투 시간은 멈춘다. 버튼·문구·수치는 기존 UI로 만들었으며 새 이미지나 3D 모델은 추가하지 않았다.

네이티브 검증은 일반 그래픽 실행 프로세스 3개와 실제 재시작 2회로 진행했다. `areas-native-checkpoint.log`, `areas-native-resume.log`, `areas-native-poison-resume.log`의 완료 표지와 종료 코드 0, `AreaNativeEvidence/runtime-areas-smoke.txt`의 PASS를 확인했다. 사용자 저장과 분리한 `AreaNativeSave`를 사용했다.

마법사는 LM01 무기와 서로 다른 네 부위의 SM 세트를 사용했다. 실제 UI 버튼의 콜백으로 ‘자신 아래·생성 위치 고정’을 적용해 장판을 만든 뒤 추적 설정으로 바꾸고 두 번째 장판을 만들었다. 기존 고정 장판은 같은 위치를 유지했다. 전투 1.85초에 두 장판과 서리 누적 1.4초를 저장·종료했고, 재실행 후 실행 ID·시간·HP·자원·RNG·준비 행동·적·장판의 개별 값을 대조했다. 2배속으로 이어서 한 개의 서리 표식을 완성하고 실제 화염구로 3.25초에 한 번 소비했다. 추가 냉기 피해 1건과 표식 CD 3초를 확인했다. 실행 ID는 `2807e0afb2c244d0a3b8ce42ed561eb7`이다.

사냥꾼은 LA01 무기와 SA 네 부위를 사용했다. 실제 A03 덫을 무장·발동시킨 뒤 A01을 맞혀 1.60초에 독 발생 ID 16을 만들었다. 2.00초에 독 수명 2.6초·다음 피해까지 0.6초와 준비 중인 두 번째 A01을 저장했다. 다시 실행해 1.5배속으로 이어 갔으며, 준비 중이던 A01이 2.20초에 같은 독을 갱신했다. 갱신은 다음 피해 시간을 미루지 않았다. 피해는 2.60·3.60·4.60초에 세 번 발생했고, 갱신된 수명이 끝난 5.20초에 독 상태를 제거했다. 동일 발생 ID에서 생성 1회·갱신 1회·만료 1회와 치명타가 아닌 주기 피해 3건을 저장 자료로 대조했다. 실행 ID는 `a86ddb44e5b04008a6765a798d8aa486`이다. 이를 한 번의 A01만 사용한 검사로 설명하지 않는다.

Metal, 540×960 화면 10장을 저장했고 설치 선택·고정/추적 상태·서리 누적/완성/소모·독의 다음 주기와 만료 화면을 확인했다. 추가한 문구와 선택 버튼에 겹침·잘림은 없었다. 효과 목록과 기존 긴 피해 기록은 스크롤해서 확인한다.

검증용 적은 정지한 무해한 고HP 대상이며 영웅은 레벨 30이다. 겹친 장판을 만들기 위해 두 번째 M02 전에 CD와 자원을 한 번 복구했다. 이후 효과·피해·관측·저장·복원은 실제 처리기를 사용했다. UI 검사는 버튼 콜백을 호출한 것으로 물리 마우스·터치 검증이 아니다. Android 실기기·자연 성장·빌드 밸런스·온라인 정합성·성능을 검증한 결과로 사용하지 않는다. 종합 증거는 `Artifacts/Validation/areas-validation-summary.json`에 기록했다. 문서 로컬 링크 115개의 대상과 절 연결에도 오류가 없었다.

초기 신규 검사 실패는 생성 준비 시간·설치 뒤의 영웅 이동·부동소수점 허용 오차·실제로 벽을 가로지르지 않던 조준 시험 위치를 잘못 기대한 사례였다. 실제 명세에 맞게 검사 조건을 고쳤다. 정상 조합 검사에는 한 부위에 두 장비를 장착하지 못하도록 검사 준비 단계의 확인도 추가했다. 이후 독 처치의 제거 사유를 보완한 최종 256개 검사와 재빌드 결과를 위 증거로 사용한다.

## 6. 이어서 개발할 범위

이후 N01–N12·E01–E06의 구현·검증은 [적 콘텐츠 개발 기록](Enemy_Expansion.md)에 이어서 정리했다. 아래는 이 장판 단계 종료 시점의 후속 범위다.

1. D3의 일반 적 12종·정예 6속성·보스 3종을 독립 패턴과 정확한 예고·공격 출처·방향 판정으로 연결한다.
2. 전체 패시브·전설·세트의 실제 부위 조합 검사를 이어 간다. 이번 장판 검증으로 전체 콘텐츠나 빌드 밸런스가 완료됐다고 집계하지 않는다.
3. D4 성장·마을·훈련 비교·결과 분석, D5 온라인 계정·교차 저장·보석·결제, D6 Android 실기기·입력·아트·음향·성능 검증을 진행한다.

씬·프리팹·패키지·프로젝트 설정·이미지 원본은 이번 장판 변경의 편집 대상이 아니다. macOS 개발 실행은 Android 실기기나 온라인 서비스 검증을 대신하지 않는다.
