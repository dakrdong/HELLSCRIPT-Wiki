# 2026-09-30 작업 통합과 저장소 정리

2026-09-30 · [English](Repository_Integration_2026_09_30.en.md)

훈련장 개편, 균열 입장 화면, 대장간 HTML 시안과 균열 도중 마을에서 대장간을 이용하는 수정을 최신 `main`에 병합했습니다. 이미 반영된 균열 결과·장비 아트·스킬 전투 미리 보기의 이력도 대조했습니다.

## 병합 원칙

- 최근 제거한 글자 크기 설정과 확대 글자 전용 검사를 복원하지 않았습니다. 현재 화면 검증은 기본 글자 크기에서 수행합니다. 과거 확대 글자 캡처는 당시 검증 기록으로 보존합니다.
- 공통 `RiftSkillShareView`에 훈련장 편집 버튼을 연결하면서 균열 결과의 기존 기여도 표시를 유지했습니다. 두 콘텐츠의 이미지 크기 제한과 공통 UI 문서 이력을 함께 보존했습니다.
- 균열 결과의 최신 반복 아이콘과 소제목 스타일을 유지했습니다. 균열 입장 브랜치에 함께 있던 이전 결과 시안으로 되돌리지 않았습니다.
- 대장간은 진행 중인 균열을 저장한 상태에서도 마을 NPC 옆에서 열 수 있습니다. 실제 전투 화면과 NPC 거리 제한, 서비스 해금·비용·소유권·저장 검증은 유지합니다.
- 대장간 HTML 시안은 별도 시안입니다. 이번 병합으로 네이티브 서비스의 해금 단계를 시안 값으로 바꾸지 않았습니다.

## 백업과 정리

원래 작업 폴더 7개와 로컬 브랜치 8개를 조사했습니다. 모든 작업 브랜치의 마지막 커밋이 통합된 `main`의 선행 이력인지 확인했습니다. Git 이력 전체와 미커밋·미등록 파일, 삭제할 작업 폴더의 빌드·저장·검증 자료·설정을 저장소 밖에 백업했습니다. 보존한 15,787개 파일은 원본과 해시를 대조했습니다. Unity 캐시와 생성된 공개 위키는 재생성 대상이며, 기본 프로젝트 폴더의 기존 빌드·저장 파일은 보존합니다.

[통합·백업 근거](MainCleanup20260930Evidence/integration.json)에 브랜치별 원본 커밋과 조정 내용을 기록합니다.

## 최종 검증

| 검사 | 결과와 범위 |
| --- | --- |
| 공통 UI 계약 | 검사 통과, 계약 테스트 11건 통과 |
| 전체 Edit Mode | 한 번 실행: 4,878건 중 4,830건 통과, 48건 실패, 건너뜀 없음 |
| 통합으로 생긴 실패 | 영어 문구 표의 동일한 중복 키 4개 제거. 번역 결과는 동일하며 해당 검사 재실행 1건 통과 |
| 기존 실패 대조 | 통합 전 `47091ff3`에서 나머지 47개 검사만 실행해 모두 실패 재현. 전체 검사를 다시 실행하지 않음 |
| macOS 개발 빌드 | 빌드 성공, 빌드 오류 0. 기존 라이선스·개발 빌드 경고는 별도로 보존 |
| macOS 런타임 | 대장간, 균열 입장·재시작, 포탈·재시작, 훈련장, 균열 결과·재시작 등 8개 검사 통과 |
| 화면·언어 | 기본 글자 크기, 한국어·영어, 440×956·956×440·1600×900·1600×1000·2100×900 |

전체 검사 XML에는 모든 검사와 종료 시각이 기록됐습니다. 이후 900초 제한의 CLI 실행기가 시간 초과를 반환했으므로 실행기의 성공으로 보고하지 않습니다. [전체 결과](MainCleanup20260930Evidence/editmode.xml)와 [기존 실패 대조](MainCleanup20260930Evidence/failure-classification.json)를 함께 제공합니다. 기존 실패를 포함하므로 전체 검사 통과 상태는 아닙니다.

균열 입장 재시작 검사에서 보상 수령 상태를 오래된 캐릭터 필드로 확인하던 검증 코드도 수정했습니다. 실제 저장 소유자인 `account.rewardBoxes`를 조회하도록 바꾸고 실패한 재시작 검사만 다시 실행해 통과했습니다. 나머지 통과한 런타임 검사는 재사용했습니다. 번역 표 정리는 중복된 동일 값만 제거했으며 런타임의 번역 결과를 바꾸지 않습니다.

대장간에서는 새 캐릭터와 진행 중인 균열 저장 상태, 실제 포탈 귀환 후 NPC 대화를 확인했습니다. 접근 조건 32개, UI 레이캐스트 클릭 96회, 저장된 균열을 보존하는 유료 강화 10회가 통과했습니다. [런타임 결과](MainCleanup20260930Evidence/native-results.json)와 [대장간 상호작용 기록](MainCleanup20260930Evidence/blacksmith/blacksmith-access.txt)을 보존합니다. 모바일 실기기는 검증하지 않았습니다.

불필요한 로컬 작업 폴더 6개와 작업 브랜치 7개를 정리해 기본 `main` 작업 폴더 하나만 남겼습니다. 기존 보관 작업 3개는 별도 백업과 함께 보존했습니다. 원격 작업 브랜치는 통합된 `main`의 푸시가 확인된 뒤 삭제합니다. 공개 위키는 이 통합 기록과 검증 근거를 병합된 `main`에서 생성·검사하고 게시합니다.
