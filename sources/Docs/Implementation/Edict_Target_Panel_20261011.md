# 공격 대상 선택 패널과 대상 AI (2026-10-11)

전투 HUD 칙령의 공격 대상 선택 묶음을 우선 순위 / 추적 거리·시간 / 보물 고블린 추적의 세 탭으로 구성한다. 위치 패널의 고정 높이, 안전 영역, 오른쪽 배치, 고정 탐색·되돌리기·재생을 함께 사용한다. 본문만 스크롤하며 회전 때 탭과 편집 이력을 보존한다. 새 Canvas나 별도의 저장 경로를 만들지 않는다.

## 화면과 실제 전투

판정 순서 칩은 좌우로, 등급·타입·상태 카드는 위아래로 끈다. 기존 `HuntEdictOrderList`가 실제 카드 중심을 읽어 간격과 가로·세로 방향을 처리한다. 고스트는 잡은 위치를 유지하며 다른 카드가 비켜 주고, 초안의 전장 순위가 즉시 바뀐다. 놓을 때 공용 `SheetApply` 거래로 한 번 저장한다. 취소는 저장하지 않으며 ▲▼와 키보드 이동을 지원한다. 전체 칙령 창의 기존 드래그도 같은 소유자를 사용한다.

우선 순위 탭은 관측한 적의 HP바를 순번·분류 태그로 바꾼다. 1순위는 금색 점선 고리와 공격 화살표를 표시한다. 추적 탭은 실제 미터 반경과 표시용 카운트다운을, 고블린 탭은 선택한 우선 추적·경로·필살 빛줄기를 표시한다. 카운트다운은 일시정지 중의 설명용 시계이며 저장된 전투 시간을 진행시키지 않는다. 라벨·선·고리를 재사용하고, 재생과 닫기 때 HP바·카메라·그래프를 복원한다. 새 래스터 에셋은 필요하지 않다.

빠른 편집의 전투 묶음은 위치 / 대상 / 행동 순서 세 개다. 포위와 추적 묶음은 전체 카탈로그에 남아 모든 전역 ID가 정확히 한 번씩 등록된다. 행동 묶음의 위치는 필터링된 카탈로그에서 찾으며 고정 번호를 가정하지 않는다.

대상 비교는 보스 단계 방침 → 고블린 우선 추적 → 분류 순서 → 각 분류의 첫 해당 항목 → 거리 제곱 → ID 순서다. 같은 비교자가 선택, 더 높은 우선순위 검사, 호출자가 제공한 순번 목록을 채운다. 등급 기본 순서는 BOSS/NORMAL/ELITE/TREASURE/SUMMONED, 타입은 MELEE/CHARGER/RANGED/CASTER/SUPPORT/EXPLODER, 상태는 WEAKENED/CONTROLLED/LOW_HP/DOT/CASTING/NEAREST/ATTACKING이다. 최저 HP는 비율로 판단하며 최저 HP와 최근접은 동점 거리·ID로 한 명만 선택한다. Slow는 CC에 포함하지 않고 출혈은 실제 W09 원장, 중독은 Poisoned를 사용한다. 위험 시전은 위협 자체이며 자신의 스킬 쿨다운과 분리한다. Idle 적을 유인하는 A11 미끼는 영웅 공격 상태로 세지 않는다.

직업 자동 스킬도 전역 비교를 먼저 사용한다. 우선 대상이 실제 사거리·사선 밖이면 공격 가능한 후보에서 같은 비교를 적용한다. 자신의 기술 조건과 물리 제약을 우회하지 않는다.

고블린 우선 추적은 죽을 때까지 유지 설정보다 우선한다(보스 단계의 기존 방침은 유지). 고블린 추적은 우선 추적과 독립적으로 거리·시간 한도를 해제하며 STOP보다 우선한다. 숨은 몸이나 도주 목적지는 읽지 않고 마지막 관측 위치·방향만 연장한다. 사망과 도주 완료 때 종료한다. 고블린 필살은 현재 고블린 대상에게만 일반 예약과 ELITE/GROUP·사용 조건을 완화하며 생명 위험 대응, 쿨다운, 실제 자원, 자동 사용 OFF, 사거리와 첫 교전 WALK를 유지한다.

## 저장 v7과 변환

v1–v6의 정의와 HED2 위치 순서는 변경하지 않는다. v7은 이전 대상 옵션 여섯 개를 제거하고 네 우선순위 순열과 두 고블린 토글을 끝에 추가한다. 전역 옵션 수는 156개다. 추적 거리는 5–50m(기본 30), 시간은 5–30초(기본 20)이며 정수 단계다. 새 문서는 고블린 우선 추적·추적 ON, 필살 OFF다. 기존 문서의 우선 추적 ON/OFF는 보존한다.

| 이전 값 | v7 변환 |
| --- | --- |
| 켜진 특수 BOSS / ELITE | 이전 순서대로 등급 앞에 배치 |
| 켜진 SUPPORT / RANGED | 타입 앞에 배치; RANGED는 RANGED·CASTER로 확장 |
| LOW_HP / NEAREST | 해당 상태를 앞에 배치 |
| 위험 시전 우선 ON | CASTING을 LOW_HP·NEAREST보다 먼저 배치 |
| HIGH_HP / DENSE | 대응 항목이 없어 기본 상태 순서로 변환 |
| 분류 순서 | GRADE·TYPE·STATUS |
| 기존 추적 거리·시간 | 이전 범위·정수 검증 후 새 범위로 맞춤 |
| 기존 고블린 거리·시간 | 유한 한도는 제거하고 신규 고블린 추적 ON |

나머지 항목은 각 기본 순서로 이어 붙인다. 원본 문서를 수정하지 않으며 영웅, `legacyEdict`, 프리셋, HED2/HED3/HED4/HED5에 같은 canonical 변환을 적용한다. 알 수 없는 필드·옵션, 중복·잘못된 순열, 이전 범위를 벗어난 값은 검증 오류를 유지한다. 채널 스냅샷 정책 v1은 저장된 자신의 필드로 v2 변환하며 현재 영웅의 변경 설정을 섞지 않는다. 무제한은 getter가 반환하고 직렬화 자료에 Infinity를 저장하지 않는다.

## 검증과 결정 기록

대상 비교·상태·직업 사거리 대체·추적·고블린 예약·스냅샷 및 저장 변환 관련 검사를 실행한다. 최종 통합 뒤 전체 Edit Mode와 macOS 개발 플레이어에서 KO/EN, 세로·가로·PC 다섯 크기, 드래그 초안·저장 횟수·취소·키보드·본문 스크롤·슬라이더·되돌리기·재생·HP바 복원을 확인한다. 최종 결과와 실제 화면은 검증 완료 뒤 이 문서에 기록한다. 현재 준비 중인 검사를 통과한 결과로 간주하지 않는다.

HIGH_HP/DENSE의 변환은 지정된 기본 상태 순서를 사용하고, 과거 유한 고블린 한도는 ON으로 바꾼다. 이는 동일 동작 보존을 보장하지 않는 의도된 변환이다. ATTACKING은 비 Idle 및 이번 틱의 영웅 관측 여부로 판정한다. 새로운 기본 대상 순서에 따른 패시브·추천·퍼즐 결과 차이는 같은 조건의 결과에서 별도로 보고한다.

작업 소스·입력·원본·보고서·로그·화면은 작업 자료의 `validation-codex/artifact-lifecycle.json`에 기록한다. macOS 화면은 물리 모바일 및 WebGL 게임 플레이어의 검증을 대신하지 않는다. 임시 빌드는 재현 목적·검토 기한을 기록하며 영구 삭제는 별도 승인 전 실행하지 않는다.
