# 전사 전설의 강제 이동·착지·단일 대상 통합

작성일: 2026-09-09 · 단계: D3 진행 중

## 1. 구현 범위

[빌드 통합 개발 기록](Build_Integration_Expansion.md)에서 이어진 작업이다. [장비 상세안 5.1](../Design/HELLSCRIPT_Itemization_Detail.md#51-lw01-강제-이동의-상세-시험-기준)에 LW01의 몸체·벽·처리 순서·중단·기록 기준을 구체화한 뒤, 기존 `CombatSimulation.TickChannel`의 유료 틱에 연결했다.

LW01은 회오리를 1초 유지하고 유료 틱을 성공했을 때 발동한다. 마지막 발동 후 20전투틱을 비교해 256초 이후에도 1초 간격을 유지한다. 저장된 `lastPull` 필드를 사용하며 새 저장 스키마나 별도 효과 관리자를 추가하지 않았다.

대상을 영웅과 가까운 순서·적 ID 순서로 처리한다. 영웅과 중심 간격 0.85m, 일반 적끼리 0.8m를 확보하고, 보스 몸체와 보행 장애물 앞에서 멈춘다. 기존에 겹쳐 있던 적은 겹침을 줄이는 방향으로만 빠져나올 수 있다. 실제로 움직인 적의 진행 중 공격을 중단하고 경로 캐시를 갱신하며, 남은 CD와 이미 생성된 공격은 유지한다. 일반 적의 통상 이동 전체를 새 몸체 충돌 방식으로 바꾸는 작업은 아니다.

끌어당김은 피해를 추가하지 않는다. 대상별 실제 이동 거리·틱·원 시전·대상 ID를 `LW01/PULLED` 기록으로 남기고, 전투 효과 화면에 최근 이동한 적 수와 거리 범위를 표시한다. 아이템 설명도 최대 거리와 제외 대상을 명시한다.

## 2. 실제 장비로 검증한 경계

검사 영웅은 30레벨이며 생성기와 실제 장착 함수로 8부위를 채운다. LW01 / SW 머리·몸 / LW03 손 / LW02 발 / LC03 허리 / LW04 목걸이 / LC01 반지를 사용한다. 4세트와 같은 부위의 전설을 동시에 장착하지 않는다. 피해·시간의 영향을 분리하기 위해 패시브를 해제하고 움직이지 않는 높은 HP의 시험 적을 사용한다. 기본 장비 능력치는 유지한다.

| 검사 | 확인한 결과 |
|---|---|
| 첫 유료 틱과 추가 피해 | 1초 전에는 적이 이동하지 않는다. 끌려서 새로 공격 반경 안에 들어온 적을 같은 틱에 다시 타격하지 않는다. |
| 몸체·벽 | 영웅·다른 적의 몸체와 시야를 막지 않는 보행 장애물 앞에서 멈춘다. 기존 겹침은 더 깊게 만들지 않고 분리할 수 있다. |
| 제외 대상 | 보스·사체·속박·기절·빙결·범위 밖·시야가 막힌 대상을 끌지 않는다. |
| 공격 중단 | 실제로 공격 준비 중인 N09가 끌리면 해당 공격을 중단한다. 남은 CD는 정상적으로 감소하며 초기화하지 않는다. |
| 발동 조건·복원 | 장비가 없거나 유료 틱의 자원이 부족하면 미발동이다. 채널 재시작과 JSON 복원에서도 마지막 발동을 유지한다. 0·128·256초 구간에서 20틱 간격을 확인한다. |
| LW02 | 실제 도약 착지 때만 별도 충격파가 발생한다. 원 착지 밖·충격파 안의 표적을 타격하며, 준비 중 취소하면 원 착지·충격파 모두 발생하지 않는다. |
| LW03 | 적중 직전의 유효 표적 0/1/2명을 기준으로 가산 피해를 결정한다. 첫 표적 사망으로 같은 공격의 두 번째 표적에 단일 대상 보너스가 잘못 붙지 않는다. 별도 추가 공격을 만들지 않는다. |

수정 전 `legendary-before.xml`의 4개 검사 중 두 개가 실패했다. 적이 영웅과 0.7m까지 겹쳤고, 256초 구간에서는 다음 발동 시각이 갱신되지 않았다. 수정 후 집중 검사 17개, LW02·LW03까지 포함한 전체 검사 **416/416개**가 통과했다. 전체 검사 시간은 60.0707329초다.

이후 실제 앱 검사 코드의 적 목록 비교를 개체별 비교로 강화하고, 최신 소스에서 집중 검사 **23/23개**를 다시 통과했다. 이 변경은 실제 앱 검사 코드에만 있으며 전투·편집기·단위 검사 소스는 전체 검사 시점과 같다. `legendary-final-source-manifest.json`에 전체 검사 시점과 최종 C# 74개의 해시를 따로 보존한다.

## 3. 생성 균열 재검사

`Artifacts/Validation/BuildComparisonLegendary`에서 기존의 6프리셋×희귀/세트 12개 구성을 같은 단계 1·시드 91367로 실행했다. 10개 구성은 클리어했고 연쇄 제어의 희귀·세트 구성은 기존처럼 시간 초과했다.

회오리 세트 구성의 클리어 시간은 277.21초에서 283.35초로, 최종 HP는 1,413.4에서 1,430.3으로 바뀌었다. 적을 영웅 안으로 겹쳐 모으던 동작을 없애고 끌린 적의 공격을 중단한 결과이므로, 이전 시간과 같게 만들기 위한 피해 보정은 하지 않았다. 나머지 구성의 클리어 시간·최종 HP·총 피해는 직전 비교와 같았다. 이 한 시드 결과는 여러 단계의 밸런스 완료 증거가 아니다.

## 4. 실제 앱 검증

macOS 개발 빌드를 오류 0개로 생성하고, 분리된 `LegendaryNativeSave`에서 두 프로세스를 실행해 실제 재시작 1회를 통과했다. 두 프로세스의 종료 코드는 모두 0이다. 1배속의 첫 발동은 1.05000007초이며 두 적이 각각 1.35m·1.5m 이동했다. 저장 후 앱을 다시 실행했을 때 적별 위치·공격 상태, 영웅 행동과 효과 상태가 같았다. 2배속으로 바꾼 뒤 2.04999924초에 다음 발동이 발생했다. 정확히 20전투틱 뒤이며, 몸체에 막히지 않은 적 하나만 약 0.35m 더 이동했다. LW01의 별도 피해는 발생하지 않았다.

`LegendaryNativeEvidence`의 장비 설명·월드·효과 기록·복원 화면 6장을 확인했다. Metal로 렌더링한 540×960 화면이며 긴 무기 설명도 할당 영역 안에 들어왔다. 실제 앱의 UI 함수를 사용한 검사이므로 물리 입력·Android·밸런스 검증으로 확대하지 않는다. 자세한 증거는 `Artifacts/Validation/legendary-validation-summary.json`에 모았다.

최종 빌드와 검사 뒤 C# 74개의 해시는 일치했다. 자산·설정 검사 174개 중 173개는 같았고 `ProjectSettings/ProjectSettings.asset` 한 파일의 해시가 달랐다. 중간 시점의 원본 바이트를 보존하지 않아 정확한 변경 줄은 확정할 수 없다. 현재 세로 720×1280·창 모드·자동 회전 해제 값은 기존 `ProjectBuilder.Setup`과 일치하며 기존 사용자 변경과 정의 심볼을 되돌리지 않았다. 현재 설정의 사본과 두 해시를 기록했다. 씬·프리팹·패키지·나머지 자산에는 이 검사 구간의 변화가 없었다.

## 5. 전설·세트 검사 근거와 다음 연결

아래 표는 검사 위치를 찾기 위한 현황이다. 각각의 효과 단위 검사가 있다는 사실과, 실제 장착·편집·저장을 통한 전체 조합 검증은 구분한다.

| 효과 | 현재 근거 | 이어서 확인할 연결 |
|---|---|---|
| LW01·LW02·LW03 | 이번 `LegendaryIntegrationTests`에서 실제 8부위 구성으로 강제 이동·착지·단일 대상 기준을 검사했다. | 전체 프리셋·여러 시드와 장비 교체 UI를 이어서 확인한다. |
| LW04·LC03 | `EffectTests`에 생존한 HP 경계·장착 스킬·CD·물약 성공·독립 보호막 검사가 있다. | 실제 장착 상태의 피해·물약·재시작 연결을 통합한다. |
| LA01·LA02 | `ActionTests`에 관통 순서·물리 화살·동일 대상 상한·그림자 충전이 있고, `PassiveTests`에 실제 LA01·SA 4세트·AP03 조합이 있다. | LA02 손 장비를 선택한 합법적 대체 빌드와 편집 화면을 비교한다. |
| LA03·LA04 | `ChargeTests`와 `PassiveTests`에 후퇴 시작점의 덫·속박·실제 조합이 있고, `OutcomeTests`에 전염 원 표적별 중복 방지·복원이 있다. | 같은 궁수 장비 구성에서 이동·독·추가 사격을 이어서 검증한다. |
| LM01·LM02 | `AreaTests`, `EffectTests`, `PassiveTests`에 실제 고정/추적·노출·후속 폭발·자원 회복의 경계 검사가 있다. | SM 4세트와 LM02 손 장비의 교체 선택을 실제 편집·장착에 연결한다. |
| LM03·LM04 | `EffectTests`에 보호막별 흡수·자원 지급·내부 CD·연쇄 재방문이 있고, `PassiveTests`에 실제 SMB 4세트·LM04·MP03 조합이 있다. | LM03의 실제 장착·보호막 생성·흡수·복원을 연결하고, 단독 보스 약점과 군중전 효과를 비교한다. |
| LC01·LC02 | `FieldContentTests`에 회수 이동·비전투·속도 상한이 있고, `ChargeTests`에 동일 대상 기본공격·할인·소비·만료·복원이 있다. | 실제 장착·회수 행동과 기본공격 순환을 통합한다. |
| 세트 6종 | `ItemizationTests`의 서로 다른 부위 집계, `ChargeTests`의 예약·소비·복원, `AreaTests`의 노출·중독, 실제 생성 균열 비교가 있다. | 합법적 2/4세트 선택·편집·저장과 여러 시드의 역할 차이를 확인한다. |

전사 전설 3종을 검증했다고 전설 15종·6세트의 모든 조합을 완료했다고 표시하지 않는다. 이어서 위 표의 남은 장착·편집·복원 연결과 [남은 개발 작업표](../Design/HELLSCRIPT_Remaining_Development_Backlog.md)의 실제 성장·훈련·마을·정리·서비스·기기 기준을 진행한다.
