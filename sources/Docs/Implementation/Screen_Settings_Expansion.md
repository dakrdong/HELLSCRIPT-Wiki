# 화면 설정·공통 안내 개발 기록

작성일: 2026-09-09 · 화면 상세 기획에 따른 부분 구현

## 범위와 실행 경로

[화면 비율·방향 대응 상세 기획](../Design/HELLSCRIPT_Screen_Layout_Detail.md)의 인계 순서에 따라 읽기 전용 안내와 화면 설정을 먼저 연결했다. 각 화면 상단의 **설정·안내**에서 열고, 성소 하단의 **게임 안내**로도 진입한다. 같은 창에서 **화면 / 게임 안내** 분류를 전환하고 **닫기**로 이전 화면에 돌아간다.

이 단계의 변경은 공통 설정·안내와 그 창을 여닫을 때의 상태 보존이다. 이후 [전투 HUD·카메라 배치](Battle_Layout_Expansion.md)와 [장비 목록·비교](Inventory_Management_Expansion.md)에 적용 범위를 넓혔다. 성소·사냥 칙령·결과·훈련 등 나머지 화면의 전체 재배치와 모바일 실기기 검증은 남아 있다. 부분 구현을 SCR-01~08 전체 완료로 표시하지 않는다.

## 표시와 상태 보존

- 넓은 창에서는 분류와 본문을 좌우로, 좁은 창에서는 분류 아래에 본문을 배치한다. 카드의 최대 크기는 1100×800이며, 카드 폭 820에서 분류 배치를 바꾼다. PC의 글자 배율은 1이고 모바일의 밀도 환산은 실기기 검증 전 초기값이다.
- 본문은 문장 길이에 맞춰 높이를 계산하고 스크롤한다. 닫기·적용은 본문 밖의 하단 영역에 유지한다. 안전 영역과 표시되는 키보드를 제외한 공간을 다시 계산한다.
- 창과 입력 객체를 다시 생성하지 않고 위치만 바꾼다. 읽던 문단과 문단 안의 위치를 복원한다. 설정 아래의 원래 화면·편집본·확인 대상도 유지한다.
- 설정·안내를 연 동안 아래 화면의 포인터 입력과 선택 이동을 막는다. 닫을 때 기존 입력 가능 상태와 선택 대상을 복원한다. 프리셋의 Escape 처리도 위쪽 설정창과 동시에 실행하지 않는다.
- 전투를 멈추기 위해 저장되는 `RunState.paused` 값을 덮어쓰지 않는다. `GameController`가 표시 창을 연 동안 전투 틱·실제 경과시간·주기 저장·반복 대기를 진행하지 않으므로, 기존 일시정지·편집·포탈 상태와 부분 틱이 유지된다. 창 크기 변경만으로 이 정지 조건을 켜지 않는다.
- 결과의 반복 대기는 설정·안내뿐 아니라 프리셋 창·확인창·백그라운드에서도 멈춘다. 닫은 뒤 남은 시간을 이어 쓰며 5초를 새로 시작하지 않는다.

## 기기별 방향 설정

| 상황 | 처리 |
|---|---|
| 모바일 처음 실행 | 저장값이 없으면 세로를 요청한다. 저장된 선호가 있으면 해당 방향을 복원한다. 자동 회전 옵션은 추가하지 않았다. |
| 값 선택 | 세로·가로 선택은 임시 값이다. **적용**을 눌러야 실제 방향을 요청한다. 닫기만 하면 선택한 임시 값을 적용하지 않는다. |
| 적용 확인 | Unity의 방향 응답과 실제 표시 영역을 함께 확인한다. 최소 두 프레임을 기다리고 5초 안에 일치하지 않으면 실패로 표시한다. 백그라운드 복귀 시 대기 시간을 다시 확보한다. |
| 실제 적용 성공 | 같은 설정창을 유지한다. 사용자가 적용한 값은 기기 파일에 저장한다. 시작 시 복원은 파일을 불필요하게 다시 쓰지 않는다. |
| 적용 실패 | 실제 방향에 맞춰 표시하고, 적용되지 않은 선택을 성공값으로 저장하지 않는다. 다시 적용할 수 있다. |
| 저장 실패 | 현재 적용 방향과 저장 실패를 함께 알린다. 이전 파일을 유지하고 **저장 재시도**를 제공한다. 재시도는 방향 전환을 다시 요청하지 않는다. |
| 연속 요청 | 완료 번호를 검사해 이전 요청의 늦은 완료와 중복 완료를 무시한다. 화면의 적용 버튼은 요청 결과를 기다리는 동안 비활성화된다. |
| PC | **가로 구성 · 창 크기에 맞춤**을 표시한다. 모바일 방향 파일을 읽어 적용하거나 변경하지 않고, 방향 선택 버튼도 제공하지 않는다. |

`hellscript-display-v1.json`은 게임 저장 폴더에 별도 파일로 보관한다. 계정·영웅·빌드·프리셋·공유 코드에는 방향 필드를 추가하지 않았다. 임시 파일을 디스크에 기록한 뒤 교체하며, 읽을 수 없는 기존 파일은 초기화하지 않는다.

## 구현 소유자

## 검증

방향 설정의 저장·복원·실패·재시도·중복 및 늦은 완료·PC 제외에 관한 새 Edit Mode 검사 19개와 기존 917개를 합친 **936개가 모두 통과했다.** 전체 검사는 2026-09-09 15:52:58~15:54:43 KST에 수행했다. 이후 변경한 C# 소스는 실제 실행 검증 스크립트 하나이며, 제품 동작 코드는 전체 검사 당시와 같다.

macOS 개발 빌드는 오류 0건으로 완료했다. 마지막 빌드의 별도 실행과 프로세스 재시작은 각각 종료 코드 0으로 끝났다. UI 콜백과 실제 macOS 창 크기 변경, Metal 렌더링을 사용했다. 사용자가 실행 중인 기존 앱과 실제 저장 폴더를 교체하지 않았다.

| 검사 | 확인한 결과 |
|---|---|
| 창 크기 11종 | 720×1280, 1280×720, 1920×1080, 1920×1200, 900×900, 640×360, 842×600, 844×600, 900×360, 1024×768, 768×1024에서 설정과 안내를 각각 확인했다. |
| 경계·본문 | 842와 844의 실제 창 폭에서 분류 배치가 바뀌어도 같은 문단을 유지했다. 640×360에서 마지막 안내 문단까지 스크롤하고 닫기 버튼에 접근할 수 있었다. |
| 창 유지·계정 불변 | 같은 표시 창과 원래 성소 페이지를 유지했고, 배치 변경으로 계정 내용을 저장·변경하지 않았다. |
| 전투·훈련 | 실행 중인 균열과 훈련에서 설정을 열어 전체 전투 상태와 계정이 동일하게 유지되는지 비교했다. 실행 중인 PC 창의 크기 변경 자체는 전투를 멈추거나 판을 초기화하지 않았다. |
| 정지·편집 | 수동 일시정지와 편집 정지를 유지했다. 미저장 목표 거리의 편집 객체와 값, 프리셋 입력 객체와 한글 문자열이 유지됐다. |
| 반복·확인창 | 설정과 확인창에서 결과의 남은 대기시간을 유지했다. 설정을 닫아도 아래 확인창을 닫거나 실행하지 않았으며, 취소가 게임 명령을 중복 실행하지 않았다. |
| 저장·재시작 | 기존 모바일 가로 선호 파일을 PC에서 읽어 적용하거나 변경하지 않았다. 별도 프로세스가 게임 저장을 복원한 뒤 설정 화면을 다시 열었다. |

[실제 실행 기록](../../Artifacts/Validation/ScreenSettingsFinalEvidence/runtime-screen-settings-smoke.txt), [재시작 기록](../../Artifacts/Validation/ScreenSettingsFinalEvidence/runtime-screen-settings-resume.txt), [검증 요약](../../Artifacts/Validation/screen-settings-validation-summary.json), [최종 소스 기록](../../Artifacts/Validation/screen-settings-final-source-manifest.json)에서 범위를 확인할 수 있다.

최종 소스는 135개다. 씬·프리팹·패키지·프로젝트 설정을 포함한 기존 보호 자산 98개와 설계 문서 21개는 시작 기준과 같다. 빌드 중 Input System이 임시로 추가한 사전 로드 참조도 빌드 종료 후 원래 값으로 복구됐다. 새 C# 파일의 `.meta` 누락과 중복 GUID는 없다.

모바일 빌드 모듈과 실기기는 현재 검증 환경에 없다. 실제 운영체제의 회전·터치·한글 조합 입력·키보드·노치·백그라운드 복귀는 미검증이다. PC의 크기 변경 검사나 설정 상태 모델 검사를 모바일 실기기 완료 증거로 사용하지 않는다.

PC 검사도 UI 콜백과 창 크기 API를 사용했으며, 사람이 창 테두리를 끌거나 실제 키보드로 입력한 검사는 아니다. 640×360 통과는 이번 공통 창의 검증 범위이며 게임 전체의 최소 지원 크기를 확정하지 않는다.

## 후속 작업

후속 [전투 HUD·카메라 배치](Battle_Layout_Expansion.md)에서 전투 표시 영역을 연결하고 공통 창의 세 번째 분류에 읽기 전용 **전투 상태**를 추가했다. [장비 목록·비교](Inventory_Management_Expansion.md)에서는 설정을 열고 창 크기를 바꾼 뒤 닫아도 선택 장비와 필터·정렬을 유지한다. 사냥 칙령 v0.2의 전체 편집 화면, 결과·훈련의 긴 비교 표, 기타 확인·오류창의 작은 화면 대응은 이어서 구현한다. 게임 전체 최소 창 크기와 모바일 밀도별 글자·입력 영역은 실제 입력 검증을 거쳐 정한다.
