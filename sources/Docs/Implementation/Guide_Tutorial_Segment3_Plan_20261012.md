광장은 기존 RM12 방을 쓴다. 앞줄 근접 탱커, 뒤쪽 장판 적 둘과 원거리 물리 적 하나, 원거리·소환 패턴 보스를 그룹 3에 배치한다. 체력 50% 판정은 영웅 사망 보호·다음 물약 틱보다 먼저 적용한다. 보스는 수업 중 범위 피해로 사라지지 않도록 마지막 전투 전까지 체력을 보호하며, 고블린 등장·추격·회수 장면 동안 공격과 소환을 멈춘다.

고블린은 기존 적·도주 상태를 사용한다. 등장 중 잔여 회오리 피해를 막고, 등장 뒤에는 광장 안에서 정상 도주 방향과 이동을 사용한다. 체력 55·속도 1로 조정하고 튜토리얼에서 탈출을 끄므로 놓쳐서 진행이 막히지 않는다. 일반 균열의 도주·보상 규칙은 유지한다.

## 기존 UI와 저장 연결

- 공격 대상·행동 우선순위 패널을 새로 만들거나 재설계하지 않는다. 기존 ▲/▼ 이동 버튼과 순번 미리보기를 그대로 사용한다. 안내 대상이 스크롤 아래에 있으면 공통 UiVisibility.EnsureVisible로 기존 목록 안에 드러내며, 기존 칙령 창과 안내 수업이 같은 처리를 쓴다. 설명 시작 때 첫 순위 카드도 보이게 맞춘다.
- 시작 등급은 NORMAL,BOSS,ELITE,SUMMONED,TREASURE, 타입은 기존 근접 우선, 판정 순서는 등급→타입→상태다. 고블린 별도 최우선은 OFF, 끝까지 추적은 ON이다. 행동 순서는 공격→회피→버프→회수→목표→정비→탐험이다.
- TargetTalk에서 대상 순서 옵션 네 개, GoblinTalk에서 seen-treasure-grade, LootTalk에서 common.order만 기존 거래로 공개한다. TaughtOptions가 공개된 옵션의 직접 편집을 허용한다. Details와 전체 칙령 편집은 졸업 전에 열지 않는다.
- 보물 몬스터는 필수 튜토리얼 중 공개 키가 없을 때만 숨긴다. 저장 순서·끌기 미리보기 모두 MoveVisible(full, visible, ...)을 사용해 숨긴 항목 위치를 보존한다. 공개 뒤 카드의 투명도·크기·금색 테두리 등장 연출을 한 번 재생하며 동작 줄이기를 따른다.
- 등급 설명 한 줄과 타입 설명 세 줄은 기존 가림막 화자 카드에 표시한다. 카드를 누르면 다음 줄로 넘어가며, 기존 패널과 적 머리 위 순번은 계속 보인다. 설명 카드가 순번을 덮으면 패널 위쪽 또는 화면 아래쪽의 덜 가리는 자리로 옮기며, 1번 표시를 우선 보존한다. T 수업은 설명 뒤 자동 닫기, L 수업은 플레이어가 직접 닫기다.
- GuideTutorial.Last=25만 안내 튜토리얼 체크포인트에 적용한다. 앱 중단 뒤 처음부터 시작하는 기존 정책은 유지한다.

## 실제 보상

기본값인 실제 계정 지급을 구현한다. 기존 고블린 금화 배율과 희귀 장비 생성·바닥 드롭을 사용한다. 수업의 회수 대상이 확실하도록 장비 등급은 희귀(2), 희귀 회수는 PRIORITY로 시작한다. 보상은 영웅 옆·뒤쪽의 다시 접근할 수 있는 바닥에 흩어져 실제로 되돌아가야 하며, 등장·복귀 장면에서는 바닥에 남겨 회수 수업을 건너뛰지 않게 한다.

수업 완료 뒤 기존 자원 회수와 CommitRecommendedLoot 거래로 금화·장비를 지급한다. 살아 있는 안내 런만 거래 소유자로 허용하며 리플레이와 일반 훈련에는 지급하지 않는다. 장비·획득 플래그·거래 영수증은 같은 저장으로 처리하고 저장 실패 때 바닥 아이템을 보존한다. 재시도와 중복 획득은 기존 영수증을 따른다.

## 검증

최종 통합 후보에서 전체 Edit Mode를 한 번 완료했다: **6,036 통과·0 실패·기존 보류 4**, 3,962초. 이후 실제 화면 검증에서 발견한 스크롤 가림과 설명 카드의 순번 가림을 보완했다. 영향을 받는 GuideTutorialTests·PrologueGateTests **20개**와 UI 계약 회귀 **15개**, UI 갱신 검사(15 바인딩)가 통과했다. 전투·저장·데이터·패키지는 전체 검사 당시와 같으므로 전체 묶음을 반복하지 않았다.

macOS 개발 플레이어의 **10/10** 조합이 통과했다. KO/EN 각각 440×956, 956×440, 1600×900, 1600×1000, 2100×900, 기본 글자 크기다. 가림막 실제 레이캐스트 44번(기술 4·첫 교전 3·전투 중 위치 4·대상 16·보물 9·회수 8), 설명 중 순번, 화면 안 고블린, 직접 닫기, 금화·희귀 장비 지급과 저장 재열기, 졸업 거래 1회를 확인했다. 캡처에서 가려졌던 보물 버튼을 스크롤로 드러내고 설명 카드는 1번 표시를 피하도록 조정했다. 최초 검사 도구의 좌표 조회 오류와 UI 실패 근거는 작업 검증 폴더에 보존한다.
