# 원소 보호막 사냥 칙령 개발 기록

작성일: 2026-09-13 · [English](Edict_Shield_Expansion.en.md)

상태: **M05의 네 핵심 옵션, 교전 시작 기록과 실제 흡수 보상을 연결했다. 전체 검사 1,652개, macOS 앱의 세 프로세스 검사와 전후 48판 진단을 완료했다.**

## 해결한 문제

원소 보호막의 일반 행동 후보는 이전 자동 행동 규칙에 의존했다. 이 경로가 새 칙령의 피격 대비 조건과 관계없이 준비 중인 연쇄 번개를 취소하고 있었다. 이제 사냥 칙령을 켠 마법사가 M05를 장착하면 네 옵션에서 독립 후보를 만든다. 이전 규칙이 없거나 꺼져 있거나 조건을 충족하지 않아도 새 설정을 사용하며, 중복 후보는 하나로 합친다. 저장된 이전 규칙 목록은 유지하고 칙령을 끄면 다시 사용한다.

클로드의 능력치·접사·밸런스 인수 작업을 포함한 `7313034` 위에서 개발했다. 클로드의 `b1f3ea5`는 이미 메인에 통합되어 있다. 이번 단계는 전투 수치나 접사 가중치를 다시 조정하지 않고, 해당 능력치 시트에서 실제 보호막 생성과 흡수를 검증한다.

## 전투에 연결한 네 옵션

| 옵션 | 실제 처리 |
|---|---|
| 자동 사용 | ON은 후보를 허용하고 OFF는 제외한다. 이미 시작한 준비 동작은 옵션 변경이나 저장 복원으로 취소하거나 중복 실행하지 않는다. |
| 방어 시점 | EMERGENCY는 전역 긴급 생존 조건, PREVENT는 여기에 전역 회피 판단에서 감지한 피해 위험을 추가한다. ENGAGE는 새 교전에서 첫 공격 전에 한 번 더 검토한다. 준비되지 않았다면 공격을 계속한다. |
| 다른 보호막 | AFTER는 다른 출처의 유효한 보호막이 남아 있으면 일반 사용을 보류한다. TOGETHER는 실제 추가 생성량이 있을 때 허용한다. |
| 허용 교전 | ALL·ELITE·BOSS는 일반 PREVENT·ENGAGE 사용을 현재 교전의 유효한 감지 적으로 제한한다. 시야 밖이나 추적에서 제외한 정예로 조건을 충족시키지 않는다. EMERGENCY 방식에서는 이 선택을 저장한 채 비활성으로 둔다. |

전역 실행기가 먼저 판단한다. 전역 긴급 생존이 M05를 **직접 선택한 경우**에는 AFTER 대기와 교전 종류 제한을 넘을 수 있다. 일반 후보가 긴급 조건을 충족했다는 이유만으로 이 예외를 만들지는 않는다. 같은 M05의 재사용 금지와 최대 HP 100%의 전체 보호막 상한은 두 경로 모두 지킨다.

PREVENT의 피격 위험은 기존 1.5초 예고 범위에 감지된 양의 최종 피해를 요구한다. 피해가 0인 제어 요청만으로는 보호막을 사용하지 않는다. 유효한 적이 없는 환경 위험도 보호할 수 있으며, 일반 방어의 공격 중단은 전역 FINISH·CANCEL_ALLOWED와 현재 행동 구간을 따른다. 이미 전역 보행·생존기가 선택되었다면 일반 보호막으로 덮어쓰지 않는다.

## 교전 시작과 저장 경계

교전 시작은 유효한 적을 감지한 뒤 주 행동을 할 수 있는 첫 일반 판단에서 한 번 검토한다. ENGAGE 보호막이 준비되어 있으면 공통 스킬 순서에서 공격보다 뒤에 있어도 첫 공격 전에 사용한다. 더 높은 우선순위의 전리품·탐색 분류는 유지한다. OFF·해금 미달·쿨타임·기존 보호막·상한 등으로 사용할 수 없으면 그 기회를 소비하고 공격을 계속하며, 나중에 준비되었다고 지연 시전하지 않는다.

적을 감지하지 않은 상태가 3초 이상이고, 기존 전투 이탈 기준인 공격·가한 피해·받은 피해의 3초 공백을 충족하며, 진행 중 주 행동과 감지 위험도 없어야 다음 교전의 기회를 얻는다. 짧은 시야 상실, 대상 교체, 옵션 변경, OFF 뒤 재활성화와 앱 재시작으로 같은 교전의 기회를 다시 만들지 않는다.

진행 중 전투에 버전 1의 선택적 `edictEngagement` 기록을 추가했다. 마법사는 칙령을 꺼 둔 동안에도 이미 시작한 공격을 기록한다. 전사·사냥꾼은 이 기록을 새로 만들지 않는다. 기록이 없는 구형 진행 중 마법사 저장은 이미 기회를 사용한 것으로 시작하고 실제 전투 이탈 뒤 다시 허용한다. 다른 영웅·균열의 기록은 재사용하지 않으며, 지원하지 않는 미래 버전은 파일을 보존하고 거절한다.

## 실제 보호막과 전설 효과

해금 레벨 **15**, 준비 **0.2초**, 쿨타임 **14초**, 자원 비용 **0**을 유지한다. M05는 자원이 0이어도 사용할 수 있고, 실제 LC02를 장착한 상태의 비용 할인 충전도 소비하지 않는다. 기본 생성량은 현재 최대 HP의 35%에 실제 의지·MP04 보호막 배율을 적용한 값이다. 남은 전체 상한으로 추가 생성량을 제한하고 지속시간은 4초다.

효과를 실행하기 직전에 같은 M05나 전체 상한 때문에 생성량이 없어졌다면 실제 중단 사건을 남기고 생성하지 않는다. 쿨타임은 돌려주지 않는다. 무적·피해·후속 공격 예약은 추가하지 않는다.

실제로 장착한 LM03은 해당 M05가 **생성 당시 최대 HP의 15%**를 실제로 흡수했을 때 자원 20을 한 번 지급한다. 다른 보호막의 흡수량은 합산하지 않는다. 이후 최대 HP가 바뀌어도 기준은 유지하며 내부 쿨타임은 4초다. 일부 흡수한 보호막의 저장 복원 뒤 남은 흡수량으로 문턱에 도달할 수 있고, 이미 지급한 보호막은 다시 지급하지 않는다. 상한 때문에 작게 생성되어 문턱에 못 미친 채 소진된 보호막은 보상을 만들지 않는다.

전투 효과 화면의 흡수량·생성 기준·남은 시간·환류 지급 여부는 실제 저장 상태를 읽는다. 영어 140% 세로 화면에서 제목이 잘리지 않도록 제목을 줄였고, 언어·글자 크기를 변경해 다시 그린 뒤 닫아도 진입 전의 실행 또는 수동 정지 상태를 보존하도록 수정했다.

## 생존 설정을 구분한 전후 진단

이전 `7313034`와 M05 구현본에서 각각 기존 규칙 8판, 새 기본값 칙령 8판, 생존 설정을 명시한 칙령 8판을 실행했다. 총 **48판**이다. 과거 결과에서 고른 시드 인덱스 0·1·2·3·4·5·9·14, 레벨 30 연쇄 제어, 20단계, 합법적인 8부위 장비를 사용했다. 무작위 표본이나 최적 프리셋 검사가 아니다.

기본 문서는 전역 긴급 생존·회피가 꺼져 있고 M04는 SURVIVAL, M05는 PREVENT다. 진단 전용 문서는 다음 설정을 명시한다. 플레이어의 기본값·저장 설정·프리셋은 바꾸지 않는다.

| 항목 | 진단 전용 설정 |
|---|---|
| 긴급 조건 | HP 30% 이하와 치명적 위험을 켜고, 복귀 HP는 50%로 둔다. |
| 지정 행동 | 방어 M05, 회피 M04, 방어→회피→보행 순서를 사용한다. 대체 대응은 OTHER_SKILL의 M05다. |
| 회피 조건 | 바닥·범위·직접 공격을 DAMAGE와 HP 15% 기준으로 둔다. 중단은 CANCEL_ALLOWED다. |

기본 칙령에서는 옛 M05 규칙으로 발생한 중단 16회가 사라졌다. 변경 뒤 중단 3회는 끌어당김 1회와 사망 2회다. 대응 조건을 켜지 않은 기본 PREVENT에서 M05가 0회 사용된 것은 설정을 따른 결과다. 사망은 7회로 같지만 보스 도달과 적중이 줄고 평균 전투 시간이 213.27초에서 168.49초로 짧아졌으므로 개선으로 판단하지 않는다.

생존 설정 문서에서는 중단이 34회에서 8회로 줄었다. 남은 사유는 전역 긴급 보행 3회, 전역 M05 전환 3회와 끌어당김 2회다. 전후 모두 사망은 없지만 모두 시간 초과했고, 보스 등장 판은 6개에서 5개로 줄었다. 따라서 생존 설정을 최적안이나 클리어 성능 개선으로 제시하지 않는다. 직전 전역 판단은 관측 문맥이며 이후 틱의 중단 원인은 실제 행동 사건을 우선한다. 수치·접사 가중치나 기본 옵션을 바꿔 결과를 보정하지 않았다.

원자료는 `Artifacts/Validation/EdictShield/Baseline24/`와 `AfterFinal24/`, 짝 비교는 `comparison.json`이다. 수집 시작은 각각 2026-09-12 17:24:51 UTC와 17:40:20 UTC이며, 수집 시간은 약 201.98초와 214.96초다. 최초 변경 후 24판은 재현 비교용으로 별도 보존한다.

## 검증과 실행본

M05 검사 49개와 진단의 명시적 설정·비간섭 검사 2개를 추가했다. 집중 검사 268개와 마지막 수정 관련 125개가 통과했다. 최종 전체 Edit Mode 검사 **1,652개**는 2026-09-12 17:40:15~17:45:03 UTC에 약 **287.28초** 동안 실행됐으며 실패·건너뜀 없이 모두 통과했다.

초기 검사는 M05의 해금 레벨 15를 비용으로 잘못 해석하고 LC02 충전 수명을 만들지 않은 검사 조건을 드러냈다. 실제 비용 0과 장착한 LC02의 유효 충전으로 바로잡았다. 첫 전체 검사의 실패 2개는 마법사 교전 기록이 다른 직업에 불필요하게 생기던 문제와, M05의 옛 무조건 사용을 전제로 한 조준 검사였다. 기록 생성은 마법사로 한정했고, 조준 검사는 ENGAGE의 유효한 사용에서 조준 통계가 생기지 않는 원래 목적을 유지했다. 초기 컴파일·검사 실패와 수정 전 보고서도 보존한다.
