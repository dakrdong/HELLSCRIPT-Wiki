# 전투 HUD 사냥 칙령 시트 (2026-10-11)

[English](Edict_Hud_Sheet_20261011.en.md)

사냥 칙령 설정을 메뉴로 나가지 않고 전투 화면 안에서 바로 바꾼다. 인장 위 사냥 칙령 버튼을 누르면 전투가 멈추고, 오른쪽에 탭 아이콘 5개(전투·생존·탐색·반복·프리셋)가 펼쳐진다. 탭을 누르면 아이콘 줄 위에 시트 하나가 열린다.

- **시트**: 위쪽에 탭 이름과 `되돌리기`·`재생`·닫기, 그 아래 그룹 칩(전투는 5개), 그 아래 선택한 그룹의 옵션이 스크롤 목록으로 나온다. 다른 팝업이나 화면 이동은 없다.
- **컨트롤**: 선택·스위치·스킬 지정은 칩, 숫자는 슬라이더와 −/+ (슬라이더는 손을 뗄 때 저장), 다중 선택은 칩 토글, 순서는 ▲▼ 목록이다. "?"는 설명을 그 자리에서 펼친다.
- **즉시 저장**: 바꾸는 즉시 기존 `CommitHuntEdict` 거래로 저장하고 저장된 값을 다시 읽어 그린다. 그래서 부모 옵션이 꺼지면 자식 옵션이 사라지고 켜지면 나타난다(`HuntEdictUiCatalog` 조건). `되돌리기`는 이 시트에서 한 변경을 최대 30단계 되돌린다.
- **효과 확인**: 시트가 열려 있는 동안 전투는 정지하고, `재생`을 누르면 그대로 흘러가 변화를 볼 수 있다(다시 누르면 정지). 닫으면 열기 전의 정지 상태로 돌아간다. 전투 위치 그룹에서는 바닥에 영웅의 예상 이동(저장된 설정 기준)을 그린다.
- **공개 규칙**: `HuntEdictProgression`을 따른다. 튜토리얼에서 아직 보여 주지 않은 옵션은 나오지 않고, 직접 편집을 허용하지 않은 옵션은 눌러도 바뀌지 않는다. 반복 탭은 반복 설정 해금 전에는 잠김 안내만 나온다.
- **데이터**: `HuntEdictHudRows`가 그룹·행·선택지를 계산한다(순수 함수, `HuntEdictHudRowsTests`). 화면은 `GameUI.EdictSheet.cs`.
- **아이콘**: 탭 아이콘 5장은 Codex로 만든 후보를 `Resources/Art/GlobalHUD/menu-edict-*.png`로 등록했다(`Docs/Art/EdictHudIcons/`에 프롬프트·해시).
- **프리셋 탭**: 아직 이 화면에서 설정할 수 없고 누르면 안내만 나온다. 다음 단계에서 슬롯·공유 코드·가져오기를 만든다.
- **범위**: 일반 균열 전투. 이전의 위치 타일 4개와 첫 탭 선택 방식은 이 시트로 대체했다.
- **검증**: 데이터 계층 테스트 4개와 관련 93개 테스트, macOS 개발 빌드 스모크(`RuntimeBattleQuickEditSmoke`: 선택 칩·스테퍼·되돌리기·순서·부모-자식 행·4개 탭·재생·닫기, 5개 화면 크기). 미검증: 전체 Edit Mode, 가방·획득·스킬 이전 단계, 실기기, 영어 화면의 긴 문구 잘림.
