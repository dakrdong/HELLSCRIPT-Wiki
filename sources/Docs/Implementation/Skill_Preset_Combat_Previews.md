# 스킬 프리셋의 실제 전투 예시

갱신일: 2026-09-30 · [English](Skill_Preset_Combat_Previews.en.md)

사냥 칙령의 액티브·궁극기 54종을 검토해 장비 의존 없는 프리셋 122개로 정리했습니다. 전사 41개, 궁수 40개, 마법사 41개입니다. 프리셋 탭에는 기존 도해 대신 실제 전투 코드와 게임의 캐릭터·몬스터·애니메이션·효과를 사용하는 독립 예시를 표시합니다. 직접 설정에는 예시 없이 세부 옵션을 표시합니다.

## 재생과 저장

- **시간 제한과 자동 반복을 사용하지 않습니다.** 재실행, 일시정지/재생, 0.5배속·1배속·2배속으로 조작합니다. 전멸·패배하면 마지막 상태를 유지하고 재실행을 기다립니다.
- 재실행은 준비된 초기 상태 전체와 난수 상태를 복원합니다. 이전 전투의 투사체·장판·소환물·보호막·이벤트 구독도 해제하고 새 표시 객체를 만듭니다.
- 다른 프리셋을 구경하면 해당 예시를 처음부터 재생합니다. 창 크기·언어 변경이나 활성화 저장은 같은 예시를 다시 시작하지 않습니다.
- 예시를 보는 것과 재생 조작은 저장하지 않습니다. **프리셋 활성화** 버튼과 직접 설정의 값 변경만 기존 항목별 저장 거래로 반영합니다. 다른 미저장 포인트 배분·전역 설정을 함께 확정하지 않습니다.
- 보이지 않는 페이지·모달 뒤·앱 백그라운드에서는 예시 실행을 멈춥니다. 페이지를 떠나거나 창을 닫으면 카메라·텍스처·전투·이벤트 구독을 해제합니다.

## 실제 전투와 같은 판단

기준 캐릭터는 레벨 40, 장착 스킬 1등급, 고정 일반 장비를 사용합니다. 룬·보석·전설·세트와 불필요한 패시브는 제외합니다. 체력·자원·쿨타임·몬스터 배치와 종류·합류 시각·난수 시드는 예시별 데이터로 고정합니다. 캐릭터는 왼쪽, 몬스터는 오른쪽에서 시작합니다.

출혈·중독·둔화·기존 보호막·덫이 필요한 초기 상태는 실제 스킬 사용과 전투 틱으로 준비합니다. 그 뒤의 사용·이동·적중·회복은 기존 자동 전투가 판단합니다. 프리셋 설명대로 보이게 만들려고 스킬을 강제 사용하거나 몬스터를 연출용 경로로 이동시키지 않습니다. 예시의 연계 스킬과 필요한 전역 조건은 본문에 표시합니다. 일반 액티브 네 칸과 궁극기 한 칸 제한을 지킵니다.

일반 회피에서 **회피기 우선**을 선택했는데 회피기를 사용할 수 없는 경우, 지정한 예방 방어가 실제 피격 위험에 대응할 수 있으면 걷기 전에 사용합니다. 걷기 우선의 동작과 보호막 사용 시점·연계·자원·쿨타임 조건은 유지합니다. 마력 회수의 후퇴 준비는 최대 2초를 시도한 뒤 회복을 시도하며, 실제 위험·이동 취소 규칙을 따릅니다. 정예·표식·제어 대상 조건으로 고른 적이 실제 광역 조준에도 포함되도록 했고, 미끼 투영의 무리 조건은 영웅 주변 일반 적 세 명을 셉니다. 피해 계수·쿨타임 밸런스는 변경하지 않습니다.

가로 화면에서는 설명·예시 조건·실시간 상태를 왼쪽 열에 모으고 오른쪽을 전투 화면에 사용합니다. 세로 화면에서는 전투 화면을 먼저 표시하고 설명을 아래에 둡니다. 활성화 버튼은 스킬 이름 오른쪽의 작은 고정 버튼이며, 본문에 별도 행동 줄을 두지 않습니다. 재실행·정지/재생은 아이콘, 배속은 `½×`·`1×`·`2×`로 작게 표시합니다.

화면에는 실제 체력·자원·보호막·재사용 대기시간과 적용 중인 스킬 효과 아이콘을 작게 표시합니다. 자막은 관찰한 사건 또는 실제 자동 사용 대기 사유에서 생성합니다. 예시 조건과 프리셋 설명은 한국어·영어를 함께 제공합니다.

## 소유 구조와 격리

| 구성 | 역할 |
| --- | --- |

| `CombatPreviewSession` | 분리된 메모리 계정과 전투 스냅샷을 소유하며 20Hz 고정 틱, 배속·정지·재실행을 담당합니다. |
| `CombatPresentationContext` | 표시할 전투·카메라·시간·캐릭터와 격리 좌표·레이어를 `WorldView`에 전달합니다. |
| `SkillCombatPreviewPresenter` | 선택한 예시 하나만 실행합니다. 전용 카메라와 RenderTexture를 UI에 연결하고 표시 갱신을 최대 30fps로 제한합니다. |

훈련장 입장·기록 저장·개발용 검증 생성 경로를 사용하지 않습니다. 실제 `GameStore`와 사용자 계정·진행 균열·훈련 기록·궁극기 대기시간·미저장 편집본을 예시 실행에서 참조하거나 변경하지 않습니다. 보상·재화·전리품·경험치를 지급하지 않습니다. 조명·후처리·이펙트는 격리 좌표와 전용 레이어에 두며 원래 전투의 전역 조명과 셰이더 설정을 변경하지 않습니다.

새 콘텐츠 창을 별도로 만든 것이 아니라 기존 사냥 칙령 창의 예시 영역을 바꾸는 어댑터입니다. 제목·분류 탐색·고정 활성화·장착 스킬 배치의 소유는 기존 공통 창에 유지합니다. 기본 공격과 공통 공격 순서는 기존 도해 부품을 사용합니다.

## 검증 기록

Unity 6000.6.0f1에서 전체 Edit Mode 검사를 한 번 실행했습니다. 최초 결과는 **4,879개 중 4,708개 통과, 171개 실패, 건너뜀 0개**입니다. 새 예시 검사의 빈 패시브 슬롯 비교와 UI null 패턴 123개 실패를 고친 뒤 해당 범위 **140개가 모두 통과**했습니다. 122개 예시 각각이 실제 자동 판단으로 주 스킬을 시작하고 발동하는지, 조건 대기·보호막 연계·초기 상태와 난수 복원·계정과 미저장 편집본 격리·이전 공유 코드 호환을 확인했습니다.

나머지 중 전투 이어가기·저장·live-ops 관련 **47개 실패는 구현 전 `b3876e0c`에서도 같은 검사로 재현**했습니다. 변경하지 않은 오디오 타이밍 검사 한 개는 이전 소스와 현재 소스의 단독 검사에서 통과했습니다. 전체 검사를 다시 실행하지 않았으므로 전체 통과로 기록하지 않습니다.
