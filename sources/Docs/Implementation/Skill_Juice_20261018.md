# 스킬 연출 보강

갱신일: 2026-10-18 · 작성일: 2026-10-18 · [English](Skill_Juice_20261018.en.md)

D4 스킬 트리의 능동 스킬 30개의 전투 연출을 더 묵직하고 신나게 보강했다. 시뮬레이션과 저장 데이터는 건드리지 않는 순수 표시 변경이며, 시전·적중·지속 효과가 모두 같은 경로(`WorldView`·`WorldFx`)를 쓰므로 전투 화면과 스킬 창의 예시 전투에 함께 반영된다.

## 현재 상태 점검 (변경 전)

- 스킬 연출은 스킬마다 얇은 선·고리·한두 번의 폭발이 전부였다. 시전이 준비되는 동안 보여 주는 것이 없었고, 맞은 적에게도 스킬별 반응이 없었으며, 화면 흔들림은 거인의 심판 하나뿐이었다.
- 화살은 가는 선 한 줄, 구체는 단색 공이었다. 눈보라·화살비·균열 결계처럼 영역에 머무는 효과도 바닥에 선 한 줄이 전부였다.
- 연출은 변형을 따로 구분하지 않았다. 반지름이나 시전 종류가 같은 변형은 사실상 같은 화면이었다. 변형이 바꾸는 반지름·각도·원소 색은 기존대로 반영된다.

## 보강한 층

1. **충전**: 시전이 준비되는 동안 영웅 쪽으로 빛 알갱이가 모이고, 범위 스킬은 땅에 룬 원이 뜬다(전사 5개·궁수 1개·마법사 5개 등 준비 시간이 있는 스킬).
2. **시전 순간**: 고리·속도선·별, 스킬별 화면 흔들림, 버프 스킬은 영웅 번쩍임. 흔들림은 기존 흔들림 설정(움직임 줄이기)을 따른다.
3. **적중**: 스킬에 맞은 적마다 스킬(또는 피해 원소) 색의 별이 터지고, 치명타는 속도선이 더해진다. 적은 공격 반대 방향으로 짧게 밀려난다(화면 위치만 바뀌고 시뮬레이션 위치는 그대로).
4. **지속 효과**: 화살·구체·유령에 원소 오라와 빛 꼬리, 눈보라·화살비·소용돌이·결계·함정의 구역 분위기 입자, 낙하하는 유성, 영웅 둘레를 도는 세 원소(M18), 거인화, 장전한 활의 원소 오라.
5. **시뮬레이션 알림**: 출혈·중독이 걸릴 때, 갈고리가 끌어당길 때, 피의 회수, 원소 반응, 서리 귀환에 별·고리를 더한다.

## 라이브러리에 추가한 것

- 질감 `hit_star`(타격 별), `speed_lines`(방사 속도선): `tools/generate_fx_textures.py`로 만들고 출처 목록에 올렸다.
- 프리셋 `star`·`charge`·`lines`·`lines.ground`·`ring`·`pop`: 흰색 기반이라 `Burst`의 색조로 원소·스킬마다 칠한다.
- `WorldFx.Streak`(리본), `WorldFx.Aura`(원소 오라), `WorldFx.Zone`(눈·화살비·소용돌이·결계·안개). 모두 풀링되거나 앵커와 함께 사라진다.
- 시간차 연출은 표시 시계로 돌아 일시정지·배속을 따르고, 월드를 지우면 함께 버려진다.

## 확인

- 개발용 `-hellscriptSkillShowcaseSmoke`가 스킬 30개(`-hellscriptShowcaseModifiers`를 주면 변형 84개까지)를 스킬 창의 예시 전투에서 프레임 단위로 녹화한다. 변경 전후를 같은 장면으로 비교했고 114개 중 113개를 녹화했다(`W06-2`는 예시 전투에서 시전되지 않는다). 녹화 자료는 저장소에 넣지 않았다.
- Unity Edit Mode: `SkillJuiceTests`(스타일 30개 전부, 프리셋·질감, 오라·구역이 앵커와 함께 사라짐, 리본 풀링, 밀림, 시간차 연출), `WorldFxTests`, `HookPresentationTests`, `RakingWoundPresentationTests`를 실행했다. 전체 Edit Mode와 스모크 묶음은 실행하지 않았다.
- `generate_fx_textures.py --check`는 질감 36개 모두 통과한다.

## 2026-10-28 보강: 크고 선명하되 절제된 리그 오브 레전드풍, 단일 대상은 땅 표시 없이

사용자 지적: 전투에서 스킬 효과가 잘 안 보이고 약하며, 범위가 없는 단일 대상 공격에 땅 범위 표시가 붙어 헷갈린다. 이어서 리그 오브 레전드처럼 멋지고 화려하되 과하지 않은 절제를 요청했다.

- **원인 확인**: 실제 전투 카메라는 세로 10~12 m를 비추는데 위 녹화는 5 m 확대 화면이었다. 같은 효과가 실제 화면에서는 절반 크기이고, 밝은 바닥에 흰 가산 효과라 대비도 낮았다. 개발용 녹화에 `-hellscriptShowcaseHalfHeight 10.5`를 추가해 실제 거리로 확인한다.
- **효과의 언어**: 작고 선명한 밝은 중심 + 얇은 고리 + 가는 불꽃. 크고 흐릿한 섬광 덩어리는 밝은 바닥에서 번지므로 쓰지 않는다. 새 프리셋 `ripple`(카메라를 보는 얇은 고리), `strike`(적중: 뜨거운 중심·고리·가는 불꽃 10개), `flare`(시전 섬광: 중심·고리·불꽃 8개)는 흰색 기반이라 스킬·원소 색으로 칠한다.
- **진하고 쨍한 색(리그 오브 레전드식)**: 밝은 바닥에서는 빛을 더하는(가산) 효과가 흰색으로 날아간다. 그래서 프리셋(`ring`·`ripple`·`strike`·`flare`·`star`·`lines`·`pop`·룬 장판)마다 일반 블렌딩 색 레이어를 아래에 깔고(`WorldFx.Solid`), 광선·초승달·리본에는 `solid` 옵션을 더했다(색 띠 위에 흰 가산 중심). 직업·원소마다 한 색: 전사 크림슨·주황, 궁수 로즈 핑크, 마법사 보라, 방벽 코발트, 영혼 청록. 원소는 불 적주황, 냉기 아주르, 번개 인디고, 독 라임, 그림자 보라, 물리 주황. 이 문서 위쪽 표의 금빛·흰색 표기는 이 팔레트로 대체됐다.
- **위계**: 일반 적중은 `strike` 하나. 만화풍 별은 치명타와 보스 적중에만, 속도선은 궁극기·큰 버프에만 쓴다. 맞은 적은 스킬 색으로 0.16초 번쩍이고(일반 0.11초) 치명타는 작은 화면 흔들림. 시전마다 작은 `flare`, 화면 흔들림은 ×1.15. 충전 알갱이 ×1.5, 화살·구체·번개·축전 구체의 몸체와 오라, 원소창·연쇄 번개 광선을 키웠다(광선은 색 띠 위에 흰 중심). `star` 프리셋 뒤에는 어두운 받침을 깔아 밝은 바닥에서도 읽힌다.
- **단일 대상**: `WorldView.SingleTarget`(갈고리 W08, 선조의 전쟁 W17, 관통 사격 A01, 사냥꾼의 표식 A05, 잇단 사격 A07, 잔상 행군 A18, 연쇄 번개 M03, 원소창 M07)은 충전 땅 룬, 땅 고리, 땅 속도선을 그리지 않는다. 힘은 대상 위의 `flare`·`strike`로 준다. 범위가 있는 스킬은 그대로 얇은 땅 고리를 쓴다.
- **확인**: `SkillJuiceTests` 두 개를 더했고(땅 룬 충전은 범위 스킬만, 단일 대상 스킬 시전은 풀에 땅 표시 프리셋이 없음, 범위 스킬 W18로 양성 대조) 새 프리셋 존재 확인을 넣었다. 모바일 실기기와 성능은 측정하지 않았다.

## 하지 않은 것

- 적중 정지(hit-stop): 시뮬레이션과 표시를 어긋나게 하므로 넣지 않았다.
- 영웅 몸동작과 장비 연출은 바꾸지 않았다.
- 실기기 성능은 측정하지 않았다. 입자 수는 모바일 품질에서 기존 설정대로 절반으로 줄고 프리셋별 수량 상한을 따르지만, 오라와 구역은 시전마다 새로 만들어지는 입자라 실기기 측정이 필요하다.
