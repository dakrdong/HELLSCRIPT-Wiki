# 인력 붕괴 엘리트

작성일: 2026-10-06 · [English](Gravity_Collapse.en.md)

퍼즐 튜토리얼 계획의 B1~B3다. 기존 N10 잿불 사술사에 E07 인력 붕괴를 명시하면 인력술사로 표시한다. 일반 균열·훈련장 엘리트 추첨은 그대로이며 E07은 추첨 목록에 넣지 않는다. 새 적 종류·모델·이미지·음원을 추가하지 않는다. L7 레벨 러너와 정찰·복기 카드는 후속 단계의 범위다.

## 동작과 판정

첫 시전은 생성 후 4초, 이후 주기는 10초다. 기존 14m·시야 판정을 통과한 영웅 위치에 반경 2.5m 원을 고정한다. 5초 지연 동안 원 안의 영웅을 고정 틱 0.05초마다 중심으로 8m/s 끌고, 끝에서 공격력 ×20의 암흑 피해로 한 번 폭발한다. 벽은 기존 `Map.MoveDirect`가 처리한다. 도약 이동 중에는 끌지 않고, 원 밖에 착지하면 끌림이 멈춘다. 제어 저항으로 끌림을 줄이지 않는다. 준비 행동을 매 틱 중단하거나 경로를 매 틱 다시 만들지 않는다.

장판의 `pull`은 저장 필드이며 구형 저장의 누락값은 0이다. 정예 CD는 7칸으로 늘리되 기존 6칸의 남은 시간은 보존한다. 새 칸은 기존 초기화 여부에 맞춰 첫 시전 4초로 시작한다. 난수를 소비하지 않는다.

예측에는 단발 범위 공격과 `IncomingControl.Pull`이 기록된다. 끌리는 중에는 WALK_FIRST·순서의 WALK와 이전 보행 완료 지름길을 모두 거부한다. 이탈 후보는 폭발까지 1.5초보다 많이 남았더라도 살아 있는 끌림 원 안이면 제외한다. 궁수의 감지 대상 조건, 전사의 공격 도약 CD와 긴급 회피 보존, 기존 준비·이동·회복 구간 판정은 유지한다.

## 표시와 소리

`WorldFx`의 기존 예고 풀·메시·게이지·폭발을 재사용한다. 인력 예고에는 안쪽을 향하는 12개 화살표를 더하고 뷰·메시·재질을 재사용한다. `WorldView`가 실제 장판의 고정 좌표와 지연을 읽는다. 폭발은 암흑 충격과 기존 `hazard.blast`를 사용하며, 생성 시점에는 N10의 준비 소리를 사용한다.

카운트다운은 기존 전투 캔버스의 보스 상태 HUD 어댑터를 재사용한다. 보스가 있으면 보스 표시가 우선이며, 보스가 없을 때 관측 가능한 인력 예고를 표시한다. 텍스트는 장판 ID·정수 초·언어·HUD 재생성 때만 갱신한다. 저장·계정 상태를 변경하는 subscriber와 별도 창·캔버스·폰트는 추가하지 않는다. 기존 안전 영역과 화면 비율 배치·공통 글꼴을 유지한다. 비용 개선은 실측하지 않았으므로 성능 향상으로 보고하지 않는다.

## 검증과 전달

핵심 검사 9개는 구현 전 모두 실패했고 코어 구현 후 모두 통과했다. 기본 생존 칙령(지정 회피기 없음)은 첫 폭발에 사망하며 최대 6.6m/s의 걷기도 원을 벗어나지 못한다. W02/A04/M04를 지정하면 첫 3주기에 장판 피해가 0이다. 순수 특성 검사는 공격을 끄고 시전자를 오래 살려 두며, 실제 공격·스킬·정비 거래가 포함된 Lv5 L7 승패는 3단계에서 검사한다.

독립 브랜치는 기존 해금 기준을 사용하므로 전사 Lv5, 궁수·마법사 Lv10에서 특성을 검증한다. 1단계와 통합하면 같은 검사도 세 직업 Lv5에서 실행되며, 실제 튜토리얼 Lv5의 게이트는 3단계 통합 결과로 기록한다. 해금을 임시로 우회하거나 기본 칙령을 수정하지 않는다.

집중 Edit Mode 검사는 중복을 제외한 326개가 통과했다(실패 0, 건너뜀 0). 저장 복원·암흑 예측 피해·최대 보행·조기 이탈·이전 보행 지름길·구형 CD 보존·일반 균열의 특성 선택·저널·번역·기존 소리·게이지·재사용 메시·할당 없는 warmed FX 경로·StoreViewBinding을 포함한다. 초기 검사 313개 중 실패한 1개는 검사 fixture의 이전 보행 메모리 초기화 누락이었고, 수정 후 그 검사와 직접 영향받은 6개만 다시 실행했다. 통과한 결과를 재사용했다.

macOS Unity 6000.6.0f1 Metal 에디터에서 인력 링·끌림·폭발 flash·5초/3초 카운트다운을 확인했다. KO/EN × 440×956·956×440·1280×720·1280×800·1680×720의 저장된 Game View 이미지 10개를 확인했다. 끌림은 0.15초에 1.2m였다. 화면 전용 fixture는 폭발 뒤 화면을 유지하도록 HP 10,000을 사용했으며 한 방 사망 수치는 위 시뮬 검사로 검증했다. 실제 클릭 입력·저장 UI·플레이어 성능·브라우저·실기기를 검증한 결과가 아니다. 공통 UI 검사 11개와 갱신 검사(12 binding·161 source)도 통과했다.
