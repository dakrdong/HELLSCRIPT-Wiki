# Hunt Edict entry points and source ownership after window removal

Updated: 2026-10-28 · [한국어](Hunt_Edict_Window_Removal_20261028.md)

A2 removes the large Hunt Edict window and the rift's ≡ observation menu. The HUD portrait seal opens no window. The Hunt Edict side menu is ordered **Skills → Combat → Survival → Exploration → Loot → Bag & Cleanup → Repeat Settings → Recommended Gear → Presets & Share**. [Entry routing](../../Assets/HELLSCRIPT/Runtime/Presentation/GameUI.EdictSheet.cs) and the [nine-row layout](../../Assets/HELLSCRIPT/Runtime/Presentation/GameUI.CasualEdictMenu.cs) own the current menu.

## Current screens and saving

| Former tab or feature | Current location and source owner |
| --- | --- |
| Skill tree and equipment | **Skills** directly opens the [standalone skill window](../../Assets/HELLSCRIPT/Runtime/Presentation/SkillTreeD4Window.cs). Its [entry and close handling](../../Assets/HELLSCRIPT/Runtime/Presentation/GameUI.HuntEdict.cs) also releases the guide gate. |
| Per-skill custom settings, usage and compatibility fields | The skill window's [tactics entry](../../Assets/HELLSCRIPT/Runtime/Presentation/SkillTreeD4Window.Tactics.cs) opens the [tactics page](../../Assets/HELLSCRIPT/Runtime/Presentation/SkillTacticsWindow.cs) and its [compatibility rows](../../Assets/HELLSCRIPT/Runtime/Presentation/SkillTacticsWindow.Legacy.cs). Recommended defaults make these settings read-only. |
| Combat, Survival, Exploration, Loot, Bag & Cleanup | The corresponding [side-menu sheet](../../Assets/HELLSCRIPT/Runtime/Presentation/GameUI.EdictSheet.cs) and [catalog rows](../../Assets/HELLSCRIPT/Runtime/Presentation/GameUI.EdictCatalog.cs) read the [existing group definitions](../../Assets/HELLSCRIPT/Resources/HuntEdictUi.json). Each edit saves immediately. |
| Repeat limits, next stage and next-run preparation | **Repeat Settings** opens the [standalone settings popup](../../Assets/HELLSCRIPT/Runtime/Presentation/RepeatSettingsWindow.cs). Its original repeat draft and added immediately applied edict section have separate save scopes. |
| Common and per-slot automatic equipment settings | **Recommended Gear** opens the [gear settings popup](../../Assets/HELLSCRIPT/Runtime/Presentation/RiftGearSettingsWindow.cs), containing the original recommendation popup settings and an immediately applied edict section. |
| Five preset slots, save/load/rename, share codes and import | **Presets & Share** opens the [standalone casual popup](../../Assets/HELLSCRIPT/Runtime/Presentation/EdictPresetsWindow.cs) with the [reused storage page](../../Assets/HELLSCRIPT/Runtime/Presentation/EdictPresetsWindow.Presets.cs) and [existing layout](../../Assets/HELLSCRIPT/Runtime/Presentation/EdictPresetsLayout.cs). |
| Recommended defaults versus custom settings | The popup's top [mode chip](../../Assets/HELLSCRIPT/Runtime/Presentation/EdictPresetsWindow.Presets.cs), outside the locked list, saves immediately through `SetRecommendedEdict`. Sharing (Rift 20 or legacy access) unlocks it; earlier accounts see the reason. |
| Combat styles and global, skill, basic-attack and common-order recipes | The same popup's **Quick Presets** page. Selecting a recipe changes only its draft; **Save** commits it. The [existing recipes and application](../../Assets/HELLSCRIPT/Runtime/Core/HuntEdictQuickPresets.cs) and [skill-policy copying](../../Assets/HELLSCRIPT/Runtime/Core/HuntEdictSkillPresets.cs) remain. |
| Tutorials and guidance | [General guidance](../../Assets/HELLSCRIPT/Runtime/Presentation/GameUI.Tutorials.cs), [prologue staging](../../Assets/HELLSCRIPT/Runtime/Presentation/GameUI.TutorialStaging.cs), [guide lessons](../../Assets/HELLSCRIPT/Runtime/Presentation/GameUI.GuideTutorial.cs) and [modifier lessons](../../Assets/HELLSCRIPT/Runtime/Presentation/GameUI.GuideModifierLesson.cs) target the current UI. [Tutorial migration](../../Assets/HELLSCRIPT/Runtime/Core/Tutorials.cs) handles old checkpoints into the deleted comparison page. |

The UI reuses [shared edict rows](../../Assets/HELLSCRIPT/Runtime/Presentation/EdictCasualRows.cs), the [additional settings section](../../Assets/HELLSCRIPT/Runtime/Presentation/EdictSettingsSection.cs) and the [edict edit transaction](../../Assets/HELLSCRIPT/Runtime/Core/GameStore.HuntEdict.cs). Live saves pass the active simulation and preserve the actual hero, unfinished rift and combat state on write failure. Stored keys and default/recommended values are unchanged. **Use default settings** at the top of Presets & Share changes the existing `useRecommendedEdict` value. Successful store notifications refresh the popup, tactics and HUD; live policy refresh retains main's existing simulation handling. Failure preserves the mode, custom drafts, presets and combat policy.

## Removed surfaces and historical records

- The unified window's summary, search, badges, change list, guide bands and after-save actions are removed. Combat styles remain on Quick Presets. The deleted window's number rows, pickers, equipment controls and preset partials are replaced by the current owners above.
- The embedded live combat examples, basic-attack diagrams and their presentation components are removed. The [skill tactics page](../../Assets/HELLSCRIPT/Runtime/Presentation/SkillTacticsWindow.cs) owns direct editing and does not provide the old live preview. Earlier example captures and test counts document that earlier implementation.
- The ≡ button and observation popup are removed. No replacement shortcuts were added for menu-only pause, speed, build editing or the idle peek. The [map panel](../../Assets/HELLSCRIPT/Runtime/Presentation/GameUI.Rift.cs) still opens the expanded map; [portal return](../../Assets/HELLSCRIPT/Runtime/Presentation/GameUI.CasualBattleHud.cs) and [training pause](../../Assets/HELLSCRIPT/Runtime/Presentation/GameUI.TrainingGround.cs) remain. The [other HUD inspection popups](../../Assets/HELLSCRIPT/Runtime/Presentation/GameUI.GlobalHud.cs) are separate.
- Runtime smokes and Editor capture tools dedicated to the old window are also removed. Their flags, object names and line numbers are not current test instructions. Current entry, edit and persistence coverage resides in [menu tests](../../Assets/HELLSCRIPT/Tests/Editor/EdictMenuColumnTests.cs), [preset tests](../../Assets/HELLSCRIPT/Tests/Editor/EdictPresetsWindowTests.cs), [tactics tests](../../Assets/HELLSCRIPT/Tests/Editor/SkillTactics/SkillTacticsWindowTests.cs), [suspended-save tests](../../Assets/HELLSCRIPT/Tests/Editor/HuntEdictSuspendedSaveTests.cs) and the [HUD smoke](../../Assets/HELLSCRIPT/Runtime/Presentation/RuntimeGlobalHudSmoke.cs). This documentation change did not run Unity or runtime checks.

Deleted source links in earlier documents and wiki revisions are corrected to current owners. Remaining old symbols, line numbers, captures and results describe the earlier implementation; this table defines current behavior and ownership. Evidence manifests retain their original paths and hashes because they attest to those historical inputs.
