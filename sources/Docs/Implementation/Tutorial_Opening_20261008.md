# 튜토리얼 도입부·새 기술 안내와 진행·타이밍 점검

갱신일: 2026-10-08 · English: [Tutorial opening, new-skill guide and flow audit](Tutorial_Opening_20261008.en.md)

이어지는 기록: [몬스터 고유 패턴 원칙](Puzzle_Tutorial_Native_Patterns.md)(레벨 구성), [튜토리얼 대장간](Tutorial_Forge_20261008.md)(대장간 레벨), [퍼즐 코어](Puzzle_Tutorial_Core.md)(러너와 저장).

## 사용자가 본 것

1. 게임을 시작하자마자 대기실에서 `사냥 칙령을 열어 스킬 탭에서 첫 번째 힘을 익혀라`라는 가이드가 뜬다. 사령관의 이야기(영웅의 사연, 이 구덩이가 무엇인지)는 스킬을 익히고 시작 버튼을 눌러야 나온다. 상황 설명 없이 스킬부터 찍으라는 순서가 어색했다.
2. 레벨 2는 사령관 대사만 있고 가이드가 없다. 새 스킬을 익히지 않고 도전하기를 눌렀더니 진행이 멈춘 것처럼 보였다.
3. 모든 튜토리얼 진행과 타이밍을 다시 검토해 문제가 있으면 고쳐 달라는 요청.

## 원인

| 증상 | 코드 원인 |
| --- | --- |
| L1에서 가이드가 먼저 | `BeginTutorial`이 곧바로 대기실을 열고, `TickPrologueLesson`이 대기실이 열리는 즉시 `hub-menu-1` 가이드를 올렸다. 사령관 카드는 대기실의 시작 버튼(`PresentTutorialStep`) 뒤에만 열렸다. |
| L2 이후 가이드 없음 | 가이드 조건이 `run.puzzleLevel==1`로 고정이었다. 새 스킬을 주는 L2·L4·L5·L7(궁수·마법사)에는 카드의 `새 기술 · …` 한 줄뿐이었다. |
| 멈춘 것처럼 보임 | `puzzle-play`는 카드를 닫은 뒤 `ContinueTutorial`이 거절하면(필수 스킬 미습득) 토스트만 띄웠다. 전투 화면의 `ShowToast`는 긴 문구를 HUD 한 줄로만 보내(`GameUI.cs`) 튜토리얼에서는 토스트도 보이지 않았다. 카드는 다시 열리지 않았다. |

## 새 흐름

**레벨 1(새 영웅).** 캐릭터를 고르면 대기실 대신 전투 화면(구덩이)이 열린다: 어둠에서 밝아지며 장 카드(`최종 시험`) → 사령관과 영웅의 대화 8줄(최종 시험, 막힌 구덩이, 영웅의 사연과 각오, `문은 시험을 끝낸 자에게만 열린다`, `싸움은 칙령이 이끈다 · 지금은 쥔 힘이 없다`, `포인트 한 점을 내려 주마`) → `시험을 받아들인다` → 칙령 창이 열리며 가이드가 한 컨트롤씩 이끈다(스킬 → `+` → 장착 → 저장 → 닫기) → 사령관 카드(`좋다. 쥐여 준 힘이 진짜인지는 싸워 보면 안다. 가라.`) → 도전하기. 대기실은 레벨 1을 깬 뒤 처음 나온다. 도입부는 첫 스킬이 칸에 걸리기 전까지만(`PuzzleTutorial.OpeningPending`) 나오고, 복습·이어하기·레벨 2 이후에는 나오지 않는다.

**레벨 2 이후.** 대기실의 시작 → 사령관 카드. 익히지 않았거나 칸에 걸지 않은 기술이 있으면 으뜸 버튼이 `새 기술 익히기`이고 `도전하기`는 없다. 누르면 같은 가이드(`PuzzleSkillStep`)가 칙령 창에서 기술을 하나씩 익히고(패시브는 `+`만) 장착하고 저장하게 하며, 닫으면 카드가 돌아와 `도전하기`가 열린다. 복습은 이전과 같다.

## 점검 결과

읽기 전용 점검(구간 4개 · 검증관 확인)이 49건을 보고했다: 차단 2 · 주요 15 · 경미 30(검증 10 실제, 미검증 20) · 문제 아님 2. 차단·주요 17건은 모두 실제로 확인됐고 모두 고쳤다.

| 문제 | 수정 |
| --- | --- |
| 필수 스킬 없이 도전하기가 조용히 거절됨 · 카드 소멸(차단) | 카드가 `새 기술 익히기`를 으뜸으로 바꾸고 `도전하기`를 숨긴다. 거절되면 토스트 뒤에 카드를 다시 연다. HUD의 일시정지 버튼은 대기 중인 튜토리얼에서 카드를 연다(`TogglePause`). |
| 정비 퍼즐의 시험 장비를 분해하면 레벨 10을 시작할 수 없음(차단) | 시험 장비를 잠그고(`locked`), 없어졌으면 다시 지급한다(`PreparePuzzleMaintenance`가 멱등). 측정해 둔 시작 수치는 유지. |
| 시간 초과·운영 목표 실패(체력이 남은 패배) 뒤 칙령을 열었다 닫으면 카드가 영영 안 돌아옴 | `TickTutorialUI`가 퍼즐의 `Fallen`도 카드 시점으로 본다. |
| 전투 화면에서 튜토리얼 거절·오류 토스트가 보이지 않음 | 튜토리얼 실행에서는 토스트 틀을 그대로 쓴다(`ShowToast`). |
| 레벨 11 기본 칙령(가방이 차면 포털)이 포털 가방 화면에서 멈춤 | 포털이 열리면 운영 레벨은 같은 틱에 목표 실패로 끝난다(`PortalForBag`). 끝난 실행에서는 포털 가방을 열지 않는다. |
| 레벨 14에서 시험 금화를 무기에 쓰면 이길 수 없고 복구 불가 | 대장간 레슨에서는 착용 방어구만 강화할 수 있고(`ForgeTarget`: 목록·`GearEnhancement.Apply`), 창은 장비 강화 탭에 착용 방어구를 고른 채 열린다. |
| 익혔지만 칸에 걸지 않은 기술로 레벨 8의 스킬 프리셋이 예외를 던져 시작할 수 없음 | 도전하기가 필수 액티브의 장착을 모든 레벨에서 확인한다. `StartPowers`는 배우고도 걸지 않은 기술을 스스로 건다. |
| 힌트에 `W02`·`A04` 같은 기술 코드가 그대로 보임 | 힌트를 `ClassSkillTree.Display`로 읽는다. 조사 두 곳 고침. 코드가 남지 않는 검사 추가. |
| 승리 카드 끝에 실패 힌트가 붙음 · 4번째 패배에 `내가 써 두었다`가 쓰기 전에 나옴 | 힌트는 승리 카드에 붙지 않는다. 칙령 레벨의 자동 상승은 3단계에서 멈추고 4단계는 `사령관의 설정으로 준비`를 눌러야 쓴다(대장간 레벨은 그대로). |
| 레벨 1 카드가 이미 익힌 스킬을 또 익히라고 하고 사연을 매번 반복 | 사연은 도입부로 옮기고, 카드는 `좋다…가라`로 바뀌었다. |
| 운영 레벨 9~13의 첫 카드가 칙령 어느 탭인지 말하지 않음 | 각 레벨 사령관 대사에 탭 이름(`전리품`·`탐색`·`가방·정리`·`장비 추천 착용`·`반복 설정`)을 넣었다. |
| 칙령 창의 안내 줄이 사령관 대사인데 `하늘의 목소리`로 표기 | `EdictCaption.Speaker`로 사령관 이름을 쓴다. |
| 마지막 레벨 승리 카드가 `다음 레벨`, 졸업 보상 언급 없음 | `마을로`와 `졸업 보상 · 금화 1,000 · 희귀 장비 1개`(마을로 가면 지급) 줄. |
| 운영 레벨 패배에 `받은 피해가 없습니다. 공격 조건…`이 붙음 | 운영 실패에는 그 줄을 붙이지 않는다. |

**고치지 않은 것(보류).** 정비 퍼즐 입구 안내(시작 버튼 라벨·확인 대사), 운영 레벨 패배 원인별 숫자, 결과 카드 연출(`VictoryBeat`), 카드 사실 줄의 언어 전환 갱신, 힌트를 시도 전에 볼 수 있는 점, 레벨 12 `hook`과 대장간의 어긋남, 레벨 16의 `배운 것을 모두 쓴다`와 레벨 9~13 칙령의 관계, 졸업 직후 보상 연출. 모두 진행을 막지 않는 경미한 항목이다.

## 검증

- **전체 Edit Mode(최종 코드, 한 번):** 5,673개 중 5,668 통과, 건너뜀 4(작성 도구), 실패 1. 실패는 새로 쓴 `TheForgeLessonOnlyTempersWornArmor`의 시작 장비 가정이 틀린 검사였다. 장비를 직접 갖춘 뒤 검사하도록 고쳐 `PuzzleOpeningTests` 7개가 통과했고 전체는 다시 돌리지 않았다. 새 검사: 도입부 조건, 정비 장비 잠금·재지급, 대장간 방어구 한정, 힌트의 기술 코드 없음. 필수 스킬 미장착 시 레벨 7 `unequipped` 사례는 이제 시작 거절을 기대하도록 바꿨다.
- **UI 계약·갱신:** `python3 tools/check_ui_contract.py --verify` 15개 통과, `python3 tools/check_ui_refresh.py` 통과.
- **macOS 개발 빌드 스모크(실제 포인터 입력, 일회용 저장 경로):** 전사·한국어·1280×720과 궁수·영어·440×956 두 번 모두 51개 PASS로 끝까지 통과했다. 새 도입부(전투 화면에서 사령관 이야기 → 가이드 → 레벨 카드), 레벨 2·4·5의 새 기술 레슨(궁수는 레벨 7의 A04도), 대장간 레벨의 방어구 +30, 졸업, 복습을 포함한다.
- **미검증:** 마법사 직업의 화면 실행(이 레슨은 같은 코드와 직업 키트로만 확인), 모바일 실기기, 사람이 읽고 이해하는 정도, 경미한 보류 항목.
