## 사냥칙령 프리셋

각 스킬의 기존 프리셋 ID는 유지하고 이름·설명·실행 조건을 갱신한다. 투쟁의 빚은 자원 30% 이하 긴급 차입과 75% 이하 선제 차입, 귀환 서리는 회수 이동과 제어 사격, 접지창은 즉시 설치와 연쇄 준비 후 설치를 구분한다. 궁수는 전투 위치의 **사선 선회** 프리셋으로 4m를 선회하고 **설치·이동·회수 연계** 공격 순서로 잔상·쇠뇌를 먼저 준비한다. 공격 순서 프리셋은 장착·투자한 스킬을 바꾸지 않는다.

스킬 프리셋의 실제 전투 미리보기에도 같은 조건·동료 스킬·전역 이동을 기록한다. 설명에 없는 수동 시전으로 효과를 만들어 보이지 않는다. 새 전역 프리셋과 순서는 기존 저장·되돌리기·공유 거래를 사용한다.

원소 보호막의 **속성 흡수 대비** 예시는 실제 이전 교전에서 번개를 시전해 기억을 만든 뒤, 다음 적을 상대로 자리를 지키며 보호막으로 맞는 조건이다. 이 예시에서만 회피를 끈다는 비용을 명시한다. 일반 생존 칙령은 회피가 먼저이며, 피한 공격은 속성 반응을 만들지 않는다.

## 경계와 검증 기록

구현 소유자: [전투 메커니즘](../../Assets/HELLSCRIPT/Runtime/Core/CombatSimulation.SkillIdentity.cs), [저장되는 스킬 상태](../../Assets/HELLSCRIPT/Runtime/Core/ClassSkillState.cs), [사냥칙령 프리셋](../../Assets/HELLSCRIPT/Runtime/Core/HuntEdictQuickPresets.cs), [macOS 화면·자동 전투 검사](../../Assets/HELLSCRIPT/Runtime/Presentation/RuntimeSkillTreeSmoke.Identity.cs), [새 프로세스 저장 재개 검사](../../Assets/HELLSCRIPT/Runtime/Core/ClassSkillNativeSmoke.cs).

빚은 재장착·저장 복원으로 사라지지 않으며 남은 빚이 있으면 수동·자동 재차입을 막는다. 추가 화살은 직접 공격 발동을 재생산하지 않는다. 실제 발사 위치를 피해 이벤트에 남기고 저장된 옛 화살은 기존 시전 위치로 처리한다. 접지 중계는 감지되지 않은 적이나 벽을 통과하는 지름길을 만들지 않는다. 생존 회피가 서리 회수 이동보다 우선한다.

아이콘 8개를 개별 생성해 원본 RGBA 바이트와 Unity GUID를 보존한다. 원본 핸드오프는 보존하고 `Docs/Art/ClassSkillIcons/identity-rework.json`이 변경된 이름·컨셉을 명시적으로 대체한다. 생성 도구는 모델 이름을 반환하지 않으므로 `model=unknown`, `approval=candidate`를 유지한다. 알파·밝은/어두운 배경·64px 구분성과 잘림을 검사한다.

집중 메커니즘 검사 26개에서 저장된 빚·왕복 경로·원소 반응·교차 관통·실제 이동·자동 프리셋·공유 복원과 빚이 없을 때의 상태 보존을 확인했다. 아래 수치는 최초 개편 당시의 역사적 결과다. 당시 전체 Edit Mode 검사는 마지막 통합 단계에서 한 번 실행했다. 5,114개 중 4,978개 통과, 136개 실패였다. 이번 변경으로 생긴 실패 8개를 수정한 뒤 관련 검사 81개가 모두 통과했다. 당시 남았던 128개는 기존 실패로 분류했다. 이전 보고서와 같은 assertion 127개를 대조했고, 보호막 예시 실패 1개는 변경 전 `4c9e7b7e`에서도 재현했다. 이 최초 실행은 전체 검사를 통과한 결과가 아니다. 남았던 실패는 위의 후속 수정에서 해결했다.

`7c6f2724`에서 빌드한 macOS 개발 플레이어는 오류 0개로 생성됐다. 실제 자동 전투에서 일곱 스킬의 밀어내기·차입·교차 피해·잔상 피해·속성 반응·귀환 완료·접지 중계를 확인했다. 설치·이동·회수 공격 순서와 사선 선회는 실제 컨트롤을 선택하고 저장 파일을 다시 읽어 검증했다. 440×956, 956×440, 1600×900, 1600×1000, 2100×900에서 KO/EN과 가로 안전 영역 모의를 확인해 캡처 91장을 남겼다. 입력은 실제 uGUI raycast와 합성 pointer down/up/click이며 물리 마우스·터치 검사로 표현하지 않는다.

별도 새 플레이어 프로세스에서 12개 전투 저장을 재개했다. 미상환 빚·귀환 중인 서리·접지창·잔상·원소 기억을 포함해 피해, 자원, RNG, 이벤트, 정책 진행, 보상이 중단 없이 진행한 결과와 일치했다. 모바일 실기기는 검사하지 않았으며 초기 수치의 최적 밸런스를 주장하지 않는다.

필수 CI가 확인하는 전투 비교 생성 문서와 스킬 트리의 직접 연계 인용을 최신 이름·효과로 갱신했다. 111개 직접 연계의 원본 대조와 프로토타입 성장·장착 검사 39개가 통과했다. 전선 돌파의 연계 보호막·장비와 투쟁의 빚·접지창 빌드 설명도 정리했다. 이 후속 수정은 설명 문구와 문서·도구 자료에 한정된다. `7c6f2724`와 전투 코드 전체 및 설명을 제외한 런타임 데이터 전 필드가 같음을 대조했으므로 통과한 실행 결과를 재사용했다.
