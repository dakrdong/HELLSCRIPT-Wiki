# 균열 목표·보상 통합 개발 기록

작성일: 2026-09-12 · [English](Rift_Integration_Expansion.en.md)

## 이번 단계의 범위

[정수 운반자·제물 운반](Objective_Chains_Expansion.md)과 완료된 [단계별 등급 확률](Rift_Rarity_Expansion.md)을 하나의 실행본으로 검증한다. 정수 처치·제물 회수·관문 개방·결과 기록과 일반·정예·보스·소탕의 보상 계산, 고정 재설정 비용이 함께 동작해야 한다.

결과 화면의 ‘사망 원인 분석’ 버튼은 **실제로 영웅이 사망해 실패한 균열**에만 표시하도록 수정했다. 생존 귀환과 시간 초과, 훈련에는 표시하지 않는다. 같은 순간에 영웅과 보스가 사망해 승리하는 기존 규칙도 유지한다.

실제 실행 검사에서는 저장된 전투 로그가 영어로 바뀌지 않는 문제도 발견했다. 결과 화면과 과거 기록에서 시간·사건 번호는 그대로 두고, 본문만 기존 번역 표의 문구와 형식에 맞춰 표시한다. 이미 저장된 숫자의 정밀도와 기록 원문을 바꾸지 않는다. 알려지지 않은 문구는 원문을 유지하고 누락으로 기록한다. 기존 영어로 작성된 기록을 한국어로 역변환하는 기능은 이번 수정에 포함하지 않았다.

## 다른 작업과의 경계

검사 준비 중 같은 원본 폴더에서 별도 작업 **「콘텐츠 공개·해금 순서 구현」**이 시작되었다. 진행 중인 해금 코드·데이터는 수정하거나 검증 완료로 간주하지 않는다. 클로드의 능력치·밸런스 변경은 아래 인수 항목으로 관리하며, 이번 실행본에는 아직 포함하지 않았다.

검증 프로젝트는 보관한 목표 기능 프로젝트에 보상 작업의 완료 커밋 `166106a`와 이번 결과 화면 수정을 적용해 만들었다. 패치가 적용 가능한지 먼저 확인하고, 목표 생성·저장 코드는 이전 검증본과 같다는 것을 파일별 해시로 대조했다. 원본에서 다른 작업의 변경을 되돌리지 않는다. 이 기록의 통합은 **목표·보상·결과 화면**의 통합을 가리키며, 해금 작업까지 포함한 현재 원본 전체의 완료를 뜻하지 않는다.

## 클로드 완료본 인수와 main 병합 상태

사용자가 클로드의 밸런스 작업 완료와 main 병합을 요청했다. 저장소 기록을 확인한 결과, `worktree-d4-stat-sheet`의 변경은 **2026-09-12 21:07:30 KST에 main으로 이미 병합**되었다. 당시 확인한 main의 끝은 `b1f3ea5`이며, 능력치 구현 `02d9d04`와 밸런스 기록 `39e2a3c`가 모두 포함된다. 중복 병합을 만들지 않았다. [브랜치 포함 관계와 병합 기록](../../Artifacts/Validation/AttributeIntegration/branch-integration-status.json)을 보존했다.

개발 범위에 다음 내용을 추가한다.

- 속성 57개와 기존 저장 번호 0~23 유지, 캐릭터 시트 계산·피격·타격·회복·자원 연결.
- 접사 54종과 부위별 접두·접미 배분, 능력치 화면 및 한국어·영어 문구.
- 클로드 보고서의 6개 구성 × 30시드 × 4단계 비교와 남은 20단계 접사 분포 확인. 현재 폴더에는 해당 측정 원본이 없어 보고서의 수치를 새 검증으로 간주하지 않는다.
- main에 있는 능력치·접사 위키 변경과 미결 항목을 현재 개발분에 통합.

현재 작업 폴더의 개발 브랜치는 `codex/claude-review-20260912`다. main에 병합되어 있다는 사실과 이 개발 브랜치의 진행 중인 변경까지 통합 검증했다는 주장은 구분한다. 별도 검토본에서 보상 코드와 번역 표의 충돌을 정리했다. 이동 속도 단위와 능력치 화면 재표시 후 전투 일시정지 복귀는 다음 검증에서 재현·수정할 항목이다. 세부 준비 상태는 [클로드 변경 검토 기록](../../Artifacts/Validation/AttributeIntegration/review-plan.json)을 따른다.

## 후속 통합 완료

이후 [능력치 통합](Attribute_Integration_Expansion.md)에서 클로드 변경과 완료된 콘텐츠 해금을 합쳤다. 해당 후속 실행본은 전체 검사 1,391개와 앱 실행·재시작 9회를 통과했다. 위 1,325개 검사와 7회 실행은 이 문서의 목표·보상·결과 전용 실행본에 대한 당시 증거로 유지한다.
