# 첫 플레이: 가방 복귀와 저장 복구

2026-09-27 · D01 구현 및 기존 차단 세이브 복구 검증

균열에서 가방 정리로 자동 복귀한 뒤 공간을 비워도 가방이 다시 열리는 결함을 수정했다. `GameUI.PlayInventory`가 포털 문맥을 인벤토리에 전달하지 않아 닫기와 전투 재개가 연결되지 않았던 문제다.

## 실제 동작

- 가방에 `균열로 복귀`, 창고, 보석 보관함을 표시한다. 전리품 정리 단계에는 `남은 보상 두고 완료`를 사용할 수 있다. 마을 귀환과 남은 보상 포기는 결과 설명과 확인을 거친다.
- 닫기와 ESC도 복귀 가능 여부를 다시 검증한다. 장비 또는 미수령 보석의 공간이 부족하면 원인과 정리 경로를 유지한다.
- `PortalRecovery`가 행동 가능 여부를 계산하고 `GameStore.ResumePortal`/`ReturnFromPortal`이 저장 후 상태를 반영한다. 전투 ID·난수·진행 시간·획득 보상을 초기화하지 않는다.
- 공통 창의 일시정지 임대는 저장된 재개 상태를 받아 마지막 창이 닫힐 때 적용한다. 자식 창만 닫아 사냥이 시작되는 일을 막고, 일반 창의 기존 정지 상태는 보존한다.
- 복귀 또는 종료 저장에 실패하면 기존 전경 안전 정지 경로로 연결한다. 정상 저장과 명시적인 재개 전에는 피로도를 추가 차감하지 않는다. 일반 일시정지·가방 체류 중 피로도 규칙은 유지한다.

가로 화면의 복귀 행동은 가방 열 아래에 둔다. 캐릭터 장착 영역을 줄여 장비·물약과 능력치가 겹치지 않게 한다. 기존 인벤토리 어댑터와 공통 장비 표시를 사용하며 별도 창 프레임워크는 만들지 않았다.

## 검증 근거

기준 커밋은 `246940407ea4ac3914285f4d59b27f2b91ea562c`다. 원본 플레이 세이브는 보존하고 복사본을 macOS Development Player에 불러왔다. 정상 1배속에서 uGUI 레이캐스트로 버튼이 실제로 눌릴 수 있는지 확인한 뒤 포인터 이벤트를 보냈다.

|---|---|---|
| 전사 Lv.12 · 균열 6 | 보스 처치 후 가방 반복 진입 | 원래 전투를 유지하고 162.9053초에 정산. 완료 기록 1개. |

[전사 실행 결과](FirstPlayRecoveryEvidence/warrior.txt) · [마법사 실행 결과](FirstPlayRecoveryEvidence/mage.txt)

레벨·재화·가방 용량·게임 시간을 주입하지 않았다. 복구용 `RuntimePortalRecoverySmoke`는 명시한 복사 세이브와 결과 폴더에서만 실행한다. 실제 마우스 또는 모바일 실기기 검증과 구분한다.

`PortalRecoveryTests` 10개는 보스 전후 복귀·귀환, 공간 부족, 획득 제한 모드, 저장 실패와 재시도, 완료 중복 방지, 중첩 창 정지 복원을 검사한다. D01/D02 후속 묶음 18개도 통과했다. 공통 UI 소유권 검사와 검사기 자체 테스트 9개가 통과했다. 전체 화면 행렬과 세 직업 균열 20 완주는 후속 D10 검증에서 별도로 기록한다.

## 소유 코드

- `Runtime/Core/PortalRecovery.cs`: 행동 판정과 저장 거래.
- `Runtime/Presentation/GameController.cs`: 저장 성공 후 전투/마을 전환과 오류 정지.
- `Runtime/Presentation/InventoryWindow.Portal.cs`, `InventoryWindow.cs`, `GameUI.PlayInventory.cs`: 포털 문맥, 확인, 정상 입력 경로.
- `Runtime/Presentation/ContentWindowHost.cs`: 중첩 창의 정지 상태 복원.

이 복구 수정으로 계정 저장 스키마를 올리지 않았다. 이전 미완료 세이브는 기존 런타임 상태에서 이어 간다. 이후 다른 개발과의 병합은 [2026-09-27 통합 기록](Main_Integration_20260927.md)을 따른다. 모바일 실기기 검증은 별도다.

복구 전후 저장값의 [무결성 비교](FirstPlayRecoveryEvidence/integrity.json)에서 기존 장비와 전투 기록 보존, 미수령 장비의 중복 없는 수령, 종료 기록 1건 추가를 확인했다. 전사 골드 변화 −125는 자동 물약 보충 125이며, 마법사는 추가 획득 3,245에서 물약 보충 130을 뺀 3,115가 정확히 반영됐다.
