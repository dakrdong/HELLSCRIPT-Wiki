# 전사 철벽·전투 함성·기본 공격 사냥 칙령 연결

작성일: 2026-09-13 · [English](Edict_Warrior_Support_Expansion.en.md)

상태: **철벽 4개·전투 함성 5개·근접 기본 공격 4개, 총 13개 핵심 옵션을 연결했다. 전사의 액티브 6종과 기본 공격에 대한 핵심 옵션 30개가 모두 독립 판단을 사용한다.**

## 개발 범위와 연결 구조

[지면 강타 연결](Edict_Slam_Expansion.md)의 `fe047ca`에서 이어서 [스킬별 옵션 기획](../Design/HELLSCRIPT_Hunt_Edict_Skill_Option_Catalog.md)과 [화면 배치 상세안](../Design/HELLSCRIPT_Screen_Layout_Detail.md)을 적용했다. 클로드의 능력치·접사·밸런스 기록은 메인에 포함된 상태를 유지한다. 병합이 끝난 작업 브랜치는 이미 정리했으며 이번 단계도 `main`에서 진행한다.

저장된 v0.2 문서 → `EdictRuleOrder.ForSimulation`의 실행 후보 → `CombatSimulation`의 순수 계획 함수 → 기존 준비·발동·회복 처리 순서로 연결한다. 전사 기본 공격은 액티브 칸을 쓰지 않는다. 이전 규칙이 없거나 꺼져 있거나 중복돼도 핵심 설정을 한 번만 평가하며, 원래 규칙은 수정하지 않는다. v0.2 사용을 끈 캐릭터는 기존 규칙을 따른다.

## 연결한 옵션과 실제 효과

| 행동 | 연결한 판단과 제약 |
|---|---|
| 철벽 · 4개 | 자동 사용, 긴급 생존·위험 예방·정예 교전 진입, 다른 보호막과의 중첩, 실제 도약 방어와의 중첩을 적용한다. 새 정예·보스 교전에서 한 번 먼저 검토하며, 사용할 수 없다고 다른 공격을 기다리게 하지 않는다. 직접 요청된 전역 긴급 생존은 다른 방어 효과의 대기를 해제하지만 자신의 철벽 재사용과 총 보호막 상한은 계속 지킨다. |
| 전투 함성 · 5개 | 자동 사용, 자원 보충·공격 강화·둘 다, 교전 종류, 강화 시점, 비전투 보충을 적용한다. 자원 보충은 실제 공격 순서에서 선택할 공격의 할인된 비용을 확인하며, 쿨다운·사거리·용도 실패를 자원 부족으로 취급하지 않는다. 자원 보충에는 강화용 교전·도달 제한을 적용하지 않는다. 인지한 적이 없는 보충은 허용 설정과 고정 기준인 자원 60 이하를 요구한다. |
| 근접 기본 공격 · 4개 | 자동 사용, 보완·자원 보충·마무리 역할, 전역·현재·가까운·낮은 HP 대상, 절제 충전까지의 대상 유지를 적용한다. 마무리는 먼저 HP 30% 이하로 후보를 제한한다. 절제 대상 유지는 실제 LC02가 있어야 하며, 사망·관측 상실·실행 불가 시 새 대상을 고른다. 먼저 실행할 액티브나 생존 행동을 막지 않는다. |

철벽은 준비 0.2초, 기본 최대 HP 30%에 실제 보호막 생성 배율을 적용한 양, 지속 4초, 재사용 대기시간 14초를 유지한다. WP05와 다른 출처의 보호막을 실제 능력치·잔여량으로 계산한다. 준비 중 다른 보호막 때문에 합계 상한에 도달하면 발동 직전에 다시 확인해 생성을 중단한다.

함성은 준비 0.35초가 끝나야 자원 40과 6초간 피해 증가 20%를 부여하며, 실제 최대 자원을 넘는 회복분은 버린다. 회오리를 취소하거나 동시에 사용하지 않는다. 긴급 생존으로 준비가 취소되면 회복·버프를 미리 지급하지 않는다. 공격 도달 검사는 유효 목표·실제 사거리·사선만 확인하므로 함성이나 충전을 요구하는 후속 조건을 재귀 검사하지 않는다.

기본 공격은 실제 2m 적중 때만 자원 10과 LC02 적중 횟수를 얻는다. 사망·거리·벽 때문에 빗나가면 실패 기록을 남기고 보상을 주지 않는다. 가까이 멈추는 방침에서도 2~2.5m 사이에 서서 공격하지 못하던 경우를 고쳐 실제 2m까지 접근한다. WP01·WP04·WP06의 기존 적중·처치 효과는 장착 여부에 따라 계산하며 선택 옵션이 패시브를 새로 부여하지 않는다.

## 저장 복원과 화면

이미 시작한 행동은 준비 중 자동 사용을 꺼도 기존 행동으로 한 번 완료한다. 준비·회복·철벽의 교전 진입 확인·LC02의 연속 적중과 실제 충전은 기존 저장 구조로 복원한다. 별도 예약이나 저장 필드를 추가하지 않았다.

한국어·영어 설명을 세 행동 화면에 추가했다. 긴 본문은 스크롤하고 돌아가기·되돌리기·저장 및 적용 버튼은 하단에 고정한다. 최종 앱에서 13개 옵션을 UI 버튼 이벤트로 순환하고, 저장 파일을 새로 읽어 선택값을 대조했다.
