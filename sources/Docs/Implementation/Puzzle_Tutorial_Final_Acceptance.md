## 마지막 구현

- L1은 대기실의 실제 스킬 메뉴에서 학습·장착·저장·닫기를 안내한다. 기존 스킬 창과 입력 게이트를 사용하고 독립 복습에는 첫 수업을 다시 강제하지 않는다.
- 고정 메뉴는 공통 창 호스트의 레이어를 사용하고 스킬 말풍선·저장 모달 동안 입력을 막는다. 슬라이드가 끝나는 프레임에 탐색을 다시 활성화한다. 전환 중 상태 막대 고정, 배경 명도·채도 감소, 빛 흐름·횃불·빛줄기·배경 이동·재사용 불씨를 연결했다.
- 기존 모션 줄이기 기기 설정과 macOS 시스템 설정을 반영한다. 다른 OS의 시스템 연동은 미검증이다. 레벨 숫자와 진행 표시는 장식판의 검은 창 안에, 제목은 공통 테마의 어두운 띠 안에 배치했다.
- 입력 게이트의 가림막 위치는 `LateUpdate`에서 최종 레이아웃을 읽는다. 기존 칙령·룬 보드 안내도 같은 소유자를 사용한다. 전투나 저장의 틱 순서는 바꾸지 않는다.
- 힌트 거래는 저장·알림 사이에서 실제 전투 참조를 보존한다. 같은 버튼 동작의 교관 설정 저장이 진행 중인 전투에 적용되며, 재패배해도 이미 연 힌트 단계는 유지한다. 관련 6개 검사가 통과했다.
- 첫 정찰과 파 사이 휴식의 표시 키에 휴식 상태를 포함한다. 스킬 트리가 없는 다른 영웅은 기존 소유자의 정확한 변환 결과만 허용하며 새 편집 권한을 주지 않는다. 관련 5개 검사와 실제 L8 마법사 저장의 소유 상태 보존·부당 편집 거부 검사가 통과했다.
- 졸업은 기존 마을 도착 연출을 재사용해 첫 인사가 성장 안내보다 먼저 나온다. 졸업 버튼을 누르기 전 재접속해도 대기실이 기존 게임 페이지를 설정하므로 캐릭터 선택 화면의 정리가 도착 연출을 취소하지 않는다.
- 단일 대사의 실제 다음 버튼으로 글을 펼치는 입력을 검증기에 연결했다. 긴 영어 문장을 기다리다 실패하던 검증 시간을 전투·대사 속도 변경 없이 해결했다.
- 복습 종료는 기존 공통 닫기 버튼을 입력 가드가 있는 고정 탐색 영역에 배치해 배경에 가리지 않게 한다. 일지에서 선택한 레벨이 독립 복습 대기실에 표시된다. 졸업 후 복습 종료·승리는 마을로 돌아오며 실제 장비·칙령·경제·졸업 보상 1회를 보존한다.
