# HELLSCRIPT 룬 영역 중앙의 엘리트 능력

작성일: 2026-09-17

## 배경

[잠긴 룬 영역 미리보기](Rune_Region_Preview.md)에서 남긴 과제를 끝낸 기록이다. 그 작업은 잠긴 영역의 중앙 칸을 실제 데이터로 읽어 보여 주는 구조만 옮겼고, 시안이 그 자리에 두기로 한 여섯 엘리트 능력은 게임에 없다고 적었다. 이번에 그 여섯을 능력 데이터·보드·전투에 넣었다.

능력의 이름·수치·조건은 `HELLSCRIPT-RuneBoard-Elite-Preview-v13.zip`의 `source/data-and-assets.js`에 있는 정의를 그대로 따랐다. 새로 설계하지 않았다.

## 영역과 엘리트를 맞춘 방법

시안의 여섯 영역과 Unity의 여섯 색 등급은 이름이 다르다. 순서대로 붙이지 않고 **두 보드의 좌표가 가리키는 방향**으로 맞췄다. 시안과 게임은 같은 육각 배치를 쓰고 반지름만 다르다(시안 영역 37칸, 게임 61칸). 각 영역 중앙의 방향각을 재면 여섯 쌍이 모두 1.04° 안에서 일치한다.

| 게임 영역 | 중앙 좌표 | 방향각 | 시안 영역 | 엘리트 |
|---|---|---|---|---|
| G1 상아 | (5, −9) | 56.33° | 파급 (55.28°) | 연쇄 붕괴 |
| G2 초록 | (−5, 9) | 236.33° | 수호 (235.28°) | 불굴의 결계 |
| G3 하늘 | (−9, 4) | 176.33° | 맹공 (175.28°) | 전투 열기 |
| G4 보라 | (−4, −5) | 116.33° | 정밀 (115.28°) | 급소 노출 |
| G5 황금 | (9, −4) | 356.33° | 기교 (355.28°) | 기술 전승 |
| G6 장미 | (4, 5) | 296.33° | 순환 (295.28°) | 순환의 핵 |

보드 중앙(G0)은 시안에서도 `elite: null`이므로 기존 공격력을 그대로 둔다.

여섯 무기가 모두 같은 표를 쓴다. 엘리트는 영역의 성질이지 무기의 성질이 아니다.

## 능력

각 능력은 수치가 아니라 하나의 효과다. 그래서 칸의 수치 등급이 없고 단위도 비어 있으며, 아래 선택 정보와 활성 능력 요약에 숫자 없이 이름과 설명으로 나온다.

| 엘리트 | 효과 |
|---|---|
| 전투 열기 | 직접 적중마다 공세 +1. 중첩당 직접 피해 +2%, 최대 5중첩. 획득 간격 0.5초. 마지막 직접 적중 후 4초에 모두 해제 |
| 급소 노출 | 직접 치명타로 맞은 대상이 8초간 내 직접 피해를 +20% 더 받음. 재적용은 시간만 갱신. 시안의 4초 +10%를 [측정](Rune_Elite_Balance.md) 뒤 올렸다 |
| 연쇄 붕괴 | 직접 타격으로 처치 시 2.5m 폭발. 공격 기준 D의 30%, 처치 타격과 같은 속성. 내부 재사용 1초 |
| 기술 전승 | 장착 중인 액티브 스킬 레벨 +1. 스킬별 레벨 룬과 합산해 최대 +5 |
| 순환의 핵 | 실제 소비 자원 50마다 남은 재사용 시간이 가장 긴 장착 액티브를 1초 감소. 내부 재사용 3초 |
| 불굴의 결계 | 생명력이 35% 위에서 35% 이하로 내려갈 때 최대 생명력의 20% 보호막 4초. 내부 재사용 30초 |

## 구현

능력은 기존 고유 장비 효과와 같은 통로로 전투에 닿는다. 룬 기여가 `HeroStats.specials`에 `ELITE_HEAT` 같은 이름을 넣고, 전투는 `Stats.specials.Contains(...)`로 읽는다. 고유 장비 `LW04`·`LM03`이 쓰는 방식 그대로다.

| 엘리트 | 붙인 자리 |
|---|---|
| 전투 열기 | `EliteDirectHit`에서 중첩 획득, `ConditionalBonus`에서 피해 적용 |
| 급소 노출 | `EliteDirectHit`에서 대상의 `eliteExposed` 갱신, `ConditionalBonus`에서 피해 적용 |
| 연쇄 붕괴 | `EliteCascade`. `Hit`이 아니라 `ApplyOutgoing`으로 때린다 |
| 기술 전승 | `HeroStats` 생성 중, 스킬별 레벨 룬을 합산한 뒤 |
| 순환의 핵 | `ConsumeCostEffects`. 실제 지불한 자원만 들어온다 |
| 불굴의 결계 | `Hurt`의 생명력 임계 통과. 기존 `LW04` 판정 바로 옆 |

몇 가지를 의도적으로 그렇게 했다.

- **중첩을 준 타격은 그 중첩으로 세지지 않는다.** 피해를 먼저 계산하고 그 뒤에 중첩·노출을 얹는다.
- **연쇄 붕괴는 `Hit`을 쓰지 않는다.** `Hit`은 치명타·압도·행운의 적중을 굴리고 다시 이 훅에 닿는다. `ApplyOutgoing`으로 직접 때리면 명세가 금지한 네 가지가 구조적으로 불가능해진다.
- **직접 피해의 정의를 한 곳에 뒀다.** `DirectHit(kind)`는 `Direct`와 `Basic`만 참이다. 지속 피해·가시·그림자·확산은 중첩도 노출도 만들지 않고 받지도 않는다.
- **`ConsumeCostEffects`는 실제 지불분만 받는다.** `paid<=0`이면 바로 돌아가므로 무료 발동과 자원 회복은 순환의 핵에 아무것도 쌓지 않는다.
- **내부 재사용 중의 50은 소모한다.** 명세가 "보류하지 않습니다"라고 했으므로 `while` 안에서 먼저 빼고 조건을 본다. 감소 대상이 없을 때는 내부 재사용을 걸지 않는다. 걸 일을 하지 않았기 때문이다.
- **새 상태는 저장되는 자리에 뒀다.** `CombatEffectState`와 `EnemyState`에 넣어 런 저장과 함께 유지된다. 전투 중 보드를 고쳐 저장해도 결계가 즉시 터지거나 대기시간이 초기화되지 않는다. 중첩 획득 시각은 `-1000`으로 시작해 런의 첫 타격이 바로 중첩을 얻는다. 이 필드가 없던 저장을 불러와도 초기값이 그대로 남는다.

## 시안과 다르게 둔 것

시안은 엘리트를 **모든 색 룬으로 활성**한다고 적었다. 게임에는 옮기지 않았다.

시안의 보드는 중앙 한 곳에서만 연결이 시작되고, 엘리트는 "모든 색을 인정하되 새 시작점이 아닌" 칸이다. 게임의 보드는 영역마다 시작칸이 하나씩 있고 그 영역의 색 룬만 시작칸을 덮을 수 있다(`ForeignStart`). 이 규칙을 풀면 다른 색 룬이 중앙을 차지한 채 그 영역의 연결을 시작하지 못하게 되어, 영역 전체가 막히는 함정이 된다.

그래서 시작칸 규칙을 그대로 두고 엘리트만 그 위에 얹었다. 결과적으로 엘리트는 그 영역의 색 룬으로만 켜진다. v13 지시문도 연결 규칙을 바꾸지 말라고 했다. 보드 위상을 시안처럼 하나의 중앙 시작점으로 바꾸는 일은 저장된 모든 배치의 유효성을 다시 정하는 별도 작업이다.

능력 아이콘도 여전히 없다. 룬 보드의 능력에는 그림이 없고, 아이콘을 넣으려면 능력별 원화가 필요하다.

## 바꾸지 않은 것

보드 좌표, 영역 개방 규칙, 색 요구 판정, 연결·간격 판정, 저장 스키마와 저장 키, 룬 배치·회수·회전·드래그, 보관함, 합성, 프리셋, 배치 연습은 그대로다. 보드 그리기도 바꾸지 않았다. 중앙은 예전처럼 청록 십자로 그린다.

일반 칸의 능력·수치·배정은 한 칸도 바뀌지 않았다. 바뀐 것은 여섯 무기 × 여섯 영역의 중앙 36칸뿐이며, [내보낸 카탈로그](Rune_Mastery_Catalog.json)의 차이도 그 36칸의 `meaning`과 `value` 두 줄씩 72줄이다.

## 검사

Unity Edit Mode, 저장소 사본에서 전체 suite를 실행했다.

새로 넣은 `RuneEliteTests`는 여섯 능력을 실제 전투 코드로 확인한다. 산술을 다시 적어 비교하지 않고 진짜 `Hit`·`Hurt`·`ConsumeCostEffects`를 부른다.

- 여섯 무기 × 여섯 영역의 중앙이 서로 다른 엘리트이고, 무기가 달라도 같은 영역은 같은 엘리트를 준다. 엘리트는 영역 중앙 말고는 보드 어디에도 없다. 보드 중앙은 공격력 그대로다.
- 중앙을 덮으면 그 엘리트가 `specials`에 들어가고 공격력이나 스탯 줄은 늘지 않는다. 아무것도 놓지 않으면 `specials`에 엘리트가 없다.
- 전투 열기: 중첩을 준 타격은 그 중첩을 받지 않는다. 0.5초 안의 두 번째 타격은 피해만 늘고 중첩은 안 준다. 1중첩 +2%, 5중첩 +10%, 5에서 멈춘다. 지속 피해는 중첩을 주지도 유지하지도 않는다. 마지막 직접 적중 4초 뒤에 전부 사라지고 피해가 원래대로 돌아온다.
- 급소 노출: 일반 타격은 노출을 만들지 않는다. 치명타는 4초 노출을 걸고 +10%를 준다. 옆의 다른 적에게는 옮지 않는다. 취약 표식은 붙지 않는다. 재적용은 시간만 갱신한다. 4초 뒤 원래대로 돌아온다.
- 연쇄 붕괴: 2.5m 안만 맞고 밖은 안 맞는다. 폭발은 치명타가 아니고, 기준 D의 30%이며, 처치 타격의 속성을 쓴다. 1초 안의 두 번째 처치는 폭발하지 않고, 1초 뒤에는 다시 폭발한다.
- 순환의 핵: 장착한 것 중 가장 긴 재사용 시간만 1초 줄고, 장착하지 않은 스킬은 건드리지 않는다. 내부 재사용 중의 50은 줄이지 않되 남기지도 않는다. 30 + 20은 한 번의 감소가 된다. 0 지불은 아무것도 쌓지 않는다. 줄일 것이 없으면 내부 재사용을 걸지 않는다.
- 불굴의 결계: 35% 위에서는 안 생긴다. 통과하면 최대 생명력의 20%가 4초 생긴다. 4초 뒤 사라진다. 30초 안의 두 번째 통과는 무시하고, 30초 뒤에는 다시 답한다.
- 엘리트가 없는 보드에서는 위의 어느 것도 일어나지 않는다.

기존 `AbilityTiersDistinguishBaseStatsSpecialtiesAndSkillLevels`에 엘리트 분기를 더했다. 엘리트는 수치가 아니므로 수치 등급이 0이다. 기존 분기는 그대로 두었다.

macOS 개발 빌드의 런타임 스모크 `-hellscriptRuneSmoke`도 늘렸다. 화면 촬영용 고정 장치가 이미 잠시 모든 영역을 열고 있으므로, 같은 자리에서 G1 룬 하나를 임시로 주고 장착 무기 보드의 G1 중앙을 실제로 덮는다. 세로 한국어와 가로 영어에서 엘리트 이름과 `능력이 활성화되었습니다.`를 읽고, 전투를 시작해 `Stats.specials`에 그 엘리트가 들어갔는지, 공격력으로 잘못 세지 않았는지 확인한 뒤 배치와 룬과 실클리어를 모두 되돌린다.

근거로 [세로 한국어 화면](RuneEliteEvidence/12-elite-centre-active-ko.png), [가로 영어 화면](RuneEliteEvidence/13-elite-centre-active-en-landscape.png), [Edit Mode 전체 보고서](RuneEliteEvidence/editmode-full.xml), [실행 기록](RuneEliteEvidence/runtime.txt), [스모크 출력](RuneEliteEvidence/smoke-result.txt)을 남겼다.

스모크는 실패로 끝난다. 이번 변경 이전부터 있던 전역 관찰 HUD `Shield` 라벨 하나가 화면마다 걸린다. 자세한 확인 방법은 [실행 기록](RuneEliteEvidence/runtime.txt)에 적었다.

검사는 macOS 개발 빌드에서만 돌렸다. 실제 모바일 기기에서는 보지 않았다. 밸런스는 재지 않았다. 시안 ZIP의 QA 결과는 브라우저 시안에 대한 것이므로 이 구현의 근거로 쓰지 않았다.

## 남은 일

엘리트를 모든 색으로 켜는 규칙은 보드 위상을 바꿔야 하므로 남겨 두었다. 능력 아이콘, 포인트로 슬롯을 사는 개방 방식, 자물쇠 팝업 형태의 화면도 룬 보드 전체를 시안에 맞추는 별도 작업이다.

여섯 능력의 수치는 시안의 밸런스 초안 그대로다. 같은 날 [룬 엘리트 밸런스 측정](Rune_Elite_Balance.md)에서 시뮬레이션으로 쟀고, 수치는 아직 바꾸지 않았다.
