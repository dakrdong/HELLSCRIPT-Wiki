# 클로드 능력치 변경 통합

작성일: 2026-09-12 · [English](Attribute_Integration_Expansion.en.md)

## 병합과 개발 범위

클로드의 `worktree-d4-stat-sheet` 변경은 2026-09-12 21:07:30 KST에 `main`으로 이미 병합되어 있었다. `main`의 `b1f3ea5`에는 능력치 구현 `02d9d04`, 밸런스 보고서 `39e2a3c`, 위키와 남은 작업표가 포함되어 있다. 중복 병합을 만들지 않고 이 변경을 당시 개발 브랜치 `codex/claude-review-20260912`에 통합했다.

검토 후 수정까지 포함한 통합 커밋은 `92d5812`이며, 로컬·원격 `main`과 개발 브랜치에 반영했다. 후속 접사 분포 검사와 현재 균열의 대조 실험은 [접사 검증 기록](Affix_Audit_Expansion.md)으로 이어진다.

2026-09-13에 로컬·원격 메인이 `f6f80ab`로 일치하고 클로드 커밋 `b1f3ea5`를 포함함을 다시 확인했다. 사용자 요청에 따라 병합이 끝난 `codex/claude-review-20260912`를 로컬과 원격에서 삭제하고 작업 위치를 `main`으로 바꿨다. 당시 커밋하지 않은 기존·진행 중 변경 파일 29개의 상태와 내용 해시는 전후 동일하다. 원격에는 `main`만 남아 있다.

이번 통합본에는 다음 작업이 함께 들어간다.

- 클로드의 속성 57개, 접사 54종, 능력치 화면과 전투·성장 계산. 기존 저장 번호 0~23을 유지한다.
- [균열 목표·보상·결과 화면](Rift_Integration_Expansion.md), 실제 관문 통행, 사냥 칙령의 대상 선택·추적·회수 정책.
- 완료된 콘텐츠 공개·해금 커밋 `046354a`. 계정 메뉴 권한과 현재 균열 단계, 영웅별 최고 기록을 구분한다.
- 단계별 장비 등급 확률 커밋 `166106a`와 아이템 레벨별 고정 재설정 비용.

충돌한 보스 정산에서는 금화 획득 보너스, 캐릭터별 초회 보상, 현재 단계의 등급 추첨, 보상 확정 후 콘텐츠 해금을 모두 유지했다. 위키는 능력치 57행·접사 54행·해금 조건 9행을 함께 읽도록 정리했다. 양쪽 개발 현황의 과거 문서 내용도 보존했다.

## 검토 후 수정한 문제

| 문제 | 수정 결과 |
|---|---|
| 능력치 화면이 이동 속도 4m/s를 4%로 표시했다. | 능력치 시트는 실제 m/s를 표시하고, 장비 옵션과 옵션 비교는 기존 % 단위를 유지한다. 3직업의 기본값·장비 보너스·상한을 검사한다. |
| 능력치 접기·펼치기와 언어 변경 후 전투로 돌아가면 정지가 남았다. | 성장·능력치 화면에 처음 들어온 시점의 정지 상태를 유지한다. 실행 중 진입, 수동 정지 후 진입, 두 화면 간 이동과 추천안 취소를 구분한다. |
| 최대 자원이 증가해도 HUD와 전투 요약은 최대 100으로 표시했다. | 실제 최대 자원을 표시하고 게이지도 그 값으로 계산한다. 자원 70/140은 절반으로 표시한다. |
| 영어 140% 글자 크기에서 능력치 화면의 부제가 잘렸다. | 영어 설명을 간결하게 다듬고 기존 화면 배치와 큰 글자 설정에서 확인한다. |

[화면 배치 상세안](../Design/HELLSCRIPT_Screen_Layout_Detail.md)에 맞춰 기존 공통 머리말·스크롤 본문·하단 이동 구조를 사용한다. 성소 또는 전투의 **성장과 스킬 → 능력치**에서 확인한다. 씬·프리팹·패키지를 새로 만들거나 교체하지 않았다. 클로드 커밋에 포함된 재질의 자동 직렬화 차이는 제외하고 기존 재질과 GUID를 보존했다.

## 밸런스 보고서와 남은 항목

[클로드의 능력치 개발 기록](Attribute_System_Expansion.md)에 있는 6개 구성 × 30시드 × 4단계 비교를 개발 기록으로 인수했다. 20단계 승리 12→6회와 접사 희석은 후속 확인 항목이다. 해당 측정 원본이 현재 폴더에 없으며, 지도·해금 규칙도 이후 변경되었으므로 그 수치를 이번 통합본의 성능으로 사용하지 않는다. 이번 검사는 기능의 동작과 회귀를 확인하며 장기 난이도를 확정하지 않는다.

기본 회피와 직접 타격의 3% 압도 판정은 장비가 없어도 존재한다. ‘새 속성이 모두 중립이다’라는 과거 설명은 이 두 예외를 포함하도록 정정했다. 전투 수치나 접사 가중치를 근거 없이 다시 조정하지 않았다.

군중 제어 지속시간 감소와 기력 2종은 정의·저장 번호를 보존하고 장비 추첨에서 제외한다. 실제 보석·소켓, 장기 경제·난이도, 모바일 실기기의 터치·성능과 서버 동기화는 남은 개발 범위다.
