# 전투 피해 그래프 (2026-10-10)

[English](Damage_Graphs_20261010.en.md)

균열 전투의 DPS 패널 아래에 받은 피해 그래프 두 개를 둔다. 물약을 HP 몇 % 아래에서 써야 살아남는지 판단하는 정보다. 한 줄은 "초당 평균 피해 · 영웅 최대 HP 대비 %"이며, 예를 들어 HP 100에 초당 30이면 30%다.

- **몬스터 피해 그래프**(항상 표시): 영웅에게 가장 최근에 피해를 준 몬스터 종류 5개를 최근 순서로 보여 준다. 초당 평균은 최근 10초(`DamageGraph.MonsterWindow`) 안의 피해를 그 종류가 때린 시간(최소 3초, 최대 10초)으로 나눈 값이다. 막 나타난 종류가 낮게 읽히지 않게 하기 위함이다. 보스 피해는 포함하지 않는다.
- **보스 피해 그래프**(보스가 살아 있을 때만): 보스 인장과 이름, 그 아래에 피해가 높은 순 5개 공격(스킬)을 아이콘과 함께 보여 준다. 초당 평균은 보스에게 처음 맞은 때부터 지금까지의 누적 피해를 경과 시간(최소 3초)으로 나눈 값이다.
- **막대**: 영웅 HP의 50%/초에서 가득 찬다. 20% 이상이면 황금색, 40% 이상이면 붉은색으로 경고한다.
- **데이터**: `CombatStatistics.recentIncoming`(최근 1분의 피해, 저장하지 않음)과 기존 `incomingSources`(누적)를 `DamageGraph`가 계산한다. 저장된 전투를 이어 하면 최근 목록은 비어 있다가 다시 채워지고, 보스 첫 피해 시각은 누적 피해와 함께 저장하여 재개 전후 초당 피해 계산을 유지한다. 첫 피해 시각이 없는 이전 저장 파일은 기록된 관측 시작 시각을 기준으로 계산한다.
- **그림**: 보스 인장 5장과 공격 아이콘 33장은 Codex로 생성했다(`Resources/Art/Boss/`, 256px, 프롬프트·해시·매니페스트는 `Docs/Art/BossDamageGraph/`). 공격 ID는 `BossCombat`이 기록하는 ID와 같다(`BOSS01_SLAM` 등, 공통 `BOSS_BASIC`·`BOSS_ROAR`·`LEGACY_BOSS`).
- **적용 범위**: 일반 균열 전투. 훈련장·튜토리얼은 기존 패널(튜토리얼 2단계 이후의 "받은 피해 · 몹 종류별")을 그대로 쓴다.
- **기능 개발 당시 검증**: `DamageGraphTests` 3개와 관련 통계·지역화·HUD 테스트 173개, macOS 개발 빌드 스모크(`RuntimeDamageGraphSmoke`, 440×956·1600×900·956×440). 미검증: 실제 보스전의 수치 감각, 실기기.

## 통합 검사 (2026-10-10)

통합본의 전체 Edit Mode에서 5,688개가 통과하고 1개 HUD 리소스 등록 검사가 실패했다. 미승인 칙령 아이콘 5장을 게임 리소스 밖의 후보 보관 폴더로 옮겨 해결했다. 기존 저장 파일의 보스 피해 시작 시각 누락도 회귀 검사로 재현해 관측 구간을 사용하도록 보완했으며, HUD·피해 그래프·통계 관련 재검사 55개가 모두 통과했다. 전체 검사에서 제외된 4개는 별도 실행용 측정·콘텐츠 작성 도구다. 동일한 전체 검사는 반복하지 않았다.
