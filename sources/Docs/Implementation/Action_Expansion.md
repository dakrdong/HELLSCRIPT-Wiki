# HELLSCRIPT 전투 동작·투사체 개발 기록

작성일: 2026-09-08 · 범위: D3의 동작 실행·투사체·덫·전투 편집 보호 기반

이 기록은 [성소·저주 상자 확장](Field_Expansion.md) 이후의 변경을 다룬다. 전체 D3나 공개 버전의 완료 기록은 아니다. 자동 검사 87개와 macOS 빌드를 통과했으며 그래픽 비활성 모드에서 실제 프로그램의 동작·재시작을 검증했다. Mac 잠금으로 실제 화면 검증은 대기 중이다.

이후 22조건·OR/AND·독립 장착 목록·판단 기록의 구현과 검증은 [행동 규칙 개발 기록](Rule_Expansion.md)을 따른다. 아래 검사 수와 남은 항목은 이 동작 확장 당시의 기록이다.

## 1. 행동을 시작한 때와 효과가 발생한 때를 분리했다

기존에는 여러 스킬이 즉시 피해나 위치 변경을 적용한 뒤 공통 대기시간을 사용했다. 이제 `CombatSimulation`이 준비·이동·유지·회복·완료를 소유하고, `WorldView`는 그 상태를 읽어 표현한다. 화면의 애니메이션이나 오브젝트 삭제가 피해·착지·저장 결과를 결정하지 않는다.

| 행동 | 현재 적용한 시간 |
|---|---|
| 전사·궁수·마법사 기본 공격 | 각각 1 / 0.9 / 0.8초를 공격 속도로 나눈다. 준비 40%, 회복 60% 배분은 이번 구현의 시험값이다. |
| W01 회오리 | 3m 이내에서 유지 동작을 시작한다. 2.5m 공격 범위와 별도로 판정하며, 범위 안의 유효 적이 0.5초 동안 없으면 종료한다. 비용은 시작 때가 아니라 0.25초마다 차감한다. |
| W02 도약 | 준비 0.15초 + 이동 0.45초 후 착지 피해를 적용한다. |
| W03 분쇄, A01 관통 사격, A02 다중 사격 | 준비 0.65초를 공격 속도로 나눈다. |
| W04 지면 강타, W06 전투 함성, M06 서리 폭발 | 준비 0.35초를 적용한다. |
| W05 강철 피부, A05 표식, A06 그림자 화살, M04 순간이동, M05 원소 보호막 | 준비 0.2초를 적용한다. 순간이동 위치는 준비 완료 때 변경한다. |
| A03 맹독 덫 | 준비 0.3초 후 덫을 놓고, 덫 자체가 별도로 0.5초 동안 무장한다. |
| A04 후퇴 도약 | 이동 0.5초 후 착지 효과를 적용한다. |
| M01 화염구 | 준비 0.7초를 공격 속도로 나눈 뒤 투사체를 발사한다. |
| M02 눈보라 | 준비 0.4초 후 지속 영역을 생성한다. |
| M03 연쇄 번개 | 준비 0.45초를 공격 속도로 나눈 뒤 연쇄를 실행한다. |

기본 공격의 준비/회복 배분과 신규 영웅 투사체 속도는 검증을 위한 시험값이며 최종 밸런스가 아니다. 기존 기획의 스킬별 준비·이동시간은 유지했다. 회오리 외의 준비·회복 중에는 일반 이동이 위치를 변경하지 않으며, 도약 중에는 저장된 시작점·착지점 사이의 진행률만 위치를 변경한다. 체공 높이는 골격 없는 임시 몸체로 표현한다.

상위의 생존 규칙은 허용된 준비·유지 동작을 중단할 수 있다. 체공·회복 중에는 새 이동기를 예약하지 않는다. 실행이 확정된 뒤 중단하면 이미 쓴 비용과 시작한 CD는 되돌리지 않는다. 발사된 투사체나 설치된 덫은 시전자 행동을 중단해도 원래 수명을 유지한다. 사망·균열 종료 시 주 행동을 종료한다.

`ACTION_START`, `ACTION_TRAVEL`, `ACTION_RELEASE`, `ACTION_END`, `ACTION_INTERRUPTED`에는 행동 ID·스킬·목표·시각·자원·설정 버전·위치·사유를 저장한다. 최근 600개를 보존한다. 피해 사건 전체와 실행되지 않은 규칙의 차단 이유까지 완성한 로그는 아니다.

## 2. 투사체와 덫이 독립적으로 존재한다

| 대상 | 구현한 판정 |
|---|---|
| 궁수·마법사 기본 공격 | 각각 18 / 14m/s, 폭 0.4m, 최대 10m의 투사체를 사용한다. 자원은 발사 때가 아니라 실제 적중 때 회복한다. 속도는 신규 시험값이다. |
| 관통 사격 | 18m/s, 폭 0.6m, 최대 10m이며 실제 이동 경로 순서대로 최대 5명, 해당 패시브가 있으면 7명에게 적중한다. 같은 투사체의 동일 대상 재적중을 막는다. |
| 다중 사격 | 기본 -30/0/+30도, LA02 적용 시 -10/0/+10도로 세 발을 발사한다. 같은 발동의 동일 대상은 기본 1회, LA02는 최대 3회로 제한한다. 그림자 충전은 세 발에 대해 한 번 소비한다. |
| 화염구 | 14m/s, 폭 0.5m로 이동하고 적·벽·최대 이동 지점에서 폭발한다. 준비 중이거나 비행 중이라는 이유만으로 목표에게 먼저 피해를 주지 않는다. |
| 적의 원거리 기본 공격 | 10m/s, 폭 0.4m, 최대 9m로 이동한다. 발사자가 사망해도 이미 나온 화살은 남는다. N09의 세 발 패턴 등 개별 NPC 확장 전체를 완료한 것은 아니다. |
| 맹독 덫 | 준비 완료 후 0.5초 무장 → 최대 8초 대기 → 적 감지 시 발동 → 5초 동안 0.5초마다 피해를 적용한다. 동시에 최대 2개이며 오래된 덫부터 교체한다. LA03의 후퇴 덫은 지속시간 3초로 같은 상한을 공유한다. |

각 투사체는 출발점·방향·남은 거리·폭·속도·생성 시각·원 행동 ID·이미 맞은 적·피해 스냅샷을 저장한다. 한 틱에서 이동한 선분 전체를 검사하므로 빠른 화살이 얇은 벽을 건너뛰지 않는다. 관통 적중은 거리와 고정 ID로 정렬하고, 추가 관통파의 지연시간과 발동 제한도 저장한다.

겹치는 활성 덫은 대상별로 가장 강한 하나의 피해를 적용한다. 무장 중에는 피해가 없고, 발동 직후부터 별도 피해 틱을 계산한다. 출처별 상태이상·보스 제압·전체 추가 피해 계산의 통합은 후속 D3 작업으로 남아 있다.

## 3. 실제 사선과 전투 중 설정 변경을 보호했다

실제 화살 충돌을 연결하자, 궁수가 시야에는 보이지만 투사체가 막히는 적을 향해 계속 공격하는 문제가 드러났다. 시드 712의 관통 빌드 진단에서 18명 처치 후 같은 장소에 머물렀다. 발사 가능 판정에 실제 투사체 폭을 적용하고, 거리 유지 이동은 사선이 확보되는 유효 위치를 선택하도록 수정했다. 위치 후보는 0.6초 주기로 검토하며 목표나 목표 위치가 크게 바뀌면 다시 평가한다. 이 이동 요청도 저장된다. 제자리 설정은 기존의 이동 제한을 유지한다.

회오리 선회 목표는 설정한 반경 위에 두도록 수정했다. 이전의 접선 이동값 때문에 실제 반경이 커지던 문제와 첫 비용이 부동소수점 오차로 한 틱 늦게 차감되는 문제를 함께 검사했다.

균열 안에서 `ApplyBuild`는 허용 필드만 복사한다. 행동 조건·순서·목표·이동·물약·탐색·획득·상호작용·반복 설정을 바꿀 수 있다. 액티브 장착 목록·패시브·장비 참조는 유지한다. 프리셋에 현재 장착 스킬이 없으면 그 스킬의 기존 규칙을 유지하고 화면에 이 방식을 안내한다. 프리셋의 새 미장착 스킬은 가져오지 않는다.

훈련 중 장착 변경은 훈련 복사본에만 적용한다. 계정에 저장한 원래 빌드에는 반영하지 않는다. 훈련 복원은 저장된 훈련 빌드를 기준으로 능력치를 재계산한다. 현재 훈련의 레벨 30 시험 설정과 정식 플레이어용 훈련 분리는 여전히 D4 과제다.

편집 적용은 진행 중 주 행동을 중단하고 이전·새 버전과 바뀐 행동 행 수를 기록한다. 균열 안에서는 능력치를 다시 계산해 HP·자원·CD를 초기화하지 않는다. 취소와 적용 후에는 편집 전의 일시정지 상태를 복원한다. 전체 22조건 편집기와 모든 필드의 상세 변경 비교는 후속 작업이다.

## 4. 저장 계약과 기존 데이터

전투 상태에 `combatVersion=1`을 추가했다. 계정 저장 스키마 2와 지도 생성기 버전 2는 유지한다. 주 행동의 구간·경과시간·목표·조준·착지점·지불한 비용, 투사체, 동일 발동의 적중 상한, 덫, 사선 확보 목표와 구조화 사건을 저장한다. 일시정지와 포탈 중에는 이 전투 시계들이 함께 멈춘다.

구버전은 즉시 효과가 이미 적용된 저장으로 취급한다. 남은 공통 행동 대기시간은 효과를 다시 적용하지 않는 회복 상태로 옮기고, 진행 중 회오리는 유지 상태로 복원한다. 구버전의 기존 지속 효과도 남긴다. 지원하는 버전보다 새 전투 상태는 저장을 보존한 채 거부한다.

연쇄 번개·서리 폭발·회오리 끌기가 복원 직후 비어 있는 감지 캐시에 의존하던 부분을 현재 효과 위치·범위·시야로 판정하도록 수정했다. 이미 시작한 행동의 복원 시험은 총 피해뿐 아니라 매 틱의 저장 상태 전체를 비교한다.

## 6. 남은 작업

1. 잠금 해제 후 최종 macOS 빌드에서 실제 화면·재시작 검증을 마친다. 특히 체공 높이·화살 방향·덫 무장 표시·준비/회복/유지 중 HUD 문구와 편집 화면의 배치를 확인한다.
2. 22조건과 OR/AND, 규칙별 목표·이동 요청, 실행되지 않은 이유, 전체 우선순위·대상 유지·상한 검증을 완성한다.
3. 출처별 버프·상태이상·보호막·흡수·보스 제압과 18패시브·15전설·6세트의 전체 피해 순서를 통합한다. 현재 일부 추가 피해·독·장판 처리는 완전한 공통 계산을 사용하지 않는다.
4. 일반 적 12종·정예 6속성·보스 3종의 개별 준비·실행·회복·위험 예고를 연결한다. 모든 패턴이 새 투사체·동작 구조로 전환된 상태는 아니다.
5. 이후 D4 성장·마을·훈련·분석, D5 서버·계정·보석·결제, D6 기기·아트·음향·공개 검증을 진행한다. 이 기록을 D1–D6 전체 완료로 해석하지 않는다.

이번 변경의 소유 파일은 `CombatActions.cs`, `CombatSimulation.Actions.cs`, `CombatSimulation.Projectiles.cs`, `CombatSimulation.cs`, `CombatSimulation.Rift.cs`, `RiftNavigation.cs`, `GameCatalog.cs`, `GameStore.cs`, `BuildEditing.cs`, `WorldView.Actions.cs`, `WorldView.cs`, `GameController.cs`, `GameUI.cs`와 해당 검사 코드다. 씬·프리팹·패키지·프로젝트 설정·생성 이미지 원본은 이번 동작 확장 과정에서 변경하지 않았다. 신규 효과와 체공은 Unity 메시·선·상태 표현으로 제작했다.
