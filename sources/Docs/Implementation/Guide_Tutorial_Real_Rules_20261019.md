# 가이드 튜토리얼 개편 2차 — 전투는 실제 규칙, 장비 수업, 말투·연출 정리 (2026-10-19)

[English](Guide_Tutorial_Real_Rules_20261019.en.md). 앞선 개편([장판·화살 회피, 레벨업 폭죽, 보스와 회오리](Guide_Tutorial_Hazard_Yard_20261019.md))을 직접 해 본 뒤 나온 아홉 가지 지적과, "튜토리얼에서 하드코딩은 진행 순서·안내·사냥 칙령 설정뿐이어야 한다"는 원칙을 반영했다. 바뀐 규칙은 튜토리얼만이 아니라 게임 전체에 적용된다.

## 원칙: 전투는 튜토리얼에서도 실제 규칙

튜토리얼이 정하는 것은 **순서(어느 단계에서 무엇을 말하고 언제 끝나는가)**, **안내(대사·가림막·강조)**, **사냥 칙령 설정(시작값과 수업이 요구하는 값)** 뿐이다. 아래 보정은 모두 걷어냈다.

| 걷어낸 것 | 이유 |
| --- | --- |
| 장판 마법사·궁수 이동 속도 0, 시전 간격·장판 시간 고정 | 영웅이 피하기만 하는 문제는 규칙(아래 1번)으로 풀었다 |
| 수업 전에는 죽지 않는 적 체력 바닥(마법사·궁수·포위·보스 무리), 보스 체력 바닥 | 수업은 시간·사건 같은 진행 조건으로만 연다 |
| 갈고리 최대 거리 끌어오기·0.4초 후퇴, 후퇴하는 궁수, 전방 몬스터의 대형 이동 | 영웅과 적의 이동은 일반 AI가 정한다 |
| 회전 베기를 강제하는 연출용 스킬 선택, 가만히 서 있는 전방 전투 | 공격 선택은 사냥 칙령이 정한다 |
| 적이 영웅을 항상 알고 있게 하는 시야 갱신, 수업 뒤 장판·화살 지우기와 시전 앞당기기 | 일반 시야·시전 규칙을 따른다 |
| 보물 고블린의 전용 도주(5m, 보스 쪽으로 달림), 보스가 공격 없이 따라다니기·무적 | 일반 도주 AI와 일반 보스 AI를 쓴다 |

남긴 것: ① 영웅이 0이 되지 않게 하는 바닥(HP 1)은 튜토리얼 안전망으로 유지했다. ② 고블린이 도망쳐 사라지는 일은 막았다(진행이 멈추지 않게). ③ 적의 체력·공격력은 수업이 말하는 수치(장판 초당 7%, 화살 5%)에 맞춘 **스탯**이다. 규칙을 바꾸는 값이 아니다.

## 실제 규칙 변경 (게임 전체)

1. **피한 뒤 멈추지 않는다.** 회피한 영웅은 안전한 자리에 도착하면 끝까지 기다리지 않고 공격을 이어 간다. 공격 범위에 있는 적을 치고, 멀면 다가가되 **경고된 공격 안으로는 한 걸음도 들어가지 않는다**(가장자리를 따라 비켜 가고, 그래도 가까워지지 않으면 멈춘다). 도약·순간이동처럼 자리를 떠나는 스킬은 회피 중에 쓰지 않는다. 걸어서 피하는 동안에는 공격하지 않는다. (`CombatSimulation.cs` `MoveHero`/`KeepDodgeStepClear`, 대상 선택의 "사거리 안만" 제한 제거)
2. **마나가 모자라면 일반 공격으로 싸운다.** 회오리는 한 틱 값만 있어도 시작해 눈 깜짝할 새 끝나고 영웅이 시작·정지를 되풀이했다. 이제 **1초 동안 돌 수 있을 때(틱 비용 × 초당 틱 수)** 시작하고, 그때까지는 일반 공격을 한다. 돌다가 마나가 떨어지면 끊김이 아니라 **정상 종료**(`회오리 자원 소진`)다. (`WhirlwindStartCost`)
3. **시전한 공격은 끝까지.** 튜토리얼의 기본 칙령에 `dodge.interrupt=FINISH`(현재 공격 완료 후 회피)를 두어 휘두르는 도중에 회피로 끊기지 않는다. 스킬이 준비되었다는 이유로 진행 중인 스킬을 끊는 경로는 없다(보스의 끌어당김 같은 외부 제어만 예외).
4. **무리 중심.** 진단 결과 일반 규칙의 `무리 중심`은 적 무리 안(중심까지 0.6~1.9m, 주변 적 3~4)으로 들어가 싸운다. 이전의 "가장자리처럼 보이던" 문제는 적을 항상 알아채게 하던 보정과 고정 체력이 만든 현상이었다. 규칙은 바꾸지 않았다.
5. **고블린은 일반 도주, 보스는 계속 공격.** 고블린은 영웅에게서 가장 먼 방으로 도망친다(영웅 반대쪽이라 보스에게서도 멀어진다). 보스는 장면 내내 평소처럼 영웅을 쫓고 때린다.
6. **기본 공격 사거리 반올림.** 적이 사거리 2.0m에 정확히 멈추면 부동소수점 때문에 2.0000x가 되어 칙령은 "사거리 밖", 실제 타격은 "사거리 안"이 되던 불일치를 `BasicReachTolerance(0.0001)`로 맞췄다(훅으로 끌려온 적을 치지 못하던 원인).

## 장비 수업 (계획 문서의 구현)

단계는 번호 끝에 이어 붙였다: `HelmetTalk=46`, `RareTalk=47`, `MagicTalk=48`, `BossLoot=49`(`Last=49`). 앞의 체크포인트는 그대로 유효하다.

- **고정 보상**: 장비는 굴리지 않는다. `GuideTutorial.Gear`가 영웅 번호·종류로 항상 같은 아이템을 만든다. 보물 고블린은 **금화 5덩이(덩이마다 200~400 무작위) + 강화석 3덩이(3·3·4개) + 마법 등급 헬멧**, 보스는 **희귀 대검 + 마법 대검**을 남긴다. 점수: 시작 무기 100 → 헬멧 149.9 → 희귀 176.8 → 마법 149.8(희귀를 착용하면 마법 대검 카드는 음수). 검은 둘 다 양손 대검이라 새 검이 항상 기존 검을 대체해 차이가 표시된다(한 손 검이면 빈 손에 끼워 차이가 없다).
- **시작 설정**: 튜토리얼 시작 때 추천 규칙을 "착용 가능한 모든 장비", 타이머 없음으로 둔다. 다시 시작하면 이전 시도의 고정 장비를 가방에서 치운다.
- **헬멧(`HelmetTalk`)**: 줍기 중 헬멧 카드가 처음 뜨면 멈춘다 → 카드 아이콘 → 상세 창의 `장착`(돋보기도 같은 창) → 착용하면 남은 보상 줍기를 이어 간다.
- **보스 뒤(`BossLoot`)**: 보스가 쓰러져도 끝내지 않고 검 둘을 떨어뜨린다(희귀 검이 영웅 쪽). **희귀 검 카드(`RareTalk`)** → `장착` → 같은 칸이라 기다리던 **마법 검 카드(`MagicTalk`)**가 점수 −로 뜬다 → 카드 톱니바퀴 → `현재 착용중인 장비보다 점수가 높은 장비` → `저장` → 설명 → 카드의 ×로 닫기 → 졸업(`Cleared`).
- **저장·세션**: 카드 목록은 안내 런에서도 보인다. 추천 판정이 저장 복사본에서 일어나므로 안내 런의 실제 드롭에 판정을 옮겨 준다(`RiftGearRecommendations.Sync`). 장착·설정 저장이 계정 복사본을 갈아끼워도 시뮬레이션이 잡은 안내 런은 그대로 유지한다. 옛 저장에서 카드가 한 번도 뜨지 않으면 해당 수업은 건너뛴다.

## 남색 테두리

안내 튜토리얼은 대사가 나오는 단계마다 "시간이 멈춘" 느낌으로 화면 가장자리에 옅은 푸른 띠(위험 수업에서는 붉은 띠)를 깐다(`GameUI.GuideTutorial.cs`의 `cinematic.Vignette`). 칙령 시트가 열리면 세계가 위쪽 작은 창으로 줄고 그 밖은 검은 화면인데, 이 띠는 화면 전체에 깔려 창 밖을 남색(위험 수업은 암적색)으로 덮었다. 이것이 "설정하고 나면 생기는 남색 테두리"였다.

처음에는 세계 카메라가 칠하지 못한 영역이라고 보고 검은 보조 카메라를 깔았지만 효과가 없었다. 플레이어에서 카메라 목록과 화면을 덮는 UI를 덤프하고 세계 카메라 배경을 빨강으로 바꿔 보니, 카메라는 자기 영역만 칠했고 남색은 이 띠가 칠한 것이었다. 보조 카메라 변경은 되돌렸고, 세계가 시트 창으로 줄어든 동안(`SettingsWorldOpen`)에는 띠를 끈다. 시트를 닫으면 전체 화면에서 옛 모습대로 돌아온다. 스모크는 시트 수업 단계마다 띠가 꺼졌는지 확인한다.

## 검증

범위는 이번 변경이 닿는 영역만이다. 전체 Edit Mode는 돌리지 않았다.

- **전투·칙령 규칙 묶음**(1023건, 규칙 변경 직후): 1020건 통과, 3건 실패. 실패는 옛 규칙을 기대하던 테스트(`StationaryDodgeAttacksAnotherReachableEnemyAndDoesNotChaseTheOldTarget`, `ResourceFailureStopsBeforeTheUnfundedTick`, `AnAffordableEarlierAttackPreventsUnnecessaryRecoveryForALaterOne`)였고 새 규칙에 맞게 고쳤다. 이후 `Runtime/Core`는 바뀌지 않았다.
- **가이드·지역화·칙령 규칙 묶음**(382건, 최종 소스): 382건 통과. 위 세 테스트가 속한 `EdictWarriorAttackTests`·`EdictWarriorSupportTests`, `GuideTutorialTests`(보상·헬멧·희귀·마법 수업 포함 한 판 통과), `GuideGearTests`(고정 장비 점수 관계), `GuideHazardYardTests`, `LocalizationTests`·`StoredLocalizationTests`(새 문구 한국어·영어 양방향)가 들어 있다.
- **UI 계약**: `python3 tools/check_ui_contract.py --verify` 통과(15건).
- **macOS 개발 플레이어 스모크**(오프라인, 한국어 440×956과 영어 956×440): 오프닝 → 훅·회전 베기 수업 → 장판·화살 회피 수업 → 레벨업(`HP·MP 회복 / 스킬 포인트 +1`, 확인 버튼과 겹치지 않음) → 보스·회오리 → 우선순위·보물 고블린 추적 카드 끌기 안내 → 헬멧·희귀 검·마법 검 수업과 설정 저장 → 졸업 → 마을까지 두 언어 모두 진행했다. 시트가 열린 수업 단계마다 가장자리 띠가 꺼졌는지를 스모크가 확인하고, 시트 화면 바깥은 검정(0,0,0)이었다(수정 전 남색 29,42,68 / 위험 수업 암적색 80,19,15).
- **기존 실패(이번 변경과 무관)**: 스모크의 마지막 `CheckHudButtons("town")`이 "Pointer blocked at 사냥 칙령"으로 실패한다. `origin/main`에서도 같은 실패다.

검증하지 못한 것: 실기기(iPhone)·성능·공개 위키 게시. Mac 개발 플레이어와 Editor 근거다.

## 알아 둘 것

- 튜토리얼 전투에서 남긴 보정은 영웅 HP 1 바닥, 고블린이 도망쳐 사라지지 않게 막는 것, 적의 체력·공격 수치뿐이다. 보스가 체력 바닥 때문에 안 죽는 일은 없다.
- 6번 지적(무리 중심)은 규칙을 바꾸지 않았다. 진단상 실제 규칙은 이미 무리 안(중심까지 0.6~1.9m)에서 싸운다.
- 스크린샷 위치: `Builds/Validation/GuideRealRules/smoke-ko`, `smoke-en`(저장소에 포함하지 않는 로컬 증거).
