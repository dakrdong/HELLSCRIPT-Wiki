# HELLSCRIPT 성소·저주 상자 개발 기록

작성일: 2026-09-08 · 상태: 성소·저주 상자 구현과 아래 범위의 검증 완료. 전체 D2 또는 전체 게임의 완료를 뜻하지 않는다.

이후 전투 동작·투사체·덫·설정 보호 변경은 [전투 동작 개발 기록](Action_Expansion.md)을 따른다. 아래 실제 실행 결과는 성소 확장 당시의 소스에 대한 기록이며, 최신 전투 코드의 실행 검증과 구분한다.

이 기록은 [자동 생성 균열과 상자 핵심 개발](Rift_Expansion.md)의 후속 변경이다. 설계 기준은 [균열·탐험 상세안 9장](../Design/HELLSCRIPT_Rift_Exploration_Detail.md#9-짧은-이벤트성소와-보류할-확장)과 [장비 상세안](../Design/HELLSCRIPT_Itemization_Detail.md)이다. 수치는 승인된 제품 정책과 구분되는 기존 시험값을 유지했다.

## 구현한 동작

| 요소 | 플레이와 저장 규칙 |
|---|---|
| 길잡이의 성소 SH01 | 안전할 때 0.5전투 초 동안 사용한다. 20전투 초 동안 비전투 탐색·회수 이동이 15% 빨라진다. 장비·패시브의 이동 증가와 합산하며 전체 50% 상한을 적용한다. |
| 결의의 성소 SH02 | 같은 사용 규칙으로 20전투 초 동안 버프 피해 감소에 10%p를 더한다. 도약 방어 등 같은 구간과 합산하고 50% 상한을 적용한 뒤 방어도 감소와 구분한다. |
| 회복과 중단 | 성소 자체는 체력·자원을 채우거나 재사용 대기시간을 초기화하지 않는다. 피격·위험·거리 이탈은 사용을 취소하고 2전투 초 후 재시도한다. 이미 사용한 성소는 충전되지 않는다. |
| 생성 | 시작방과 보스 방을 제외하고 판당 50% 확률로 성소 0–1개를 배치한다. 등장한 성소의 두 종류는 같은 확률로 선택한다. 지도에 상자·성소 몸체와 두 곳 이상의 접근 위치를 함께 기록한다. |
| 저주 상자 CH03 | 5단계 이상에서 25% 확률로 일반 상자 하나를 대체한다. 게이지 70 이상, 참여 설정 켜짐, 전투 잔여 시간 90초 이상에서 시작한다. 참여 기본값은 꺼짐이고 잔여 시간 기준은 90–180초로 설정할 수 있다. |
| 잔향 진압 | 미리 확보한 후보에서 잔향 4마리를 한 번만 생성한다. 12전투 초 안에 모두 처치하면 성공하며, 그 뒤 상자를 1.5전투 초 동안 연다. 잔향은 별도 이벤트 ID와 보상 없음 태그를 갖고 기본 적 150점에 포함되지 않는다. |
| 실패와 종료 | 현장을 떠나도 이벤트 시간은 흐른다. 실패한 상자는 다시 시도할 수 없고 예약 보상이 다른 상자로 옮겨 가지 않는다. 보스 등장 후 새 이벤트는 시작하지 않으며, 보스 처치·시간 초과·중도 종료는 미완료 이벤트와 미사용 성소를 종료한다. |
| 보상 | 잔향은 경험치·게이지·골드·재료·장비를 주지 않는다. CH03은 판당 상자 장비 2개 중 두 번째 장비와 골드 가중치 2를 배정받는다. 상자 전체 골드·재료·장비 예산은 늘지 않는다. |
| 시간과 복원 | 사용 진행률·버프 잔여 시간·이벤트 잔여 시간·잔향 ID와 상태를 저장한다. 일시정지와 포탈 정리에서 전투 시간은 멈추며, 같은 판의 복원으로 성소 효과나 이벤트 시간을 새로 받지 않는다. |
| 개별 설정 | 성소 사용, 종류별 추적, 성소까지의 최대 이동 거리, 저주 상자 참여와 잔여 시간 기준을 행동 설정에 연결했다. 상자 개봉을 전체로 끄면 저주 상자도 시작하지 않는다. |

SH01의 비전투 판정은 인지한 살아 있는 적·유효 공격 대상이 없고, 마지막 공격·가한 피해·받은 피해 이후 3전투 초가 지난 상태다. LC01의 회수 이동 증가도 같은 판정을 사용한다. 성소 버프는 균열 종료 때 제거하고 마을·훈련·새 판으로 이월하지 않는다.

상자와 성소는 표현용 Unity 물리 충돌이 아니라 저장된 보행 장애물로 통행을 막는다. 영웅은 접근 위치로 돌아가서 사용한다. 적이 접근 위치를 차지하면 다른 사용 위치를 찾으며, 시작 위치를 충분히 확보하지 못한 저주 상자는 새 적이나 비용을 만들지 않고 재시도한다.

## 탐색 정보와 화면

- 한 번 감지한 적의 마지막 위치·발견 시각·확인 여부를 기록했다. 시야 밖으로 사라진 적을 쫓을 때 현재의 숨은 좌표를 계속 읽지 않고 마지막 발견 위치를 확인한다. 추적 기억의 유효 시간은 30전투 초다.
- 정예의 마지막 발견 위치는 미니맵에 마름모로 표시하며, 현재 감지하지 못하는 표식은 흐리게 표시한다. 사망했거나 마지막 위치를 확인한 적은 표식을 정리한다.
- 일반 전투에서 적은 감지 거리와 시야 안에 있을 때 모델을 표시한다. 바닥 드롭도 발견 상태를 따로 기록한다. 보스 안내는 기존 균열 목표 규칙을 유지한다.
- 성소는 기단·기둥·발광부로, 저주 상자는 붉은 봉인과 원형 표식으로 구별한다. 사용한 성소의 발광부는 꺼지고, 열린 상자는 뚜껑이 회전한다. 골격 애니메이션이 없는 임시 모델이다.
- 미니맵 아래에 성소 효과의 남은 시간과 잔향 처치 수·제한시간을 표시한다. 확대 지도에는 발견한 성소와 저주 이벤트 상태를 추가했다. 미개봉 상자의 장비 결과는 노출하지 않는다.

기존 장비·스킬·바닥 이미지를 유지했다. 이번에 추가한 성소·상자 움직임과 지도 표식은 자체 제작한 3D 부품과 Unity UI이며, 새 래스터 생성물이나 새 이미지 모델 사용 실적으로 집계하지 않는다. 이미지 원본과 검증된 모델 정보는 [자산 출처](Asset_Provenance.md)를 따른다.

## 저장 경계

지도 명세는 버전 2다. 이미 저장된 버전 1 균열은 같은 방·적·상자 명세로 이어서 진행하며, 성소·저주 상자·새 몸체 장애물을 중간에 추가하지 않는다. 미래 버전은 원본을 보존하고 읽기를 중단한다. 계정 저장 스키마는 기존 2를 유지한다.

성소 사용, 이벤트 시작, 성공·실패는 각각 고정 요청 ID로 계정·균열의 복사본을 검증한 후 파일을 확정한다. 저장이 실패하면 버프·적 생성·상자 성공을 확정하지 않고 진행을 멈춘다. 같은 요청으로 다시 확인하면 결과를 한 번만 적용한다. 시뮬레이션과 화면이 참조하는 균열의 루트 객체는 유지한다.

이것은 한 기기의 로컬 개발 저장 검증이다. 실제 서버의 세션 소유권·수령 영수증·시각 검증·다른 기기와의 충돌 해결을 구현한 것으로 표시하지 않는다. 실제 앱 미실행 구간의 정산은 중단된 균열과 별도로 처리되므로, 이벤트 보상 검사는 복귀 정산이 끝난 계정 값을 기준으로 비교한다.

전체 C# 30개 파일의 SHA-256은 `Artifacts/Validation/field-source-manifest.json`, 검사·실행 결과의 통합 요약은 `field-validation-summary.json`에 보존했다. 일반 균열·장비 회귀와 최종 필드 실행 사이에는 검사기의 미실행 보상 비교 기준만 수정했고 게임 판정 코드는 동일하다.

화면을 확인하려면 [성소와 저주 상자 설정](../../Artifacts/Validation/FieldScreens/03-field-policy.png), [잔향 진압 시작](../../Artifacts/Validation/FieldScreens/04-cursed-event.png), [개봉과 회수 완료](../../Artifacts/Validation/FieldScreens/07-cursed-chest-opened.png)를 연다. Unity에서는 `Assets/HELLSCRIPT/Scenes/Hellscript.unity`를 열고 Play를 누른다. 저주 상자는 5단계부터 등장할 수 있으며 행동 설정에서 참여를 켜야 시작한다.

## 남은 구현과 한계

1. 조건 22종과 주 행동 순서를 완성하면서 ‘전투 중에도 상자 개봉’과 공격·생존·획득의 우선순위를 연결한다. 현재 화면의 상자·성소 사용은 안전할 때 사용하는 흐름이다.
2. 좌·우 벽 추종의 출구 반복 횟수, 모든 목표 접근 실패 시 오류 전이, 전투와 탐색의 구조화된 판단 로그를 보완한다. 마지막 적 위치 저장만으로 전체 탐색 명세가 완료됐다고 보지 않는다.
3. 정예 6특성, 전체 스킬·패시브·전설·세트 효과를 정식 행동·타격 사건에 연결한다. 피해 감소 구간의 성소 효과를 추가한 것으로 전체 방어도·저항 명세를 완료했다고 표시하지 않는다.
4. 같은 투자량의 여섯 빌드, 시작 계정의 성장, 상자만 열고 중도 종료하는 정책의 시간당 수입을 비교한다. 검사에서 부여한 장비나 빈 방 상태를 자연 성장·파밍 밸런스의 근거로 쓰지 않는다.
5. 온라인·교차 저장·구매, 검증된 보석 데이터, Android 실기기·접근성·성능·음향은 [D3–D6 개발 순서](../Design/HELLSCRIPT_Development_Expansion_Plan.md#7-개발-순서와-완료-조건)에 따라 계속 진행한다.
