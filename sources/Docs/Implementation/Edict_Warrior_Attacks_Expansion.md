# 전사 회오리·도약·분쇄 사냥 칙령 연결

작성일: 2026-09-13 · [English](Edict_Warrior_Attacks_Expansion.en.md)

상태: **W01~W03의 13개 핵심 옵션 연결을 마쳤다. 전체 검사 1,847개와 macOS 실행·재시작 11회가 통과했다.**

## 개발 범위와 인수 기준

클로드의 능력치 57개·접사 54종은 통합 커밋 `92d5812`를 통해 메인에 유지된다. 이번 단계는 번개탄까지 연결한 `47294f4`에서 시작하며, 전사의 W01~W03 핵심 옵션 13개를 독립 판단에 연결한다. [스킬별 옵션 기획](../Design/HELLSCRIPT_Hunt_Edict_Skill_Option_Catalog.md)과 [화면 배치 상세안](../Design/HELLSCRIPT_Screen_Layout_Detail.md)을 따른다. W04~W06과 전사 기본 공격은 후속 연결 범위다.

예전 규칙의 누락·중복·사용 중지·숨은 조건이 새 핵심 옵션을 덮어쓰지 않는다. 실행 후보만 문서에서 만들고 저장된 예전 규칙은 변경하지 않는다. 사냥 칙령을 끄면 이전 규칙을 그대로 사용한다. 피해 계수·접사 가중치·재사용 대기시간은 조정하지 않았다.

## 회오리

- 시작 범위는 실제 자기 중심 2.5m다. 적 1명, 무리 2명 이상, 정예·보스 조건은 시작할 때만 검사한다. 무리에서 적 한 명이 죽었다는 이유로 회전을 취소하지 않는다.
- 시작 순간에는 자원을 쓰지 않고 0.25초마다 실제 틱 비용을 낸다. 기본 비용 6, SW 2세트·2초 이후 WP02·LC02 할인과 기존 50% 할인 상한을 유지한다. LC02는 첫 유료 틱에서만 소비한다.
- 3초 종료는 정상적인 12번째 공격 틱까지 실행한 뒤 전체 행동을 다시 판단한다. 자원·공격 대상 소실·설정 변경 등 먼저 발생한 종료 사유는 그대로 적용한다.
- 전역 위치, 대상 추적, 무리 외곽 선회, 제자리 중 선택한 이동을 사용한다. 외곽 선회는 적을 피해 범위 안에 두는 유효 경로를 찾고, 전역 위험·추적 한도를 지킨다. 제자리 회전과 아직 비용을 내지 않은 이동은 SW4 보행 충전을 만들지 않는다.
- 도약 충전 연계는 실제 SW4·W02·충전이 있을 때 현재 회오리의 채널 잠금만 제외해 도약 조건을 검사한다. 최소 거리·역할·쿨타임·착지 제한 등이 남으면 계속 회전한다. 통과하면 정상 종료하고 다시 판단하며, 도약이나 충전을 미리 예약하지 않는다.

## 도약과 착지 후 공격

공격 도약의 최소 거리는 **대상까지의 거리**다. 실제 이동은 2~8m이며, 유효 지면·시야와 전역 위험 기준을 검사한다. 대상 주변과 외곽은 우선 대상이 기본 2.5m 착지 공격에 포함되는 지점을, 밀집은 그 범위에 적을 가장 많이 넣는 지점을 찾는다. 생존 전용 역할은 일반 공격에 쓰지 않고, 전역에서 긴급용으로 보존한 도약도 공격 진입에 쓰지 않는다. 긴급 이탈은 공격 최소 거리를 적용하지 않는다.

도약은 비용 0·기본 쿨타임 8초이며, 준비 0.15초가 끝나 실제로 이륙할 때 SW4 충전을 예약한다. 유효하지 않은 이륙은 충전을 소비하지 않는다. 준비 또는 체공 중 설정을 바꾸거나 앱을 재시작해도 확정한 목적지와 착지 후 선호를 유지한다. 체공 중에는 다른 주 행동으로 바꾸지 않는다.

착지 후 선호는 다음 일반 공격 한 번에만 적용한다. W01 또는 W03을 사용할 수 없으면 다른 행동을 선택하고 기다리지 않는다. 더 먼저 실행할 전역 생존·회피·회수나 함성의 순서를 넘지 않는다. 후속 스킬의 사용 가능 여부는 도약 시작 조건이 아니다. 착지 직후 저장해도 선호가 남고, 다음 일반 공격을 선택하면 지운다.

W03은 낮은 HP 비율·현재 대상·특수 적 등 선택한 대상을 포함하는 전방 100도·3m를 판단한다. 많은 적을 넣는 방향을 탐색하며, 한 명만 포함할 수 없는 경우에는 고립 공격을 건너뛴다. 실제 SWB4 충전과 LC02 할인은 시전 시작 때 소비하고, 준비 중 취소 또는 빗나감에 환불하지 않는다. WP03·SW4 착지 효과와 실제 W02 적중 후 SWB4 충전은 기존 효과 경로를 사용한다.

## 저장과 화면에서 수정한 문제

새 착지 후 선호가 없는 저장을 Unity가 빈 객체로 복원하는 경우를 처리했다. 빈 상태 때문에 기존 저장을 거부하지 않으며, 지원하지 않는 미래 버전은 계속 거부한다. 회전 시간·다음 틱·이미 쓴 비용·실제 보행 거리와 충전은 복원 시 유지한다. 같은 설정을 다시 읽는 것과 실제 설정 변경도 구분한다.

실제 앱 검사에서 영어로 계산된 ‘이동 중’·‘동작 마무리’ 문구가 한국어 전환 후 남는 문제를 발견했다. HUD와 전투 상세는 저장된 표시 문자열 대신 현재 행동 단계로 문구를 다시 만든다. 준비·체공·회전·마무리 모두 양방향 언어 변경을 지원하며 언어 선택은 전투 상태를 바꾸지 않는다. 행동이 끝난 뒤에는 완료 안내로 갱신해 다음 판단 전에도 이전 언어가 남지 않는다. 영어 스킬명은 기존 `Leap Slam`·`Crushing Blow`와 맞췄다.

검사는 별도 Unity 프로젝트에서 실행했다. 최초 저장 복원 실패, 초기 버튼 선택 실패, 언어 표시 수정 전후의 자료를 따로 보존한다. 최종 소스에 대한 전체 검사는 `Full4`, 앱 제작은 `Build4`, 실제 실행은 `Native4`, 생성 균열은 `Before12`·`AfterRelease12`다. 마지막 문구 수정 전후의 12판도 전체 기록이 같음을 확인했다.

실제 앱의 검사는 조건을 통제한 훈련에서 시작한다. 전용 저장 폴더를 사용하고, 앱을 네 번 종료·재실행하여 다음 경계를 확인한다.

1. 유료 회전과 일부 보행 거리를 저장한 뒤 이어서 걸어 실제 SW4 충전을 만든다.
2. 도약 준비 중 저장해 이륙 전에는 충전을 쓰지 않았는지 확인한다.
3. 이륙 후 충전을 예약하고, 실제 설정 화면에서 선호를 바꾼 채 체공 상태를 저장한다.
4. 복원한 착지가 W02·SW4 피해와 WP03 방어를 한 번 발생시키는지 확인한 뒤, 남아 있는 선호를 저장한다.
5. 원래의 W03 선호를 복원해 다음 일반 공격으로 한 번 선택하고, 비용 25와 실제 적중을 확인한다.

SWB4의 실제 착지 적중→분쇄 충전→시전 소비와 빗나감은 Editor 검사에서 확인한다. 위 macOS 시나리오를 모든 전설·세트 조합의 실기기 검사로 확대하지 않는다. 첫 실행 실패는 검사 도구가 버튼 제목과 선택값을 함께 찾아 두 버튼에 일치한 문제였으며, 제목으로 선택하도록 수정했다. 초기 검사·화면 증거도 보존한다.

## 생성 균열의 전후 비교

두 추천 전사 빌드 × 두 시드 × 세 설정으로 버전당 12판, 총 24판을 비교한다. 레벨 30, 아이템 레벨 30 장비 8부위, 20단계의 같은 지도·초기 적·장비·능력치를 사용한다. 설정은 이전 규칙, 핵심 옵션 기본값, 충전 연계를 명시한 문서로 구분한다. 연계 문서는 회오리 빌드에서 W01 충전 종료·착지 후 W01을, 분쇄 빌드에서 실제 분쇄 충전 조건·착지 후 W03을 선택한다. 전역 생존은 기본값을 유지하며 새 권장 생존 설정을 임의로 넣지 않는다.

| 설정 | 변경 전 승리·사망·시간 초과 | 변경 후 승리·사망·시간 초과 | 관측 결과 |
|---|---|---|---|
| 이전 규칙 | 1·0·3 | 1·0·3 | 네 판의 전체 결과가 동일하다. |
| 핵심 옵션 기본값 | 2·0·2 | 2·1·1 | SW4 도약 예약은 0→4회, 실제 SWB4 충전은 6→29회다. |
| 명시적 충전 연계 | 2·2·0 | 2·2·0 | 회오리 정상 종료는 0→3회, SW4 예약은 0→5회다. |

표본마다 클리어 수는 같고, 기본값에서는 사망이 한 번 생겼다. 회오리 중단도 기본값 36→50회, 명시적 연계 36→59회로 늘었다. 기능 연결과 실행 차이를 확인한 결과이며 난이도 개선이나 직업 순위를 뜻하지 않는다. W04~W06·기본 공격의 후속 연결, 생존 대응과 공격 중단 원인, 실제 성장·파밍 효용 및 모바일 실기기 검증은 남아 있다.

증거는 [검증 요약](../../Artifacts/Validation/EdictWarriorAttacks/validation-summary.json), [전후 대조](../../Artifacts/Validation/EdictWarriorAttacks/comparison.json), [검증 소스](../../Artifacts/Validation/EdictWarriorAttacks/validated-source.json)에 보관한다. 실행본은 [macOS 앱](../../Builds/macOS-EdictWarriorAttacks/HELLSCRIPT.app)이다. 씬·프리팹·패키지와 별도 작업의 미커밋 변경 17개를 보존했다.
