# 공통 옵션창 캐주얼 적용

2026-10-15 · [English](Casual_Options_Window_20261015.en.md)

`codex/casual-options`는 최신 `origin/main` `af716fba66cfeb2cb210c5a549779eb68bc5efe2`에서 시작했다. 24장 시안과 검증한 Codex 인앱 브라우저의 Claude 캔버스를 확인했다. 기존 작업이 남은 기본 체크아웃은 수정하지 않았다. PR은 사용자 승인 전 병합하지 않는다.

공통 옵션창의 화면·소리·언어·캐릭터·계정과 게임 안내·전투 상태에 크림 판, 흰 카드, 노란 선택 탭, 슬라이더, 새 PNG 그림을 적용했다. 설정 적용·저장·재시도·계정 인증·캐릭터 변경의 기존 소유자는 유지한다. 칙령·추천 장비·상점 옵션과 톱니바퀴 진입 버튼은 이번 범위에 없다.

| 결정 | 적용 결과 |
|---|---|
| 1 · 구성과 글자 | 기존 글자 크기와 번들 Jua/Noto Sans KR을 유지했다. 탭은 한 줄, PC는 아이콘+글자, 세로는 위/아래, 짧은 가로는 글자만 표시한다. 닫기와 탭은 최소 44 화면 픽셀이다. 카드 높이·스크롤량은 시안의 작은 글자 치수와 다르다. |

| 3 · 판 | 안전 영역의 기존 오른쪽 절반/세로 전체 소유권 안에서 8–12px 띄웠다. 키보드, 읽던 위치와 핸들 갱신을 유지한다. 세로 상단 젬과 제목 간격 및 회전 후 비율 버튼 높이를 보완했다. |

| 6 · 스크롤바 | 추가하지 않았다. |

`CasualSettingsStyle`과 설정 전용 배치 부품을 각 본문이 공유한다. 누락된 색만 `UiTheme.Settings*` 토큰에 정의해 `UiSkin.Casual`로 참조한다. 전역 테마 전환은 없다. 영웅 인장과 +/− 그림, 패널 9-slice는 기존 공통 자원을 재사용한다. UI는 열 때 만들고 기존 갱신 경로로 값·선택 상태를 반영한다.

계정 UID와 수집 대기 숫자, 전투 상태 배지는 배경 뒤로 글자가 가려지지 않도록 공통 pill 안에 배치했다. 긴 UID는 복사 버튼과 겹치기 전에 줄을 나눈다. 현재 영웅은 균열에서도 선택 색을 유지하고 다른 영웅만 회색 잠금으로 표시한다. 튜토리얼은 캐릭터 탭 없이 4개 탭이며 계정 맨 위에 타이틀 이동을 둔다.

그림 원본은 [generated](../Design/Options/Casual/assets/generated/), 요청과 출처는 [image-generation.json](../Design/Options/Casual/assets/image-generation.json), 게임용 파생본의 크기·알파·해시는 [sprite-manifest.json](../Design/Options/Casual/assets/sprite-manifest.json)에 있다. [전체 그림](CasualOptionsEvidence/art-contact.jpg) · [최종 지도 3종](CasualOptionsEvidence/map-options-v2.jpg). 기본 제공 이미지 생성 도구가 모델 선택/응답 버전을 노출하지 않으므로 **실제 모델은 unknown**이다. `gpt-image-2` 사용을 검증했다고 주장하지 않는다.

아이콘은 원본 PNG의 네이티브 알파와 완전 투명 픽셀을 검사한 뒤 128×128로 축소했다. 지도는 256×164다. 배경 제거·크로마키·SVG 변환을 사용하지 않았다. 결과 28개 PNG는 1,029,406바이트이고 RGBA 환산은 2,142,208바이트다. 지정한 4×4 블록 압축을 모두 사용했을 때의 예상 텍스처 합은 535,552바이트이며 GPU 실측값은 아니다. 성능 개선은 측정하지 않았다.

통합 담당은 개발 빌드의 기존 `-hellscriptScreenSettingsSmoke`와 새 `-hellscriptCasualOptionsSmoke`를 함께 사용해 110장 네이티브 옵션 검증을 실행할 수 있다. 반드시 독립 `-hellscriptSavePath <dir>`와 `-hellscriptScreenshots <dir>`를 지정한다. 이 모드는 전체 빌드 횟수를 늘리지 않고 통합 담당의 동일 바이너리를 재사용한다.

작업 산출물은 `Builds/Validation/CasualOptions/`와 그 안의 `artifact-lifecycle.json`에 경로·소유자·측정 크기·재생성 방법·보존 사유를 기록한다. 원본 아트와 검수 증거는 PR에 보존한다. 이 작업의 import Library, 로그와 실패한 초기 캡처는 PR 검토까지 보존하고 2026-10-22 또는 병합 때 먼저 재검토한다. 테스트용 네이티브 바이너리는 만들지 않았다. 영구 삭제는 하지 않았고 다른 작업의 산출물은 건드리지 않았다. Unity Editor는 경로와 무변경 상태를 확인하고 정상 종료한 뒤 통합 담당에게 양도한다.

공개 위키 생성·검사·게시는 작업 브랜치에서 실행하지 않았다. 병합 승인 뒤 위키 입력 영향과 최종 검증을 통합 담당이 처리한다. 처리/대기/재시도 세부 시간은 분리 계측하지 않았으며, 산출물 manifest에 전체 경과 시간과 실제 검사 횟수를 남긴다.
