- 15레벨 퍼즐 튜토리얼, 정비 단계 두 개, 졸업·다시보기·보상 저장과 전사 생존 조정을 포함한다. 자세한 구성과 기존 검증 범위는 [튜토리얼 최종 검증](Puzzle_Tutorial_Final_Acceptance.md)을 따른다.
- 옛 v2 생존 안내의 물약 숫자 입력 수정과 관련 검사를 반영했다. 기존 계정의 물약 프리셋과 신규 계정의 직접 설정을 구분하고, 폐기된 장비 옵션을 단계 공개 설명 검사에서 제외했다. 이후 구현에 이미 포함된 포인터 안정화와 현재 퍼즐 검사는 유지했다.
- 폐기된 v3 검사 파일을 되살리지 않았다. 당시 조사 문서와 근거는 역사 기록으로 합쳤으며, 삭제된 파일의 링크는 해당 커밋 원본을 가리킨다.
- 초기 HTML 시안의 그림·생성 기록·검증 자료를 보존하고, 시안의 현재 15레벨·성장 곡선·검사 코드를 유지했다. 위키 이력 충돌은 본문 해시로 중복을 제외해 합쳤다.
- N13·N02·N12·BOSS03의 준비된 모델 원본과 meta, 가져오기 도구, 공통 WorldView 연결을 포함했다. 미커밋 원본 241개와 수정 패치는 커밋 전에 별도로 보존하고 해시를 확인했다.

- 전체 Edit Mode: 5,614개 통과, 실패 0개, 별도 측정 도구 2개 Explicit 제외.
- macOS 개발 플레이어: 전사 KO 세로·마법사 EN 가로에서 30레벨 승리, L7 재실행 복원 2건, 졸업 2건과 다시보기 2건. 허브의 5개 화면 비율·KO/EN·안전 영역도 확인했다.
- 간편 프리셋·물약·단계별 설정 화면: 5개 화면 비율과 KO/EN, 실제 포인터·저장·재실행 검사 통과. 첫 실행에서 발견한 기존/신규 계정 검사 조건을 수정하고 해당 화면 검사만 재실행했다. 생산 게임 로직은 바뀌지 않아 전체 검사와 튜토리얼 결과를 재사용했다.
- 공통 UI 계약 15개 검사와 UI 갱신 정적 검사 통과.

플레이어 입력은 합성 EventSystem 포인터이며 전투는 실제 고정 틱을 가속했다. 일반 균열은 보통 속도로 5초 진입·복귀만 확인했다. 모바일 실기기·사용자 이해도·일반 속도 전체 균열 완주·성능 개선을 검증한 결과는 아니다.

병합한 v3 문서의 과거 이력이 삭제된 소스를 참조하여 위키 생성이 한 차례 중단됐다. 당시 커밋의 원본을 문서 첨부로 보존하고 과거 링크를 그 파일로 연결했다. 과거 본문·날짜·해시는 변경하지 않았으며, 소스 해시와 다른 누락 링크의 오류 처리를 회귀 검사한다.

모델 4종의 실제 WorldView 생성·LOD·공유 뼈대·걷기·공격과 기본 카메라 표시를 Unity Editor에서 확인했다. BOSS03은 기존 50% 최소 카메라 거리에서 일부가 화면 밖으로 나간다. 기본 거리는 통과했고 모델 크기나 카메라 규칙을 바꾸지 않았다. 이 검사는 통제된 표시 검사이며, 전체 플레이·성능·모바일 실기기 검증과 구분한다.
