# 퍼즐 튜토리얼 L2·L5·L7 시뮬 프로토타입

작성일: 2026-10-07 · [English](Puzzle_Level_Prototypes.en.md)

**3단계 게이트 통과: 79통과·0실패·0건너뜀.** 승인된 전사 L2 외곽 이동 추가 정답과 공통 후퇴 회복 정책을 적용했다. 이후 4~9단계로 진행한다. 이 PR은 테스트 전용 프로토타입과 공통 물약 정책을 다루며, 15레벨 러너·허브·XP·졸업은 후속 단계다. PR 병합과 공개 위키 배포는 하지 않는다.

## 실제 파이프라인과 확정 수치

새 GameStore의 실제 영웅·시작 무기(공격20)를 보존하고, HuntEdictEditSession → 실제 스킬 학습·장착 → CommitHuntEdict → CombatSimulation.Tick(0.05)를 사용한다. 시드77123, L2=Lv2/L5=Lv4/L7=Lv5, 회피 확률0이다. 정답은 적 전원 실제 처치·HP10% 이상·90초 이내, 오답은 적이 남은 실제 사망이다. 강제 패배·인위적 회복·PitRooted·PitUnbeaten을 사용하지 않는다.

- L2: N02×5 HP65/공격3/속도3.6, N14 HP550/공격 최대HP×1.3/속도2.7/첫CD2/예고1.8초. 전사는 외곽 이동도 정답이며 궁수·마법사에서는 사망한다. 전사 회피 선택에는 균형 생존을 병행한다.
- L5: N07×4 HP234/215/500(전사/궁수/마법사), 공격 최대HP×0.43/0.326/0.326, 속도2.2, 첫CD2, 이후CD1.5, 예고0.2초. 실제 물리 경감 후 단일 피해 약25%다. 물약60%를 유지한 채 생존 우선45/75가 승리하며 균형30/55·위급20/40은 사망한다. 실제 신규 계정 성향 필터를 적용한 공격적 설정 이월도 포함한다.
- L7: 영웅(-7,-7), N10+E07(7,7), HP900/1750/1750, 공격50/속도2.3. N01×4 HP70/공격3/속도2.7을 0/12초에 투입한다. 첫4초·주기10초·지연5초·끌림8m/s·반경2.5를 유지한다. 지정한 이동기는 기존 reserveSkill=ON으로 긴급 이탈용 보존한다. 미지정 상태에는 유효한 보존 대상이 없다. 거리 유지·외곽 포위 대응과 사방 포위 배치에서도 정답을 검증했다. 성공한 모든 L7 조합은 E07 세 번 이상·E07 피해0이다.

## 공통 후퇴 회복 정책

같은 영웅·실행의 활성 후퇴 기억이 있고 복귀HP에 못 미치면 물약 기준을 max(물약HP, 복귀HP)로 계산한다. AssessEdictSurvival의 기준을 ExecuteEdictSurvival의 실제 TryUsePotion에 전달한다. On/Off·실제 재고·쿨다운·회복량은 기존 소유자를 따른다. 비활성·다른 영웅·다른 실행·물약끔·남은CD에는 추가 회복이 없다. 일반 전투에도 적용되며 KO/EN 도움말을 갱신했다.

## 검증과 재사용

`stage3-owned-kit-matrix.xml`의 L2 42개·L5 21개는 통과했다. 그 실행의 L7 보조 설정3실패를 수정한 뒤 `stage3-l7-reserved-kit.xml`의 L7 16개를 모두 통과했다. 변경되지 않은 L2/L5를 재실행하지 않고 합쳤다. [최종 게이트 JSON](../../Artifacts/PuzzleTutorial/20261006/stage3-gate-validation.json)은 각 행의 XML·실제 저장 경로·설정·상태해시를 제공한다.

`stage3-approved-policy.xml` 중 EdictResponse62·GravityCollapse19·IncomingForecast88·Potion19 = 188개는 모두 통과했으며 변경이 없어 재사용했다. 이는 당시 전체258개 중248통과/10실패였고, 10실패는 이후 수정된 L5였다. 전체 EditMode·런타임 스모크·플레이어·브라우저·모바일 실기기는 이번 단계에서 실행하지 않았다. 최종 통합 상태에서 필요한 검사를 한 번 수행한다.

처음의 after-aggressive 검사는 전체 레시피로 물약40%를 덮어썼다. 이를 실제 신규 계정 창과 같다고 설명한 기록을 정정한다. 신규 계정의 CombatStyleScope는 이전 물약60%를 유지하며 아래 최신 행렬은 실제 필터를 사용한다. 최초70개 실패 표·XML·상태와 [추가 튜닝 기록](../../Artifacts/PuzzleTutorial/20261006/stage3-recovery-progress.json)은 역사적 근거로 보존한다.
