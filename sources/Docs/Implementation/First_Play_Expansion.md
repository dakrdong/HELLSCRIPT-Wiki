# 첫 플레이 안내 개발 기록

작성일: 2026-09-09 · D4 첫 이용 흐름 구현·macOS 실행 검증 완료 · 신규 사용자 관찰은 남음

## 구현

[첫 플레이 상세안](../Design/HELLSCRIPT_First_Play_Detail.md)에 따라 성소·게임 안내·결과에서 아홉 단계의 안내를 열 수 있게 했다. 공통 자동 전투 설명은 계정에, 직업의 성장·전투·비교·수정·훈련 기록은 영웅에 저장한다. 숨기기와 다시 표시는 기록이나 서비스 자격을 바꾸지 않는다. 구형 저장은 진행 단계를 추정하지 않고 빈 안내 상태로 정규화한다.

`FirstPlayGuide`는 기존 `AccountSave`·`HeroSave`의 안내 기록만 갱신한다. 균열 진입·실제 설정 적용은 `GameController`, 화면 열람은 기존 `GameUI`가 호출한다. 전투 틱·아이템 생성·보상 정산에는 튜토리얼 전용 보정이 없다.

첫 실제 스킬 사용을 관찰하면 판단 기록으로 가는 방법을 한 번 알린다. 판단 화면에서는 현재도 같은 ID의 규칙이 남아 있을 때 편집기로 이동한다. 안내·판단·편집 사이를 이동할 때 이전 일시정지 상태를 전달한다.

편집안은 실제 적용 전후의 전투 행동 차이를 보여 준다. 이름·버전·규칙 ID·장비 참조·반복 설정만 바꾼 경우는 조건 수정으로 기록하지 않는다. 새로운 실제 수정안을 적용하면 아직 진행 중인 안내의 훈련·재도전 단계는 그 수정안을 기준으로 다시 확인한다. 아홉 단계를 모두 수행한 뒤에는 과거 완료 기록을 다시 쓰지 않는다.

소유 장비의 비교 화면과 후보가 없을 때 읽는 설명을 구분한다. 훈련은 소유 캐릭터 복사본의 종료 결과와 실제 수정 설정이 일치해야 하며, 개발용 훈련·즉시 귀환·다른 설정을 사용한 훈련은 제외한다. 재도전은 해당 훈련 뒤 새 실제 균열에 같은 설정으로 입장했을 때만 기록한다.

결과에서 다른 화면을 읽는 동안에는 자동 반복 대기시간이 멈춘다. 결과 화면에 자동 반복 중지 버튼도 추가했다. 안내로 이동하면서 진행 중인 균열을 포기하거나 반복 설정을 자동으로 바꾸지 않는다.

최종 앱 시험의 마법사는 Lv.1 기본 장비로 시작해 실제 생성 균열에서 64마리를 처치하고 장비 3개를 획득했다. 215.9전투초에 사망했으며 Lv.4·XP 165의 획득 진행을 유지했다. 이 장비를 비교만 하고 장착하지 않은 채, 직접 적용한 거리 설정으로 60초 훈련을 완료했다. 레벨·HP·드롭을 주입해 안내를 끝낸 시험이 아니며, 해당 실패 결과나 한 시드를 성장 밸런스 통과로 해석하지 않는다.

결과 화면에서 안내를 6실시간초 동안 읽어도 자동 반복이 다음 판을 시작하지 않았고, 명시적 중지 버튼으로 반복 설정을 저장했다. 재시작에서는 안내 기록·선택 영웅 전체·균열 ID·전투 시간·RNG·HP·자원이 체크포인트와 같은지 확인했다. 자동 UI 콜백을 사용한 흐름은 148.3초였으며 물리 입력·사용자의 이해도를 측정한 시간이 아니다.

검사 당시 코드 84개와 빌드 해시, 마지막 UI 변경 2개는 [`현재 소스 기록`](../../Artifacts/Validation/onboarding-current-source-manifest.json)에 남겼다. 씬·패키지·설정 등 보호 대상 98개는 변하지 않았고, 최종 정적 검사에서 소스 메타 누락·중복 GUID·문서의 끊어진 로컬 링크가 없음을 확인했다. 새 패키지·씬·프리팹·이미지를 추가하지 않았다.

### 실행 중단과 회복 기록

첫 실행에서는 앱의 파일 삭제 처리와 독립적인 프로젝트 파일 읽기가 운영체제 호출에서 함께 멈췄다. 수동 잠금 해제 후에도 회복되지 않아 해당 테스트 앱만 종료 코드 143으로 중단했고, 성공 증거로 사용하지 않았다. Mac 재시동 후 파일 접근이 회복되어 기존 코드·검사·빌드 해시를 대조하고 새 격리 계정으로 다시 실행했다. 원인은 확정하지 않았으며 보안 설정을 변경하지 않았다. 이전 로그·화면과 [`회복 기록`](../../Artifacts/Validation/onboarding-recovery-record.json)을 보존했다.

### 남은 범위

실제 신규 사용자의 설명 없는 첫 15분 관찰과 이해도 검사는 별도다. 이후 추가한 A/B의 동일 조건·변경 표시·전체 누적 집계·저장은 [훈련 비교 개발 기록](Training_Comparison_Expansion.md)을 따른다. 이 문서의 542개 검사와 이후 A/B 검사를 구분한다. 장비 교체 훈련, 사냥 칙령 저장·공유, 전체 장비 비교 개선, 마을·경제·서비스·Android 기기 품질은 [남은 작업표](../Design/HELLSCRIPT_Remaining_Development_Backlog.md)를 유지한다.
