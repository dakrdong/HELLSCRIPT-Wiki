# 서리 폭발 사냥 칙령 개발 기록

작성일: 2026-09-13 · [English](Edict_Nova_Expansion.en.md)

상태: **M06의 네 핵심 옵션, 실제 범위와 보행 접근, 빙결·제압·연쇄 충전을 연결했다. 전체 검사 1,705개, macOS 앱의 세 프로세스 검사와 전후 48판 진단을 완료했다.**

## 클로드 통합과 이번 개발의 범위

클로드의 능력치·접사·밸런스 작업 `b1f3ea5`는 병합 커밋 `92d5812`를 통해 메인에 포함되어 있다. 이번 단계는 이후 보호막 개발까지 반영한 `76cf5b0`에서 이어 간다. 원격 갱신 후 클로드 커밋이 `origin/main`의 조상임을 다시 확인했다. 능력치 57개·접사 54종과 기존 저장 구조를 유지하며 피해 수치나 접사 가중치를 조정하지 않았다.

이전에는 서리 폭발을 쓰려면 옛 자동 행동 규칙도 사용 조건을 충족해야 했다. 이제 칙령을 켠 마법사가 M06을 장착하면 새 옵션에서 독립 후보를 하나 만든다. 옛 규칙이 없거나 꺼져 있거나 조건을 충족하지 않아도 새 옵션을 따르고, 중복 규칙으로 시전을 늘리지 않는다. 칙령을 끄면 저장된 이전 규칙을 다시 사용한다. 이 단계로 마법사 액티브 M01~M06의 핵심 판단을 연결했으며, 기본 공격과 다른 직업의 남은 판단까지 완료한 것은 아니다.

## 전투에 연결한 네 옵션

| 옵션 | 실제 처리 |
|---|---|
| 자동 사용 | ON이면 후보를 검토하고 OFF이면 제외한다. 이미 시작한 준비 동작은 이후 옵션 변경이나 저장 복원으로 다시 지불하거나 중복 실행하지 않는다. |
| 사용 목적 | CONTROL은 새 제어가 가능한 범위 대상과 전역 긴급 생존·회피 요청을 요구하거나, 준비가 끝나기 전에 실제로 끊을 수 있는 위험 시전을 찾는다. GROUP은 실제 자기 범위의 대상 2명 이상을 요구한다. CHAIN_CHARGE는 실제 SMB 4세트, 장착·해금·자동 사용 중인 M03, 연쇄 강화 0회 또는 수명 1초 이하와 원 피해 대상 1명 이상을 요구한다. |
| 시전 위치 | HERE는 현재 자기 중심 3m만 검사한다. APPROACH는 현재 감지한 교전의 적에게 유효하고 안전한 위치가 있을 때 먼저 걷고, 실제 범위에 들어간 다음 시전을 시작한다. |
| 보스에게 사용 | PURPOSE는 보스도 목적에 맞게 센다. STAGGER_ONLY는 이미 제압·면역 중인 보스를 판단에서 제외한다. HOLD_ALONE은 범위에 보스만 있으면 보류하고, 일반 적이 함께 있으면 목적을 다시 검사한다. |

위기 제어는 준비 0.35초 뒤에도 기존 빙결·기절이 남는 적을 새 제어 대상으로 세지 않는다. 위험 시전은 적의 남은 준비 시간, 실제 공격 예고 범위와 제어 가능 여부를 함께 읽는다. 치유 시전과 보스 소환도 실제로 끊을 수 있는 경우에 평가한다. 보스는 제압·면역 중이 아니고 이번 제어 기여 15로 게이지 100에 도달해야 새로 행동을 멈출 수 있다고 판단한다. 보스에게 일반 빙결을 부여하지 않는다.

연쇄 충전 준비는 M03의 쿨타임이나 자원 회복을 기다리지 않는다. M03을 빼거나 끄거나 아직 해금하지 않았다면 현재 동작만 CONTROL로 전환하고 저장된 CHAIN_CHARGE 선택은 보존한다. 실제 SMB 4세트가 없으면 장착 조건 부족으로 차단한다.

전역에서 M06을 방어기로 직접 선택해도 사용 목적과 보스 제한을 지킨다. 직접 방어는 현재 위치에서 새로 제어할 수 있는 대상도 요구하며, 위급한 상황에 접근부터 시작하지 않는다. M05에 정의된 중첩·교전 제한 예외를 M06으로 확대하지 않았다. 일반 GROUP·CHAIN_CHARGE는 진행 중 공격을 취소할 수 없고, CONTROL의 전환은 전역 FINISH·CANCEL_ALLOWED와 현재 행동 구간을 따른다.

## 실제 자기 범위와 접근 한도

판단 대상은 감지·시야·추적 제외 조건을 통과한 현재 적에서 구한다. 전역 우선 대상이 3m 밖에 있어도 주변의 다른 적이 목적을 충족하면 시전할 수 있다. 후보 판단에서 적용한 보스 필터는 실제 폭발의 피해 범위를 바꾸지 않는다. 실행 시점에 반경 안에 있는 적에게 원래 피해와 제어 처리를 각각 적용한다.

APPROACH는 적 근처와 가까운 두 적 사이의 위치를 검토하고, 지형 통행·몸체 간격·경로상의 전역 위험·추적 거리와 시간을 확인한다. 걷는 동안 다시 판단하므로 OFF 변경, 위험 발생이나 접근 조건 상실에 대응한다. 이동만으로 자원이나 쿨타임을 쓰지 않으며 반경을 늘리거나 순간이동하지 않는다.

추가 교전 금지는 최근 관찰 기록에 남아 있지만 현재 교전에 포함되지 않은 적 무리에 새로 접근하는 경로를 제한한다. 보이지 않는 적의 현재 좌표는 읽지 않으므로, 아직 발견하지 못한 적까지 완전히 피한다고 보장하지 않는다. 경로의 위험 검사는 현재 전역 회피 설정을 따른다.

M06 추적 한도를 소진한 대상은 다시 허용할 때 반경 3m를 사용하도록 선택적 `excludedReaches` 기록을 남긴다. 마법사 기본 공격 사거리 10m 안이라는 이유만으로 곧바로 추적을 재개하는 반복을 막는다. 기존 대상·위치·추적 시간과 이 제외 기록은 저장 복원 후에도 이어진다. 기록이 없는 이전 저장은 기존 공격 사거리 기준을 유지한다.

## 실제 장착 효과와 저장 복원

해금 레벨 **20**, 준비 **0.35초**, 기본 비용 **20**, 쿨타임 **10초**, 냉기 피해 계수 **1.0**, 자기 중심 반경 **3m**와 일반 적 빙결 **1.5초**를 유지한다. 실제 비용 할인은 준비 시작에 한 번 소비한다. 준비 중 대상을 모두 잃으면 비용과 쿨타임을 돌려주지 않고 실제 불발 사건을 남긴다.

실제로 SMB 4세트를 장착한 상태에서 원 피해가 적중하면 연쇄 강화 2회와 수명 6초를 만든다. 각각의 M03이 준비를 시작할 때 한 번씩 예약하고 연결 횟수 2를 추가한다. MP06은 실제 냉기 적중 뒤 번개 적중이 있어야 4초 강화가 발생한다. LC02의 유효한 할인 충전은 실제 유료 시전 한 번에만 쓰이며, 저장 복원으로 다시 사용하지 않는다. 서리 폭발 후 순간이동이나 연쇄 번개를 강제로 예약하지 않는다.

macOS 검사에서는 실제 생성·장착한 SMB 4부위와 LC02, MP06을 사용한다. 자원 100에서 유효한 LC02로 M06 비용 10을 지불하고, 준비 중 M06의 목적·위치·보스·자동 사용과 M03 자동 사용을 실제 UI로 바꾼 뒤 저장한다. 다음 프로세스에서 원래 준비를 한 번 마치고 실제 냉기 피해·빙결·충전 2회를 확인한다. 이후 보통 판단으로 선택한 M03이 SMB 2세트 비용 21.25와 충전 1회를 예약한다. 다시 재시작한 뒤 실제 번개 피해와 MP06 발동을 확인하고, 별도 접근 구간에서는 걷는 동안 비용 0, 실제 시전 시 비용 20을 검사한다.

## 고정한 설정에서의 전후 진단

직전 M05 단계의 최종 24판을 이전 자료로 재사용하고 M06 구현 후 같은 24판을 실행한다. 보관한 소스 목록과 `76cf5b0`의 C#·영어 문구·패키지 입력 253개가 일치함을 검사했다. 비교 조건과 원래 결과를 보존하므로 이전 버전을 다시 구성한 것으로 가장하지 않는다.

양쪽에서 기존 규칙, 새 기본값 칙령, 생존 설정 칙령을 각각 8판씩 사용한다. 시드 인덱스 0·1·2·3·4·5·9·14는 앞선 결과에서 선택한 표본이며, 레벨 30 연쇄 제어·20단계·합법적인 8부위 장비를 고정한다. 지도·적·목표·장비 전체 값·능력치 시트·최대 HP·기본 피해와 전체 칙령 원문이 전후 쌍에서 같다. M03 시전·발사·적중·중단과 50ms 단위 관측 시간을 실제 집계와 대조한다.

기본 문서는 전역 긴급 생존·회피가 꺼져 있다. 진단 전용 생존 문서는 HP 30%·치명적 위험·복귀 HP 50%, 방어 M05·회피 M04·방어→회피→보행, OTHER_SKILL 대체 M05, 바닥·범위·직접 공격 DAMAGE 15%와 CANCEL_ALLOWED를 사용한다. 16개 명시 설정 중 기본값과 실제로 다른 값은 13개다. WALK_FIRST·HP 40% 물약·보존 OFF와 나머지 옵션은 유지한다. 두 칙령 문서의 M06은 기본 CONTROL·HERE·PURPOSE이고, 결과에 맞추어 목적이나 순서를 바꾸지 않았다. 기존 규칙 모드는 칙령을 사용하지 않는다.

이 표는 최종 소스의 `AfterFinal24` 완료 자료에서 산출했으며 첫 변경 후 24판의 전체 결과 요약도 재현했다. 기본 칙령은 사망 수가 같아도 보스 도달과 연쇄 적중이 줄었다. 기본값에서도 끊을 수 있는 위험 시전은 CONTROL의 별도 사용 사유이므로, 전역 생존이 꺼졌다는 이유만으로 M06 사용이 0회가 되지는 않는다.

생존 설정 문서의 M03 중단 68회 중 52회는 실제 `edict:M06`으로 전환한 사건이다. 나머지는 전역 M05 전환 7회, 전역 보행 6회, 끌어당김 1회와 시간 초과 2회다. 전후 모두 사망은 없었지만 전부 시간 초과했고 보스 등장 판은 5개에서 3개로 줄었다. 이 결과를 성능 개선이나 최적 프리셋으로 제시하지 않는다. 실제 제어를 위해 공격 준비를 취소한 비용과 보스 도달 과정의 관계를 다음 진단에서 구분한다.

보스 등장 전 평균 시간에는 보스를 만나기 전에 사망·시간 초과한 판도 포함된다. 따라서 기본값에서 시간이 짧아진 것을 이동 개선으로 해석하지 않는다. 직전 전역 판단은 관측 문맥이며 이후 중단 원인은 실제 행동 사건을 우선한다. 접근 옵션은 이 표본에서 HERE로 고정되어 있으므로 APPROACH의 밸런스를 검증한 표가 아니다.

## 검사와 실행 증거

M06 관련 검사 51개를 추가했다. 독립 후보·범위·목적·보스 정책·중단 허용·추적·관찰 기록·실제 장착 효과·유료 준비 복원과 읽기 전용 판단의 비간섭을 확인한다. 기존 M03 연계 검사는 M03 자동 사용을 끈 상태에서도 유효하게 시전할 수 있도록 M06 GROUP을 명시했다.

집중 검사 280개와 첫 전체 검사 1,703개가 통과했다. 첫 집중 검사에서 MP06을 실제 번개 발사보다 먼저 검사한 조건을 수정했다. 첫 앱 재시작 검사에는 정상 이어하기 호출이 빠져 있어 검사 코드를 보완했다. 두 번째 앱 검사는 전투 도중 영어로 바꾸면 이전 언어로 조합된 행동 문구가 남는 제품 문제를 드러냈다. HUD에서 저장된 행동 문구를 현재 언어로 읽도록 고치고, 원래 저장 내용을 유지하는 번역 검사 2개를 추가했다. 실패 자료는 삭제하지 않는다.

최종 전체 Edit Mode 검사 **1,705개**는 2026-09-12 18:34:31~18:39:19 UTC에 약 **288.47초** 동안 실행됐고 실패·건너뜀 없이 모두 통과했다. 최종 macOS 빌드가 성공했고, `Native3`의 세 프로세스도 18:38:29~18:38:55 UTC에 모두 성공했다.
