# 신규 적과 이동형 보스 공격의 소리

작성일: 2026-09-28 · [English](New_Content_Sounds.en.md)

신규 일반 적 8종(N13–N20)과 보스의 새 이동 공격 일부가 소리 없이 공격하던 문제를 고쳤다. 녹음이 있는 소리 중 가장 가까운 것을 빌려 쓴다. 새 소리를 만들거나 외부 서비스로 생성하지는 않았고, 게임 규칙과 수치는 바꾸지 않았다. [다크 고딕 개편](Dark_Gothic_Overhaul_Stage1.md) 2단계에서 따로 떼어 낸 항목이다.

## 원인

적의 공격 준비·공격·사망 소리는 적 번호(N01–N12)별로 녹음되어 있고, 보스 공격은 공격 종류별 신호(휘두르기·내려찍기·갈고리·소환·광선·돌진·폭발)에 묶여 있다. N13–N20은 자기 녹음이 없어 해당 소리를 찾지 못했다. 보스의 새 공격 중 거두기 베기, 사슬 회오리, 아가리 물기, 꼬리 채찍은 신호 목록에 없어 기본 공격 소리로 떨어지거나 맞는 소리를 쓰지 못했다.

## 빌려 쓰는 소리

| 적 | 소리 |
| --- | --- |
| N13 사구 약탈자 | N01 쇠사슬 시체(칼날) |
| N14 모래굴 벌레, N15 동굴 식인귀 | N02 무덤 사냥개(짐승) |
| N16 포자 부풀이 | N06 부푼 순례자, 죽을 때 남는 포자 구름은 독 장판 소리 |
| N17 가시뿔 야수인, N19 서리 망자 | N07 철갑 망령(무거운 망자) |
| N18 가시덤불 마녀, N20 빙결 술사 | N05 장송 사제(시전자) |

보스 공격은 거두기 베기를 무거운 휘두르기, 사슬 회오리와 아가리 물기를 돌진, 꼬리 채찍을 내려찍기 신호에 연결했다.

## 검증

2026-09-28, 통합한 프로젝트에서 `NewContentAudioTests` 2개를 포함한 Edit Mode 대상 검사 157개가 모두 통과했다. 적의 공격 준비·공격·사망 신호와 모든 보스 공격의 소리 연결을 검사했다. [검사 요약](CompletedIntegrationEvidence/editmode-summary.txt)

## 확인하지 못한 것

- 실제 게임에서 소리를 귀로 들어 확인하지 않았다.
- 빌린 소리는 임시다. 적과 공격마다 전용 녹음을 만드는 일은 남아 있다.
