# D4 스킬 트리 구현 기록

작성일: 2026-10-12 · [English](D4_Skill_Tree_Implementation_20261012.en.md)

기준 계획은 `claude/d4-skill-tree-plan`의 최종 커밋 `3be804b955e97b3c4500eb7d20acfbc2a3c32733`이다. 한국어·영어 계획서의 최종본 표시와 깨끗한 기획 워크트리를 확인했다. 원본의 장비 추천 미커밋 변경을 보존하고 별도 작업 폴더에서 최신 `main` `a5596519`를 포함했다. 구현은 한 에이전트가 단계 순서대로 진행한다.

## 1단계 — 데이터와 규칙

- `build_skill_tree_d4.py`가 기획 원본에서 JsonUtility가 읽는 `SkillTreeD4.json`을 생성·검사한다. 직업별 본 스킬 10, 보조 28, 패시브 10의 144개 노드와 111개 옛 id 대응을 담는다. 시안의 예시 배분·선택·초기 행동 설명은 게임 데이터에 넣지 않는다.
- 검증된 C# 모델·규칙을 복사하고 게임 데이터 어댑터와 랭크별 값 접근자를 연결했다. 개수 단위는 내림, 나머지는 선형 보간한 기획 정답 값을 쓴다.
- `SkillTreeD4.Enabled`는 기본 false이며 개발 실행 인자로만 켠다. 이 단계는 기존 스킬 카탈로그·UI·전투·저장 스키마를 바꾸지 않는다.
- 생성기 check와 Python 검사 2개가 통과했다. Unity 6000.6.0f1의 관련 EditMode 9개가 통과했고, **규칙 정답 32,208건·랭크 값 802건**이 일치했다. [검사 XML](D4SkillTreeEvidence20261012/phase-1-editmode.xml), [입력 해시](D4SkillTreeEvidence20261012/phase-1-inputs.json), [결과](D4SkillTreeEvidence20261012/phase-1-validation.json).
- 첫 임포트가 자동으로 바꾼 RuntimeShader 머티리얼과 URP 전역 설정은 이번 변경만 원래 바이트로 복원했다. 새 파일의 `.meta`는 Unity가 생성했다.

## 2단계 — 저장·이관·레벨

v5 투자 20항목과 수정자 레벨, 60레벨 상한을 개발 플래그 안에 연결했다. 읽기 시점 이관은 `.schema21-before-d4-skill-tree.json`에 원본을 보관하고 포인트를 전부 환급한다. 프리셋, 진행 중 전투, 훈련 기록과 튜토리얼 사본도 정리한다. 기존 HED3·4·5는 설정만 가져오며 v5 공유 코드는 HED6이다. 플래그가 꺼진 빌드는 schema 22를 백업으로 대체하지 않고 거부한다. 알림은 영웅별로 저장하고 첫 확인은 원자적 거래로 기록한다.

검증: 관련 첫 실행 37개 중 34개 통과. 옛 형식을 재현하는 테스트 코드 및 기대값 3개를 고친 뒤 추가한 배분 왕복 검사와 함께 15/15 통과했다. 옛 형식으로 먼저 생성한 5개 세이브·HED3/4/5 원본 바이트, 이관 반복 안전성, 원본 보관, 전투 체력·자원·진행 상태, 실패 시 백업 대체 금지와 40→60 경험치를 검사했다. 골든 배분 288개가 저장→JSON 불러오기→공유 코드 왕복 후 일치한다. Balance1000 지문 갱신 결과 1,000행·오류 0이다. [결과](D4SkillTreeEvidence20261012/phase-2-validation.json), [최종 EditMode](D4SkillTreeEvidence20261012/phase-2-editmode.xml).

미검증: 새로운 화면과 전투 구현, 전체 EditMode, macOS 스모크, 모바일 실기기. 퍼즐 키트 사본은 무효화했으며 6단계에서 새 규칙의 키트 재생성을 연결한다.

## 3단계 — 아이콘

계획의 PNG 92장을 원본 바이트로 임포트했다. `adopt_generated_game_art.inspect`로 모든 해시와 네이티브 알파를 확인했고 기존 A06·M07의 메타 바이트와 GUID는 유지했다. 스킬 아이콘 경로가 수정자·핵심 패시브를 포함한 144개 노드를 해결한다. 대표 W09-1을 먼저 SkillIconView로 렌더해 확인하고 나머지를 임포트했다. 관련 EditMode 18/18이 통과했다. [렌더](D4SkillTreeEvidence20261012/representative-W09-1.png), [검사](D4SkillTreeEvidence20261012/phase-3-editmode.xml), [결과](D4SkillTreeEvidence20261012/phase-3-validation.json).

메모리 예산은 Android ASTC 6×6 약 10.38MiB(10.9MB), 데스크톱 BC7·웹 ETC2 각각 23MiB(24.1MB)다. 최종 계획 D11은 이미 이 값으로 정정되어 있어 다시 수정하지 않았다. 압축 플레이어 다운로드 크기와 모바일 실기기는 아직 측정하지 않았다. 기존 111장 이력과 새 92장 출처는 아트 manifest의 별도 갱신 묶음으로 보관한다.

## 화면 UI-1 — 계산 핵심부

Layout·ViewModel·Session·Fx를 검증된 C# 포트에서 바이트 그대로 옮겼다. 테스트는 게임 데이터 모델을 사용하며 시안의 예시 배분과 선택만 명시적인 테스트 입력으로 주입한다. 관련 EditMode 11/11 통과: 레이아웃 2,975, 추가 레이아웃 15,034, 문구 600, 상호작용 4,986건으로 화면 정답 23,595건이 일치한다. 앞서 통과한 규칙 32,208건과 합쳐 총 55,803건이다. 6개 화면 크기의 좌표 변환과 반 포인트 폰트 반올림도 통과했다. [검사](D4SkillTreeEvidence20261012/ui-1-editmode.xml), [결과와 복사 해시](D4SkillTreeEvidence20261012/ui-1-validation.json).

아직 실제 uGUI 창과 메시·시각 효과·포인터 입력을 구현·검증하지 않았으며 UI-2부터 진행한다.

## 화면 UI-2 — 그리기 도구

공통 UiMesh에 그라디언트 테두리, 헥사곤, 원호, 둥근 점선, 광원·내부 음영을 추가했다. 연결선은 한 메시에서 설계 순서로 광원→본선을 그린다. 3/5분할 랭크 호, 정점으로 자른 아이콘, 글자 그라디언트와 스텐실·클립을 지원하는 톤·블러 셰이더를 만들었다. 색상은 UiTheme가 소유한다. 수정자 원본 이미지는 수정하지 않았다.

실제 검사에서 다중 인자 Mathf.Min의 숨은 배열 할당을 찾아 제거했다. 새 도구 관련 EditMode 10/10, 최종 모양 개선 범위 4/4, 선행 공통 Graphic·대장간 회귀 8개가 통과했다. 준비 후 도형·점선·랭크 호·6종 연결선·아이콘 자르기·부분 선 효과의 메시 작성은 관리 GC 0이다. 공통 UI 계약과 회귀 15개도 통과했다. Unity 카메라의 [견본 렌더](D4SkillTreeEvidence20261012/ui-2-sample-plate.png)에서 셰이더·도형·끝 겹침을 확인했다. [검사와 범위](D4SkillTreeEvidence20261012/ui-2-validation.json).

## 화면 UI-3 — 실제 창과 정적 트리

독립 캔버스 어댑터와 가로·세로 스크롤, PC 맞춤 배치, 기억하는 노드 집합과 명시적 메모리 호스트를 만들었다. 428개 시안 스타일을 221개 정규화 색 토큰과 불변 페인트 데이터로 생성하며 원본 CSS·골든은 변경하지 않는다. 트리 히트 영역·카드 내부 좌표, 금속 링·태그·랭크 바·연결선·화살표·모서리 장식·우측 페이드를 그린다. 반투명 광원은 허용 근사 A7의 단일 보정값 0.55를 사용한다. 단어 줄바꿈과 캡처용 폰트 갱신으로 기기 폰트 차이를 처리한다.

검증: 스타일 2/2, 위젯·메시 16/16, 최종 내부 좌표 2/2 통과(마지막 17:11:39 UTC). 새 CSS 페인트·화살표·모서리·페이드의 메시도 준비 후 관리 GC 0이다. 공통 계약 회귀 15개와 화면 갱신 지킴 16개를 통과했다. 3직업×4뷰×2언어의 24개 Unity 렌더에서 트리 요소의 시각 오차가 모두 기준 20 이하다. [검사 범위](D4SkillTreeEvidence20261012/ui-3-validation.json), [24개 수치](D4SkillTreeEvidence20261012/ui-3-comparison-summary.json), [렌더](D4SkillTreeEvidence20261012/ui-3-shots).

전체 화면 비교는 **0/24**다. 이 단계에서 상세 패널을 의도적으로 빈 틀로 남겼기 때문이며 통과로 보고하지 않는다. UI-4에서 패널을 채운 후 전체 L5를 확인한다. 실제 클릭·효과·실저장 호스트·네이티브 플레이어와 모바일 실기기는 아직 검증하지 않았다.

## 화면 UI-4 — 상세 패널과 글자

액티브·수정자·패시브·핵심·잠김의 상세 패널을 구현했다. 예약 설명 높이, 능력치 행, 수정자 선택 테두리·랭크 알약, 해금 진행 막대, 연계 칩, 가로/PC 하단 버튼과 세로 헤더 ± 버튼, 막힌 이유, 탭 마름모·포인트 점·닫기 심볼을 설계대로 배치한다. 설명은 부분 굵게·금색을 포함한 어절 줄바꿈을 사용한다. 기존 UiFonts(D6)를 유지하며 실제 글자 폭과 줄 높이로 잘림을 막는다.

검증: 설계 `panel.parts` 배분 시나리오 1,008개와 패널 6상태 좌표(±1pt)를 포함한 7/7, 실제 폭·글자·흐름 13/13, 다섯 화면 크기×양 언어의 모든 액티브/수정자 설명·행과 카드 이름 16/16 통과. 심볼 메시 GC 0, 공통 UI 회귀 15개와 갱신 지킴 16개 통과. [검사 기록](D4SkillTreeEvidence20261012/ui-4-validation.json).

전체 화면 시각 비교 **24/24 통과**: 색 오차 ≤6, 경계 ≥.7, 최악 타일 ≤32, 모든 요소 ≤20. [24장 수치표](D4SkillTreeEvidence20261012/ui-4-visual-table.md), [원본 보고서](D4SkillTreeEvidence20261012/ui-4-comparison-summary.json), [Unity 렌더](D4SkillTreeEvidence20261012/ui-4-shots). 새 창만 `vertexColorAlwaysGammaSpace`를 켜고 전용 셰이더를 맞춰 어두운 UI 색의 정밀도를 보존한다. CSS border-box 배경 합성과 방사 마스크를 재현하고 A7 전체 번짐 보정값은 0.50으로 최종 조정했다. 데이터·밸런스 수치는 바꾸지 않았다. 마지막 캡처 18:08:15 UTC, 최종 비교 보고서 18:09:02 UTC.

실제 입력·투자/회수·저장 실패·연출(UI-5), 실저장 진입·부모 창 갱신(UI-6), 전투와 의존 시스템 연결, 최종 전환·전체 EditMode·macOS 검증이 남았다. 모두 끝난 뒤 완료된 장비 추천 PR #109도 함께 main에 통합하고 해당 SHA의 CI 결과를 확인한다. 22:25 UTC의 최신 사용자 지시에 따라 웹 빌드와 이후 브랜치·워크트리 일괄 정리는 취소했다. 공개 위키·사이트 게시와 루틴 변경은 하지 않는다.
## UI-5 — 입력·저장·화면 재사용·효과

선택·투자·환불·직업 탭 버튼을 호스트 거래에 연결했다. 저장 실패는 배분과 효과 신호를 되돌리며 화면을 재생성하지 않는다. 누름은 시각 요소만 움직이고 히트 영역은 고정한다. ScrollRect가 드래그를 소유하며 입력 중 외부 저장 갱신을 미룬다. 표시 키 비교로 트리 요소를 재사용하고, 확정된 20개 애니메이션 곡선을 고정 효과 풀에서 재생한다. 같은 연결선에서 투자 효과가 우선하며 동작 줄이기를 따른다.

최종 관련 EditMode **16/16** 통과(20:07:50 UTC). 렌더 화면의 GraphicRaycaster와 포인터 입력으로 **60개 시나리오, 클릭 1,170회·비활성 입력 492회**를 재생했고 매 단계의 화면 상태와 효과 신호가 기준에 일치했다. 준비된 메시·무변경 프레임·진행 중 효과는 관리 메모리 할당 0 제약을 통과했다. 준비 후 투자 거래는 기존 트리 계층을 재사용하고 변경된 6개 요소만 그린다. Mono 스레드 할당 계수는 0을 반환했으며, 실제 실행 빌드의 클릭 프레임 프로파일러 측정은 남아 있다. 투자·환불을 0.10/0.30/0.80초에 촬영한 6개 근거를 보존했다. 공통 UI 15/15, 갱신 가드 16/16 통과. [근거](D4SkillTreeEvidence20261012/ui-5-validation.json).

실행 빌드 EventSystem·드래그, 실제 저장·재실행, 물리 기기는 아직 미검증이다. 다음은 UI-6 실제 저장 호스트·진입점·부모 창 갱신이며 전투 구현은 시작 전이다.
## UI-6 — 실제 저장 호스트와 진입점

현재 선택 캐릭터를 바꾸지 않는 직업별 거래, 즉시 디스크 저장, 전투 중 투자·마을 환불, 다른 영웅의 전투 소유자 거부를 연결했다. 직접 트리 진입은 독립 창을 열며 기존 전체 칙령 진입은 유지한다. 칙령의 스킬 관리 페이지에는 장착·공격 순서·트리 진입을 남겼다. 자식 창 저장 시 부모의 저장 기준을 갱신해 옛 배분 덮어쓰기를 막는다. 환급 알림은 처음 연 영웅만 확인 처리한다. 관련 없는 저장은 표시 키를 유지하고 레벨 변경은 저장을 기다리지 않고 감지한다. 편집 제한·번역·효과 머티리얼 복원과 해제를 보완했다.
