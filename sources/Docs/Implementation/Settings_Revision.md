# 설정 메뉴 개편

작성일: 2026-09-14 · [English](Settings_Revision.en.md)

## 화면과 조작

모든 화면 상단에서 기존의 넓은 ‘설정·안내’ 버튼을 정사각형 톱니바퀴 버튼으로 바꿨다. 기본 상단 바의 높이는 110에서 80으로 줄이고, 마을 안내와 이동 공간도 함께 맞췄다.

가로 화면에서는 설정 메뉴가 사용 가능한 화면의 오른쪽 절반을 채운다. 왼쪽에는 실제 마을이나 사냥터를 표시하며, 그곳에 있는 플레이어가 왼쪽 중앙에 보인다. 왼쪽 배경을 누르면 메뉴가 닫힌다. 세로 화면에서는 메뉴가 사용 가능한 화면 전체를 채우며 플레이 화면은 메뉴 뒤로 가려진다. 두 방향 모두 우측 상단에 고정된 X 버튼으로 닫을 수 있다. 본문만 스크롤하므로 X 버튼은 스크롤 위치와 무관하게 유지된다. 노치와 홈 바, 표시 중인 키보드 영역은 조작 공간에서 제외한다.

별도 캐릭터 모델·전용 카메라·미리보기 텍스처를 만들던 초기 구현을 제거했다. 실제 플레이어의 위치·방향·자세를 유지하고 기존 게임 카메라의 화면 영역과 중심만 잠시 조절한다. 카메라 각도와 화면에 보이는 크기는 유지한다. 메뉴를 닫으면 원래 카메라 구도와 게임 UI를 복원한다. 아직 마을에 입장하지 않은 타이틀에서는 기존 화면을 어둡게 표시한다.

## 네 가지 설정

| 분류 | 기능 |
|---|---|
| 화면 | 화면에 맞춤, 가로 16:9·16:10·4:3·20:9·21:9, 세로 9:16·10:16·3:4·9:20·9:21 |
| 가시거리 | 화면 분류 맨 위에서 50~150%를 5%씩 조절한다. 50%는 가까운 화면, 100%는 기본, 150%는 넓은 화면이다. 슬라이더·휠·− / + 버튼으로 조절한다. |
| 글자 크기 | 화면 분류 안에서 50~150%를 5%씩 조절한다. 슬라이더 끌기, 휠, − / + 버튼을 지원한다. |
| 소리 | 전체·음악·효과음 음량, 전체 음소거, 효과음 미리 듣기, 기본값 복원 |
| 언어 | English / 한국어를 선택한다. 선택 즉시 현재 화면을 다시 표시한다. |
| 캐릭터 변경 | 전사 → 마법사 → 궁수 순서로 표시한다. 현재 캐릭터는 선택할 수 없다. |

비율을 선택하면 즉시 적용한다. PC에서는 모니터 안에 들어가는 창 크기로 맞추고, 모바일에서는 방향 전환을 요청한 뒤 선택한 비율로 게임 영역을 맞춘다. 남는 공간은 검은 여백으로 표시한다. ‘화면에 맞춤’을 선택하면 현재 창이나 기기 화면을 그대로 사용한다.

가시거리는 직교 카메라의 시야 크기를 조절하며 카메라 각도, 플레이어 위치, 이동 속도와 UI 크기는 바꾸지 않는다. 가로 설정 화면에서는 실제 마을·사냥터에 바로 반영된다. 세로 화면에서는 설정을 닫은 뒤 확인할 수 있다. 설정은 `hellscript-view-distance-v1.json`에 별도로 저장하며, 파일 손상 시 원본을 보존하고 100%로 시작한다. 저장에 실패해도 선택한 시야는 즉시 적용하고 재시도 버튼을 제공한다.

글자 크기는 기존 구조에 따라 글자와 조작 영역을 함께 조절한다. 슬라이더를 누르고 있는 동안 설정 메뉴의 배율은 고정하고, 손을 떼면 선택한 배율을 적용해 조작 중 슬라이더가 움직이지 않도록 했다. 읽던 위치도 보존한다. 비율·크기·언어·소리는 계정과 별도의 기기 설정 파일에 저장한다. 손상된 설정 파일은 원본을 보존하고 기본값으로 표시하며, 저장 실패는 안내와 재시도로 처리한다.

## 캐릭터 변경과 상태 보존

설정 메뉴가 열려 있는 동안 전투·훈련·반복 사냥 대기는 멈춘다. X 또는 배경으로 닫으면 원래 상태에서 이어지며, 미리 일시정지했던 전투는 계속 일시정지 상태를 유지한다.

캐릭터를 변경하면 진행 중인 균열과 반복 사냥을 종료하고 새 캐릭터로 마을 시작 지점에 도착한다. 이미 획득한 재화·장비·경험치와 전투 기록은 기존 종료 규칙에 따라 보존한다. 아직 열지 않은 상자 등의 미획득 보상은 지급하지 않는다. 훈련 종료로 보상이나 실제 균열 기록을 만들지 않는다.

계정 사본에서 균열을 마무리하고 캐릭터 선택을 저장한 뒤에만 실제 계정과 화면을 전환한다. 저장에 실패하면 기존 캐릭터·전투·파일을 그대로 유지하고 설정 메뉴에서 오류를 표시한다. 재시도해도 전투 기록과 보상이 중복되지 않는다.

## 구현과 검증

UI 구성은 `GameUI.ScreenSettings.cs`, 실제 플레이 화면 배치는 `WorldView.Settings.cs`, 가시거리 조작·저장은 `GameUI.ViewDistance.cs`와 `ViewDistance.cs`, 기기 비율은 `DisplayAspect.cs`, 캐릭터 전환 저장은 `GameStore.CharacterSwitch.cs`가 담당한다. 씬이나 프리팹을 교체하지 않는다. 기존 안내와 전투 상태 화면의 진입 경로는 유지한다.

Unity 6000.6.0f1의 관련 Edit Mode 검사 174개를 통과했다. 비율 파일 보존·재시도, 캐릭터 변경의 저장 성공·실패, 전투 기록 중복 방지, 화면 너비 변경 후 비율 버튼의 줄 배치, 언어 문구와 기존 화면 배치 검사를 포함한다. 가시거리 기본값·21단계 저장·범위 보정·손상 파일 보존·저장 실패와 재시도도 검사했다. 동시에 진행 중인 균열 지형 작업과 섞이지 않도록 `297018b`에 실제 플레이 화면·가시거리 변경을 더한 별도 체크아웃에서 검증했다.

macOS 개발 앱에서는 타이틀·마을·전투의 톱니바퀴, 네 분류, 비율 10종, 크기 21단계, 휠·끌기, 배경과 X의 실제 입력 판정, 가로 반쪽·세로 전체 배치, 실제 마을·사냥터의 플레이어 동일성·위치·자세·카메라 각도·표시 크기 유지, 가시거리 21단계의 즉시 반영, 설정 닫기 후 카메라·UI 복원, 훈련 정지·재개와 기존 일시정지 유지, 실제 균열의 경험치 보존·기록 1회 종료·마을 귀환을 확인했다. 별도의 실행으로 비율·크기·가시거리·언어·선택 캐릭터의 복원도 확인했다. 시험은 전용 저장 경로를 사용했다. 실제 iOS·Android 기기의 방향 전환과 터치는 별도 검증 대상이다.
