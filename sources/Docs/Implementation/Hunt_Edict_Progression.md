# 사냥 칙령 단계 공개와 첫 비교 튜토리얼

갱신일: 2026-10-04

[English](Hunt_Edict_Progression.en.md)

설정을 바꿨을 때 사냥이 달라지는 경험을 먼저 제공한다. 신규 계정은 첫 스킬과 물약 HP 기준부터 시작하고, 계정 내 최고 클리어에 따라 설정을 공개한다. 공개된 권한은 되돌리지 않는다. 이해도와 공개 간격의 적절성은 실제 신규 사용자 플레이테스트에서 별도로 확인한다.

## 첫 필수 맵 v3

자동 전투 소개 → 직업별 첫 스킬 실제 포인트 사용·첫 슬롯 장착·저장 → 방식 A 관찰 → 방식 B 활성화·저장·관찰 → 원하는 방식 활성화·최종 확인 → 보스전에서 HP 기준 40%를 60%로 변경·저장 → 실제 자동 물약 사용 → 처치·기존 보상 거래·마을 도착 순서다.

전사는 W01 stand/edge, 궁수는 A01 steady/pack, 마법사는 M01 steady/pack을 비교한다. 기존 전투 예시 실행기에서 실제 초반 영웅과 장비·스킬 등급을 복사한다. A의 적 배치·시드·등장 시점·시작 HP·자원을 양쪽에 사용하며 해당 스킬 정책만 바꾼다. 1배속 10초와 재생·일시정지·재실행을 제공한다. 공격력은 1 이하이며 연습 재화·물약·기록·보상은 계정에 반영하지 않는다. 10초만 기다려서는 통과하지 않는다. 실제 시전과 edge 이동 또는 pack 조건 대기도 필요하다.

최종 선택은 저장된 정책으로 검사하며 실제 전투 영웅에도 적용한다. 물약 단계는 실제 회복 성공을 기록한다. 연습과 필수 맵의 설정 변경이 후속 F05/H09 실습을 완료시키지 않는다. 훈련·재도전 서명에는 실제 실행 정책과 추천 모드를 포함한다.

## 화면과 안내

기존 HuntEdictWindow 어댑터, ContentWindowHost, UiTheme/UiFonts, StoryDialogueWindow, 전투 예시 소유자를 재사용한다. 첫 맵에서는 현재 스킬·첫 슬롯·현재 조작만 노출한다. 마을에서는 개요·스킬·생존으로 시작하며 공개 탭 수에 맞춰 배치한다. 검색·요약·변경 목록·도움말·기록·바로가기에서도 공통 공개 판정을 사용한다. 미공개 탭의 잠금 자리나 빈칸을 만들지 않고 다음 기능 하나만 예고한다.

결과와 보상 흐름 뒤 마을에서 안내 카드 한 개를 표시한다. `설정해보기`는 해당 탭·설정을 강조하고 `나중에`는 이용을 막지 않고 넘긴다. 안내 기록에서 다시 읽고 실습한다. 룬 필수 안내가 먼저이며 전투 중 선택형 설명창을 자동으로 띄우지 않는다. 첫 일반 균열 안내는 보존된 마지막 5초 HP·피해와 주요 피격원도 보여 준다. 한국어·영어를 함께 제공한다.

StoreViewBinding 표시 키는 영웅·레벨·공개 목록·물약 revision·칙령/스킬/프리셋·안내 단계를 포함한다. 무변경 저장은 다시 그리지 않으며 누름·입력·드래그·자식 창 동안 갱신을 보류한다. 편집본, 이름 경로의 포커스와 소유자 스크롤을 유지한다. 중단·되돌리기·수동 보호·수동 보충은 계속 접근 가능하다.

## 저장과 기존 계정

스키마 21에 계정 공개 버전/ID/기존 접근 보존, 안내 최초 노출 `announced`, 필수 맵 flowVersion/lessonStep를 추가한다. 안내 노출·읽음·미룸·실습은 다른 상태다. 설정과 단계는 저장 성공 후 전환한다. 재시작 시 저장된 비교 구간을 처음부터 재생한다. v2 진행 중 저장은 기존 흐름으로 마무리한다. 완료 요청 ID `tutorial-map-complete-v2`는 유지하여 보상을 중복 지급하지 않는다.

잠긴 값이 그대로인 전체 칙령 저장은 허용한다. 변경된 값은 공통 공개 권한으로 검사한다. 공식 간편 설정은 Store가 실제 템플릿 ID와 범위를 재계산한다. 공유 코드에는 계정 공개 권한·간편 설정 예외를 넣지 않는다. 미공개 값을 바꾸는 프리셋은 공개 조건을 알리고 거절한다. 일반 Save의 직접 변경도 마지막 성공 저장의 칙령과 비교한다.

신규 영웅은 편집 칙령을 실제 실행한다. 자동 구매·처분·장착·반복은 처음에 OFF이며 공개만으로 켜지지 않는다. 기존 계정은 설정과 접근을 보존하고 읽음/실습을 새로 완료 처리하지 않는다.

## 검증 근거

[검증 기록](EdictProgressionEvidence20261004/validation.json)에 최종 검사 범위·결과와 미검증 항목을 기록한다. 개발 중에는 공개 분류·우회 저장·동일 비교 조건·v3 저장 실패/재시작/실제 물약/보상 중복 검사를 제한적으로 실행했다. 전체 EditMode·UI 계약·갱신 검사와 macOS 개발 플레이어의 실제 UI 경로는 최종 변경을 기준으로 한 번 묶어 실행한다. 실패 시 실패한 검사와 직접 영향 범위만 다시 수행한다.

macOS 합성 포인터·입력 검증과 브라우저·모바일 실기기·사용자 이해도 검증을 구분한다. 성능 향상이나 모바일 실기기 통과를 이 문서로 주장하지 않는다.

[152-field disclosure database](#/db/edict-disclosure)

현재 검사 상태: 전체 EditMode는 한 번 실행했다(5,147개 중 5,065 통과, 82 실패). 수정 재검사 158개 중 156 통과·2 실패 뒤 직접 영향 검사 32개가 통과했다. 최초 실패 82개는 모두 해소했고, 이후 공개 권한 경계 검사 31개 및 영웅 레벨 경계 검사 1개도 통과했다. 전사 네이티브 입력에서 A/B 실제 관찰·재시작·최종 선택 저장과 실행, 한국어/영어 5개 화면 비율, HP 40→60 저장, 실제 물약 사용·보스 처치·1,000골드 완료 거래까지 확인했다. 마을 전환 중 출석 팝업이 인사창보다 먼저 열리는 충돌을 소스에서 수정했으며 런타임 C# 컴파일을 통과했다. 사용자의 통합·정리 요청에 따라 게임 테스트는 다시 시작하지 않았다. 수정 후 마을 인사, 마을/입장/수동 보충·갱신 입력과 궁수·마법사 네이티브 검증은 미완료이며, 전 범위 런타임 완료로 주장하지 않는다.

균열 입장의 수동 물약 보충은 공개 전에도 사용할 수 있다. 현재 지정 물약·예산·남길 골드를 적용하고 자동 구매는 OFF로 유지한다. 스킬 장착 변경은 기존 정책을 유지한 장착 상태끼리 비교하여 세부 정책 편집으로 잘못 판정하지 않는다.
