# 숲속 정착민 마을과 타이틀 진입 동선

작성일: 2026-09-14

[English](Forest_Settlement.en.md)

## 목적과 현재 동선

마을은 어두운 침엽수림 속에 자리 잡은 정착민의 생활 공간이다. 목조와 회반죽 건물, 돌기단, 경사진 지붕, 따뜻한 창문과 등불, 보급 상자, 우물, 야외 훈련 표적으로 각 시설을 구분한다. 디아블로 4에서 연상되는 숲과 정착지의 분위기를 참고하되, 외부 게임의 모델이나 이미지는 사용하지 않는다. 건물·NPC·포탈은 프로젝트 안에서 생성하는 교체 가능한 3D 메시이며, 영웅은 기존 게임의 모델을 공유한다.

게임 시작 → 타이틀 → 캐릭터 선택 → **입장하기** → 마을 도착 순서로 진행한다. 타이틀에 머무는 동안 마을 이동 상태를 만들지 않는다. 캐릭터 선택은 기존 세 캐릭터와 기기의 저장 기록을 사용한다. 진행 중인 균열이 있으면 해당 캐릭터로 입장하며, 마을 포탈에서 기존 균열을 이어간다.

마을에서는 왼쪽 아래의 원형 가상 조이스틱으로 움직인다. 손을 떼면 멈추며, 두 번째 손가락으로 다른 버튼을 눌러도 조이스틱을 조작하는 손가락이 바뀌지 않는다. 설정 창·시설 안내·앱 비활성화 때 이동 입력을 초기화한다. PC에서는 WASD와 방향키로도 이동하고 E로 상호작용할 수 있다. 바닥 터치와 시설 안내의 목적지 선택은 보조 이동 수단이며, 건물을 돌아가는 경로를 이용한다.

2026-09-14 요청에 따라 기존 문서의 **마을 조이스틱 미제공**과 **도착 즉시 서비스 자동 열기** 규칙은 이 문서의 동선으로 대체한다. 전투의 자동 행동 방식은 바꾸지 않는다.

## 배치와 크기

좌표는 고정 카메라를 기준으로 오른쪽이 +X, 화면의 먼 쪽이 +Y다. 카메라는 회전하지 않는다. 주 이동로의 서쪽 끝과 동쪽 끝은 110m 떨어져 있고, 기본 이동 속도 5.5m/s로 약 20초가 걸린다. 전체 보행 범위는 110m × 70m다. 건물을 우회하는 동선은 직선 횡단보다 오래 걸릴 수 있다.

| 시설 | NPC 또는 대상 좌표 | 배치와 기능 |
|---|---|---|
| 창고 | (-37, 13) | 보급 상자와 통이 있는 창고 앞의 창고 관리자가 계정 공용 창고를 연다. |
| 장비 상점 | (-14, 16) | 차양과 장비 진열대 앞의 상인이 기본 장비 구매, 장비 판매, 기존 미확인 장비 상점을 연결한다. |
| 대장간 | (14, 17) | 굴뚝·화덕·모루가 있는 대장간 앞에서 장비 선택, 강화, 옵션 재설정, 제작을 연결한다. |
| 훈련장 | (37, 9) | 교관 뒤쪽에 표적과 울타리가 있는 야외 훈련장을 둔다. 첫 균열 시도 전부터 무료 훈련과 설정 비교를 이용한다. |
| 보석 상점 | (-32, -24) | 보석 진열대 앞에서 1단계 보석 구매와 소켓·보관함 관리로 연결한다. |
| 룬 상점 | (21, -24) | 룬 블록 진열대 앞에서 G0 룬 구매와 기존 룬 보드로 연결한다. |
| 균열 | (8, 0) | 마을 중앙에서 약간 오른쪽에 주황·금빛 포탈을 둔다. 회전하는 문양, 입자, 반투명 막과 등불 효과를 사용하며 단계 선택과 균열 입장을 연다. |

각 NPC는 건물의 카메라 쪽 앞마당에 서 있다. 건물 충돌 영역은 보행 모델과 목적지 경로 계산에서 같은 정의를 공유한다. 수동 이동은 작은 구간으로 나누어 검사하므로 긴 프레임이나 대각선 입력으로 벽을 통과하지 않는다. 대각선 속도도 직선 이동 속도를 넘지 않는다.

## 근접 상호작용과 가림 처리

대상 2.8m 안으로 들어가면 해당 NPC의 말풍선과 오른쪽 고정 기능 카드로 서비스를 확인한다. 기능 버튼을 눌러야 화면이 열리며, 접근이나 도착만으로 화면을 열거나 거래하지 않는다. 여러 대상이 가까우면 가장 가까운 하나를 선택한다. 기능 카드는 화면 안전 영역의 오른쪽에서 22 UI 단위 떨어진 위치, 아래에서 35% 높이를 유지한다. 가로·세로 화면 모두 같은 기준을 사용한다.

카메라에서 캐릭터의 몸과 머리로 향하는 광선이 건물을 통과하면 해당 건물의 지붕·벽·부속물을 함께 18% 불투명도까지 낮춘다. 가림이 해소되면 원래 불투명도와 그림자를 복구한다. 직교 카메라의 평행 광선을 사용하며, 반투명 처리는 렌더링에만 적용한다. 투명해진 건물도 통과할 수 없다.

## 거래와 성장 규칙

새 상인은 기초 물품을 확정 구매하는 경로를 제공한다. 고급 장비 추첨·제작·해금, 보석 합성, 룬 성장의 기존 규칙은 각 서비스에서 유지한다. 가격은 초기 플레이 조정을 위한 기본값이다.

| 판매 물품 | 기본 가격 | 받는 위치 |
|---|---|---|
| 일반 장비 | 140 + 생성 아이템 레벨 × 40 골드 | 선택 캐릭터의 가방 |
| 1단계 보석 7종 | 각 350 골드 | 계정 공용 보석 보관함 |
| G0 1칸 / 2칸 / 3칸 룬 블록 | 300 / 1,200 / 2,700 골드 | 계정 룬 보유 목록 |

생성 아이템 레벨은 선택 영웅의 최고 실제 클리어 단계를 사용하며 최솟값은 1, 최댓값은 기존 아이템 레벨 상한이다. 구매 버튼에서 물품과 가격을 확인한 뒤 확인 창에서 확정한다. 진행 중인 균열, 부족한 재화, 가방·보관함 부족, 잘못된 물품은 거래를 거절한다. 거래는 기존 저장 트랜잭션에 통합하며 같은 요청을 다시 실행해도 지급과 차감이 중복되지 않는다. 저장 실패 때 계정과 파일을 모두 보존한다. 첫 보석 구매는 기존의 정상 보석 획득 해금 조건을 충족한다.

## 구현 소유권과 검증

기존 `GameController → GameUI / WorldView → TownWalk` 구조를 확장한다. 신규 패키지나 씬·프리팹 교체는 필요하지 않으며, 런타임 건물·카메라·상호작용은 기존 소유 경로에서 생성한다. 이동 상태는 세션 전용이고 기존 캐릭터 저장 형식을 바꾸지 않는다.

2026-09-14, Unity 6000.6.0f1에서 검증했다. 관련 Edit Mode 검사 79개를 모두 통과했고, macOS 개발 빌드는 오류 0건으로 성공했다. 별도의 시험용 저장 경로에서 타이틀과 캐릭터 선택, 조이스틱 중심·이동·손 떼기·두 손가락 소유권·비활성화 시 입력 해제, 7개 시설과 명시적 상호작용, 가로·세로 및 130% UI 배율, 건물 앞의 정상 불투명도·뒤쪽의 투명화·원상 복구, 장비·보석·룬 구매 확인 창, 첫 계정의 훈련과 실제 균열 진입을 확인했다. 실행 검증은 `HELLSCRIPT_FOREST_TOWN_RUNTIME_OK`로 종료했다.

전체 검사 과정에서 발견한 기존 실패 13건은 변경 전 커밋 `1ad2d84`의 별도 체크아웃에서도 같은 결과로 재현했다. 보상 수치와 저장 스키마의 기대값 불일치이며 이번 작업에서 수정하지 않았다. 따라서 전체 프로젝트의 모든 검사가 통과한 상태로 보고하지 않는다. [검증 요약](ForestTownEvidence/validation.json), [관련 검사 결과](ForestTownEvidence/editmode-results.xml), [실행 결과](ForestTownEvidence/runtime-result.txt), [변경 전 실패 목록](ForestTownEvidence/baseline-failures.json)을 함께 보존한다.

현재 마을 미술은 교체 가능한 기본 3D 메시다. 정식 모델·텍스처로 미술 품질을 높이는 작업과 실제 iOS·Android 기기의 터치 감각, 발열, 프레임 성능은 후속 검증 대상이다.
