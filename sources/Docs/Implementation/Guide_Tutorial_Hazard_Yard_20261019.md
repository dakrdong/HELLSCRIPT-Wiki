# 가이드 튜토리얼 개편 — 장판·화살 회피, 레벨업 폭죽, 보스와 회오리 (2026-10-19)

[English](Guide_Tutorial_Hazard_Yard_20261019.en.md). 새 계정이 처음 하는 `칙령의 길`(흐름 7)을 다시 짰다. 요청: 회전 베기 수업 뒤에 지속 피해 장판 회피와 투사체 회피를 가르치고, 레벨업을 화려하게 바꾸고, 보스를 더 뒤로 옮겨 만나는 자리에서 회오리를 가르치고, 전체 대사와 연출을 점검한다.

## 처음 시작 연출 (`Awakening`)

새 계정이 처음 시작하면 아무 말 없이 걷기 시작하던 것을 바꿨다. 흐름 7의 새 런은 `Awakening`(번호 45, 대기 단계)에서 멈춘 채 시작하고, 연출이 끝나야 걷기(`Entrance`)로 넘어간다.

1. 검은 화면, 심장 소리, 영웅이 무릎 꿇은 자세. 세계관 세 줄이 카드로 지나간다: "세계는 갈라졌다 / 갈라진 틈마다 마물이 기어 나왔다" → "그 틈을 균열이라 불렀다 / 균열 앞에 선 영웅에게는 길을 일러 주는 목소리가 있었다" → "그 목소리는, 당신 / 당신이 쓰는 칙령이 영웅의 길이 된다"(플레이어를 칙령을 쓰는 목소리로 세워 이후 벨리나의 안내로 이어진다). 건너뛰기 버튼이 있다.
2. 2.4초에 걸쳐 밝아지며 화면이 영웅 쪽으로 다가가고, 영웅의 독백 세 줄(머리가 울린다 / 마을 성문을 나섰는데 이런 곳은 지도에 없었다 / 발밑이 차갑고 누군가 지켜본다)이 나온다. 마지막 줄에서 신성한 빛이 내리고 금빛 테두리가 번진다. 벨리나는 아직 말하지 않는다(그녀는 플레이어에게 존댓말로 말하므로 영웅에게 말을 걸지 않는다).
3. `몸을 일으킨다`를 누르면 영웅이 일어서고 효과음과 함께 빛이 걷히며 `튜토리얼 · 칙령의 길` 카드가 오르고 길을 걷기 시작한다. 이어서 기존 벨리나의 첫인사가 나온다.

세이브 중간(연출 중 종료)에서 다시 열면 연출을 처음부터 다시 보여 준다. 구 체크포인트는 시작 단계가 달라지지 않는다.

## 새 순서 (광장 이후)

| 단계 | 일어나는 일 | 저장되는 설정 |
| --- | --- | --- |
| `Road3` → `DotFight` | 광장 입구에 닿으면 원형 장판 마법사(1마리)가 연기와 함께 나타난다. 영웅은 아직 장판을 피하지 않아 그 안에서 싸운다. | 없음 |
| `DotTalk` | 장판 피해가 두 번(초당 7%) 쌓이면 벨리나가 나타나 위험을 말한다. 사냥 칙령 → 생존 → 피해 유형별 회피 → 지속 피해 장판 회피 여부를 **1~7%** 로 정하게 한다(가림막이 버튼을 하나씩 짚는다). | `dodge.ground` 1~7% |
| `DotDodge` | 영웅이 장판이 깔릴 때마다 비켜서며 마법사를 처치한다. | |
| `ShotFight` / `ShotTalk` | 궁수 3명이 나타난다. 화살 한 발 = 최대 HP의 5%. 첫 화살을 맞으면 벨리나가 투사체 회피 여부를 **1~5%** 로 정하게 한다. | `dodge.direct` 1~5% |
| `ShotDodge` → `LevelUp` | 궁수를 모두 처치하면 레벨 3이 되고(HP·MP 완전 회복, 스킬 포인트 +1) **긴 폭죽 연출**(5초, 확인 버튼)을 보여 준다. | |
| `LevelTalk` → `Road4` | 벨리나 대사 뒤 길을 따라 새로 만든 보스 방으로 간다. 보스 무리가 영웅을 알아보기 직전(15m)에 멈춘다. | |
| `BossTalk` | 카메라가 보스를 비추고 보스 카드가 뜬다. 벨리나가 회오리를 소개한다(전사의 메인 스킬, 주변 모든 적을 계속 베어 가장 효율적이고 빠르게 몬스터를 처치한다). 포인트 1을 회오리에 쓰고 **두 번째 칸**에 장착하게 한다(찢어낸 상처는 첫 칸에 남는다). | 회오리 습득·장착 |
| `MixedFight` → 기존 | 이후는 기존 흐름(협동 공격 → 우선순위, 보물 고블린, 회수, 보스, 마을)이다. | |

위치 수업(`OpeningTalk`, `CombatTalk`)은 그대로 광장 앞 회랑에서 한다. 보스 무리(탱커·마법사 2·궁수·보스)는 새 **5번째 방**(`RM06`, 중심 (122,50), 복도로 광장 동쪽 문과 연결)으로 옮겼다. 영웅이 길을 따라 걸어가고 보스는 원래보다 훨씬 뒤에서 만난다.

## 수치와 이유

- **피해량**: 장판 한 번의 펄스는 계산된 HP 비율의 절반, 초당 두 번이므로 정확히 **7.02%**, 화살은 **5.02%** 다. 방어·저항이 다른 장비를 입어도 같도록 예측과 `Hurt`가 쓰는 `IncomingDamageNumbers`를 이분법으로 맞춘다. 저장 기준이 7%(또는 5%)와 같아도 `>=` 비교로 회피하도록 0.02를 더했다.
- **시작 상태**: 영웅은 장판·투사체·범위 회피를 모두 `OFF`로 시작한다(슬라이더 0% '피하지 않음'). 수업이 1~7%·1~5%로 올린다. 칙령 순서는 `DODGE,ATTACK,…`(회피 우선)로 바꿨다. 기존 `ATTACK,DODGE`로는 근접 영웅이 늘 공격할 수 있어 저장한 기준이 영웅을 움직이지 못한다. 회수 수업이 `PRIORITY_LOOT`을 맨 위로 올려도 회피가 공격 위에 남는다.
- **적은 일반 규칙으로 싸운다**: 이 문서의 첫 판은 마법사·궁수를 제자리에 묶고 시전 간격과 장판 시간을 줄이고 수업 전에는 죽지 않게 체력 바닥을 두었다. 2026-10-19 두 번째 개편에서 모두 걷어냈다. 전투(적의 이동·시전 주기·피해, 영웅의 이동·공격)는 튜토리얼에서도 실제 규칙이고, 튜토리얼이 정하는 것은 순서·안내·사냥 칙령 설정뿐이다. [실제 규칙 개편](Guide_Tutorial_Real_Rules_20261019.md).
- **저장·재개**: 새 단계는 번호 끝(35~44)에 붙였고 `Last`를 올렸다. 방이 4개이던 이전 체크포인트는 배치 지문(`tutorial-v7r2`)이 달라 `Tutorials.Normalize`가 조용히 버리고 처음부터 다시 시작한다(없는 방으로 걸어 들어가는 것을 막음). 흐름 6(옛 체크포인트)은 코드가 그대로다.

## 레벨업 연출

`LevelUpCelebration`(화면 위 연출 층): 흰 섬광, 회전하는 후광(16줄기), 리본 배너에 `레벨 업!`과 `Lv.N`이 튀어나오고(오버슈트), 양쪽 아래 모서리의 색종이 대포와 상단의 폭죽 여러 발(터지는 불꽃 + 반짝이 + 색종이), 튜토리얼 첫 레벨은 마지막까지 색종이비. 모든 레벨업이 **5초**이고 일반은 6발·대포 2번, 튜토리얼 광장 레벨업은 11발·대포 3번·색종이비. 화면 가운데 아래에 **확인 버튼**이 5초 카운트다운(`확인 (5)`와 줄어드는 금빛 막대)으로 나타나, 누르면 0.3초 안에 닫히고 시간이 다 되면 저절로 닫힌다. 버튼 밖의 입력은 모두 통과한다. 튜토리얼에서는 연출이 끝나는 즉시(일찍 눌러도) 레벨 업 대사로 넘어간다. 동작 줄이기 설정에서는 배너 페이드만. 안내가 필요한 곳은 `RefreshGrowthHud`(최근 3초 이내 레벨업만 연출, 복원된 기록은 알림만). 세계에는 기존 황금 고리·광주를 그대로 둔다.

그림은 Codex(`gpt-6-astra` 요청, 모델 `unknown`)에게 5장을 받았다: 리본 배너(빈 파란 판), 후광, 반짝이 2×2, 색종이 4×4(16종), 폭죽 2×2(모란·고리·버들·하트). 첫 시도에 진짜 알파로 나왔고(가장자리 알파 ≤7/255) 다시 그리지 않았다. 기록: [`Docs/Art/LevelUpCelebration20261019`](../Art/LevelUpCelebration20261019/manifest.json). 런타임은 `Resources/Art/LevelUp/`(`LevelUpArtImporter`, 예산 1024 ASTC 6x6), 원본 1254²는 저장소 밖 `~/HellscriptBackups/levelup-celebration-20261019/native/`에 있다.

## 대사·연출 점검 결과

- 소개에 **영웅이 사냥 칙령의 글자 그대로 움직인다**는 설명이 없었다. 첫 구간에서 칙령을 계속 고치게 하면서 마지막 `Cleared`에서야 "이것이 사냥 칙령"이라고 했다. 소개에 두 문장을 더했다.
- 길 위 대사 "보셨나요? 영웅이 당신이 가르친 그대로 움직였습니다"가 기술·물약 수업 직후에 나와 맞지 않았다(흐름 7). 흐름 7에서는 "저 앞쪽에서 또 다른 적들의 기척이 느껴져요…"로 바꿨고 끝 장면에는 그대로 둔다.
- 새로 등장하는 적마다 **알림**("새로운 적 · …")과 발밑 연기·고리·반짝임을 더했다(몰려오는 작은 몬스터, 포위, 장판 마법사, 궁수). 수업을 마칠 때마다 `완료` 알림(예: `꿰뚫는 갈고리 습득`, `지속 피해 장판 회피 설정`, `전투 중 위치 설정`)을 띄운다.
- 장판·화살 대사는 영웅이 지금 왜 맞고 있는지(현재 기준)를 저장 상태에서 읽어 말한다. 위험 설명 중에는 화면 가장자리가 붉게 물든다. 보스는 카드와 카메라로 소개한다.
