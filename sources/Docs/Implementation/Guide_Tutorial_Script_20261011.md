# 안내 튜토리얼 1·2·3구간

갱신일: 2026-10-12

[English](Guide_Tutorial_Script_20261011.en.md). 퍼즐 레벨 튜토리얼을 대체하는 튜토리얼 전용 스테이지(흐름 6)의 첫 구간이다. 대본, 안내자 설정, 구현과 검증을 함께 기록한다.

## 안내자

- 이름: **벨리나**, 칭호 "칙령의 여신". 이름은 베일(velum)에서 왔다. 천으로 눈을 가린 모습은 그림으로만 보여 주고, 대사에서는 눈 가림이나 시간 정지 같은 설정을 설명하지 않는다(2026-10-11 사용자 요청).
- 말투: **존댓말**로, 영웅이 아니라 **게임을 하는 플레이어에게** 말한다. 영웅은 "당신이 지켜보는 이 영웅"이다.
- 초상: Codex 생성 후보 B(손바닥의 빛으로 이끄는 자세). `Resources/Art/NpcPortraits/guide-goddess(-mirror).png`, 원본·프롬프트·메타는 `Docs/Art/GuideGoddess/`.
- 개발자는 직접 등장하지 않는다. 세계관을 깨지 않도록 "이 세계의 규칙을 알려 주는 여신"으로만 말한다.

## 진행과 대사

맵은 오른쪽 위로 꺾여 올라가는 네 개의 방(입구 회랑, 첫 투기장, 긴 회랑, 광장)과 꺾인 통로다. 1구간은 앞의 두 방을 쓰며, 2구간은 위쪽 문과 꺾인 통로를 지나 긴 회랑에서 위치 칙령을 가르친다. 3구간은 광장에서 공격 대상 순서·보물 고블린·회수를 가르친다. [2구간 구현·검증](Guide_Tutorial_Segment2_Plan_20261012.md)을 함께 따른다.

## 규칙과 구현

- **첫 시작:** 튜토리얼을 시작하거나 마친 영웅이 없는 계정(`GuideTutorial.FirstStart`)은 게스트·구글 로그인 뒤 직업 선택 없이 전사로 바로 들어간다. 중단 후 다시 들어와도 같다.
- **진행 중인 퍼즐 계정:** 이미 퍼즐 레벨을 진행 중인 계정은 기존 퍼즐을 마저 한다. 새 계정만 새 스테이지를 탄다.
- **졸업:** 1·2·3구간을 모두 마치면 마을로 졸업한다(`guide-graduate` 거래 1회, 기존 프롤로그 금화 지급). 전사의 스테이지가 모든 영웅의 튜토리얼을 대신하므로 다른 직업은 튜토리얼 없이 마을에서 시작한다. 2구간 수업에서 위치 옵션 세 개만 먼저 공개하며, 3구간의 공격 대상·행동 순서는 해당 수업 때 공개하며, 나머지 옵션은 졸업 시 기존 전체 개방을 따른다.
- **마을 도착 = 튜토리얼 완료(2026-10-11 추가):** 졸업과 함께 튜토리얼이 모두 끝난 것으로 보고 모든 기능을 연다. 모든 콘텐츠 해금(훈련장~걸작 강화), 사냥 칙령의 모든 옵션 공개(`edictLegacyAccess`), 반복 사냥 설정, 룬판(룬 수업 없이 완료 처리, 균열 15 첫 클리어의 룬 블럭 세트 수업 보상은 없음)을 열고 튜토리얼 힌트를 끈다(설정에서 다시 켤 수 있음). 표시는 `AccountGuide.everythingOpen`, 처리는 `GuideTutorial.OpenEverything`이다.
- **재시작:** 스테이지 도중 앱을 끄면 다음 진입 때 길의 처음부터 다시 시작한다(스킬도 다시 비운다).
- **HUD 스킬 레벨 올리기(일반 기능):** 남은 스킬 포인트가 있으면 HUD 기술 칸 목록에 아직 배우지 않은 스킬이 흐리게 따라 나오고, 누르면 상세 창의 '레벨 올리기'로 포인트를 쓴다. 튜토리얼이 가르친 경로가 이후 균열에서도 그대로 쓰이도록 일반 기능으로 넣었다.
- 주요 파일: `GuideTutorial.cs`(맵·단계·규칙), `CombatSimulation.Guide.cs`(걷기·소환·단계 전환), `GameStore.Guide.cs`(입장·졸업), `GameUI.GuideTutorial.cs`(대사·HUD 수업), `GameController.Tutorials.cs`(진입 경로).
