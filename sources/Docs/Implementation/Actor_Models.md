# 영웅·적·보스 모델 연결

작성일: 2026-09-28 · [English](Actor_Models.en.md)

[다크 고딕 개편](Dark_Gothic_Overhaul_Stage1.md) 1단계에서 만들어 둔 3D 모델을 전투와 마을 화면에 연결했다. 2단계의 다섯 번째 항목이다. 모델이 있는 몸은 모델로 그리고, 모델이 아직 없는 몸은 지금까지의 기본 도형을 그대로 쓴다. 게임 규칙과 수치는 바꾸지 않았다.

## 연결한 모델

| 영웅 전사·사냥꾼·마법사 | 이족 | 전사는 검과 방패, 사냥꾼은 활과 화살통, 마법사는 지팡이를 모델의 부착 위치에 붙인다. |
| 황금 고블린 | 이족 | |
| N01 쇠사슬 시체, N03 해골 궁병, N04 역병 시종, N05 장송 사제 | 이족 | |

N08–N20과 B04 사구의 폭군, B05 혹한의 여사제는 아직 모델이 없어 기본 도형으로 싸운다. 모델 파일이 추가되면 코드를 고치지 않아도 모델로 바뀐다.

## 움직임과 표현

- 모델마다 [`ActorRig`](../../Assets/HELLSCRIPT/Runtime/Presentation/ActorRig.cs)를 붙여 행동 단계를 몸짓으로 보여 준다. 걷기, 공격 준비(시전형은 시전 자세), 돌진, 이동 공격, 공격, 회복, 보스 무력화, 피격 움찔임이 있다. 영웅도 공격 준비·집중·이동 기술·공격 자세를 취한다.
- 쓰러진 적은 1초 동안 무너진 뒤 녹아 사라진다. 기본 도형은 전처럼 바로 녹는다.
- 피격 번쩍임, 공격 준비 때 달아오르는 테두리 빛, 몬스터 등급 빛, 순간이동 때 녹았다 나타나는 표현이 모델에도 똑같이 들어간다. 모델 재질의 차가운 테두리 빛은 이런 효과가 켜져 있는 동안에도 유지된다.
- 모델은 기본 도형보다 가늘어서 전투 화면 거리에서 작게 보였다. 그래서 영웅·일반 적·고블린은 모델 키의 1.25배로 그린다. 보스는 4.3–5m라 원래 크기를 쓴다. 체력 막대는 모델 키에 맞춰 머리 위에 둔다.
- 기본 도형 보스는 몸을 가로 2배·세로 1.7배로 키워 썼다. 모델 보스는 그렇게 키우지 않으므로 도약 높이, 잠행 깊이, 앞으로 내딛는 거리를 같은 비율로 맞췄다.
- 정예는 보라색 고리 대신 이펙트 라이브러리의 몬스터 등급 이펙트(발밑 문양과 등급 색 테두리 빛)를 두른다. 이펙트 라이브러리를 불러오지 못한 경우에만 고리를 쓴다.
- 마을에서도 영웅이 모델로 걷는다.

## 벽 뒤 영웅 실루엣

영웅이 벽이나 기둥에 가려질 때 보이는 금색 실루엣을 모델에도 붙였다. 처음 연결했을 때는 팔·방패·망토처럼 영웅 자신의 다른 부위에 가려진 곳에도 실루엣이 칠해져 영웅 전체가 누렇게 번져 보였다. 두 가지로 고쳤다.

- 영웅 재질이 그린 픽셀에 스텐실 표시(비트 64)를 남기고, 실루엣은 이 표시가 없는 픽셀에만 그린다. 다른 물체가 영웅을 가린 곳에서만 실루엣이 보인다.
- 실루엣을 카메라 쪽으로 0.75m 당겨 그린다. 영웅 바로 앞 0.75m 안의 물체는 실루엣을 만들지 않는다. 모델이 없을 때 쓰는 기본 도형 영웅도 방패와 몸이 겹친 곳이 더 이상 칠해지지 않는다.

- 모바일에서 스킨 메시와 스텐실이 드는 비용은 재지 않았다.
- N08–N20, B04–B05, 필드 바닥·벽·소품, 상자, 마을 건물과 NPC의 모델은 아직 연결하지 않았다.
