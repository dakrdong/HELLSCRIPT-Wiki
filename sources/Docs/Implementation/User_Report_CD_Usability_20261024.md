# 장비 안내와 작은 사용성 수정 (2026-10-24)

[English](User_Report_CD_Usability_20261024.en.md)

장비 점수 안내(U-C, 사용자 4·5번)와 지도·상점·일일 퀘스트·룬 표시(U-D, 3·6·7·10번)를 수정했다. 기존 저장 키와 장비 비교 계산은 유지한다.

- 헬멧 추천 상세에서 장착 전에 공통 장비 점수를 강조해 설명한다.
- 추천 설정 수업은 저장된 선호가 있어도 직접 더 높은 점수 옵션을 선택하고 저장해야 진행한다. 수업의 초기 선택은 분리한 편집본에만 적용한다. 취소나 저장 실패로 수업을 완료하지 않는다. 저장 뒤 낮은 점수 장비도 가방에 들어온다고 설명한다.
- 지도 경계는 같은 탐색 마스크를 사용하는 어두운 외곽선과 밝은 안쪽 선으로 그린다. 기존 갱신 조건을 유지하며 프레임별 검색이나 새 타이머를 추가하지 않는다.
- 구매한 상점 행은 거래 성공 직후 목록에서 제외한다. 물품·구매 이력·소지품과 되사기 규칙은 유지한다.
- 짧은 세로 화면에서 일일 퀘스트 카드를 최소 104px로 유지하고 필요한 경우에만 본문을 스크롤한다. 수령 버튼의 기존 진행도·날짜·수령 여부 판정은 변경하지 않았다.
- 룬 탭 위 16px 행에 실제 착용 무기를 표시한다. 선택 중인 보드와 구분하며 기존 탭·이름 크기는 유지한다. 세로 보드의 무대 높이가 16px 줄고 창 전체 높이는 그대로다. 장비 변경 저장은 배지만 갱신하고 룬 편집본을 다시 불러오지 않는다. 무관한 저장은 다시 그리지 않는다.

- 세부 검사: 기존 추천 설정과 수업의 수동 선택/저장, 취소, 실패 시 편집본 보존; 실제 구매 버튼 뒤 목록 제거와 소지품 유지; 한·영 착용 배지의 독립 선택 및 저장 후 룬 편집본/카메라 보존; 지도 외곽/안쪽 대비와 동일 탐색 좌표 및 시뮬레이션 불변.
