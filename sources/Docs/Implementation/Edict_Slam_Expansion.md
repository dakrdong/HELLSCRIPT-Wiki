# 전사 지면 강타 사냥 칙령 연결

작성일: 2026-09-13 · [English](Edict_Slam_Expansion.en.md)

상태: **W04 핵심 옵션 4개의 연결을 마쳤다. 전체 검사 1,903개와 최종 macOS 앱의 실행·재시작 3회가 통과했다.**

## 개발 범위

[전사 공격 연결](Edict_Warrior_Attacks_Expansion.md)의 `f6f80ab`에서 이어서 W04 지면 강타의 핵심 옵션 4개를 독립 전투 판단에 연결한다. [스킬별 옵션 기획](../Design/HELLSCRIPT_Hunt_Edict_Skill_Option_Catalog.md)의 일반 적·기존 제어·보스 사용 조건과 [화면 배치 상세안](../Design/HELLSCRIPT_Screen_Layout_Detail.md)을 따른다.

클로드의 능력치·접사·밸런스 기록은 메인에 유지된다. [통합 기록](Attribute_Integration_Expansion.md)에 병합 커밋과 후속 검토를 보존했으며, 사용자의 요청으로 병합이 끝난 작업 브랜치를 로컬·원격에서 정리했다. 이후 작업은 `main`에서 진행한다.

## 실제 전투 판단

| 설정 | 연결한 동작 |
|---|---|
| 자동 사용 | 꺼져 있으면 일반 공격과 지정 생존 수단에서 모두 사용하지 않는다. 예전 규칙이 없거나 꺼져 있거나 중복되어도 켜진 핵심 설정은 한 번만 판단한다. 원래 규칙은 그대로 보존한다. |
| 일반 적에게 쓸 때 | 무리 처리는 실제 3m 안에 일반·정예 적이 2명 이상 있어야 한다. 위험 시전 방해는 범위 안에서 진행 중인 위험 시전을 확인한다. 후퇴 보조는 전역의 긴급·회피 요청과 새 제어 기회를 함께 확인한다. |
| 이미 제어된 적 | 피해용은 제어 상태로 제한하지 않는다. 새 제어는 기절·빙결이 없는 적을, 만료 직전은 두 상태 중 더 오래 남은 시간이 0.35초 이하인 적을 요구한다. 보스에게 이 조건을 적용하지 않는다. |
| 보스 사용 방식 | 피해용은 제압·면역 중에도 사용할 수 있다. 제압 누적은 제압·면역이 끝난 상태를 요구한다. 완성 시점은 현재 게이지에 기존 15점을 더해 100을 채울 수 있어야 한다. 일반 적을 위한 사용 기회는 별도로 판단한다. |

판단 조건은 시전 여부를 정한다. 실제로 시전한 강타는 기존 3m 범위 전체에 피해와 제어를 적용하며, 사용 조건에서 제외한 보스를 실제 피해 대상에서 지우지 않는다. 벽·시야·감지·추적 제외 상태를 확인하고, 먼 우선 대상 때문에 가까운 유효 무리를 놓치지 않는다.

위험 시전이 진행 중이라고 즉시 방해 성공으로 기록하지 않는다. 강타 준비 중 적의 시전이 끝나면 장판이 먼저 생길 수 있고, 그 뒤 적중한 강타는 이미 생성된 장판을 없애지 않는다. 반대로 준비가 긴 적은 실제 강타 적중 후 기절하면서 시전이 중단된다. 적이 범위를 벗어나면 실제 빗나감을 기록한다.

## 생존 순서·행동·저장

전역에서 지면 강타를 생존 수단으로 지정해도 일반 적·보스 설정을 지킨다. 생존 제어 후보는 이번 적중으로 새 제어 또는 보스 제압 완성이 가능해야 한다. 먼저 선택된 긴급 도약·보행을 강타 준비 때문에 미루지 않는다.

일반 무리 처리나 보스 피해만을 위해 진행 중인 공격을 취소하지 않는다. 일반 적의 실제 위험 시전·후퇴 보조 기회에서만 전역 중단 허용을 확인하며, 체공·회복 구간의 잠금은 유지한다. 보스 단독 상황이 일반 적의 방해 설정을 빌려 다른 공격을 취소하지 못하도록 제한했다.

기본 비용 **0**, 준비 **0.35초**, 재사용 대기시간 **10초**, 피해 계수 **1.2**, 일반 적 기절 **1.5초**를 유지한다. 자원이 0이어도 사용할 수 있고, 유료 스킬용 LC02 할인을 소비하지 않는다. 보스는 직접 기절하지 않으며 기존 제압 누적·3초 제압·면역을 사용한다. 이미 시작한 준비는 설정을 바꾸거나 앱을 재시작해도 한 번만 완료한다. 피해·제어·할인 상태를 중복 적용하지 않는다.
