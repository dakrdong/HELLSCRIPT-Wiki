# HELLSCRIPT 사냥 칙령 개편 HTML 시안

작성일: 2026-10-04 · 상태: 시안 1차 (Unity 코드 미변경)

[시안 열기](HELLSCRIPT-HuntEdict.html) · [원본 파일 해시](source-manifest.json) · 빌드 `node build.cjs` · 검사 `node browser.test.cjs`(52개)

## 목표

기존 기능(전역 옵션 152개·스킬 트리·프리셋·공유)을 모두 담으면서, 처음 보는 플레이어가 한 번에 이해하고, 튜토리얼과 균열 진행에 따라 기능이 하나씩 열리는 구조에 맞는 화면이다.

## 핵심 구조

1. **탭 10개 → 5개.** 개요 / 스킬 / 전투 / 자동 관리 / 프리셋. 전투 탭은 기존 전투+생존을 "어디서 싸울까 → 누구를 칠까 → 어떻게 버틸까" 순서로 묶고, 자동 관리 탭은 전리품·탐색·가방·자동 장착·반복을 소분류 탭으로 묶는다. 세로 화면은 5개가 한 줄에 들어간다.
2. **판단 카드 한 가지 패턴.** 모든 설정은 `질문 → 현재 답 → 한 줄 설명` 카드이며 누르면 간편 설정 시트(라디오)가 열린다. 시트 맨 아래 「직접 설정」은 균열 6부터 보인다. 바꾼 카드는 왼쪽 금색 막대로 표시한다.
3. **개요는 읽는 화면.** 현재 싸우는 방식 요약, 전투 성향 3종(균열 2), 지난 사냥 조언, 장착 스킬, 자동 관리 요약, 다음에 열릴 기능 한 가지.
4. **단계별 공개.** 미공개 탭·카드는 잠금 자리 없이 아예 보이지 않고, 개요에 「다음에 열림」 한 줄과 진행 막대만 둔다. 새로 열리면 개요 위에 「새로 열림」 띠가 뜨고 `설정해 보기`는 해당 탭의 카드를 맥동 링과 안내 말풍선으로 짚는다. `나중에`는 막지 않는다. 미확인 탭에는 금색 점을 붙인다.
5. **강제 튜토리얼 단계(프롤로그).** 지정한 버튼만 남기고 화면을 어둡게 덮는 가림막, 맥동 테두리, 「칙령의 목소리」 말풍선. 1단계는 스킬 배우기→장착→사용 방식→저장 4칸 진행 표시, 2단계는 물약 HP 기준 한 카드만 보인다.

## 시안 사용법

상단 도구줄에서 화면(가로 956×440 / 세로 440×956 / PC 1600×900), 언어, **공개 단계**(프롤로그 ①②부터 균열 20까지 17단계), 튜토리얼 안내선 ON/OFF를 바꾼다. 저장·되돌리기·간편 설정 적용·스킬 배우기와 장착은 화면 안에서 실제로 동작한다.

## 데이터 출처와 시연 값

- 간편 설정 이름·설명(한/영), 전투 성향 구성, 전사 스킬 37개와 아이콘, 칙령 글리프, 색은 게임 파일(`HuntEdictQuickPresets.json`, `Prototypes/SkillTree/catalog.json`, `UiTheme.cs`)에서 빌드가 읽는다.
- 공개 단계 표는 `HuntEdictProgression.json`을 옮겼다. 균열 14·12의 전설/세트 비교, 영약 등 일부는 단순화했다.
- **시연 값:** 성향 카드의 속도/안전 눈금, 지난 사냥 조언 내용, 프리셋 슬롯 이름, 영웅 레벨 곡선, 직접 설정의 세부 옵션 예시.

## 검증과 한계

- `browser.test.cjs`: 프롤로그 4단계·2단계 흐름, 단계별 탭과 전투 카드 수(1→3→5→7→9→10), 새로 열림→설정해 보기 초점, 간편 설정 적용·되돌리기, 성향 일괄 적용, 3개 화면×2개 언어×5개 탭 가로 넘침 없음 52개 통과(macOS 헤드리스 크롬).
- 미검증: 실제 터치 기기, 사파리·파이어폭스, 스크린 리더, 사람 대상 이해도. 스킬 트리는 기존 트리 시안의 배치를 그대로 쓰며 이번 개편 대상이 아니다.
- Unity 이식 시 `HuntEdictProgression.Tab`이 5개 탭 기준으로 바뀌어야 하며, 기존 스모크가 가정한 탭 이름(`combat`/`survival`/`loot` 등)을 함께 바꿔야 한다.
