# 룬 마스터

작성일: 2026-09-21 · [English](Rune_Master.en.md)

## NPC와 화면

마을 남동쪽의 룬 상인 옆에 별도의 룬 마스터를 배치한다. 가까이 가서 **룬 공방 열기**를 누르면 창이 열리며, 접근만으로 열리지는 않는다. 창을 연 동안 마을 이동은 차단된다.

기존 상점·창고의 올리브 바탕, 황동 테두리, 글꼴과 버튼을 재사용한다. 룬은 기존 `RuneBoardGraphic`으로 그리며 실제 색상과 모양을 표시한다. 가로 화면은 작업 공간 왼쪽·룬 보관함 오른쪽, 세로 화면은 작업 공간 위·보관함 아래다. 보관함은 항상 정사각형 슬롯 8열이며 세로로 스크롤한다. 긴 블록도 아이콘 영역 안에 맞춰 축소한다.

## 룬 재형성

재료는 **같은 색·모양·등급의 서로 다른 룬 두 개**다. 칸 수가 3 이상이어야 하며, 보드에 배치했거나 프리셋에 저장한 룬과 미수령 결과는 소모하지 않는다. 보관함에서 룬을 누르거나 두 재료 슬롯 중 하나로 끌면 조건에 맞는 두 번째 룬이 자동 등록된다. 등록·해제·창 닫기는 보유 데이터를 바꾸지 않는다.

짝이 없으면 다음 문구를 표시한다.

> 모양을 바꾸기 위해서는 똑같은 색, 똑같은 모양의 룬 블럭이 하나 더 필요합니다

색·모양은 같지만 등급만 다른 경우에는 같은 등급이 필요하다고 안내한다. **합성**을 누르면 두 재료를 제거하고 같은 색·칸 수·등급의 다른 모양 한 개를 보관함에 넣는다. 회전만 다른 동일 형상도 결과에서 제외한다. 추가 재화는 소모하지 않는다.

저장이 완료되면 두 블록이 가운데로 모여 짧게 빛나는 연출을 재생하고 결과를 표시한다. 연출 중 중복 합성을 차단하며, 연출 도중 창을 닫아도 이미 저장한 결과는 남는다.

## 데이터와 저장 경계

기존 `AccountSave.runes.owned`의 실제 룬 인스턴스를 사용한다. 화면의 재료 선택은 임시 상태이며, `GameStore.ReshapeRunes`가 보유 리비전·소유권·보호 상태·짝 조건을 다시 검사한다. 계정 사본에 변경을 적용해 저장한 다음 라이브 상태를 교체한다. 저장 실패 시 재료와 디스크 데이터는 그대로이며 같은 요청으로 재시도할 수 있다. 거래 식별자로 중복 요청을 방지한다.

현재 프로젝트의 권위 있는 저장 경계는 로컬 `GameStore`다. 원격 서버 통신이나 계정 서버를 추가하지 않았다. 별도 룬 복제 목록이나 소유권 저장소를 만들지 않는다.

## 룬 승급

등급은 `RuneEconomy.Bands`에서 읽으며 현재 G0~G6이다. 각 등급 버튼은 모든 크기·모양을 합친 보관 수량을 표시한다. 오른쪽에는 선택한 등급의 재료 후보를 **등급·색·모양별 묶음**으로 표시하며, 2개 이상은 수량을 황동색으로 강조한다. 잠금·보드 배치·프리셋 사용·미수령·최종 단계 룬은 후보에서 제외한다.

룬 묶음을 누를 때마다 실제 인스턴스 한 개를 칸 수별 작업 그룹에 등록한다. 등록한 작은 실루엣을 누르면 해제한다. 등급 또는 탭을 바꾸면 임시 선택은 정리하지만 저장된 미수령 결과는 보존한다.

합성 조건은 같은 등급 안에서 **칸 수별·색상별로 모두 짝수**이며, 모양은 달라도 된다. 1~4칸 두 개는 같은 등급의 다음 크기 하나, 5칸 두 개는 다음 등급 1칸 하나가 된다. G6 5칸은 최종 단계다. 능력 색은 등급과 독립되어 있으므로 결과에도 재료 색을 유지한다. 결과 모양은 해당 크기의 실제 카탈로그에서 거래 ID를 시드로 결정한다. 한 요청은 최대 100쌍이며 실패와 수수료는 없다.

각 그룹의 **그룹 합성**은 해당 그룹만 검사한다. **한번에 조합하기**는 선택이 있는 모든 그룹이 유효해야 활성화한다. 비어 있는 그룹은 제외하며, 홀수·색 불일치·미수령 결과가 있는 그룹은 안내 문구와 비활성 버튼으로 표시한다. 전체 검증 뒤 한 거래로 재료를 소모하고 결과를 생성하므로 일부 그룹만 소모되는 경우는 없다.

재료 한 쌍마다 물음표 결과 하나를 미리 표시한다. 합성 성공 후 짧은 압축·빛 연출로 결과를 공개한다. **연출 제거**는 기기 설정으로 저장되며 재형성과 승급 모두에 적용한다. 공개 중 중복 합성·수령을 차단한다. 결과 카드 하나를 누르면 **현재 선택한 원본 등급의 모든 미수령 결과**를 한 번에 수령한다. 다른 등급 결과는 남는다.

미수령 결과는 기존 `OwnedRune.pending/sourceGrade/sourceSize`에 저장하므로 탭 변경·창 닫기·재실행 후 복구된다. `GameStore.AscendRunes`와 `ClaimRuneAscensions`는 거래 영수증과 리비전을 검사한다. 기존 룬 보드 합성 진입도 같은 `RuneAscension` 규칙을 사용한다. 잠금 필드 `OwnedRune.locked`만 하위 호환 방식으로 추가했으며 기존 저장에서는 false로 읽힌다. 저장 버전이나 룬 ID를 변경하지 않는다.

## 재형성 검증

- 관련 Unity Edit Mode 검사 63개가 모두 통과했다. 재형성 규칙, 저장 실패·중복 요청·재접속, 마을 이동과 현지화를 포함한다.
- macOS 개발 빌드가 오류 없이 완료되었고 실제 uGUI 레이캐스트·포인터 이벤트 기반 검증이 통과했다. NPC 접근·명시적 진입, 양쪽 슬롯 드래그, 빈 곳 드롭 취소, 오류 안내, 8열, 합성 중 중복 입력 차단, 실제 소모와 지급, 창 닫기·재접속을 확인했다.
- 1600×900 / 1920×1080 PC, iPhone 17 Pro Max 예시 비율인 440×956 / 956×440 창에서 한국어·영어를 확인했다. 모바일 실기기 터치·노치·성능 검증은 수행하지 않았다.

## 승급과 최종 통합 검증

최종 관련 Edit Mode 검사 **186개가 모두 통과**했다. 모든 등급·칸 수·색의 성장 규칙, 여러 그룹의 원자적 처리, 홀수·색·등급·크기 불일치, 중복 인스턴스, 보호 상태, 최대 단계, 미수령 차단, 100쌍 상한, 저장 실패·중복 요청·재접속을 검사했다. 기존 룬·장비 상점·갬블 상점·창고·마을·현지화 검사도 포함한다.

macOS 개발 빌드는 오류 없이 완료되었다. 실제 UI를 대상으로 클릭 51회와 드래그 5회를 수행한 실행 검증이 통과했다. 모의 터치 포인터로 세로 화면 드래그도 확인했다. 재형성·승급 왕복 중 삭제된 스크롤 영역을 참조하던 문제를 수정한 뒤 전체 실행 검증을 다시 통과했다. 그룹 합성·전체 합성·물음표 미리보기·공개 중 입력 차단·연출 제거·등급 전환·창 닫기·미수령 복구·결과 하나를 통한 전체 수령·상점과 창고 복귀를 확인했다.
