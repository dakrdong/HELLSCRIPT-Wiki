# 퍼즐 튜토리얼 — 몬스터 고유 패턴 원칙 (2026-10-08)

English: [Native monster patterns](Puzzle_Tutorial_Native_Patterns.en.md)

사용자 결정: 레벨의 답을 만들려고 **몬스터의 공격 패턴을 바꾸지 않는다.** 바꿀 수 있는 것은 몬스터 레벨(수치)·체력·피해량·마릿수·등장 시각뿐이다. 이전 구현은 예고 시간 0.1초, 재공격 300초, 이동 속도 0, 열두 마리에 체력 1000 같은 값으로 승패를 맞췄고, 사용자가 "한 번 공격하고 다시는 공격을 안 해서 없어 보인다"고 지적했다. 이전 레벨 설계 기록(퍼즐 코어·콘텐츠·운영·졸업 문서)은 당시 구현의 기록으로 남기고, 현재 구성은 이 문서가 기준이다.

## 제거한 수단

| 수단 | 이전 | 지금 |
| --- | --- | --- |
| 예고 시간 덮어쓰기 `preparation` | L2·L3·L4·L5·L10·L12~L15 | 필드 삭제, 몬스터 고유 예고 |
| 재공격 대기 덮어쓰기 `repeatCooldown` | L3·L4·L5·L6·L10·L12~L15 (L3은 300초) | 필드 삭제, 고유 쿨타임 |
| 첫 공격 대기 `cooldown`·`cooldownOffset` | 전 레벨 | 필드 삭제, 일반 균열 생성과 같은 추첨 |
| 이동 속도 `speed` | L4 1, L6 0(제자리), L14 0.5 등 | 필드 삭제, 몬스터 고유 속도 |
| 테스트 안의 예고 주입 | `PuzzleLevelTests` 프로토타입 | 파일 삭제, 실제 레벨 검사로 대체 |

남긴 것: `kind`, `count`, `elite`, `boss`, `afterClear`, `pauseBefore`, `at`, `position`, `offset`, `health`, `attack`(`attackMaxHp`). 시작 칙령 상태(`start`·`presets`)는 레벨이 정하는 영웅 쪽 조건이라 몬스터 패턴이 아니다.

## 레벨별 현재 설계

각 레벨은 한 가지를 배우고, 시작 상태에서는 실제로 지거나 시간 초과가 나며, 정답을 저장하면 실제로 이긴다. 수치는 `PuzzleTutorial.json`, 결과는 EditMode 시뮬(시드 77123)이다.

| 레벨 | 배우는 것 | 시작 상태에서 실패하는 이유 | 정답 |
| --- | --- | --- | --- |
| 1 | 첫 스킬 익히고 장착 | (스킬 없이는 도전 불가) | 스킬 장착 후 사냥개 4마리 처치 |
| 2 | 큰 공격 회피 | 모래벌레가 예고 뒤 발밑을 한 방(최대 HP 130%)으로 때린다. 회피를 끄면 3~8초에 사망 | `모든 예고 회피` (세 직업 무피해) |
| 3 | 자동 물약 켜기 | 시작 칙령에 물약이 꺼져 있고 회피·후퇴도 꺼져 있다. 약탈자 6마리의 공격이 그대로 들어와 사망 | `자동 물약` 아무 설정(`넉넉한 생존 보급` 권장) |
| 4 | 몰아붙이는 성향 | 시작이 `신중`이라 약한 시체 14마리의 작은 공격까지 피하느라 60초 시간 초과 | `공격적`(또는 `균형`) |
| 5 | 물러서기 | 후퇴가 꺼져 있어 느리지만 강한 철갑 망령 네 마리와 맞서다 사망 | `생존 우선` + `보행 후퇴` (다른 후퇴 설정도 클리어) |
| 6 | 위험한 적 우선 | 가까운 시체만 베는 동안 멀리서 궁수 둘이 쏘아 사망(전사·궁수) | `위험한 적 우선` |
| 7 | 회피기 장착 | 사술사의 `인력 붕괴`는 걸어서 못 벗어나고 폭발에 사망 | `지정 회피기`(직업 이동기) |
| 8 | 스킬 사용 방식 | 무리를 기다리는 조건은 적이 하나 남으면 나가지 않아 시간 초과 | 단일·강적용 사용 방식 |
| 9 | 장비 거르기 | 모든 장비 회수는 가방을 채우고, 먼 회수는 위험 구역을 밟는다 | `희귀 이상 회수` + `가까운 것만 빠르게` |
| 10 | 저주 상자 | 체력 50%에서 바로 열면 잔향 4마리를 12초 안에 못 잡는다. 열지 않으면 목표 미달 | `여유 있을 때 도전` |
| 11 | 가방 정리 | 귀환·방치·모두 보관은 목표(금화 80, 빈칸 1)를 못 채운다 | 교체 + 일반·마법 판매 + 투자 보호 |
| 12 | 장비 추천 착용 | 끄면 낮은 무기로 45초 안에 정예를 못 잡는다 | 추천 착용 켬 + 같은 무기 계열 |
| 13 | 반복 사냥 | 한 판 종료·같은 단계 반복·실패 단계 고정은 목표 금화 미달 | 성공 후 다음 단계, 실패 후 한 단계 아래 |
| 14 | 장비 강화 | 피하지 못하는 묵직한 근접 공격을 방어력 없이 받아 사망(회피·후퇴·물약은 꺼진 시작 상태) | 첫 패배 뒤 열린 대장간에서 방어구를 `최대 강화`(+15 이상 필요, 시험 금화로 +30까지) |
| 15 | 위험의 세 얼굴 | 장판·원거리 직격·즉발 범위 중 하나라도 끄면 사망 | 세 분류 `항상 회피` + 취소 허용 |
| 16 | 졸업 | 설정 없이는 보스전에서 사망 | 앞선 설정과 단단해진 갑옷 |

## 직업별 예외와 확인된 한계

- **마법사 L6:** 화염구는 같은 값이면 대상 지정보다 폭발 효율을 먼저 보므로, 마법사는 `가까운 적부터`로도 클리어한다. 전사·궁수는 `위험한 적 우선`이어야 한다.
- **전사 L15:** 즉발 범위만 꺼도 걸으면서 피하는 경우가 있어, 전사의 벌레 체력을 1400으로 높여 벌레와 오래 싸우게 했다. 그러면 즉발 범위를 꺼도 사망한다(경계가 좁아 수치를 바꿀 때 다시 확인한다).
- **L15 허용 풀이:** 전사·마법사는 `공격 유지 우선`과 `공격 마무리` 조합도 클리어한다(궁수는 석궁 피해가 커서 사망한다). 장판은 피하고 큰 피해만 피해도 몬스터 고유 패턴에서는 이긴다.
- **L5 후퇴:** `위급할 때만 후퇴`·`균형 생존`도 클리어한다. 막는 것은 후퇴를 끈 상태다.
- **`큰 피해 위주 회피`:** L2 모래벌레의 한 방(최대 HP 98%)을 궁수·마법사는 이 설정으로 피하지 못하고 사망한다(`모든 예고 회피`는 피한다). 게임 쪽 회피 판정의 의문점으로 기록하고 이 작업에서는 고치지 않았다.

## 몬스터 고유 AI에서 확인한 함정

- 영웅은 예고된 공격을 스스로 피한다. 피해가 필요한 레벨(L3·L5·L6·L10)은 시작 상태에서 회피를 꺼 둔다.
- 제자리 전사(도달 2m)는 8m 사거리의 궁수·돌격병·석궁병을 잡지 못한다. 적을 영웅 가까이에 두거나 도달 가능한 종류만 쓴다.
- 광신 돌격병은 돌격 뒤 물러서 있어 제자리 전사와 교전이 끝나지 않는다(L3에서 제외).
- 사제의 치유 반경 3m와 사제의 접근 거리 6m, 광역 스킬이 사제를 함께 맞히는 점 때문에 치유자 우선 레벨은 직업마다 결과가 갈려 쓰지 않는다.
- 영웅의 한 대상 공격력은 낮아(약 20~40/초) 단일 몹의 체력을 크게 올리면 전사가 시간 안에 못 잡는다.

## 장비 강화 레벨 (L14)

사용자가 말한 "방어력을 높여야 버틸 수 있는 난이도를 장비 강화로 푼다"를 열여섯 번째 레벨로 넣었다. 대기실 하단 메뉴의 `대장간`(PR #78)을 그대로 쓰며 별도 정비 창은 없다.

- **흐름:** L14는 회피·후퇴가 꺼진 시작 상태에서 시작한다. 첫 시도는 철갑 망령 네 마리의 묵직한 근접 공격에 사망한다. 첫 패배가 기록되면 대장간의 `장비 강화`만 열리고(`ContentUnlocks.Has`가 `PuzzleTutorial.ForgeOpen`을 확인, 계정에 해금을 쓰지 않는다) 시험 금화 8,100이 지급된다. 방어구를 강화하고 다시 도전해 이기면 쓰지 않은 금화는 거두고(`forgeBaseGold`로 복원) 강화한 방어구는 영웅에게 남으며 대장간은 다시 닫힌다. 복습은 시작 영웅에 새 시험 금화를 준다.
- **수치(방어력과 피해만):** 영웅이 입는 방어구 한 벌의 강화 1단계는 방어 +3이다. 시작 방어는 전사 192·궁수/마법사 56이고 받는 피해는 방어/(방어+110)로 줄어든다. 철갑 망령의 피해를 전사 0.275·궁수/마법사 0.42(최대 HP 비율)로 정하면 강화 없이는 사망하고 +10까지도 사망하며 +15부터 이긴다. 시험 금화 8,100은 +30까지 닿아 `최대 강화` 한 번으로 남는 체력이 전사 12%·궁수 27%·마법사 27%이다. 방어구 레벨 1의 누적 비용은 +10 1,429·+20 3,931·+30 8,055이다.
- **정비 P2 제거:** 시험 금화 110으로 무기를 +1 강화하던 비전투 정비(L12 전)는 이 레벨이 대신한다. 저항 장비 비교 P1(L10 전)은 그대로다.
- **번호 이동:** 위험의 세 얼굴이 L15, 졸업 시험이 L16이 됐다. 강화한 방어구는 이후 레벨에도 남으므로 L15·L16의 수치를 다시 맞췄다.
- **힌트:** 사령관이 대신 써 줄 칙령이 없어 `puzzle-hint`는 4단계 힌트에서 끝나고 설정 대행은 없다.

## 검증과 도구

- 확인 도구: `PuzzleContentTests.Probe`(L1~L8)와 `PuzzleOperationTests.ProbeOperations`(L10·L12~L15)는 `PUZZLE_PROBE_FILE`의 JSON 계획으로 체력·피해·마릿수를 메모리에서만 바꿔 직업별 승패를 찍는다. 환경 변수가 없으면 무시한다.
- 초기 집중 검사(퍼즐·튜토리얼·번역 13개 클래스): 371개 중 363개 통과, 실패 6개는 옛 설계 기대값(L1 영웅 레벨 검사, L14 공격 마무리 조합)이라 수정했다.
- 전체 Edit Mode(장비 강화 레벨까지 반영한 최종 상태): 5652개 중 5648개 통과, 건너뜀 2개(확인 도구). 실패 2개(`MeasureEveryDesignBuild`, `Capture`)는 출력 폴더 환경 변수가 없으면 실패하는 측정·캡처 도구이며 이번 변경과 무관하다.
- macOS 개발 빌드 스모크(`-hellscriptTutorialSmoke`, 1280×720, 일회용 저장 경로, 전사): 16레벨 전부 화면 조작으로 클리어, L2·L7·L14 첫 시도 실제 피해 실패, 첫 패배 뒤 대장간 창에서 방어구 +30 강화, 정비 P1, 졸업과 안톤 첫 인사까지 `HELLSCRIPT_TUTORIAL_RUNTIME_SMOKE_OK`. 한 해상도·한 직업만 확인했다.
- 모바일 실기기는 확인하지 않았다.
