# 신규 일반 적 8종의 고유 공격

작성일: 2026-09-28 · [English](New_Enemy_Attacks.en.md)

필드 4종과 함께 추가했지만 N01의 근접 타격을 빌려 쓰던 N13–N20에 각자의 공격을 넣었다. 모든 공격은 [예고 게이지](Attack_Telegraph_Gauge.md)로 범위와 시점을 보여 주고, [예비 동작과 타격 반응](Enemy_Attack_Feedback.md)을 그대로 쓴다. [다크 고딕 개편](Dark_Gothic_Overhaul_Stage1.md) 2단계의 네 번째 항목이다. 수치는 [균열 필드 6종](../Design/HELLSCRIPT_Rift_Fields.md)과 [콘텐츠 카탈로그 11장](../Design/HELLSCRIPT_Content_Catalog.md#11-일반-적-20종)에 있다.

## 공격

| 적 | 필드 | 공격 |
| --- | --- | --- |
| N13 사구 약탈자 | 작열 사막 | 반경 2.3m·110도 두 번 베기, 0.35초 간격(각 0.6배) |
| N14 모래굴 벌레 | 작열 사막 | 영웅 위치 반경 2.2m를 예고하고 땅속으로 파고들어 분출(1.4배) |
| N15 동굴 식인귀 | 습한 동굴 | 가까이는 휘두르기, 2.5–4.5m에서는 영웅 1m 앞으로 도약해 반경 1.6m(0.9배) |
| N16 포자 부풀이 | 습한 동굴 | 휘두르기, 쓰러지면 반경 2.6m 독 포자 구름 4초(둔화) |
| N17 가시뿔 야수인 | 황혼 초원 | 자신 주변 반경 2.1m 회전 공격(1.1배) |
| N18 가시덤불 마녀 | 황혼 초원 | 길이 9m 가시 창 0.8초 예고 후 솟구침(0.85배, 둔화) |
| N19 서리 망자 | 눈 덮인 고원 | 반경 2.4m·120도 냉기 베기(둔화) |
| N20 빙결 술사 | 눈 덮인 고원 | 영웅이 띠 위에 서는 서리 고리(1.3배, 둔화) |

## 설계에서 바꾼 점

- 가시덤불 마녀의 가시 창은 계획에서 즉시 발동이었지만, 모든 공격을 피할 수 있게 보여 주자는 원칙에 따라 0.8초 예고를 넣었다.
- 빙결 술사의 고리를 영웅 위치에 맞추면 가만히 선 영웅이 고리 가운데의 안전한 곳에 서게 된다. 그래서 고리 중심을 영웅에게서 술사 쪽으로 2.6m 옮겼다. 영웅은 띠 위에 서게 되고, 고리 가운데로 들어가거나 밖으로 벗어나야 피한다.
- 동굴 식인귀가 영웅 위치에 정확히 내려앉으면 영웅과 겹친다. 그래서 영웅 1m 앞에 내려앉게 했다. 1단계 동굴 전투가 과하게 어려워지지 않도록 도약을 0.9배, CD 5초로 맞췄다.
- 근접 슬롯(N13·N15·N17·N19)은 N01과 같은 초당 피해를 유지하도록 CD를 맞췄다. 사구 약탈자 1.8초, 가시뿔 야수인 1.65초, 서리 망자 1.6초이며, 동굴 식인귀의 휘두르기는 N01과 같다.

## 1단계 전투에 미치는 영향

1단계의 습한 동굴과 황혼 초원은 동굴 식인귀와 가시뿔 야수인이 주력이다. 1단계 30초 전투 기록 8개 시드에서 잊힌 묘지 3개는 그대로였다. 황혼 초원 3개는 영웅 체력이 조금 더 남았다(372.6→388.2, 369.4→388.2, 353.9→365.0). 습한 동굴 2개는 영웅 체력이 약 9% 적게 남았다(338.8→307.1, 360.8→328.1). 처치 수는 19→18, 21→17로 줄었다. 영웅이 새 도약 예고를 피하느라 공격할 시간이 줄어든 영향으로 보인다. 이 값은 `FieldTests`의 기록에 반영했다.

## 검증

2026-09-28, 복제 프로젝트와 macOS 개발 빌드에서 확인했다.

- **Edit Mode 전체 검사**: 4,589개 중 4,542개 통과. 실패 47개는 모두 개편 전 기준선에 있던 것이며 새 실패는 없다. [요약](NewEnemyAttacksEvidence/editmode-full-summary.txt)
- **`NewEnemyAttackTests`**:
  - 새 적마다 자기 모양의 예고를 보여 주고, 예측과 실제 피해가 같다.
  - 사구 약탈자는 0.35초 간격으로 두 번 벤다.
  - 모래굴 벌레는 영웅이 있던 곳으로 파고들어 도착 순간 분출한다.
  - 동굴 식인귀는 3.5m에서 도약하고 1.8m에서 휘두른다.
  - 포자 부풀이의 구름은 틱마다 피해를 주고 둔화시킨다.
  - 마녀·서리 망자·빙결 술사는 둔화를 건다.
  - 근접 슬롯의 초당 피해는 N01의 ±15% 안이다.
- **기존 검사**:
  - N13–N20 전부가 `EnemyTests`의 준비·재사용 대기, `IncomingForecastTests`의 예측과 실제 피해 일치, `TelegraphGaugeTests`의 게이지 완료 시점(땅속 이동과 도약은 도착 순간)을 통과했다.
  - `FieldTests`는 동굴·초원 시드의 기록을 새로 받았고, 묘지 시드는 그대로다. [기록](NewEnemyAttacksEvidence/stage1-fight-record.txt)
- **`-hellscriptNewEnemySmoke` 통과**: 실제 게임에서 8종 모두 예고 안에 선 영웅을 자기 공격으로 맞혔고, 포자 구름이 틱마다 피해를 주며 둔화시켰다. [결과](NewEnemyAttacksEvidence/runtime-new-enemy-smoke.txt)
  - 캡처(준비·공격 직후): [사구 약탈자](NewEnemyAttacksEvidence/n13-dune-marauder.png), [모래굴 벌레](NewEnemyAttacksEvidence/n14-burrowing-sandworm.png), [동굴 식인귀](NewEnemyAttacksEvidence/n15-cave-ghoul.png), [포자 구름](NewEnemyAttacksEvidence/n16-sporebloat-death-cloud.png), [가시뿔 야수인](NewEnemyAttacksEvidence/n17-thornhorn-brute.png), [가시덤불 마녀](NewEnemyAttacksEvidence/n18-briar-witch.png), [서리 망자](NewEnemyAttacksEvidence/n19-frostbitten-revenant.png), [빙결 술사](NewEnemyAttacksEvidence/n20-rime-caller.png)
- **예고 게이지·공격 이펙트·보스 패턴 스모크**도 같은 빌드에서 통과했다. 게이지 스모크는 캡처 직후 느린 프레임 때문에 한 번 예고 단계를 건너뛴 적이 있다. 이제는 그런 경우를 실패로 끝내지 않고 결과 파일에 적는다.

## 확인하지 못한 것

- 실기기와 Android 빌드에서 보지 않았다.
- N08–N20의 전용 모델과 효과음은 아직 없다. 몸은 기본 도형이고 소리는 없다.
- 가시덤불 마녀는 계획의 "6m 거리 유지" 대신 다른 원거리 적처럼 사거리(9m)까지 다가온다.
- 1단계 동굴 전투에서 처치 수가 줄어든 원인은 추정이다. 실제 플레이 난이도는 따로 재지 않았다.
- 사람의 눈으로 한 품질 평가가 아니다.
