# 스킬 사용 옵션 비교 실험

같은 빌드에서 사용 규칙만 바꾼 전투 18건입니다. 전사 BUILD_SWB는 도약의 현재 거리 활용·거리 확보를 비교하고, 마법사 BUILD_REF_SM05는 제자리·후퇴 충전과 마나 50%·90% 종료를 비교합니다. 모든 경우는 40레벨·스킬 1등급·장비 30레벨·동일 난수 시드 9137·60초입니다. 옵션 외의 장비·투자·적 조건은 상황별로 같습니다. 이 마법사 빌드는 고요한 균열을 사용하지 않으므로 종료 목표는 마나 비율만 적용됩니다. 해당 장비와 결계가 있을 때 1.5초까지 준비하는 선택은 별도 능력 검사에서 다룹니다.

## 결과 해석

모든 실험에서 캐릭터는 생존했습니다. 통합본에서 도약의 거리 확보는 세 상황 모두 DPS를 높였고, 보스 상황의 증가 폭은 작았습니다. 받은 피해는 세 상황 모두 줄었습니다. 후퇴하는 동안 다른 공격을 멈추는 비용이 있으므로, 좁은 길·빠른 추격·짧은 전투 조건은 추가로 비교해야 합니다.

제자리 충전은 같은 종료 목표의 후퇴 충전보다 DPS가 높았습니다. 후퇴 충전은 대체로 받은 피해가 적었지만, 보스 상황의 90% 목표에서는 두 방식이 거의 같았습니다. 적 8명을 상대할 때 후퇴 충전도 실제로 시작되었습니다. 충전 시간은 50% 목표에서 0.40초, 90% 목표에서 0.90초였습니다. 이전 개별 브랜치의 충전 0초 결과를 통합본에 적용하지 않습니다.

마나 90% 종료는 제자리 충전과 후퇴 충전 모두 세 상황에서 DPS를 높였지만 받은 피해도 함께 늘렸습니다. 따라서 항상 더 나은 선택은 아닙니다. 이 결과는 통제된 조건의 관찰이며 보편적인 최적 빌드나 완성된 밸런스 결론이 아닙니다.

거리 확보 이동량은 의도적으로 물러난 거리만 셉니다. 충전 시간은 실제 집중 중인 시간이고 회복 마나는 최대치에서 잘린 뒤의 실제 증가량입니다. 스킬별 보류 시간은 겹칠 수 있습니다. 전체 이동량·총 피해·체력·궁극기 및 다른 스킬의 시전 횟수도 원본 JSON에서 확인할 수 있습니다.
