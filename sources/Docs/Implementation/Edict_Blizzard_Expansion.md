# 눈보라 사냥 칙령 개발 기록

작성일: 2026-09-13 · [English](Edict_Blizzard_Expansion.en.md)

상태: **M02의 다섯 핵심 옵션 연결, 전체 검사와 새 macOS 앱 실행·재시작 검증을 완료했다.**

## 해결한 문제

눈보라 카드의 선택값은 저장되지만, 실제 설치는 이전 자동 행동의 조건과 장판 이동 설정을 따르고 있었다. 이제 사냥 칙령을 켜고 M02를 장착하면 저장된 옵션에서 실행 판단을 만든다. 이전 눈보라 규칙이 없거나 꺼져 있거나 조건을 만족하지 않아도 새 설정으로 판단한다. 중복 규칙은 실행 후보 하나로 합치며 기존 규칙 목록은 수정하지 않는다. 사냥 칙령을 끄면 이전 규칙을 사용한다.

화염구와 눈보라는 공통 공격 순서를 따른다. 판단 기록에는 각각의 스킬 이름을 표시한다. 해금, 실제 비용, 쿨타임과 행동 잠금은 기존 실행 검사를 통과해야 하며, 전역 생존 대응이 주 행동을 차지한 회차에는 설치하지 않는다.

## 전투에 연결한 다섯 옵션

| 옵션 | 실제 처리 |
|---|---|
| 자동 사용 | OFF이면 새 설치를 검토하지 않는다. 이미 지불한 준비 동작과 생성된 장판의 남은 수명은 유지한다. |
| 사용 방식 | NEW_AREA는 후보가 기존 자기 눈보라 밖의 적을 한 명 이상 덮어야 한다. GROUP은 예상 대상 세 명 이상과 기존 영역 밖의 대상 한 명 이상이 필요하다. KEEP_TARGET은 후보가 현재 대상을 덮고, 그 대상을 덮는 기존 장판의 **가장 긴 남은 수명**이 1초 이하여야 한다. 대상이 기존 영역 밖이면 남은 시간을 0으로 판단한다. |
| 설치 위치 | TARGET은 전역에서 선택한 적의 현재 위치, SELF는 자신의 현재 위치를 쓴다. DENSE는 설치 목적을 만족하는 유효 후보 중 감지한 적을 가장 많이 덮는 위치를 고른다. PATH는 최근 관측 속도로 0.75초 뒤의 위치를 계산하고 지형에서 이동을 제한한다. 정보가 없거나 0.4초보다 오래됐거나 미래 시각·유효하지 않은 속도·이동 불가 상태이면 현재 위치로 대체한다. |
| 두 장판이 남아 있을 때 | KEEP은 유효한 자기 눈보라 두 개가 남으면 설치를 보류한다. REPLACE는 설치 목적과 실행 검사를 통과한 시전이 완료될 때 가장 오래된 자기 장판만 교체한다. 외부 소유자의 장판은 제거하지 않는다. |
| 장판 이동 | FIXED는 생성 위치를 유지한다. FOLLOW는 LM01이 있을 때 현재 감지한 공격 대상을 초당 1m, 총 4m까지 따라간다. LM01이 없으면 고정 장판을 만들며 저장된 FOLLOW 선택은 보존한다. 시전 시작 때 이동 설정을 보관하므로 이후 수정·OFF·저장 복원이 진행 중인 시전이나 기존 장판의 이동 방식을 바꾸지 않는다. |

현재 유효한 자기 장판만 기존 영역으로 취급한다. 적대 장판, 다른 소유자의 장판, 만료된 장판과 아직 시작하지 않은 영역은 현재 대상을 덮는 것으로 세지 않는다. 생성된 뒤 활성화를 기다리는 자기 장판은 두 개 보존 제한에는 포함한다. 옛 저장의 비어 있는 소유자는 기존 처리대로 자기 장판으로 해석한다.

DENSE는 적의 중심, 두 적의 중간점, 반경 3m 원의 교점, 사거리 경계와 가까운 쪽의 대체 위치를 비교한다. 삼각형으로 떨어진 세 적이나 중심이 사거리 밖에 있는 적도 덮을 수 있다. 모든 후보는 실제 10m 사거리, 설치 가능한 지형과 시야를 검사한다. 감지하지 못하거나 죽었거나 전역 추적에서 제외된 적을 인원에 더하지 않는다. 설치 예측은 현재 관측한 배치에 대한 판단이며, 이후 적의 이동까지 적중으로 보장하지 않는다.

겹친 눈보라의 피해는 기존 실행 코드에서 강한 값 하나만 적용한다. MP02 둔화, SM 2세트 비용, SM 4세트 노출과 LC02 할인은 기존 효과를 사용한다. 눈보라는 화염구를 기다리지 않으며, 눈보라가 만든 자기 노출을 화염구가 실제 적중 때 소비하는 연결도 검사한다. 피해 수치와 접사 가중치는 변경하지 않았다.

## 화면과 저장

눈보라 카드에 다섯 설정의 적용 범위와 새 장판부터 이동 설정이 적용된다는 안내를 추가했다. 한국어 원문과 영어 문구를 함께 제공한다. 판단 기록의 스킬 이름을 확장해 눈보라를 화염구로 표시하지 않도록 했다. [화면 배치 상세안](../Design/HELLSCRIPT_Screen_Layout_Detail.md)의 본문 스크롤, 하단 버튼 접근성, 큰 글자와 작은 가로 화면을 검증 기준으로 삼는다.

저장 스키마, 기존 규칙 목록, 장판 소유자와 식별자, 씬·프리팹·패키지는 유지한다. 새 판단의 식별자는 `edict:M02`이며 실행 중 파생하는 값이다. 검사는 별도 프로젝트와 전용 저장 폴더에서 수행한다.

## 검증

첫 집중 검사 245개에 지형·추적·순서의 경계 검사를 추가해 최종 **집중 검사 250개**가 통과했다. 새 M02 검사는 53개다. 기존 영역의 소유자·활성·만료, 1초 유지 경계, 세 명 조건, 설치 지형, 정확한 전역 대상, 관측 이동, 사거리 밖 접근과 OFF, 실제 비용·할인, 시전 및 장판의 저장 복원과 SM4 화염구 연결을 검사했다.

최종 **전체 Edit Mode 검사 1,514개**가 2026-09-12 15:18:44~15:23:32 UTC에 통과했다. 실패·건너뜀은 0개이며 약 287.75초가 걸렸다. 기본 공격으로 전역 대상만 검사하는 기존 구성은 M02 자동 사용도 명시적으로 꺼 격리했다. 조준 단계가 없는 스킬 검사는 이미 연결된 M02 대신 M05를 대상으로 유지했다.

| 실제 macOS 앱 검사 | 결과 |
|---|---|
| 옵션 편집·저장 | 실제 버튼으로 GROUP·SELF·KEEP·FOLLOW를 선택했다. 편집 중 원본은 유지되고, 저장 뒤 메모리와 다시 읽은 파일이 일치했다. |
| 설치 판단 | 대상 한 명에서는 GROUP이 보류됐다. 세 명과 기존 장판 두 개가 있을 때 KEEP은 설치를 막았고, REPLACE로 저장하자 준비를 시작했다. |
| 별도 프로세스 재시작 | 준비 중 FIXED·OFF로 저장해도 기존 장판과 지불한 시전의 FOLLOW 설정·시간·자원을 복원했다. 한 번만 효과를 생성하고 가장 오래된 장판만 제거했으며, 새 추적 장판의 피해와 기존 수명 종료를 확인했다. 추가 시전이나 중복 지불은 없었다. |
| 화면·정지 상태 | 1280×720·720×1280·640×360에서 한국어·영어와 140% 글자를 확인했다. 텍스트 높이·번역 누락·하단 버튼의 안전 영역 검사가 통과했다. 판단 화면의 언어 변경 뒤 실행 중·수동 정지 상태를 각각 복원했다. |

앱 실행과 재시작은 2026-09-12 15:18:59~15:19:19 UTC에 모두 성공했다. 화면 10장을 보관했으며, 영어 140% 옵션, 작은 가로 옵션, 한국어 재시작 판단과 추적 장판 전투 화면을 직접 확인했다. 전투 배치와 시간은 검사용으로 고정하고 실제 편집·저장·복원 코드를 사용했다.

새 실행본은 `Builds/macOS-EdictBlizzard/HELLSCRIPT.app`이다. 증거는 `Artifacts/Validation/EdictBlizzard/`의 `focused-final.xml`, `full.xml`, `Native1/`, `validation-summary.json`에 있다. 최종 Runtime C# 170개와 영어 문구 표가 빌드 소스와 일치하며 C# 메타 누락과 중복 GUID는 없다. 검사에 사용한 소스·기획·설정 642개 파일을 `validated-source.tar.gz`로 보관했다. SHA-256은 `faf2336cc02a1dba6c250e94cdf0fd7448fe0b529450e585e60bb96c677370a4`다. 검증 사본의 머티리얼에 Unity가 추가한 URP Editor 버전 자료는 별도 차이로 기록하고 원본 머티리얼을 유지했다.

## 남은 개발

이번 단계는 M02 다섯 옵션의 연결 범위다. 다음에는 M03의 사용 목적·첫 대상·연결 선택을 이전 규칙 조건과 분리하고, 완료된 접사 대조 실험에서 드러난 연쇄 제어 빌드의 낮은 클리어율을 실행 시간·연결·피해 기록으로 조사한다. 이 변경만으로 여러 시드의 성장 밸런스나 모바일 기기의 성능·터치 검증이 완료된 것은 아니다.
