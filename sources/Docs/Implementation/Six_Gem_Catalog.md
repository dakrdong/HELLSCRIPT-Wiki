# 보석 6종 전환과 이미지 제작 기록

갱신일: 2026-09-23 · [English](Six_Gem_Catalog.en.md)

해골을 제외하라는 사용자 결정에 따라 현재 보석 목록을 **홍옥·청옥·황옥·취옥·자수정·금강석 6종**으로 바꿨다. 기존 6단계를 유지하므로 종류와 단계의 조합은 36개다. [현재 기획](../Design/HELLSCRIPT_Gem_Socket_Detail.md)에 한·영 기준과 효과표를 정리했다.

## 적용 내용

`GemCatalog` 버전 2에서 G07을 제거했다. G01~G06의 ID, 효과 수치, 합성 비용과 소켓 규칙은 유지했다. 새 드롭은 여섯 종류를 균등 추첨하며, 새 거래에서는 G07을 받지 않는다.

기존 저장 파일을 읽을 때 유효한 해골 보석을 같은 단계·수량의 금강석으로 이관한다. 보관함 묶음, 저장 대상 장비의 소켓, 진행 중인 균열과 반복 사냥 결과의 보석 보상에 적용한다. 묶음 경계와 보상 수령 여부를 보존하고 원본 파일을 별도로 보관한다. 잘못된 보관 수량이나 지원하지 않는 소켓 구조는 기존처럼 불러오기를 중단한다. 이미 수령한 보상을 다시 지급하지 않으며, 변환된 저장을 다시 읽어도 중복 이관하지 않는다.

## 이미지

[종류별 대표 이미지 6개](../Art/Gems/2026-09-23/Gem_Icon_Candidates.md)를 제작했다. 모두 1254×1254 RGBA PNG이며 생성 원본의 투명 알파를 그대로 보존했다. 밝고 어두운 배경과 48px 표시에서 색·실루엣을 검토했다. 등급별 36개 이미지 묶음은 아니다.

내장 생성 도구가 실제 모델명을 반환하지 않아 요청된 `gpt-image-2` 사용 여부를 검증할 수 없다. 따라서 이미지 파일은 검토용 시안으로 보관했으며 게임 화면에는 연결하지 않았다. 원문 프롬프트, 파일 해시와 알파 검사 결과를 함께 남겼다.

## 검증 결과

> 통합 기준: 현재 보석상의 합성은 5:1, 분해는 1:5이며 골드 비용이 없다. 아래 3:1·900골드 결과는 이 브랜치의 변경 전 검증 기록이다. 최신 통합 검증은 [2026-09-23 메인 통합](Main_Integration_20260923.md)을 따른다.

영어 가로 화면은 스크롤 목록이다. 각 보석의 실제 텍스트를 순서대로 표시 영역에 이동시키고, 텍스트 경계가 영역 안에 들어오는지 검사한 뒤 화면을 저장했다. 거래와 스크롤 이동은 실행용 검증 도구에서 호출했다. 실제 마우스·터치 입력이나 모바일 실기기 검증을 수행했다는 뜻은 아니다.

## 검증 범위와 남은 항목

이번 결과는 보석 변경에 대한 집중 검사이며 전체 게임 회귀 검사를 뜻하지 않는다. 초기 956×440 가로 화면에서는 목록 표시 영역이 지나치게 좁은 현상을 확인했다. 이번 보석 변경에서 화면 배치를 수정하지 않았으며 작은 가로 화면의 사용성은 별도 점검이 필요하다. 실행 로그에는 후처리 셰이더 제거 경고가 남아 있어 무경고 실행으로 보고하지 않는다.

이미지의 모델 출처 확인, 정식 리소스 채택과 게임 화면 연결은 남아 있다. 공개 위키 게시는 저장소 규칙에 따라 `main` 병합 시 수행한다.
