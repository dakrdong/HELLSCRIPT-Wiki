# 사냥 칙령 회피·긴급 생존 판단 개발 기록

작성일: 2026-09-09 · 관측 피해 예측과 전역 생존 판단 단계

후속으로 추가한 생존 명령의 실제 시전·보행·물약·중단·저장 경로는 [생존 행동 실행 기록](Edict_Response_Expansion.md)을 따른다. 아래 내용은 피해 예측·판단 단계의 완료 기록이며, 새 원본을 정기 전투 판단과 설정 화면에 연결하는 작업은 계속 남아 있다.

## 구현 범위

[전역 옵션 상세안](../Design/HELLSCRIPT_Hunt_Edict_Global_Options.md)의 일반 회피와 긴급 생존 조건을 판단할 계산을 추가했다. 감지한 공격에서 앞으로 잃을 HP를 구하고, 새 사냥 칙령 원본의 피해 기준·항상 회피·행동 방해·중첩 위험·체력 위기·치명적 피해·복귀 체력·자동 물약 방침을 읽는다.

실제 피격과 예측은 같은 방어·저항·피해 감소 계산을 사용한다. 새 `AssessEdictSurvival`은 판단 이유와 대응 순서를 반환하지만, 아직 전투의 행동 선택에 연결하지 않았다. 이 결과만으로 방어기나 회피기를 시전하거나 물약을 소비하지 않는다. 현재 설정·프리셋 저장, HED2 편집 화면과 전역 8분류 전체의 실행이 완료됐다는 의미는 아니다.

## 감지한 공격의 예상 HP 손실

`ForecastIncoming`은 완료된 전투 틱의 상태를 읽는다. 현재 위치 또는 검토할 한 위치에 계속 머문다는 가정으로 이미 예고한 공격과 존재하는 효과만 계산한다. 새로 결정할 적의 행동, 앞으로 생성될 적, 미래 이동 목표는 읽지 않는다. 검토 위치를 멀리 지정해도 현재 영웅이 감지할 수 있는 범위가 넓어지지 않는다.

| 대상 | 계산 범위 |
|---|---|
| 준비 중인 적·보스 공격 | 고정한 방향·조준점·범위·준비 시간을 사용한다. 부채꼴, 장판 설치, 광선, 세 지점 폭발, 투사체와 첫 돌진 경로를 처리한다. 내려찍기의 같은 위치 추가타는 포함하지만, 이후 새로 정할 두 번째 돌진 경로는 만들지 않는다. |
| 비행 중인 적 투사체 | 현재 위치에서 실제 지형 충돌과 영웅 몸체와의 충돌 시점을 계산한다. 시전자가 죽거나 사라져도 이미 날아오는 공격을 유지한다. 같은 발사의 중복 피격 제한과 이미 맞은 기록을 반영한다. |
| 현재 장판·사망 효과 | 원·고리·선형 범위, 남은 대기시간·주기·수명과 실제 피해량을 사용한다. 고리의 안전한 안쪽, 벽 뒤와 투사체를 막는 장애물을 구분한다. 사망 파편은 생성 후 첫 이동 틱부터 충돌할 수 있다. |
| 구형 저장의 효과 | 단순 준비 시간으로 저장한 공격을 상태 변경 없이 해석한다. 기존 장판의 고정 틱 처리와 마지막 피해량 규칙을 보존한다. |
| 보호막과 피해 감소 | 보호막은 남은 시간이 짧은 순서와 ID 순서로 소모한다. 각 보호막 잔량을 전체 공격 목록에서 한 번씩만 사용하고, 만료한 보호막은 차감하지 않는다. 도약 방어와 성소의 감소 효과도 실제 고정 틱의 만료 처리를 따른다. |

공격은 피해가 적용될 틱과 실제 처리 단계 순서로 정리한다. 동일 틱에는 적 행동, 투사체, 기존 장판, 적 위험 효과의 순서를 따른다. 새 투사체·돌진은 발사·출발 틱에 바로 피해를 준다고 계산하지 않는다. 이 차이는 보호막 만료 경계와 직접 연결된다.

반환값은 공격 출처·종류·피격 시점·원 피해·방어 적용 후 피해·흡수량·예상 HP 손실을 분리한다. 목록은 변경할 수 없고, 호출해도 전투 시간·난수·HP·보호막·장비 발동·보상·계정·초안이 변하지 않는다. 사망 위험 판정을 위해 예상 손실의 합계를 현재 HP로 잘라 내지 않는다.

이 계산은 고정 위치의 위험 추정이다. 이동·끌어당기기 이후 위치, 적의 사망·새 제어 효과, 미래 오라·광폭 중첩 변화, 아직 쓰지 않은 회복·방어 스킬을 예측하지 않는다. 관측 중인 시전자의 현재 공격 강화 상태를 반영하며, 시전자는 감지하지 못하고 예고 영역만 보이는 경우에는 기본 공격력으로 추정한다. 실제 미래 피해를 보장하는 자료로 표시하지 않는다.

## 전역 회피와 긴급 대응 판단

| 판단 | 이번 구현 |
|---|---|
| 장판 회피 | 감지한 해당 장판에서 앞으로 1초간 예상되는 HP 손실을 최대 HP와 비교한다. 장판이 아직 시작되지 않았다면 시작 시점부터 1초를 계산한다. |
| 순간 범위·직접 공격 회피 | 해당 공격의 1회 예상 HP 손실과 설정한 비율을 비교한다. 부채꼴·폭발은 순간 범위, 투사체·돌진은 직접 공격으로 분류한다. |
| 항상 회피·행동 방해 | 보호막이 피해를 전부 막아도 항상 회피 방침을 유지한다. 실제로 예고된 끌어당기기는 제어 회피에 포함한다. 냉기 피해나 둔화를 빙결로 바꾸어 해석하지 않는다. |
| 겹치는 공격 | 사용자가 지정한 시간 안의 HP 손실을 합산한다. 각 공격의 손실이 개별 기준보다 작더라도 합계가 중첩 기준 이상이면 이유를 반환한다. |
| 체력 위기·치명적 피해 | 현재 HP 비율과 감지한 공격의 예상 손실을 각각 검사한다. 초기 고정 판단 정책의 일반 관측·치명적 피해 확인 범위는 1.5초이며, 사용자가 지정한 중첩 합산 시간과 구분한다. |
| 정상 전투 복귀 | 같은 영웅·같은 전투에서 긴급 상태에 들어간 뒤에는 복귀 체력까지 유지한다. HP가 회복되어도 치명적 위험이 계속되면 긴급 상태를 해제하지 않는다. 다른 영웅·전투의 기억은 적용하지 않는다. |
| 자동 물약 | 주 행동과 별개로 사용 여부·HP 기준·현재 물약 대기시간을 검사한다. 계산이 반환하는 사용 의도는 실제 소비 명령이 아니며, 일시정지 중에도 계산 자체가 전투를 진행시키지 않는다. |
| 대응 순서와 대체 수단 | 원본의 방어기·회피기·보행 순서와 회피기 사용 불가 시 방침을 그대로 반환한다. 미장착·미해금·자동 사용 꺼짐은 참조 불가 이유를 남기고 원래 선택값을 보존한다. |
| 생존 수단 보존 | 유효한 회피기 참조에만 긴급 전용 보존과 1회분 자원 예약 의도를 반환한다. 현재 세 직업의 회피기는 실제 비용이 0이므로 임의 비용을 만들지 않는다. 공격 진입 전용 도약은 생존 참조로 인정하지 않는다. |

기절·빙결·속박의 비트와 부착 피해 분류는 자료형에 있지만 현재 영웅에게 적용되는 해당 예고·부착 피해 공급자는 없다. `survival.dot`을 켜면 이 제한을 반환하며, 바닥의 독 장판을 영웅에게 붙은 중독으로 대신 계산하지 않는다.

`EdictSurvivalState`는 전투별 긴급 상태 기억이다. 다음 상태는 별도 사본으로 돌려주며 아직 `RunState` 저장과 실제 판단 주기에 연결하지 않았다. 방어기·회피기의 참조 가능 표시는 장착·해금·자동 사용 조건에 한정한다. 쿨타임과 비용은 함께 제공하지만, 실제 시전에는 행동 잠금·자원·스킬 목적·유효 착지점·실패 시 대체 행동을 다시 검사해야 한다. 보행 가능 경로나 회피 성공을 이 단계에서 보증하지 않는다.

## 화면 배치 기획과의 연결

[화면 비율·방향 대응 상세안](../Design/HELLSCRIPT_Screen_Layout_Detail.md)을 전체 개발 기준으로 유지한다. 판단 계산과 긴급 상태 기억은 화면 크기·방향·카메라와 분리했으며, 반환한 이유 자료를 모바일 세로·가로·PC의 공통 표시에서 사용하도록 구성했다.

후속 화면은 같은 판단 자료를 배치에 맞춰 표시하고, 실제 선택한 행동의 이유만 현재 행동으로 안내해야 한다. 미실행 대응 후보를 실행 원인으로 표시하지 않는다. 화면을 다시 배치하거나 설정을 열었다는 이유로 긴급 상태·전투·초안을 초기화하거나 저장해서도 안 된다.

이번 변경에는 새 화면·씬·프리팹·방향 설정·네이티브 앱 빌드가 없다. 실제 PC 리사이징과 모바일 방향·터치·키보드·복귀 검증은 [화면 배치 개발 기록](Screen_Layout_Expansion.md)의 남은 범위로 유지한다.

## 검증과 후속 연결

Unity 6000.6.0f1의 전체 Edit Mode 검사 **871개가 모두 통과**했다. 신규 검사 52개와 기존 검사 819개를 포함한다. 2026-09-09 15:04:33~15:06:05 KST에 약 92.20초 동안 실행했다. [전체 결과](../../Artifacts/Validation/edict-survival-editmode.xml)와 [실행 로그](../../Artifacts/Validation/edict-survival-editmode.log)를 보존했다.

신규 검사는 실제 전투 틱을 진행해 보호막 흡수 순서·만료, 방어·저항·감소 효과, 보스·일반 공격, 투사체 중복 피격 제한, 장판 주기와 구형 효과를 피해 기록과 대조한다. 숨은 공격의 제외, 원본·상태 불변, 회피 비율과 합산 시간 경계, 긴급 상태 진입·복귀·전투 소유권, 미해금·자동 사용 꺼짐의 참조 보존도 포함한다.

첫 집중 검사 160개가 통과한 뒤, 출발 지점에서 이미 영웅과 겹치는 투사체·돌진을 검토했다. 실제 피해는 0.25초에 발생하지만 예측은 0.20초로 앞당기는 오류를 [회귀 검사 10개 중 8개 실패](../../Artifacts/Validation/edict-survival-release-regression.xml)로 재현했다. 첫 이동 가능 틱을 반영하고 긴 타이머의 부동소수점 만료 경계도 보완한 뒤 [집중 검사 174개](../../Artifacts/Validation/edict-survival-corrected-focused.xml)와 최종 전체 검사가 통과했다. 첫 컴파일 오류는 지역 변수 선언을 고쳐 해결했고 [해당 로그](../../Artifacts/Validation/edict-survival-compile-error.log)도 남겼다.

[검사 소스 기록](../../Artifacts/Validation/edict-survival-source-manifest.json)의 C# 126개가 최종 검사 시작 이후 동일하다. 신규 소스 5개와 기존 피격 계산의 공통 함수 연결 1개를 포함한다. 보호 자산 98개와 기준 기획 6개는 단계 시작 해시와 일치하며 메타 파일 누락·GUID 중복이 없다. Unity 패키지가 자동으로 제거한 설정 기호는 [원문 차이](../../Artifacts/Validation/edict-survival-package-define-change.diff)를 남기고 단계 시작 값으로 복원했다. [검증 요약](../../Artifacts/Validation/edict-survival-validation-summary.json)에 실제 연결과 미완료 범위를 함께 기록했다.

이어서는 이 판단 결과를 실제 방어·회피·보행 후보의 시전 자격 및 공통 행동 우선순위에 연결한다. 기존 조준 단계, 나머지 핵심 옵션, 현재 설정의 명시적 저장·이전, 가로·세로 공통 편집 화면도 계속 개발할 범위다. 전체 데이터·공유 형식의 상태는 [핵심 옵션 v0.2 개발 기록](Hunt_Edict_V2_Expansion.md)을 함께 따른다.
