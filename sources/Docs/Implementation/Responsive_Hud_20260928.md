# 창 축소와 하단 HUD 통일

작성일: 2026-09-28 · [English](Responsive_Hud_20260928.en.md)

화면을 줄이면 UI와 글자도 같은 비율로 줄인다. 전투·마을·반응형 페이지와 설정·프리셋의 고정 픽셀 배율을 `UiTheme.Scale`의 안전 영역 배율로 바꿨다. 기존 페이지 좌표가 공통 콘텐츠 좌표의 두 배이므로 배율에 0.5를 적용한다. 창 크기나 안전 영역이 달라지면 캔버스를 다시 계산한다.

## 하단 HUD는 한 세트

`GlobalHudLayout`의 가로 기준 배치를 모든 화면에서 유지한다. 포션·궁극기·일반 스킬·기존 패시브·캐릭터 인장·레벨·경험치·HP·MP·상태 효과는 같은 배율을 쓴다. 세로 화면에서 포션만 키우거나 경험치 바만 짧게 만들지 않는다. 기준 묶음은 안전 영역의 하단 중앙에 맞추며, 여백이 남아도 요소 사이 간격과 상대 위치를 늘리지 않는다.

궁극기와 일반 스킬은 항상 한 줄이다. 물약 세 칸은 스킬 왼쪽에서 같은 행의 중심선에 맞춘다. 하단 묶음이 화면 안에 들어오도록 전체를 축소하며, 줄바꿈으로 높이를 늘리지 않는다. 고정 최소 배율 0.4는 제거했다. 읽기 크기 설정은 유지하지만, 하단 묶음이 넘칠 때는 전체가 들어가는 배율을 우선한다. 글꼴의 정수 픽셀 반올림 이외에 일부 요소만 크기를 다르게 바꾸지 않는다.

전투 로그는 안전 영역 맨 아래에 고정한다. 로그 영역이나 오른쪽 버튼을 누르면 펼치거나 접는다. HUD 묶음은 로그 바로 위에 놓고, 로그 높이 변화만큼 모든 요소를 같은 거리로 이동한다. 이때 HUD 크기·내부 간격·배율은 바꾸지 않는다. 전투 화면을 떠나면 로그를 위한 하단 여백을 해제한다.

## 절전 모드와 출석 표시

절전 가로 화면은 같은 폭의 두 열이다. 왼쪽은 창고와 착용 장비 변경, 오른쪽은 얻은 장비와 클리어 정보다. 본문 중앙의 세로 선이 두 열을 나누며 상단 시간·상태와 하단 성장·해제 영역에는 선을 그리지 않는다.

장비 변경 로그는 시각과 부위명을 한 줄에 표시한다. 두 장비 칸은 공통 `EquipmentSlotView`와 `UiTheme.CompactEquipmentSlot`의 40 단위 크기를 사용하며 행 간 여백은 6 단위다. 100% 기준 행 높이는 기존 78에서 46으로 줄었다. 읽기 크기 확대에도 한 줄 표시와 이전·이후 장비 상세 열기를 유지한다.

출석창에서 수령 가능한 미수령 보상은 아이템 뒤에 초록빛을 그리고 초록색 테두리와 점으로 표시한다. 선택 여부와 무관하게 해당하는 모든 보상을 강조하며, 수령 완료·미도달 보상에는 나타나지 않는다. `AttendanceClaimGlow`는 투명해지는 방사형 빛과 부드러운 광선을 그리는 벡터 UI 리소스다. 기존 코드 기반 UI 그래픽 방식을 따르며 새 래스터 이미지나 이미지 생성 모델을 사용하지 않는다. 프레임마다 다시 그리는 애니메이션 없이 표시하고, 테두리는 계속 보인다. 색은 `UiTheme.Claimable`이 소유한다.

## 검증

기하 검사는 화면 크기·방향·읽기 크기를 바꿔 모든 HUD 요소의 상대 위치와 크기 비율, 한 줄 스킬 배치, 영역 겹침을 확인한다. macOS 실행 검사에서는 실제 표시 배율, 주기적 갱신 뒤의 글자 크기, 절전 열 구분, 출석 수령 전후의 초록 표시와 기존 클릭·스크롤·저장을 확인한다. 결과와 실행 근거는 [전체 통합 기록](All_Work_Integration_20260928.md)에 모은다. 모바일 실기기 검증과 배터리 측정은 별도다.
