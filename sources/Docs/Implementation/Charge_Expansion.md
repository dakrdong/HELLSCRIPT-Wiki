# 세트 충전·다음 비용 감소 개발 기록

작성일: 2026-09-09 · 단계: D3 진행 중

## 1. 변경 목적

일부 세트가 효과 실행 시점에 버프를 확인하던 구조를 고쳤다. 준비·체공 중 버프 시간이 끝나도 이미 예약한 보너스가 해당 공격에 적용되며, 취소·복원으로 충전이나 피해가 중복되지 않아야 한다. LC02의 5초 수명과 AP05의 실제 보행 후 비용 감소도 같은 전투 시간 안에서 처리한다.

기준은 [장비 상세 명세의 전설·세트·처리 경계](../Design/HELLSCRIPT_Itemization_Detail.md)다. 이전 공통 피해·보호막·제압의 구현은 [전투 효과 통합 기록](Effect_Expansion.md)에 보존했다. 이번 변경은 기존 전투 소유자와 행동 상태를 확장하며 별도 실행 관리자나 외부 패키지를 추가하지 않는다.

## 2. 적용한 규칙

| 효과 | 생성·예약·소비와 예외 |
|---|---|
| SW 4세트 | 유료 회오리 틱을 지불한 채널에서 실제 보행한 거리만 센다. 4m마다 6초 충전 하나를 생성한다. 보유 중에는 추가 거리를 4m 직전까지 저장하고 시간을 갱신하지 않는다. 채널 중단은 미완성 거리만 초기화한다. 도약의 유효 이동 시작에 충전을 예약하고 유효 착지에서 추가 피해를 한 번 적용한다. 이동 전 취소·무효 목적지는 충전을 소비하지 않으며, 이동 후 무효 착지·중단은 예약을 제거한다. |
| SWB 4세트 | 도약의 원 착지 적중으로 얻은 충전은 다음 분쇄의 시전 시작에 소비한다. 준비 중 만료되어도 예약은 남으며 원 부채꼴의 유효 대상에게 추가 피해를 적용한다. 대상이 떠나 빗나가거나 유료 시전이 중단돼도 충전을 돌려주지 않는다. |
| SAB 4세트 | 후퇴 이동 완료로 얻은 충전은 관통 시전 시작에 소비한다. 준비 중 만료되어도 원 사격과 같은 원점·방향의 잔영을 0.3초 지연으로 한 번 발사한다. 잔영의 최대 대상 5명·D120%·추가 발동 금지를 유지한다. |
| SMB 4세트 | 서리 폭발의 원 적중이 6초·2충전을 생성한다. 다음 연쇄 번개 시전 시작마다 1충전을 소비하고 해당 시전의 타격 수 +2를 저장한다. 다른 1충전의 만료와 이미 시작한 시전의 보너스는 독립적이다. MP03 포함 최대 7회와 LM04의 방문 제한을 유지한다. |
| LC02 | 같은 대상에게 기본공격 3회가 적중하면 5초 충전을 생성하고 내부 CD 4초를 시작한다. 보유·CD 중에는 횟수를 쌓지 않는다. 다른 스킬은 미완성 횟수를 유지한다. 기본공격 대상 변경·대상 사망은 미완성 횟수를 지우되, 세 번째 적중으로 처치했다면 완성한 충전은 지급한다. 유효한 다음 유료 시전 또는 회오리의 첫 유료 틱만 소비한다. |
| AP05 | 궁수가 연속 1초 실제로 보행하면 비용 감소 +25%를 준비한다. 이동기·위치 복원·멈춘 시간은 세지 않는다. 다음 유료 시전까지 준비를 유지하고 실제 소비 때 내부 CD 4초를 시작한다. 준비·CD 중 다음 보행 시간을 미리 쌓지 않으며, CD가 끝나는 틱에서도 끝난 뒤의 시간만 센다. |
| 할인 중첩 | LC02와 AP05를 접사·해당 세트 등과 합산해 최종 감소 50%를 적용한다. 같은 유료 시전에서 준비된 두 효과를 모두 소비한다. 무료 행동·자원 부족·실행 불가는 소비하지 않는다. |
| LA03 | 후퇴가 유효하게 이동을 시작할 때 출발점에 덫을 놓는다. A03 장착이 필요하며 착지 때 다시 만들지 않는다. 이동이 실패하면 그 이동이 만든 덫만 제거한다. 기존 무장·대기·3초 피해·전체 덫 수 제한을 유지한다. |

주 실행 변경은 `CombatSimulation.Charges.cs`, `CombatSimulation.Actions.cs`, `CombatSimulation.cs`, `CombatSimulation.Projectiles.cs`에 있다. 충전·CD·보행 누적은 기존 `CombatEffectState`에, 개별 시전의 예약은 `HeroActionState`에 저장한다. 이미 발사한 공격과 지연 잔영은 기존 투사체 상태를 그대로 사용한다.

## 3. 화면과 저장 호환

전투 효과 상세 화면은 남은 세트 충전, 절제·절약된 집중의 준비 상태, 현재 시전에 예약된 보너스를 구분한다. 원소 보호막의 흡수 자격이 충족됐지만 내부 CD 때문에 기다리는 경우에는 대기시간을 표시한다. 피해 기록에는 방어 이외의 추가 피해 감소율도 표시한다. 행동 편집의 지정 버프 목록에 절약된 집중을 추가했으며, 기존 선택지 번호는 유지했다.

효과 버전은 `effectVersion=2`다. 계정·지도·행동의 별도 버전은 바꾸지 않았다. 이전 버전의 ‘다음 할인’이 남아 있으면 5초 충전으로 한 번 변환한다. 아직 실행되지 않은 준비·체공 구간에 유효한 세트 충전이 남아 있으면 예약에 연결하며 비용을 다시 차감하지 않는다. 이미 실행한 공격은 다시 예약하거나 발사하지 않는다. 과거 시점에 이미 만료된 충전은 소급 복원하지 않는다.

이전 버전에서 저장한 후퇴 체공은 당시 예정됐던 착지 시 덫 생성 한 번을 유지한다. 새로 시작하는 후퇴부터 출발 시 생성한다. 이 호환 상태도 저장하며 반복 복원으로 덫이 늘어나지 않게 한다. 일시정지와 포탈 정리 중에는 충전·내부 CD·예약·보행 누적이 변하지 않는다. 훈련에서 패시브나 효과 구성을 해제하면 미사용 준비 상태를 정리하고, 행동 편집으로 취소한 시전은 예약을 돌려주지 않는다.

네이티브 실행은 배치 모드·그래픽 비활성 옵션 없이 Metal, 540×960으로 진행했다. 충전 검사 화면 9장과 효과 회귀 화면 7장을 저장했다. 예약된 분쇄, 남은 연쇄 충전, 두 할인 준비·소비, 복원된 보호막과 보스 제압, 자원 회복 완료 화면을 직접 확인했으며 새 문구의 겹침이나 잘림은 없었다. 화면 전환은 실제 UI 버튼의 콜백을 호출했다.

실행 검사는 레벨 30·기본 지급 무기·실제로 착용 가능한 4세트 또는 LC02 목걸이·정지한 무해한 고체력 적을 사용했다. 세트 효과를 실제로 얻은 뒤 SW/SWB/SAB의 남은 시간을 의도적으로 줄여 준비·체공 중 만료 경계를 만들었고, 행동 사이의 위치도 고정했다. 효과 회귀는 LC03과 LM03 허리를 서로 다른 배치에서 각각 착용했으며, 제압 85·앞선 발동의 잔여 CD 1.25초·최대 HP 16% 상당의 지면 피해를 초기 조건으로 주었다. 사용자 저장과 분리된 `ChargeFinalSave`, `ChargeEffectSave`에 저장했다. 이 결과는 물리 마우스·터치, Android 실기기, 자연 성장·전체 빌드 밸런스의 검증을 뜻하지 않는다.

최종 집계는 `Artifacts/Validation/charges-validation-summary.json`에 기록했다. 최종 C# 52개·실행 라이브러리·검사 XML의 해시가 기록과 일치하며, 문서 로컬 링크 100개에 누락된 대상이나 절 제목 연결 오류가 없었다. 이전 효과 단계의 174개 검사와 전체 균열 실행 기록은 당시 결과로 보존하며, 이번 197개 검사나 최종 빌드의 실행 결과와 혼용하지 않는다. 기존 URP 심도 효과·Panini 셰이더 제외 경고는 남아 있다.

최초 회귀에서는 분쇄가 시작되기 전 전역 충전을 보던 기존 검사 한 개가 실패했다. 새 규칙은 시전 시작에 충전을 예약하므로, 해당 검사는 도약 완료와 다음 분쇄 시작 사이를 분리해 기존 추가 피해·CD 기대값을 유지했다. 실행 검사 도구의 지역 변수 이름 충돌도 수정했다. 위 표는 이 수정과 CD·세 번째 적중 경계 보강 후의 최종 결과다.

## 5. 남은 구현

이후 LA04 원 표적 판정, 감속 만료·구형 보스 제어, 같은 틱 사망 정산은 [전염·사망 정산 개발 기록](Outcome_Expansion.md)으로 이어진다. 아래 목록은 충전 단계 종료 시점의 후속 범위이며 당시 197개 검증 결과를 보존한다.

1. SA/SM의 노출·갱신·만료 전체 경계, LM01의 고정/추적 선택과 조준 규칙, 전체 패시브·전설·세트의 실제 가능한 장비 조합을 검증한다. LA04는 서로 다른 원 대상에서 같은 적으로 전염되는 경우, 보스 감속은 한 틱 도중 강한 감속이 끝나고 약한 감속만 남는 경우, 이전 보스 저장은 구형 제어 필드가 남은 경우를 다음 회귀 사례에 포함한다.
2. 일반 적·정예·보스의 독립 패턴·공격 속성·방향 판정·원 공격 ID와 제어 상태를 통합한다. 같은 전투 틱의 보스·영웅 동시 사망 정산도 남아 있다.
3. D4의 성장·마을·훈련 비교·결과 분석, D5의 보석·서버·계정·결제, D6의 Android 실기기·입력·표현·음향·성능 검증을 진행한다.

이번에는 기존 정적 이미지를 유지하고 코드로 만든 UI·임시 모델·투사체 표시를 사용했다. 씬·프리팹·이미지 원본·패키지·프로젝트 설정은 충전 기능의 변경 대상으로 삼지 않았다.
