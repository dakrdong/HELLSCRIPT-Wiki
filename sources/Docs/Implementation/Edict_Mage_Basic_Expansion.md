# 번개탄 사냥 칙령 개발 기록

작성일: 2026-09-13 · [English](Edict_Mage_Basic_Expansion.en.md)

상태: **번개탄의 네 옵션과 실제 적중·자원·절제·원소 연계를 연결했다. 전체 검사 1,765개, macOS 실행·재시작 17회와 전후 48판 비교를 완료했다.**

## 클로드 통합과 개발 범위

클로드의 능력치·접사·밸런스 완료본 `b1f3ea5`는 통합 커밋 `92d5812`를 통해 로컬·원격 `main`에 포함되어 있다. 이번 단계 시작 시 원격을 다시 확인했으며, 메인과 개발 브랜치는 서리 폭발까지 연결한 `214b3de`였다. 속성 57개·접사 54종·기존 저장 번호를 유지하고, 피해 수치와 접사 가중치는 조정하지 않았다. 인수 내용과 수정 사항은 [능력치 통합 기록](Attribute_Integration_Expansion.md)을 따른다.

[스킬별 옵션 명세](../Design/HELLSCRIPT_Hunt_Edict_Skill_Option_Catalog.md)의 HEC-MAGE-01~04를 실제 기본 공격에 연결했다. 사냥 칙령을 켜면 액티브 슬롯과 별개인 번개탄 후보를 하나 만든다. 이전 기본 공격 규칙의 누락·사용 중지·막힌 조건·중복 행에 의존하지 않으며, 칙령을 끄면 이전 규칙을 사용한다. 이전 규칙 원본과 사용자 선택을 자동으로 바꾸지 않는다.

## 네 옵션의 실제 동작

| 옵션 | 처리 |
|---|---|
| 자동 사용 | ON이면 후보를 검토하고 OFF이면 새 공격을 시작하지 않는다. 이미 확정한 준비와 날아가는 투사체는 원래 방향·판정으로 마친다. |
| 사용 방식 | FILL은 공통 행동·스킬 순서를 따른다. RESOURCE는 장착·해금·자동 사용·쿨타임·목적·실제 범위를 만족한 유료 액티브가 현재 비용을 지불할 수 없을 때만 공격한다. DISCOUNT는 실제 LC02 장착을 요구하며 충전과 내부 쿨타임이 없을 때 유효한 연속 적중 대상을 우선한다. 충전이나 내부 쿨타임이 남아 있으면 FILL과 같은 방식으로 돌아간다. |
| 우선 대상 | GLOBAL은 전역 대상, CURRENT는 현재 유효 대상, LOW_HP는 남은 HP 비율이 가장 낮은 적을 고른다. OWN_BLIZZARD는 실제 자기 눈보라에 들어 있는 적을 우선하고 없으면 전역 대상으로 돌아간다. 절제 준비 중 유효한 연속 적중 대상은 이 선택보다 우선한다. |
| 조준 방식 | CURRENT는 준비 시작 때의 위치, PREDICTED는 유효한 관측 이동과 준비·비행 시간을 반영한 위치를 조준한다. 관측이 없거나 오래되었거나 비정상적이거나 적이 이동 불가 상태면 현재 위치를 사용한다. |

자원 보충은 단순한 잔량 기준을 쓰지 않는다. M01의 실제 비용이 LC02로 25에서 12.5로 줄었다면 자원 12.5에서는 보충하지 않고, 12.49에서는 다른 조건도 만족할 때 보충한다. M06이 멀리 있어 먼저 걸어야 하는 상황은 아직 자원만 부족한 시전 후보가 아니다. 비용 확인은 자원·충전·쿨타임을 소비하지 않는 읽기 전용 판단이다.

자기 눈보라 판정은 소유자·생성 시점·남은 시간·활성 지연·실제 범위와 시야를 확인한다. 이전 저장의 빈 소유자 표시는 기존 호환 규칙을 따르며, 다른 영웅·적의 장판이나 아직 시작하지 않은 장판을 자기 영역으로 세지 않는다. 대상은 현재 감지와 추적 제외 정책을 통과해야 한다. 접근은 전역 이동과 추적 한도를 사용하고, 저장을 다시 불러와도 소진한 한도를 초기화하지 않는다.

## 실제 적중·장착 효과·저장

기존 사거리 **10m**, 속도 **14m/s**, 투사체 반경 **0.2m**, 번개 피해 계수 **0.8**과 단일 충돌을 유지한다. 총 행동 시간은 `0.8 / 공격 속도`이며 준비 40%·회복 60%로 나눈다. 앞의 다른 적이나 벽에 먼저 닿으면 그 실제 결과를 적용하며 관통·연쇄를 추가하지 않는다. 예상 위치 조준은 유도가 아니다.

자원 **5**와 LC02 적중 횟수는 실제로 맞은 적과 적중 시점에 처리한다. 자원은 실제 최대치에서 멈추며 MP05는 이 5를 늘리지 않는다. LC02의 같은 적 3회 적중은 할인 충전 5초와 내부 쿨타임 4초를 만든다. 충전·내부 쿨타임 중에 다음 충전을 미리 쌓지 않고, 충전을 얻어도 유료 액티브를 강제로 예약하지 않는다. MP06은 실제 번개 피해와 다른 속성 피해의 연결로 처리한다.

[장비 상세안](../Design/HELLSCRIPT_Itemization_Detail.md)의 기존 LC02 경계를 유지했다. 다른 적에게 기본 공격을 **시작**하면 미완성 횟수를 초기화하며, 실제로 다른 적에게 맞아도 새 대상의 횟수로 이어 간다. 시작 자체는 적중 보상이나 할인 충전을 주지 않는다. 이 규칙을 ‘실제 적중만 중요하므로 시작 시 초기화를 삭제한다’로 바꾸지 않았다.

실행 중 선택을 바꾸고 저장해도 준비 중인 공격의 대상·조준·행동 ID와 이미 날아가는 투사체를 보존한다. 재시작 후 중복 발사·중복 적중·중복 자원·중복 할인 없이 원래 공격을 한 번 마친다. [화면 상세안](../Design/HELLSCRIPT_Screen_Layout_Detail.md)의 기존 편집·스크롤·하단 이동 구조 안에 한국어·영어 안내를 추가했다.

## 서리 폭발 전환 기록 보완

앞 단계의 생존 설정 8판에는 M03 준비를 M06으로 바꾼 사건 52회가 있었지만, 당시 기록만으로 각 전환의 제어 목적을 구분할 수 없었다. 이번에는 전환한 바로 그 판단의 사유, 새 M06 행동 ID, 실제 발사·중단·불발, 피해 적중 수와 제어 적용 대상 ID를 함께 기록한다. 전역 긴급·회피 요청과 끊을 수 있는 위험 시전을 구분하며, 전투 계산이나 선택 조건을 바꾸지 않는다.

제어 적용 기록에는 기존 상태의 갱신도 포함한다. 이를 끊은 적 시전 수나 막은 피해량으로 해석하지 않는다. 이전 기록에 없던 원인을 소급하여 붙이지 않으며, 마지막 전역 판단의 관측값과 같은 시점의 실제 선택 사유를 구분한다.

## 고정 표본의 전후 비교

이전 M06 최종 기록의 24판과 이번 24판을 비교했다. 레벨 30·균열 20단계·연쇄 제어 빌드·합법 장비 8개와 시드 0·1·2·3·4·5·9·14를 사용한다. 지도·적·목표·장비 ID와 값·능력치 시트·최대 HP·기본 피해 및 전체 칙령 문서가 대응하는 판끼리 동일함을 확인했다. 이전 소스 보관본과 `214b3de`의 C#·영어 문구·패키지 입력 256개를 대조한 뒤 이전 자료를 재사용했다.

| 각 8판의 설정 | 사망 / 시간 초과, 전→후 | 보스 등장 판, 전→후 | 번개탄 적중 수, 전→후 | M03 중단 수, 전→후 |
|---|---|---|---|---|
| 이전 규칙 | 4 / 4 → 4 / 4 | 4 → 4 | 989 → 989 | 28 → 28 |
| 기본값 칙령 | 7 / 1 → 7 / 1 | 1 → 2 | 627 → 658 | 2 → 2 |
| 생존 대응을 명시한 칙령 | 0 / 8 → 0 / 8 | 3 → 5 | 1,033 → 1,050 | 68 → 64 |

모든 조건의 클리어는 전후 모두 0회다. 이전 규칙 8판의 전체 결과는 정확히 같았다. 기본값 칙령은 전역 생존이 꺼진 문서이며, 별도로 생존 대응을 켠 실험 문서와 혼용하지 않는다. 기본값과 생존 문서는 스킬 옵션·슬롯·순서가 같고 전역 항목 13개만 다르다. 이번 비교에서도 두 문서의 번개탄은 FILL·GLOBAL·PREDICTED를 사용한다. 사용자 저장에 이 실험 설정을 덮어쓰지 않는다.

생존 설정의 M03 준비→M06 전환은 52→56회였다. 이번 56회는 모두 같은 시점에 ‘준비가 끝나기 전에 끊을 수 있는 위험 시전’을 사유로 선택했고, M06은 모두 발사되어 피해 적중 222회와 행동별 제어 적용 대상 합계 183회를 기록했다. 이 중 5회는 각각 피해 적중 1회가 있었으나 빙결·제압 적용 기록은 없었다. 처치로 제어가 불필요해진 경우 등을 아직 구분하지 않았으므로 실패한 제어 5회라고 단정하지 않는다.

생존 설정의 보스 전 구간 평균은 271.21→266.26전투 초였다. 보스가 등장하지 않은 판은 전체 전투 시간을 이 구간에 포함한다. 이 시드는 앞선 결과를 보고 선택한 진단 표본이므로 일반 승률·예상 파밍 효율이나 순수한 번개탄 조준 효과의 측정값으로 쓰지 않는다. 보스 도달과 피해가 늘어도 클리어·성장·장기 난이도의 개선을 확정하지 않는다. [대조 결과](../../Artifacts/Validation/EdictMageBasic/comparison.json)에 전체 정책·대응 판과 한계를 보존했다.

초기 전체 검사에서 이전 기본 공격의 개별 대상 규칙을 기대하던 검사 1개를 발견했다. 이를 칙령 ON에서는 새 전역 대상, OFF에서는 저장된 이전 대상을 사용한다는 두 경계로 바꿨다. 저장된 규칙 원본도 그대로인지 검사한다. 최종 전체 검사에는 이 두 경우를 모두 포함하며, 초기 실패 자료도 남겼다.

검사는 별도 Unity 프로젝트와 전용 저장 폴더에서 실행했다. C#·영어 문구 입력 257개를 최종 전체 검사 소스와 대조했다. 앱은 실행용 C# 181개와 영어 문구 표를 대조하며, 빌드 후 바뀐 대상 선택 검사 파일은 Editor 검사 전용으로 구분한다. C# 메타 누락과 자산 GUID 중복은 없다. 씬·프리팹·패키지와 원본의 별도 설정·위키 변경 17개를 보존했다.

## 남은 개발

이 단계로 마법사 액티브 M01~M06과 기본 공격의 핵심 옵션을 독립 판단에 연결했다. 다른 직업의 남은 판단, 실제 성장·파밍 효용, 제어 전환의 기회비용과 장기 난이도, 모바일 실기기의 입력·성능 검증은 계속 진행한다. 이 단계의 검사는 전체 게임 완성이나 밸런스 확정을 뜻하지 않는다.
