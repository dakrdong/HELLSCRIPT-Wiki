# 전투 효과 통합 개발 기록

작성일: 2026-09-09 · 단계: D3 진행 중

## 1. 이번 변경의 목적과 범위

같은 공격이라도 직접 타격·장판·추가 피해가 서로 다른 방어 계산을 사용하던 문제를 고쳤다. 보호막은 생성 원천별로 유지하고, 실제 흡수와 HP 감소를 분리했다. 중독·감속·속박·기절·빙결·표식에는 발생 출처와 남은 시간을 연결했으며 보스 제어는 제압 게이지로 변환했다.

상세 정책은 [장비 명세 7장](../Design/HELLSCRIPT_Itemization_Detail.md#7-스탯-연산과-효과-상호작용)과 [전투 완료 기준](../Design/HELLSCRIPT_Gameplay_Completion_Checklist.md#4-전투-판정과-적-콘텐츠)을 따른다. 아래 내용은 D3의 공통 계산과 일부 개별 효과를 연결한 범위다. 18개 패시브·15개 전설·6개 세트 전체를 완료한 것으로 집계하지 않는다.

## 2. 적용한 규칙

| 영역 | 실제 변경 |
|---|---|
| 피해 계산 | 기초 공격값·가산·독립 배율·극대화·방어·버프 감소를 공통 수식에서 처리한다. 물리 방어 75%, 비물리 저항 70%, 버프 감소 50% 상한을 적용한다. 받은 피해도 속성에 따라 방어도 또는 저항을 사용한다. |
| 피해 기록 | 발생 ID·원 공격 ID·효과 ID·시전자·대상·전투 틱·속성·극대화·방어 전 값·감소율·최종 피해·흡수·실제 HP 감소를 기록한다. 최근 피해 2,000건과 효과 사건 600건을 저장하며 화면에는 최근 피해 20건을 표시한다. LA04 중복 방지는 이 표시 기록과 별도 원장을 사용한다. |
| 보호막 | W05·M05·LC03 등 각 원천의 보호막을 별도로 유지한다. 남은 시간이 짧은 순서, 동률이면 생성 순서대로 흡수한다. 같은 원천은 새 발생으로 갱신하고 전체 양은 최대 HP를 넘지 않는다. 의지와 생성 증가를 적용하며 AF24는 보호막을 늘리지 않는다. |
| LM03 | M05의 실제 누적 흡수가 생성 당시 최대 HP의 15%에 도달하면 자원 20을 한 번 회복한다. 내부 CD 4초를 별도 저장한다. CD 중 자격을 갖춘 보호막이 살아 있으면 CD 종료 후 지급하며, 소멸·교체된 보호막은 지급하지 않는다. 마지막 흡수로 소진되더라도 당시 CD가 끝났으면 지급한다. |
| LC03 | 성공한 물약 회복 직전 HP가 0% 초과~20% 이하일 때 보호막을 생성한다. 자체 20초 CD를 사용하고 물약 정책을 바꾸지 않는다. M05 보호막이 함께 유지될 수 있다. |
| LW04 | HP가 30% 초과에서 생존한 채 30% 이하로 내려오고 장착한 도약이 CD 중일 때만 초기화한다. 자체 30초 CD를 사용한다. 사망·흡수만 발생·도약 미장착·이미 CD가 0인 경우에는 발동하지 않는다. |
| 상태 출처 | A03/LA03 중독과 SA4 추가 독을 구분한다. 익명 중독·다른 시전자·세트 독은 ‘내 덫의 중독’으로 인정하지 않는다. 다른 시전의 감속은 따로 만료되며 가장 강한 비율 하나를 사용한다. 새 표식은 이전 자기 표식을 제거한다. |
| 보스 제압 | 속박·기절·빙결은 같은 원 공격·효과 정의·보스에 한 번만 `예정 지속시간×10`을 적립한다. 감속은 가장 강한 비율과 실제 유지 시간만 적립하고 보스 이동을 동시에 늦추지 않는다. 100에서 3초 무력화 후 10초 면역으로 전이한다. 준비 중인 기존 패턴은 취소하고 생성된 투사체·장판은 보존한다. |
| 눈보라·후속 폭발 | 눈보라의 공격값을 생성 때 저장하고 겹친 영역은 강한 장판 하나만 0.5초 간격으로 적용한다. LM01 이동 장판은 생성 당시 추적 여부를 유지하고 최대 4m 이동한다. LM02는 화염구가 충돌할 때의 공격값을 저장해 0.4초 뒤 한 번 폭발한다. LM02는 SM4 노출을 소비하거나 자기 폭발을 재생성하지 않는다. |
| 사격·연쇄·회복 | A06은 암흑 피해를 별도 계산하고 LA04는 방어 전 값을 전달하며 원 공격·대상별 중복을 막는다. LM04는 방문하지 않은 적을 먼저 선택한다. WP04는 첫 처치부터 회복 배율을 한 번 적용한다. AP04의 속박 연장과 MP02 감속 증가, 지속 피해를 포함한 MP06 속성 교차를 연결했다. LW01은 채널 1초 뒤 유효 틱부터 발동하며 제어 중인 적을 끌지 않는다. |

`CombatSimulation`의 기존 실행·저장 소유 구조를 유지했다. 계산은 `CombatSimulation.Damage.cs`, 상태와 보호막은 `CombatSimulation.Effects.cs`로 나누고 공통 데이터와 수식은 `CombatEffects.cs`에 두었다. 별도 전투 관리자나 Unity 오브젝트를 판정 원장으로 추가하지 않았다.

## 3. 화면과 저장

전투 화면의 HP 표시를 누르면 보호막별 양·지속시간·흡수량과 최근 피해 기록을 확인할 수 있다. 이 화면은 전투를 멈추고, 돌아갈 때 이전 일시정지 상태를 유지한다. 보스 전투의 게이지에는 제압 진행도·무력화·면역 시간이 표시되고, 무력화 중인 보스 발밑에는 냉기색 고리가 나타난다.

효과 저장 버전은 `effectVersion=1`이다. 기존 계정 스키마·지도 버전·동작 버전은 변경하지 않았다. 기존 합산 보호막은 출처 미상 인스턴스로 변환하며 재변환하지 않는다. 더 새로운 효과 버전은 기존 파일을 보존한 채 로드를 거절한다. 일시정지·포탈 정리 중에는 흡수 자격·내부 CD·상태이상·제압·면역 시간도 멈춘다.

## 4. 검증

효과 실행 검사는 레벨 30 마법사·기본 지급 무기·정지한 무해한 보스가 있는 개발용 배치다. 첫 검사에는 LC03 허리를, 다음 검사에는 LM03 허리를 실제 아이템으로 하나씩 착용했다. 두 전설은 같은 허리 부위라 동시에 착용하지 않는다. 제압 85, 앞선 발동의 잔여 CD 1.25초, 최대 HP의 16%를 흡수하게 하는 지면 피해를 초기 조건으로 주고 나머지는 실제 행동 실행기로 진행했다. 공통 흡수 엔진을 확인하는 단위 검사 조합과 플레이어가 착용 가능한 조합을 구분한다.

실행은 배치 모드·그래픽 비활성 옵션 없이 Metal, 540×960으로 진행했다. 앱 자체가 저장한 보호막 목록·제압 HUD·복원 상세·보상 완료·면역 화면을 확인했다. 도약·투사체는 기존과 같은 개발용 고정 배치다. 물리 마우스·터치 입력, Android 실기기, 성장 밸런스 또는 최종 아트 품질의 검증은 아니다. 기존 URP 심도 효과·Panini 셰이더 제외 경고는 남아 있으며, 이를 새 화면의 렌더링 실패와 혼동하지 않는다.

최종 결과는 `Artifacts/Validation/effects-validation-summary.json`에 집계했다. 문서의 로컬 링크 93개에 누락된 대상이 없었고, 검사·빌드 이후 C# 49개의 해시가 모두 일치했다. 새 상세 화면의 글자 겹침은 없었다. 기존 결과 화면의 배경 위 로그 대비와 제압 고리의 대비 개선은 D6 표현 작업으로 남긴다.

최초 회귀의 2개 실패는 단일 보호막 필드를 직접 주입하던 기존 검사에서 발생했다. 이전 저장 변환 검사는 이전 효과 버전도 지정하도록 고쳤고, 현재 전투의 흡수 검사는 출처가 있는 보호막을 주입하도록 바꿨다. 기존 기대값은 유지했다. 최초 빌드 실행은 잘못 지정한 편집 도구 네임스페이스 때문에 실행 메서드를 찾지 못했으며, 실제 `Hellscript.Editor.ProjectBuilder.BuildMac`으로 다시 실행한 최종 로그를 근거로 사용한다.

## 5. 남은 작업

이후 SW/SWB/SAB/SMB 예약과 LC02·AP05를 연결한 변경은 [충전·비용 효과 개발 기록](Charge_Expansion.md)을 따른다. 이 문서는 효과 버전 1과 당시 174개 검증 결과를 보존하며, 현재 소스의 효과 버전 2와 구분한다.

1. SW/SWB/SAB/SMB의 충전을 시전 시작·이동 시작에 예약·소모하는 전체 규칙과 LC02의 5초 충전 수명, AP05의 이동 후 비용 감소를 마무리한다.
2. LM01의 고정/추적 선택과 조준 설정, SA/SM 노출·갱신·만료의 전체 경계 사례, 모든 패시브·전설·세트의 실제 가능한 8부위 조합을 검증한다.
3. 일반 적 12종·정예 6속성·보스 3종의 독립 패턴을 연결한다. 현재 제압 취소는 기존 보스의 공통 6초 CD 동작을 대상으로 한다. 개별 패턴 CD·연속 공격·갈고리·광선·속박 중 돌진 완료 제한 등은 별도 후속 구현이다. 적 속성별 실제 공격 데이터와 방패의 방향 판정, 공통 ‘적 공격’으로 기록되는 일부 근접·장판 사건의 정확한 시전자·원 공격 ID 연결도 남아 있다.
4. 보스와 영웅의 동시 사망에서 같은 틱에 이미 발생한 모든 피해를 보존하고 보스 처치를 우선 정산하는 배치 처리를 완성한다. 현재 즉시 보스 종료를 그 완료 근거로 사용하지 않는다.
5. 모든 버프의 출처 모델 통합, D4의 저레벨 성장·마을·훈련 비교·결과 분석, D5의 서버·보석·계정·결제, D6의 Android·입력·음향·표현·성능 검증을 이어 간다.

이번 변경은 새 이미지 제작을 요구하지 않아 기존 생성 이미지를 유지했다. 새 상태 표시에는 코드로 만든 고리와 기존 UI를 사용한다. 씬·프리팹·패키지·프로젝트 설정·이미지 원본을 이번 효과 작업의 변경 대상으로 삼지 않았다.
