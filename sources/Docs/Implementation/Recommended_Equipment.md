# 장비 점수와 추천 착용

갱신일: 2026-10-01

[English](Recommended_Equipment.en.md)

새로 획득한 장비가 사용자가 정한 조건을 만족하면 즉시 착용합니다. 교체한 장비는 공통 설정에 따라 창고 보관·분해·판매합니다. **사냥 칙령 → 장비 추천 착용 → 공통 설정**에서 **추천 장비 자동 장착**을 On으로 켜고 **저장**하면 시작할 수 있습니다. 기존 계정과 새 계정 모두 처음에는 꺼져 있습니다. 사냥 칙령 자체를 끄면 추천 착용도 멈춥니다.

## 플레이어 설정

추천 설정은 같은 계열의 더 높은 점수 무기, 더 높은 점수의 방어구·장신구, 교체 장비의 창고 보관으로 구성합니다. 이후 필요한 부위만 바꿉니다. 머리·몸통·손·발·벨트·목걸이·왼쪽 반지·오른쪽 반지를 따로 설정합니다.

| 대상 | 화면의 선택 항목 | 교체 조건 |
| --- | --- | --- |
| 무기 | 같은 무기 계열 · 높은 점수 | 한손검·도끼·양손검 등 기존 무기와 종류가 같고 교체 후 무기 구성 점수가 높음 |
| 무기 | 모든 무기 계열 · 높은 점수 | 종류가 달라도 교체 후 무기 구성 점수가 높음 |
| 무기 | 변경하지 않음 | 무기와 보조 장비를 자동 교체하지 않음 |
| 방어구·장신구 | 점수가 높으면 착용 | 후보의 장비 점수가 현재 장비보다 높음 |
| 방어구·장신구 | 선택한 옵션이 더 높으면 착용 | 선택한 모든 옵션이 기존보다 높음. 전체 점수가 낮아도 허용 |
| 방어구·장신구 | 점수 상승 + 선택한 옵션 유지 | 점수가 높고 선택한 모든 옵션이 기존 이상 |
| 방어구·장신구 | 변경하지 않음 | 해당 부위는 자동 교체하지 않음 |

옵션을 사용하는 두 방식에서는 **비교 옵션 추가**로 장비 분해와 같은 부위별 옵션 목록을 엽니다. 기본 수치도 선택할 수 있으며, 추가 옵션과 구별하도록 `기본 수치 · 방어도`처럼 표시합니다. 선택한 항목에는 현재 착용품의 값과 제거 버튼을 표시합니다. 항목을 하나도 고르지 않으면 그 부위는 교체하지 않습니다. 후보에 없는 옵션은 조건을 만족하지 못하며, 현재 장비에 없는 옵션의 비교값은 0입니다. 옵션 값은 상세창과 같은 소수 둘째 자리 기준으로 비교합니다.

왼쪽·오른쪽 반지 중 조건을 만족하는 칸만 후보로 삼고 점수 개선폭이 가장 큰 칸을 선택합니다. 개선폭까지 같으면 왼쪽을 먼저 선택합니다. 빈 칸도 해당 부위 규칙을 적용합니다. 같은 계열 모드에서 빈 손에 무기를 추가할 때도 현재 무기 계열을 따릅니다. 방패 등 보조 장비를 착용하려고 유일한 공격 무기를 자동으로 해제하지 않습니다. 설정 저장 시 가방을 다시 훑지 않으며, 저장 이후 새로 획득한 장비부터 적용합니다. 창고 이동과 상점 되사기는 새 획득으로 취급하지 않습니다.

## 교체 장비와 창고 부족 설정

**장비 추천 착용 → 공통 설정 → 교체한 장비 처리**에서 **창고에 보관 / 분해 / 판매**를 선택합니다. 기본값은 창고 보관입니다. 실제 교체가 완료된 뒤 이전 착용품에만 적용합니다. 양손 무기 교체로 두 개가 벗겨지면 각각 처리합니다.

**창고가 가득 찼을 때 설정**을 누르면 **가방·자동 정리 → 공간 부족 대응**으로 이동합니다. 추천 착용과 일반 자동 정리의 창고 보관은 아래 규칙을 공유합니다.

| 설정 | 선택 항목 | 처리 |
| --- | --- | --- |
| 새 장비를 넣는 방법 | 판매가가 가장 낮은 장비 판매 | 판매 가능한 창고 장비 중 가장 저렴한 하나를 판매하고 보관 |
| 새 장비를 넣는 방법 | 점수가 가장 낮은 장비 판매 | 공통 장비 점수가 가장 낮은 하나를 판매하고 보관 |
| 새 장비를 넣는 방법 | 가장 먼저 보관한 장비 판매 | 획득 순서가 아닌 창고 입고 순서로 가장 오래된 하나를 판매하고 보관 |
| 새 장비를 넣는 방법 | 새 장비를 보관하지 않음 | 기본값. 새 장비를 가방에 유지 |
| 반복 사냥 | 사냥을 멈추고 창고 정리 대기 | 현재 전투는 끝내고, 창고가 가득 차 있으면 다음 전투 시작을 보류 |
| 반복 사냥 | 입고 규칙을 적용하며 계속 사냥 | 기본값. 창고 부족만으로 중단하지 않고 위 입고 규칙을 사용 |

- 열린 다른 탭에 빈칸이 있으면 판매하지 않고 그곳에 보관합니다. 가격·점수가 같으면 먼저 보관한 장비, 입고 순서도 같으면 아이템 ID 순으로 결정합니다.
- 잠금·장착·모든 캐릭터의 프리셋 참조·보석 장비는 자동 판매·분해에서 제외합니다. 가방·자동 정리의 강화·지정 전설 효과·세트 보호 및 전설·세트 자동 처리 허용 설정도 적용합니다.
- 팔 수 있는 장비가 없거나 골드·분해 재료 한도로 처리할 수 없으면 교체한 장비를 가방에 남깁니다. 초과 보관 중인 창고 탭은 기존처럼 꺼내기만 가능하며, 한 아이템을 넣으려고 여러 장비를 연달아 판매하지 않습니다.
- 창고 보관 대기 상태는 저장·재실행 후에도 유지합니다. 창고 정리 후 결과 화면에서 다시 시도하면 보관을 재시도합니다. 추천 착용이 켜져 있는 동안 대기 장비를 등급별 자동 정리로 판매·분해하지 않습니다.
- 계속 사냥을 선택해도 가방 부족, 목표 달성, 횟수 제한 등 다른 중단 조건은 유지합니다. 가방도 가득 찼을 때의 행동은 바로 아래에서 설정합니다.
- 수동 창고 이동·드래그는 자동 판매를 실행하지 않습니다. 창고에 넣거나 꺼냈다가 다시 넣으면 입고 순서가 갱신되고, 탭 이동·정렬은 순서를 바꾸지 않습니다. 기록이 없는 옛 저장은 기존 창고 목록 순서로 한 번만 초기화합니다.

## 장비 점수

실물 장비의 상세창에서 이름·등급 아래에 **장비 점수**를 표시합니다. 인벤토리·상점·창고·보상·훈련은 공통 `ItemTooltip`과 `ItemDetailView`를 사용하므로 동일한 장비는 동일한 점수를 표시합니다. 비교창은 착용품 왼쪽, 후보 오른쪽의 기존 배치를 유지하고, 후보에 교체 전후 점수를 함께 표시합니다. 아직 옵션이 정해지지 않은 도감 범위에는 가상의 확정 점수를 표시하지 않습니다.

점수는 빌드별 최종 피해량 예측이 아닌 **장비 자체의 성장 참고값**입니다. 레벨에 따른 실제 기본 수치와 추가 옵션을 반영하며 강화·각성·상위 옵션·걸작도 기존 수치 계산을 그대로 따릅니다. 희귀도 자체에 별도 보너스를 중복해서 붙이지 않습니다. 전설·세트 효과, 장착 보석, 직업 스킬·룬과의 조합은 점수에 넣지 않습니다.

`EquipmentScore.Version = 2`의 수식은 다음과 같습니다.

- 기본 점수: `100 × 실제 기본 수치 ÷ 부위별 기준 수치`. 공격 무기는 여기에 기본 공격 속도 배율을 곱합니다.
- 고정 저항: `25 × 실제 고정 저항 ÷ 35`.
- 장비 베이스의 고정 특성: `25 × 실제 고정 특성 수치 ÷ 같은 능력치 옵션 정의의 max`. 신규 재질의 방어·회피와 방패 막기 등도 포함하며 추가 옵션과 중복해서 세지 않습니다.
- 추가 옵션: 각 줄마다 `25 × 실제 옵션 수치 ÷ 해당 옵션 정의의 max`를 더합니다. 이 `max`는 카탈로그의 기준값이며, 현재 아이템의 레벨별 최대값으로 다시 나누지 않습니다. 따라서 레벨 상승에 따른 성장도 점수에 남습니다.
- 합산한 뒤 소수 첫째 자리에서 표시·비교합니다. 표시된 점수가 같으면 점수 조건에 따른 교체를 하지 않습니다.

| 기본 수치 | 기준 수치 |
| --- | ---: |
| 무기 공격 | 20 |
| 머리 방어력 | 20 |
| 몸통 방어력 | 40 |
| 손 공격 속도 | 2 |
| 발 이동 속도 | 3 |
| 벨트 생명력 | 160 |
| 목걸이 모든 저항 | 2 |
| 반지 치명타 확률 | 1 |

무기는 양손 구성 전체를 비교합니다. 쌍수 공격 무기의 기본 공격력과 공격 속도는 기존 `HeroStats`처럼 평균을 사용하며, 공격용 보조 장비의 공격력을 더합니다. 방패는 방어력 기준 24로 환산하고 추가 옵션·고정 저항은 실제 착용 개수만큼 합산합니다. 두 칸을 쓰는 양손 무기는 한 번만 계산합니다. 이 때문에 개별 무기 점수의 단순 합계와 **무기 구성 점수**는 다를 수 있습니다.

자동 장착 토글이 Off이면 아래 설정을 흐리게 표시하고 조작을 막습니다. On으로 켜면 기존 값이 돌아옵니다. 교체 장비 처리 방식은 작은 목록 상자로 선택하고, 창고 부족 설정 바로가기는 창고에 보관할 때만 표시합니다. 맨 아래 장비 점수 도움말 항목은 제거했으며 공통 아이템 상세의 점수 표시는 유지합니다.

## 교체 보호와 획득 처리

- **추천 착용 예외**에서 실제 장착 위치 10개를 체크합니다. 체크한 위치에는 자동 교체·빈칸 장착을 하지 않으며, 양손 무기나 호환되지 않는 보조 장비의 교체 때문에 간접적으로 해제되는 경우도 막습니다. 수동 장착에는 적용하지 않습니다. 전설·세트 효과 유지 항목은 별도의 자동 교체 조건에서 제거했습니다.
- 잠근 후보와 잠근 착용품은 자동으로 바꾸지 않습니다. 직업·요구 레벨·양손 점유·보조 장비 조합·가방 공간은 `EquipmentSlots.Plan`이 최종 검증합니다. 보석은 기존 장비에 남습니다.
- 자연 전리품, 보상 상자, 도박·제작 등 기존 `Economy.AddItem` 경로와 새 상점 구매에 적용합니다. 새 아이템을 소유한 뒤 추천 판단을 수행하고, 교체는 기존 `EquipmentSlots.Equip`만 사용합니다.
- 실제 사냥의 전리품 회수는 `GameStore.CommitRecommendedLoot`에서 획득·착용·교체 장비 처리·창고 자리 확보·회수 완료 표시·거래 영수증을 하나의 저장으로 처리합니다. 저장 실패 시 아이템과 착용 상태를 바꾸지 않고 사냥을 일시정지해 다시 시도할 수 있게 합니다.
- 착용 후 전투 장비 수치를 갱신합니다. 체력·자원을 회복시키거나 재사용 대기시간을 초기화하지 않으며, 새 최대값을 넘는 값만 줄입니다. 활성 물약 효과도 최대값 계산에 포함합니다.

## 디아블로 참고와 적용 범위

[디아블로 III 2.1.2 공식 패치 노트](https://news.blizzard.com/en-us/article/17561388/patch-2-1-2-now-live)의 Recovery는 회복과 생명력·강인함을 엮은 참고 지표이며, 고대 전설은 기본·보조 수치 범위를 높입니다. [디아블로 IV 시즌 4 Loot Reborn 공식 소개](https://news.blizzard.com/en-us/article/24077223/galvanize-your-legend-in-season-4-loot-reborn)는 드롭을 보고 업그레이드를 쉽게 판단하도록 옵션 구조를 단순화하고, 상위 옵션과 걸작으로 수치를 성장시키는 방향을 설명합니다.

여기서 **읽기 쉬운 성장 지표와 세부 옵션 비교의 병행**을 참고했습니다. 이 문서의 가중치와 자동 착용 규칙은 HELLSCRIPT의 장비·무기 조합에 맞춘 설계입니다. 디아블로 III·IV의 공식 공통 자동 착용 수식을 그대로 옮겼다는 의미는 아닙니다. 참고 자료의 과거 아이템 위력 상한을 현재 게임 규칙으로 사용하지 않습니다.

## 구현 소유자와 저장 호환

- 계산: [EquipmentScore.cs](../../Assets/HELLSCRIPT/Runtime/Core/EquipmentScore.cs).
- 부위 정책·검증·실행 연결: [EquipmentRecommendation.cs](../../Assets/HELLSCRIPT/Runtime/Core/EquipmentRecommendation.cs), [GameStore.RecommendedEquipment.cs](../../Assets/HELLSCRIPT/Runtime/Core/GameStore.RecommendedEquipment.cs).
- 실제 소유 상태는 `HeroSave.inventory`와 `HeroSave.edict`, 편집 상태는 `HuntEdictEditSession.Draft`, 전투 능력치는 `CombatSimulation.Stats`입니다. 상세창은 전달받은 장비의 복사본과 명시적인 `EquipmentViewSource`를 사용하며 저장을 변경하지 않습니다.
- 화면은 기존 `HuntEdictWindow` 내부의 [전용 탭 어댑터](../../Assets/HELLSCRIPT/Runtime/Presentation/HuntEdictWindow.Equipment.cs)입니다. 기존 창·스크롤·고정 저장/되돌리기·공통 테마를 유지합니다. 새 독립 창은 만들지 않습니다.
- 자동 보관·교체 처리는 [EquipmentAutomation.cs](../../Assets/HELLSCRIPT/Runtime/Core/EquipmentAutomation.cs), 기존 `EdictCleanupPolicy`·`Economy`·`Storage` 거래가 소유합니다. 입고 순서는 `Item.warehouseOrder`·`AccountSave.warehouseSequence`, 보관 대기는 `Item.pendingAutoStorage`에 저장합니다.
