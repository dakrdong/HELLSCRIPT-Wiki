# 퍼즐 튜토리얼 코어 v5

갱신일: 2026-10-07

English: [Puzzle tutorial core](Puzzle_Tutorial_Core.en.md)

신규 필수 튜토리얼 진입을 데이터 기반 퍼즐 러너로 전환했다. 현재 PR 범위는 레벨 1·2, 저장·재도전·복습·첫 클리어 경험치·스킬 트랙이다. 15레벨 콘텐츠, 허브, 운영·정비 퍼즐과 졸업은 뒤따르는 단계다.

## 실제 흐름과 소유자

`PuzzleTutorial.json`은 직업별 허용 스킬, 정찰·복기·힌트 문구, 누적 공개 옵션, 시간표 스폰·체력·공격·이동·예고·엘리트와 경험치를 정의한다. `CombatSimulation.Puzzle.cs`가 파 순번을 저장하며 실제 적 행동·회피·스킬·피해 엔진으로 싸운다. 제한시간 초과와 사망은 다른 실패다. 적 체력 하한·이동 고정·시간 비례 공격 보정은 제거했다.

`AccountGuide.puzzle`은 소유 영웅, 현재 레벨, 레벨별 시도·준비·클리어·힌트·최근 판정, 첫 진입 키트를 저장한다. `GameStore.StartPuzzleLevel`은 현재 레벨만 시작하고 진행 중 실행은 같은 체크포인트로 돌려준다. 종료된 시도는 먼저 결과를 저장해야 다시 시작할 수 있다. 다음 시도는 HP·위험·행동·쿨다운·AI 기억을 새 실행으로 초기화하고 저장된 답안은 유지한다.

`GameStore.RecordPuzzleAttempt`는 소유 체크포인트·영웅·실제 종료 조건을 검증한다. 클리어 XP 영수증은 실행 ID에 묶여 반복 요청에도 한 번만 지급한다. L1 +120 XP는 Lv2·남은 XP20, L2 +140은 Lv2·남은 XP160이다. 패배와 복습은 XP·금화를 지급하지 않는다. 졸업 보상은 이 PR에서 지급하지 않는다.

`PuzzleTutorial.CreateReplay`는 해당 레벨의 처음 상태를 복사한다. 원래 계정의 저장·재화·현재 장비·레벨은 변경하지 않는다. 과거 완료 계정은 필수 튜토리얼 면제를 유지하며 첫 퍼즐 복습도 별도 계정에서 실행한다.

스킬 창은 각 레벨의 허용 노드와 필요한 액티브 칸만 표시한다. 튜토리얼 동안 노드별 한 포인트로 스킬 트랙을 따른다. 추가 투자와 다른 노드는 일반 게임으로 넘어간 뒤 사용할 수 있다. 옵션과 스킬 제한은 표시와 `CommitHuntEdict`의 거래 검증 양쪽에서 적용한다. L2 이동·회피는 첫 실제 패배 뒤 열린다. 일반 균열의 단계 공개보다 퍼즐 목록을 먼저 사용한다.

## 이전과 복원

완료·레거시 면제 계정은 그대로 둔다. 미완료 v4 체크포인트는 새 러너에 들어갈 때 레벨 1로 전환한다. 소유 장비·레벨·경험치는 보존하고 첫 스킬 배분만 첫 수업 상태로 초기화한다. 이전 배분은 `edictLegacyBuild`에 보존한다. 계정 초기화 도구는 기존 전체 새 계정 생성 경로를 사용한다.

v5 체크포인트는 `tutorial-v5`, 현재 레벨·영웅·파 순번·필수 훈련 모드가 일치해야 한다. 잘못된 상태는 원본을 보존하고 거부한다. Unity JSON 복사에서 비어 있는 선택 필드가 객체로 생성되는 문제는 빈 퍼즐 진행과 목표 없는 빈 제단을 정규화해 해결했다.

## 사령관 대사 규칙 (2026-10-08)

- 사령관은 평생 군인으로 산 과묵한 여성 지휘관이다. 말은 짧고 건조하며 칭찬에 인색하되 인정할 때는 한마디로 한다. 플레이어를 수습으로 대하고 **해라체(~다/~라/~지)만** 쓴다. 존댓말·반말을 섞지 않는다.
- 대사는 대사만 한다. 몬스터 구성·수치·레벨 구성·시스템 설명을 읊지 않는다(구성 줄 `PuzzleScout`는 삭제). 보상·새 기술·피해 복기 같은 사실은 화자 없는 해설 줄로 분리한다.
- 레벨마다 `scout`(시작), `review`(실패·시간 초과), `clear`(성공)를 따로 쓴다. 힌트는 ① 지금 무엇이 문제인가 ② 무엇을 바꿔야 하는가 ③ 칙령의 어느 탭·항목인가(화면의 실제 이름을 따옴표로) ④ 사령관이 대신 써 둔 설정과 그 이름 순서다. 3번 힌트 뒤 한 번 더 누르면 `PuzzleInstructor`가 정답을 저장하므로 4번 힌트는 "대신 써 두었다, 열어서 확인하라"로 쓴다(대장간 레벨 L14는 대신 써 줄 칙령이 없어 힌트가 대장간에서 끝난다).
- **기대감 장치:** 클리어 직후 사령관이 구덩이 밖을 내다보는 한 줄(`hook`)을 마지막에 말한다. 1레벨 시작 대사에 "문은 시험을 끝낸 자에게만 열린다"를, 15레벨 시작 대사에 "이걸 넘으면 문이 열린다"를 두고, 15레벨 클리어에서 문이 열리는 장면을 가장 크게 쓴다. 단서는 문 → 더 큰 어둠 → 균열 → 문 너머 마을의 대장장이 → 칙령이 내게 온 까닭 → 사령관 자신의 궁금증 순으로 쌓는다. 안톤의 도착 대사에는 "균열은 아직 가장 얕은 곳만 열려 있다"를 둔다. 복습에서는 말하지 않는다.
- 안톤 진다크의 도착 대사는 하게체로 통일하고 조작법 안내(이동 패드·WASD)는 마을 이동 안내(F01)에 맡긴다.
- 범위 밖: 구덩이 v4·프롤로그 v2/v3 코드의 이전 대사, 가이드 본문(`Tutorials.cs`), 룬 교사·상점 주민 안내.
