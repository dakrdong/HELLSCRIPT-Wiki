# 패시브 경계와 장비 조합 구현

작성일: 2026-09-09 · 단계: D3 진행 중

## 1. 기준과 구현 범위

[패시브 전투 상세 시험안](../Design/HELLSCRIPT_Passive_Combat_Detail.md)에 18개 효과의 발동·시간·저장·장착 변경 기준을 먼저 작성했다. 기존 18개 패시브·최대 3개 장착·8부위·비용 감소 50%·치명 확률 75% 등의 수량과 상한을 유지한다. [보스 개발 기록](Boss_Expansion.md) 이후의 확장이다.

`GameController`가 진행하는 기존 `CombatSimulation` 안에 패시브 시간·발동·제거 처리를 모았다. 독립 전투 관리자나 새 이동 권한을 만들지 않았다. 기존 피해 계산·사망 정산·투사체·장판·충전의 처리 순서를 이어 쓴다. 씬·프리팹·패키지·프로젝트 설정·이미지 원본은 이 단계에서 직접 편집하지 않았다.

## 2. 달라진 동작

| 항목 | 결과 |
|---|---|
| 군중 속으로 | 동시 범위 공격의 첫 타격 전에 군중 조건을 확정한다. 먼저 맞은 적이 사망해도 같은 공격의 나머지 타격에서 보너스가 사라지지 않는다. 별도 충격파는 독립 실행 시점에 판정한다. |
| 끝나지 않는 회전 | 2초 유지 시점의 유료 틱부터 비용 감소를 적용한다. 누적 소수 오차로 2.25초까지 기다리지 않는다. 중단·재시작은 유지 시간을 초기화한다. |
| 착지 자세·탈출의 발걸음 | 실제 착지에서 각각 2초 버프를 생성한다. 타이머 잔여값 때문에 효과가 한 틱 연장되지 않게 했으며 발생·만료·장착 해제를 기록한다. |
| 피의 회복 | 같은 틱 처치에 한 번 회복하고 20개 전투 틱의 CD를 적용한다. 128초·256초 이후에도 1초 경계를 유지한다. 실제 회복량을 기록하며 HP 상한과 사망 우선 정산을 유지한다. |
| 처형자의 눈·마무리 사격 | 정확히 HP 30%인 대상도 포함한다. 계산 중간값을 저장된 HP와 같은 정밀도로 맞춘다. |
| 원소 교차 | 속성별 최근 적중 틱 여섯 개를 저장한다. 최근 4초에 서로 다른 두 속성이 있으면 4초 버프를 갱신한다. 최근 두 타격만 비교해 동일 속성 연속 적중 사이의 유효한 다른 속성을 잃던 공백을 보완했다. 1중첩이며 발동시킨 피해에 소급하지 않는다. |
| 장착 변경 | 훈련장에서 해제한 영웅 버프와 미완성 원소 기록을 제거한다. 과거 투사체·장판이 해제한 원소 교차를 재발동하지 못하게 했다. 이미 생성한 공격·보호막·덫·장판의 수치는 보존한다. |
| 화면 | 선택 가능한 18개 패시브 각각의 효과를 설명한다. 전투 효과 화면에 착지·이동·원소 버프의 남은 시간과 회오리 유지 할인을 표시한다. |

## 3. 저장 호환

전투 효과 버전은 4에서 5로 올렸으며 행동 버전 3과 규칙 버전 2는 유지했다. 구형 저장의 마지막 속성·적중 시각 하나를 해당 속성의 틱으로만 옮긴다. 알 수 없는 다른 속성 이력은 만들어 내지 않고 이미 남아 있던 원소 버프의 시간은 보존한다. 반복 정규화는 같은 상태를 유지한다. 더 새로운 효과 버전은 기존 보호 경계에서 불러오기를 거절한다.

새 범위 공격의 군중 조건은 피해 스냅샷에 담는다. 구형 공격 스냅샷에 그 정보가 없으면 기존처럼 적중 시점의 군중 조건을 사용한다. 과거에 확정하지 않았던 군중을 임의로 복원하지 않는다.

## 4. 검증 기록

패시브 검사에 사용하는 영웅은 아이템 생성기와 실제 장착 함수로 8개 부위를 채우며, 직업·부위·장착 제한을 먼저 검사한다. 개별 피해 공식을 분리하는 사례에는 화력·HP·방어 등을 통제한다. 실제 장비 능력치를 유지하는 비용·보호막·자원 회복 조합 검사와 구분하며, 단위 검사 수치를 6빌드의 밸런스 결과로 사용하지 않는다.

기존 `EffectTests`의 보호막·회복·덫 속박·둔화·제압, `ChargeTests`의 AP05 이동 충전과 합산 할인에 더해 `PassiveTests`에서 발동·경계·동시 타격·훈련장 해제·저장 후 미래 상태를 검사한다. SA 2세트와 LA03·AP04의 속박, AP03과 LA01·SA 4세트의 관통, MP03과 SMB 4세트·LM04의 연쇄, SW 2세트·WP02·LC02의 할인은 부위 충돌 없이 함께 장착해 확인한다.

초기 전체 검사에서는 HP 30%의 피해·치명 보너스 두 사례가 실패했다. 비교식을 단순히 곱셈으로 바꾼 중간 검사에서도 같은 결과가 나왔다. Mono가 중간 계산에 남긴 확장 정밀도를 저장된 단정도 HP에 맞추도록 명시적으로 변환한 뒤, 패시브 집중 검사 40/40개가 통과했다. 이후 LA03 속박 두 사례와 MP02 장판 보존·둔화 상한 한 사례를 추가했다.

최종 Unity Edit Mode 결과는 `Artifacts/Validation/passives-editmode-final.xml`의 **384/384개 통과**, 68.646307초다. 기존 341개와 새 패시브 검사 43개를 포함한다. 검사한 C# 71개의 해시를 `passives-final-source-manifest.json`에 기록해 실행 빌드와 같은 코드인지 확인한다. 이전 `passives-editmode-initial.xml`·`passives-editmode-verified.xml`의 각 두 실패와 집중 검사 결과를 최종 통과 결과로 덮어쓰지 않는다.

## 5. 실행 빌드와 실제 재시작

`passives-build-mac-final.log`에서 macOS 개발 빌드 성공과 오류 0개를 확인했다. 일반 앱을 네 번 실행하고 세 차례 실제 프로세스를 재시작했다. 네 실행 모두 종료 코드 0이며, `PassiveNativeEvidence/runtime-passives-smoke.txt`에 최종 통과 기록이 있다. 저장 폴더는 `Artifacts/Validation/PassiveNativeSave`, 화면·중간 상태 JSON은 `Artifacts/Validation/PassiveNativeEvidence`에 분리했다.

각 직업의 30레벨 영웅에게 실제 생성한 희귀 장비 8부위를 장착하고, 공격하지 않는 고정 표적을 배치했다. 실제 자동 행동으로 도약·후퇴 도약·서리 폭발·화염구를 실행해 버프를 얻었다. 버프가 생긴 뒤 새 판단만 멈추고 진행 중 행동·비용·투사체·버프를 보존했다. 재실행 직후 전투 ID·시간·난수·HP·자원·패시브 상태·현재 행동·피해 기록 수가 저장 값과 같음을 확인했다.

| 직업·버프 | 실제 실행 결과 |
|---|---|
| 전사 · 착지 자세 | 0.65초에 실제 도약 착지로 2초 버프를 얻고 저장했다. 재실행 후 1.5배속에서 전투 2.65초에 해제됐다. 생성 틱 13부터 만료 틱 53까지 정확히 40틱이다. |
| 궁수 · 탈출의 발걸음 | 0.55초에 실제 후퇴 도약 착지로 2초 버프를 얻었다. 재실행 후 2배속에서 전투 2.55초에 해제됐다. 생성 틱 11부터 만료 틱 51까지 정확히 40틱이다. |
| 마법사 · 원소 교차 | 0.40초 서리 폭발의 냉기, 1.35초 화염구의 화염 적중으로 발동했다. 속성 기록과 준비 중인 다음 화염구를 함께 저장했다. 재실행 후 해당 화염구가 2.15초에 적중해 버프를 갱신했고 1배속에서 6.15초에 해제됐다. 갱신 틱 43부터 만료 틱 123까지 정확히 80틱이며, 새 버프 중복 생성은 없었다. |

마법사의 두 화염구는 같은 장비 속성 보너스를 사용하며, 복원 후 두 번째 공격에만 원소 교차의 가산 피해 +0.1이 더해졌다. 실제 피해 기록의 가산 구간은 0.0676→0.1676이다. 이미 지급한 버프를 복원 때 다시 지급한 결과가 아니라 저장된 다음 행동이 새로 적중한 결과임을 공격 ID와 발동·갱신 기록으로 구분했다.

Metal 렌더러의 540×960 화면 10장을 확인했다. 세 직업의 스크롤형 패시브 설명 목록과 버프 발생·복원·만료 화면을 포함한다. 설명 목록의 마지막 항목은 추가 스크롤이 필요한 구성이다. 이번 검사는 앱 내부 UI 호출이며 실제 손가락·마우스 입력, Android, 접근성·성능, 여섯 빌드의 자연 성장·밸런스 검증은 아니다.

`Artifacts/Validation/passives-validation-summary.json`에 최종 소스·빌드 해시, 자동 검사, 실제 실행·재시작, 화면 크기, 문서 링크 검사 결과를 모았다.

## 6. 이어서 진행할 범위

15개 전설·6세트의 전체 상호작용과 여섯 추천 빌드를 실제 편집 화면에서 구성하는 검증이 남아 있다. 이번에 확인한 합법적 조합 몇 가지를 전체 조합 완료로 확대하지 않는다. D4 성장·마을·훈련·결과 분석, D5 온라인·보석·결제, D6 기기·입력·아트·음향·성능 기준도 계속 진행한다.

이후의 12회 생성 균열 비교와 경로·PM01 추천 규칙 보완은 [빌드 통합 개발 기록](Build_Integration_Expansion.md)에 이어서 기록한다. 이 문서의 384개 검사와 실행 빌드는 패시브 단계 당시의 증거로 보존한다.
