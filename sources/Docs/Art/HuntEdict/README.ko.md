# HELLSCRIPT 사냥 칙령 — 공통 UI 리소스

작성일: 2026-09-15

이 문서는 기존 승인 패키지에 동봉된 원본 설명입니다. 패키지 경로는 제작 당시 구조를 가리킵니다. 현재 게임용 PNG는 `Assets/HELLSCRIPT/Resources/Art/HuntEdict/`에 복사했으며, 실제 구현 상태는 사냥 칙령 게임 UI 구현 문서를 따릅니다.

스킬 외 탭의 119개 옵션과 프리셋·공유 화면에서 필요한 공통 외형을 묶었습니다. 기존 스킬 시안의 먹색·청회색, 낡은 황동과 초록색 상태 표시를 따릅니다.

## 포함된 리소스

| 구분 | 수량 | 파일 |
| --- | ---: | --- |
| 배경·상태 스킨 | 24종 | Textures/edict-ui-skins.png 한 장에 수록 |
| 탭·조작 아이콘 | 24종 | Glyphs/ 안에 개별 투명 PNG와 SVG |
| 체크·수치 조절 부품 | 8종 | Controls/ 안에 개별 투명 PNG와 SVG |

게임용 PNG는 아틀라스 1장과 개별 이미지 32장입니다. 스킨까지 따로 세면 총 56종입니다. Preview/의 안내 그림은 게임에 넣는 리소스 수에 포함하지 않습니다.

- index.html: 실제 스킨을 9분할하여 늘린 미리보기와 전체 아이콘 목록입니다.
- resource-manifest.json: 이름, 한국어·영어 설명, 이미지 경로, 분할 좌표와 권장 글자색입니다.
- unity-sprite-rects.csv: Unity의 왼쪽 아래 원점 기준으로 적은 분할 좌표입니다.
- generation-prompt.txt: 내장 이미지 생성 도구에 입력한 스킨 아틀라스 프롬프트입니다.
- Licenses/LUCIDE.txt: 기존 아이콘 원본의 라이선스입니다.

## 스킨 아틀라스의 순서

왼쪽에서 오른쪽으로 읽고, 그다음 행으로 내려갑니다.

| 행 | 1열 | 2열 | 3열 | 4열 | 5열 | 6열 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 공통 본문 | 일반 옵션 | 입력 영역 | 확인창 | 접힌 하위 옵션 | 펼친 하위 옵션 |
| 2 | 보조 버튼 | 보조 버튼 강조 | 누른 버튼 | 비활성 버튼 | 저장·확인 | 저장·확인 강조 |
| 3 | 순서 카드 | 이동 중 카드 | 드롭 위치 | 저장된 프리셋 | 현재 프리셋 | 빈 프리셋 |
| 4 | 일반 탭 | 선택한 탭 | 선택 해제 칩 | 선택한 칩 | 빈 선택 칸 | 오류·덮어쓰기 안내 |

스킨은 사각형 UI 영역 안을 채우는 불투명 재질입니다. 아이콘·조절 부품은 투명도가 있는 개별 PNG로 제공합니다.

## Unity 가져오기 기준

현재 프로젝트의 uGUI Image, Button, Toggle, Slider, ScrollRect와 기존 문구 처리 경로를 유지합니다. 이미지 파일을 프로젝트에 넣은 뒤 아래 설정을 적용합니다. 이 작업에서 게임 프로젝트에 자동으로 가져오거나 화면을 연결하지는 않았습니다.

### 스킨

- Texture Type: Sprite (2D and UI)
- Sprite Mode: Multiple
- Mesh Type: Full Rect
- Filter Mode: Bilinear
- Wrap Mode: Clamp
- Generate Mip Maps: 끔
- Non Power of 2: None
- Max Size: 2048 이상, 원본 1536 × 1024 유지
- 압축: 초기 외형 검토 시 None
- 분할: unity-sprite-rects.csv의 좌표와 이름을 사용합니다.
- Border: 왼쪽·아래·오른쪽·위 각각 32px
- Pixels Per Unit: 400
- 표시할 Image의 Type: Sliced
- 스킨 Image의 색상은 흰색으로 두어 원본 재질색을 유지합니다.

생성된 그림의 행 경계는 균등한 256px 간격과 조금 다릅니다. 자동 256 × 256 격자 자르기를 쓰면 다음 행의 테두리가 들어올 수 있습니다. 제공한 실측 좌표가 기준입니다. 원본 PNG를 다시 자르거나 재인코딩하지 않고 Unity에서 영역을 지정할 수 있습니다.

기준 Canvas의 Reference Pixels Per Unit이 100이면 32px 테두리는 8 UI 단위에 해당합니다. 작은 버튼에서 장식이 차지하는 공간이 지나치게 커지지 않도록 합니다.

### 아이콘·조절 부품

- Texture Type: Sprite (2D and UI), Sprite Mode: Single
- Alpha Is Transparency: 켬
- Filter Mode: Bilinear, Mip Maps: 끔, Wrap Mode: Clamp
- 탭·조작 아이콘: 128 × 128, 흰색 원본입니다. Image.color로 일반 문구색·황동색·비활성색을 적용합니다.
- 스위치·체크·슬라이더 부품은 상태별 색이 들어 있으므로 기본 Image.color는 흰색입니다.
- 아이콘과 손잡이는 종횡비를 유지합니다. 슬라이더 채움의 양, 스위치 손잡이 위치, 체크 상태는 UI 기능으로 바꿉니다.
- 텍스트·숫자·프리셋 이름·슬롯 번호는 이미지에 포함하지 않습니다. 현행 한국어·영어 문구 표와 데이터로 표시합니다.

## 상태와 대비

현재 프리셋은 초록색, 다른 저장 프리셋은 베이지색입니다. 베이지색 위의 글자는 어두운 갈색 #211B14를 사용합니다. 밝은 저장 버튼 강조 상태의 글자는 흰색 #FFFFFF를 사용합니다. 다른 기본 글자는 #E8E3D4입니다. 항목별 값은 resource-manifest.json에 있습니다.

접힌 하위 옵션은 청회색, 펼친 하위 옵션은 어두운 청동색입니다. 일반 옵션보다 열고 닫을 수 있는 영역을 쉽게 구분할 수 있습니다. 이동 중 카드와 드롭 위치도 별도 스킨으로 제공하지만 순서 변경 동작과 판정은 기존 드래그 처리기가 담당합니다.

모든 상위 탭이 스크롤 없이 보이는 배치, 고정 설명창, 작은 저장·되돌리기 버튼, 미저장 경고와 프리셋 덮어쓰기 확인은 기존 시안을 유지합니다.

## 제작과 확인

스킨 아틀라스는 Codex 내장 image_gen으로 생성했고, PNG의 생성 메타데이터에서 gpt-image / 2.0을 확인했습니다. 아이콘은 기존 Lucide 벡터 모양을 재사용했으며, 조절 부품은 단순 UI 도형으로 제작했습니다. 이 PNG들은 원래 투명한 벡터를 직접 렌더링한 결과이며 배경 제거를 하지 않았습니다.

아틀라스 24개 영역의 경계와 9분할 확장, 32개 개별 PNG의 RGBA·투명 픽셀·부드러운 경계, 미리보기의 이미지 로딩과 오류 유무를 확인했습니다. 본문 영역의 표본 픽셀에 대한 글자 대비도 확인했습니다. 이는 Unity 실행·실기기 입력·접근성 전체 인증을 뜻하지 않습니다.

게임 씬·프리팹·저장 데이터를 바꾸지 않았습니다. 실제 게임에 연결하고 기기별 크기를 검증하는 작업은 별도입니다.
