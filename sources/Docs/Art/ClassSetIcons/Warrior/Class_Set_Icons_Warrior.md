## 원본과 검수

생성기가 반환한 1254×1254 RGBA PNG 원본 43개를 `originals/`에 바이트 그대로 보존했습니다. 1024×1024 규격본은 네이티브 알파를 유지한 비례 축소와 투명 여백 추가로 만들었습니다. 배경 제거와 알파 재구성은 하지 않았습니다.

[64px 밝은·어두운 배경 시트](qa-contact.png)에서 43개를 확인했습니다. 장비 부위와 문양을 구별할 수 있고, 눈에 띄는 사각 배경이나 매트 테두리가 보이지 않습니다. 중앙 76% 여백, 실제 투명 픽셀, 원본 해시와 규격 변환 재현은 파일 검사로 확인했습니다. 항목별 판정은 manifest의 `qa.visual`에 기록했습니다. 거인의 분노 7개는 [별도 검수 기록](REF_SW08-production.json)과 [보조 시트](REF_SW08-qa-contact.png)도 제공합니다.

`REF_SW06_P05` 목걸이의 첫 생성본은 끈이 완전히 닫히지 않아 내장 도구로 수정했습니다. 최초 시안과 프롬프트는 `rejected/`에 보존했으며 [수정 기록](REF_SW06_P05.edit.json)에 참조 원본과 실제 요청을 남겼습니다. 최종 시안은 닫힌 고리 형태와 내부 투명 공간을 확인했습니다.

총 43개 후보가 준비됐으며 제작 누락은 없습니다. 게임 내 연결, Unity 임포트·실행과 실기기 검증은 수행하지 않았습니다. 이 한계와 실제 모델 정보 부재 때문에 게임용 확정 승인을 표시하지 않았습니다.
