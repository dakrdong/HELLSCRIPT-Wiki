## 원본과 규격본

내장 생성기는 1024px 요청에도 **1254×1254 RGBA PNG**를 반환했습니다. 그 사실을 감추거나 원본이 1024px였다고 기록하지 않았습니다. 생성 원본 43개는 `originals/<ID>.png`에 바이트 그대로 보관했고 도구가 반환한 경로와 SHA-256을 기록했습니다.

게임 프로젝트에 제공하는 규격본은 `Assets/HELLSCRIPT/Resources/Art/ClassSetIcons/<ID>.png`의 **1024×1024 RGBA PNG**입니다. 이미 존재하는 네이티브 알파의 전체 영역을 기준으로 비율을 유지해 축소하고 투명 여백을 더했습니다. 알파를 유지한 재샘플링이므로 규격본의 픽셀은 생성 원본과 다릅니다. 크로마키, 배경 제거, 알파 재구성, 내용의 재도색은 수행하지 않았습니다.

## 검수 결과

[파일 검증 기록](validation.json)에서 43개 모두 다음 항목을 통과했습니다.

- PNG와 RGBA 형식, 실제 완전 투명 픽셀 및 불투명 픽셀의 존재를 확인했습니다.
- 모든 규격본은 1024×1024이며 비투명 픽셀 전체가 중앙 76% 영역 안에 있습니다.
- 생성 경로의 원본과 보관한 원본의 바이트 해시가 일치합니다.
- 기록한 내보내기 과정을 다시 계산한 픽셀과 규격본이 일치합니다.
- 43개 규격본의 파일 해시가 모두 다르며 ID 누락과 중복이 없습니다.

제작 담당자는 생성 결과와 [가독성 검수 시트](qa-contact.png)를 직접 확인했습니다. 시트는 각 항목을 실제 64px 크기로 어두운 배경과 밝은 배경에 표시하고 112px 보조 미리보기를 제공합니다. 각 장비의 부위와 세트 특징을 구별할 수 있고, 아이콘 크기에서 사각 매트나 눈에 띄는 가장자리 오염이 보이지 않습니다. 항목별 판정과 한영 메모는 manifest의 `qa.readability64`와 `qa.edges`에 남겼습니다. 이 시각 판정은 제작 담당자의 검수이며 검증 스크립트가 독립적으로 그림을 평가한 결과가 아닙니다.
