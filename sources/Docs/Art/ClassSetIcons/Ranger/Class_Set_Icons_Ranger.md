# Ranger 신규 세트 아이콘 제작 기록

작성일: 2026-09-22

[English](Class_Set_Icons_Ranger.en.md)

신규 Ranger 8세트의 장비 35개와 세트 문양 8개를 제작했습니다. 총 43개 모두 `generated_candidate` 상태입니다. 내장 이미지 생성 도구가 모델명을 반환하지 않아 실제 모델은 `unknown`으로 기록했습니다. 요청 기준 모델은 `gpt-image-2`이며, 이 모델을 사용했다고 확정하지 않습니다.

## 범위와 기준

ID·한영 이름·효과는 읽기 전용 인계 사본 [sets.json](../brief/sets.json)과 [인계 설명](../brief/README.md)을 따릅니다. 문양의 `name`은 세트 원문 이름을 보존하며, 문양임을 덧붙인 표시는 `displayName`에 분리했습니다. Ranger의 효과 20단계는 해당 8개 세트 문양을 공유합니다. 단계 숫자는 그림에 넣지 않았습니다.

기존 `EquipmentAtlas.png`, `GlobalHUD/menu-character.png`, `GlobalHUD/status-sword.png`를 직접 확인해 가죽·금속의 마모와 명암을 참고했습니다. 기존 아이콘을 복제하지 않고 각 ID를 개별 요청으로 새로 생성했습니다. 게임 UI, 연결 코드, 전투 데이터, 씬과 프리팹은 이 제작 범위에 포함하지 않았습니다.

## 생성 원본과 규격 내보내기

내장 도구에 1024×1024 투명 PNG와 중앙 여백을 요청했으나, 최종 선택된 43개 생성 원본은 모두 1254×1254로 반환됐습니다. 원본 파일을 `originals/<ID>.png`에 바이트 그대로 보존하고 생성 경로와 SHA-256을 기록했습니다.

게임용 경로 `Assets/HELLSCRIPT/Resources/Art/ClassSetIcons/<ID>.png`에는 원래 알파 영역을 기준으로 비례 축소하고 투명 여백을 더한 1024×1024 PNG를 저장했습니다. 축소는 알파를 미리 곱한 색 공간에서 수행했으며, 재표본화로 출력 픽셀은 원본과 달라집니다. 배경 제거, 크로마키, 알파 재구성이나 의미적 내용 편집은 수행하지 않았습니다. 원본과 규격본을 구분해 기록합니다.

[전체 검수 시트](qa-contact.png)는 각 항목을 64px의 어두운 배경과 밝은 배경에서 나란히 보여 주고 아래에 112px 확대 참고본을 제공합니다. 장비 부위와 세트 문양이 구분되며, 얇은 끈과 표면 흠집은 작은 크기에서 약해져도 큰 형태가 유지됩니다.

총 45회의 개별 생성 요청에서 최종 후보 43개를 선택했습니다. `REF_SA03_P04`의 첫 결과는 목걸이 끈이 잘려 재생성했고, `REF_SA08_P01`의 첫 결과는 어두운 64px 배경에서 대비가 약해 활대와 은빛 외곽면을 강화해 재생성했습니다. 탈락본과 사유·프롬프트는 `rejected/` 및 항목별 manifest 기록에 보존했습니다. 기존 GUID를 담은 `.meta`는 이 교체 과정에서 변경하지 않았습니다.

## 기록과 검증 범위

- [manifest.json](manifest.json)은 43개 항목의 ID, 파일, 한영 효과, 실제 프롬프트, 모델 근거, 해시, 알파 수치, 시각 검수와 재생성 이력을 제공합니다.
- `evidence/<ID>.json`은 원본과 규격본의 실제 수치 및 내보내기 절차를 제공합니다.
- [validation.json](validation.json)은 Ranger 43개 파일의 검증 결과를 제공합니다. 오류·미완료·경고는 모두 0개입니다.
- [progress.json](progress.json)은 생성 43개, 재사용 0개, 미완료 0개의 최종 상태를 기록합니다.

이 검증은 파일과 제작 담당자의 시각 검수입니다. Unity 임포트, 게임 실행, 실제 UI 연결과 실기기 검증은 수행하지 않았습니다. 세트 효과의 런타임 구현 상태를 이 이미지 제작 결과로 판단하지 않습니다.
