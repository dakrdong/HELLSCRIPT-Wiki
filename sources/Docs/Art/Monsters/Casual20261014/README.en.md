# Casual monster codex portraits and aspect correction

2026-10-14 · [한국어](README.md)

Scope: redraw all 35 codex monsters in the approved casual StyleD and keep their faces visible. Work started in a managed worktree from main `53d6a3e13304a781f9823134ba0f497bafb78621`, preserving unrelated art and work.

Use the actual warrior sheet and StyleD title as mandatory references, preserving each monster species, silhouette and identifying props from its existing portrait and production spec. Portraits are opaque squares with bold outlines and simple cel shading. The 29 normal monsters use ivory backgrounds; all six bosses use pale lavender. Keep the entire head, chin, horns and ears within the image. Nonhuman creatures retain their distinct head, mouth or crystal core.

The shared list/detail `MonsterCodexWindow.Portrait` fits the entire source into the allotted frame, preserving its aspect ratio and full UVs. Existing PNG metadata/GUIDs, saves, kill counts and combat definitions are preserved.

Generation uses built-in `image_gen`. It returns no actual model identifier, so provenance is `unknown` and `productionApproved: false`; use of `gpt-image-2` is unverified. Prior dark fantasy originals remain recoverable from Git history. Store prompts, IDs, hashes and actual dimensions in the production manifest.

Completed all 35 redraws with 39 built-in generation calls, including four corrections. All runtime PNGs are opaque RGB, 1254x1254, totaling 63,061,786 bytes. Existing 33 metadata files are unchanged; Unity generated N23/B06 metadata. Pending world models remain pending while ready codex portraits display. Boss/ID labels sit below faces, fit one line and do not overlap; opaque shared UI backgrounds keep them readable on bright art. Final 17 focused window cases and 15 UI contract regressions passed. Native macOS development acceptance covered five sizes, Korean/English, actual kill/save/reload and pointer/raycast clicks/dragging. The last paint-only correction passed window tests and compilation; unchanged face/geometry/interaction results are reused, and native screenshots precede that paint correction. Unchanged gameplay/save areas reuse latest main full tests and focused description repairs. Physical mobile and enlarged text remain untested; no public game release was deployed.
