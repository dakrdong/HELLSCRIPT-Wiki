# 전사 스킬 아이콘 제작 기록

작성일: 2026-09-22

[English](Class_Skill_Icons_Warrior.en.md)

일반 액티브 16개, 궁극기 2개와 패시브 18개를 각각 생성했습니다. 모두 1254px 네이티브 RGBA 원본이며 원본과 게임 사본의 바이트가 같습니다. 검수와 전체 범위는 [통합 제작 기록](../Class_Skill_Icons.md), 항목별 요청과 효과는 [manifest 폴더](manifests/)에 있습니다.

전사는 거친 철과 어두운 가죽에 옅은 금빛 가장자리를 사용했습니다. 액티브는 회전, 긴 도약, 전방 분쇄, 방사형 충격, 사슬 끌기, 선형 파동처럼 움직임의 방향을 구분했습니다. W02는 긴 궤적 끝의 내려찍기입니다. W17은 두 선조와 중앙 전사, W18은 큰 수직 망치로 일반 기술보다 강한 중심을 만들었습니다.

패시브는 지속되는 성향을 정적인 상징으로 표현했습니다. WP06은 넓은 눈, WP07은 낙인을 가리키는 손으로 구별했고, WP03의 두 다리와 WP11의 돌로 둘러싸인 발도 서로 다른 실루엣입니다. 문자, 숫자, UI 프레임과 바닥을 넣지 않았습니다.

36개 원본 및 실제 64px의 [어두운 배경](../qa/Warrior-64px-dark.png)과 [밝은 배경](../qa/Warrior-64px-light.png)을 검토했습니다. 주요 형태의 잘림, 불투명 배경과 눈에 띄는 매트·헤일로가 없음을 확인했습니다. 미세 재질은 축소 시 사라질 수 있으므로 중심 형태로 구분하도록 판단했습니다. 중앙 76% 지침과 낮은 알파의 경계 픽셀은 측정값과 경고를 보존했습니다.

모델은 반환 근거가 없어 `unknown`, 승인 상태는 `candidate`입니다. 기존 에셋 재사용, 배경 제거, 크로마키, 원본 크기 조정은 없었습니다. UI·전투 코드 변경이나 런타임 검증은 수행하지 않았습니다.
