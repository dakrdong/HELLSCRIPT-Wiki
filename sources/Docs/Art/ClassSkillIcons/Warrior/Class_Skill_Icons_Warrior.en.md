# Warrior skill icon production record

Updated on: 2026-09-22

[한국어](Class_Skill_Icons_Warrior.md)

Individually generated 16 normal actives, 2 ultimates and 18 passives. Every file is a native 1254px RGBA master, byte-identical to its preserved original. See the [combined record](../Class_Skill_Icons.en.md) for verification scope and [per-ID manifests](manifests/) for actual prompts and effects.

Warrior artwork uses worn iron, dark leather and pale-gold edge lighting. Actives distinguish rotation, a long leap, forward crushing, radial impact, chain pulls and linear waves through their motion. W02 shows a long arc ending in a downward slam. W17 uses two ancestors surrounding the living warrior; W18 uses a massive vertical hammer for a stronger ultimate silhouette.

Passives are static symbols of ongoing combat tendencies. WP06 uses a wide eye while WP07 points a hand toward a brand. WP03's two braced legs differ from WP11's stone-protected boot. No text, numbers, UI frames or floors are baked into masters.

All 36 originals and actual 64px [dark](../qa/Warrior-64px-dark.png) and [light](../qa/Warrior-64px-light.png) previews were inspected. No visibly clipped primary forms, opaque backgrounds, mattes or halos were observed. Fine material detail can disappear at small sizes, so primary shapes carry distinction. Measured central-76% and faint-border warnings remain preserved.

Model identity is `unknown` and approval is `candidate`. There was no asset reuse, background removal, chroma key or resizing of originals. UI/combat code changes and runtime verification are outside this task.
