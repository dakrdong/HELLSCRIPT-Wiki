# 마법사 스킬 아이콘 제작 기록

작성일: 2026-09-22

[English](Class_Skill_Icons_Mage.en.md)

마법사의 전체 인계 범위는 일반 액티브 16개, 궁극기 2개, 패시브 18개로 총 36개입니다. 이 제작 묶음에서는 `M01`~`M18`과 `MP01`~`MP09`의 27개 원본을 제작하고 검수했습니다. `MP10`~`MP18`의 9개는 병렬 제작 담당자가 완성했습니다. 전체 완료 여부는 상위 통합 검사와 각 ID의 manifest를 기준으로 판단합니다.

## 전체 36개 통합 완료

후반 패시브 MP10~MP18도 병렬 제작과 검수를 마쳤습니다. 최종 통합 검사에서는 마법사 36개 모두 통과했습니다. 아래의 27개 기록과 비교판은 최초 담당 묶음의 근거이며, 전체 36개 상태는 [통합 검사](../qa/validation.json)와 [최종 64px 비교표](../qa/Mage-64px-dark.png)를 기준으로 확인합니다.

## 원본과 제작 기준

- [고정 인계 JSON](skills.json)의 ID, 한영 이름, 설명, `visualConcept`, 태그와 장비 연계를 기준으로 제작했습니다. 현재 체크아웃의 오래된 전투 정의를 제작 기준으로 사용하지 않았습니다.
- 원본 인계 작업 공간은 읽기 전용으로 확인했습니다. 원본 경로는 `/Users/t8g-2410-pn-005/.codex/worktrees/class-skill-runtime/HELLSCRIPT`입니다.
- 원본 프로젝트의 `EquipmentAtlas.png`, `GlobalHUD/status-flame.png`, `status-mana.png`, `passive-MP03.png`, `passive-MP01.png`를 직접 열어 확인했습니다. 장비 아틀라스의 어두운 재질과 밝은 가장자리, HUD의 단순하고 읽기 쉬운 중심 형태를 참고했습니다.
- 기존 패시브 이미지는 256px 선형 문양과 UI 판을 포함하므로 이번 회화풍 원본으로 재사용하지 않았습니다. 이 묶음의 27개는 모두 별도 요청으로 새로 생성했습니다.

최초 프롬프트는 1024px 원본과 중앙 76% 여백을 요청했습니다. 후속 인계 지시에서 내장 도구가 반환한 **1254×1254 정사각형 네이티브 RGBA 원본**도 유효한 마스터로 인정하고, 중앙 76%는 잘림 여부를 확인하는 가이드로 정리했습니다. 이번 원본은 모두 1254px이며, 크기 조정이나 여백 삽입 없이 반환된 PNG를 그대로 보관했습니다. 실제 요청 프롬프트는 변경하지 않고 남겼습니다.

## 저장 위치와 생성 근거

- 게임 프로젝트의 원본은 `Assets/HELLSCRIPT/Resources/Art/ClassSkillIcons/Mage/ID.png`에 저장했습니다.
- [raw](raw/)에는 반환된 네이티브 PNG를 같은 ID로 보관했습니다. 게임 폴더 사본과 원본은 SHA-256이 일치합니다.
- [prompts](prompts/)에는 항목별 실제 요청을, [manifests](manifests/)에는 한영 효과 요약, 경로, 생성 근거, 모델 정보, 알파와 시각 검수 결과를 기록했습니다.
- 내장 `image_gen`만 사용했습니다. 반환 근거는 `image_url`과 `output_hint`이며 모델명은 제공되지 않았습니다. 따라서 `model: unknown`, `modelEvidence: null`, `approval: candidate`를 유지합니다.
- 배경 제거, 크로마키, 색상 교체, SVG 대체, 기존 아이콘 복제, 외부 API/CLI 생성은 수행하지 않았습니다.
- 새 `.meta`는 공통 검증 도구의 단일 Sprite 설정과 새 GUID로 만들었습니다. 기존 GUID를 재사용하거나 변경하지 않았습니다.

## 의미와 형태

액티브는 주된 동작을, 패시브는 지속되는 전투 성향을 표현했습니다. 화염구의 구형 폭발과 잔상, 눈보라의 낙하 얼음과 회전 바람, 번개의 연결선, 얼음 창의 넓은 톱니 날처럼 큰 형태를 구분했습니다. 궁극기는 삼원소 충돌 덩어리와 강화된 현자의 상반신으로 강한 중심 질량을 만들었습니다. 프레임, 글자, 숫자, UI 배경을 원본에 넣지 않았습니다.

`M13` 마력 회수는 두 손을 고정한 상태에서 푸른 에너지가 안쪽의 핵으로 모이는 형상입니다. 무쿨타임, 정지 중 기본 마나 회복 10배, 이동·공격 시 취소, 피격 시 유지라는 최신 설명을 따랐습니다. 고정 JSON의 `parameters.cooldownSeconds`에는 이전 값 `14`가 남아 있지만 설명과 `visualConcept`를 우선했고, 인계 JSON이나 전투 코드를 수정하지 않았습니다.

## 검수 근거

직접 제작한 27개는 다음 검사를 통과했습니다.

- PNG의 네이티브 RGBA 구조, 1254×1254 크기, 실제 완전 투명 픽셀과 가시 알파를 확인했습니다.
- 게임 폴더 사본과 보관 원본의 해시 일치, 서로 다른 이미지 해시와 GUID를 확인했습니다.
- 실제 64px 크기의 [어두운 바탕 비교판](qa/Mage-64px-dark.png)과 [밝은 바탕 비교판](qa/Mage-64px-light.png)을 열어 가독성과 항목 구별을 확인했습니다.
- 256px 확대 비교판 6개와 생성 당시 원본을 확인했습니다. 불투명 매트, 배경 무늬, 눈에 보이는 주형태 잘림은 발견하지 못했습니다.
- 각 ID의 관찰 내용은 [27개 시각 검수 기록](qa/manual-review-27.json)에 남겼습니다. 자동 측정치는 [클래스 검사 결과](qa/report.json)에 있습니다. 클래스 검사에는 병렬 제작 중인 9개도 포함되므로, 이 27개 묶음의 완료와 전체 클래스 완료를 구분합니다.

중앙 76% 범위를 넘는 형태와 일부 원본의 외곽 `alpha=1` 픽셀은 자동 경고로 보존했습니다. 원본을 잘라내거나 알파를 정리하지 않았으며, 밝고 어두운 바탕에서 실제 잘림이나 매트가 보이는지를 별도로 확인했습니다. 모델 근거 미확인도 경고로 남깁니다.

게임 UI 연결, 씬, 프리팹, 전투 코드와 아이콘 연결 코드는 수정하지 않았습니다. Unity 에디터에서의 실제 가져오기, 게임 런타임, 모바일 실기기 검증은 이번 이미지 제작 검수에 포함되지 않습니다. 커밋·푸시와 전체 108개 통합 검사는 상위 제작 작업에서 수행합니다.
