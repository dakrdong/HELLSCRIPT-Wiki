# 위상 문양 제작 기록

작성일: 2026-09-22

## 제작 범위

전설 장비의 고유 효과 141개를 상징하는 위상 문양을 제작합니다. 대응키는 인계 JSON의 전설 장비 ID를 그대로 사용하며, 게임용 파일명은 `aspect-ID.png`입니다. 이 작업은 이미지 제작만 담당합니다. 별도의 위상 추출·획득·장착 시스템이나 UI 연결을 구현하지 않습니다.

인계 원본은 `class-skill-runtime` 작업 공간의 `Docs/Art/SkillExpansionBrief`에서 읽었습니다. `brief/SkillExpansionBrief-README.txt`와 `brief/aspects.json`은 이번 작업 공간에 보관한 사본이며, 현재와 이전 사본의 SHA-256은 `source-provenance.json`에 기록했습니다. 제작 중 갱신된 인계 내용도 비교해 반영했습니다. ID와 이름 변경은 없었고, `DES_LM44`의 발동 조건을 제작 전에 ‘자신의 균열 결계 안에서 마력 회수를 1.5초 이상 중단 없이 유지’로 수정했습니다. 현재 작업 공간의 오래된 기획보다 이 인계 파일의 ID, 한영 이름, 설명, 연결 스킬을 우선합니다.

## 아트 기준과 생성 경로

원본 프로젝트의 `EquipmentAtlas.png`, `GlobalHUD/passive-WP04.png`, `passive-MP02.png`, `passive-AP02.png`를 직접 열어 확인했습니다. 어두운 금속 질감과 밝은 모서리는 장비 아트에서, 단순하고 분명한 실루엣은 HUD 아이콘에서 참고했습니다. 기존 이미지를 복사하거나 색만 바꾼 항목은 없습니다.

항목마다 내장 `image_gen`을 개별 호출합니다. 효과의 발동 조건과 결과를 함께 읽고, 끌어오기·회복·속박·보호·재사용 대기시간 단축을 구별하는 형태를 사용합니다. 전체 콘셉트는 `concepts.json`, 실제 요청 프롬프트는 `manifest.json`의 각 항목에 보관합니다.

기본 요청 모델은 `gpt-image-2`지만, 현재 내장 인터페이스에는 모델 선택 인자가 없고 반환 결과에도 모델 근거가 없습니다. 따라서 실제 모델은 **unknown**이며, 모든 생성물은 **후보 자산**입니다. 이미지 검수를 통과해도 모델 확인이나 게임 내 채택이 완료된 것으로 표시하지 않습니다.

## 네이티브 원본과 검수용 사본

네이티브 투명 PNG만 사용합니다. 최신 인계 규격은 1024px을 목표로 하되 내장 도구의 1254px 네이티브 원본도 허용합니다. 최종 자산 폴더의 `aspect-ID.png`와 `native/`의 보관본은 반환된 원본과 바이트까지 동일합니다. 실제 크기와 알파 통계, 원본·자산 해시는 [manifest.json](manifest.json)에 남깁니다. 표시 크기와 Unity 임포트 설정은 UI 통합 단계에서 정합니다.

작은 화면에서 보수적으로 비교하기 위한 **검수용 사본만** 다음 과정으로 만듭니다. 이 사본은 `qa/previews/`에 있으며 게임용 원본을 대체하지 않습니다.

1. 원본의 실제 알파가 있는 영역을 기준으로 빈 여백을 정리합니다.
2. 알파를 보존한 비례 축소로 가장 긴 변을 756px에 맞춥니다.
3. 1024px 정사각형 투명 캔버스 중앙에 배치합니다.

검수 사본은 크기와 여백만 조정합니다. 크로마키, 배경 제거, 재채색, 복제 변형을 사용하지 않습니다. 알파가 없는 반환물은 미완료로 남기며 자동으로 보정하지 않습니다. 초기에 만든 1024px 자산 사본은 네이티브 원본 허용이 확인된 뒤 원본으로 교체했고, 이후 1024px 사본은 검수에만 사용합니다.

## 검수와 진행 상태

`manifest.json`은 141개 항목 전체의 상태를 관리합니다. 한영 이름·효과, 직접 연결 스킬, 파일 경로, 콘셉트·프롬프트, 생성 시도, 모델 근거, 재사용 여부, 원본·마스터 해시, 알파·여백 검사, 시각 검수를 기록합니다. `generation/`에는 항목별 생성 반환 경로를 보관합니다.

자동 검사는 원본의 RGBA, 완전 투명 픽셀, 불투명 픽셀, 허용된 정사각형 크기, 반환 원본과 자산의 해시 일치, ID 누락·중복, 파일 중복, GUID 충돌을 확인합니다. 원본의 가장자리 알파 수치도 그대로 기록합니다. 검수 사본은 별도로 1024px 크기, 투명한 가장자리, 중앙 76% 안의 배치를 확인합니다. `qa/contact-*.png`는 이 사본을 192px 미리보기와 밝고 어두운 바탕의 실제 64px 표시로 나란히 제공합니다. 세부 질감이 줄어들어도 주요 동작과 실루엣이 구별되는지, 가장자리에 배경색이나 테두리가 남지 않는지 시각적으로 검수합니다.

새 PNG와 폴더에는 고유 GUID를 부여합니다. 이번 작업에서 이미 부여한 GUID는 원본 교체 후에도 유지했습니다. 초기의 임시 Sprite 임포트 설정은 제거하고 최소 메타데이터만 남겨 UI 통합 담당자가 실제 설정을 정할 수 있게 했습니다. 이 작업 이전에 존재한 자산과 메타데이터는 변경하지 않았습니다. 실제 Unity 임포트·UI 연결·macOS 런타임·모바일 실기기 확인은 이 이미지 제작 작업의 검증 결과에 포함하지 않습니다.

최신 수량은 [검사 결과](qa/validation.json)와 [제작 진행표](Class_Aspect_Icons_Progress.md)에 기록합니다. 생성, 자동 검사 통과, 시각 검수 통과, 모델 확인은 서로 다른 상태입니다. 이 브랜치를 main에 병합하거나 공개 위키에 배포하는 작업은 인계 범위에 포함되지 않습니다.
