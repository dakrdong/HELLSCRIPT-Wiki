# 스킬 트리 화면 이미지 제작 기록

작성일: 2026-09-27 · [English](Skill_Tree_UI_Art.en.md)

사냥 칙령 스킬 트리 개편에 쓴 장식 이미지 다섯 장의 제작 기록입니다. 사용자가 스킬 트리를 꾸미는 데 필요한 이미지를 GPT로 만들어 쓰라고 요청했습니다. 화면 구성과 검증은 [사냥 칙령 스킬 트리 통합](../../Implementation/Hunt_Edict_Skill_Tree.md)에 있습니다.

## 제작 방식

`codex exec`(codex-cli 0.155.0)로 설치된 imagegen 스킬의 내장 `image_gen` 경로를 사용했습니다. 이미지마다 별도 요청을 보냈습니다. 기존 스킬 아이콘 두 장, 기존 원형 테두리, 개편 전 스킬 화면을 화풍 참고로만 첨부했습니다. 다른 게임의 이미지·로고·화면은 사용하지 않았습니다.

생성 결과를 그대로 복사했습니다. 크기 조정, 잘라내기, 색 보정, 배경 제거를 하지 않았고, 투명 이미지는 생성기가 만든 알파를 유지합니다. 다섯 장 모두 PNG 안에 C2PA 정보가 있고 생성 도구 이름이 `ChatGPT`, `gpt-image`로 기록되어 있습니다. 정확한 모델 식별자는 확인할 수 없어 `unknown`으로 남깁니다. 서명 검증은 하지 않았습니다.

프롬프트, 원본 경로, 해시, 시도 횟수와 검수 결과는 [manifest.json](manifest.json)에 있습니다.

| 파일 | 크기 | 사용 위치 |
| --- | --- | --- |
| `tree-backdrop.png` | 1024×1536, 불투명 | 스크롤되는 트리 뒤에 고정된 배경. 새겨진 나무 문양의 어두운 석판 |
| `node-frame-active.png` | 1254×1254, 투명 | 액티브 스킬의 원형 테두리. 트리·장착 칸·설명 머리글 |
| `node-frame-passive.png` | 1254×1254, 투명 | 패시브 스킬의 사각 테두리. 트리·설명 머리글 |
| `node-frame-ultimate.png` | 1254×1254, 투명 | 궁극기의 네 갈래 문장 테두리. 트리·궁극기 칸·설명 머리글 |
| `skill-point-gem.png` | 1254×1254, 투명 | 트리 머리글의 남은 스킬 포인트 표시 |

## 검수

Codex는 테두리 안쪽 원이 완전히 투명한지 엄격하게 검사했고, 세 테두리 모두 두 번씩 다시 생성했습니다. 최종본도 안쪽에 알파 값 1/255인 점이 남아 불합격으로 기록되었습니다. 이 값은 눈에 보이지 않고, 그 자리에는 스킬 아이콘이 깔리므로 채택했습니다. 가운데와 네 모서리는 모두 완전히 투명합니다.

테두리의 투명한 안쪽 폭을 직접 측정했습니다. 원형은 가장 넓은 반지름, 사각형은 변 가운데까지의 거리를 테두리 절반 폭에 대한 비율로 기록합니다. 액티브 0.657, 패시브 0.684, 궁극기 0.579입니다. 화면 코드의 `ActiveHole`·`PassiveHole`·`UltimateHole`이 이 값을 사용해 아이콘을 안쪽 폭에 맞추고 테두리의 안쪽 가장자리가 아이콘 끝을 덮게 합니다. 개편 전 화면에서 아이콘이 상자 위쪽에 붙어 어긋나 보이던 문제는 이 크기와 가운데 정렬로 해결합니다. 테두리를 바꾸면 아래 검사로 값을 다시 확인합니다.

```sh
python3 Docs/Art/SkillTreeUi/measure.py
```

## 가져오기 설정과 용량

기본 설정은 테두리·보석 최대 512px, 배경 최대 1024px이며 압축합니다. `ResourceTextureBudget`에 같은 한도의 ASTC 6×6 항목을 추가했습니다. 휴대폰에서 테두리는 약 250px 이하로 표시되고, 배경은 패널 전체를 덮습니다.

## 상태

스킬 트리 화면에서 사용 중입니다. 생성 모델을 확인할 수 없으므로 출시 승인 자산으로 표시하지 않습니다.
