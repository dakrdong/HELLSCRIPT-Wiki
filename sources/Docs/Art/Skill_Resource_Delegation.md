# 스킬·장비 이미지 제작 인계

2026-09-22 · [English](Skill_Resource_Delegation.en.md)

사용자는 개별 아이템마다 작업을 만들지 않고 종류별로 나누도록 확정했습니다. 다음 네 가지 이미지 제작 작업을 별도 작업 공간에서 시작했습니다. 각 작업에 항목별 ID, 한국어·영어 이름, 효과, 연계 기술과 표현할 핵심 형태를 전달했습니다. 원본은 [공통 제작 안내](SkillExpansionBrief/README.md)와 그 문서의 JSON 목록입니다.

| 담당 종류 | 제작 범위 | 작업 브랜치 |
| --- | --- | --- |
| 스킬 | 직업별 36개, 총 108개 아이콘 | `codex/class-skill-icons` |
| 전설 장비 | 기존 123종과 추가 18종, 총 141개 장비 아이콘 | `codex/class-legendary-icons` |
| 세트 장비 | 신규 24세트의 장비 105개와 세트 문장 24개 | `codex/class-set-icons` |
| 위상 | 전설 효과 141종의 위상 문장 | `codex/class-aspect-icons` |

통합 시점에 스킬 아이콘 108개, 전설 장비 아이콘 141개, 세트 장비 105개와 문양 24개의 파일 검사와 기존 시각 검수 기록을 확인했습니다. 위상 문양은 생성된 123개를 포함하며, 그중 122개가 시각 검수를 통과했습니다. `LM29`는 검수 실패, 신규 연계 문양 `DES_LW41–46`·`DES_LA41–46`·`DES_LM41–46`의 18개는 미제작 상태로 남습니다. 별도 완료 파일이 없음을 사용자에게 확인했습니다.

네 종류 모두 생성 모델은 `unknown`, 승인 상태는 `candidate`입니다. 원본·알파·GUID와 기존 경계 경고를 유지하며, 병합만으로 게임 화면 채택이나 출시 승인을 의미하지 않습니다. 제작 결과와 검사는 각 작업의 `Docs/Art/ClassSkillIcons`, `ClassLegendaryIcons`, `ClassSetIcons`, `ClassAspectIcons` 기록에서 관리합니다.

## 공통 제작 조건

장비 아이콘은 물건의 형태를, 위상 문장은 효과의 상징을 보여 줍니다. 스킬은 효과를 알아볼 수 있는 동작과 실루엣을 사용하고, 패시브는 지속적인 성질을 상징합니다. 기존 게임의 완성 이미지나 로고를 복사하지 않고 HELLSCRIPT의 개별 원본을 제작합니다.

배경 없는 PNG와 실제 알파를 요구합니다. 원본 크기, 파일 해시, 투명 픽셀, 가장자리, 작은 크기의 식별 가능성과 항목 ID를 검증해 기록합니다. 공통 원본 목표는 1024px이지만 내장 생성기가 반환하는 1254px 등 충분한 해상도의 원본도 허용합니다. 크기를 맞추기 위한 별도 이미지 편집은 요구하지 않습니다. 실제 크기를 명시한 원본을 인계하고 UI 연결 단계에서 표시 크기를 정합니다.

생성 모델은 확인 가능한 근거로만 기록합니다. 도구가 모델 정보를 제공하지 않으면 `unknown`으로 남기며, `gpt-image-2`나 출시 승인 자산으로 표시하지 않습니다. 이미지별 미확인 사항은 각 제작 기록에서 유지합니다.

## 연결 경계

각 작업은 자신의 이미지 폴더와 제작 기록만 수정합니다. 스킬 계산, 장비 효과, 저장, 씬, UI 배치, 애니메이션과 시각 효과 코드는 변경하지 않습니다. 이미지를 스킬 슬롯에 배치하거나 일반 플레이에서 새 장비를 공개하는 일은 UI 통합 작업에서 처리합니다.

마력 회수 M13은 정지 충전을 나타내고, 단순 피격으로 깨지는 장면으로 표현하지 않습니다. DES_LM44의 최신 효과는 자기 결계 안에서 1.5초 이상 집중했을 때 4초 동안 최대 HP 10% 보호막을 얻는 것이며, 재발동 간격 6초는 충전 재시작으로 초기화되지 않습니다. 전설 장비와 위상 작업은 같은 효과 ID를 사용하되 서로 다른 용도의 이미지를 제작합니다.

작업 브랜치에서 공개 위키를 배포하지 않습니다. 각 결과를 병합하는 작업이 병합된 `main`에서 문서·DB·이미지·원본 근거를 함께 검증하고 게시합니다.
