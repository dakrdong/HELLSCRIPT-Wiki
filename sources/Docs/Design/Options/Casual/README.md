## 양식

다른 캐주얼 시안과 같은 규칙이다.

- **판:** 크림 `#fff6e3` + 위쪽 흰 광택, 남색 외곽선 `#2a3150` 3px, 아래 그림자 `0 5px 0 잉크` + `0 14px 24px rgba(42,49,80,.22)`, 안쪽 5px에 `2px dashed rgba(42,49,80,.13)` 바느질, 위 가운데 노랑 둥근 젬(지름 18, 가로 화면은 숨김). 모서리 26(PC)·18(가로)·24(세로). 판은 화면 가장자리에서 12(PC)·8(가로·세로) 안쪽에 뜬다.
- **제목:** Jua, 노랑 `#ffd23f` + 잉크 8방향 외곽선 + 아래 그림자, 가운데. 닫기는 오른쪽 위 코랄 둥근 단추(`#ff8b8e→#ff5a5f`, 잉크 3px, 흰 ×).
- **탭:** 흰 바탕 `#ffffff` + 테두리 `#8a93b5` 2px + 아래 그림자 `0 2px 0 #8a93b5`, Jua. 선택은 노랑 그라데이션 `#ffe26b→#ffc21a` + 잉크 3px + 아래에 노랑 마름모 꼬리. 탭은 한 줄에 같은 폭으로 놓는다(5개, 튜토리얼 중 4개). PC는 아이콘+글자 가로, 세로는 아이콘 위·글자 아래, 가로 화면은 글자만.
- **카드(`sec`):** 흰색, 테두리 `#c9d0e2` 2px, 모서리 16, 아래 그림자 `0 2px 0 #c9d0e2`. 머리줄은 아이콘 젬(둥근 사각 흰 바탕 + 잉크 고리 + 색 아이콘) + Jua 제목 + 오른쪽 값.
- **슬라이더:** 물약 창의 막대+마커 그대로. 막대는 잉크 2px 테두리 + 위쪽 광택, 채움은 노랑(가시거리·전체 음량)·하늘(음악)·초록(효과음) 그라데이션, 위치는 마름모 두 개 + 가운데 선 마커. 값은 Jua 오른쪽(주황 `#c46d00`·하늘 `#1f6fb5`·초록 `#26722f`). 가시거리는 −/+ 둥근 단추(흰 바탕 + 잉크 2px)와 50·100·150% 눈금, 100%에 막대 위 눈금을 둔다.
- **선택 칩(화면 비율):** 탭과 같은 흰/노랑 상태. 칩 안에 비율 모양의 작은 사각형 아이콘(긴 변 22px)을 그린다.
- **선택 카드(지도 표시·언어):** 흰 바탕 카드, 선택은 노랑→흰 가로 그라데이션 + 잉크 2px + 아래 그림자 + 오른쪽 노랑 체크 원. 지도 표시는 왼쪽에 미니 전장 썸네일(겹침 지도·미니맵 창·표시 안 함), 언어는 파랑 EN·주황 한 원 배지.
- **영웅 카드:** 인장(원형, 잉크 링)+Jua 직업 이름+성별 표시+레벨 알약. 현재 캐릭터는 선택 카드 모양 + 오른쪽 아래 체크, 균열 중 잠긴 카드는 회색 + 자물쇠.
- **체크 줄(전체 음소거):** 물약 창의 체크 상자 줄. 켜면 카드가 노랑으로 켜지고 음량 막대 세 개가 흐려진다.
- **단추:** 흰색(`#ffffff`, 잉크 2px, 아래 그림자)이 기본, 확정은 초록 그라데이션 `#8ee07a→#4cbf55` + 흰 글자 + 잉크 외곽, 저장 재시도는 코랄. 높이는 PC 56·세로 50·가로 40.
- **안내 상자:** 정보는 하늘색(`#eef7ff`, 테두리 `#bfe0ff`, 글자 `#1f4f7d`), 경고·잠금은 코랄 연한 바탕(`#fff0f0`, 테두리 `#ff5a5f`, 글자 `#8c2327`), 안내 문서는 노랑 연한 바탕(`#fff9dc`, 테두리 `#ffd23f`).
- **글꼴:** 제목·탭·숫자·버튼·카드 제목은 Jua, 본문은 Noto Sans KR 400. 시안에서 쓰는 글자 크기는 아래 치수 표.
- **색 요약:** 잉크 `#2a3150`, 크림 `#fff6e3`, 노랑 `#ffd23f`·`#ffc21a`·`#ffe26b`, 주황 `#ff9f1c`, 하늘 `#35a7ff`, 초록 `#4cbf55`·`#8ee07a`, 코랄 `#ff5a5f`·`#ff8b8e`, 민트 `#5ee0d4`, 빈 막대 `#e6e9f0`, 보조 글자 `#4a5272`·`#6b7393`. 작은 주황 글자는 흰 판에서 대비를 위해 `#b86200`·`#c46d00`으로 진하게 쓴다.

## 탭 본문 (순서가 곧 게임의 순서)

1. **화면:** 가시거리(−/+·막대·눈금·저장 안내) → 지도 표시 방식(카드 3장·저장 안내) → 화면 비율(화면에 맞춤 칩, 가로 비율 5개, 세로 비율 5개, 현재 비율, 저장 안내).
2. **소리:** 소리 설정 카드(전체 음량·음악·효과음 막대 3개) → 전체 음소거 체크 줄 → 효과음 들어 보기·기본 음량으로 단추 두 개 → 안내. 저장 실패면 카드 위에 코랄 안내 + 저장 재시도.
3. **언어:** English·한국어 선택 카드(선택하면 시안 전체가 그 언어로 바뀐다).
4. **캐릭터 변경:** 타이틀로 이동 단추 + 설명 → 안내 상자 → 만들어진 영웅 카드(전사 남·여, 마법사 남·여, 궁수 남·여 순서). 균열 중이면 경고 상자 + 현재 영웅만 켜짐, 나머지는 잠금.
5. **계정:** (튜토리얼 중이면 맨 위에 타이틀로 이동 + 경고) → UID 줄과 복사 단추 → Google 연동 카드(수집 대기 알약, 확정 단추) → 안내 상자 3개.
6. **게임 안내:** 한 줄 소개 + 번호 젬 카드 6개 + 노랑 안내 2개. **전투 상태:** 균열 단계, HP·자원·보호막 막대, 현재 행동, 배속, 처치·게이지, 스킬 줄(상태 알약), 상자·성소.

## 시안이 게임과 다르게 제안하는 것 (적용하려면 결정이 필요하다)

- 탭 5개를 한 줄에 놓는다(지금 게임은 폭 620 미만에서 2열이라 5개가 두 줄이 된다).
- 판이 화면 가장자리에서 8~12 안쪽에 뜬 카드이고 제목이 가운데다(지금은 가장자리까지 채운 판, 제목은 왼쪽).
- 탭 아이콘, 카드 머리줄 아이콘 젬, 비율 칩의 비율 모양 아이콘, 지도 표시 썸네일, 가시거리 눈금과 기본값 표시, 영웅 카드의 인장·레벨 알약, 언어 카드의 배지는 새 요소다.
- 영웅 성별은 번들 글꼴에 ♂♀가 없어서 `assets/icons/gender-*.svg`로 그린다.

## 확인한 범위

- `node tools/smoke.js`로 모든 값 연결, 탭·언어·상태·입력 규칙을 확인했다(방향 3 × 언어 2 × 탭 7 × 상태 4 조합).
- Chrome으로 24장을 렌더해 눈으로 확인했고 소리 막대 겹침, UID 줄, 인장 배지 겹침을 고쳤다.
- 캔버스 호스트, 터치, 실기기, 키보드 이동, 게임 안의 모양은 확인하지 않았다. 게임에 적용하지 않았다.
