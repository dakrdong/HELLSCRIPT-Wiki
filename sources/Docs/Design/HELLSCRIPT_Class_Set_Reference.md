## 공통 설계 규칙

### 적용 범위

직업마다 8종인 신규 후보 24종입니다. 기존 SW·SA·SM·SWB·SAB·SMB 6종과 별개인 기획 데이터이며, 교체·통합 정책은 아직 정하지 않았습니다. 기존 세트 정의·전투·드롭·저장을 변경하지 않습니다. 각 후보의 개별 장비, 효과 단계, 한국어·영어 문구, 출처를 함께 제공합니다.

### 원작과 각색의 구분

원작은 Diablo IV: Lord of Hatred의 Talisman에 장착하는 부적 세트입니다. HELLSCRIPT의 장비 세트와 같은 구조가 아닙니다. 실제 공용 5종과 직업 전용 12종의 효과 구조를 참고해 24종을 구성했습니다. 여기서 정한 이름·장비 부위·3/4/5/6개 구성·효과 수치는 HELLSCRIPT의 제안이며, 디아블로 4의 공식 번역이나 그대로 옮긴 원작 수치가 아닙니다.

### 출처의 확인 범위

2026-09-22에 Blizzard 공식 확장팩 소개와 3.1 패치 노트에서 Talisman 세트 체계를 확인하고, InfinityBuilds의 직업 필터 및 17개 개별 페이지를 열어 이름·구성 수·효과를 확인했습니다. 개별 효과 요약은 커뮤니티 DB를 출처로 삼습니다. 최신 게임 클라이언트 전수 대조나 현재 시즌의 최적 빌드 검증은 수행하지 않았습니다.

### 장비 구성과 계수

기존 무기·머리·몸통·손·발·허리·목걸이·반지의 8개 부위 분류만 사용합니다. 각 세트 안의 부위는 중복되지 않습니다. 무기는 해당 직업의 기존 무기 베이스 중 유효한 종류로 구성하고, 한 개의 양손 무기가 두 부위를 차지해도 세트 수는 1개입니다. 실제 소유·장착 중인 서로 다른 정의 ID만 세며 보관함·미리보기·다른 직업 장비는 제외합니다. 희귀도 표기 Legendary는 기존 세트 아이템 분류를 따르는 제안입니다. 기본 능력치·접사·품질은 기존 장비 규칙을 따릅니다.

### 효과 단계

3개 구성은 2/3, 4개 구성은 2/4, 5개 구성은 2/3/5, 6개 구성은 2/4/6개 착용 효과를 가집니다. 달성한 하위 효과를 함께 적용합니다. 명시적으로 교체한다고 적힌 수치만 교체합니다. 예를 들어 거인의 분노 6개 효과는 4개 효과의 피해·범위를 교체하고 준비·회복 시간 +20%는 유지합니다. 같은 수의 장비로 구성된 후보들은 직업별로 서로 다른 주력 행동을 갖습니다.

### 피해 계산과 상한

D는 기존 주능력 적용 후의 공격값입니다. D80%는 D×0.8이며, 최종 피해의 80%라는 뜻이 아닙니다. 일반 피해 증가는 기존 가산 구간에 한 번만 더합니다. 자원 비용 감소 50%, 재사용 대기시간 감소 40%, 공격·이동속도 증가 50%, 치명 확률 75%, 버프 피해 감소 50%, 획득 반경 6m, 기술 보너스 등급 +5의 기존 상한을 공유합니다. 방어도·저항 증가를 피해 감소 %p로 해석하지 않습니다. 물리 방어 75%·비물리 저항 70% 상한을 유지합니다. 범위 +%는 원 기술 반경·길이·폭에 곱하고 각도·최대 대상 수·이동 거리는 유지합니다.

### 적중과 추가 효과

직접 피해는 원 기본공격·원 기술의 직접 적중이며 장판 틱·출혈·세트 추가 피해는 제외합니다. 직접 사격은 기본 사격·A01·A02입니다. 시전당 효과는 관통·다중 화살·연쇄의 대상 수만큼 다시 발동하지 않습니다. 새 세트의 추가 피해는 기본공격·직접 기술·행운의 적중으로 재분류하지 않으며 추가 세트·전설 발동, 자원·회복 발동, A06 충전 소비를 다시 만들지 않습니다. 별도 표기가 없으면 새 추가 피해·지속 피해는 치명을 굴리지 않습니다. 원 기술의 기존 치명·A06 규칙은 유지합니다.

### 시전·시간·재발동

유효 시전은 자원·대기시간·실행 가능 판정을 통과한 시전입니다. 무료 이동·방어 기술도 해당합니다. 시간은 전투 진행 시간을 사용하고 일시정지 중에는 흐르지 않습니다. 시전 조건·열기·복수·자원 비율은 시전 전 확정하고 새 중첩은 그 시전에 소급하지 않습니다. 내부 대기시간은 실제 발동 때 시작하며 일반 쿨타임 감소로 줄이지 않습니다. 재시전·장비 탈착으로 내부 대기시간을 초기화하지 않습니다. 확률은 저장한 시전 ID와 전투 난수열로 한 번만 추첨합니다.

### 충전과 지연 공격

선조의 전열·삼원소의 대순환의 다음 공격 충전은 다음 해당 유효 시전 시작에 예약·소비합니다. 준비 중 시간 만료는 예약을 취소하지 않지만 중단·빗나감·장면 종료에는 환급하지 않습니다. 적중 조건이 있는 추가 공격은 적중하지 않으면 발생하지 않습니다. 삼원소 충전은 충전을 만든 세 번째 시전에 쓰지 않으며 기존 장판 틱에도 쓰지 않습니다. 눈먼 그림자는 발사 시점의 원점·방향을 보존하고 원 사격이 빗나가도 발생하되, 같은 대상은 복제 화살 수와 관계없이 1회만 맞습니다.

### 출혈·동상·독

이 세트들의 지속 피해 저장량은 공격측 보정을 한 번 적용한 방어 전 값으로 보관합니다. 실제 피해나 잔여 피해 정산 때 대상 방어·저항만 한 번 적용하며 공격측 증가를 다시 곱하지 않습니다. 붉은 상흔·삼독의 화살은 새 총량과 기존 잔여량 중 큰 값을 쓰고 시간을 갱신하되 틱 주기는 되돌리지 않습니다. 동상은 각 적립분이 6초에 걸쳐 소진되는 기록이며 남은 합계가 신규 시전 스냅샷 D90%를 넘으면 초과 적립분을 버립니다. 더 약한 신규 시전이 기존 저장량을 깎지는 않습니다. 같은 계열 눈보라 중첩은 강한 유효 틱 하나만 적립합니다. 정산은 이 세트 소유의 남은 기록만 제거합니다.

### 연계·보호막·대상 상태

연계 제한 시간은 첫 유효 단계에서 시작하고 완료·만료 때 기록을 비웁니다. 거수 사냥은 표식 대상 변경·사망·표식 만료 시 미완성 횟수를 비웁니다. 삼원소 보호막은 그 순환에서 새로 추가된 원소당 현재 최대 체력 5%를 남은 보호막에 더하고 15%에서 제한하며, 중복 원소는 양·시간을 갱신하지 않습니다. 다른 동일 원천 보호막은 기존 보호막 갱신 규칙을 따릅니다. 기절·빙결·둔화는 기존 보스 제압·면역 규칙을 따릅니다. 최대 체력·자원·회복 상한을 넘어 회복하지 않습니다.

### 장비 변경과 저장

요구 개수 미달·직업 변경·전투 장면 종료 때 해당 단계의 버프·충전·지연 공격·지속 피해를 제거합니다. 전투 중 탈착 후 재장착해도 남아 있던 내부 대기시간은 보존합니다. 후보 ID를 기존 세트 ID로 자동 변환하거나 소유 아이템에 주입하지 않습니다. 현재 파일은 실행용 Resources 밖에 있으며 runtimeEnabled=false입니다. 향후 실행 구현 시 진행 중 전투 저장의 시전·예약·난수·지속 피해 복원 정책을 별도로 검증해야 합니다.

### 보상·드롭·밸런스

골드와 경험치 증가는 몬스터 처치 보상에만 적용합니다. 영웅 경험치와 룬 숙련 경험치를 분리하고 거래·제작·분해·퀘스트·중복 보상에는 적용하지 않습니다. 드롭 가중치는 미정(null)이며 드롭 후보에 등록하지 않았습니다. 숫자는 비교용 초안으로, 동일 아이템 레벨·품질·강화·전투 시간에서 기존 세트·희귀·전설 혼합과 비교해야 합니다. 구성 수가 많다고 항상 더 강하도록 정하지 않습니다.

## 데이터 관리와 다음 검증

JSON은 원작 출처와 HELLSCRIPT 제안을 별도 항목으로 저장합니다. `sources`는 원작 이름·부적 수·효과 요약, `sets`는 제안 세트·개별 장비·수치 매개변수입니다. `runtimeEnabled=false`, `proposedDropWeight=null`을 유지합니다. 기존 실행용 세트 DB의 수량은 이 파일 때문에 늘어나지 않습니다.

```sh
python3 tools/class_set_reference.py build
python3 tools/class_set_reference.py check
```

현재 검사는 요청 수량·ID 중복·직업별 기술·부위 충돌·효과 단계·출처 연결·한영 문서 일치를 확인합니다. 전투 성능이나 저장 복원 성공을 증명하지 않습니다. 실행 구현 전에는 동일 투자비의 단일 보스·정예·군중전 비교, 2/3/4/5/6개 착용 경계, 중복 타격과 재귀 발동 방지, 탈착·중단·장면 종료·저장 복원, 기존 전설과의 부위 경쟁을 검증해야 합니다.
