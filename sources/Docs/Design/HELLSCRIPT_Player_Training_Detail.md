# HELLSCRIPT 플레이어 훈련 상세안

작성일: 2026-09-09 · 기존 훈련 격리 정책의 구현 기준

## 1. 목적과 진입

현재 캐릭터가 실제로 사용할 수 있는 행동을 고정 환경에서 시험한다. 성소의 훈련장 버튼은 실제 계정·영웅을 깊은 복사한 훈련으로 진입한다. 레벨·소유 장비·강화·접사·스킬 장착·패시브를 그대로 가져오며 잠긴 스킬은 실행하지 않는다. 레벨 30의 전체 스킬 시험은 개발 명령으로만 진입하며 일반 훈련 버튼과 분리한다.

훈련은 균열 단계 선택과 무관한 단계 1 환경을 사용한다. 세 배속에서 전투 시간은 동일하게 흐르며, 각 훈련은 60전투초·표적 전멸·영웅 사망·수동 종료 중 먼저 발생한 시점에 끝난다. 시간 경계는 정수 전투틱으로 비교한다. 60초 생존을 균열 클리어·보상·승률로 표시하지 않는다.

2026-09-09의 [배속 잠금·사용권 정책](HELLSCRIPT_Speed_Access_Detail.md)에 따라 현재 사용자 훈련은 1배속만 제공한다. 위 세 배속은 내부 계산 검증 범위로 유지한다. 향후 훈련의 고배속 제공·사용권 차감 여부는 BM 상세 설계에서 따로 정하며, 초도 기준안은 1배속 훈련과 사용권 미차감이다.

## 2. 고정 배치의 시험값

| 훈련 | 배치와 관찰 목적 | 시험값 |
|---|---|---|
| 단일 표적 | 움직이거나 공격하지 않는 표적 하나를 상대로 자원과 스킬 순환을 본다. | 시작 방 중앙에서 앞쪽 2m, HP 100,000 |
| 다수 표적 | 움직이거나 공격하지 않는 표적 8개를 상대로 범위·관통·선회를 본다. | 3열 격자, 열 간격 2m·행 간격 1.5m, 각각 HP 100,000 |
| 위험 패턴 | 고정 위치의 잿불 사술사 3명이 실제 예고와 피해 영역을 만든다. 이동·회피·생존 규칙을 본다. | 위치 (-4,2)/(0,3)/(4,2)m, HP 100,000, 단계 1 공격력, 초기 CD 2/2.5/3초 |

영웅 시작점은 기존 훈련 방 중앙에서 뒤쪽 4m다. 세 훈련은 각각 고정 시드를 사용한다. 높은 HP는 60초 동안 행동을 관찰하기 위한 표적 전용 값이며 균열 적의 수치를 바꾸지 않는다. 위험 훈련은 무적 시험이 아니므로 현재 캐릭터가 사망할 수 있다. 다른 두 훈련은 피격 성능을 평가하는 근거로 쓰지 않는다.

## 3. 복사본과 저장

훈련의 XP·골드·재료·장비·강화·초회·실클리어·소탕 횟수·최근 균열 기록은 실제 계정에 반영하지 않는다. 훈련 상태를 진행 중 균열로 저장하지 않는다. 앱을 종료하면 훈련을 다시 시작한다. 진행 중 균열이 있으면 먼저 해당 균열을 마무리해야 한다.

훈련 중 행동 적용은 훈련 복사본에만 적용한다. 실제 계정에 남기고 싶으면 기존의 슬롯 저장 버튼을 명시적으로 사용한다. 훈련 중 조건을 바꾸어도 HP·자원·CD를 초기화하지 않는다. 화면의 해금 표시, 실행 차단 이유, 피해 계산의 레벨은 같은 복사본을 기준으로 한다.

## 4. A/B 비교와 후속 작업

후속으로 구현한 행동 A/B의 진행·동일 조건·전체 누적 집계·저장 기준은 [훈련 A/B 비교 상세안](HELLSCRIPT_Training_Comparison_Detail.md), 실제 구현과 검증은 [훈련 비교 개발 기록](../Implementation/Training_Comparison_Expansion.md)을 따른다. 장비 교체와 분석의 남은 범위는 별도로 유지한다.

기본 훈련의 완료 범위는 실제 캐릭터 훈련·해금·격리·60초 종료다. 후속 A/B는 A 실행 직전의 영웅·장비·배치·시드를 보존하고 B에서 행동·스킬·패시브를 편집한다. 두 시도의 변경 행과 전역 목표·이동·물약·장착 차이를 보여 주며, 실제 영웅이 성장해도 B의 기준을 바꾸지 않는다.

피해·사용 횟수·피격·이동·자원 부족은 실제 사건에서 누적하며 로그 상한 이후도 포함한다. 비교 저장·실제 계정 적용 미리보기와 N10 예고 공격에 한정한 이동기 회피 집계를 연결했다. 장비 교체 훈련, 모든 적을 대상으로 한 회피 분석, 사냥 칙령 저장·공유 이관은 후속 작업이다.
