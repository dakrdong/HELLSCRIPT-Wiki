# 일반 적·정예 전투 상세 시험안

작성일: 2026-09-09 · D3 구현 기준

[콘텐츠 카탈로그](HELLSCRIPT_Content_Catalog.md)의 N01–N12·E01–E06과 [완료 기준](HELLSCRIPT_Gameplay_Completion_Checklist.md)의 개별 패턴을 실행하기 위한 세부 시험값이다. 기존 HP·공격·속도 배수와 정예 조합 제한은 유지한다. 보스 3종의 정식 패턴은 이 공통 처리 다음 단계이며, 기존 보스 동작을 정식 패턴 완료로 집계하지 않는다.

## 공통 규칙

준비 시작에 방향·위치를 고정한다. 새 공격의 CD는 준비 시작부터 계산하고, 기절·빙결로 준비가 중단되어도 되돌리지 않는다. 돌진은 속박에도 멈추며 벽 앞에서 종료한다. 이미 발사된 투사체·생성된 장판·사망 예고는 시전자의 사망이나 제어로 취소하지 않는다. 같은 틱의 사망·승패는 기존 통합 정산을 사용한다.

인지 범위는 14m와 벽 판정, 시야를 잃은 뒤 추적 기억은 4초다. 추적은 마지막으로 본 위치로 향하며 보이지 않는 영웅의 새 위치를 사용하지 않는다. 상태·방향·남은 준비·이동·연속 횟수·공격 ID·특성 CD·분노·사체 소비를 저장한다. 생성된 공격의 피해량은 발사·장판 생성·돌진 시작 때 확정한다. 종지기가 죽으면 이후 확정되는 공격에서 오라가 해제되며 이미 발사된 공격은 원래 값을 유지한다.

영역의 원·고리·부채꼴·직선 자료를 실제 피해, 위험 조건, 화면 예고가 함께 사용한다. 투사체는 기존 연속 선분 충돌을 사용하고 돌진은 이동한 선분을 검사한다. 원·고리·부채꼴 장판은 영웅 중심점을 기준으로 판정한다. 화면상의 예고는 피해 전까지 영웅을 따라가지 않는다.

## 일반 적의 보완 수치

| 대상 | 실행 기준 |
|---|---|
| N01·N06 기본 타격 | 0.65초 준비, 반경 2.5m·전방 120도, D100%, CD 1.5초다. N06의 사망 폭발은 기본 공격과 별개다. |
| N02 | 0.8초 준비, 최대 8m 직선 돌진, 속도 12m/s, 충돌 폭 1.2m, D150%, CD 5초다. 한 돌진에서 한 번만 맞는다. |
| N03 | 사거리 9m, 1초 준비, 속도 10m/s·반경 0.2m 화살 한 발, D100%, CD 2초다. 사선이 막히면 유효한 발사 위치를 찾는다. |
| N04 | 1.2초 준비, 대상 위치 반경 2.5m에 4초 독 장판, 초당 D50%, CD 6초다. 0.5초 간격 여덟 번이며 최초 피해는 활성 0.5초 후다. |
| N05 | 1초 준비, 자신을 포함한 반경 3m의 살아 있는 아군 HP 15% 회복, CD 6초다. 벽 너머는 제외하고 보스·보스 부하도 허용한다. 회복할 아군이 없으면 준비하지 않는다. |
| N07 | N01과 같은 전방 타격 후 명중 여부와 무관하게 0.8초 후방 취약이 열린다. 공격 종료 방향의 뒤쪽 120도에서 들어오는 직접·기본 공격은 가산 피해 +25%다. 지속 피해에는 적용하지 않는다. |
| N08 | 0.9초 준비 후 N02 방식으로 돌진하고, 0.6초 동안 새 방향을 예고한 뒤 한 번 더 돌진한다. CD 7초는 전체 연속 동작의 첫 준비부터 계산한다. |
| N09 | 1.2초 준비, 사거리 9m·중심 기준 -10/0/+10도 화살 세 발, 각 D100%, CD 3초다. 같은 발동에서 영웅은 한 발만 맞는다. |
| N10 | 1.5초 준비, 최근 0.5초 이내 관측 이동을 근거로 최대 4m 앞을 예측한다. 그 위치 반경 2.5m에 3초 화염 장판, 초당 D60%, CD 6초다. 예측 위치는 벽 앞 유효 지형으로 제한한다. |
| N11 | 살아 있는 동안 벽으로 막히지 않은 반경 4m의 다른 아군 공격을 20% 높인다. 같은 오라는 한 번만 적용하며 가장 낮은 시전자 ID로 출처를 정한다. 사망·이탈은 그 틱에 반영한다. |
| N12 기본·사망 | 기본 근접은 N01과 같다. 사망 당시 방향을 저장하고 0.9초 뒤 -30/0/+30도 파편 세 발을 쏜다. 사거리 8m·속도 12m/s·반경 0.2m·D120%이며 같은 발동에서 영웅은 한 발만 맞는다. |

N06은 사망 1초 뒤 반경 2.5m에 D200% 물리 폭발을 한 번 일으킨다. 사망 예고와 사체는 각각의 ID를 가지며 사체 목록을 정리해도 이미 생성된 예고를 제거하지 않는다.

## 정예 특성

| 특성 | 실행 기준 |
|---|---|
| E01 | 독립 CD 5초, 현재 관측한 영웅 위치에 1초 예고 후 반경 2m·3초 화염 장판을 만든다. 초당 D50%이며 0.5초 주기다. |
| E02 | 독립 CD 8초, 영웅의 관측 위치에 1.5초 예고 후 안쪽 2m·바깥쪽 4m의 얼음 고리를 한 번 폭발시킨다. D150% 냉기 피해와 이동속도 35% 감소 2초다. 중심은 안전하다. |
| E03 | 저장된 연결 상대가 살아 있고 다른 정예이며 5m 안에 있을 때 받는 피해를 20% 줄인다. 중복 연결로 곱하지 않는다. 생성 단계의 연결 상대 선택을 유지한다. |
| E04 | 정면 120도에서 들어온 화살·기본 원거리 투사체 피해를 50% 줄인다. 물리 여부로 판단하지 않는다. 근접·연쇄 번개·화염구의 범위 폭발·지속 영역은 이 특성으로 줄이지 않는 시험안이다. |
| E05 | 독립 CD 6초, 6m 안의 생성 후 10초 이내인 일반 적 사체 한 개를 선택한다. 가까운 순·사체 ID 순이며 1.2초 예고 후 반경 2.5m에 D150% 암흑 폭발을 일으킨다. 사체는 E05 전체에서 한 번만 소비한다. N06/N12 고유 사망 효과와 공존하며, 보스·소환 부하 사체는 선택하지 않는다. |
| E06 | 생성 이후 살아 있는 시간 10초마다 공격 +10%, 최대 +50%다. 인지·교전 여부와 무관하며 이탈·복원으로 초기화하지 않는다. 일반 공격과 그 정예가 만드는 효과에 한 번 적용한다. |

특성은 첫 번째 `elite` 값뿐 아니라 저장된 `eliteTraits` 전체를 적용한다. 준비 중에도 E01/E02/E05는 자기 CD를 사용하지만 기절·빙결·보스 무력화 중에는 새 효과를 만들지 않는다. 효과가 생성된 뒤에는 고유 수명으로 유지한다. 기존 버전에서 이미 죽은 적에게 사망 효과를 새로 지급하지 않으며, 생존 시간의 과거 자료가 없는 구형 분노는 남은 스냅샷을 보존하는 범위에서 새 누적을 시작한다.

## 검증 계획

각 일반 적의 실제 준비·발사·명중·빗나감·중단과 저장 복원을 검사한다. 정예는 두 속성 동시 적용, 고리 안전 경계, 연결 해제, 정면/측면/후면과 공격 분류, 사체 중복 소비, 분노 상한을 확인한다. 네이티브 화면에서 위험 형상·연속 돌진 재예고·오라/연결을 관찰하고 실제 앱 재시작을 포함한다. 소환·갈고리·광선·안전 구역을 요구하는 정식 보스 패턴은 별도 검증을 남긴다.
