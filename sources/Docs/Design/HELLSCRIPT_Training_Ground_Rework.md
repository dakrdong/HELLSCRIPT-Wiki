## 1. 목적

같은 세팅에서 사냥 칙령만 바꿔 전투가 어떻게 달라지는지 확인하는 훈련장을 만든다. 플레이어는 균열 단계와 적 구성, 사용할 스킬을 정하고 싸운 뒤, 같은 세팅의 직전 성공 기록과 클리어 시간·평균 DPS를 비교한다. 이 기능은 기존의 고정 훈련 3종(단일·다수·위험 패턴)과 A/B 비교 화면을 대체한다.

모든 수치와 규칙은 실제 전투와 같다. 적의 능력치·공격·패턴·정예 특성, 영웅의 스킬·사냥 칙령·물약·피격·사망은 실제 전투 시뮬레이션이 계산한다. 훈련만을 위한 별도 전투 규칙이나 배율을 만들지 않는다.

## 2. 훈련장 세팅

| 항목 | 규칙 |
| --- | --- |
| 사용 스킬 | 현재 장착한 일반 액티브 4개와 궁극기 1개를 보여 준다. 체크박스를 끈 스킬은 이번 훈련에서 쓰지 않는다. 체크박스는 훈련에만 적용되며 저장된 장착과 사냥 칙령을 바꾸지 않는다. 칙령의 자동 사용이 꺼진 스킬은 체크해도 쓰지 않으며 행에 경고를 표시한다. |
| 칙령 수정 | 스킬마다 **칙령 수정** 버튼을 둔다. 기존 스킬별 사냥 칙령 편집(간편 설정, 직접 설정의 자동 사용·사용 방식·세부 옵션)을 그대로 사용한다. 저장하면 현재 사냥 칙령에 반영되어 훈련과 균열·반복 사냥 모두에 적용된다. |
| 사냥 칙령 설정 | 사냥 칙령 창의 스킬 탭을 바로 연다. 스킬 교체·투자, 공통 공격 설정, 전역 칙령은 이 창에서 바꾼다. |
| 균열 단계 | 1단계부터 최고 돌파 단계 + 1까지 고른다. 균열 입장과 같은 범위다. 몬스터는 실제 균열의 같은 단계와 같은 능력치로 등장한다. |
| 적 구성 | 보스와 일반 몬스터를 합쳐 최대 5종이다. 보스는 한 종류만 1마리이며, 다른 보스를 고르면 교체한다. 일반 몬스터는 종류마다 1~20마리이고 한 종류는 한 행만 둔다. |
| 몬스터 등급 | 일반 몬스터에 일반·매직·희귀·전설 등급을 준다. 희귀는 실제 균열의 정예와 같다. 매직·전설은 실제 전투에서 등급 효과만 있는 표시 등급이므로 능력치는 일반과 같다. |
| 기록 표시 | 현재 세팅의 최고 기록과 직전 성공 기록을 보여 준다. |

## 3. 몬스터 능력치

적은 균열과 같은 생성 경로(`CombatSimulation.SpawnEnemy`와 능력치 함수 `CombatSimulation.EnemyStats`)로 만든다. 2026-09-28 기준 공식은 다음과 같다.

- HP = 70 × 1.08^(단계−1) × 종류별 HP 계수, 공격력 = 18 × 1.055^(단계−1) × 종류별 공격 계수.
- 보스는 HP ×45, 공격력 ×3에 보스별 보정을 곱한다. 보스의 전반·후반 패턴도 실제 균열과 같다.
- 1~5단계는 입문 균열 보정을 적용한다. 라이브 운영 배율도 실제 균열과 같은 값을 쓴다.
- 희귀(정예)는 HP ×3, 공격력 ×1.5이며 `RiftGenerator`의 규칙으로 정예 특성을 받는다. 추적 화염·얼음 고리·사격 방벽·분노 축적 가운데 하나이고, 같은 종류가 4마리 이상이면 시체 폭발이 후보에 추가된다. 20단계(`ContentUnlocks.doubleEliteStage`)부터 50% 확률로 두 번째 특성을 받으며, 추적 화염과 얼음 고리는 함께 붙지 않는다. 정예 두 마리 행은 25% 확률로 생명 연결 쌍이 된다. 특성은 행마다 따로 뽑으므로(`TrainingGround.EliteTraits`) 다른 행을 바꿔도 달라지지 않고 로비에 미리 보인다.

공식은 게임 코드가 단일 기준이다. 균열 공식을 바꾸면 훈련장도 함께 바뀐다. 훈련장에서 공식을 복제하지 않는다.

## 4. 전투

- 같은 세팅은 항상 같은 배치와 시드로 시작한다. 같은 칙령으로 다시 하면 같은 결과가 나오며, 결과 차이는 칙령에서만 생긴다.
- 전투 중에는 최근 3초 평균의 실시간 DPS, 직전 성공 판의 같은 시점과 비교한 증감률, 이번 판과 직전 판의 초당 피해 그래프, 평균·최고 DPS, 총 피해, 남은 적, 보스 HP, 영웅 HP를 보여 준다.
- **일시정지**를 누르면 전투 시간이 멈춘다. 멈춘 시간은 클리어 시간에 넣지 않는다. 일시정지 화면에서 계속하거나 훈련을 중단할 수 있으며, 중단한 판은 기록하지 않는다.
- 일반 몬스터는 종류마다 한 무리로 시작 방에 모인다. 보스가 있으면 일반 몬스터를 모두 처치한 뒤, 실제 균열의 이동형 보스처럼 영웅에게서 6~18m 떨어진 곳에 등장한다.
- 보스가 있으면 보스 처치, 없으면 일반 몬스터 전부 처치가 성공이다. 보스가 부른 소환수는 실제 균열처럼 성공 조건에 넣지 않는다. 영웅이 쓰러지거나 균열과 같은 제한 시간(라이브 운영 설정, 기본 300초)을 넘기면 실패로 끝난다.

## 5. 결과

| 결과 | 표시 |
| --- | --- |
| 성공 | 클리어 시간, 직전 성공 판 대비 증감(초와 %), 첫 기록·빨라짐·느려짐·같음 구분, 최고 기록 갱신, 평균 DPS 증감, 최고 DPS, 총 피해, 두 판의 DPS 그래프를 보여 준다. |
| 실패 | 클리어 시간은 `기록 없음`으로 표시하고, 쓰러진 시점과 남은 적을 알려 준다. 실패한 판은 기록하지 않고 비교하지 않는다. |
| 공통 | 스킬별 피해 비중·사용 횟수·현재 칙령 요약과 스킬마다 **칙령 수정** 버튼, 직전 성공 판 이후 바뀐 사냥 칙령 목록을 보여 준다. 하단에는 **훈련장 세팅 변경**(로비로 돌아가기)과 **다시 시작하기**(지금 세팅 그대로)를 둔다. 결과 화면에서 저장한 칙령은 다시 시작할 때 적용된다. |

## 6. 같은 세팅과 기록

같은 세팅의 기준은 영웅, 영웅 레벨, 장착 장비, 균열 단계, 적 구성(종류·등급·마릿수), 체크한 스킬이다. 사냥 칙령은 시험하는 변수이므로 기준에 넣지 않는다.

기록은 영웅별·세팅별로 직전 성공 판과 최고 기록을 저장한다. 시간, 평균·최고 DPS, 초당 피해 요약, 당시 사냥 칙령을 남긴다. 성공한 판만 저장한다.

훈련은 XP·골드·재료·장비·균열 기록에 반영하지 않는다. 실제 계정에 남는 것은 사용자가 저장한 사냥 칙령과 훈련 기록뿐이다.

## 7. 화면 크기와 언어

세로 440×956, 가로 956×440, PC 16:9·16:10·21:9에서 고정 행동 영역과 스크롤 영역이 겹치지 않아야 한다. 모든 문구는 한국어와 영어를 갖추고 글자 크기 확대를 지원한다. 적 초상화 25장과 훈련장 배경은 Codex로 생성했으며 출처는 [이미지 출처](../Art/TrainingGround/art-manifest.json)에 기록했다.
