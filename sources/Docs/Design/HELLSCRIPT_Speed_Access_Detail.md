# HELLSCRIPT 배속 잠금·구독·시간 사용권 정책

작성일: 2026-09-09  
버전: v0.1  
문서 상태: 배속 잠금과 향후 해금 방식은 사용자 확정 정책이다. 시간 차감·권한 만료·저장 등의 운영 세부 규칙은 구현을 위한 제안이다.  
적용 대상: 일반 화면과 절전 방치에서 사용하는 배속의 접근 권한이다. 이번 작업은 기획 반영이며 실제 게임의 잠금이나 결제 기능을 구현한 것은 아니다.

## 1. 이번에 확정한 정책

현재 제공 단계에서는 **1배속만 사용할 수 있고, 1.5배속과 2배속은 잠금 상태로 둔다.** 향후 BM을 설계하고 해당 기능을 도입할 때 1.5배속은 월 구독 혜택으로, 2배속은 이벤트로 배포하는 시간 단위 사용권으로 해금한다.

| 배속 | 현재 제공 정책 | 향후 해금 방식 |
|---|---|---|
| 1배속 | 기본으로 제공한다. | 별도 권한 없이 사용한다. |
| 1.5배속 | 잠근다. | 월 구독이 유효한 사용자에게 해금한다. |
| 2배속 | 잠근다. | 이벤트의 ‘2배속 사용권’으로 사용 시간을 충전한다. |

2배속 사용권은 시간 단위로 지급하며, **1h 쿠폰은 60분을 추가한다. 남은 시간이 있으면 기존 시간에 합산한다.** 잔여 30분에서 1h 쿠폰을 사용하면 90분이 된다. 잔여 시간을 60분으로 교체하거나 남은 시간을 버리지 않는다.

이 정책은 [상위 기획서](HELLSCRIPT_Unity_Implementation_Plan.md)의 기존 ‘1배·1.5배·2배 무료 제공’ 결정을 대체한다. 배속에 따라 전투·이동·제한시간이 함께 진행되고, 같은 처치·획득·실클리어 규칙을 적용한다는 계산 원칙은 유지한다.

‘지금 잠금’과 ‘나중에 권한에 따라 해금’을 구분한다. 현재 구독 상품·결제·이벤트 지급 기능을 먼저 도입하지 않는다. 세 배속의 전투 계산과 내부 성능 검사는 유지할 수 있으며, 개발용 검증 권한이 일반 사용자에게 노출되어서는 안 된다.

## 2. 2배속 사용권의 시간 기준안

이 절의 세부 동작은 사용자의 ‘2배속을 켜고 60분 동안 사냥’이라는 의도를 **실제 사용 시간 차감**으로 구체화한 제안이다. 쿠폰 사용 시각으로부터 60분 뒤 만료되는 방식으로 해석하지 않는다.

| 구분 | 제안 규칙 |
|---|---|
| 쿠폰 수령 | 보관 중인 쿠폰을 추가한다. 수령만으로 배속을 바꾸거나 시간을 차감하지 않는다. |
| 쿠폰 사용 | 쿠폰 1장을 소비하고 해당 시간만큼 사용 잔액을 늘린다. 배속은 자동으로 바꾸지 않는다. |
| 2배속 선택 | 남은 시간이 있고 사용 권한을 확인한 경우 2배속으로 진행한다. 월 구독 가입을 추가 조건으로 요구하지 않는다. |
| 시간 단위 | 실제 시간 1초의 2배속 사냥은 잔액 1초를 사용한다. 그동안 전투는 2초 진행한다. |
| 추가 충전 | 사용 중에도 남은 시간에 합산하며, 현재 균열·행동·타이머를 초기화하지 않는다. |
| 보관·이월 | 잔액은 접속·영웅 변경·날짜 변경으로 초기화하지 않는다. 누적 상한과 유효기간은 사용자가 정하지 않았으므로 임의로 추가하지 않는다. |

시간은 초보다 세밀한 내부 단위로 누적하여 여러 번 켜고 꺼도 분 단위 올림 차감이나 나머지 시간 손실이 발생하지 않게 한다. 화면에는 시간·분으로 표시하고 마지막 1분은 초까지 보여 준다.

| 예시 | 잔여 시간 |
|---|---|
| 잔여 0분에서 1h 쿠폰을 사용한다. | 60분이 된다. |
| 2배속으로 실제 30분 동안 사냥한다. | 30분이 남는다. |
| 잔여 30분에서 1h 쿠폰을 추가 사용한다. | 90분이 된다. |
| 1배속으로 전환하여 20분 동안 사냥한다. | 90분을 유지한다. |
| 다시 2배속으로 실제 10분 동안 사냥한다. | 80분이 남는다. |

## 3. 차감하는 구간과 보존하는 구간

**2배속이 실제 적용되어 균열의 게임 시간이 진행되는 구간에만 차감한다.** 일반 화면·절전 화면·잠깐 보기의 차감 규칙은 같다. 화면을 보지 않는다는 이유로 무료 사용 처리하거나 더 빨리 차감하지 않는다.

| 상황 | 시간 처리 기준안 |
|---|---|
| 균열 탐색·이동·전투·상자·성소 | 실제로 2배속 진행 중이면 차감한다. 적을 공격하는 순간만 차감하는 것은 아니다. |
| 클리어 후 전리품 회수 | 회수 이동 등에 2배속이 실제 적용되는 동안은 차감한다. 모든 진행이 멈춘 정리 화면에서는 차감하지 않는다. |
| 절전 화면·잠깐 보기 | 사냥이 계속되면 동일하게 차감한다. 표시 전환 자체는 시간에 영향을 주지 않는다. |
| 1배속·1.5배속 | 2배속 잔액을 차감하지 않는다. |
| 수동 정지·설정·편집·포탈 정리 | 실제 진행이 멈춘 동안 차감하지 않는다. |
| 결과의 다음 판 대기·로딩·마을 | 차감하지 않는다. |
| 앱 전환·화면 잠금·종료·통신 대기 | 실제 전투를 보존하고 중단하는 기존 정책을 따른다. 중단된 구간은 차감하지 않는다. |
| 훈련 | 초도 사용자 제공은 1배속으로 두고 사용권을 차감하지 않는 안을 권고한다. 향후 훈련의 고배속 제공 방식은 BM 설계에서 별도로 정한다. |

같은 계정의 영웅들이 사용 시간 잔액을 공유하는 안을 권고한다. 기존 계정당 활성 전투 세션 하나를 따르며, 기기를 바꾸어 잔액을 복제하거나 두 곳에서 같은 시간을 사용하지 못하게 한다. 월 구독의 만료 시각은 서버 시각을 따르고 2배속 사용 잔액과 별도로 관리한다. 구독 해지·만료가 남은 2배속 시간을 지우지 않는다.

## 4. 잠금·잔액 표시와 만료 처리

현재는 배속 선택 영역에 **1배속 / 1.5배속 잠김 / 2배속 잠김**을 표시한다. 잠긴 항목을 눌러도 전투 속도를 바꾸지 않으며 ‘현재는 사용할 수 없는 배속입니다’를 보여 준다. 도입 시점이 정해지기 전에는 구매·구독·쿠폰 사용 화면으로 연결하지 않는다.

향후 기능 도입 시에는 1.5배속에 구독 권한 상태를, 2배속에 **남은 사용 시간**을 표시한다. 쿠폰 사용 결과는 ‘60분이 추가되었습니다. 총 1시간 30분 사용할 수 있습니다’처럼 추가량과 합계를 함께 보여 준다. 쿠폰 자체의 보유 수량과 이미 충전한 사용 시간을 구분한다.

**만료 처리 제안:** 2배속 잔액이 0이 되면 유효한 월 구독이 있는 경우 1.5배속으로, 없는 경우 1배속으로 전환한다. 1.5배속 사용 중 구독이 만료되면 1배속으로 전환한다. 구독 만료를 이유로 보유한 2배속 시간을 자동 사용하지 않는다. 잔액 만료 시 사냥을 멈추거나 진행 중 균열을 실패 처리하지 않는다.

권한 만료 경계에서 적용할 배속을 먼저 확정하고 남은 실제 시간은 새 배속으로 처리한다. 고정 전투 틱의 나머지 시간도 보존하여 사용 시간보다 오래 2배속을 쓰거나 마지막 잔액을 버리지 않게 한다. HP·자원·행동·재사용 대기시간·제한시간을 초기화하지 않는다. 만료와 쿠폰 충전이 겹치면 같은 세션의 처리 순서에 따라 잔액과 적용 배속을 한 번 확정한다.

만료 안내는 일반 화면에서는 작은 알림으로, 절전 화면에서는 상태 문구로 표시한다. 전투 화면 전체를 가리는 구매창을 자동으로 띄우지 않는다. 다시 접속할 때 이전에 선택한 배속을 적용하기 전에 현재 잠금 상태·구독·잔액을 확인한다. 현재 잠금 단계에서는 기존 저장값이 1.5배속·2배속이어도 1배속을 적용한다.

## 5. 구현 인계와 검증

서버가 구독 권한·2배속 잔액·쿠폰 사용 기록의 기준을 가진다. 쿠폰 소비와 시간 추가는 하나의 확정 처리로 묶고 요청 ID를 저장한다. 같은 사용 요청을 재전송해도 시간은 한 번만 추가한다. 클라이언트 시계 변경이나 저장 복원으로 잔액을 늘릴 수 없어야 한다.

진행된 2배속 구간, 사용한 시간, 전투 체크포인트를 같은 순서로 기록한다. 화면 프레임 수로 사용 시간을 차감하지 않는다. 강제 종료로 사용 시간 차감만 되돌아오거나, 같은 진행에 두 번 차감하는 일이 없도록 복구 규칙을 검증한다. 권한·잔액을 확인할 수 없으면 기존 통신 중단 정책을 따르며, 확인되지 않은 2배속 진행을 허용하지 않는다.

| 단계 | 완료 기준 |
|---|---|
| 현재 잠금 구현 | 일반·절전·재접속·기존 저장·우회 입력에서 1배속만 적용한다. 구독·이벤트·쿠폰 발급 기능은 도입하지 않는다. |
| 향후 권한 도입 | 1.5배속은 유효 구독만 허용하고, 2배속은 잔여 시간만큼 허용한다. 두 배속을 곱해 3배속으로 만들지 않는다. |
| 시간 누적 | 잔여 30분+1h=90분, 연속 충전, 중복 요청, 동시에 들어온 서로 다른 쿠폰 사용을 검증한다. |
| 차감 구간 | 실제 60초 사용 시 60초 차감·전투 120초 진행을 확인한다. 정지·대기·1배속·1.5배속·앱 중단에서는 잔액이 유지된다. |
| 만료 경계 | 잔액 0, 구독 만료, 추가 충전, 모드 전환, 판 종료가 겹쳐도 권한·잔액·전투 상태가 일치한다. |
| 저장·기기 전환 | 재접속·강제 종료·시계 변경·기기 인계로 사용 시간이 복제·중복 차감되지 않는다. |
| 전투·배터리 | 내부 검증에서는 세 배속의 전투 동등성과 2배속 최대 부하 검사를 유지한다. 무료 제공 여부와 검사 범위를 혼동하지 않는다. |

연결 문서는 [절전 방치 모드 기획](HELLSCRIPT_Idle_Mode_Detail.md), [상위 기획 5.5와 10.3](HELLSCRIPT_Unity_Implementation_Plan.md), [남은 개발 작업표](HELLSCRIPT_Remaining_Development_Backlog.md)다.

## 6. 나중 BM 설계에서 정할 항목

월 구독의 가격·다른 혜택·결제 주기 상세, 이벤트 지급 대상·주기·쿠폰 종류, 쿠폰의 사용 기한·잔액의 유효기간·누적 상한·훈련 고배속 정책은 이번에 확정하지 않는다. 2배속 사용권의 직접 판매나 상시 구매도 추가하지 않는다. 만료·시간 차감·계정 공유에 관한 이번 제안은 BM 상세 설계에서 검토한다.

배속은 실제 시간당 사냥량을 바꾸므로 향후 구독·이벤트 경제 검증에 반영한다. 배속 사용권은 추가 드롭률이나 보상 2배 효과를 뜻하지 않으며, 실제 처치·획득 규칙은 기존과 같다.
