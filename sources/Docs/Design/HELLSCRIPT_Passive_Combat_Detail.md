# 패시브 18종의 발동·시간·조합 기준

작성일: 2026-09-09 · D3 개발 시험안

[콘텐츠 카탈로그](HELLSCRIPT_Content_Catalog.md#3-패시브-18종)의 효과와 수량을 유지하고, 구현에 필요한 판정 시점·만료·저장 기준을 보완한다. 직업별 6종 중 최대 3종을 장착한다. 장비·액티브·패시브 장착 변경은 성소·훈련장에서 하며, 균열 안에서는 행동 규칙과 이동·획득 설정만 바꾼다. 이 문서의 경계 처리와 원소 기록 방식은 개발 시험안이며 새로 사용자 확정을 받은 수치로 표시하지 않는다.

## 1. 개별 효과와 검증 기준

| ID·이름 | 판정·효과 | 경계와 조합 검사 |
|---|---|---|
| WP01 군중 속으로 | 공격할 때 영웅 중심 3m 안의 살아 있는 적이 3명 이상이면 가산 피해 +15%를 적용한다. | 거리 3m를 포함한다. 동시 범위 공격은 첫 타격 전 군중 조건을 함께 확정해 앞선 적의 사망으로 뒤 타격의 보너스가 달라지지 않게 한다. 별도 후속 충격파는 자기 실행 시점에 다시 판정한다. |

| WP06 처형자의 눈 | 타격 직전 대상 HP가 30% 이하이면 가산 피해 +20%를 적용한다. | 정확히 30%를 포함한다. 여러 연속 타격은 각 타격 직전 HP로 판정하며 첫 타격 전부터 사망 후 효과를 앞당기지 않는다. |
| AP01 긴 사거리 | 실제 적중 시 영웅과 대상의 거리가 7m 이상이면 가산 피해 +15%를 적용한다. | 발사 거리와 구분한다. 비행 중 영웅·대상의 이동을 반영하며 정확히 7m를 포함한다. |
| AP02 탈출의 발걸음 | 후퇴 도약 착지 성공 후 2초 동안 이동속도 증가 구간에 +20%p를 더한다. | 체공 거리를 늘리지 않는다. 이동 접사·LC01·성소 보너스와 합산해 증가 상한 50%를 지킨다. 재착지는 2초로 갱신하며 중첩하지 않는다. |

| AP04 덫 사냥꾼 | 덫에 저장한 패시브 구성을 따라 속박 시간을 1.5초에서 1.875초로 늘린다. | A03·LA03 모두 적용한다. 무장·대기·피해 지속시간과 독 반경은 늘리지 않는다. 보스는 실제 속박 대신 기존 제압 처리를 따른다. |

## 2. 저장과 구성 변경

0.05초 고정 전투 틱을 사용한다. 지속시간 2초·4초의 뺄셈 잔여값 때문에 다음 틱까지 효과가 연장되지 않게 한다. 1초 처치 회복 CD와 4초 원소 기억의 경계는 같은 틱 번호 체계를 사용해 전투 128초·256초 이후에도 확인한다. 배속은 틱 진행 속도만 바꾸며 효과의 전투 시간을 바꾸지 않는다.

원소 교차는 속성별 최근 적중 틱 여섯 개와 현재 버프의 남은 시간을 저장한다. 기존 저장의 마지막 속성·시각 하나는 그 속성의 기록으로만 변환하고 알 수 없는 다른 다섯 속성은 만들지 않는다. 이미 남아 있던 원소 교차 버프는 남은 시간을 보존한다. 변환은 반복해도 같은 상태여야 한다.

훈련장에서 WP03·AP02·MP06을 해제하면 해당 영웅 버프와 MP06의 미완성 속성 기록을 제거한다. 이미 생성된 보호막·투사체·덫·장판의 저장된 피해·상태 수치는 다시 계산하지 않는다. 단, 해제한 MP06이 옛 투사체나 장판 때문에 영웅에게 새 버프를 다시 만들 수는 없다. 재장착은 과거의 제거한 버프를 되살리지 않는다. WP04의 내부 CD와 기존 HP·자원·스킬 CD는 보존한다.

## 3. 검증 순서와 완료 범위

1. 18개 효과 각각의 정상·경계·미발동 사례를 검사한다. 기존 보호막·덫·충전 검사를 재사용하되 현재 코드에서 실제로 해당 기준을 덮는지 확인한다.
2. 실제 아이템 생성·장착을 거친 합법적인 8부위 조합에서 패시브·접사·전설·세트를 함께 검사한다. 같은 부위의 전설과 세트가 동시에 장착된 가상 능력치를 전체 빌드의 증거로 사용하지 않는다.
3. 실제 앱에서 버프 발생·남은 시간·저장 후 재시작·만료를 확인한다. 패시브 선택 화면에 효과를 설명하고 전투 효과 화면에 현재 영웅 버프를 표시한다.
4. 이후 15개 전설·6세트의 전체 조합과 여섯 프리셋의 비교를 이어 간다. 패시브 단위 검사만으로 6빌드 밸런스나 D3 전체 완료를 선언하지 않는다.
