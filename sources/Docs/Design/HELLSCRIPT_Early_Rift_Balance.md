# 초반 균열 난이도와 콘텐츠 개방 조정

갱신일: 2026-09-24

[English](HELLSCRIPT_Early_Rift_Balance.en.md) · [이전 1~10단계 플레이 기록](HELLSCRIPT_Rift_1_10_Playtest.md) · [성장 기획](HELLSCRIPT_Balance_1000.md)

신규 캐릭터가 1~5단계를 빠르게 익히고, 희귀 장비로 성장한 뒤 미확인 구매와 전설·세트 파밍에 진입하도록 조정했다. 단계는 캐릭터 레벨이 아닌 **균열 단계**다.

| 균열 | 적용 내용 |
|---|---|
| 1~5 | 약 절반 규모의 입문 맵, 일반 55마리·정예 4마리, 완화한 적 공격력·생명력 |
| 6 | 기존 맵 규모와 일반 110마리·정예 8마리 사용 |
| 10 | 보석 이용, T1 보석 선택 상자 2개와 심연 주화 100개 |
| 25 클리어 | 미확인 장비 구매 개방. 마법 60%, 희귀 38%, 전설·세트 합산 2% |
| 30 | 균열 전설·세트 확률 시작. 최초 정상 클리어 후 전설 무기 확정 상자와 T2 보석 선택 상자 |
| 35 클리어 | 옵션 재설정 개방, 최초 보상에 골드 20,400 상자 |

## 입문 전투와 맵

좌표와 방 크기를 `sqrt(0.5)`배로 줄여 바닥 외곽 면적을 약 절반으로 만든다. 캐릭터·보스의 크기는 그대로이므로 통로는 최소 4m 폭을 확보하고 출입구와 적 배치 공간을 다시 계산한다. 보이는 맵과 실제 이동 판정이 같은 저장된 형상을 사용한다. 정예·보스 공격 예고와 회피·물약·사망 규칙은 유지한다.

| 단계 | 일반·정예 HP 배율 | 보스 HP 배율 | 모든 적 공격력 배율 |
|---|---:|---:|---:|
| 1 | 55% | 45% | 30% |
| 2 | 60% | 50% | 35% |
| 3 | 65% | 55% | 40% |
| 4 | 70% | 60% | 45% |
| 5 | 75% | 65% | 50% |

배율은 기존 단계별 적 수치에 곱한다. 일반 55마리·정예 4마리로 수를 줄이고 처치 진행도는 두 배로 지급해, 적 부족 때문에 보스가 나오지 않는 상황을 방지한다. 보스 장비 3개, 장비가 든 필드 상자 2개, 기존 보스·클리어 자원 보상은 유지한다. 일반·정예 처치 보상의 개별 지급량은 유지하므로 총 수입은 실제 처치 수에 따라 달라진다.

새 입문 맵은 지도 버전 8과 `introductory` 상태를 저장한다. 기존 진행 중 맵은 저장된 형상·적 수치로 이어간다. 6단계 이후의 기존 형상과 지문은 버전 7로 유지한다. 훈련장과 구형 목표형 맵 호환 검사는 입문 맵 대상으로 바꾸지 않는다.

## 전설·세트 보상 제한

일반·정예·보스·황금 고블린과 필드 상자에서 새로 생성하는 균열 장비는 **실제 플레이 단계**가 30 미만이면 전설·세트를 지급하지 않는다. 높은 최고 기록으로 낮은 균열에 들어가도 같은 제한을 받는다. 세트는 전설 등급 안의 후보이므로 같은 제한으로 함께 제외된다.

몬스터의 전설 확률을 0으로 만든 뒤 기존 비전설 비율대로 재분배한다. 별도 등급표를 쓰는 필드 상자의 전설 추첨은 희귀로 바꿔 장비 수를 보존한다. 30단계부터는 기존 단계별 확률과 전설 내부 가중치를 사용한다. 미확인 구매는 독립된 획득처이므로 25단계부터 전설·세트가 나올 수 있다.

첫 전설 확정 상자는 10단계에서 30단계로 옮겼으며, 새 최초 보상 목록에 제한보다 이른 전설·세트 상자를 등록하면 데이터 검증이 실패한다. 이미 소유한 장비·상자, 이미 추첨해 저장된 전리품, 이미 개방한 콘텐츠는 회수하지 않는다. 과거에 받은 확정 상자를 열면 원래 보장한 등급을 지급한다.

## 표시와 수치 소유

최초 보상 목록과 상세 팝업은 같은 `ContentUnlocks`와 `RewardBoxCatalog`를 읽는다. 25·35단계의 개방 안내, 30단계의 전설·세트 시작 안내와 확정 상자, 균열 등급 확률 화면을 갱신했다. 거래는 기존 `GameStore`에서 개방 조건·잔액·저장 성공을 검사한다.

장기 계산표도 개방 시점과 입문 처치 예산을 반영해 재계산한다. 전체 1,000단계의 적 HP·드랍 개수·강화 가격 변경안까지 런타임에 적용했다는 의미는 아니다. 미확인 구매는 선택 지출이므로 기본 획득 예측에 더하지 않는다.

## 검증 기록

새 계정에서 시작해 실제 `CombatSimulation`과 저장·거래 코드를 사용했다. 전사는 1~10단계, 궁수와 마법사는 1~5단계를 연속 진행했다. 전투는 0.05초 단위의 1배속 게임 시간을 CPU로 가속 계산했다. 얻은 장비와 재화만 사용하고, 실패·재도전 기록을 삭제하거나 시작 시드를 골라 바꾸지 않았다. 마을 정리 시간은 포함하지 않는다. 직업별 한 경로의 관찰 결과이며, 전체 이용자의 승률을 뜻하지 않는다.

| 직업 | 1~5단계 누적 | 10단계까지 누적 | 전투 실패 | 종료 캐릭터 레벨 |
|---|---:|---:|---:|---:|
| 전사 | 8분 1.35초 | 21분 43.85초 | 0회 / 10판 | 13 |

이전 전사 기록은 1~5단계에 실패 시간을 포함해 16분 54.10초, 10단계까지 33분 8.75초였다. 이번 관찰에서는 각각 약 52.5%, 34.4% 짧아졌다. 실패가 줄면 이후 시도에 배정되는 시드도 달라지므로, 동일 지도끼리 비교한 통계 실험으로 해석하지 않는다.

전사는 균열 장비 **87개(일반 6·마법 31·희귀 50)**와 최초 보상의 희귀 무기 1개를 얻었다. 전설·세트는 0개다. 균열 장비의 획득처는 일반 11개, 정예 40개, 보스 30개, 상자 6개였다. 보석은 자연 획득 33개와 선택 상자 20개로 총 53개이며, T1 52개·T2 1개다. 룬은 시작 16개에서 75개가 됐다. 보석·룬의 조기 수집은 허용하되 이용은 각각 10·15단계 개방을 따른다. 선택 상자 2개가 한 묶음이어서 이번 조작 정책은 금강석 20개를 선택했다.

전사 종료 시 공격력은 30.24에서 56.22로, 최대 생명력은 330에서 1,119.51로 올랐다. 총수입은 골드 35,648·재료 518·강화석 508·심연 주화 100이며, 소비 후 잔액은 골드 1,481·재료 518·강화석 448·심연 주화 100이다. 획득·장착·판매·분해·상자 기록과 최종 소유 장비·재화가 일치하고 세 직업 모두 재로드 검사가 통과했다.

장기 기획안과 같은 처치 수를 비교하면 일반·정예·보스 장비의 기대량은 약 49.84개, 이번 실제 획득은 81개였다. 현재 정예가 장비를 확정 지급하는 반면 기획안은 35%이므로 차이가 난다. 상자 6개와 최초 보상은 이 비교에서 제외했다. **전체 드랍 축소안은 아직 적용하지 않았다.** 현재 보석·룬의 획득 단계도 장기 기획안과 구분한다.

### 수정 중 발견한 문제와 최종 확인

초기 축소판에서는 바닥 경계에서 이동이 멈춰 1단계가 300초 시간 초과로 끝났다. 짧은 이동일수록 경계 오차 허용치가 지나치게 작아지는 문제를 수정했다. 0.20·0.22·0.30m 이동과 실제 1mm 바닥 틈 차단을 함께 검사했다. 이어서 상자·성소를 놓은 뒤 큰 적의 1.2m 통행 여유도 다시 검사하도록 보완했다. 실패한 조정 기록, 중간 통과 기록과 최종 재측정은 원본 압축 파일에서 구분해 보존했다.

- Unity 6000.6.0f1의 관련 Edit Mode 검사 **216개 통과**, 실패·건너뜀 0. 전체 테스트 모음의 결과는 아니다. 추가 장비·이동 회귀 검사도 **24개 통과**, 실패·건너뜀 0이다.
- macOS Development 빌드 성공, 빌드 오류 0. 실행 검사 **28개 통과**: 20개 화면 조합, 25·30·35단계 안내, 개방 전후 상태, 저장과 영웅 교체를 포함한다.
- 440×956·956×440·1600×900·1600×1000·2100×900에서 한국어·영어, 글자 크기 100%·150%를 확인했다. 자동 실행은 레이캐스트로 대상 버튼을 확인한 뒤 Unity 포인터 이벤트를 전달했다.
- 자연 성장한 전사의 저장 복사본을 macOS Player에서 다시 열어 캐릭터·전체 장비·지갑·보석·룬·최초 보상·단계 기록을 대조했다. 실제 macOS 입력으로 전체 능력치 팝업을 여는 것도 확인했다. 실행 시 별도로 정산된 오프라인 골드 10은 플레이 수입에 포함하지 않는다.
- 수급 모델 검사 22개와 공통 UI 검사 9개 통과. 모바일 실기기, 이용자 전체 승률, 자연 플레이로 1,000단계까지의 진행은 이번 검증 범위가 아니다.
