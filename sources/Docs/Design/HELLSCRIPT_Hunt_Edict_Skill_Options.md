# 사냥 칙령: 스킬 옵션과 화면 구조

작성일: 2026-09-09 · 버전: v0.2 · 상태: 스킬당 최대 8개, 권장 4~6개를 적용한 기획안입니다. 게임 구현 완료 기록은 아닙니다.

**스킬 하나의 편집 항목은 자동 사용을 포함해 4~6개로 구성합니다.** 각 스킬의 정확한 선택지·기본값·고정 동작은 [스킬별 핵심 옵션](HELLSCRIPT_Hunt_Edict_Skill_Option_Catalog.md)을 따릅니다. 이전의 여러 규칙과 임의 OR/AND 편집을 스킬 카드에서 제거하고, 플레이 방식에 차이를 만드는 선택만 남깁니다.

## 1. 화면 구성

```text
사냥 칙령 · Hunt Edict
├─ 전역 설정
│  └─ 공통 생존·회피·자원 보존·대상·추적·회수·정리
├─ 사용 스킬·개별 설정
│  ├─ 사용할 액티브 선택·배치 [사용 스킬 칸 1~4]
│  │  ├─ 스킬 선택 / 교체 / 해제
│  │  └─ 미보유 스킬: 빈칸 + 원본 스킬·이유
│  ├─ 현재 직업의 기본 공격
│  │  └─ 핵심 옵션 4~6개
│  └─ 현재 장착한 액티브 [최대 4개]
│     ├─ 스킬명·고유 효과 [정보]
│     ├─ 자동 사용 [옵션 1]
│     ├─ 용도·조준·이동·유지·연계 중 필요한 선택
│     │  └─ 자동 사용까지 합쳐 총 4~6개, 최대 8개
│     └─ 현재 장비 효과·실행 불가 사유 [정보]
├─ 전체 행동 순서 [공통 목록 1개]
└─ 저장·되돌리기·프리셋 5칸·공유
```

고급 설정을 펼쳐도 추가 편집 항목은 나오지 않습니다. 장비 전용 옵션 행이나 개별 규칙을 추가하지 않으며, 장비가 관련 선택지를 활성화하더라도 기존 한 행에서 하나의 값만 고릅니다. 피해·사거리·효과 시간과 같은 고정 수치는 설명으로 표시합니다.

## 2. 공통 설정과 스킬 설정의 경계

| 구분 | 편집 범위 |
|---|---|
| 전역 설정 | 모든 스킬이 공유하는 회피·HP 위기·생존용 자원·이동·추적·전리품 방침을 정합니다. 스킬별 예외 목록을 추가하지 않습니다. |
| 개별 스킬 | 다수 처리·집중 공격, 조준·설치·착지 목적, 채널이나 표식의 유지, 핵심 연계처럼 사용 결과가 달라지는 선택을 정합니다. |
| 자동 실행 검사 | 해금·장착·사거리·사선·자원·CD·행동 잠금·효과 중복·충전 예약을 검사합니다. 사용자가 해제할 수 있는 토글을 만들지 않습니다. |
| 패시브 | 실제 장착한 효과를 같은 판단에 반영하고 읽기 전용으로 설명합니다. 수동 시전·효과 수치 편집은 없습니다. |

자동 사용을 끄면 전역 생존 목록에서 선택했더라도 해당 스킬을 실행하지 않습니다. 공통 행동 순서는 한 곳에서 관리하며 스킬 카드의 배치 순서로 바뀌지 않습니다. ‘우선’ 선택은 정의된 일반 대체 행동을 사용하고, ‘전용·때만’ 선택은 조건이 없으면 해당 스킬을 보류합니다. 어느 쪽도 다른 행동의 판단을 막지 않습니다.

## 3. 스킬 배치와 저장

사용할 액티브의 선택·배치와 옵션은 하나의 편집본입니다. 프리셋을 불러오면 보유한 스킬은 원래 칸에 배치하고 옵션을 복원하며, 미보유 스킬은 이유가 표시된 빈칸으로 둡니다. 자동으로 다른 스킬을 채우지 않습니다. 빈칸에 직접 고른 스킬은 자신의 옵션을 사용합니다.

미장착 스킬의 값은 숨겨 보관합니다. 같은 편집 중 수정한 스킬을 해제했다가 다시 장착하면 미저장 수정값이 돌아옵니다. 새 편집을 시작하거나 되돌리면 마지막 저장 성공본을 읽습니다. 나중에 스킬을 해금하더라도 빈칸에 자동 배치하지 않습니다.

변경은 `저장하기`가 성공했을 때만 실제 배치·사냥·공유 코드에 반영됩니다. 되돌리기, 미저장 이탈의 저장·버리기·계속 편집, 5개 프리셋 슬롯, 전투 중 편집과 상태 보존은 [공통 명세](HELLSCRIPT_Hunt_Edict_Detail.md)를 따릅니다.

## 4. 이전 상세안과의 관계

v0.1의 스킬당 최대 3규칙과 OR 2묶음·AND 3조건은 기존 실행 표현과 구형 자료를 해석할 때 참고하는 제약입니다. 이번 스킬 편집 화면에 여러 규칙·조건식 입력을 다시 노출하는 근거로 사용하지 않습니다. 새로운 고정 방식의 구현과 기존 실행기로의 연결은 별도 검증이 필요합니다.

새 공유 원본에는 스킬별 핵심 선택값과 그 판단 버전을 저장합니다. 임의 규칙이나 이전 고급 옵션을 숨겨 실행하지 않습니다. 구형 코드의 의미를 정확히 표현할 수 없으면 원본을 보존하고 바뀔 내용을 보여 준 뒤 간소화 편집본으로 불러오게 합니다. 변환·실제 저장·원본 슬롯 덮어쓰기는 구분하며, 상세 이관 기준은 [핵심 옵션 명세](HELLSCRIPT_Hunt_Edict_Skill_Option_Catalog.md#저장프리셋구형-설정의-처리)를 따릅니다.

## 5. 확인 기준

- 액티브 18종·기본 공격 3종 모두 자동 사용을 포함해 4~6개이며 최대 8개를 넘지 않습니다.
- 한 행 아래 독립적인 토글·수치·조건 편집이 숨겨져 있지 않습니다.
- 장비·패시브·빈칸 프리셋 때문에 옵션 행 수가 늘어나지 않습니다.
- 단독 보스·첫 교전·자원 부족·선행 스킬 미보유에서도 사용 또는 보류의 이유가 분명합니다.
- 저장·되돌리기·공유·미보유 부분 적용과 스킬별 CD·HP·자원 보존 정책은 유지합니다.
