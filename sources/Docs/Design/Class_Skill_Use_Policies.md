# 스킬 사용 규칙과 실험

[English](Class_Skill_Use_Policies.en.md)

전투 설정의 재미는 조건에 맞는 행동을 고르고, 결과를 관찰해 다시 고치는 과정에 둡니다. 좋은 설정은 상대와 장비에 따라 달라져야 합니다. 아래 선택은 기술의 사용 시점·대상·위치·대기 방식을 바꾸며, 선택만으로 무료 능력치를 추가하지 않습니다.

액티브·궁극기 54개에 사용 방식 하나씩을 제공하고, 마력 회수의 종료 목표를 별도로 둡니다. 총 55개 옵션 묶음·164개 선택지입니다. 패시브 54개는 자동 사용 조건 대신 세 칸의 장착 예산으로 경쟁합니다. 기존 칙령의 세부 옵션은 보존하며, 이 문서의 기존 기술 선택은 해당 칙령 값을 함께 설정합니다. 기본 선택은 원래 조건을 사용합니다.

## 두 가지 기준 사례

도약 내려찍기는 실제 이동 거리가 2m를 넘으면 1m마다 직접 피해 가산 15%를 얻고 8m에서 90%에 도달합니다. 뒤로 걷기 자체는 피해를 만들지 않습니다. 거리 확보는 최대 2초, 목표 대상과 6m 거리이며 벽·몸체·감지 위험을 피해 걷습니다. 경로가 막히거나 시간이 끝나면 현재 거리의 유효한 도약을 시도하고, 그마저 불가능하면 다른 행동으로 넘깁니다. 이 추가 규칙은 신규 능력 검증 경로에만 적용합니다.

마력 회수는 1등급에서 평소 마나 회복 속도의 10배, 5등급에서 14배입니다. 쿨타임과 고정 종료 시간은 없습니다. 이동 요청·실제 이동·다른 유효한 공격은 충전을 끊지만, 실패한 공격 요청이나 단순 피격은 끊지 않습니다. 자동 충전은 마나 35% 이하에서 시작하고 50% 또는 90%에서 종료합니다. 거리 확보 선택은 최대 2초 동안 5m 거리를 만들고 충전하며, 충전 중 3m 안에 적이나 감지 위험이 생기면 중단합니다. 제자리 선택은 일반 피격을 감수하되 사용자가 정한 전역 긴급 생존 방침은 우선합니다. 마나가 가득 차거나 사망한 뒤 중복 회복을 만들지 않습니다.

마력 회수 연동 장비 DES_LM44는 자기 결계 안에서 1.5초 이상 집중하면 4초짜리 최대 HP 10% 보호막을 줍니다. 충분히 준비 선택은 해당 장비의 재발동이 가능하면 마나 90%에 도달해도 보호막 발동까지 기다립니다. 짧게 회복 선택은 이 추가 대기를 하지 않습니다. 무쿨타임 충전 재시작으로 보호막을 반복 생성하지 않도록 장비 재발동 간격 6초를 유지합니다.

## 비교할 때 고정할 조건

같은 장비·등급·적·난수 시드·전투 시간에서 한 가지 선택만 바꿉니다. 총 피해, 초당 피해, 생존, 받은 피해, 자원 부족 시간, 실제 시전 횟수를 함께 봅니다. 옵션별 대기 시간, 거리 확보 이동량, 충전 시간과 마나 회복량도 기록합니다. 다른 조건을 기다리는 여러 스킬의 대기 시간은 겹칠 수 있으므로 서로 더해 전체 전투 시간으로 해석하지 않습니다.

한 번의 결과로 최적 설정을 확정하지 않습니다. 정지한 적, 추격하는 무리, 이동·위험 예고가 있는 보스에서 반복하고, 피해가 증가해도 사망률이나 전투 공백이 늘었는지 확인합니다. 현재 수치는 첫 실험을 위한 시작값이며 모든 선택이 동등하게 강하다는 뜻은 아닙니다.

## 구현 연결

`ClassSkillOptions.For`로 한영 선택지·이득·손해·관찰 지표를 조회합니다. `WithOption`은 원본을 건드리지 않는 초안을 반환하고 `CommitClassSkills`가 마을에서 저장합니다. 옵션 ID와 선택 값은 HED4·프리셋·전투 저장에 포함됩니다. 알 수 없는 값은 거부하고 원본을 보존합니다. `InspectClassSkillAutomatic`은 현재 보류 이유를 설명하고 `ReadClassSkillPolicies`는 관찰 수치를 반환합니다. UI 배치와 아이콘은 이 작업에서 연결하지 않습니다.
