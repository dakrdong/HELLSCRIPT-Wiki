# 전역 HUD 01: 캐릭터 인장

작성일: 2026-09-14

## 기능과 표시

현재 선택한 클래스의 얼굴을 왼쪽 아래 원형 인장으로 표시한다. 클래스의 초상, 원형 마스크, 금속 테두리, 레벨 표지를 분리한다. 인장은 이동·공격·캐릭터 변경 버튼으로 쓰지 않는다. 캐릭터를 선택하지 않았거나 데이터를 불러오는 동안에는 기본 실루엣을 표시한다.

| 상태 | 표시 규칙 |
|---|---|
| 전사·궁수 | 기존 SkillAtlas의 18·19번 셀을 원형 마스크 안에 표시한다. |
| 마법사 | 이번에 제작한 은발 마법사 초상을 사용한다. |
| 미선택·로딩 | `portrait-placeholder`와 값 없음 표기를 사용한다. |
| 사망 | 동일한 얼굴을 유지하고 사망 상태를 문구로 구분한다. 다른 캐릭터 얼굴로 바꾸지 않는다. |

## 데이터와 구현 계약

선택 캐릭터 ID·클래스·전투 세션 ID를 하나의 읽기 모델에서 받는다. 새 캐릭터로 바뀌면 인장·HP·자원·장착 스킬·물약·레벨·XP·효과를 같은 스냅샷으로 교체한다. 앞 캐릭터의 쿨타임을 새 얼굴과 함께 보여 주지 않는다.

`portrait-mage`, `portrait-placeholder`, `mask-circle`, `frame-seal`을 조합한다. 원본 초상은 비파괴적으로 유지하고 Unity 마스크 안에서 얼굴 위치와 확대율을 조정한다. 전사·궁수 아틀라스는 기존 프로젝트 텍스처를 참조한다. 새 그림 때문에 기존 클래스 리소스를 덮어쓰지 않는다.

## 완료 조건

세 클래스와 미선택 상태에서 올바른 얼굴이 나온다. 방향 전환과 마을·전투·가방·설정 이동 중 인장이 사라지지 않는다. 인장 주변이 투명하고 원형 밖의 초상이 새지 않는다. 빠른 캐릭터 교체에서도 다른 영웅의 값이 섞이지 않는다.
