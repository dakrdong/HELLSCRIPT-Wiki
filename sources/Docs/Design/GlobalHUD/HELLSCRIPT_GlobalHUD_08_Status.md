# 전역 HUD 08: 버프·디버프와 부드러운 스크롤 경계

작성일: 2026-09-14

## 표시와 데이터

플레이어에게 현재 적용된 효과의 그림·강화/약화 표지·남은 지속시간·중첩 수를 표시한다. 지속시간은 스킬 재사용 대기시간과 구분한다. 상시 효과는 시간 대신 상시 표기를 사용하며 중첩이 1이면 숫자를 생략할 수 있다. 색만으로 강화와 약화를 구분하지 않고 작은 +/− 표지를 함께 쓴다.

`GameUI.Effects.cs`가 읽는 보호막·아이템 효과·플레이어 상태를 기반으로 표시 전용 어댑터를 만든다. 적에게 걸린 독·표식·빙결이나 플레이어가 설치한 장판을 플레이어의 디버프로 오인하지 않는다. 각 항목은 인스턴스 ID, 정의 ID, 대상 ID, 강화/약화 구분, 아이콘 ID, 중첩, 남은 시간, 총 지속시간, 이름·설명 키를 제공한다. 현재 직접 열거되는 필드에 안정된 ID가 없으면 어댑터에서 정의와 소스의 조합으로 지속적인 키를 제공한다.

## 폭과 입력

| 항목 | 규칙 | 44 크기·8 간격 예시 |
|---|---|---|
| 접힘 | `4.5 × s + 4 × g` | 230 |
| 최대 펼침 | `8 × s + 7 × g` | 408 |
| 콘텐츠 | `N × s + max(0,N−1) × g` | 12개이면 616 |

4개 이하이면 있는 효과만 보여 주고 +를 숨긴다. 5개 이상이면 4.5칸과 반투명 +를 표시한다. +는 마스크 밖 오른쪽에 놓는다. 펼치면 왼쪽 시작점은 유지하고 오른쪽으로 최대 8칸까지 늘리며, 새 오른쪽 끝에 −를 표시한다. 효과가 8개를 넘어도 나머지는 삭제하지 않는다. 안전 너비가 모자라면 가용 폭까지만 늘리고 스크롤로 접근한다.

접힘·펼침 모두 가로 드래그·트랙패드·영역 위의 휠을 지원한다. 세로 이동과 탄성 넘침은 끈다. 펼치기 버튼은 그림 32, 입력 여백 포함 44를 제안한다. 인접 효과의 입력 영역을 덮지 않게 한다. 펼침 애니메이션은 0.18초를 제안하며 조작 중 위치를 유지한다. 현재 왼쪽 효과의 ID와 내부 오프셋을 보존하고 마지막 위치를 넘으면 범위 안으로 보정한다.

## 투명도 그라데이션

경계에서 그림·테두리·시간·중첩 표지가 함께 100%에서 0%로 사라진다. 기본 감쇠 폭은 반 칸인 22다. 맨 앞에서는 오른쪽만, 중간에서는 양쪽, 맨 끝에서는 왼쪽만 감쇠한다. 넘치는 콘텐츠가 없으면 양쪽 감쇠를 모두 없앤다.

스크롤 위치를 `p`, 최대 스크롤을 `m`이라 하면 왼쪽 폭은 `min(22,p)`, 오른쪽 폭은 `min(22,m−p)`다. 뷰포트 경계까지의 거리 `d`에 대해 `t=clamp01(d/폭)`, `t²(3−2t)`를 원래 알파에 곱한다. 폭이 0이면 계수는 1이다. 두 경계가 활성화되면 두 계수를 곱한다. 가장자리까지 남은 거리가 줄어들수록 폭이 함께 줄어 마지막 아이콘이 갑자기 나타나지 않는다.

`RectMask2D`는 바깥 누출을 막고 실제 감쇠는 뷰포트 좌표를 공유하는 UI 재질에서 처리한다. 숫자용 `UnityEngine.UI.Text`도 글꼴 텍스처 보정을 지원하는 동일한 감쇠 재질을 사용한다. 기본 Sprite 재질만 바꾸고 숫자가 잘리는 상태를 완료로 보지 않는다. +/− 버튼과 설명 창은 감쇠 영역 밖에 둔다. `mask-edge-smooth`는 선택적 알파 룩업 리소스이며 검은 그라데이션 덮개로 그리지 않는다.

## 설명과 갱신 정책

접힌 상태와 펼친 상태 모두 아이콘을 짧게 선택하면 효과 이름·전체 설명·잔여시간·중첩·출처를 볼 수 있다. 효과가 4개 이하라 펼치기 버튼이 없어도 설명에 접근할 수 있어야 한다. 이 입력은 정보 조회이며 효과 발동이나 전투 행동을 실행하지 않는다. 드래그와 선택을 구분하고 드래그 종료를 선택으로 처리하지 않는다. PC는 포인터 정지 시 같은 설명을 보여 줄 수 있다. 자세한 전투 효과 화면에는 기존 일시정지 정책을 적용하되 펼치기·접기·스크롤만으로 전투를 멈추지 않는다.

효과 출처별 고정 순서를 유지하고 같은 출처의 보호막은 생성 ID 순서로 표시한다. 남은 시간이 줄 때마다 재정렬하지 않는다. 드래그 중 만료된 효과는 비활성 자리만 잠시 유지하고 활성 효과로 표현하지 않는다. 놓는 순간 목록을 정리하며 추가된 효과도 그때 배치한다. 변경 후 현재 기준 효과가 사라졌으면 가장 가까운 이웃을 유지한다.

## 완료 조건

0·4·5·8·12·40개, 시작·중간·끝, 확장·축소·방향 전환·효과 만료를 검사한다. 12개 모두 마지막까지 접근할 수 있어야 한다. 밝은 바닥과 어두운 바닥에서 실제 배경이 비치며 숫자도 부드럽게 사라져야 한다. 목록 조작으로 공격·이동·물약 사용이 발생하지 않아야 한다. 현재 제공한 상태 그림은 의미별 공통 아이콘이며 모든 게임 효과가 독립된 전용 그림을 가진다는 뜻은 아니다.
