# 전투 HUD·실시간 그래프 — 캐주얼 시안 정본

작성일: 2026-10-14 · [English](README.en.md)

캐주얼 StyleD 아트 컨셉에 맞춰 전투 화면의 메인 HUD(인장·HP·자원·보호막·물약·스킬·레벨·경험치·상태 효과·사냥 칙령 단추·미니맵)와 전투 그래프 창(실시간 DPS·몬스터 피해·보스 피해·활동 시간)을 다시 그린 시안이다. 사용자가 디자인 캔버스에서 보며 고친 최종판(캔버스 버전 6)이다. 이 폴더는 시안 자료이며 게임 코드는 바꾸지 않았다. 게임 적용 지시는 [Codex 작업 지시](../../../Implementation/Casual_Battle_HUD_Codex_Prompt_20261014.md)에 있다.

- 디자인 캔버스(비공개): https://claude.ai/artifact/PK5gEQdR1rrbW8Jzx3nDaA. 열 수 없어도 이 폴더의 사본이 정본이다.
- 같은 양식의 다른 캐주얼 시안: 전투 위치 거리 HUD(1Pkt5gL8FtWFDzYTkTaDdJ), 훈련장(KZpgGkzK1YJ9yNzLex2san), 스킬 트리(JsCKnJUbKkzfBYyJDR3493).

## 양식

다른 캐주얼 시안과 같은 규칙이다.

- **잉크 외곽선** `#2a3150` 2~3px, 덩어리 아래 그림자 `0 3px 0 잉크`. 큰 패널은 `0 5px 0 잉크` + `0 12px 20px rgba(42,49,80,.18)`.
- **패널(DPS·활동 시간):** 크림 `#fff6e3` + 위쪽 흰 광택, 5px 안쪽 점선 바느질(`2px dashed rgba(42,49,80,.13)`), 모서리 18(PC)·14(휴대전화), 테두리 3px(PC)·2px(휴대전화).
- **보조 창(몬스터·보스 피해):** 흰 `#ffffff`, 테두리 2px, 모서리 14, 바느질 없음.
- **둥근 단추:** 흰 바탕 + 잉크 2px + 아래 그림자. 켜짐은 노랑 그라데이션 `#fff6c2→#ffd23f` + 노란 고리 `rgba(255,210,63,.55)`.
- **색:** 노랑 `#ffd23f`, 주황 `#ff9f1c`, 금색 고리 `#ffc21a`, 하늘 `#35a7ff`(자원), 코랄 `#ff5a5f`(위험), 민트 `#5ee0d4`(보호막, 글자 `#127a72`), 초록 `#4cbf55`, 보조 글자 `#4a5272`·`#6b7393`·`#8a93b5`, 빈 칸 `#e6e9f0`.
- **글꼴:** 숫자·제목은 Jua, 본문은 Noto Sans KR 700. 바·슬롯 위 숫자는 흰 글자 + 잉크 외곽선, RIFT 제목은 노랑 글자 + 잉크 외곽선.
- 전장 배경(연두 잔디와 대각선 무늬)과 동그란 몬스터는 시안 전용이다. 게임에서는 실제 필드가 보인다.

## 부품과 상태

- **인장:** 원형 초상 + 노란 고리 4px(휴대전화 3px) + 잉크. HP 30% 미만이면 코랄 고리로 1.1초 주기 약한 깜박임, 쓰러지면 회색 고리 + 흑백 초상.
- **레벨 알약:** 노랑 바탕, Jua, 잉크 테두리.
- **HP·자원 바:** 빈 칸 `#e6e9f0` + 잉크 1px 테두리 + 1px 고리 + 아래 2px. HP는 코랄 그라데이션 `#ff9a9d→#ff5a5f`, 자원은 하늘 `#5cc8ff→#35a7ff→#2f8fd8`, 둘 다 위쪽 흰 광택. HP 30% 미만이면 바에 코랄 고리.
- **보호막:** HP 바 위쪽 4px 민트 띠(보호막 ÷ 최대 HP)와 바 위의 "보호막 +420" 글자.
- **물약 칸:** 둥근 사각, 흰색→크림, 잉크 2px, 병 그림은 칸의 66%, 아래에 수량 "×12". 재사용 대기는 원형 덮개(`rgba(42,49,80,.6)`, 남은 비율) + 남은 초(10초 미만은 소수 한 자리). 수량 0은 점선 회색 칸 + 흑백 병. 보조 물약 효과 중에는 노란 고리.
- **스킬 칸:** 원형, 크림 + 노란 빛, 잉크 2px. 궁극기는 금색 고리 + 아래 "궁극기". 사용 중은 노란 빛 번짐, 재사용 대기는 원형 덮개 + 초, 자원 부족은 가운데 파란 마름모 + 아이콘 채도 낮춤. 잠김·빈칸 표시는 게임 규칙을 유지한다.
- **상태 효과:** 둥근 사각 칸. 버프는 파란 아이콘 + 오른쪽 위 초록 "+" 배지, 디버프는 연분홍 칸 + 코랄 아이콘 + 코랄 "−" 배지. 중첩은 오른쪽 아래 잉크 알약, 칸 아래 남은 초. 접힘은 4.5칸에 오른쪽 끝을 흐리게, "+" 단추로 8칸까지 펼친다.
- **사냥 칙령 메뉴:** 단추를 누르면 노랗게 켜지고, 아래로 크림 틀 세로 메뉴가 나온다. 탭 순서는 게임과 같다(전투·생존·탐색·반복·프리셋). 각 탭은 둥근 아이콘 + 아래 이름이다.
- **경험치:** 노랑→주황 채움, 10~90% 눈금 9개(50%는 진하게), 바 위 "EXP 62%".

## 그래프 창

공통 규칙:
- 네 창(실시간 DPS·몬스터 피해·보스 피해·활동 시간)은 각자 따로 옮기고(제목을 끌기) 따로 접는다(왼쪽 원형 단추).
- 몬스터·보스 창은 더 이상 DPS 창에 붙어 있지 않다.
- 위치는 지금의 DPS·활동 창처럼 기기에 저장하는 것을 전제로 한다.

창별 내용:
- **실시간 DPS:**
  - 머리: "실시간 DPS" + "최근 3초 평균" + 큰 숫자(Jua).
  - 비교 줄: "직전 판 같은 시점 대비 ±n%"(올라가면 초록 `#23863a`, 내려가면 `#c62f35`, 화살표 아이콘).
  - 범례: 이번 판 주황 실선, 직전 판 하늘 점선.
  - 차트: 위 눈금값과 0, 연한 격자 3줄, 이번 판 노랑 영역 30% + 주황 3px 선, 직전 판 하늘 점선(6·5), 끝점(주황 점 + 잉크 고리). 스킬 사용 표시는 선 위의 작은 원형 스킬 아이콘(궁극기는 금색 고리)이고, x축은 0초·중간·끝이다.
  - 아래 줄: 평균·최고·총 피해 세 칸.
  - 화면별: 가로는 범례를 뺀다. 세로는 범례와 세 칸을 뺀다. 접으면 단추 + 제목 + 숫자만 남는다.
- **몬스터 피해 · 최근 5종:**
  - 줄 구성: 이름 | 막대 | "520/초 · 22%".
  - 막대는 최대 HP의 50%에서 가득 찬다. 20% 이상 주황, 40% 이상 코랄, 그 아래는 회청 `#8a93b5`.
  - 세로는 이름·값 한 줄 + 아래 막대 줄이다.
- **보스 피해:**
  - 머리에 보스 인장 + 이름, 줄마다 원형 공격 아이콘 + 이름 + 막대 + 값. 색 규칙은 몬스터와 같다.
  - 보스가 살아 있을 때만 보인다.
- **활동 시간:**
  - 비율 막대: 이동 하늘·공격 코랄·회피 노랑·파밍 초록. 12% 이상이면 칸 안에 %를 쓴다.
  - 막대 아래 "누적 시간 · 0.0~48.0초".
  - 2×2 칸: 색 사각 + 이름, "n초 · n%", 누적 선 그래프(선 색 이동 `#2f8fd8`, 공격 `#e8474c`, 회피 `#d9a300`, 파밍 `#36a845`).
  - 접으면 제목 옆에 같은 비율 막대를 글자 없이 색으로만 보인다(PC 96×14, 휴대전화 72×12).

시안의 "처치 38 · 균열 72/100", 몬스터·스킬 이름, 수치는 시연 값이다.

## 시안 메모

1. 사용자가 이 시안에서 직접 정한 것이 있다. 칙령 단추는 오른쪽 위에 두고 탭은 아래로 펼친다(세 방향 통일). 미니맵은 오른쪽 아래, 상태 효과는 첫 물약 위에 둔다(세로는 물약·스킬 줄 위 왼쪽). 세로 그래프는 작은 창으로 하고, 그래프 창은 각자 옮기고 접는다. 접은 활동 시간 창에는 색 막대를 둔다.
2. 세로 HUD는 지금 게임처럼 한 줄에 맞추면 휴대전화에서 슬롯이 약 27pt로 작아진다. 그래서 위의 쌓기 배치를 쓴다.
3. 시안의 오른쪽 위에는 메뉴·설정 단추만 그렸다. 게임의 콘텐츠 독 열과의 관계는 게임 쪽에서 정한다.
4. 스킬·보스 그림은 다른 캐주얼 시안처럼 기존 게임 그림이다. 전투 대지의 인장은 전사 스킬 그림에 맞춰 남전사를 썼다.
5. 시안의 크기는 휴대전화에서 읽기 좋게 잡았다(가로 슬롯 48, 세로 42). 게임 HUD의 실제 배율 규칙과 맞추는 것은 게임 작업에서 정한다.
6. 시안은 디자인 캔버스(Design 형식)로 만들었다. 참조 화면은 같은 런타임을 로컬에서 실행해 headless Chrome으로 찍었다. 창 끌기 동작은 브라우저에서 실제로 끌어 보지 않았다.
