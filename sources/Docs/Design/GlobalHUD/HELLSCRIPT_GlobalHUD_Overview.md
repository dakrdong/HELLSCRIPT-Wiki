# 관찰용 전역 HUD: 확정 사양과 리소스

작성일: 2026-09-14

상태: Unity 6000.6·uGUI에서 전역 HUD와 물약·칙령을 구현했다. 검증 결과와 실행 화면은 [구현 기록](../../Implementation/Global_HUD_Potions.md)에서 확인한다. 모바일 실기기 검증은 별도 출시 조건이다.

## 목표와 확정 범위

풀 자동 게임의 진행을 오래 관찰할 수 있도록 플레이 영역을 화면 아래까지 보여 준다. 큰 하단 패널 없이 캐릭터와 생존 정보를 왼쪽에, 스킬과 물약을 오른쪽에 띄운다. 스킬과 물약 아이콘은 발동 버튼이 아니라 현재 상태를 보여 주는 표시다. 정보를 확인하기 위한 펼치기·접기·스크롤·설명 보기만 입력을 받는다.

가로는 스킬을 오른쪽 맨 아래 줄에 놓고 직전 기준 크기의 120%로 만든다. 물약은 그 위에 놓으며 병 그림만 기준의 75%로 만든다. 상태 목록은 기본 4.5칸, 펼치면 최대 8칸으로 표시하고 두 상태 모두 좌우로 스크롤한다. 가려지는 경계에는 검은 덮개가 아닌 투명도 그라데이션을 적용한다. 경험치는 맨 아래에 길게 표시하고 10~90%에 내부 눈금 9개를 둔다.

세로는 앞서 승인된 배치를 유지한다. 두 방향에서 같은 인장·색·아이콘·표시 규칙을 사용하되, 가로에만 요청한 줄 이동·배율·긴 경험치 바를 세로에 자동 적용하지 않는다.

## 시안과 실제 리소스의 구분

- [가로 최종 시안](Resources/v1/references/landscape-soft-edge.png)은 부드러운 경계를 포함한 디자인 기준이다.
- [가로 펼침 시안](Resources/v1/references/landscape-expanded.png)은 8칸 배치 참고용 이전 이미지다. 실제 구현에는 최종 그라데이션 규칙을 적용한다.
- [세로 승인 시안](Resources/v1/references/portrait.png)은 세로 배치 기준이다.

이 이미지들은 실제 게임 실행 화면이 아니다. 한 장의 HUD 스크린샷을 게임에 붙이지 않는다. 얼굴·프레임·아이콘·채움·숫자를 분리해 실제 데이터로 조합한다. 기존 액티브 스킬 그림과 전사·궁수 초상은 프로젝트 리소스를 재사용하므로 시안의 예시 그림과 일부 다르다.

## 전달 파일

리소스 묶음에는 PNG 68개가 있다. 새로 생성한 투명 원화 4개, 직접 제작한 공통 UI·상태·패시브 PNG 63개, 기존 스킬 아틀라스 사본 1개다. 아틀라스 한 장에는 액티브 18종과 기존 클래스 초상 3종의 좌표가 정의되어 있다. 벡터 원본 63개도 포함했다.

- [리소스 ZIP](Resources/HELLSCRIPT-GlobalHUD-v1.zip)을 내려받는다.
- [리소스 목록과 사용법](HELLSCRIPT_GlobalHUD_Resources.md)에서 각각의 파일을 확인한다.
- [전체 매니페스트](Resources/v1/resource-manifest.json)에는 크기, 해시, 스프라이트 좌표와 Unity 임포트 제안이 있다.
- [배치 수치](Resources/v2/layout-profile.json)는 확정된 런타임 설정의 사본이다. 기준 화면은 1600×900·900×1600이며 가로 스킬 64→76.8, 병 그림 60→45를 적용한다. 패시브 3개와 액티브 4개 사이에는 24의 여백을 둔다.
- [리소스 검사 결과](Resources/v1/resource-qa.json)에는 실제 알파와 파일 무결성 검사 결과가 있다.

## 지금 완료한 검증과 남은 검증

PNG 크기·알파 채널·투명 픽셀·스프라이트 좌표·파일 해시·생성 메타데이터를 검사했다. 병과 마법사 초상은 내장 이미지 생성 결과의 알파를 그대로 보존했다. 배경 제거·크로마키·후처리 재색칠은 하지 않았다. 첫 체크무늬 물약과 사용하지 않는 녹색 변형은 전달 묶음에서 제외했다.

게임은 `Assets/HELLSCRIPT/Resources/Art/GlobalHUD`의 PNG 67개와 기존 스킬 아틀라스를 사용한다. 런타임에서 구성하는 `GlobalHudView`를 미리보기와 실제 게임이 공유한다. 씬·프리팹을 재작성하거나 새 UI 패키지를 추가하지 않는다. Canvas 105는 페이지와 지도 위, 조회·설정 팝업 아래에 유지된다. 카메라는 선택한 화면 비율 전체를 사용한다.

작은 화면에서 50% 설정을 선택해도 핵심 표시가 읽히도록 HUD 배율의 하한을 0.4로 두었다. 가로의 7슬롯이 들어가지 않으면 패시브를 윗줄로 옮기고, 세로도 그룹 단위로 줄을 바꾼다. 상태 아이콘 아래 숫자의 단위는 초이며 상세 설명에서 단위를 함께 표시한다. 나머지 글자 크기 설정은 50~150% 범위를 유지한다.
