# 전역 HUD 07: 경험치와 10% 눈금

작성일: 2026-09-14

## 기능과 배치

가로에서는 선택한 화면 비율과 안전 영역 안에서 거의 왼쪽 끝부터 오른쪽 끝까지 경험치 선을 놓는다. 맨 아래의 얇은 채움·미진행 선·눈금·짧은 수치만 보인다. HUD를 위한 불투명 띠를 만들거나 카메라 높이를 줄이지 않는다. 세로는 승인된 왼쪽의 짧은 경험치 바를 유지한다.

전체를 10등분하고 10~90%에 내부 눈금 9개를 둔다. 양 끝은 0·100%다. 50% 눈금만 약간 길게 만든다. 각 눈금에 숫자를 붙이지 않는다. 62%라면 여섯 번째 눈금을 조금 지난 곳에서 채움이 끝나야 한다. 화면 너비가 바뀌어도 눈금은 정규화 위치를 유지한다.

## 데이터와 예외

`HeroSave.xp / Economy.XpRequired(level)`을 사용한다. 누적 총 경험치를 분자로 사용하지 않는다. 레벨 상승으로 XP가 줄면 새 레벨의 실제 잔여 XP에 맞춘다. 여러 레벨을 한 번에 올려도 잘못된 과거 레벨의 분모로 나누지 않는다. 최대 레벨은 성장 시스템이 명시한 상태에서 `MAX`로 표시하며 0으로 나누지 않는다. 훈련은 실제 저장 성장과 구분한다.

10% 구간의 시각적 판단은 채움과 눈금이 기준이다. 숫자 표시는 경계를 조기 통과해 보이지 않도록 기본 정수 내림을 제안한다. 진행률 100%는 성장 처리 직전의 실제 상태에서만 잠깐 표시할 수 있다. 장식용 반짝임으로 진행 위치를 가리지 않는다.

## 리소스와 완료 조건

`fill-white`에 XP 색을 적용하고 `xp-tick`, `xp-tick-major`, `xp-cap`을 배치한다. 제안 두께는 논리 크기 3이며 픽셀 정렬은 실제 디스플레이 배율에 맞춘다. 0·10·50·62·90·100%, 레벨 상승·최대 레벨·노치·20:9·작은 창에서 눈금 개수와 위치, 실제 채움, 하단 제스처 여백을 확인한다.
