# 전역 HUD 02: 체력

작성일: 2026-09-14

## 기능과 표시

인장 오른쪽에 얇은 붉은 HP 바와 현재값/최댓값을 표시한다. 넓은 배경 패널 없이 개별 바의 얕은 내부 음영과 얇은 외곽선만 사용한다. 숫자에는 상아색과 어두운 외곽선을 적용한다. 보호막이 있을 때에는 HP 바 위에 별도 얇은 청록색 선과 보호막 수치를 표시한다. 보호막을 HP에 더해 체력이 최댓값을 넘은 것처럼 보여 주지 않는다.

## 데이터와 상태

현재 체력은 `RunState.health`, 최대 체력은 실제 `HeroStats.hp`, 보호막은 `RunState.shield`를 읽는다. `clamp(현재/최대, 0, 1)`로 채움 비율을 구하고 최대값이 0 이하이면 `—`를 표시한다. 사망은 실제 전투 상태를 따른다. 숫자가 작다는 이유만으로 사망으로 판정하지 않는다.

HP 25% 이하일 때 바 끝이나 외곽선만 천천히 강조하는 방식을 제안한다. 전체 화면 점멸은 사용하지 않는다. 강조 임계값은 UI 경고 설정으로 분리하며 물약 자동 사용 조건과 공유하지 않는다. 이번 구현에서는 숫자와 채움을 같은 스냅샷의 실제 값으로 갱신한다. 저체력 강조와 채움 보간은 별도 시각 개선 후보이며 현재 적용하지 않는다.

마을에서 현재 체력을 제공하는 데이터가 없으면 최대값과 `전투 전` 상태를 보여 준다. 이전 전투의 낮은 체력을 현재 마을 HP처럼 표시하거나 임의로 전량 회복시키지 않는다.

## 리소스와 완료 조건

`frame-vital`의 9-slice 테두리, `fill-vital`의 흰색 채움에 HP 색을 적용한다. 보호막은 `fill-white`를 재사용한다. 0·25·100%, 보호막 생성·소진, 최대 HP 변경, 사망·재시작, 훈련 복사본에서 값과 비율을 확인한다. 숫자 확대 옵션을 적용해도 바와 겹치지 않아야 한다.
