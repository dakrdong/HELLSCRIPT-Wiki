# 전역 HUD 04: 장착 스킬과 쿨타임

작성일: 2026-09-14

## 슬롯과 배치

패시브 3개와 액티브 4개를 표시한다. 패시브는 마름모, 액티브는 사각형을 사용한다. 가로에서는 오른쪽 정보 묶음의 맨 아래 줄에 놓고 슬롯의 가로·세로를 기준의 1.20배로 만든다. 경험치 선과 겹치지 않게 한다. 세로는 기존 승인 배치를 유지한다.

현재 장착 3개와 해금·프리셋을 유지한다. 가로는 패시브 3개와 액티브 4개를 모두 보여 주며, 세로는 패시브 줄을 따로 둔다. 잠긴 슬롯과 빈 슬롯도 구분해 표시한다.

## 상태 표시

| 상태 | 표시 |
|---|---|
| 준비 | 선명한 아이콘을 표시하고 쿨타임 숫자는 숨긴다. 준비가 곧 즉시 시전을 뜻하지는 않는다. |
| 재사용 대기 | 아이콘 위에 어두운 원형 채움과 중앙 남은 시간을 표시한다. |
| 자동 시전 중 | 작은 테두리 강조로 발동을 알린다. 수동 입력을 받지 않는다. |
| 자원 부족·조건 불충족 | 실제 판정 이유를 작은 표지 또는 상세 설명으로 구분한다. 쿨타임 숫자를 대신 만들지 않는다. |
| 미장착·잠김 | 빈 틀 또는 잠김 문구를 표시하고 가짜 스킬 그림을 넣지 않는다. |
| 상시 패시브 | `상시 / Permanent`를 표시한다. 발동형 패시브는 실제 내부 쿨타임이 있을 때만 이를 표시한다. |

## 연결과 리소스

장착 ID를 `GameCatalog`의 정의와 연결하고 해당 정의의 인덱스로 `RunState.cooldowns`를 읽는다. HUD의 1~4번 슬롯 번호를 전역 스킬 인덱스로 사용하지 않는다. 0초 쿨타임 스킬은 나누기를 수행하지 않는다. 남은 시간/이번 시전에 적용된 총 쿨타임을 마스크 비율로 사용하며, `RunState.cooldownTotals`에 시전 당시 총 대기시간을 저장한다.

10초 이상은 정수 올림, 10초 미만은 소수 첫째 자리 올림으로 표시한다. 아직 대기 중인데 `0.0`으로 보이지 않게 한다. 스킬 그림 18종은 기존 아틀라스를 재사용하고 패시브 18종은 `passive-WP01`~`passive-MP06`을 사용한다. 테두리와 쿨타임, 문구는 별도 요소다. 상시 표기가 작은 슬롯의 폭을 넘으면 ∞로 표시하고 설명 창에서는 전체 의미를 유지한다. 기존 아틀라스에는 자체 테두리가 있으므로 새 프레임을 중첩하지 않고 필요할 때 하나만 선택한다.

## 완료 조건

각 클래스에서 장착 순서를 바꿔도 올바른 스킬과 쿨타임이 표시된다. 패시브의 상시·조건 활성·내부 대기가 구분된다. 0·0.01·9.99·10·20초, 배속·일시정지·화면 이동에서 숫자와 채움이 일치한다. 아이콘 클릭으로 전투 행동이 발생하지 않는다.
