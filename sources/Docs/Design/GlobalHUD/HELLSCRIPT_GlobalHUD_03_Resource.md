# 전역 HUD 03: 마나와 직업 자원

작성일: 2026-09-14

## 기능과 표시

HP 바로 아래에 푸른 자원 바와 현재값/최댓값을 표시한다. 마법사의 마나는 MP로 표시하며, 다른 클래스는 프로젝트에 정의된 자원 이름을 사용한다. 모든 직업의 자원을 기획 확인 없이 마나로 이름 붙이지 않는다. 색·바 두께·숫자 규칙은 가로와 세로에서 같다.

## 데이터와 상태

`RunState.resource`와 현재 `HeroStats.maxResource`를 읽어 0~1로 제한한 비율을 표시한다. 최대값이 유효하지 않으면 `—`를 표시한다. 자원 소모, 자연 회복, 물약 회복은 시뮬레이션 결과를 읽으며 HUD가 직접 값을 변경하지 않는다.

자원이 0인 상태와 특정 스킬의 비용이 부족한 상태를 구분한다. 비용이 부족한 스킬에는 작은 자원 부족 표지를 붙일 수 있지만, 자원 바에 거짓 쿨타임을 만들지 않는다. 마을·로딩·전투 종료의 데이터 부재 규칙은 HP와 같다. 일시정지 중 자원 회복을 HUD가 임의로 재생하지 않는다.

## 리소스와 완료 조건

`frame-vital`, `fill-vital`, 독립 텍스트를 사용하며 채움에 MP 색을 적용한다. 0·일부·최대 자원, 최대 자원 변경, 연속 소모와 회복, 배속·일시정지에서 실제 값과 일치해야 한다. 클래스별 자원 이름은 한국어와 영어를 각각 등록한다.
