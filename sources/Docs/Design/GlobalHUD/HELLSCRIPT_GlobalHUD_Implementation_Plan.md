# 전역 HUD·물약·사냥 칙령 구현 기준 v2

작성일: 2026-09-14

## 확정된 변경

패시브는 기존 장착 규칙대로 3개를 각각 표시한다. 액티브 4개와 HP·자원·보조 물약 3슬롯을 함께 표시한다. 전투 화면의 넓은 배경판을 제거하고 선택한 화면 비율 전체에 전투 배경을 그린다. 표시용 그림은 전투 입력을 받지 않는다.

가로 1600×900에서 스킬은 76.8, 물약 그림은 45로 표시한다. 이는 이전 기준 64와 60의 120% 및 75%다. 가로 오른쪽 하단은 패시브 3개→액티브 4개 순서이며 물약은 위에 둔다. 세로 900×1600은 패시브·액티브·물약을 각각 한 줄로 나눈다. 작은 화면과 글자 확대에서는 정보 묶음 단위로 줄을 바꾼다.

상태 목록은 가로에서 4.5칸(230), 펼침 최대 8칸(408), 아이콘 44·간격 8이다. 펼침은 0.18초다. 감쇠 최대 폭은 22이며 현재 숨겨진 거리까지 축소한다. 그림·글자·표지를 같은 알파로 감쇠하며 버튼은 마스크 밖에 둔다. 양쪽 경계와 상태 0·4·5·8·12·40개를 검증한다. 세로는 4개와 추가 개수로 표시하고 전체 목록을 조회한다.

가로 경험치 바는 좌우 32, 하단 16, 두께 3으로 두며 10~90%에 눈금 9개를 표시한다. 50% 눈금을 더 길게 둔다. 세로는 왼쪽의 짧은 바를 유지한다.

## 물약 계약

HP는 최대 HP 35% 회복과 기존 회복 보정, 자원은 최대 자원 35% 회복이며 각각 대기 20초다. 보조는 질주(이속 증가 +20%p), 맹공(공격력 +15%), 저항(모든 속성 저항 +20+레벨×3), 강철(방어도 +30%), 속공(공속 증가 +15%p), 집중(치명 확률 +10%p)의 6종이다. 모두 8초 지속·30초 대기이며 기존 상한을 지킨다. 같은 효과가 남았을 때 다시 소모하지 않는다.

성소에서 선택한 보조 종류만 자동 구매한다. 목표 수량은 HP 20·자원 20·보조 10, 가격은 5·5·15금화다. 방문당 예산 500, 최소 잔액 200을 지키며 HP→자원→보조 순서로 산다. 첫 출정분은 캐릭터마다 한 번 지급한다. 화면 재구성은 구매 사건이 아니다.

HP·자원 사용 여부/임계값, 보조 종류/발동 조건, 자동 구매/목표 수량/예산/최소 잔액과 부족 시 출정 지침을 사냥 칙령에 둔다. 부족 시 지침은 HP가 없으면 대기, 목표 수량까지 대기, 부족해도 출정이다. 신규 기본값은 HP가 없으면 대기이며 사용자의 저장된 지침을 따른다. 진행 중 전투는 수량 부족만으로 강제 종료하지 않는다.

기존 HP 임계값과 패시브·해금·프리셋은 유지한다. 구버전의 진행 중 전투는 기존 물약 규칙으로 마친 뒤 성소에서 전환한다. 훈련·비교에서는 재고와 금화를 복사한다. 이전 사냥 칙령 코드와 저장에는 새 옵션을 기본값으로 추가하고 기존 선택을 보존한다.

## 구현과 검증 순서

1. 배치·리소스 기준을 갱신하고 같은 컴포넌트로 미리보기와 실제 화면을 만든다.
2. 배치 계산, 그림·글자의 알파 감쇠와 상태 탐색을 검증한다.
3. 실제 물약·능력치·재고·칙령·구매·저장을 연결한다.
4. 가로·세로·작은 화면·글자 50~150%·안전 영역·한영·일시정지·배속·복원을 검사한다.
5. Unity Edit Mode와 macOS 개발 빌드의 실제 실행 증거, 한영 기록과 공개 위키를 갱신한다. 모바일 실기기 터치는 별도 출시 검증으로 기록한다.

현재 구현 결과와 최종 증거는 [한영 구현 기록](../../Implementation/Global_HUD_Potions.md)에서 확인한다. 이 문서는 구현과 검증에 적용한 요구사항을 보존한다.
