# 전역 HUD 05: 물약과 사냥 칙령

갱신일: 2026-09-23 · 작성일: 2026-09-14

물약 3슬롯은 인벤토리에서 지정한 서로 다른 물약과 캐릭터별 실제 재고를 표시한다. 최초 배치는 HP·자원·강철이며 기존 저장의 보조 선택은 유지한다. 장비 가방 칸은 사용하지 않는다. HUD 아이콘을 선택하면 설명을 볼 수 있으며 물약이 수동으로 발동하지 않는다. 가로의 병 그림은 45, 세로는 60 논리 크기다. 수량·재사용 시간은 그림과 별도로 표시한다.

## 기본 데이터

| ID | 종류 | 효과 | 지속 | 재사용 | 가격 |
|---|---|---|---|---|---|
| PH01 | HP | 최대 HP의 35% 회복 × 기존 치유·물약 회복 보정 | 즉시 | 20초 | 5금화 |
| PM01 | 자원 | 최대 자원의 35% 회복 | 즉시 | 20초 | 5금화 |
| PU01 | 질주 | 이동속도 증가 +20%p | 8초 | 30초 | 15금화 |
| PU02 | 맹공 | 공격력 +15% | 8초 | 30초 | 15금화 |
| PU03 | 저항 | 모든 속성 저항 수치 +20 + 영웅 레벨×3 | 8초 | 30초 | 15금화 |
| PU04 | 강철 | 방어도 +30% | 8초 | 30초 | 15금화 |
| PU05 | 속공 | 공격속도 증가 +15%p | 8초 | 30초 | 15금화 |
| PU06 | 집중 | 치명타 확률 +10%p | 8초 | 30초 | 15금화 |

수치의 원본은 `Assets/HELLSCRIPT/Resources/Data/Potions.json`이다. 각 슬롯에는 보유한 물약만 지정하며 같은 물약 ID를 중복 지정하지 않는다. 슬롯의 종류는 고정하지 않는다. 보조는 공통 호박색 병과 종류별 문양으로 구분하고, 활성 효과를 상태 목록에도 표시한다. 현재 8종은 모두 등급 0이며 새 등급별 성능은 추가하지 않았다.

기존 이동속도 증가 50%, 공격속도 증가 50%, 치명타 확률 75% 상한을 유지한다. 저항은 물리 방어도가 아닌 기존 다섯 속성의 저항 수치에 더하며 최종 피해 감소 상한은 기존 계산을 따른다. 같은 효과는 중첩하지 않는다. 활성 보조 효과가 남았거나 능력치 상한 때문에 적용되는 변화가 없으면 소모하지 않는다.

## 자동 사용과 장착

기존 HP 임계값을 보존하고 신규 기본값은 40%로 둔다. 자원은 30% 이하에서 사용한다. 두 종류의 자동 사용 여부와 임계값은 사냥 칙령에서 각각 변경한다.

보조 기본 장착은 강철이다. `물약별 기본 조건`을 선택하면 질주는 실제 이동 중, 맹공·속공·집중은 교전 중, 저항·강철은 HP 60% 이하 또는 기존 위험 판정에서 발동한다. 직접 선택 가능한 조건은 사용 안 함·이동 중·교전 중·정예 또는 보스 교전·위험할 때다.

마을의 인벤토리에서 물약 슬롯을 눌러 물약을 변경한다. 처음 설정하기 전까지는 사냥 칙령의 보조 선택을 따르고, 명시적으로 배치한 뒤에는 인벤토리 슬롯이 기준이다. 진행 중인 실제 균열에서는 배치 변경을 저장 단계에서도 거부한다. 훈련 중 보조 슬롯의 설명에서 종류를 바꾸면 훈련 복사본에만 적용한다. 활성 효과가 남은 동안 교체하지 않는다.

## 슬롯별 소진 후 선택

장비 영역의 물약 슬롯 3개는 장비 칸과 같은 크기를 사용하고 오른쪽 위에 톱니바퀴를 표시한다. 슬롯을 누르면 고정 크기의 말풍선에 ‘지정 물약을 모두 소진 했을 시’와 다음 네 가지 항목이 나온다. 현재 선택에는 체크와 강조색을 함께 쓰며 설정을 바꿔도 가방과 말풍선의 위치·크기를 유지한다.

- 높은 등급 물약 사용: 같은 효과 후보를 등급 내림차순으로 선택한다.
- 낮은 등급 물약 사용: 같은 효과 후보를 등급 오름차순으로 선택한다.
- 가장 최근에 얻은 물약 순서로 사용: 남아 있는 획득 묶음의 최근 순번을 우선한다.
- 가장 오래된 물약 순서로 사용: 남아 있는 획득 묶음의 오래된 순번을 우선한다.

지정 물약이 남아 있으면 항상 먼저 사용한다. 소진 후에는 **같은 효과**만 허용하고 다른 슬롯의 지정 물약과 이미 선택된 대체품은 제외한다. 등급이 같으면 오래된 획득 순번과 ID로 순서를 정한다. 대체품이 없으면 해당 슬롯의 사용을 멈춘다. 현재 데이터에는 같은 효과의 상·하위 등급 물약이 없으므로 등급별 실제 대체는 이후 데이터가 추가될 때 적용된다.

기준은 슬롯별·캐릭터별로 저장하며 전투 중에도 변경할 수 있다. 보조 물약을 여러 칸에 배치해도 기존 공통 대기시간과 한 번에 하나의 활성 보조 효과는 유지한다. 획득 순서는 구매·지급 시 묶음별 순번으로 기록한다. 순서 기록이 없는 옛 재고는 저장된 목록 순서를 한 번만 사용하며 과거의 실제 획득 시각을 복원했다고 간주하지 않는다. [구현과 검증](../../Implementation/Potion_Slots.md)을 함께 참고한다.

## 성소 자동 구매와 출정 대기

목표 재고는 배치된 물약의 효과를 기준으로 HP 20·자원 20·각 보조 10개다. 빈 슬롯과 미배치 종류는 구매하지 않는다. 구매 순서는 HP→자원→보조이며, 방문당 누적 예산 500금화와 최소 잔액 200금화를 함께 지킨다. 자동 구매 여부·효과별 목표 수량·예산·최소 잔액을 칙령에서 바꿀 수 있다. 자동 사용 여부와 구매·출정 지침은 별개다. 자동 사용이 꺼져 있어도 저장된 목표 수량만큼 구매하며, 특정 종류를 구매하지 않으려면 목표 수량을 0으로 설정한다.

실제 성소 진입과 반복 사냥의 다음 출정 준비에서 구매한다. 같은 방문의 식별자와 지출액을 저장하므로 화면 갱신·설정창 열기·재시도로 예산이 초기화되지 않는다. 구매는 기존 거래 처리로 재고·금화·방문 정보를 함께 저장한 뒤 메모리에 반영한다. 저장 실패 시 모두 이전 상태를 유지한다.

| 출정 지침 | 처리 |
|---|---|
| HP가 없으면 대기 | HP 슬롯이 배치되어 있고 같은 효과의 사용 가능한 물약이 없으면 자동 사용 여부와 관계없이 기다린다. 신규 기본값이다. |
| 목표 수량까지 대기 | 3슬롯 중 저장된 목표 수량에 못 미치는 슬롯이 있으면 기다린다. |
| 부족해도 출정 | 재고가 모자라도 출정한다. |

저장된 지침을 그대로 따른다. 수량 부족으로 진행 중인 전투를 강제 중단하지 않는다. 대기 중에는 금화·재고·칙령 변화가 있을 때 다시 평가하며, 저장 후 앱을 다시 열었다는 이유만으로 자동 출정하지 않는다.

## 저장과 이전

캐릭터별 첫 출정분은 HP 20·자원 20·강철 10개를 한 번 지급하고 `PotionInventory.version`으로 지급 여부를 저장한다. 재고 0개가 재지급 조건이 되지 않는다. 저장 형식은 5, 물약 재고·전투 상태 버전은 1, 칙령 전역 옵션 버전은 2다.

진행 중인 구버전 전투는 물약 상태 버전 0으로 유지한다. 기존 무한 HP 물약은 `∞`, 아직 사용하지 않는 자원·보조 슬롯은 잠김으로 표시한다. 전투를 마친 뒤 성소 또는 다음 출정 준비에서 새 재고 방식으로 전환한다. 기존 HP 임계값·장착 패시브·해금·프리셋·칙령 사용 여부는 보존한다. 구버전 HED1·HED2 코드는 기존 값을 검증하고 새 물약 옵션의 기본값만 보충한다.

훈련과 A/B 비교는 재고를 포함한 계정 복사본을 사용한다. HUD 표시와 조회는 재고·금화·전투 시간을 변경하지 않는다. 소모 시 효과 적용·수량 차감·대기시간 시작을 같은 시뮬레이션 단계에서 처리하고, HP 물약의 LC03 보호막 연계를 유지한다.
