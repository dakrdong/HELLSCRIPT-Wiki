# 전역 HUD 05: 물약 3종

작성일: 2026-09-14

## 종류와 배치

HP는 붉은 각진 병, MP는 푸른 긴 병, 보조는 호박색 둥근 병으로 구분한다. 가로에서는 스킬 위 줄에 세 병을 놓고 병 그림의 가로·세로만 기준의 0.75배로 만든다. 수량은 오른쪽 아래, 남은 쿨타임은 병 중앙의 별도 텍스트로 표시한다. 숫자를 75%로 함께 축소하지 않는다. 세로는 승인된 기존 크기와 줄 순서를 유지한다.

## 표시 상태

| 상태 | 처리 |
|---|---|
| 사용 가능 | 병과 실제 보유 수량을 표시한다. |
| 쿨타임 | 어두운 마스크와 남은 시간을 표시하고 수량도 유지한다. |
| 소진 | `0`과 약한 병 그림을 표시한다. 쿨타임을 임의로 시작하지 않는다. |
| 미장착·잠김 | 빈 슬롯 또는 잠김 상태를 표시한다. |
| 수량 시스템 미연결 | `—`와 개발용 미연결 상태를 사용한다. 예시 수량을 실제 수량처럼 보여 주지 않는다. |

## 선행 시스템 결정

현재 `CombatSimulation.Effects.TryUsePotion()`은 수량 차감 없는 HP 자동 물약과 단일 `potionCd`를 사용한다. HP 회복량·임계값·쿨타임은 현재 시스템이 정하며 이번 리소스 작업으로 변경하지 않았다. 요청한 3종을 구현하려면 아래 계약을 먼저 확정해야 한다.

- `PotionState`는 종류/장착 아이템 ID/수량/남은 쿨타임/이번 사용의 총 쿨타임/해금 상태/사용 불가 이유를 제공한다.
- 인벤토리가 수량의 유일한 원본이 되며 자동 사용 판정과 차감은 시뮬레이션에서 원자적으로 처리한다. HUD는 읽기만 한다.
- MP 물약의 회복량과 임계값, 보조 물약의 실제 효과와 발동 조건, 공급·보충 규칙을 콘텐츠 기획에서 확정한다. HUD는 새 효과나 경제 수치를 임의로 만들지 않는다.
- 개별 쿨타임을 기본 제안으로 삼되 공용 잠금이 필요하면 `max(개별 잔여, 공용 잔여)`를 표시하고 사유를 구분한다. 기존 저장의 초기 수량과 보상·환불 정책도 구현 시작 전에 확정한다.

## 리소스와 완료 조건

`potion-hp`, `potion-mp`, `potion-utility`는 각각 실제 알파를 가진 PNG다. 그림 외부의 넓은 배경은 없다. 쿨타임은 병의 알파를 보존하며 어둡게 하거나 별도 작은 마스크로 표현한다. 0·1·999개, 동시 사용 조건, 공용/개별 대기, 저장·불러오기에서 수량 중복 차감이나 표시 오염이 없어야 한다. 아이콘은 물약 사용 입력을 받지 않는다.
