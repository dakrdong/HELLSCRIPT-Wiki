# 전역 HUD 06: 레벨

작성일: 2026-09-14

## 기능과 데이터

인장 아래의 작은 표지에 `Lv.24`처럼 현재 레벨을 표시한다. 숫자는 이미지에 넣지 않고 기존 글꼴과 현지화 흐름으로 만든다. 표지는 `badge-level`을 사용하며 두 방향에서 동일한 문법을 유지한다.

실제 캐릭터는 `HeroSave.level`을 읽는다. 훈련에서 복사된 레벨을 사용하는 경우 훈련 컨텍스트임을 구분하고 원본 저장에 반영하지 않는다. 레벨과 XP를 같은 스냅샷에서 갱신한다. 미선택·로딩 중에는 `Lv.—` 또는 현지화된 미선택 표시를 사용한다.

레벨 상승은 숫자를 즉시 갱신한다. 표지의 짧은 강조는 별도 시각 개선 후보이며 현재 적용하지 않는다. 전체 화면을 막는 레벨업 창을 HUD 요구사항으로 추가하지 않는다. 최대 레벨은 실제 성장 규칙이 제공할 때만 표시하며 임의의 상한을 만들지 않는다.

## 완료 조건

한 자리·세 자리 레벨과 최대 레벨에서 텍스트가 잘리지 않는다. 한국어·영어·글자 크기 설정을 적용해도 인장·HP·XP와 겹치지 않는다. 빠른 캐릭터 변경과 훈련 종료 후 올바른 레벨로 복귀한다.
