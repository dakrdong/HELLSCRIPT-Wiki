# 무기별 룬 성장 — v13 적용 기획

갱신일: 2026-09-20 · 버전 13 · [English](HELLSCRIPT_Rune_Mastery.en.md)

## 기준과 목적

사용자가 제공한 [HELLSCRIPT-RuneBoard-Publish-v13.zip](RuneV13/reference-v13.zip)의 화면·보드 데이터·배치 규칙을 실제 Unity 콘텐츠의 기준으로 적용합니다. 첨부 README의 외부 게시 절차는 실행 지시로 해석하지 않습니다. [원본 해시와 추출 기록](RuneV13/provenance.json)을 보관합니다.

기존 427칸·영역당 61칸·균열 클리어 기반 개방·7색 배치 규칙을 대체합니다. PackBound에서 가져온 34종 육각 조각, 회전·편집 트랜잭션, 공용 보관함과 기존 드롭·합성 경제는 재사용합니다. 첨부 데모의 룬 160개와 경험치 조작 기능은 실제 계정에 지급하지 않습니다.

룬은 장비 한 개가 아닌 **무기 종류**에 적용됩니다. 도검·대검·도끼·활·쇠뇌·지팡이의 보드 중 실제 장착한 무기 종류의 활성 능력만 전투에 반영합니다. 공용 능력도 다른 무기를 사용할 때는 적용하지 않습니다. 룬은 언제든 회수하여 다른 무기에 쓸 수 있지만 하나의 실물 룬을 여러 보드에 동시에 배치할 수 없습니다.

## 보드와 성장

무기마다 고정된 259칸, 총 1,554칸입니다. 중앙·맹공·정밀·파급·기교·순환·수호의 7영역에 각각 37칸이 있습니다. 좌표·능력·값·등급·문양은 첨부 데이터를 직접 읽으며 임의로 다시 생성하지 않습니다.

| 구분 | 적용 규칙 |
| --- | --- |
| 숙련도 | 무기별 Lv.1~41. 처음에는 중앙 19칸이 열립니다. 다음 레벨 경험치는 현재 레벨 × 100입니다. |
| 슬롯 포인트 | 레벨마다 6P. 칸당 1P이며 시작점에 연결된 개방 경계부터 확장합니다. |
| 영역 순서 | 중앙 37칸을 완성한 뒤 바깥 영역을 선택합니다. 선택한 영역도 모두 완성해야 다음 영역을 선택할 수 있습니다. |
| 무료 중앙 칸 | 바깥 영역을 선택하면 엘리트 중앙 칸이 무료로 열립니다. 이 칸은 개방 경로나 룬 연결의 새로운 시작점이 아닙니다. |
| 전체 개방 | 유료 234칸, 무료 중심 6칸, 초기 19칸. Lv.40에 모두 열 수 있고 Lv.41에는 6P가 남습니다. |
| 경험치 획득 | 사용 중인 무기에 일반 5·정예 25·보스 100 × `(1 + floor(균열 단계 / 5))`. 훈련·소환 몬스터를 제외하고 처치·보상 중복 지급을 막습니다. |

경험치의 실제 처치 보상은 첨부에 없던 게임 연동 수치입니다. 기존 드롭 주기를 유지하며 위 수치를 초기 밸런스로 정했습니다. 영웅 경험치 증가 능력은 무기 숙련 경험치를 늘리지 않습니다.

## 색·능력 등급·획득 등급

능력 색은 **공격·마법·보조·치명타·스킬 보너스** 5종입니다. 룬과 슬롯의 색이 일치해야 능력이 켜집니다. 엘리트 칸은 모든 색을 허용합니다.

획득 등급 G0~G6은 드롭 크기와 합성 성장 단계입니다. 색이나 보드 개방 조건과 무관합니다. 낮은 획득 등급의 룬도 열린 최상급 능력 칸에서 색을 맞추면 활성화할 수 있습니다.

능력 등급은 첨부의 1~4단계 분류를 따릅니다. 공격력·기본 속성·체력 등은 낮은 단계, 치명타·공격속도·스킬 추가 효과는 높은 단계, 스킬 레벨은 최상위 단계입니다. 개별 수치와 상한은 도감과 [Unity 카탈로그](../Implementation/Rune_Mastery_Catalog.json)에 기록합니다. 실행 용도가 없는 제어 저항·최대 기력·기력 회복 3종은 첨부와 같이 실제 슬롯에서 제외합니다.

| 무기 | 특화 스킬 | 추가 효과 |
| --- | --- | --- |
| 도검 | W02 도약 내려찍기 | 피해·레벨·재사용 대기시간·범위 |
| 대검 | W01 회오리 | 피해·레벨·자원 소모·범위 |
| 도끼 | W03 분쇄 일격 | 피해·레벨·자원 소모·범위 |
| 활 | A02 다중 사격 | 피해·레벨·자원 소모·사거리 |
| 쇠뇌 | A01 관통 사격 | 피해·레벨·자원 소모·관통 대상 수 |
| 지팡이 | M01 화염구·M02 눈보라·M03 연쇄 번개 | 피해·레벨·자원 소모 및 범위·지속시간·대상 수 |

직접 피해는 지속 피해·가시·추가 발동을 제외합니다. 다수 적 피해는 같은 시전의 같은 타격에서 서로 다른 적 3명 이상을 맞힐 때 적용하며, 연쇄 번개의 서로 다른 도약을 하나의 타격으로 합치지 않습니다. 광역 피해는 기존 범위 공격과 장판을 강화하며 새로운 범위를 만들지 않습니다. 제어 지속시간은 일반·정예에게 적용하고 보스 무력화량은 늘리지 않습니다. 장판 종속 둔화는 기존 영역 이탈·만료 조건을 유지합니다.

스킬 피해 룬은 +60%, 개별 스킬 자원 감소는 30%p, 일반 감소와 합친 비용 감소는 50%가 상한입니다. 스킬 레벨은 이미 배운 스킬에 최대 +5를 적용하고 레벨당 피해 계수 10%를 더합니다. 상속 효과와 레벨 룬도 이 상한을 공유합니다. 범위·재사용·지속시간·대상 수는 해당 추가 효과가 있을 때만 바뀝니다.

## 배치와 연결

중앙의 공용 시작점은 비워 둡니다. 각 색은 시작점에 인접한 블록에서 연결을 시작합니다. 같은 색의 서로 다른 블록은 변을 맞댈 수 없습니다. 두 칸이 공통 이웃 칸 2개를 공유하는 간격으로 연결하며 두 중간 칸도 개방되어 있어야 합니다. 축 방향으로 곧게 두 칸 떨어진 위치는 연결이 아닙니다.

공통 이웃 2칸을 **하나의 다른 블록**이 모두 덮으면 그 연결은 막힙니다. 서로 다른 두 블록이 한 칸씩 덮으면 막지 않습니다. 다른 색은 맞닿을 수 있지만 겹칠 수 없습니다. 색이 맞지 않는 슬롯을 덮는 것은 허용하며 연결 통로로만 사용합니다. 바깥 엘리트 중심은 독립 시작점이 아니므로 중앙에서 연결해야 활성화됩니다.

배치·회전·회수는 전체 연결을 검사합니다. 잘못된 동작은 이전 배치를 보존합니다. 중간 룬을 회수하려면 연결이 끊기는 바깥 룬부터 회수합니다. 뒤집기는 없으며 60도 회전 6방향을 제공합니다.

## 화면과 저장

가로 화면은 왼쪽 무기 목록, 가운데 보드, 오른쪽 보관함을 사용합니다. 세로 화면은 위쪽 무기 목록, 보드, 보관함 순서입니다. 첨부의 무기 그림·328개 SVG 문양·색·일체형 블록 외곽선과 금빛 경계를 사용합니다. 보관함은 8열이며 색 필터와 1~5칸 복수 크기 필터를 제공합니다.

숙련도·슬롯 포인트, 영역 미리보기, 지도·미니맵, 확대·이동·맞춤, 보기/편집, 활성 효과, 도감, 가이드, 선택 상세·회전·회수, 되돌리기·실행 취소와 저장을 제공합니다. 보관함과 상세 팝업 내부만 스크롤합니다.

편집 중에는 전투를 정지합니다. 무기 변경은 편집 대상을 바꿀 뿐 장착 무기를 바꾸지 않습니다. **변경 저장**은 모든 무기의 개방 경로·배치·프리셋 변경을 함께 저장합니다. 닫을 때 미저장 변경이 있으면 폐기를 확인합니다. 실행 취소는 최근 50번까지입니다.

프리셋은 정확히 5칸입니다. 한 슬롯에 **모든 무기의 룬 ID·좌표·회전**을 함께 기록합니다. 숙련도·개방 경로·보유량·장비·스킬 설정은 포함하지 않습니다. 프리셋 등록·이름·비우기도 편집 상태이며 변경 저장 후 보존됩니다. 불러오기는 전체 배치를 검사하고 누락된 룬이나 잘못된 연결이 있으면 전부 거절합니다. 일부만 적용하거나 룬을 복제하지 않습니다.

저장 실패나 오래된 편집본 충돌은 실제 계정과 전투를 바꾸지 않습니다. 전투 중 저장은 체력·자원을 회복시키거나 대기시간·현재 행동을 초기화하지 않습니다. 이미 생성된 공격은 생성 당시 공격 능력 스냅샷을 유지합니다.

## 드롭과 합성

일반 몬스터 2%, 정예 20%로 1개, 실제 균열 보스는 4개를 지급합니다. 훈련·소환 몬스터·소탕은 제외합니다. 전용 보관함에 자동 수령하며 장비 가방 용량과 무관합니다. 색은 각각 20%, 모양은 결정된 크기 안에서 균등합니다.

| 균열 단계 | 획득 등급 | 1칸 | 2칸 | 3칸 | 4칸 | 5칸 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 1~4 | G0 | 100% | 0% | 0% | 0% | 0% |
| 5~9 | G1 | 80% | 20% | 0% | 0% | 0% |
| 10~14 | G2 | 45% | 40% | 15% | 0% | 0% |
| 15~19 | G3 | 15% | 35% | 35% | 15% | 0% |
| 20~24 | G4 | 5% | 15% | 40% | 30% | 10% |
| 25~29 | G5 | 0% | 5% | 30% | 40% | 25% |
| 30 이상 | G6 | 0% | 0% | 20% | 40% | 40% |

표는 드롭 성공 이후의 크기 분포입니다. 예를 들어 10~14단계 일반 몬스터의 3칸 룬 확률은 처치당 0.3%입니다.

같은 등급·같은 크기 2개를 합성하면 1~4칸은 같은 등급의 다음 크기, 5칸은 다음 등급 1칸이 됩니다. G6 5칸은 최종 단계입니다. 실패·수수료 없이 최대 100쌍을 합성합니다. 같은 색을 먼저 짝지어 색을 보존하며 나머지 다른 색 한 쌍은 각각 20%로 결과 색을 정합니다. 결과는 미수령 상태로 먼저 저장하고 수령 후 배치합니다. 현재 배치 중이거나 미수령인 룬은 재료로 쓸 수 없습니다.

초기 지급은 기존의 G0 1칸 12개와 2~5칸 예제 각 1개를 한 번만 유지합니다. 이는 낮은 단계 몬스터의 1칸 전용 드롭 규칙에 대한 예제 지급 예외입니다.

## 이전 저장과 연습

이전 보유 룬의 ID·등급·모양·수량을 보존합니다. 기존 색은 이전 등급을 기준으로 5종 색에 결정적으로 대응합니다. 이전 클리어로 이미 획득한 개방 범위는 새 보드의 동등한 완료 영역 수와 숙련도로 이행합니다. 새 규칙에 맞는 기존 좌표 배치는 유지하고 나머지는 보관함으로 회수합니다. 원래 전체 배치와 프리셋은 저장 안의 `legacyV1`에 그대로 보관합니다.

5페이지 배치 연습은 보유 룬과 무관한 독립 콘텐츠입니다. 첨부의 고정 블록을 연결 기점으로 삼으며 튜토리얼에 명시된 대로 다른 블록의 중간 간격 차단은 적용하지 않습니다. 실제 무기 보드는 공용 중앙 시작점과 간격 차단 규칙을 적용합니다.
