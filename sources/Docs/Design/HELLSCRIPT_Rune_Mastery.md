# 무기별 룬 성장과 전체 배치 프리셋

버전 1.0 · 2026-09-13 · 구현 기준입니다. 검증 결과는 개발 기록을 따릅니다. [English](HELLSCRIPT_Rune_Mastery.en.md)

## 콘텐츠의 목적과 확정 범위

룬 성장은 무기 종류별 마스터리를 육각 배치 퍼즐로 강화하는 계정 성장 콘텐츠입니다. 능력은 보드 칸에 있으며, 보유 룬 조각으로 연결하여 활성화합니다. 장비 개별 인스턴스에 보드를 붙이지 않습니다. 같은 종류의 더 좋은 장비를 얻어도 보드 배치와 투자를 유지합니다.

사용자는 언제든 편집, 룬의 자유로운 회수와 다른 보드 재사용, 동시 중복 사용 금지, **모든 무기 보드의 배치를 함께 저장하는 프리셋 정확히 5칸**을 확정했습니다. 영구 귀속은 적용하지 않습니다. 기본 능력치는 낮은 수치 등급, 치명타·공격속도·스킬 추가 능력은 높은 등급, 스킬 레벨 증가는 최상위 등급으로 구분합니다.

아래 무기 분류, 계정 공유 범위, 개방·보상 주기와 수치는 이 요구를 현재 게임에 연결한 구현 기준입니다. 장기 경제와 체감 균형은 플레이 조정 대상으로 남깁니다. 기존 기획의 ‘룬 조합 제외’는 이 신규 콘텐츠에 한하여 이번 사용자 요청으로 대체됩니다.

## 무기 종류와 적용 조건

| 종류 | 현재 무기 베이스 | 대표 고등급 능력 | 스킬 강화 대상 |
| --- | --- | --- | --- |
| 도검 | B01 | 공격속도·치명타 확률·물리 피해를 강화합니다. | W02 도약 내려찍기를 강화합니다. |
| 대검 | B02 | 근거리 피해·치명타 피해·군중 제어 대상 피해를 강화합니다. | W01 회오리를 강화합니다. |
| 도끼 | B03 | 부상 대상 피해·치명타 피해·물리 피해를 강화합니다. | W03 분쇄 일격을 강화합니다. |
| 활 | B04·B05 | 공격속도·건강한 대상 피해·취약 피해를 강화합니다. | A02 다중 사격을 강화합니다. |
| 쇠뇌 | B06 | 원거리 피해·치명타 확률·취약 피해를 강화합니다. | A01 관통 사격을 강화합니다. |

무기 종류·보드·룬 보관함·프리셋은 계정이 공유합니다. 현재 영웅이 실제 장착한 무기 종류의 보드 하나만 능력치 계산에 들어갑니다. 화면에서 선택한 보드는 편집 대상이며, 장착 무기나 적용 보드를 바꾸지 않습니다. 맨손일 때는 적용되는 보드가 없습니다. 다른 직업의 보드를 미리 구성할 수 있습니다.

공용 능력치도 선택한 보드의 무기를 사용하는 동안에만 적용합니다. 도끼 보드의 민첩성은 활을 사용할 때 적용하지 않습니다. 별도의 숙련 경험치나 중복 성장 트리는 추가하지 않습니다.

## 보드와 세 종류의 등급

무기마다 고정 보드 하나를 제공합니다. PackBound의 육각 영역 7개, 영역당 61칸, 전체 427칸 구조와 시작점을 사용합니다. 여섯 보드의 총 칸 수는 2,562칸입니다. 장비 획득에 따른 무작위 설계도 변경은 없습니다.

| 구분 | 규칙 |
| --- | --- |
| 영역 개방 등급 | 계정 최고 실클리어 0·5·10·15·20·25·30단계에서 G0~G6을 순서대로 엽니다. 다른 영웅의 실클리어도 인정합니다. |
| 룬 등급 | G0~G6은 먹빛·상아·초록·하늘·보라·황금·장미와 일대일 대응합니다. 개방 등급보다 높은 룬은 배치할 수 없습니다. |
| 칸의 수치 등급 | 그 능력의 희소성과 수치 단계를 나타냅니다. 영역 개방이나 요구 색과 별개의 값입니다. 열린 G0 영역에도 수치 등급 6의 최상위 칸이 있을 수 있습니다. |

각 영역의 중심에서 거리가 가까운 순서로 61칸을 배정합니다. 중심 시작칸은 공격력입니다. 안쪽에는 기본 능력치, 바깥으로 갈수록 고등급과 최상위 능력을 배치합니다. 모든 설계는 버전이 고정된 결정적 데이터이며 실행·재접속으로 다시 뽑지 않습니다.

| 수치 등급 | 능력 종류 | 영역당 칸 수 |
| --- | --- | --- |
| 0~2 | 공격력·힘·민첩성·지능·의지력·체력·모든 저항·방어도를 제공합니다. | 37칸입니다. |
| 3~4 | 치명타·공격속도와 표의 무기별 능력을 제공합니다. | 12칸입니다. |
| 5 | 특정 스킬의 추가 피해 또는 자원 소모 감소를 제공합니다. | 9칸입니다. |
| 6 | 특정 스킬 레벨 +1을 제공합니다. | 3칸입니다. |

수치 등급 5의 추가 능력은 실제 구현된 피해·자원 계산을 강화합니다. 새로운 발사체·소환·스킬 행동을 임의로 표시하지 않습니다. 비용이 없는 도약에는 자원 소모 감소 칸을 배치하지 않습니다.

## 초기 수치와 합산

낮은 등급의 배율은 `1 + 수치 등급 × 0.25`입니다. 공격력은 `0.4 × 배율`, 체력은 `2 × 배율`, 나머지 기본 능력치는 `1 × 배율`을 더합니다. 공격력은 무기 기초 공격값에 더한 뒤 기존 주능력 계산을 따릅니다. 힘·민첩성 등의 파생 방어·치명타는 기존 캐릭터 능력치 계산을 따릅니다.

고등급 치명타 확률·공격속도·재사용 대기시간 감소는 `0.12 × 배율`%p, 나머지 고등급 비율 능력은 `0.5 × 배율`%p를 더합니다. 같은 능력을 합산한 뒤 HELLSCRIPT의 기존 최종 상한을 적용합니다. PackBound의 별도 전투 상한을 가져오지 않습니다.

스킬 추가 피해 칸은 +3%이며 룬 합계 상한은 +60%입니다. 스킬 자원 소모 감소 칸은 +2%p이며 룬 합계 상한은 30%p, 기존 효과까지 합친 총 감소는 기존의 50%를 지킵니다. 스킬 레벨은 배운 스킬의 기본 Lv.1에 룬의 추가 레벨을 더하며, 룬으로 최대 +5레벨까지 강화합니다. 추가 레벨 하나는 해당 스킬 피해 계수 +10%를 제공합니다. 추가 피해와 레벨 계수는 가산하여 최대 +110%입니다. 피해 계수만 강화하며 사거리·제어·지속시간을 자동으로 늘리지 않습니다. 배우지 않은 스킬은 레벨 표시 0이며 룬으로 선행 해금되지 않습니다.

## 조각과 배치 규칙

원본의 34종을 사용합니다. 크기별 형태 수는 1·1·3·7·22종이며, 1~5개의 육각 칸이 변으로 이어집니다. 60도씩 회전하며 뒤집기는 없습니다.

같은 색의 첫 조각은 자기 색 시작칸을 덮어야 합니다. 서로 다른 같은 색 조각은 변으로 맞닿을 수 없으며, 한 쌍 이상의 칸이 육각 거리 2로 연결되어야 합니다. 연결은 전체 배치에서 시작점까지 이어지는지 검사합니다. 자기들끼리 고리를 만들어도 시작점과 떨어져 있으면 무효입니다. 잘못 놓인 조각은 다른 조각의 연결을 중계할 수 없습니다.

다른 색끼리는 인접할 수 있지만 겹칠 수 없습니다. 다른 색 시작칸을 덮을 수 없습니다. 일반 능력 칸은 다른 색으로 덮어 길을 만들 수 있으나 그 능력은 비활성입니다. 중간 간격을 다른 색이 차지해도 연결은 유지되지만, 잠긴 영역이나 보드 밖을 가로질러 연결할 수 없습니다.

회수는 룬을 공용 보관함으로 되돌립니다. 해당 편집 세션 안에서 다른 보드로 옮길 수 있으며, 전체 배치 저장 전에는 전투에 적용되지 않습니다. 중간 조각의 회수·회전으로 연결이 끊기면 남은 조각을 오류로 표시하고 저장·보드 이동을 막습니다. 현재 보드를 고치거나 되돌린 뒤 계속할 수 있습니다.

## 화면과 편집

성소의 ‘룬 성장’ 바로가기와 성장 화면에서 진입합니다. 전투 중에는 성장 화면을 통해 열 수 있습니다. 상단에 여섯 무기 종류를 한 줄로 표시하고 선택한 무기의 보드를 엽니다. 전체 프리셋·합성·배치 연습으로 이동할 수 있습니다.

보드에는 배치 가능 영역과 실제 착지 후보, 선택 조각, 오류 배치, 요구 색과 시작칸을 표시합니다. 선택 후 탭 배치·드래그 이동·60도 회전·회수, 확대·축소·이동·원점 복귀를 제공합니다. 보관함은 보드 오른쪽에서 별도로 스크롤하며 등급과 크기로 필터링합니다. 상세에는 능력 수치 등급·요구 룬 등급·영역 개방 조건·비활성 이유를 구분합니다. 합산 요약은 저장 전 미리보기와 현재 확정 상태를 구분합니다. 저장·되돌리기·닫기는 고정 하단에 둡니다. 미저장 상태로 닫으면 폐기 여부를 확인합니다.

화면 밖 드롭과 무효 드롭은 이전 배치를 유지합니다. 화면 전환·포인터 취소는 드래그를 취소합니다. 한영 문구, 세로·가로 화면과 글자 크기는 기존 UI 체계를 따릅니다.

## 전투 중 편집과 저장

룬 편집을 열면 전투와 제한시간을 정지하고, 닫을 때 열기 전의 일시정지 상태를 복원합니다. 전투 종료 후 반복 진입 대기도 편집 중에는 진행하지 않습니다. 저장 성공 후 해당 무기의 능력치를 갱신합니다. 기존 체력·자원은 늘리지 않으며, 최대치가 줄면 새 최대치까지만 유지합니다. 재사용 대기시간·현재 행동·발사체·장판·무작위 난수 상태는 초기화하지 않습니다.

이미 발사된 공격과 만들어진 장판의 룬 공격·속성·치명타·스킬 강화·조건부 피해 값은 기존 스냅샷을 유지합니다. 새 효과는 기존 게임의 효과 생성 시점에 새 값을 잡습니다. 아직 효과를 생성하지 않은 준비 행동은 기존의 발동 시점 계산을 따릅니다. 회오리 등 지속 행동은 다음 정상 유료 틱에서 새 값을 사용합니다.

편집·불러오기·합성은 복사본에서 먼저 검사하고 파일 저장 성공 뒤 실제 계정에 반영합니다. 실패하면 배치·소유·프리셋·현재 전투와 디스크 원본을 보존하며 같은 편집을 재시도할 수 있습니다. 소유 상태가 갱신된 오래된 편집본은 덮어쓸 수 없습니다.

## 전체 배치 프리셋 5칸

각 슬롯은 모든 보드에 배치된 실제 룬 ID, 무기 종류, 좌표, 회전을 기록합니다. 비어 있는 보드도 전체 교체 결과에서 비어 있게 됩니다. 장착 무기·영웅·스킬 장착·사냥 칙령·룬 소유량·합성 결과는 프리셋의 저장 범위가 아닙니다.

한 룬을 여러 프리셋에서 참조할 수 있지만, 적용되는 현재 전체 배치에서는 한 보드에서만 사용할 수 있습니다. 저장은 현재 확정된 전체 배치를 기록하며 슬롯 덮어쓰기를 확인합니다. 불러오기는 현재 전체 배치를 프리셋으로 교체하는 것임을 확인한 뒤, 모든 룬의 존재·소유·등급·중복·연결을 검사하고 전부 함께 적용합니다.

합성으로 필요한 룬이 없어졌거나 영역 조건이 맞지 않으면 전체 불러오기를 거절합니다. 비슷한 다른 룬으로 바꾸거나 일부만 적용하지 않습니다. 슬롯을 지워도 실제 룬과 현재 배치는 유지합니다. 미저장 배치가 있으면 먼저 저장 또는 되돌리기를 요구합니다.

## 획득과 합성

신규 계정과 기존 저장의 최초 이행에 G0 1칸 룬 12개, 2·3·4·5칸 예제 조각 각 1개를 한 번만 지급합니다. 기존 장비·재화·진행을 변경하지 않습니다. 실제 균열 보스 처치마다 룬 4개를 지급합니다. 보상 등급은 `min(6, floor(균열 단계 / 5))`, 크기는 1~5칸 균등, 형태는 해당 크기의 형태군에서 균등 선택합니다. 전투·장비 보상 난수열과 분리하며 같은 실행 보상을 중복 지급하지 않습니다. 훈련·미실행 보상·소탕은 룬을 지급하지 않습니다.

같은 등급·크기 두 조각을 합성합니다. 모양은 달라도 됩니다. 1~4칸은 같은 등급의 다음 크기로, 5칸은 다음 등급 1칸으로 성장합니다. G6 5칸은 최종 단계입니다. 조건을 만족하면 항상 성공하고 수수료·파괴가 없습니다. 배치 중인 조각과 미수령 결과는 재료로 쓸 수 없습니다. 한 번에 최대 100쌍이며 행마다 짝수가 아니면 해당 작업 전체를 거절합니다.

결과는 먼저 수령 대기 상태로 저장하고 공개 후 선택 등급의 모든 결과를 함께 받습니다. 이 등급은 결과 등급이 아니라 재료 등급입니다. 미수령 결과가 있는 행에서는 추가 합성을 막습니다. 창을 닫거나 재접속해도 결과 모양은 유지됩니다. 선택만 한 재료는 닫을 때 선택을 취소하며 소비하지 않습니다.

## 원본 재사용과 검증 기준

PackBound의 좌표·모양·회전, 전체 그래프 검사, 편집·소유 모델, 효과 활성화·합산, 19칸 5페이지 연습 모델을 재사용합니다. 출처와 해시는 [이식 기록](../Implementation/Rune_Growth_Import.json)에 있습니다. 원본 프로젝트는 수정하지 않습니다. 장비별 54종 능력표·무작위 설계도 로더·전투 소유자·씬은 가져오지 않습니다. 기존 HELLSCRIPT의 UGUI와 저장 소유자에 맞춰 화면과 연결부를 작성합니다.

검증은 형태·연결·등급 분리, 여섯 무기 적용 범위, 자유 회수·이동, 다섯 전체 프리셋·소모 룬 거절, 합성·중복 보상, 저장 실패·재시도·재접속, 전투 상태 유지, 높은 등급의 스킬 실제 효과, 한영 화면·작은 세로 화면·가로 화면을 포함합니다. 구현 상태와 실행 증거는 [개발 기록](../Implementation/Rune_Mastery_Implementation.md)에 별도로 기록합니다.
