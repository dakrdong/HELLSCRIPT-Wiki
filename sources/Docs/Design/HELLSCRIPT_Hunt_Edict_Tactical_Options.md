# 사냥 칙령: 스킬별 전술 옵션 기획안

작성일: 2026-10-22 · 버전: v1.0 초안 · **기획 전용 / 구현 전**

[English](HELLSCRIPT_Hunt_Edict_Tactical_Options.en.md)

액티브 **30종(일반 24종·궁극기 6종)**과 부모 효과를 바꾸는 **보조 84종**을 대상으로 한다. 유저는 스킬을 **어디에, 누구에게, 어떤 순서로 쓸지** 고른다. 피해·사거리·효과 시간·쿨타임을 바꾸는 강화 시스템은 추가하지 않는다.

각 부모 카드에는 자동 사용을 포함해 4~5개를 두고, 선택한 보조만 2개를 추가하거나 부모 행을 교체한다. **보조 적용 상태를 포함한 최대 편집 항목은 카드당 7개**다. 비활성/접힌 수치도 따로 세었다. 84개 보조에 독립 자동 사용·쿨타임·스킬 슬롯을 만들지 않는다.

본 문서는 현재 D4 스킬 구성에 맞춘 후속 설계 제안이다. [기존 핵심 옵션 v0.2](HELLSCRIPT_Hunt_Edict_Skill_Option_Catalog.md), [구현 계약](HELLSCRIPT_Hunt_Edict_Implementation_Contract.md), [저장·프리셋 계약](HELLSCRIPT_Hunt_Edict_Detail.md)의 실제 구현/버전을 바꾼 기록은 아니다. v0.2의 18개 액티브·3개 기본 공격·89개 옵션 수를 D4 전체 목록으로 사용하지 않는다. 검토 후 구현할 때 계약을 함께 개정해야 한다.

## 1. 중복을 없애는 구성

- **전역에 한 번만**: 대상 등급·타입·상태 우선순위, 추적 범위, 교전 거리, 몰이, 내 영역 유지, 위험·HP·긴급 자원·회피기 보존, 공통 실행 순서.
- **부모 스킬에 한 번만**: 자동 사용, 고유 전술, 전술 인원/횟수/위치 기준, 지정한 한 번의 연계. 기존 원생 사용 옵션과 새 전술 메뉴를 나란히 두지 않는다.
- **보조 선택 시만**: 변형의 실제 목적에 맞는 2개 행. 공격 형태가 바뀌면 맞지 않는 부모 행을 교체한다. 교체 전 값은 보존하지만 해당 형태에서 작동하지 않는다.
- **고유한 기존 예외 유지**: W04/M06 보스 사용, W06 비전투 자원 보충, M04 엄격한 목적지 기준. 성격이 다른 기능을 전역 한 값으로 억지로 합치지 않는다.
- **자동 계산/읽기 전용**: 실제 적중 예측, 효과 상한, 남은 CD·충전·표식·장판, 선택 불가 이유. 틱 수·명중률·예측 오차·개별 수식 편집기는 제공하지 않는다.

`HET-*`는 **기획 행 ID**다. 저장 키·실행 코드·공유 코드 형식을 새로 구현했다는 뜻이 아니다. 한 행은 선택 하나 또는 숫자 하나이며, 선택 아래 별도 슬라이더를 숨기지 않는다.

## 2. 선택·수치·연계의 공통 의미

| 항목 | 기획 결정 |
|---|---|
| 자동 사용 | 모든 부모 카드 `-01`: 켜기/끄기, 신규 유효 장착 카드 기본 **켜기**. 가져오기는 원래 Off를 보존한다. 미장착/미해금은 실행 불가다. 부모 Off는 긴급 선택보다 먼저 적용된다. |
| 선택형 | 표의 선택지는 단일 선택이다. 기본값은 신규 초안용이며 기존 설정을 덮어쓰지 않는다. |
| 수치형 | 표에 최솟값·최댓값·단위·간격·기본값을 모두 적는다. 인원·충전·링크는 실제 형태·랭크 상한을 넘겨 적용하지 않는다. |
| 일반 전술·우선 | 결과 선호다. 후보가 없으면 같은 스킬의 일반 대상/현재 안전 위치, 그마저 불가하면 다음 유효 행동으로 돌아간다. 수치 미달로 모든 사냥을 멈추지 않는다. |
| 전용·때만·대기 | 명시된 조건이 없으면 **이 스킬만** 보류한다. 다른 공격·생성·생존은 계속 판단한다. |
| 자유 | 기존 공유 실행 순서와 전역 대상/위치를 따른다. 별도 우선순위 편집기를 만들지 않는다. |
| 스킬 참조 | 실제 장착·해금·자동 허용·변형이 맞는 같은 직업 스킬만 활성화한다. 새 초안의 기본 참조가 없으면 '자유/없음', 필수 참조는 공유 순서 첫 유효 항목으로 정한다. 후보가 전혀 없으면 전술을 비활성화하고 이유를 표시한다. |
| 선택지 변경 | 지원하지 않는 선택지는 회색으로 이유 표시. 숨겨 둔 다른 보조의 값은 해당 보조를 실제 선택하기 전까지 적용하지 않는다. |
| 효과 상한 변화 | 예: 관통 목표 7명이나 현재 랭크 상한 3명이면 실제 상한 3명을 표시한다. 기존 요청값은 원본에 보존하고 효과를 7명으로 늘리지 않는다. |

**판단 순서**는 부모 자동 허용 → 실제 행동 잠금/소유/비용/CD/사거리/사선/합법 착지 → 전역 긴급·회피·생존 보존 → 해당 스킬의 명시된 허용 조건 → 전술 선호/연계 → 일반 공유 순서다. 부모 Off 때문에 사용할 수 없는 긴급 지정은 이유를 표시하고 다른 유효 생존 행동으로 넘어간다.

연계 예약은 **다음 한 행동**에만 적용한다. 실제 발사·적중·착지·제어·처치·충전 사건을 구분하고, 성공하지 않은 사건을 선행으로 인정하지 않는다. 예약 후 상황이 바뀌면 재검사하고 취소한다. 후속 행동에서 또 연계를 재귀 예약하지 않으며 이후 일반 공유 순서로 돌아간다. 준비 행동도 1회만 선호하고 반복 준비 루프를 만들지 않는다.

같은 사건에서 부모와 보조가 서로 다른 후속기를 지정하면 **선택한 보조의 후속기 하나**를 우선한다. 보조의 배치 선호도 해당 형태의 부모 선호보다 먼저 평가하지만 부모 Off·보스 사용 허용·전역 생존은 우회하지 않는다. 이미 유효한 예약은 실행/취소까지 유지하고, 같은 시점의 다른 선호로 예약을 쌓거나 계속 덮어쓰지 않는다.

위치 전술은 **기존 이동 허용 안의 후보 선택**이다. 설치 위치·방향을 만들기 위한 추가 공세 이동은 해당 행에서 허용한 상한과 전역 한도 중 더 작은 값 안에서만 한다. 별도 상한이 없는 전술은 전역 이동 정책만 따른다. 공격 이동 금지면 현재 자리의 가능한 전술로 돌아간다. 이동기가 없는 스킬에 돌진을 주지 않는다.

내 장판/표식/출혈/감속은 실제 소유 효과만 읽는다. 사라졌거나 보조로 다른 형태가 된 효과는 기준점에서 제외한다. 적의 이동 경로는 관측값이며 미발견 적·확정 미래를 읽지 않는다. 피해 계산은 실제 장비·세트·패시브만 반영하고, 보조/장비가 없는 중복 적중·빙결·차징·추적을 지급하지 않는다.

**준비 교착 방지**: 준비/생성 행동의 실행 가능 검사는 그 행동이 앞으로 만들 강화·충전을 요구하지 않는다. 채널 후속은 정상 종료 뒤 실제 자격을 다시 검사한다. 예약된 소비기가 없거나 버프 안에 사용할 수 없으면 강화 보존을 해제한다. 필요한 자원을 만드는 유일한 기본/생성 공격까지 보존으로 막힌 경우 1회 생성 공격을 허용하고 재평가한다.

## 3. 현재 칙령과 합치는 위치

아래는 **설계상 목적지**다. '직접 대응'은 해당 필드의 의미만 같다는 뜻이며 전체 프리셋의 자동 변환 성공을 뜻하지 않는다. 나머지는 기존 원본/버전을 유지한 채 차이를 표시하는 변환 초안으로 다룬다. 특히 엄격 조건을 우선 조건으로 바꾸거나 서로 다른 충전을 같은 값으로 읽지 않는다.

## 7. 기존 저장·프리셋과의 관계

저장 화면·5개 프리셋·미저장 편집본·되돌리기·원자적 적용은 [기존 저장 계약](HELLSCRIPT_Hunt_Edict_Detail.md)을 참조한다. 이번 기획을 위해 같은 기능의 새 저장 UI를 만들지 않는다. 스킬 장착과 해당 옵션을 함께 복원하고, 없는 스킬은 원래 슬롯을 빈칸으로 둔다. HP·자원·CD·진행 중 동작·충전·기존 투사체·장판은 프리셋 때문에 새로 채우거나 초기화하지 않는다.

보조 설정은 부모 ID와 실제 보조 ID로 구분해 보존한다. 다른 보조의 값이 남아 있어도 발동하지 않는다. 지원하지 않는 옛 옵션은 원본을 보관하고 변환 차이를 표시한다. 사용자가 변환 초안을 저장하기 전 현재 실행 설정을 바꾸지 않는다. 구버전 독립 `M04-3`는 버전/형태를 식별하지 않고 D4 보호막 보조로 읽지 않는다.

## 8. 구현 전에 확인할 쟁점과 완료 기준

**기획에서 정한 것:** 모든 액티브/보조의 실제 선택지, 숫자 범위·간격·기본값, 고유한 기존 기능의 소유 위치, 보조에 따른 행 교체, 참조 부재/면역/불법 위치/자원 부족 시 동작, 연계 예약의 한계.

**구현 전에 측정·검증할 것:** W09-2의 CD·출혈 지속으로 가능한 중첩 유지, A07/A14의 실제 주입·잔상 소비 지원 범위, 발사 중 합법 재타깃 경계, 선조/쇠뇌의 목표 배분 지원, 각 보조/장비 조합의 충돌과 실제 적용 상한. 현재 지원이 확인되지 않은 소비자는 선택지에 자동 추가하지 않는다. 모든 숫자는 초기 기획값이며 실전 밸런스 검증을 거친 값이 아니다.

후속 구현의 수용 기준은 관련 영역에 한정한다.

1. 실제 장착 구성에서 카드당 최대 7개이며, 다른 형태의 덫·장판·폭발·빙결 행이 남지 않는다.
2. 예시에서 같은 스킬/장비로 서로 다른 전술을 재현할 수 있다. 대체 행동과 보류 이유를 확인할 수 있다.
3. Off·전역 생존·자원·CD·사거리·사선·안전 착지·효과 소유를 연계가 우회하지 않는다.
4. 생성 자원·충전·이전·적중은 실제 사건에만 반응하며 예약 취소·참조 해제·면역에서 반복 대기하지 않는다.
5. 원본 저장/공유를 보존하고, 의미가 다른 구버전 값은 명시적 변환 초안으로만 적용한다.

이번 작업의 검증은 문서의 목록·선택지·기본값·숫자·행 수·링크 대조다. 게임 코드·데이터·저장 형식은 구현하지 않았으며 Unity/Play Mode/밸런스/기기 검증을 수행하지 않았다.
