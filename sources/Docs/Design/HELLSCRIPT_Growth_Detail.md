# HELLSCRIPT 성장과 저레벨 추천 행동

작성일: 2026-09-09 · CHK-G01·CHK-G03 구현 기준

## 1. 전투 중 경험치 정산

일반 적·정예·보스의 경험치 공식은 유지한다. 같은 전투 틱에 확정한 경험치를 모아 사망·보스 결과를 정산하는 경계에서 한 번 반영한다. 한 번에 여러 레벨을 올릴 때도 기존 필요 경험치를 순서대로 차감하고, 30레벨 이후에는 경험치를 쌓지 않는다.

최대 HP가 바뀌면 정산 직전의 현재 HP 비율을 유지한다. 예를 들어 최대 HP 300 중 150이 남은 상태에서 최대 HP가 335로 늘면 현재 HP는 167.5가 된다. 사망한 영웅은 HP 0을 유지한다. 처치 회복은 기존 최대 HP로 먼저 정산하며 레벨업을 별도 회복 효과로 세지 않는다. 최대 자원은 현재 모든 직업이 100이므로 현재 자원도 그대로 유지한다.

현재 행동·남은 CD·물약 CD·채널 시간·위치는 초기화하지 않는다. 이미 생성된 투사체·지속 효과·보호막의 피해 스냅샷, 남은 시간과 생성 당시 최대 HP도 유지한다. 아직 발동하지 않은 효과는 기존 스킬의 확정 시점 규칙을 따른다. 새 능력치와 해금 레벨은 다음 행동 판단부터 사용한다.

정산 대기 경험치는 균열 상태에 보존한다. 저장된 정산을 이어 받더라도 두 번 지급하지 않으며, 전리품 정리 단계로 복원된 경우에도 먼저 반영한다. 레벨업 기록에는 획득 경험치·변경 전후 레벨과 XP·최대/현재 HP·새로 해금한 스킬을 남긴다.

## 2. 현재 레벨의 추천안

완성 빌드 6종의 원본은 유지한다. 현재 레벨 추천안은 이 원본을 복사하고 미해금 스킬의 규칙을 꺼 둔다. 해당 스킬의 장착 슬롯과 규칙은 남겨 두므로 이후 직접 켜거나 새 추천안을 불러올 수 있다. 사용자가 꺼 둔 규칙을 레벨업만으로 다시 켜지 않는다.

PM01은 눈보라를 배우기 전까지 자기 눈보라 안 조건을 사용할 수 없다. 1~2레벨 추천안에서는 화염구로 예상 명중 2명 이상 또는 보스 1명을 공격한다. 3레벨부터는 기존 눈보라·화염구 연계 추천안을 제시한다. 기존 저장의 화염구 조건은 자동으로 바꾸지 않는다.

PW01·PA01·PA02는 현재 해금한 공격을 사용한다. PW02의 1레벨과 PM02의 1~5레벨은 기본 공격 중심의 잠긴 빌드임을 설명한다. 없는 장비를 지급하거나 잠긴 스킬을 실행해 빌드가 완성된 것처럼 보이게 하지 않는다.

## 3. 미리보기와 성장 화면

추천안을 누르면 빌드의 목적·현재 사용 가능한 스킬·잠긴 스킬과 요구 레벨·변경될 행동 행·목표·이동·패시브를 먼저 보여 준다. 미리보기에서 불러오면 작성 중인 편집안만 바뀐다. 실제 행동 적용은 기존의 설정 적용 버튼으로 확정한다. 돌아가면 작성 중인 편집안을 유지한다.

균열 안에서는 기존 장착을 유지한 후보를 미리 보여 준다. 새 추천안으로 장착 제한을 우회하지 않는다. 마을과 훈련에서는 기존 편집기에서 허용한 변경을 사용한다.

전투 HUD는 현재 레벨·XP를 갱신한다. 성장 화면에서는 다음 해금과 스킬별 배움/장착/규칙 상태, 최근 레벨업을 확인한다. 화면을 보는 동안 전투를 멈추고 닫을 때 이전 일시정지 상태를 복원한다. 새 해금은 행동 설계에서 설정을 확인하도록 안내하며, 레벨업이 자동 장착·규칙 교체의 허가가 되지는 않는다.

## 4. 검증 범위

직업 3종 × 빌드 2종 × 레벨 1/3/6/10/15/20/30에서 추천안의 해금과 편집 유효성을 검사한다. 실제 군집에서 저레벨 화염구의 발사·피해를 확인하고 단일 일반 적·미해금 눈보라의 비발동도 확인한다.

일반 처치·여러 레벨·보스 보상·사망 동시 발생·30레벨 상한·정산 대기 저장·진행 중 효과에서 HP·자원·행동·XP를 확인한다. 실제 앱에서는 성장 화면·추천 미리보기·취소·적용·자연 전투와 저장 후 재시작을 연결한다. 신규 사용자의 첫 15분 안내 전체와 장기 성장 밸런스는 별도 후속 검증으로 남긴다.
