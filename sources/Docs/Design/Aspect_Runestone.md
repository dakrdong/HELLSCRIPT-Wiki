# 위상 각인석과 위상 성장

갱신일: 2026-09-22
영어판: [Aspect Runestone and progression](Aspect_Runestone.en.md)

## 플레이 흐름

마을 왼쪽 중앙의 바위에 다가가 **각인석 열기**를 누른다. 기물은 너비 5m, 높이 약 7m, 깊이 2m의 독립된 검은 바위이며 전면에 비취색 룬이 빛난다. 중심은 마을 좌표 `(-34, 4)`, 상호작용 지점은 `(-34, 1)`이다. 중앙 통로를 막지 않으며 바위의 발밑 영역은 이동을 막는다. 게임 화면에는 필드 배치 탭을 두지 않는다.

착용 장비를 선택하고, 도감에서 위상을 살펴본 뒤 각인한다. 세로 화면은 장비 선택 → 위상 도감 → 각인 확인 순서이고, 가로 화면은 세 영역을 나란히 보여 준다. 확인 화면의 교체 버튼은 착용 장비 목록을 그 자리에서 열며 선택한 위상을 유지한다.

## 수집과 레벨업

수집 기록은 계정 공용이다. 전설 장비를 분해하는 기존 거래에서 장비가 **원래 지닌 위상**을 1개 자동 등록한다. 원래 위상이 없는 희귀 장비를 각인으로 전설로 만든 경우에는 분해해도 위상을 얻지 않는다. 자연 획득한 전설을 다시 각인한 경우에는 원래 위상을 1개 얻는다. 각인과 분해를 반복해 위상을 복제하는 순환을 막고, 기존 전설의 분해 보상을 보존하는 규칙이다. 장비 상세와 분해 확인에서 수집 결과를 보여 준다. 세트 장비는 위상을 주지 않는다.

| 누적 등록 수 | 도달 가능 레벨 | 적용 방식 |
| ---: | ---: | --- |
| 0 | 비활성 | 이름과 효과만 조회 |
| 1 | Lv.1 | 최초 분해 시 자동 활성화 |
| 2 | Lv.2 | 사용자가 레벨업 버튼 선택 |
| 4 | Lv.3 | 사용자가 레벨업 버튼 선택 |
| 8 | Lv.4 | 사용자가 레벨업 버튼 선택 |
| 16 | Lv.5 | 사용자가 레벨업 버튼 선택 |

레벨업 한 번에 한 단계만 오른다. 누적 등록 수는 레벨업이나 각인으로 줄어들지 않는다. 16개 이상도 실제 등록 수를 계속 표시한다. 현재 레벨보다 도달 가능 레벨이 높으면 도감 진입부·필터·해당 위상·레벨업 버튼에 빨간 점을 표시한다. 열람만으로 지워지지 않고, 모든 가능한 레벨업을 완료해야 사라진다. 미등록 위상도 동일한 도감에서 이름·효과·고유 룬석 문양을 조회할 수 있다.

## 각인과 저장

- 희귀와 전설 등급의 **착용 중인 장비**에 각인한다. 세트는 제외한다. 위상의 직업·분류에 따라 대상 부위를 제한하거나 무기·목걸이 배수를 추가하지 않는다. 직업 전용 효과는 해당 직업에서만 발동하며 화면에 적용 직업을 안내한다.
- 장비에는 위상 하나만 적용한다. 새 위상은 기존 능력을 대체한다. 희귀는 전설이 되며 기존 3개 접사·기본 장비·이름·레벨·강화·소켓·품질·프리셋 참조를 유지한다. 원래 전설의 4개 접사도 그대로 유지한다.
- 각인 시점의 위상 레벨을 장비에 저장한다. 각인석에서 레벨을 올린 뒤 같은 위상을 다시 각인하면 장비에도 새 레벨이 적용된다. 이미 각인된 장비와 과거 전투·훈련 기록의 수치는 자동 변경하지 않는다.
- 같은 위상을 여러 부위에 착용하면 가장 높은 레벨 하나만 적용한다. 낮은 레벨이 높은 레벨을 덮거나 위상 수치가 중복 합산되지 않는다.
- 각인에는 추가 자원을 쓰지 않는다. 화면에는 비용 항목을 두지 않으며 실행 버튼은 **각인**으로 표시한다.
- 거래가 확정될 때 실제 소유자·착용 상태·장비 원본·현재 도감 레벨을 다시 검사한다. 변경된 미리보기, 다른 캐릭터, 사냥 진행 중 작업은 거절한다. 저장 실패 시 장비·수집 기록·레벨을 함께 보존한다. 동일 거래 재시도는 중복 지급하지 않는다.
- 저장 스키마는 9다. 기존 저장은 빈 위상 도감으로 이행하며 보유 장비를 자동으로 분해하거나 위상을 소급 지급하지 않는다. 더 높은 스키마를 읽지 못하는 구버전은 저장을 보존하고 실행을 중단한다.

## 효과 성장 기준

Lv.1은 기존 전설 효과와 같다. 일반적인 핵심 수치는 원래 값의 **100% / 105% / 110% / 115% / 120%**로 증가한다. 기절·속박·빙결은 지속시간을 늘리고, 마지막 명령의 내부 대기시간과 좁혀진 사선의 발사각은 **100% / 95% / 90% / 85% / 80%**로 줄인다. 절제의 서약은 최종 자원 감소 상한에 막히지 않도록 충전 유효시간을 늘린다.

발동 조건·필요 적중 수·대상 수·반경·기본 재발동 간격은 아래에서 명시한 예외 외에는 바꾸지 않는다. 각종 피해·감소·속도·극대화의 기존 최종 상한도 유지한다. `D`는 원래 전투 규칙의 공격 기준값이고, `%p`는 가산되는 퍼센트포인트다. 지연 타격·투사체·지속 피해는 발동 시점의 위상 레벨을 보존한다. 아래 수치는 초기 밸런스이며 장기적인 난도·효율 조정의 근거가 되는 첫 적용값이다.
