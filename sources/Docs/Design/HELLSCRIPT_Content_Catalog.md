# HELLSCRIPT 콘텐츠 카탈로그

작성일: 2026-09-08  
문서 상태: 공유 대화의 콘텐츠 데이터 v0.1을 정리한 **구현 검토용 테스트 초안**입니다. 2026-09-08 확정한 상위 기획서 v1.1의 정책을 함께 적용합니다.

**v1.2 후속 명세:** 이 문서의 기존 178개 정의와 ID는 보존합니다. 이후 개발은 [전체 상세 기획](HELLSCRIPT_Development_Expansion_Plan.md), [장비·빌드](HELLSCRIPT_Itemization_Detail.md), [균열·탐색·상자](HELLSCRIPT_Rift_Exploration_Detail.md), [게임 완성 체크리스트](HELLSCRIPT_Gameplay_Completion_Checklist.md)의 보완 규칙을 함께 적용합니다. 추가 세트 등 후속 콘텐츠를 이 문서의 기존 수량에 소급 합산하지 않습니다. 현재 구현 수량과 추가 ID는 후속 상세안과 [개발 기록](../Implementation/Itemization_Expansion.md)을 따릅니다.

이 문서는 처음에는 [공유 대화](https://chatgpt.com/share/6a9fb7c6-43e0-83e8-b6f4-7630c9f9e98f)의 GDD 화면 본문과 콘텐츠 부록을 대조해 작성했습니다. 2026-09-12 사용자가 제공한 [GDD 기준본](HELLSCRIPT_GDD_v0.1.md)과 [콘텐츠 Excel](../Data/HELLSCRIPT_Content_v0.1.xlsx)을 프로젝트에 저장했으며, 균열 등급 확률·재설정 고정 비용과 관련 수식을 직접 대조했습니다. 이 카탈로그의 초기 콘텐츠 행 전체를 최신 구현에 맞춰 다시 작성한 것은 아닙니다. 기존 ID와 수치·효과·제약을 보존하며, 이름·효과·계수·가중치를 사용자 확정값으로 해석하지 않습니다.

**현재 보상 규칙:** [균열 단계별 등급 확률](HELLSCRIPT_Rift_Rarity_Detail.md)을 적용합니다. 일반·정예·보스의 현재 전투 단계와 소탕의 최고 실제 클리어 단계를 구분하며, 전설 등급 결정 이후의 구성원 가중치는 별도로 유지합니다. 아래 초기 가중치와 이후 프로젝트 가중치의 차이는 [장비 미결 항목 정리](HELLSCRIPT_Itemization_Open_Items.md)와 [개발·검증 기록](../Implementation/Rift_Rarity_Expansion.md)을 따릅니다.

게임의 전체 규칙과 구현 순서는 [Unity 구현 기획서](./HELLSCRIPT_Unity_Implementation_Plan.md)를 함께 확인합니다. 원본에서 뜻이 충분히 정해지지 않은 부분은 이 문서 끝의 **구현 전 보완**에 남겼습니다. 그 항목을 실제로 적용하기 위한 신규 시험안은 상위 기획서 **16장**에 정리했습니다. 아래 표는 원본을 보존한 표이므로, 구현할 때는 상위 기획서의 보완 규칙을 함께 적용합니다.

## 표를 읽는 기준

- `D`는 장비와 직업 주능력을 반영한 공격 기준값입니다. `D180%`는 `D × 1.8`입니다. 적 패턴에 쓰인 `D`는 플레이어의 `D`와 혼동하지 않도록 별도 정의가 필요합니다.
- `HP`는 체력, `CD`는 재사용 대기시간, 내부 CD는 효과 자체의 재발동 제한입니다. `+10%p`는 퍼센트포인트 증가입니다.
- 액티브 표에서 자원 비용은 1회 발동 기준이며, 휠윈드만 0.25초마다 비용을 지불합니다. 피해 주기를 별도로 적지 않은 공격은 1회입니다. 피해가 없는 스킬의 D 계수는 0입니다.
- 범위와 사거리가 없는 자기 강화 스킬은 원본에서 모두 0입니다. 숫자 0은 쿨타임·비용이 없거나 해당 공간 값이 적용되지 않는다는 뜻이며, 공격 동작까지 즉시 완료된다는 뜻은 아닙니다.
- 등장 가중치 `100 / 20 / 1`은 같은 후보군 안에서 비교하는 상대값입니다. 전체 드롭 확률이나 백분율이 아닙니다.
