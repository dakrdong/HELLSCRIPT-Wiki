# 전설·세트와 여섯 빌드의 통합 검사 기준

작성일: 2026-09-09 · D3 개발 시험안

[장비 상세](HELLSCRIPT_Itemization_Detail.md)와 [패시브 상세](HELLSCRIPT_Passive_Combat_Detail.md)의 개별 효과를 실제 8부위 구성으로 연결한다. 추가 세트 SWB·SAB·SMB를 포함한 6세트는 기존 개발 시험 범위를 유지한다. 이 문서의 검사 장비는 비교용 지급품이며, 실제 계정의 장비를 지급·교체하거나 드롭 확률을 변경하는 기능이 아니다.

## 1. 비교할 합법적 장비 구성

같은 칸에는 장비 하나만 들어간다. 4세트는 머리·몸·손·발을 모두 사용하므로 손·발 전설과 동시에 장착할 수 없다. 첫 비교는 30레벨 영웅과 아이템 레벨 30, 강화 0으로 진행한다. 희귀 기준군은 같은 직업의 두 프리셋에 동일한 생성 시드의 희귀 장비 8부위를 준다. 세트군은 아래 구성의 실제 생성 장비를 사용하며 접사까지 포함한 변화다. 세트 효과만의 독립 배율 실험으로 해석하지 않는다.

| 프리셋 | 무기 | 머리·몸·손·발 | 허리 | 목걸이 | 반지 |
|---|---|---|---|---|---|
| PW01 회오리 생존 | LW01 | SW 4부위 | LC03 | LC02 | LC01 |
| PW02 도약 분쇄 | 희귀 | SWB 4부위 | LC03 | LW04 | LC01 |
| PA01 관통 거리유지 | LA01 | SAB 4부위 | LC03 | LC02 | LC01 |
| PA02 맹독 매복 | LA01 | SA 4부위 | LC03 | LA04 | LC01 |
| PM01 서리 장판 | LM01 | SM 4부위 | LM03 | LC02 | LC01 |
| PM02 연쇄 제어 | 희귀 | SMB 4부위 | LM03 | LM04 | LC01 |

별도 조합 검사는 전사 2세트+LW02·LW03·LW04, 궁수 2세트+LA02 또는 LA03, 마법사 2세트+LM02를 포함한다. 스킬을 장착하지 않은 전설은 발동하지 않는 선택으로 표시하며, 단지 등급이 높다는 이유로 모든 프리셋에 추천하지 않는다. SW 4세트와 LW02, SA/SAB 4세트와 LA03, SM/SMB 4세트와 LM02는 각각 부위 충돌로 불가능하다.

## 2. 효과별 통합 검사

| 효과 | 확인할 동작 |
|---|---|
| LW01 | 실제 유료 회오리 1초 이후 발동한다. 반경 3.5m 내 일반·정예만 최대 1.5m 끌어오고 보스·사체·이동 불가 적은 제외한다. 벽과 몸체 안으로 밀어 넣지 않으며 전설이 직접 새 피해를 만들지 않는다. 채널 재시작·저장으로 1초 간격을 우회하지 않는다. |
| LW02·LW03 | 성공 착지의 충격파는 원 피해와 별도 1회다. 분쇄는 실제 유효 대상 목록이 정확히 한 명일 때만 +50%를 적용한다. 빈 공격·중단·다수 대상과 앞선 대상 사망을 검사한다. |
| LW04·LC03 | 체력 경계에 정확히 도달한 경우를 포함한다. 생존·장착·쿨타임·실제 HP 감소 또는 물약 성공 조건을 지킨다. 내부 CD와 원래 물약·도약 규칙을 유지한다. |
| LA01·LA02 | 실제 투사체 충돌 순서와 한 시전의 화살 집합으로 판정한다. 관통 +60% 상한, 동일 적 최대 세 발, A06 충전 한 번 소비를 지킨다. |
| LA03·LA04 | 후퇴 시작점에 3초 피해 덫을 생성한다. 덫 장착·두 덫 상한·중단 처리를 적용한다. 자기 독의 암흑 추가 피해만 전염 원천이 되며 원 공격·원 표적별로 한 번, 다른 적 최대 두 명에게 전달한다. |
| LM01·LM02 | 고정/추적 설정과 4m 이동 상한을 유지한다. 화염구 후속 폭발은 0.4초 후 별도 한 번이며 자신을 다시 만들거나 SM 표식을 소비하지 않는다. |
| LM03·LM04 | 보호막 발생별 실제 누적 흡수와 내부 CD를 지킨다. 연쇄의 총 타격 수·재방문 최대 두 번·두 번째 피해 ×0.5·단독 적 반복 금지를 확인한다. |
| LC01·LC02 | 획득 반경 상한과 회수 이동·비전투 조건을 구분한다. 기본공격 세 번으로 만든 할인은 같은 대상·기한·실제 유료 사용·합산 상한을 지킨다. |
| SW·SWB·SA·SAB·SM·SMB | 같은 세트의 서로 다른 부위만 2/4세트로 센다. 발동·충전·예약·소비·만료·독립 효과가 각 원천에 한 번만 연결되며 저장 후에도 다음 상태가 같다. |

LW01의 몸체 간격·처리 순서·기존 겹침·공격 중단·발동 기록은 [장비 상세안 5.1](HELLSCRIPT_Itemization_Detail.md#51-lw01-강제-이동의-상세-시험-기준)을 따른다. 일반 몬스터의 모든 이동에 새 충돌 시스템을 적용하는 범위로 확대하지 않는다.

## 3. 여섯 빌드의 행동 차이

프리셋을 별도 검사 전용 규칙으로 바꾸지 않고 기존 추천 규칙 그대로 실행한다. 군중·단일 보스·원거리 접근·낮은 HP에서 첫 행동·스킬 비중·이동·중단·자원 부족을 비교한다. 예를 들어 전사는 회오리 유지와 진입 도약·분쇄, 궁수는 표식·사선과 덫·중독 사격, 마법사는 눈보라·화염구와 연쇄·근접 제어의 차이를 확인한다.

실제 생성 균열에서도 같은 시드·단계·성장 수준으로 희귀군과 세트군을 비교한다. 클리어 여부, 전투 시간, 처치·상자·탐색·피해·사용한 스킬을 기록한다. 실패를 통과로 바꾸기 위해 HP·공격력·시간 제한·보상·도착 위치를 실행 중 수정하지 않는다. 실패 원인이 규칙·경로·범위 오류이면 수정하고, 정상적인 시간 초과·생존력 차이는 밸런스 관찰로 남긴다.

1배·1.5배·2배의 처리 속도는 같은 고정 틱을 진행해야 한다. 배속 비교에서는 같은 전투 틱까지의 행동·피해·상태가 같아야 하며 실제 경과 시간은 구분한다. 자동 검사와 실제 앱의 편집·재시작·화면 결과도 구분해 기록한다.

### 3.1 첫 비교에서 발견한 보완 작업

2026-09-09 첫 비교는 시드 91367의 1단계 균열을 6프리셋×희귀/세트 구성으로 실행했다. 이 결과는 한 지형·한 장비 수준의 진단이며, 전체 밸런스나 자연 성장의 검증 결과가 아니다.

| 항목 | 관찰한 문제 | 구현·검사 기준 |
|---|---|---|
| 근접 접근 | PW02 희귀 구성은 약 211초부터 벽 모서리에서 이동하지 못했다. `navigationError`가 비어 있어도 경로 재시도는 반복됐다. | 가까운 우회 지점도 다음 구간이 벽에 막히면 실제로 지나간다. 생성 지형의 재현 좌표에서 여러 이동 간격·복원 후 도달을 검사하고, 전체 균열을 같은 조건으로 다시 실행한다. |
| 서리 장판의 단독 보스 대응 | PM01은 적 3명 조건 때문에 단독 보스에게 눈보라를 설치하지 않았다. 자기 눈보라 안의 적에게만 쓰는 화염구도 함께 비활성화됐다. | 추천 시험안을 ‘예상 적중 3명 이상 **또는 현재 대상이 보스**’로 보완한다. 화염구의 자기 눈보라 조건·비용·쿨타임은 유지한다. 일반 적 한 명이나 감지하지 못한 보스는 예외를 만족하지 않아야 한다. |
| 연쇄 제어의 단독 보스 | PM02는 두 장비군 모두 제한시간에 보스를 잡지 못했다. | 연쇄가 단독 적을 반복 타격하도록 바꾸지 않는다. 보스 도달 시각·남은 HP·스킬별 보스 피해를 기록하고, 경로 수정 후에도 남는 차이는 다중 시드·단계별 밸런스 평가로 넘긴다. |
| 장비 설명 | 후퇴 덫의 지속시간, 획득 반지의 이동 조건 등 일부 설명이 실제 발동 조건과 달랐다. | 효과 시간·발동 원천·내부 대기시간을 설명에 반영한다. 장비 상세와 도감에서 긴 설명의 마지막 문장까지 읽을 수 있는지 확인한다. |

PM01 보완은 개발 검증을 위한 추천 프리셋 수정이다. 기존 사용자의 저장 슬롯과 편집한 규칙을 자동으로 덮어쓰지 않는다. 새로운 추천안을 선택할 때 실제 OR 조건으로 표시하고, 확인 가능한 규칙을 거치지 않는 숨은 보스 보정은 넣지 않는다.

비교 기록에는 경로 재시도 횟수, 행동하지 않고 접근 위치에 머문 최장 시간, 보스 생성 시각과 남은 HP, 스킬별 보스 피해를 추가한다. 이러한 관찰값은 실패 원인을 조사하는 단서이며, 시간이 오래 걸렸다는 이유만으로 캐릭터를 순간이동시키거나 보상을 지급하는 복구 조건으로 쓰지 않는다.

## 4. 완료 판정

개별 효과의 기획·실제 코드·직접 검사 근거를 연결한 표를 유지한다. 수량만 맞는 검사나 특수효과 이름을 능력치 목록에 직접 넣은 시험만으로 전체 장비 조합을 완료했다고 표시하지 않는다. 실제 편집·장착·저장·생성 균열까지의 연결은 별도 증거로 확인한다. D4의 자연 성장·마을·훈련 분석과 D5·D6의 온라인·기기·표현 기준은 이 단계의 단위 비교와 구분한다.
