# 튜토리얼 진행과 콘텐츠별 안내

갱신일: 2026-09-29

> 2026-10-04: 장(章) 단위 재설계와 코드·문서 차이는 [Tutorial_Chapters.md](Tutorial_Chapters.md)를 따른다.

승인한 흐름을 구현한다. 별도 튜토리얼 맵의 프롤로그 「칙령의 목소리」에서 하늘에서 내려온 사냥 칙령으로 첫 스킬을 배워 장착하고 스킬 프리셋을 고른다. 이어서 수문장과 싸우며 자동 물약과 회피 설정을 바꾸고, 수문장을 처치하면 금화 1,000을 받고 마을로 이동한다. 이후 균열, 사냥칙령 수정, 새 스킬 장착을 익히며 콘텐츠가 열릴 때 해당 사용법을 안내한다.

## 확정한 진행 규칙

- 별도 맵만 계정 최초 1회 필수로 진행한다. 이후 안내는 읽기·나중에 보기·숨기기·다시 열기를 지원하며, 설명 확인과 실제 수행을 별도로 저장한다.
- 필수 맵의 두 사냥 칙령 설정은 지정한 버튼만 누를 수 있는 강제 단계로 진행한다. 다음에 누를 버튼은 실제 저장 상태에서 정한다.
- 최초 맵을 마치면 완료 보상으로 금화 1,000을 한 번 받는다. 보상과 계정 완료 표시는 한 거래로 저장하며, 장비는 지급하지 않는다. 이 보상 외에 튜토리얼 전투는 XP·골드·무작위 전리품·피로도·균열 기록·최초 클리어·미접속 보급 기준을 만들지 않는다.
- 다른 캐릭터의 핵심 안내는 영웅별로 기록한다. 다시보기는 레벨 1 계정 복사본을 사용하며 보상을 실제 계정으로 옮기지 않는다.
- 최초 실습 지원은 계정 전체에 10종류를 각각 한 번 제공한다. 실행 거래의 임시 계정 안에서만 비용을 지원하며 결과와 함께 저장한다. 취소·조건 불충족·저장 실패 시 지원 기회를 유지한다.
- 기존 콘텐츠의 선행 조건·가격·확률·공간·보호 상태와 NPC 거리를 그대로 검증한다. 연습을 이유로 전설·위상·레벨·선행 강화·소탕 횟수를 지급하지 않는다.
- 기존 계정은 필수 맵을 면제한다. 과거의 확인/건너뛰기 기록은 읽음으로만 이전하며, 의미가 동일한 실제 첫 플레이 수행 기록은 보존한다. 기존 계정에는 현재 이용 맥락에 맞춰 안내한다.

## 필수 맵 상세 흐름

단계 이름은 전투 상태 `ProloguePhase`의 값이다.

| --- | --- | --- |
| 준비 | 계정의 첫 캐릭터로 시작한다. | 스킬 배분을 초기화해(1레벨 포인트 1, 빈 칸) 직업별 첫 스킬(W01·A01·M01)의 시작 프리셋을 정하고 저장한다. 맵 소유 영웅과 실행을 시작 전에 저장한다. |

| `EdictLesson` | 강제 단계로 사냥 칙령을 열어 첫 스킬에 포인트 1을 찍고 장착·저장한다. 이어서 프리셋 탭을 차례로 살펴보고 지정한 프리셋을 활성화한다. | 첫 스킬 장착과 지정 프리셋이 실제로 저장되고 창을 닫아야 넘어간다. |

| `Gatekeeper` | 대화 뒤 보스 방으로 자동 이동해 수문장과 싸운다. | 기존 전투 엔진으로 수문장을 생성한다. 목소리가 개입하기 전에는 수문장 체력이 35% 아래로 내려가지 않는다. 캐릭터 HP가 50% 아래로 떨어지면 다음 단계로 넘어간다. |
| `SurvivalLesson` | 시간이 멈추고 목소리가 개입한다. 강제 단계로 자동 물약을 「넉넉한 생존 보급」, 피해 유형별 회피를 「모든 예고 회피」로 바꾸고 저장한다. | 바꾼 설정은 소유 캐릭터의 사냥 칙령에 저장한다. 두 설정을 저장하고 창을 닫아야 넘어간다. |
| `Showdown` | 바꾼 설정으로 수문장과 계속 싸운다. | 실제 수문장 사망으로 완료한다. |
| `Cleared` | 승리 연출 뒤 「보상을 받고 마을로」를 누른다. | 금화 1,000·계정 완료·실행 제거를 한 거래로 저장한다. 완료 요청이 반복되어도 보상은 한 번만 지급한다. |
| 마을 도착 | 균열지기 안톤 진다크가 마을의 내력과 이동 방법, 첫 균열을 안내한다. | 첫 완료 때만 대화가 나온다. |

전투 중 쓰러지면 그 자리에서 캐릭터를 회복해 다시 싸운다. 살아 있는 일반 마물도 체력을 되찾지만, 수문장이 입은 피해는 유지한다. 다시보기는 레벨 1 계정 복사본으로 진행하며, 바꾼 설정은 복사본에만 적용하고 보상은 없다. 옛 갑옷 흐름의 체크포인트(`tutorial-v1`)는 단계 의미가 달라 버리고 프롤로그를 처음부터 시작한다. 구현과 검증은 [프롤로그 — 칙령의 목소리](../Implementation/Prologue_Edict_Voice.md)를 따른다.

### 장면 연출

2026-09-29부터 필수 맵은 하늘의 목소리가 캐릭터에게 말을 거는 프롤로그로 보여 준다. 목소리는 얼굴 없이 후광만 빛나는 신으로 그리며, 균열지기 안톤 진다크는 마을에 도착한 뒤 처음 등장한다.

- `Surrounded`: 암전에서 밝아지는 도입, 영화식 띠, 「프롤로그 · 칙령의 목소리」 제목 카드. 캐릭터의 독백 중 카메라가 포위한 마물을 비춘다. 빛기둥이 쏟아지고 목소리가 말한 뒤, 두루마리가 내려와 캐릭터가 두 팔로 받들고 사냥 칙령 인장이 메뉴 칸으로 날아간다.
- `EdictLesson`·`SurvivalLesson`: 지정한 버튼만 남기고 나머지 화면을 어둡게 덮는 가림막, 그 버튼의 맥동 테두리와 목소리의 지시.
- `Encircled`: 새 목표 알림과 전투 화면의 처치 진행 수, 첫 처치 때 목소리의 짧은 대사.
- `Gatekeeper`: 목표 완료 알림, 수문장이 화면에 들어올 때의 등장 컷(일시정지, 카메라, 포효, 이름 카드).
- `SurvivalLesson` 개입: 붉은 가장자리와 영화식 띠, 다시 쏟아지는 빛기둥.
- `Showdown`·`Cleared`: 수문장 체력이 30% 이하일 때 목소리의 대사, 「승리 · 수문장 처치」 카드와 금화 1,000 보상 알림.
- 쓰러짐: 붉은 가장자리와 「쓰러졌다」 카드, 다시 일어서라는 목소리.
- 마을 도착: 암전 뒤 「잿빛 숲 · 정착민 마을」 지명 카드와 안톤 진다크의 첫 대화.

연출은 진행 조건과 저장을 바꾸지 않는다. 연출 장면은 화면을 누르거나 건너뛰기로 바로 끝낼 수 있다. 두 강제 단계는 연출이 아니므로 지정한 버튼을 눌러야 진행한다. 대화창과 옛 갑옷 흐름의 연출 기록은 [튜토리얼 연출](../Implementation/Tutorial_Staging.md)에 있다.

## 개방 기준과 세부 상황

현재 신규 계정의 개방 단계는 다음과 같다. 구버전 계정은 기존에 열려 있던 콘텐츠 이용 권한을 유지한다.

| 안내 ID | 콘텐츠 | 계정 최고 균열 클리어 |
| --- | --- | --- |
| UL01_TRAIN | 훈련장 | 마을 도착 |
| UL02_ENHANCE | 장비 강화 | 1단계 |
| UL03_OFFLINE | 미접속 보급 | 1단계 |
| UL04_RARE_CRAFT | 부위 선택 기본 제작 | 3단계 |
| UL10_SLOT_ENHANCE | 장착 슬롯 강화 | 5단계 |
| UL05_GEM | 보석 장착·교체·합성 | 10단계 |
| UL11_RUNE | 룬 배치·합성·무기 숙련 | 15단계 |
| UL07_UNIDENTIFIED_SHOP | 미확인 장비 상점 | 25단계 |
| UL06_REROLL | 옵션 재설정 | 35단계 |
| UL12_ASPECT | 위상 성장·각인 | 40단계 |
| UL08_SWEEP | 소탕 | 60단계 |
| UL13_ELIXIR | 보석 물약 제조 | 60단계 |
| UL14_MASTERWORK | 걸작 강화 | 80단계 |
| UL09_CORE_CRAFT | 전설 코어 제작 | 50단계 |

개방 단계는 `Resources/ContentUnlocks.json`을 직접 조회한다. 튜토리얼 코드에 단계별 해금 수치를 중복 정의하지 않는다. `H14`는 전설·세트·각성을 각각 기록한다. `H15`는 봉인·운반자·공물·상자·성소·고블린·정예·보스를 각각 기록한다.

최초 맵 4~6분은 사용성 목표이며, 사람의 실제 플레이로 검증한 수치가 아니다. 진행 조건은 안내를 읽은 시간 대신 실제 행동으로 판단한다.

구현 구조와 검증 범위는 [구현 기록](../Implementation/Tutorial_Progression.md)을 따른다.
