# 튜토리얼 진행과 콘텐츠별 안내

갱신일: 2026-09-25

승인한 흐름을 구현한다. 별도 튜토리얼 맵에서 실제 갑옷 획득·장착과 보스 처치를 경험하고 마을로 이동한다. 이후 균열, 사냥칙령 수정, 새 스킬 장착을 익히며 콘텐츠가 열릴 때 해당 사용법을 안내한다.

## 확정한 진행 규칙

- 별도 맵만 계정 최초 1회 필수로 진행한다. 이후 안내는 읽기·나중에 보기·숨기기·다시 열기를 지원하며, 설명 확인과 실제 수행을 별도로 저장한다.
- 최초 맵에서 획득한 레벨 1 일반 몸통 장비는 소유 장비로 남는다. 튜토리얼 전투는 XP·골드·무작위 전리품·피로도·균열 기록·최초 클리어·미접속 보급 기준을 만들지 않는다.
- 다른 캐릭터의 핵심 안내는 영웅별로 기록한다. 다시보기는 레벨 1 계정 복사본을 사용하며 보상을 실제 계정으로 옮기지 않는다.
- 최초 실습 지원은 계정 전체에 10종류를 각각 한 번 제공한다. 실행 거래의 임시 계정 안에서만 비용을 지원하며 결과와 함께 저장한다. 취소·조건 불충족·저장 실패 시 지원 기회를 유지한다.
- 기존 콘텐츠의 선행 조건·가격·확률·공간·보호 상태와 NPC 거리를 그대로 검증한다. 연습을 이유로 전설·위상·레벨·선행 강화·소탕 횟수를 지급하지 않는다.
- 기존 계정은 필수 맵을 면제한다. 과거의 확인/건너뛰기 기록은 읽음으로만 이전하며, 의미가 동일한 실제 첫 플레이 수행 기록은 보존한다. 기존 계정에는 현재 이용 맥락에 맞춰 안내한다.

## 개방 기준과 세부 상황

현재 신규 계정의 개방 단계는 다음과 같다. 구버전 계정은 기존에 열려 있던 콘텐츠 이용 권한을 유지한다.

| 안내 ID | 콘텐츠 | 계정 최고 균열 클리어 |
| --- | --- | --- |
| UL01_TRAIN | 훈련장 | 마을 도착 |
| UL02_ENHANCE | 장비 강화 | 1단계 |
| UL03_OFFLINE | 미접속 보급 | 1단계 |

| UL11_RUNE | 룬 배치·합성·무기 숙련 | 15단계 |

개방 단계는 `Resources/ContentUnlocks.json`을 직접 조회한다. 튜토리얼 코드에 단계별 해금 수치를 중복 정의하지 않는다. `H14`는 전설·세트·각성을 각각 기록한다. `H15`는 봉인·운반자·공물·상자·성소·고블린·정예·보스를 각각 기록한다.

최초 맵 4~6분은 사용성 목표이며, 사람의 실제 플레이로 검증한 수치가 아니다. 진행 조건은 안내를 읽은 시간 대신 실제 행동으로 판단한다.

구현 구조와 검증 범위는 [구현 기록](../Implementation/Tutorial_Progression.md)을 따른다.
