# 장비 비교 공통 규칙

갱신일: 2026-10-05 · 최초 작성: 2026-09-22 · 규칙 버전: `equipment-comparison-v1` · [English](Equipment_Comparison_Rules.en.md)

이 문서는 인벤토리·창고·상점·획득 보상·훈련을 포함한 **모든 장비 비교 화면의 공통 표시 계약**이다. 새 콘텐츠는 별도 비교 계산이나 툴팁을 만들지 않고 `ItemComparison.Preview`, `ItemTooltip`, `EquipmentComparisonView`를 사용한다. 아이템 생성·거래·장착은 기존 서비스가 계속 담당한다.

## 근거와 적용 범위

사용자가 제공한 Diablo IV [무기 비교](ItemComparisonReference/diablo-weapon-comparison.png)와 [신발 비교](ItemComparisonReference/diablo-boots-comparison.png)를 시각·상호작용 근거로 삼는다. 두 이미지에서 착용품은 왼쪽에, 후보는 오른쪽에 놓이며, 후보에 수치 차이와 잃는 속성을 표시한다. 이는 **첨부 화면에서 확인한 표시 방식**의 채택이다. Diablo IV 최신 버전의 전체 규칙이나 수치 체계를 복제한다는 뜻은 아니다.

아이템 위력, 내구도, 직업별 무기 체계 등 다른 게임의 데이터를 추가하지 않는다. HELLSCRIPT의 `ItemCatalog`, `ItemQuality`, `StatCatalog`, `GemCatalog`, `EquipmentSlots`, `HeroStats`를 계산 근거로 사용한다.

## 배치와 상태 표시

| 항목 | 공통 규칙 |
| --- | --- |
| 왼쪽 | `장착 중 · 장착 위치`를 표시한 현재 장비. 본래 수치만 표시한다. |
| 오른쪽 | `선택한 장비` 후보. 원래 수치 뒤에 괄호로 차이를 표시한다. |
| 카드 순서 | 이름 → 등급·부위 → 장비 점수·교체 전후 점수 → 아이템/요구 레벨 → 손 사용 방식 → 기본 수치 → 고정 속성 → 접사 → 고유·세트 설명 → 소켓·성장 기록 → 잃는 속성 → 교체 후 전체 능력치. 보석의 수치 기여는 별도 `보석` 행으로 구분한다. |
| 같은 장비 | 장착 중인 아이템은 자기 자신과 비교하지 않는다. 상세 정보만 표시하며 비교 버튼을 제공하지 않는다. |
| 빈 위치 | 왼쪽에 `장착 장비 없음`을 표시한다. 없는 속성의 기준값은 0이다. |
| 공간 | 창과 카드 바깥 크기는 고정한다. 긴 이름·설명·속성은 카드 내부에서 줄바꿈하고 스크롤한다. 비교 기준 변경으로 창 높이를 바꾸지 않는다. |
| 조작 | 확인·구매·장착 등의 콘텐츠별 행동 버튼은 카드 본문 밖의 고정 영역에 둔다. 비교를 읽거나 기준 위치를 바꾼 것만으로 장착·거래하지 않는다. |

## 수치 차이와 범위

옵션 범위는 **인벤토리 하단의 직업·레벨 옆에 있는 범위 아이콘**으로 켜고 끈다. 켜지면 아이콘을 금색으로 강조한다. 옆의 `?` 버튼을 누르면 `옵션의 최소~최대 범위를 표시합니다.`라는 짧은 도움말이 위쪽으로 열린다. 도움말은 설정을 바꾸지 않으며 바깥을 누르거나 Esc로 닫는다. 기본값은 Off이며 이 기기에 저장한다. 캐릭터와 콘텐츠가 바뀌어도 인벤토리·창고·상점·보상·훈련·대장장이 등 모든 장비 상세와 비교가 같은 설정을 읽는다. 계정 진행 데이터나 아이템 수치는 바꾸지 않는다.

PC에서는 왼쪽 또는 오른쪽 Ctrl을 누르고 있는 동안 범위를 임시 표시한다. 키를 놓거나 게임이 포커스를 잃으면 저장된 선택으로 돌아간다. On을 Off로 반전하는 단축키가 아니며 설정 파일을 쓰지 않는다. 버튼 위에 마우스를 올리면 `컨트롤 키로 일시 활성화`를 표시한다. 터치 입력에는 이 말풍선을 띄우지 않는다. 모바일의 작은 버튼과 PC 단축키는 같은 범위 표시 규칙을 사용한다.

범위가 붙은 본문에 필요한 공간을 처음부터 확보한다. 표시 전환은 글자만 갱신하며 카드 크기·본문 행 위치·스크롤·반지 교체 기준을 초기화하지 않는다. 범위 계산은 `ItemComparison.Affix`와 `ItemComparison.Properties`, 표시 선택은 `ItemRangeDisplay`, 기존 본문의 즉시 갱신은 `ItemRangeText`를 재사용한다.

1. 차이는 **후보 값 − 교체 대상 값**이다. 증가분은 초록색 `(+값)`, 감소분은 붉은색 `(−값)`으로 표시한다. 부호도 함께 표시해 색만으로 구분하지 않는다. 표시 정밀도에서 0인 차이는 생략한다.
2. 퍼센트 속성은 퍼센트 포인트 차이다. 예를 들어 18%에서 30%로 바뀌면 `(+12%)`이며, 상대 증가율 66.7%를 표시하지 않는다. `24.8% → 17.1%`는 `(−7.7%)`다.
3. 같은 속성은 번역된 이름이 아니라 안정된 키로 찾는다. `main`, `implicit`, `affix`, `gem`을 분리하고 접사는 `StatId`, 보석은 효과 종류와 속성 ID를 사용한다. 조건이 다른 피해·저항·감소 효과를 합치지 않는다. 보석 기여를 접사 기준값에 섞지 않는다.
4. 후보에만 있는 속성은 기준값 0과 비교해 전체 값을 증가분으로 표시한다. 양쪽에 있지만 낮아진 속성은 그 행의 감소분으로 표시하며, 사라지는 속성 목록에 중복 기재하지 않는다.
5. 접사 범위 `[최소–최대]`는 해당 아이템의 실제 레벨·각성·상위 옵션·걸작 배율을 반영한다. 상위 옵션처럼 최대값이 고정된 경우 범위 양끝이 같다. 범위가 확인되지 않는 기존 이관 수치는 범위를 생략한다. 강화나 걸작을 앞으로 했을 때의 예상치를 현재 값에 섞지 않는다.
6. 기본 공격 속도는 현재 게임의 배율 단위 `×`로 표시한다. 아이템 기본 수치의 차이는 전체 캐릭터 공격력이나 DPS의 변화와 동일하지 않다.

## 장착 시 사라지는 속성

후보 카드 아래에 **장착 시 사라지는 속성**을 별도 제목으로 표시한다. 교체 장비에만 있는 수치 속성과 실제로 잃는 고유·세트 효과를 붉은색 목록으로 보여 준다. 목록이 없으면 제목도 생략하되 창 크기는 그대로 유지한다.

- 기본/고정 속성·접사·보석 효과가 후보에서 없어지면 기존 값을 표시한다.
- 다른 고유 효과를 같은 수치로 환산하지 않는다. 기존 효과가 남는 다른 장비에 있다면 사라지는 효과로 표시하지 않는다.
- 세트는 아이템 이름이 바뀌었다는 이유만으로 해제로 처리하지 않는다. 교체 후 실제 2/4세트 활성 조건이 해제되는지 `HeroStats`로 확인한다.
- 보석은 기존 장비에 남는다. 비교 표시는 보석을 제거하거나 새 장비에 옮기는 동작이 아니다.

## 반지와 두 무기 위치

반지는 장착된 두 반지를 모두 왼쪽에 표시하고 후보는 오른쪽 끝에 둔다. 한쪽만 장착했다면 빈 반지 카드를 추가하지 않는다. 위쪽의 **왼쪽/오른쪽 반지 교체 기준**을 선택하면 후보의 증감과 전체 능력치가 그 위치를 기준으로 바뀐다. 기준 전환 중 카드 수·크기·창 크기는 고정된다. 비어 있는 위치를 선택하면 다른 반지는 유지한다.

무기 교체 대상은 `EquipmentSlots.Plan`이 정한다. 양손 무기는 기존 두 장비를 함께 교체할 수 있고, 호환되지 않는 보조 장비도 함께 해제될 수 있다. 이때 실제로 교체되는 장비를 강조하고 후보에 함께 교체되는 이름을 표시한다. 같은 양손 아이템을 두 번 계산하지 않는다.

여러 장비가 동시에 교체되면 접사·저항·보석 등 합산 가능한 기여는 합한다. 공격 무기의 기본 수치와 기본 공격 속도는 현재 `HeroStats`의 쌍수 평균 규칙을 따르며, 공격용 보조 장비 기본값은 별도로 더한다. 방패 방어도를 무기 공격력에서 빼지 않는다. 아래 **교체 후 전체 능력치** 영역은 룬·세트·상한을 반영한 실제 캐릭터 값이며, 위의 아이템별 차이와 구분한다.

장착 조건을 만족하지 못하면 조건을 붉은색으로 표시하고 전체 능력치 예측을 생략한다. 창고·상점·훈련 후보는 복사본에서만 장착을 시뮬레이션한다. 인벤토리의 기존 읽음·가이드 진행 기록은 유지하되 비교 계산 자체는 저장 데이터를 수정하지 않는다.

## 구현과 검증 기준

- 계산: `Runtime/Core/ItemComparison.cs`
- 공통 본문·카드: `Runtime/Presentation/EquipmentComparisonView.cs`
- 연결: `InventoryWindow`, `StorageWindow`, `EquipmentShopWindow`, 기존 `GameUI` 장비 상세와 훈련 후보. 획득 연출은 단일 상세를 표시하고 `장착 비교`를 누르면 공통 비교창을 연다.
- 새 비교 화면을 추가할 때 동일 아이템·장착 상태·언어에서 기존 화면과 같은 본문이 나오는지 확인한다.
- 검사는 동일/신규/제거 속성, 단위·0차이·품질 범위, 반지 두 위치, 양손 교체, 조건 미충족, 원본 무변경과 고정 크기를 포함한다.
- 실행 증거와 범위는 [공통 비교 구현 기록](../Implementation/Equipment_Comparison.md)에 남긴다.

## 공통 아이템 카드 양식

모든 장비 상세는 `ItemDetailView`가 그린다. 어두운 바탕에 등급색 모서리 장식과 얇은 이중 테두리를 쓰고, 이름·종류 아래에 장비 점수를 강조한 뒤 레벨과 주요 수치를 표시한다. 기본 속성, 추가 옵션, 특수 효과, 소켓·성장 정보를 구분선으로 나누며 옵션에는 작은 마름모 표식을 붙인다. 특수 효과는 별도 안쪽 패널에 표시한다. 비교에서는 공통 조밀한 표시를 사용한다. 작은 아이콘과 제목을 나란히 두고, 폭 160 미만의 카드에서는 아이콘을 생략하며 주요 수치·차이는 같은 행에 표시한다. 외부 창틀·반복 제목과 교체 위치가 하나뿐인 기준 버튼을 만들지 않는다. 장식은 입력을 가로채지 않는다.

장비 점수는 `EquipmentScore.Value`, 교체 전후 점수는 `ItemComparison.Preview`의 `scoreBefore`·`scoreAfter`를 사용한다. 무기는 양손 구성 전체를 비교한다. 상세·비교·추천 착용에서 별도 점수식을 만들지 않는다. 아직 옵션이 정해지지 않은 도감 범위에는 확정 점수를 표시하지 않는다. 수식과 적용 범위는 [장비 점수와 추천 착용](../Implementation/Recommended_Equipment.md)을 따른다.

- 정보와 계산은 `ItemTooltip` / `ItemComparison`에서 받는다. 주요 수치를 크게 그리기 위해 전달하는 `label` / `value`도 같은 계산 결과다.
- 모바일·PC, 한국어·영어, 확대 글자 모두 같은 양식을 쓴다. 창 크기는 유지하고 내용만 스크롤한다. 범위 On/Off·Ctrl은 기존 위치와 스크롤을 유지한다.
- 인벤토리·분해 확인·창고·상점·획득 보상·대장간·보석 장착·위상 각인·훈련·장비 도감은 같은 표시 부품을 사용한다. 콘텐츠별 거래·편집·스냅샷 소유권은 바꾸지 않는다.
- 참고: [Diablo II 기본 아이템 정보](https://classic.battle.net/diablo2exp/items/basics.shtml)의 등급·요구 조건 구조, [Diablo III 전설·고대 안내](https://news.blizzard.com/en-gb/article/22989464/legendary-an-ancient-primal-guide)의 등급색 테두리 설명, 위에 링크한 사용자 제공 Diablo IV 비교 화면의 정보 위계를 참고했다. 게임의 그림을 복제하지 않고 벡터 장식과 HELLSCRIPT 장비 그림으로 구성했다.

## 드래그 장착 안내와 필터

인벤토리에서 장비를 끄는 동안 실제로 장착할 수 있는 캐릭터 슬롯의 테두리를 금색으로 밝힌다. 해당 칸 위에서는 선을 더 굵게 표시한다. `EquipmentSlots.PlanDrop`은 실행과 같은 소유권·레벨·직업·무기 조합·소지품 여유 검사를 사용한다. 반지는 두 위치를 각각 검사하며, 양손 무기는 두 칸을 안내하고 어느 칸에 내려놓아도 하나의 아이템을 주무기에 기록한다. 드래그 종료·취소·Esc·포커스 해제·창 닫기·화면 재배치 때 강조를 지운다. 표시만으로 장착·저장하거나 슬롯 크기를 바꾸지 않는다.

현재 등급은 일반·마법·희귀·전설·세트다. 데이터의 `UniqueItemDefinition`은 전설의 특수 효과 정의이며 별도 고유 등급이 아니다. 자동 선택 설정의 비활성 고유 항목을 제거하되 저장된 등급 마스크의 비트 4는 예약 상태로 남긴다. 세트는 계속 비트 5를 사용한다. 가방 하단의 별도 자동 선택 설정 버튼은 없애고 일괄 분해 내부의 진입점은 유지한다.

## 단일 상세의 장비 점수 비교 (2026-10-02)

비교 버튼을 누르지 않아도 실제 장비의 모든 상세에서 `장비 점수 착용값 → 후보값`을 표시한다. 같은 위치가 비어 있으면 기준은 0, 후보가 높으면 초록색, 낮으면 빨간색, 같으면 중립색이다. 현재 착용한 아이템 자체의 상세는 자기 비교 없이 점수만 표시한다.

`ItemTooltip.Score`가 `EquipmentScore.Value`와 `EquipmentSlots.ComparisonTarget`을 재사용한다. 반지·쌍수의 기본 기준은 기존 비교창과 같은 첫 착용 위치이며, 비교창에서 위치를 바꾸면 선택한 위치를 따른다. 무기의 이 행은 해당 위치의 개별 아이템 점수를 비교하고, 기존 `무기 구성 점수` 행은 실제 양손 구성을 별도로 비교한다. 장착 조건을 만족하지 못해도 개별 점수 비교는 표시한다.

콘텐츠 제어 코드가 `ItemDetailView.Create`/`Append`에 `hero`를 전달한다. 공통 표시 부품은 아이템과 비교 캐릭터를 복사하고 계정 저장에 접근하지 않는다. 훈련·전투 상세는 명시된 편집본·스냅샷을, 획득·변경 이력은 원래 캐릭터의 현재 착용 상태를 비교 기준으로 전달한다. 실제 수치가 정해지지 않은 도감 범위에는 점수를 만들지 않는다.

## 2026-10-04 Diablo IV 기준 카드 재구성

사용자 제공 Diablo IV 화면의 정보 위계를 가로·세로 화면에 맞게 다시 옮겼다. 계산·거래·저장 소유권은 바꾸지 않고 `ItemDetailView`, `ItemDetailPopup`, `EquipmentComparisonView`의 표시만 바꾼다.

- **주요 수치 한 줄**: `1,435 초당 공격력 (+236)`처럼 큰 값, 이름, 차이를 같은 줄에 둔다. 폭이 모자라면 이름을 아래 줄로 내리며 값을 줄여서라도 한 줄에 둔다.
- **고정 속성 가지선**: 기본 공격 속도·고정 저항 같은 고정 속성은 주요 수치 아래 `├`/`└` 벡터 가지선으로 연결한다.
- **상위 옵션 강조**: 상위 접사는 밝은 금색 글자와 큰 마름모 표식으로 일반 접사와 구분한다. 기존 `◆` 글자는 유지한다.
- **소켓 줄**: 소켓이 있는 장비는 빈 고리 또는 보석이 채워진 고리 표식과 함께 소켓 정보를 표시한다.
- **하단 요구 조건**: 넓은 카드에서 `아이템 레벨 · 요구 Lv.`, 손 사용 방식, 재질, 장착 중·잠금 상태는 하단 오른쪽 정렬로 모은다. 조밀 카드(폭 300 미만)는 기존처럼 제목 아래에 둔다.
- **두 열 카드(가로)**: 폭 520 이상이고 접사·특수 효과·잃는 속성·교체 후 능력치가 있으면 왼쪽(제목·주요 수치·소켓·요구 조건)과 오른쪽(접사·특수 효과·비교)으로 나눠 한 화면에 보이게 한다. 세로·좁은 카드는 한 열이다.
- **아래로 스크롤 안내**: 카드가 창보다 길고 끝에 닿기 전까지 하단에 `아래로 스크롤`을 표시한다. 입력은 가로채지 않는다.
- **가로 상세 창**: 인벤토리 상세는 가로에서 최대 640 폭으로 넓히고, 하단 행동 버튼은 폭 480 이상이면 한 줄에 최대 4개를 놓아 카드 높이를 지킨다.
- **세로 비교(폭 460 미만)**: 카드 두 장을 200 폭으로 줄이지 않고 `선택한 장비 / 장착 중 · 위치` 탭으로 한 번에 한 장을 전체 폭으로 보여 준다. 기본은 선택한 장비다. 반지 교체 기준 탭은 그대로 위에 있고, 탭 전환은 저장 데이터를 바꾸지 않는다. 가로(폭 460 이상)는 장착 중이 왼쪽, 선택한 장비가 오른쪽인 기존 나란히 비교를 유지한다.
- **가로 기본 비교**: 가로에서 소지품의 미장착 아이템을 누르면, 같은 부위에 장착한 장비가 있을 때 상세 창이 곧바로 `장착 중`(왼쪽)과 `선택한 장비`(오른쪽) 나란히 비교로 열린다. 창은 전체 폭이고 장착·잠금·장착 비교·닫기 버튼은 그대로다(`장착 비교`는 반지 위치별 장착 버튼이 있는 전용 창을 연다). 장착 중이거나 같은 부위에 장착한 장비가 없거나 세로 화면이면 단일 상세다.

## 2026-10-05 장식 아트와 연출

사용자의 "UI 디자인도 미감을 최대한 발휘해 더 쥬시하게" 요청에 따라 카드의 장식과 연출을 한 번 더 키웠다. 표시만 바꾸며 계산·거래·저장 소유권은 그대로다. 아트는 [아이템 상세 카드 장식 아트](../Art/ItemCard/Item_Card_Art.md)의 Codex 이미지를 `ItemCardArt`가 불러 쓴다.

- **등급 색 틀**: 넓은 카드(폭 300 이상)는 모서리 장식 네 개(한 장을 뒤집어 사용)와 위쪽 등급 색 줄을 둔다. 조밀 카드는 벡터 모서리를 유지한다.
- **점수 명판**: 장비 점수(`equipment-score`)는 글자 길이에 맞게 늘어나는 명판 위에 놓인다. 점수가 오르면 초록 ▲, 내리면 빨강 ▼를 옆에 붙인다. 글자 텍스트와 이름은 그대로라 기존 검사가 같은 값을 읽는다.
- **큰 구분선**: 머리 아래와 `추가 옵션`·`특수 효과` 앞은 장식 구분선, 나머지는 얇은 벡터 선이다. 가로 비교처럼 높이가 420 미만인 카드는 높이를 아끼려고 벡터 선과 낮은 명판(52)을 쓰고, 300 미만이면 후광과 명판 없이 점수를 글자로 보여 준다.
- **등급 후광**: 장비 그림 뒤에 등급 색 후광을 깔고 그림 틀 테두리를 등급 색으로 칠한다. 전설·세트는 후광이 더 밝다.
- **상위 옵션 별**: 상위 접사 앞의 마름모를 불꽃이 오르는 별로 바꾸고 글자는 밝은 금색이다.
- **소켓 고리**: 빈 소켓은 회색 고리, 보석이 있으면 금색 고리 안에 보석 그림을 넣는다.
- **비교 강조**: 수치가 오르거나 내린 옵션 줄에는 연한 초록·빨강 바탕을 깔고, 주요 수치 차이에는 삼각형 화살표를 붙여 색만으로 구분하지 않는다.
- **특수 효과 틀**: 특수 효과 안쪽 패널의 테두리는 등급 색이다.
- **스크롤 안내**: `아래로 스크롤` 글자 위에 아래 화살표를 두고 아래쪽에 불투명한 띠를 깔아 뒤의 글줄이 비치지 않는다.
- **등장 연출**: 카드는 0.2초 동안 투명에서 나타나며 96.5%에서 100%로 자리를 잡고, 전설·세트 머리에는 기울어진 빛줄기가 한 번 지나간다. 연출이 끝나면 컴포넌트가 스스로 사라져 이후 프레임 비용이 없다. 네이티브 스모크는 안정된 화면을 찍으려고 기본적으로 끄며, `-hellscriptUiMotion`으로 느린 프레임을 확인한다.
- **상세 창 제목 장식**: 아이템 상세 창의 제목 줄 가운데에 장식 구분선을 놓는다.
