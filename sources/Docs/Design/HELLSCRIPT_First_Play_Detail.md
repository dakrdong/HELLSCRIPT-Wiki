# HELLSCRIPT 첫 플레이 안내 상세안

작성일: 2026-09-09 · D4 / CHK-G04 개발 시험안

## 목적과 범위

실제 캐릭터로 균열을 경험하고 행동 이유·장비·설정을 확인한 뒤 훈련과 재도전으로 이어지도록 안내한다. 15분은 사용성 관찰 목표다. 안내를 끝내려고 전투 시간을 줄이거나 레벨·아이템·재화를 지급하지 않는다. 자동 검사와 UI 동작 검증은 사용자의 이해도·첫 15분 사용성 검사를 대신하지 않는다.

성소에는 다음 안내와 진행 수를 표시하고, 게임 안내에서 전체 단계를 다시 열 수 있다. 단계는 순서대로 권하지만 기능 진입 조건으로 쓰지 않는다. 안내 숨기기는 화면의 추천 표시만 끄며 완료를 위조하지 않는다. 다시 표시해도 기존 기록은 유지한다.

## 단계와 기록 경계

| 단계 | 안내 내용 | 기록 조건 |
|---|---|---|
| 자동 전투 이해 | 이동·공격·수집이 자동이며 행동 설계에서 우선순위와 조건을 바꾼다. 배속은 전투와 제한시간에 함께 적용된다. | 설명을 읽고 확인 버튼을 누른다. 이 기록은 계정 공통이다. |
| 현재 직업과 빌드 | 직업당 두 빌드의 목적, 완성 요구 레벨, 현재 해금 스킬과 기본 무기를 확인한다. | 현재 직업의 성장 화면을 연다. 다른 직업으로 바꾸면 별도로 안내한다. |
| 첫 균열 | 현재 캐릭터로 입장하고 처치 게이지와 제한시간을 본다. | 실제 균열에 입장하거나 저장된 실제 균열을 이어 받는다. 훈련은 해당하지 않는다. |
| 행동 이유 | 첫 스킬 사용 후 현재 행동을 눌러 판단 기록을 열 수 있다고 한 번 안내한다. 선택된 규칙으로 바로 이동한다. | 실제 균열에서 선택된 행동이 있는 판단 기록을 연다. 빈 기록과 개발용 훈련은 해당하지 않는다. |
| 첫 결과 | 성공·실패와 무관하게 획득한 XP·장비는 유지되며 미개봉 상자는 지급하지 않는다고 설명한다. | 실제 종료한 균열 결과를 연다. 성소로 바로 중도 귀환한 사실을 결과 열람으로 바꾸지 않는다. |
| 장비 비교 | 소유 후보와 현재 장비를 비교한다. 후보가 없으면 현재 기본 무기와 비교할 항목을 설명한다. | 실제 소유 후보의 비교 화면을 열거나, 후보가 없을 때 비교 설명을 읽고 확인한다. 두 경우를 별도로 표시한다. 장착은 요구하지 않는다. |
| 행동 한 가지 수정 | 바뀐 목표·이동·거리·물약 조건·규칙을 자연어로 확인한다. 변경안은 설정 적용 전까지 저장하지 않는다. | 실제 적용에 성공한 전투 행동 차이를 기록한다. 이름·버전·규칙 ID·장비 참조만 바꾸거나 취소한 경우는 제외한다. 훈련 복사본의 변경만으로 실제 설정 변경을 완료하지 않는다. |
| 수정한 설정 훈련 | 실제 캐릭터 복사본으로 60초 또는 사망까지 시험하고 판단과 결과를 읽는다. | 소유 캐릭터 훈련의 종료 결과를 열고, 그 설정이 기록한 수정안과 같으며 실제 전투 판단이 있어야 한다. 개발용 훈련·즉시 귀환은 제외한다. A/B 비교는 별도 후속 기능이다. |
| 다시 도전 | 다음 판의 반복·단계 상승·실패 중단·가방 처리 정책을 확인한다. | 결과 열람·실제 설정 수정·해당 설정 훈련 이후, 같은 수정 설정으로 새 실제 균열에 입장한다. 이어하기와 같은 판은 제외한다. |

계정 공통 설명 외에는 영웅별로 저장한다. 기존 저장에 없는 안내 기록은 미완료로 초기화하며 레벨이나 최고 단계를 보고 완료를 추측하지 않는다. 안내 표시를 숨겨도 실제로 수행한 단계는 기록할 수 있다. 기록은 보상·경제 거래·실클리어 자격과 연결하지 않는다.

## 화면 이동과 예외

안내와 판단 기록을 읽는 동안 전투를 멈추고 돌아갈 때 이전 일시정지 상태를 복원한다. 안내에서 편집기로 이동할 때도 이 상태를 전달한다. 장비·훈련·새 균열은 진행 중인 균열을 임의로 포기하지 않으며, 필요하면 현재 균열 완료 후 이용하도록 설명한다.

첫 스킬 안내는 현재 직업의 실제 스킬 발동 사건이 있을 때만 표시한다. 이미 열린 성장 알림을 덮어쓰지 않고 표시할 수 있을 때 기다린다. 판단 기록에서는 선택된 규칙이 현재 설정에도 남아 있을 때 해당 규칙을 연다. 삭제된 규칙의 행 번호로 다른 규칙을 대신 열지 않는다.

결과에서 안내·장비·판단을 읽는 동안 자동 반복 대기시간은 진행하지 않는다. 반복을 켰더라도 결과 화면에서 멈출 수 있다. 안내를 읽었다는 이유로 자동 반복을 켜거나 저장 설정을 교체하지 않는다.

## 검증

계정/영웅 구분, 숨김/재열람, 구형 저장, 반복 호출, 빈 판단, 훈련/실제 균열 구분, 적용 취소와 메타데이터 변경, 설정 불일치 훈련, 이어하기와 새 판을 검사한다. 새 계정의 실제 생성 균열 결과까지 실행한 뒤 소유 장비 또는 무보상 비교 설명, 직접 설정 수정, 60초 훈련, 새 균열 입장과 앱 재시작을 연결한다. 화면 내용·버튼 경계·스크롤과 알림을 실제 앱에서 확인한다.
