# 코드 조사 기록 (구현 전 읽기 전용 조사)

작성일: 2026-10-12 · [English](README.en.md)

Codex가 구현하기 전에, 지금 코드가 계획의 각 부분과 어떻게 만나는지 조사한 기록이다. 코드는 바꾸지 않았고 읽기만 했다. 기준은 `main` `a3fe67c5`(이 브랜치의 기반)이다. **줄 번호는 그 시점 기준**이라 코드가 바뀌면 조금씩 어긋난다. 함수·클래스 이름으로 다시 찾는다.

| 파일 | 내용 | 쓰이는 곳 |
|---|---|---|
| `ui_infrastructure.md` | 그리기 도구(`UiMesh` 등)의 기능과 격차, 어댑터 창 단위, 스크롤·입력, 글자, 애니메이션, 스모크 틀, EditMode UI 시험, 아이콘·마스크, 파일 규칙, 위험 | UI 명세 |
| `combat_warrior.md` `combat_ranger.md` `combat_mage.md` | 직업별 전투 구현 지점. 스킬마다 A(수치만) · B(기존 경로에 새 동작) · C(새 장치) 분류, 패시브·핵심 패시브, 시험 틀, 풀리지 않은 질문 | 전투 명세 |
| `save_migration.md` | 저장 구조, 이전(마이그레이션) 순서와 알고리즘, 만렙 40 → 60 영향, 시험 틀 | 계획 7장, 2단계 작업서 |
| `dependents.md` | 옛 스킬창과 그에 기대는 곳(빠른 편집, 튜토리얼, 칙령, 도구, 문구, 스모크, 시험)과 잊기 쉬운 15곳 | 계획 12장, 6·7단계 작업서 |

각 파일 끝의 **풀리지 않은 질문**은 코드만으로 정할 수 없던 것이다. 중요한 것은 계획 17장의 결정 목록(D1~)과 전투 명세 부록에 모았다.

영어로 남긴 이유: 코드 식별자와 `파일:줄` 인용이 대부분이라 번역하면 오히려 찾기 어렵다. 결과물(계획·명세·작업서)은 한국어와 영어를 함께 둔다.
