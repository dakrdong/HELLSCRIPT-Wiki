# 스킬창 캐주얼 스킨 시안

작성일: 2026-10-14 · [English](README.en.md)

게임의 아트 컨셉이 어두운 고딕("Obsidian & Gilt")에서 밝고 아기자기한 캐주얼 중세 판타지(스타일 D, 12세 이상)로 바뀌었다([컨셉 기록](../../../Art/CasualConcept/2026-10-13/Casual_Art_Concept_20261013.md)). 이 폴더는 **스킬창(`../SkillWindow.dc.html`)을 같은 구성 그대로 새 컨셉으로 입힌 시안**이다. 규칙·배치·문구·상호작용은 그대로고 색, 글꼴, 테두리, 그림자, 장식만 바뀐다.

- 디자인 캔버스(사용자 확인 완료): https://claude.ai/artifact/JsCKnJUbKkzfBYyJDR3493 (24장, 직업 3 × 세로·가로·PC × 한/영 + 패시브 화면)
- 원본(어두운 시안)은 `../SkillWindow.dc.html`이며 커밋 `86cfeff1`과 같다.

## 파일

| 파일 | 내용 |
|---|---|
| `SkillWindow.casual.locked.dc.html` | **게임에 옮길 기준.** 캔버스 시안에서 배치에 영향을 주는 글자 크기·순위 배지 크기를 원본으로 되돌려, 모든 사각형과 글자 크기가 원본과 같다. 시안이 이 파일이면 `golden/layout`·`viewmodel`·`interaction`·`rules_golden`은 다시 만들어도 바뀌지 않아야 한다. |
| `SkillWindow.casual.dc.html` | 사용자가 캔버스에서 확인한 그대로의 시안. 제목·탭·패널 이름·구역 제목·단추·배지 글자가 원본보다 조금 크다(아래 표). 게임에 반영할지는 사용자가 따로 정한다. |
| `tools/restyle.py` | 원본 → 캐주얼 변환(모든 치환의 횟수를 검사한다). 원본이 바뀌면 이 스크립트가 실패해서 알려 준다. |
| `tools/lock_geometry.py` | 캐주얼 → 잠금판 변환(글자 크기 되돌리기). |
| `tools/geo_compare.js` | 두 시안을 36가지 조합(직업 3 × 배치 3 × 보기 2 × 언어 2)으로 돌려 사각형·글자 크기 차이를 나열한다. `node tools/geo_compare.js <원본> <잠금판>`이 글자 크기 차이 0이어야 한다. |

## 보이는 변화

- 바탕: 하늘색에서 크림색으로 이어지는 그라데이션과 구름. 판은 크림색(`#fff6e3`), 남색(`#2a3150`) 3px 외곽선과 아래쪽 단단한 그림자(`0 5px 0`), 안쪽에 점선 바느질 테두리, 위쪽에 둥근 젬. 번진 아트 배경(`artWrap`)은 얼룩처럼 보여 없앴다.
- 글자: 제목·탭·숫자·단추·소제목은 Jua, 본문은 Noto Sans KR 700/900. 제목은 노란 글자에 남색 8방향 외곽선.
- 색 역할: 투자한 것·선택·핵심 패시브 `#ffd23f / #ffc21a / #ff9f1c`(글자 `#e08a00`), 패시브·정보 `#35a7ff / #2f8fd8 / #1f6fb5`, 투자 가능 `#8a93b5`, 잠김 `#e6e9f0` 점선, 경고 `#ff5a5f`, 투자 단추 초록 `#8ee07a → #4cbf55`, 닫기 단추 코랄.
- 선: 3px, 켜진 선 밑에 7px 남색 밑줄. 잠긴 선은 연한 회색 점선.
- 스킬 아이콘(스프라이트)은 기존 그림 그대로다.

## 캔버스 시안과 잠금판의 차이(배치에 영향이 있는 부분)

| 요소 | 캔버스 시안 | 잠금판(=원본 크기) |
|---|---|---|
| 창 제목(가로 / 세로 / PC) | 28 / 31 / 30 | 24 / 27 / 26 |
| 직업 탭 글자(가로·PC / 세로) | 15 / 16 | 13 / 14 |
| 버튼(회수·투자) 글자 | 16 | 13 |
| 패널 이름(가로·PC / 세로) | 18 / 22 | 16 / 19 |
| 패널 소제목(가로·PC / 세로) | 14 / 16 | 12.5 / 14.5 |
| 티어 배지 번호(앞 3개 / 나머지) | 14 / 12 | 13 / 11 |
| 티어 배지 이름(가로 / 세로) | 13 / 14 | 12 / 13 |
| 레벨·사용 포인트 값 | 15 | 주변 글자 크기 |
| 순위 배지 원 | 18×18 | 16×16 |

잠금판에서도 안쪽 치수는 조금 다르다(패시브 메달 고리 안쪽 여백, 순위 배지 줄 높이, 패널 보조 스킬 우측 칩 여백). 모두 요소 사각형이 아니라 요소 안쪽 그림이다.

## 다시 만들기

```bash
python3 -I tools/restyle.py <원본 SkillWindow.dc.html> SkillWindow.casual.dc.html
python3 -I tools/lock_geometry.py SkillWindow.casual.dc.html SkillWindow.casual.locked.dc.html
node tools/geo_compare.js <원본> SkillWindow.casual.locked.dc.html   # 글자 크기 차이 0
```
