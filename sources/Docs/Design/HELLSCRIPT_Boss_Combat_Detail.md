# 보스 5종 전투 상세 시험안

작성일: 2026-09-28 · [English](HELLSCRIPT_Boss_Combat_Detail.en.md) · 최초 작성 2026-09-09(D3 구현 기준), 2026-09-28 보스 5종·2페이즈 패턴 반영

[콘텐츠 카탈로그 13장](HELLSCRIPT_Content_Catalog.md#13-보스-5종), [상위 기획서 16.4](HELLSCRIPT_Unity_Implementation_Plan.md), [완료 기준 4.3](HELLSCRIPT_Gameplay_Completion_Checklist.md#43-정예-6종과-보스-3종)의 기존 수치와 HP 전환·중단 규칙을 실행 단위로 구체화한다. 누락된 준비 시간·범위·우선순위·배치 수치는 아래 시험안을 사용한다. 밸런스 확정값은 아니다.

## 공통 행동과 단계 전환

보스마다 패턴 6개를 가진다. 1–3번은 1페이즈 패턴, 4–6번은 2페이즈 패턴이다. 기본 공격과 여섯 패턴의 CD를 칸마다 따로 저장하고 준비 시작부터 계산한다. 최초 등장 대기는 기존 생성기의 1–2초를 각 CD에 적용한다. 준비·돌진·광선 유지·연속 폭발 실행 중에는 다른 주 행동을 시작하지 않는다. 1페이즈에서는 1–3번 패턴을 돌아가며 고르고, 사거리·시야·사선·공간이 부족하거나 CD 중인 후보는 건너뛴다. 쓸 수 있는 패턴이 없으면 기본 공격을 쓴다. 선택은 저장된 순번으로만 정하며 전투 난수를 쓰지 않는다. 인지는 14m·벽 판정, 시야를 잃은 뒤 추적 기억은 4초다.

HP가 한 번이라도 50% 이하가 되면 전환을 예약하고, 다음 행동을 고를 때 2페이즈로 전환한다. 예약 이후 회복해도 취소하지 않고 1페이즈로 돌아가지 않는다. 진행 중인 행동의 횟수·형상을 바꾸지 않는다. 전환 순간 보스는 포효한다. 포효는 1.5초 준비 동안 보스 주변 반경 4m를 예고한 뒤 D80% 암흑 충격파를 한 번 준다. 포효를 알린 다음 틱부터 발동할 때까지 보스는 피해를 받지 않고 무력화 수치도 쌓이지 않는다. 포효를 알린 틱에 이미 처리 중이던 피해는 그대로 적용한다. 포효가 끝나면 2페이즈 패턴의 첫 CD가 1초·3초·5초로 차례대로 열린다. 2페이즈에서는 4–6번 패턴을 먼저 고르고, 쓸 수 없으면 1–3번 패턴, 그다음 기본 공격을 고른다.

저장 형식은 CD 7칸과 순번이다. 이전 저장의 CD 3칸은 값을 보존한 채 7칸으로 늘리고, 새 칸은 기존 값 중 가장 큰 값으로 채운다. 전투 행동 버전은 6이다. 준비 시작에 추가타 여부·고정 방향·목표·폭발 배치를 저장한다. 피해량은 실제 발사·돌진 시작·효과 생성 때 확정한다.

무력화는 진행 중 행동을 중단하고 남은 CD를 보존한다. CD는 무력화 중에도 흐른다. 중단 시 이미 발사된 갈고리와 생성된 광선·후속 폭발은 남은 수명을 유지한다. 아직 준비만 한 공격과 추가타는 취소한다. 기존 제압 100→3초 무력화→10초 면역을 유지한다. 동일 틱 사망·승패는 기존 통합 정산을 따른다.

보스 공격의 바닥 예고도 일반 적과 같은 게이지 방식이다. 범위를 옅게 보여 준 뒤 준비 시간에 맞춰 안쪽부터 채우고, 가득 차는 틱에 피해가 적용되며 그 순간 범위가 한 번 밝게 번쩍인다. 보스 예고는 일반 적보다 밝고 굵다. 무덤 종소리·삼중 분출·연속 폭발처럼 발동 뒤 차례로 떨어지는 원은 보스가 예고를 시작한 때부터 각 원이 떨어질 때까지를 하나의 게이지로 계산하므로, 발동 순간에 처음부터 다시 차지 않는다. 탐식의 끌어당김처럼 도중에 끌어당긴 뒤 물기가 떨어지는 공격도 물기까지 게이지가 끊기지 않는다. 내려찍기 추가타·두 번째 돌진처럼 앞선 타격이 끝난 뒤 새로 예고하는 공격은 게이지를 새로 시작한다.

보스는 서 있지 않는다. 보스마다 1페이즈와 2페이즈에 이동하는 패턴을 하나 이상 가진다(보스 5종 합계 12종). 돌진·미끄러지기·땅속 잠행은 정해진 속도로 길을 따라가고, 도약과 순간이동은 정해진 시간이 걸린다. 경로와 착지 지점은 준비를 시작할 때 벽과 장애물을 피해 정해 두고 저장하며, 보스는 발동 다음 틱부터 움직인다. 예고는 착지할 곳마다 그곳에 떨어지는 순간 가득 차고, 몸으로 치는 돌진은 달릴 길을 함께 보여 준다. 이동 중에도 보스를 공격할 수 있고, 무력화되면 그 자리에서 멈춘다. 쓸 수 있는 패턴이 없어 기다리는 동안에는 영웅 주위를 원을 그리며 돈다(기존 속도의 55%). 3초마다 도는 방향을 바꾸며, 같은 시드는 같은 방향으로 돈다. 저장 형식은 전투 행동 버전 7이며 이동 중인 구간과 경과 시간을 저장한다.

기본 근접은 사거리 3m·전방 120도·0.6초 준비·D100%·CD 2초다. 보스 공통 능력치는 바꾸지 않는다. 종류별 HP·공격 배수와 이동 방식은 보스별 설정표에 둔다. 합창자는 영웅과 8m 안이면 위치를 유지하며, 밖으로 나갔을 때 기존 보스 속도의 35%로 접근한다. 여사제는 7m 안이면 위치를 유지하고 기존 속도의 50%로 접근한다. 다른 보스는 기존 속도로 접근한다.

등장 단계는 집행자 1단계, 합창자 11단계, 포식자 21단계, 폭군 31단계, 여사제 41단계부터다. 해금 단계는 ContentUnlocks.json에서 바꿀 수 있다. 보스 수가 3일 때 보스 선택 결과는 이전과 같다. 선택은 여전히 난수 한 번만 쓴다.

## 묘지의 집행자

- 내려찍기는 사거리와 부채 반경 4m, 전방 120도, 준비 1.2초, D200%, CD 6초다. 준비 시작 위치·방향을 고정한다.
- 후반 단계에서 시작한 내려찍기는 같은 위치·방향에 0.7초 재예고한 뒤 D200% 추가타를 한 번 준다. 같은 원 공격 ID를 유지하되 각 타격은 별도 피해 사건이다. 두 번째 준비 중 제압되면 추가타를 취소한다.
- 갈고리는 CD 9초·1초 준비·거리 10m·폭 1m·속도 12m/s·D100% 물리 투사체다. 발사자 사망 후에도 이동한다. 실제 투사체와 예고는 같은 벽 끝점을 사용한다.
- 명중하면 영웅을 저장된 발사 위치 쪽으로 최대 2m 끌어당긴다. 보행 벽과 살아 있는 몸체 앞에서 멈춘다. 끌림이 일어나면 영웅의 진행 중 행동을 중단하고 기존 비용·CD는 돌려주지 않는다. 이동기 도중 현재 위치가 유효한 보행·착지 지형이 아니면 피해만 적용하고 끌림은 생략한다. 끌림으로 벽 안에 착지시키지 않는다.

- 거두기 베기(1페이즈): 사거리 7m, 준비 1초, CD 8초다. 영웅을 지나 1.5m 앞까지 최대 7m를 초속 14m로 돌진하며, 몸에 닿은 영웅에게 D80%를 한 번 준다. 멈춘 자리에서 전방 220도·반경 3.5m를 베어 D120%를 준다.
- 처형 도약(2페이즈): 사거리 9m, 준비 1.2초, CD 10초다. 영웅 앞 1.2m의 비어 있는 착지 지점으로 0.55초 동안 포물선을 그리며 날아가, 착지 순간 반경 3m에 D160%를 준다. 착지할 수 없으면 쓰지 않는다.
- 사슬 회오리(2페이즈): 사거리 6m, 준비 1초, CD 11초다. 영웅 쪽으로 최대 7.5m의 길을 예고한 뒤, 회전하며 초속 3m로 그 길을 따라 나아간다. 반경 3.2m 회오리가 보스를 따라다니며 0.5초마다 D50%를 준다.
- 무덤 종소리(2페이즈): 사거리 9m, 준비 1.2초, CD 12초다. 조준선 2.5·5·7.5m 지점으로 0.4초씩 세 번 뛰어오르고, 착지할 때마다 그 자리 반경 2m에 D100% 암흑 피해를 준다. 벽이나 착지할 수 없는 곳 앞에서 행진을 멈춘다.

## 종말의 합창자

- 부하 소환은 CD 14초·준비 0.8초·영웅 인지 거리 12m다. 자기 소유의 살아 있는 부하가 최대 8명이 되도록 한 번에 최대 4명을 소환한다.
- 보스 주변 3m·4.5m·6m 고리의 정해진 후보를 순서대로 검사한다. 보행·착지·도달 가능·보스까지 시야와 기존 몸체 간격을 확인한다. 준비 시작에 후보를 고정하고 실행 때 다시 검사하며 무효 지점을 다른 곳으로 몰래 옮기지 않는다. 소환할 자리가 하나도 없으면 준비하지 않고 1초 뒤 후보를 다시 검토한다.
- 부하는 N01의 기본 행동을 사용하며 소환자 ID를 저장한다. 경험치·처치 게이지·골드·아이템·일반 사체를 주지 않는다. 처치 수와 전투 로그에는 남긴다. 자기 부하가 하나라도 살아 있으면 보스의 받는 피해를 20% 줄이며 다른 사건의 소환 적과 구분한다.
- 집중 광선은 CD 8초·준비 1.5초·폭 1.5m·거리 12m다. 준비 시작 방향을 고정하고 벽까지의 끝점을 저장한다. 생성 후 2초 동안 0.25초마다 D37.5% 암흑 피해를 8번 준다. 최초 피해는 활성화 0.25초 뒤다. 영웅 중심점이 광선 폭 안에 있어야 한다. 광선 생성 후 보스는 유지 동작을 하며, 제압·사망해도 이미 생성된 광선의 판정은 통합 전투 종료 전까지 유지된다.

- 만가의 고리(1페이즈): 사거리 9m, 준비 1.2초, CD 9초다. 영웅에게서 3.2m 떨어진 빈 자리로 0.35초 만에 순간이동하고, 나타난 자리를 중심으로 안쪽 2m·바깥 4.5m 고리에 D120% 암흑 피해를 준다. 보스에게 바짝 붙거나 고리 밖으로 벗어나면 피할 수 있다.
- 진혼 합창(2페이즈): 사거리 12m, 준비 1.6초, CD 12초다. -30·0·+30도 방향 폭 1m, 2–12m 광선 3줄을 1.5초 동안 유지하며 0.25초마다 D30%를 준다. 보스는 그동안 자리를 지킨다.
- 침묵의 찬가(2페이즈): 보스 주변 반경 5m, 준비 1.6초, CD 14초, D160%다. 보스에게서 3.2m 떨어진 반경 1m 피할 지점을 최대 2곳 보여 주며, 그 안에서는 피해를 받지 않는다.
- 비탄의 구체(2페이즈): 사거리 10m, 준비 1.2초, CD 9초다. 영웅 옆 5.5m 지점으로 0.3초 만에 순간이동한 뒤 그 자리에서 전방위로 구체 6발(속도 8m/s, 거리 10m, 반경 0.35m)을 쏜다. 한 번에 최대 1발만 적중한다.

## 균열의 포식자

- 돌진은 CD 7초·준비 1초·속도 10m/s·거리 최대 8m·폭 1m·D150%다. 이동 선분과 영웅 반경으로 한 돌진당 한 번 검사한다. 보스 몸체의 보행 반경 1.2m로 벽 앞에서 멈춘다.
- 후반 단계에서 시작한 돌진은 두 번 이동한다. 첫 돌진 종료 때 마지막 관측 위치로 다시 조준하고 0.8초 예고한다. 첫 돌진 중 HP가 50% 이하가 되더라도 두 번째 돌진을 끼워 넣지 않는다.
- 연속 폭발은 CD 12초·준비 1.3초다. 현재 영웅 위치와 그 양쪽 3.5m의 세 지점을 후보로 삼고, 지형에 맞는 방향을 탐색한다. 세 원을 처음부터 예고하며 각각 시작 후 1.3·1.65·2.0초에 반경 2.5m·D150% 암흑 피해를 한 번씩 준다. 준비가 끝나면 세 효과를 독립 생성하므로 이후 제압으로 남은 폭발을 지우지 않는다.
- 반경 0.65m 피난 지점 두 곳은 서로 1.5m 이상 떨어져 있고 모든 폭발 원에서 벗어나야 한다. 영웅의 실제 보행 속도·현재 감속과 0.2초 판단 간격을 고려해 첫 폭발까지 도달 가능한 경로를 검사한다. 벽·착지 불가·몸체 겹침과 예고 시작 때 이미 알려진 위험도 검사한다. 후보 탐색은 유한하며 유효한 배치가 없으면 CD를 소비하지 않고 1초 뒤 재검토한다.
- 피난 지점은 이 연속 폭발에 대한 안전 영역이다. 예고 이후 다른 적이 새로 만드는 공격까지 무효화하는 보호 구역은 아니며, 영웅이 규칙에 따라 계속 공격하기로 선택하면 자동 이동시키지 않는다. 준비 중에는 피난 지점을 별도 윤곽으로 보여 준다. 저장된 배치·경로·폭발 순서를 재시작 때 다시 추첨하지 않는다.

- 아가리 물기(1페이즈): 사거리 7m, 준비 0.7초, CD 7초다. 영웅 앞 1.4m까지 최대 4m를 초속 16m로 달려든 뒤, 전방 70도·반경 4m를 물어 D140%를 준다.
- 균열 찢기(2페이즈): 사거리 12m, 준비 1.2초, CD 11초다. 최대 12m를 초속 18m로 가로질러 달리고, 지나간 길(폭 1.6m)에 3초 동안 균열을 남겨 0.5초마다 D35% 암흑 피해를 준다.
- 파편 폭풍(2페이즈): 준비 1초, CD 10초다. 전방위로 파편 8발(속도 10m/s, 거리 10m)을 쏜다. 한 번에 최대 1발만 적중한다.
