# 보스 3종 전투 상세 시험안

작성일: 2026-09-09 · D3 구현 기준

[콘텐츠 카탈로그 13장](HELLSCRIPT_Content_Catalog.md#13-보스-3종), [상위 기획서 16.4](HELLSCRIPT_Unity_Implementation_Plan.md), [완료 기준 4.3](HELLSCRIPT_Gameplay_Completion_Checklist.md#43-정예-6종과-보스-3종)의 기존 수치와 HP 전환·중단 규칙을 실행 단위로 구체화한다. 누락된 준비 시간·범위·우선순위·배치 수치는 아래 시험안을 사용한다. 밸런스 확정값은 아니다.

## 공통 행동과 단계 전환

보스마다 기본 공격·패턴 1·패턴 2의 CD를 따로 저장하고 준비 시작부터 계산한다. 최초 등장 대기는 기존 생성기의 1–2초를 각 CD에 적용한다. 준비·돌진·광선 유지·연속 폭발 실행 중에는 다른 주 행동을 시작하지 않는다. 유효한 패턴 1→패턴 2→기본 공격 순서로 선택하며 사거리·시야·사선·공간이 부족한 후보는 건너뛴다. 인지는 14m·벽 판정, 시야를 잃은 뒤 추적 기억은 4초다.

HP가 한 번이라도 50% 이하가 되면 전환을 예약하고, 다음 행동을 고를 때 후반 단계로 전환한다. 예약 이후 회복해도 취소하지 않고 후반 단계에서 돌아가지 않는다. 진행 중인 행동의 횟수·형상을 바꾸지 않는다. 준비 시작에 추가타 여부·고정 방향·목표·폭발 배치를 저장한다. 피해량은 실제 발사·돌진 시작·효과 생성 때 확정한다.

무력화는 진행 중 행동을 중단하고 남은 CD를 보존한다. CD는 무력화 중에도 흐른다. 중단 시 이미 발사된 갈고리와 생성된 광선·후속 폭발은 남은 수명을 유지한다. 아직 준비만 한 공격과 추가타는 취소한다. 기존 제압 100→3초 무력화→10초 면역을 유지한다. 동일 틱 사망·승패는 기존 통합 정산을 따른다.

기본 근접은 사거리 3m·전방 120도·0.6초 준비·D100%·CD 2초다. 보스 공통 능력치와 종류별 HP·공격 배수는 바꾸지 않는다. 합창자는 영웅과 8m 안이면 위치를 유지하며, 밖으로 나갔을 때 기존 보스 속도의 35%로 접근한다. 다른 보스는 기존 속도로 접근한다.

## 묘지의 집행자

- 내려찍기는 사거리와 부채 반경 4m, 전방 120도, 준비 1.2초, D200%, CD 6초다. 준비 시작 위치·방향을 고정한다.
- 후반 단계에서 시작한 내려찍기는 같은 위치·방향에 0.7초 재예고한 뒤 D200% 추가타를 한 번 준다. 같은 원 공격 ID를 유지하되 각 타격은 별도 피해 사건이다. 두 번째 준비 중 제압되면 추가타를 취소한다.
- 갈고리는 CD 9초·1초 준비·거리 10m·폭 1m·속도 12m/s·D100% 물리 투사체다. 발사자 사망 후에도 이동한다. 실제 투사체와 예고는 같은 벽 끝점을 사용한다.
- 명중하면 영웅을 저장된 발사 위치 쪽으로 최대 2m 끌어당긴다. 보행 벽과 살아 있는 몸체 앞에서 멈춘다. 끌림이 일어나면 영웅의 진행 중 행동을 중단하고 기존 비용·CD는 돌려주지 않는다. 이동기 도중 현재 위치가 유효한 보행·착지 지형이 아니면 피해만 적용하고 끌림은 생략한다. 끌림으로 벽 안에 착지시키지 않는다.

## 종말의 합창자

- 부하 소환은 CD 14초·준비 0.8초·영웅 인지 거리 12m다. 자기 소유의 살아 있는 부하가 최대 8명이 되도록 한 번에 최대 4명을 소환한다.
- 보스 주변 3m·4.5m·6m 고리의 정해진 후보를 순서대로 검사한다. 보행·착지·도달 가능·보스까지 시야와 기존 몸체 간격을 확인한다. 준비 시작에 후보를 고정하고 실행 때 다시 검사하며 무효 지점을 다른 곳으로 몰래 옮기지 않는다. 소환할 자리가 하나도 없으면 준비하지 않고 1초 뒤 후보를 다시 검토한다.
- 부하는 N01의 기본 행동을 사용하며 소환자 ID를 저장한다. 경험치·처치 게이지·골드·아이템·일반 사체를 주지 않는다. 처치 수와 전투 로그에는 남긴다. 자기 부하가 하나라도 살아 있으면 보스의 받는 피해를 20% 줄이며 다른 사건의 소환 적과 구분한다.
- 집중 광선은 CD 8초·준비 1.5초·폭 1.5m·거리 12m다. 준비 시작 방향을 고정하고 벽까지의 끝점을 저장한다. 생성 후 2초 동안 0.25초마다 D37.5% 암흑 피해를 8번 준다. 최초 피해는 활성화 0.25초 뒤다. 영웅 중심점이 광선 폭 안에 있어야 한다. 광선 생성 후 보스는 유지 동작을 하며, 제압·사망해도 이미 생성된 광선의 판정은 통합 전투 종료 전까지 유지된다.

## 균열의 포식자

- 돌진은 CD 7초·준비 1초·속도 10m/s·거리 최대 8m·폭 1m·D150%다. 이동 선분과 영웅 반경으로 한 돌진당 한 번 검사한다. 보스 몸체의 보행 반경 1.2m로 벽 앞에서 멈춘다.
- 후반 단계에서 시작한 돌진은 두 번 이동한다. 첫 돌진 종료 때 마지막 관측 위치로 다시 조준하고 0.8초 예고한다. 첫 돌진 중 HP가 50% 이하가 되더라도 두 번째 돌진을 끼워 넣지 않는다.
- 연속 폭발은 CD 12초·준비 1.3초다. 현재 영웅 위치와 그 양쪽 3.5m의 세 지점을 후보로 삼고, 지형에 맞는 방향을 탐색한다. 세 원을 처음부터 예고하며 각각 시작 후 1.3·1.65·2.0초에 반경 2.5m·D150% 암흑 피해를 한 번씩 준다. 준비가 끝나면 세 효과를 독립 생성하므로 이후 제압으로 남은 폭발을 지우지 않는다.
- 반경 0.65m 피난 지점 두 곳은 서로 1.5m 이상 떨어져 있고 모든 폭발 원에서 벗어나야 한다. 영웅의 실제 보행 속도·현재 감속과 0.2초 판단 간격을 고려해 첫 폭발까지 도달 가능한 경로를 검사한다. 벽·착지 불가·몸체 겹침과 예고 시작 때 이미 알려진 위험도 검사한다. 후보 탐색은 유한하며 유효한 배치가 없으면 CD를 소비하지 않고 1초 뒤 재검토한다.
- 피난 지점은 이 연속 폭발에 대한 안전 영역이다. 예고 이후 다른 적이 새로 만드는 공격까지 무효화하는 보호 구역은 아니며, 영웅이 규칙에 따라 계속 공격하기로 선택하면 자동 이동시키지 않는다. 준비 중에는 피난 지점을 별도 윤곽으로 보여 준다. 저장된 배치·경로·폭발 순서를 재시작 때 다시 추첨하지 않는다.

## 검증 기준

각 패턴의 준비·CD·형상·피해·중단·사망 후 수명·앱 복원을 검사한다. HP 50% 위/아래와 준비 중 경계 통과, 갈고리의 벽·몸체·이동기 충돌, 부하 상한·소유자·무보상, 광선 8틱·벽·고정 방향, 연속 폭발 세 시점·두 피난 경로·배치 불가 재시도를 포함한다. 네이티브에서 추가타 사이·광선 유지 중·연속 폭발 사이의 실제 앱 재시작을 확인한다. 균열 전체 흐름과 세 배속 검증을 이어 가며 Android 성능·물리 터치와 구분한다.
