# HELLSCRIPT 사냥 칙령 전역 옵션

작성일: 2026-09-09  
버전: v0.1  
문서 상태: 사용자가 검토한 전역 옵션 구성과 트리를 보존한 상세 기획 초안이다. 이 문서는 기존 게임의 모든 항목이 구현됐음을 뜻하지 않는다.  
적용 범위: 현재 캐릭터의 사냥 전반에 적용하는 기본 행동 규칙이다.

## 1. 문서의 기준과 연결 문서

기능명은 **사냥 칙령 · Hunt Edict**다. 이 문서는 `사냥 칙령 → 전역 설정 → 대분류 → 소분류 → 설정 항목`의 관계를 정리한다.

사용자는 회피, 전투 포지션, 체력 위기 대응, 아이템 획득·정리 옵션을 먼저 제시하고 추가 전역 옵션을 요청했다. 담당자는 이를 8개 묶음으로 보완했고, 사용자는 해당 구성을 긍정적으로 검토한 뒤 트리 정리를 요청했다. 따라서 아래 구성은 그 검토안을 보존하되, 세부 수치·기본값·조건 판정까지 사용자 확정 사항이나 구현 완료 사항으로 확대해서 해석하지 않는다.

| 구분 | 내용과 상태 |
|---|---|
| 사용자 명시 요구 | 공격 유형별 회피 여부와 HP 대비 피해 기준, 무조건 회피, 초회 조우와 포위 시 전투 위치, 낮은 HP에서 지정 회피기 사용, 회피기 재사용 대기 중 보행 후퇴, 등급별 전투 중·후 회수, 황금 고블린 우선 처치, 금화 최소 회수량, 가방 부족 시 귀환·교체, 등급별 판매·분해·창고 이동이다. |
| 담당자가 보완한 구조 | 8개 대분류와 하위 분류, 선택지 충돌 방지, 부착된 지속 피해와 장판의 구분, 긴급 생존·자원 보존·물약·전투 복귀, 대상 추적, 탐색, 반복·중단, 현재 행동 이유 표시 등을 제안했다. 사용자가 이 구성을 검토하고 트리 정리를 요청했다. |
| 수치의 상태 | 피해 회피 기준 1~100%는 사용자 제시 범위다. 나머지 `n%`, `n초`, `n m`, `n회`, `n골드`는 조절 대상의 자리표시자이며 기본값이나 허용 범위가 확정됐다는 뜻이 아니다. 후퇴 30%·복귀 50% 등의 설명 예시도 기본값으로 채택하지 않는다. |
| 현재 구현과의 관계 | 기존 코드에 일부 유사한 선택지가 있더라도 이 문서의 옵션 전체가 저장·화면·자동 행동에 연결됐다고 보지 않는다. 구현 범위와 검증 결과는 구현 문서에서 별도로 기록한다. |

- [사냥 칙령 저장·프리셋·공유 상세 기획](HELLSCRIPT_Hunt_Edict_Detail.md)은 명시적 저장, 되돌리기, 미저장 이탈, 코드 생성·불러오기·공유, 프리셋 5개 슬롯을 정의한다.
- [사냥 칙령 스킬별 옵션](HELLSCRIPT_Hunt_Edict_Skill_Options.md)은 모든 스킬의 옵션 정의와 현재 사용하는 스킬만 표시하는 규칙을 정의한다.
- [스킬별 핵심 옵션 v0.2](HELLSCRIPT_Hunt_Edict_Skill_Option_Catalog.md)는 스킬당 최대 8개·권장 4~6개의 편집 범위를 정의한다. 공통 생존·자원 보존·추적은 이 전역 문서의 같은 값을 참조하며, 제거한 개별 옵션을 전역의 스킬별 예외 메뉴로 다시 추가하지 않는다.
- [장비 상세 기획](HELLSCRIPT_Itemization_Detail.md)은 등급·세트·장비 보호·판매·분해의 기준을 제공한다.
- [균열 생성·탐색 상세 기획](HELLSCRIPT_Rift_Exploration_Detail.md)은 같은 균열을 보존하는 정리 귀환, 필드 상자와 성소, 탐색·제한시간의 기준을 제공한다.

사용자가 후속으로 요청한 **저장하기를 눌렀을 때만 저장하는 방식**을 따른다. 아래 옵션을 편집하거나 하위 분류를 이동하는 것만으로 저장하지 않으며, 저장 전의 변경은 실제 사냥에도 반영하지 않는다. 앞선 논의의 ‘적용’ 버튼과 ‘변경 내용 확인·적용’ 표현은 별도 상세 기획의 저장 흐름으로 대체한다.

## 2. 표시 방식

전역 설정 안에 대분류별로 접고 펼치는 카드를 둔다. 접힌 카드에서도 ‘장판 항상 회피 · HP 30% 이하 후퇴’처럼 저장된 설정 또는 현재 편집 중인 설정의 요약을 보여 주되, 두 상태를 혼동하지 않게 구분한다. 상세한 미저장 표시는 저장·프리셋 문서를 따른다.

서로 배타적인 행동은 목록에서 하나를 선택한다. 여러 조건을 함께 켤 수 있는 기능은 On/Off 또는 복수 선택을 사용한다. 수치는 슬라이더와 숫자 직접 입력을 함께 제공한다. 선택하지 않은 기능의 세부 수치는 접어 둔다.

다음 트리의 `↳`는 상위 기능이나 해당 선택지를 사용할 때만 표시하는 세부 옵션이다. 고정 기준과 시스템 판정은 사용자가 켜고 끄는 옵션과 구분하여 설명한다.

   │  │  ├─ 순간 범위 공격

   │  │  │  ↳ 1회 예상 피해가 최대 HP의 n% 이상
   │  │  └─ 직접 타격·투사체
   │  │     ├─ 사용 안 함 / 항상 회피 시도 / 피해 기준으로 회피
   │  │     ↳ 1회 예상 피해가 최대 HP의 n% 이상
   │  │
   │  ├─ 1-2. 특수 위험 회피

   │  │  └─ 겹치는 공격 대응 [On/Off]
   │  │     ↳ 합산할 시간: 앞으로 n초
   │  │     ↳ 합산 피해가 최대 HP의 n% 이상
   │  │
   │  └─ 1-3. 회피 실행 방식
   │     ├─ 회피 수단

   │        └─ 중단 가능한 공격 취소 / 현재 공격 완료 후 회피

   │  │  ├─ 체력 위기 대응 [On/Off]
   │  │  │  ↳ 현재 HP가 최대 HP의 n% 이하
   │  │  ├─ 치명적 피해 대응 [On/Off]
   │  │  │  └─ 감지한 공격으로 사망할 것으로 예상될 때
   │  │  └─ 부착된 지속 피해 대응 [On/Off]
   │  │     ↳ 중독·출혈 등의 초당 피해가 최대 HP의 n% 이상
   │  │
   │  ├─ 2-2. 긴급 대응 수단
   │  │  ├─ 사용할 방어기·회피기 선택
   │  │  ├─ 긴급 행동 순서
   │  │  │  └─ 지정 방어기 / 지정 회피기 / 보행 후퇴의 순서
   │  │  └─ 회피기 사용 불가 시 행동
   │  │     └─ 보행 후퇴 / 다른 지정 생존기 / 전투 유지
   │  │
   │  ├─ 2-3. 생존 수단 보존
   │  │  ├─ 회피기 사용 방침
   │  │  │  └─ 자유롭게 사용 / 긴급 생존용으로 보존
   │  │  └─ 회피용 자원 확보
   │  │     └─ 보존하지 않음 / 지정 회피기 1회분 보존
   │  │
   │  ├─ 2-4. 자동 물약 [독립 행동]
   │  │  └─ 자동 사용 [On/Off]
   │  │     ↳ 현재 HP가 최대 HP의 n% 이하이면 사용
   │  │
   │  └─ 2-5. 정상 전투 복귀
   │     ├─ 복귀 체력: 최대 HP의 n% 이상
   │     └─ 긴급 대응을 유발한 위험의 해소 여부 확인 [판정 기준]
   │
   ├─ 3. 전투 위치·몰이
   │  │
   │  ├─ 3-1. 교전 시작
   │  │  └─ 적을 처음 발견했을 때
   │  │     └─ 즉시 접근 / 제자리에서 맞이 / 거리 유지 / 길목 유인
   │  │
   │  ├─ 3-2. 기본 전투 위치
   │  │  ├─ 위치 유지 방식
   │  │  │  └─ 무리 중심 / 가장자리 / 거리 유지 / 선회 / 제자리
   │  │  ↳ 거리 유지 시 희망 거리
   │  │  │  └─ 기본 공격 사거리 기준 / n m 직접 지정
   │  │  └─ 자신의 장판·덫을 활용한 위치 선정 [On/Off]
   │  │
   │  ├─ 3-3. 포위 대응
   │  │  └─ 적에게 둘러싸였을 때
   │  │     └─ 중심에서 전투 / 외곽으로 이탈해 한쪽에 모으기 / 회피기 이탈
   │  │
   │  └─ 3-4. 몰이 방침
   │     ├─ 몰이 규모
   │     │  └─ 한 무리씩 상대 / 최대 n명까지 모으기
   │     ├─ 전투 중 추가 적 유인 [On/Off]
   │     └─ 몰이 종료 조건
   │        ├─ 목표 인원 도달
   │        ├─ 최대 몰이 시간 n초 경과
   │        └─ 체력 위기 발생
   │
   ├─ 4. 공격 대상·추적
   │  │
   │  ├─ 4-1. 기본 대상 선택
   │  │  ├─ 기본 선택 기준
   │  │  │  └─ 가까운 적 / 낮은 HP / 높은 HP / 밀집한 곳
   │  │  ├─ 특수 대상 우선순위
   │  │  │  └─ 보스 / 정예 / 회복·지원형 / 원거리형의 순서
   │  │  └─ 위험한 시전을 방해할 대상 우선 [On/Off]
   │  │
   │  ├─ 4-2. 대상 유지·추적
   │  │  ├─ 대상 변경 방침
   │  │  │  └─ 처치까지 유지 / 더 높은 우선순위의 적으로 변경

   │  │  ├─ 최대 추적 시간: n초

   │  │     └─ 추적 중단 / 마지막으로 본 위치까지 확인

   │     ├─ 황금 고블린 우선 처치 [On/Off]

   │        └─ 보스 우선 / 소환된 적 우선 / 위험한 지원형 먼저

   │  │  ├─ 세트 장비 회수 방식 [전설 설정에 대한 별도 예외]
   │  │  │  └─ 획득 안 함 / 지나가며 획득 / 전투 후 / 전투 중 우선
   │  │  ├─ 장비 필터
   │  │  │  ├─ 모든 직업 / 현재 직업
   │  │  │  ├─ 획득할 장비 부위 [복수 선택]

   │  │  └─ 필터와 관계없이 획득할 예외

   │  │  ├─ 최대 회수 경로 거리: 현재 위치에서 n m
   │  │  └─ 위험 지역의 전리품
   │  │     └─ 위험 해소 대기 / 안전 경로 이용 / 회피 기준 이하 피해 감수
   │  │

   │     └─ 남은 획득 대상 회수 후 종료 / 남은 장비를 두고 종료

   │  │  ├─ 실행 시점
   │  │  │  └─ 사용 안 함 / 정리 귀환 시 / 매 균열 종료 후
   │  │  └─ 등급·종류별 처리 [각각 1개 선택]

## 4. 각 분류의 의미와 충돌 방지 기준

### 4.1 회피와 긴급 생존

1. **장판은 공격 형태이며, 도트는 반복 피해 방식이다.** 이동으로 벗어날 수 있는 지속 피해 장판은 1-1에서 다룬다. 이미 캐릭터에게 붙은 중독·출혈은 2-1에서 별도로 다룬다. 걷기만 해도 부착 효과가 해제되는 것으로 해석하지 않는다. 부착 피해 상황의 후퇴는 추가 피격을 줄이는 행동이며, 해제는 실제 해제 효과가 있는 수단을 사용할 수 있을 때만 가능하다.
2. 일반 회피의 피해 비율은 **최대 HP 대비 예상 HP 손실**로 통일하는 제안이다. 방어·저항·현재 보호막을 반영한다. 같은 보호막을 겹치는 공격 각각에서 중복 차감하여 합산 위험을 축소하지 않는다. 체력 위기 조건과 복귀 조건은 현재 HP를 최대 HP로 나눈 비율이다.
3. 지속 피해 장판은 초당 손실, 순간 범위 공격·직접 타격·투사체는 1회 손실, 겹치는 공격은 지정한 앞으로의 시간 동안 합산할 손실을 기준으로 한다. 모두 감지한 공격과 추정 가능한 피해에 한정한다.
4. 사용자 표현인 ‘무조건 피한다’는 화면에서 **‘항상 회피 시도’**로 표시한다. 경로가 없거나 행동이 잠긴 상황에서도 회피 성공을 보장하는 기능으로 설명하지 않는다.
5. 행동 방해 효과의 회피는 캐릭터가 감지할 수 있는 기절·빙결·속박·끌어당기기 등의 예고에 적용한다. 긴급 대응은 일반 공격 중단 방침과 별도로 공통 행동 우선순위를 확인한다. 중단 불가능한 행동을 취소할 수 있다고 가정하지 않는다.
6. 지정 방어기·회피기는 장착한 스킬 중 해당 역할을 수행할 수 있는 수단에서 선택한다. 회피기 사용 불가에는 재사용 대기, 자원 부족, 유효 착지점 부재가 포함된다. 현재 스킬을 바꿨을 때의 참조·표시·저장 처리는 스킬별 옵션 문서를 따른다.
7. 회피기를 긴급 생존용으로 보존하면 일반 회피와 공격 진입도 이 보존 조건을 확인한다. 회피용 자원 1회분을 남기는 설정은 공격 스킬의 자원 사용 판단과 연결한다.
8. 전투 복귀 체력은 후퇴를 시작하는 체력보다 높게 두는 것을 제안한다. 복귀하려면 체력 조건뿐 아니라 긴급 대응을 일으킨 위험도 해소되어야 한다. 구체적인 기본값은 후속 밸런스 검증에서 정한다.
9. 자동 물약은 이동·공격·회피와 함께 판단할 수 있는 독립 행동이다. 물약을 주 행동 순서의 한 칸으로 넣어 다른 행동을 불필요하게 정지시키지 않는다. 실제 물약 사용 제한은 물약 시스템을 따른다.

### 4.2 전투 위치·몰이와 대상·추적

1. ‘적에게 돌진한다’는 전역 설정에서 우선 **빠르게 접근하는 이동 방침**으로 해석한다. 실제 돌진·도약 스킬 사용 여부는 스킬별 사용 규칙과 생존 수단 보존 설정을 따른다.
2. ‘적을 가운데로 모은다’는 캐릭터의 이동·위치 선정으로 적을 유도하는 의미다. 원거리 적을 강제로 끌어당기거나 모든 적이 따라오게 만드는 능력을 추가하지 않는다. 길목이 없거나 몰이를 이어가기 어려우면 기본 전투 위치로 전환한다.
3. 몰이는 이미 발견한 적을 대상으로 한다. 추가 적 유인을 꺼도 스스로 교전에 합류한 적에게는 대응한다. 목표 인원 도달, 최대 시간 경과, 체력 위기 중 하나가 발생하면 몰이를 종료하고 정상 전투 또는 긴급 생존으로 전환한다.
4. 기본 공격 대상보다 특수 대상 우선순위를 먼저 확인한다. ‘위험한 시전 방해’는 방해 가능한 시전이면서 실제 사용할 방해 수단이 있을 때 의미가 있다. ‘현재 대상 유지’도 대상 소실과 긴급 생존에 의해 종료될 수 있다.
5. 최대 추적 거리와 시간 중 한도에 도달한 조건이 있으면 해당 추적을 끝내고 다른 유효 대상을 판단한다. 시야를 벗어난 적은 현재의 숨은 위치가 아니라 마지막으로 감지한 위치까지만 확인한다.
6. 황금 고블린 우선 처치는 사용자가 제시한 콘텐츠 연동 요구다. 이 문서는 고블린 콘텐츠 자체를 구현하거나 현재 존재한다고 확정하지 않는다. 고블린은 일반 공격 대상보다 우선하되 긴급 생존·일반 회피와의 관계는 공통 행동 우선순위를 따른다.

### 4.3 전리품 회수

1. **같은 대상의 회수 방식은 하나만 선택한다.** ‘전투 후 회수’와 ‘전투 중 우선 회수’를 동시에 On으로 만드는 구조를 사용하지 않는다. ‘지나가며 획득’은 획득 범위에 들어온 물건을 줍되 그 물건 때문에 이동 경로를 바꾸지 않는 방식이다.
2. ‘전투 후’는 던전의 모든 적을 처치한 뒤가 아니다. 현재 교전 중인 적이 없고 진행 중인 공격 위험이 해소된 시점이다. ‘전투 중 우선 회수’는 일반 공격보다 먼저 회수하러 이동하되 회피와의 충돌은 공통 순서로 판단한다.
3. 일반·마법·희귀·전설은 등급이다. **세트는 전설 등급에 속하며 별도 등급이 아니다.** 세트 장비에 대해서는 별도 회수 행이 전설의 일반 회수 방식을 덮어쓰는 예외로 작동한다. 일반 전설에는 전설 행을 적용한다. 두 행을 동시에 적용하지 않는다.
4. 전설·세트·지정 효과의 필터 예외는 직업·부위·최소 아이템 레벨 필터를 통과시킨다는 뜻이다. 이 예외가 해당 장비의 회수 방식인 ‘획득 안 함’을 몰래 변경하지 않는다. 회수 대상과 실제 회수 시점은 해당 등급 또는 세트 행에서 확인한다.
5. 금화 최소 수량은 일부러 이동해서 주울지 판단하는 기준이다. 기준 미만의 금화라도 이동 중 획득 범위에 들어오면 주울 수 있다. 재료·보석·코어는 앞서 제안한 종류별 회수 항목으로 보존하며, 해당 콘텐츠의 실제 분류·존재 여부는 콘텐츠 명세와 연결한다.
6. 회수 거리에는 경로 거리를 사용한다. 위험 지역에서 회피 기준 이하 피해를 감수하는 선택도 긴급 생존 규칙을 무효화하지 않는다. 균열 종료 전 회수는 이미 획득 대상으로 정한 물건에만 적용한다.

### 4.4 가방·자동 정리

1. **등급·종류별 정리 결과는 가방 보관·판매·분해·창고 이동 중 하나다.** 판매와 분해를 같은 장비에 함께 지정하지 않는다. 세트의 별도 정리 정책이 있으면 전설 일반 정책보다 우선하는 예외로 취급한다. 세트를 새로운 상위 등급으로 만들지 않는다.
2. 가방 장비 교체는 가방에 보관 중인 장비의 교체다. 착용 장비를 자동 변경하는 기능이 아니다. 등급만 비교하는 사용자 요구를 유지하고, 등급 → 아이템 레벨 → 판매가 순 비교는 앞서 보완한 제안이다. 비교 결과가 동률이면 기존 장비를 유지한다. 전설과 세트는 같은 등급이며 세트라는 이유만으로 자동 우위를 부여하지 않는다.
3. 잠금·현재 장착·저장된 빌드에서 참조하는 장비는 자동 판매·분해·낮은 가치 교체에서 항상 제외하는 기존 장비 기준을 따른다. 강화·보석 장착·지정 전설 효과·지정 세트는 추가 보호 대상으로 설정할 수 있다. 사냥 칙령 코드가 다른 사람의 장비 소유권이나 개별 장비 인스턴스를 복제하는 기능은 아니다.
4. 기존 장비 기획의 **전설·세트 자동 폐기에 대한 별도 허용과 장비 보호 기준**을 보존한다. 이 문서의 ‘교체’ 항목을 근거로 장비를 즉시 바닥에 버리거나 삭제하는 새 구현을 추가하지 않는다. 교체 시 제거 대상과 처리는 기존 가방 교체 정책에 연결하며, 보호 조건을 먼저 확인한다.
5. 창고 이동이 실패하면 가방 보관 또는 정리 중단 방침을 따른다. 실패했다는 이유로 판매·분해로 자동 전환하지 않는다. 정리 후에도 공간이 없으면 사용자가 지정한 반복 중단 또는 획득 제한 방침을 사용한다.
6. 마을 정리 후 복귀는 기존의 같은 균열을 보존하는 정리 귀환이다. 정리 중 전투를 멈추고 HP·자원·재사용 대기시간 등을 유지한다. 정리 귀환을 전투 회복이나 새 균열 생성 수단으로 해석하지 않는다.

### 4.5 탐색·상호작용과 반복·중단

1. 탐색은 이미 감지한 대상과 미탐색 지역을 구분한다. 발견물 처리 순서는 각 대상의 사용·회수·교전 조건을 만족하는 경우에 적용한다. 상자·성소를 발견했다는 사실만으로 이용 조건을 무시하지 않는다.
2. 저주·전투 상자의 조건부 개봉은 HP 기준과 지정 생존기 사용 가능 조건을 함께 확인한다. 성소의 ‘필요한 효과’ 판정은 해당 성소의 효과와 콘텐츠 명세에 연결한다. 이 문서가 새로운 성소 효과를 정의하지는 않는다.
3. 보스 해금 시 이동 방침과 남은 시간 부족 시 우회 중단 방침은 전역 진행 우선순위다. 계속 획득할 예외 전리품은 별도로 지정할 수 있지만 회수 거리와 생존 기준은 함께 확인한다.
4. 길이 막혔을 때 재탐색하고 끼임에서 복구하는 동작은 정상 자동 탐색의 기본 동작으로 보장할 대상이다. 사용자가 켜고 끄는 추가 전역 옵션으로 만들지 않는다.
5. 자동 반복 성공·실패 결과에 따라 다음 단계·같은 단계·하위 단계·중단을 선택한다. 반복 횟수와 실제 세션 시간 제한에는 ‘제한 없음’을 제공하는 앞선 제안을 보존한다. 시간 제한 도달 시 전투 중이면 현재 판 종료 후 멈춘다.
6. 다음 판은 설정한 가방 여유가 확보되고 예정된 정리가 완료된 뒤 시작한다. 결과 화면 대기시간을 두며, 사용자가 장비나 결과 상세를 보고 있는 동안에는 기다린다.

## 5. 분류 사이의 연결 관계

| 연결 | 적용 관계 |
|---|---|
| 회피 규칙 ↔ 긴급 생존·회복 | 일반 회피도 지정한 회피기를 참조하되 긴급 생존용 보존과 자원 확보 조건을 확인한다. |
| 긴급 생존 ↔ 전투 위치·공격·회수 | 긴급 생존 조건이 발생하면 공통 우선순위에 따라 진행 중 행동보다 먼저 대응할 수 있다. |
| 전투 위치·몰이 ↔ 공격 대상·추적 | 대상 선택으로 적을 정하고, 위치 방침으로 접근·거리 유지·유인 방향을 정한다. 추적 한도와 긴급 생존 조건을 함께 확인한다. |
| 전리품 회수 → 가방·자동 정리 | 먼저 획득 대상인지 판단한다. 가방 공간이 부족하면 가방 부족 대응으로 넘어간다. |
| 가방·자동 정리 → 반복 사냥 | 정리 완료와 다음 판 시작 조건을 충족해야 자동 반복을 이어간다. |
| 탐색 → 전투·회수·상호작용 | 발견 대상에 맞는 분류의 규칙을 적용한다. 각 분류의 조건을 만족하지 않으면 그 행동을 강제로 시작하지 않는다. |
| 자동 물약 ↔ 모든 행동 | 물약은 이동·공격·회피와 별도로 조건을 판단한다. |
| 전역 설정 ↔ 스킬별 설정 | 개별 스킬의 목표·이동 설정은 ‘전역 설정 따르기’를 기본 연결로 삼는 제안이다. 개별 지정값은 해당 스킬 행동에 적용하고 긴급 생존과의 충돌은 공통 우선순위를 따른다. |

공통 행동 순서의 시작 제안은 **긴급 생존 → 일반 회피 → 전투 중 우선 회수 → 공격 → 전투 후 회수 → 탐색**이다. 앞선 답변의 제안대로 이 순서를 화면에 공개하고 조정할 수 있는 구조를 검토한다. 이 순서는 확정된 밸런스 기본값이나 기존 코드 실행 순서의 설명이 아니다. 물약은 이 순서와 별도로 판단하며, 고블린 우선 처치는 공격 대상 선택 안에서 처리한다.

## 6. 공통 기능의 문서 경계

현재 행동과 그 행동을 고른 설정을 함께 보여 주는 기능을 보존한다. 예를 들어 ‘HP 28%로 후퇴’, ‘회피기 사용 불가로 보행 이탈’, ‘전설 장비 우선 회수’를 표시하고, 해당 표시에서 관련 설정으로 이동할 수 있게 한다. 표시할 이유는 실제 판단 결과를 따르며 실행하지 않은 규칙을 원인으로 표시하지 않는다.

명시적 저장·되돌리기·미저장 이탈 팝업·코드 생성·이름이 있는 프리셋 5개 슬롯·불러오기·클립보드 공유는 [저장·프리셋·공유 상세 기획](HELLSCRIPT_Hunt_Edict_Detail.md)을 따른다. 이 문서의 전역 8개 분류는 해당 저장 단위 안의 설정 내용이다.

사용할 스킬의 네 칸 배치와 해당 스킬의 칙령도 같은 저장 단위에 포함한다. 프리셋을 불러오면 전역 설정만 바뀌는 것이 아니라 스킬 배치와 개별 옵션까지 함께 복원한다. 미저장 편집본을 기준으로 전역 회피기 선택 등의 연결 표시도 갱신하되, 실제 장착과 사냥 행동은 저장 성공 시 함께 반영한다.

불러온 프리셋에 미보유 스킬이 있으면 해당 칸만 비우고 가능한 전역·스킬 설정을 가져와 저장할 수 있다. 전역 설정이 없는 회피기를 참조하면 그 항목에 이유를 표시하고 원본의 가능한 다른 대응을 유지한다. 보행 후퇴 등이 원본에서 꺼져 있다면 자동으로 켜지 않으며, 미보유 수단에 대한 참조 보류만으로 전체 저장을 막지 않는다. 빈칸의 수동 대체, 원본 코드 보존과 부분 적용한 구성의 새 코드 생성은 공통 상세안을 따른다.

모든 스킬의 사냥 칙령 옵션을 미리 정의하고 현재 사용하는 스킬만 화면에 표시하는 구조는 [스킬별 옵션 기획](HELLSCRIPT_Hunt_Edict_Skill_Options.md)을 따른다. 스킬 교체 때문에 다른 전역 옵션을 재작성하거나, 보이지 않는 스킬 설정을 이 트리에서 삭제하는 것으로 해석하지 않는다.
