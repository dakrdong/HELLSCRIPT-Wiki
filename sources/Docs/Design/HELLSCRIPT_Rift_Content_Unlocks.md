# 균열 단계별 콘텐츠 개방

갱신일: 2026-09-24 · 개발 브랜치 구현

[English](HELLSCRIPT_Rift_Content_Unlocks.en.md) · [실제 해금 데이터](../../Assets/HELLSCRIPT/Resources/ContentUnlocks.json) · [최초 보상 상자](HELLSCRIPT_Reward_Boxes.md) · [성장·전투 밸런스안](HELLSCRIPT_Balance_1000.md)

균열 최초 보상 목록에서 **어느 단계에 어떤 기능이 열리는지** 함께 확인한다. 기능별 조건은 `ContentUnlocks.json` 한 곳에서 관리하며, 팝업 안내와 화면 접근, 실제 강화·제작·룬 변경 거래가 같은 판정을 사용한다. 신규 계정에 적용하는 개방 순서는 아래와 같다.

| 균열 클리어 | 개방 콘텐츠 | 배치 의도와 첫 이용 조건 |
|---:|---|---|
| 시작 | 훈련장·장비 관리·사냥 칙령·기본 회복 물약·판매·분해·창고 | 전투 설정과 장비 정리를 처음부터 사용할 수 있다. 직업 스킬은 기존 영웅 레벨·트리 조건을 따른다. |
| 1 | 장비 강화·오프라인 보상 | 첫 장비 개선을 경험한다. 장비 강화는 골드가 필요하고, 오프라인 보상은 개방 이후 시간만 정산한다. |
| 3 | 부위 선택 희귀 제작 | 초반에 부족한 부위를 보완한다. 실제 골드·재료 비용을 지불해야 한다. |
| 5 | 장착 슬롯 강화 | 장비 교체와 별개로 유지되는 성장을 소개한다. 강화석과 비어 있는 작업 칸이 필요하다. |
| 10 | 보석 구매·장착·교체·합성·분해 | 첫 전설 무기와 보석 상자 보상에 맞춘다. 합성은 같은 보석 5개로 상위 1개, 분해는 반대 방향으로 한 단계씩 진행한다. |
| 15 | 룬 배치·형상 변환·합성·구매·무기 숙련 | 보드 배치를 학습한 뒤 성장시킨다. 이때부터 적 처치로 숙련 경험치를 얻는다. |
| 25 | 미확인 장비 구매 | 부위별 무작위 구매를 성장 선택지로 추가한다. 일반 장비 상점은 시작부터 유지한다. |
| 35 | 옵션 재설정 | 초반의 장비 교체 이후 유효 옵션을 다듬는다. 한 줄 고정과 기존 골드 비용을 유지한다. |
| 40 | 위상 성장·각인 | 수집한 전설 효과를 다른 착용 장비에 적용한다. 분해로 위상을 수집하는 것은 개방 전에도 가능하다. |
| 60 | 소탕·보석 물약 제조 | 반복 수급과 소모품 제작을 연다. 소탕에는 선택 영웅의 실제 기록과 일일 횟수가, 물약 제조에는 해당 보석이 필요하다. |
| 80 | 걸작 강화 | 강화 +5 이상 장비를 추가 성장시킨다. 계정별 걸작 상한과 재료·골드 조건도 충족해야 한다. |
| 120 | 전설·세트 코어 선택 제작 | 부족한 부위나 빌드 효과를 보완한다. 같은 부위 코어 10개를 제작 시 소비한다. |

메뉴 14개의 영구 이용 권한을 관리한다. 시작부터 가능한 관리 기능은 별도의 잠금을 추가하지 않았다. R100 각성 장비 상자, R200 세트 상자, R300·500·650 룬 상자와 R750·1000 보석 상자는 **아이템 지급 목표**이며 새로운 메뉴 개방 조건이 아니다. 이후 구간은 이미 열린 콘텐츠의 성장을 이어간다. 자연 드랍의 각성 확률·룬 등급, 걸작 상한 곡선과 전체 전투 수치는 이 변경에서 조정하지 않는다.

최신 개방 순서는 [초반 균열 조정](HELLSCRIPT_Early_Rift_Balance.md)을 따른다. R25 미확인 구매에서 전설·세트를 추첨할 수 있고, 균열 보상은 R30부터 전설·세트를 지급하며, 옵션 재설정은 R35에 열린다.

## 최초 보상 팝업

1~1000단계의 목록 행에 보상 상자 수·수령 상태와 **콘텐츠 개방: 기능 이름**을 표시한다. 단계를 누르면 해당 기능의 현재 상태와 사용 방법, 다음 개방 단계, 최초 보상 상자를 함께 보여 준다. 목록은 화면에 필요한 행만 재사용한다.

**콘텐츠는 계정의 클리어 기록이 확정되면 자동으로 열린다. 상자 수령 버튼을 누를 필요가 없다.** 현재 전투 소유 코드가 보스 처치 보상을 확정하면서 `highestClear`를 기록하는 시점을 그대로 따른다. 훈련과 소탕은 이 기록을 새로 올리지 않는다. 진행 중인 전투·포탈에서 제작이나 강화를 허용하는 것은 아니며 기존 전투 중 이용 제한을 계속 적용한다.

상자는 별도 규칙에 따라 해당 단계의 정상 종료·최단 기록이 있어야 수령할 수 있다. 따라서 콘텐츠가 이미 열렸어도 보스 처치 후 전리품 정리를 중단했다면 그 단계 상자는 정상 완료 후 수령해야 할 수 있다. 팝업은 콘텐츠 개방 상태와 상자 수령 상태를 따로 표시한다.

## 신규 계정과 기존 계정

- 신규 계정은 보석을 먼저 얻거나 같은 부위 코어를 10개 모아도 기능이 조기에 열리지 않는다. 보유 수량은 보존하며 각각 R10·R120에서 사용할 수 있다.
- 룬과 위상은 개방 전에도 획득·수집한다. 신규 계정의 룬 배치·변경과 숙련 경험치는 R15, 위상 성장·각인은 R40부터 가능하다.
- 계정 내 어느 영웅이 단계를 달성해도 모든 영웅이 기능을 이용한다. 소탕 보상 단계와 기록 요구는 선택 영웅을 기준으로 유지한다.
- 기존 해금 상태 v1은 v2로 한 번 이관한다. 이전의 단계별 권한, 보석·코어 조기 해금, 시작부터 열려 있던 룬·위상, 장비 강화와 함께 열렸던 슬롯·걸작, 보석과 함께 열렸던 물약 제조를 보존한다. 재화·장비·룬·위상·프리셋은 회수하지 않는다.
- 이관 전에 원본 저장을 `.before-content-unlocks-v2.json`으로 보관한다. 저장 schema는 13이다. 현재 저장의 누락·낯선 해금 버전은 원본을 보존하고 읽기를 중단한다. 안내 확인 여부는 이용 권한과 분리한다.

## 실행 경로와 검증

기존 소유자 `ContentUnlocks`, `GameStore`, `ContentServices`, `Jeweler`, `ItemQuality`, `AspectStone`, `RuneGrowth`를 확장했다. 새 관리자를 만들지 않았다. 잠금 상태에서는 거래가 재화·장비·룬 배치·난수 상태를 바꾸지 않으며, 저장 실패와 재시도는 기존 거래 규칙을 따른다. 대장간 탭에는 개방 조건을 표시하고, 룬·위상 진입에서는 같은 조건을 안내한다.

[검증 기록](../Implementation/RiftUnlockEvidence/Rift_Content_Unlock_Verification.md)에서 실제 실행 결과와 화면 증거를 확인한다. 모바일 실기기와 자연 플레이로 R1000까지 진행한 결과는 포함하지 않는다. 공개 위키 게시와 원본 `main` 반영은 해당 브랜치 병합 뒤에 수행한다.
