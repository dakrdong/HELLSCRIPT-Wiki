# HELLSCRIPT 궁수 스킬 36종

정리 기준일: 2026-09-22

상태: 확정 기획 · 능력·장비 구현의 검증 상태는 [구현 기록](../Implementation/Class_Skill_Runtime.md). 일반 플레이 공개와 UI 연결은 대기 중입니다. 아래 수치는 1등급 기준입니다.

[공통 규칙·출처](HELLSCRIPT_Class_Skills.md) · [장비 대응표](HELLSCRIPT_Skill_Equipment.md) · [English](HELLSCRIPT_Ranger_Skills.en.md)

일반 액티브 16개·패시브 18개·궁극기 2개입니다. 장착은 일반 액티브 최대 4개, 패시브 최대 3개, 궁극기 1개를 제안합니다. 기본 공격은 별도입니다. 전체 목록 35·36번인 궁극기는 같은 최종 단계에 놓고 둘 중 하나만 선택합니다.

## 장비에서 출발한 빌드 예시

각 행은 해당 세트 전체를 착용하는 예시입니다. 제시한 전설은 세트와 부위가 겹치지 않습니다. 남은 부위에는 희귀 장비를 사용합니다. 각 빌드의 기술 순서를 사냥 칙령으로 설정하며, 자동 사용 조건은 아래 기술별 제안을 따릅니다.

### 유랑 사냥꾼 · `REF_SA01`

일반 액티브: 잇단 사격 (`A07`), 응시 사격 (`A08`), 사냥꾼의 표식 (`A05`), 사냥 준비 (`A16`).

패시브: 표식의 빈틈 (`AP07`), 다시 당기는 시위 (`AP09`), 집중 조준 (`AP13`). 선택 궁극기: 그림자 추격 (`A18`).

함께 착용하는 전설: 인내하는 사냥활 (`DES_LA41`), 이중 사냥의 맹세 (`DES_LA46`).

이동으로 좋은 사선을 잡고 표식 대상에 잇단 사격·응시 사격을 집중합니다. 사냥 준비와 기본 공격으로 자원을 채웁니다.

### 생환자의 외투 · `REF_SA02`

일반 액티브: 후퇴 도약 (`A04`), 미끼 투영 (`A11`), 연막 엄폐 (`A12`), 갈라지는 화살 (`A14`).

패시브: 탈출의 발걸음 (`AP02`), 유인 전술 (`AP14`), 빈틈 없는 재장전 (`AP16`). 선택 궁극기: 그림자 추격 (`A18`).

함께 착용하는 전설: 착지하는 독구름 (`LA23`), 민첩한 재장전 (`LA24`).

미끼로 일반 적을 모은 뒤 분열 사격을 사용하고, 후퇴·연막의 서로 다른 방어 구간으로 생존합니다.

### 명사수의 교본 · `REF_SA03`

일반 액티브: 관통 사격 (`A01`), 다중 사격 (`A02`), 사냥꾼의 표식 (`A05`), 독화살 (`A13`).

패시브: 꿰뚫는 시선 (`AP03`), 표식의 빈틈 (`AP07`), 독의 순환 (`AP10`). 선택 궁극기: 일제 소탕 (`A17`).

함께 착용하는 전설: 이중 사냥의 맹세 (`DES_LA46`), 핏줄 추적자 (`LA31`).

표식 대상에 독화살을 먼저 맞힌 뒤 관통·다중 사격으로 세트 자원 회복과 직접 피해 증가를 받습니다.

### 거수 사냥 · `REF_SA04`

일반 액티브: 관통 사격 (`A01`), 다중 사격 (`A02`), 사냥꾼의 표식 (`A05`), 응시 사격 (`A08`).

패시브: 긴 사거리 (`AP01`), 마무리 사격 (`AP06`), 무음의 살수 (`AP18`). 선택 궁극기: 일제 소탕 (`A17`).

함께 착용하는 전설: 끝없는 궤적 (`LA01`), 좁혀진 사선 (`LA02`).

같은 표식 정예에게 관통·다중 사격 3회를 모읍니다. 응시 사격과 궁극기는 별도 공격이며 3회 집계를 대신하지 않습니다.

### 복수의 시선 · `REF_SA05`

일반 액티브: 관통 사격 (`A01`), 다중 사격 (`A02`), 경계 쇠뇌 (`A15`), 사냥 준비 (`A16`).

패시브: 다시 당기는 시위 (`AP09`), 집중 조준 (`AP13`), 길잡이 (`AP17`). 선택 궁극기: 그림자 추격 (`A18`).

함께 착용하는 전설: 준비된 초소 (`DES_LA45`), 먼 사냥의 맹세 (`LA06`).

기본 공격 5중첩을 만든 뒤 주력 사격을 사용합니다. 쇠뇌는 기본 공격 횟수를 올리지 않으며 먼 위치에서 지원합니다.

### 연금 사냥터 · `REF_SA06`

일반 액티브: 맹독 덫 (`A03`), 후퇴 도약 (`A04`), 가시 덫 (`A09`), 서리 올가미 (`A10`).

패시브: 덫 사냥꾼 (`AP04`), 연금 숙련 (`AP11`), 준비된 도주 (`AP12`). 선택 궁극기: 일제 소탕 (`A17`).

함께 착용하는 전설: 이중 사냥의 맹세 (`DES_LA46`), 독사의 탈피 (`LA03`).

독 덫 안에 속박·서리 덫을 겹쳐 적을 붙잡습니다. 새 덫은 세트가 세는 맹독 덫 수와 첫 독 피해 발동을 대신하지 않습니다.

### 삼독의 화살 · `REF_SA07`

일반 액티브: 그림자 화살 (`A06`), 관통 사격 (`A01`), 다중 사격 (`A02`), 독화살 (`A13`).

패시브: 사냥감의 발자취 (`AP08`), 독의 순환 (`AP10`), 독과 서리 (`AP15`). 선택 궁극기: 그림자 추격 (`A18`).

함께 착용하는 전설: 좁혀진 사선 (`LA02`), 검은 전염 (`LA04`).

독화살로 선행 중독을 만들고 그림자 화살을 준비한 뒤 관통·다중 사격으로 주입 효과를 소비합니다. 독화살은 A06 충전을 소비하지 않습니다.

### 눈먼 그림자 · `REF_SA08`

일반 액티브: 후퇴 도약 (`A04`), 관통 사격 (`A01`), 다중 사격 (`A02`), 연막 엄폐 (`A12`).

패시브: 탈출의 발걸음 (`AP02`), 절약된 집중 (`AP05`), 빈틈 없는 재장전 (`AP16`). 선택 궁극기: 그림자 추격 (`A18`).

함께 착용하는 전설: 이중 사냥의 맹세 (`DES_LA46`), 꺼지지 않는 심장 (`LC03`).

후퇴 후 6초 동안 원 사격으로 복제 효과를 사용합니다. 연막은 위험한 구간을 버티는 보조 기술이며 후퇴 발동을 대신하지 않습니다.

### 독무덤지기 · `SA`

일반 액티브: 맹독 덫 (`A03`), 관통 사격 (`A01`), 후퇴 도약 (`A04`), 사냥꾼의 표식 (`A05`).

패시브: 덫 사냥꾼 (`AP04`), 독의 순환 (`AP10`), 준비된 도주 (`AP12`). 선택 궁극기: 일제 소탕 (`A17`).

기존 2·4세트의 원 기술 조건을 유지합니다. 새 궁극기는 별도 슬롯에서 사용하며 세트의 지정 기술로 가장하지 않습니다.

### 긴 그림자의 추적자 · `SAB`

일반 액티브: 후퇴 도약 (`A04`), 관통 사격 (`A01`), 사냥꾼의 표식 (`A05`), 그림자 화살 (`A06`).

패시브: 긴 사거리 (`AP01`), 탈출의 발걸음 (`AP02`), 표식의 빈틈 (`AP07`). 선택 궁극기: 그림자 추격 (`A18`).

기존 2·4세트의 원 기술 조건을 유지합니다. 새 궁극기는 별도 슬롯에서 사용하며 세트의 지정 기술로 가장하지 않습니다.

### 07. 잇단 사격 · `A07`

**장비 연결:** 인내하는 사냥활 (`DES_LA41`).

**참고 구조:** D2 Guided Arrow; D3 Impale.
