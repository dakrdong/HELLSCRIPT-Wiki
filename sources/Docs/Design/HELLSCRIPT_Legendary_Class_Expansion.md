# 직업별 전설 장비 40종 확장

작성일: 2026-09-22. 같은 날 참고 자료를 확인했다. 아래 신규 수치는 HELLSCRIPT의 밸런스 시험안이다.

## 범위와 원본

전사 40종, 궁수 40종, 마법사 40종과 기존 공용 전설 3종으로 총 123종이다. 세트 장비 24종은 별도로 센다. 기존 직업 전설 12종의 ID를 유지하고 직업마다 36종을 추가한다. 신규 항목의 직업·부위·효과·한국어와 영어 문구·실행 규칙은 [LegendaryPowers.json](../../Assets/HELLSCRIPT/Resources/Data/LegendaryPowers.json)을 원본으로 사용한다.

참고 자료는 Codex 내장 브라우저로 확인한 [D4 Builds의 디아블로 IV 위상 DB](https://d4builds.gg/database/legendary-aspects/)이다. 전사는 야만용사, 궁수는 도적, 마법사는 원소술사의 효과 구조를 중심으로 삼고 공용·다른 직업의 패턴도 필요에 따라 변형했다. 표의 참고 위상은 발상의 출처를 뜻한다. 디아블로 IV의 문구·수치·스킬 규칙·최신 밸런스를 그대로 이식한 목록은 아니다. 이름과 설명을 새로 쓰고 HELLSCRIPT의 18개 스킬에 맞췄다. 출혈은 물리 지속 피해로, 은신 회복은 후퇴 도약 회복으로, 보강은 기존 보호막으로 바꾸었다. 하나의 참고 위상에서 서로 다른 스킬 연계를 만들기도 했다.

## 공통 전투 규칙

- 신규 장비의 상대 가중치는 20이며 기존 직업·부위 추첨에 참여한다. 가중치는 드롭 백분율이 아니다. 희귀도·품질·무작위 접사·획득 경로는 기존 규칙을 따른다. 후보 수가 늘어나므로 개별 전설과 세트의 상대 출현 비율은 달라진다. 신규 아트는 포함하지 않으며 베이스 장비의 아이콘을 공유한다.
- `D`는 발동 공격이 캡처한 공격력이다. 신규 전설의 피해 보너스는 별도 가산 풀에 합산하며 최대 +150%까지 기존 피해 계산에 곱한다. 신규 전설의 받는 피해 감소는 합산 50%를 상한으로 삼고 기존 감소 항목과 곱연산한다. 극대화 확률은 75%, 자원 소모 감소는 50%, 이동·공격 속도는 기존 상한을 유지한다. 신규 수치는 초기 조정값이며 밸런스 검증 완료를 뜻하지 않는다.
- 적중 횟수는 대상별 실제 피해 사건을 센다. 범위 공격은 대상마다, 회오리·장판은 유료 틱 또는 활성 피해 틱마다 센다. 집계 후 5초 동안 새 적중이 없으면 초기화한다. 내부 대기시간에는 횟수를 쌓거나 발동을 예약하지 않는다. 극대화 발동은 실제 극대화 결과가 필요하며 처치 조건은 원 공격이 대상을 죽이기 직전 상태를 기준으로 한다.
- 시전 효과는 준비와 착지 지점 검사를 거쳐 효과 실행 또는 착지 후 발동한다. 빗나간 시전에서도 시전 효과를 소비할 수 있지만 준비 중 취소하면 얻지 못한다. 적중 효과에는 실제 HP 피해가 필요하다. 물약 효과에는 HP 물약의 실제 회복이 필요하다. 피격 효과는 회피하지 않고 생존한 경우에만, 방어 효과는 방어에도 성공한 경우에만 발동한다.
- 전설의 추가 피해는 극대화·압도·행운 적중을 새로 추첨하지 않으며 이 목록의 효과를 다시 발동시키지 않는다. 추가 피해의 처치를 원 스킬의 처치로 잘못 집계하지 않는다. 범위 피해·제어는 시야를 확인하고 가까운 생존 적 최대 5명을 선택하며 같은 거리에서는 적 ID로 순서를 정한다. 시전 범위 효과의 중심은 효과 실행 후 영웅 위치이며 이동 스킬은 착지 지점이다.
- 지연 범위 폭발은 예약 당시 위치를 유지한다. 단일 대상 추가 타격과 지속 피해는 원래의 생존 대상을 따라가며 대상 사망 시 끝난다. 같은 전설이 같은 대상에게 남긴 예약 피해는 갱신하며 중첩하지 않는다. 지속 피해를 갱신하면 지속시간과 캡처한 공격력을 바꾸되 다음 1초 주기 피해 시점은 유지한다. 같은 시간제 강화도 중첩 없이 갱신한다. 보호막은 기존 생성량·지속시간·교체·총 HP 상한을 따른다.
- 기절·빙결·속박은 보스를 직접 묶지 않고 기존 보스 제압 수치로 환산한다. 따라서 빙결 대상 전용 보너스는 보스가 제압되었다는 이유만으로 적용되지 않는다. 피해의 대상 조건은 적중 시점에 확인하고, 시간제 공격 강화와 피해 보너스 장비 목록은 공격 생성 시점에 캡처한다.
- 적중 횟수·재발동 가능 시각·강화 종료 시각·예약 피해는 전투 저장에 포함한다. 일시정지 중에는 전투 시간이 흐르지 않는다. 종료 시점은 기존 전투 틱으로 비교해 소수점 누적 오차를 피한다. 장비를 빼면 활성 강화와 적중 횟수는 지우되 내부 대기시간은 남긴다. 이미 생성된 피해는 기존 스냅샷을 사용하고, 적중 발동에는 해당 장비가 여전히 장착되어 있어야 한다. 발사 후 장비를 끼워도 이전 공격에 새 발동 권한을 주지 않는다.
- HP 회복은 기존 치유 배율을 적용하며 HP·자원 최대치를 넘지 않는다. 쿨타임 감소는 장착한 대상 스킬에만 적용하고 0초 아래로 내리지 않는다. HP·자원이 가득 찼거나 줄일 대상 쿨타임이 없으면 발동을 소비하지 않는다.
