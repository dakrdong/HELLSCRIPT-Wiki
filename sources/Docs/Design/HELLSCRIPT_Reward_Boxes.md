# 지급용 보상 상자와 균열 최초 보상

갱신일: 2026-09-24 · 개발 브랜치 구현

[균열 단계별 콘텐츠 개방](HELLSCRIPT_Rift_Content_Unlocks.md)도 최초 보상 목록과 단계 상세에서 확인할 수 있다. 기능은 클리어 기록 확정 시 자동으로 열리며, 상자 수령 여부와 관계없다.

[English](HELLSCRIPT_Reward_Boxes.en.md) · [드랍·수급 기획](HELLSCRIPT_Rift_Rewards_1000.md) · [상자 정의](../../Assets/HELLSCRIPT/Resources/Data/RewardBoxes.json) · [아이콘 전체 보기](../Art/RewardBoxes/contact-sheet.png)

장비·보석·재화를 지급하는 **소비형 상자 96종**을 등록했다. 가방 하단의 **보상 상자**에서 보유 목록을 열고, 균열 입장의 **최초 보상**에서 1~1000단계별 지급 내용을 확인하고 수령한다. 상자는 계정이 공유하며 장비는 개봉하는 캐릭터에게 지급한다.

## 상자 종류

| 종류 | 등록 수 | 내용 |
|---|---:|---|
| 희귀 장비 | 9 | 전체 장비 랜덤 1종, 무기·머리·몸통·장갑·신발·허리·목걸이·반지 랜덤 각 1종 |
| 전설 장비 | 9 | 희귀와 같은 9종. 전설 확정이며 현재 출시된 직업별 획득 풀을 사용 |
| 특별 장비 | 3 | 직업 세트 몸통, 각성 전설 머리, 각성 전설 무기 |
| 색상 고정 보석 | 36 | 6색 × 6단계. 같은 색·단계 보석 10개 |
| 색상 선택 보석 | 6 | 단계별 1종. 선택한 한 색상 보석 10개 |
| 재화 고정량 | 17 | 강화석 30/100/500/3000, 재료 50/200/1500, 골드 10000/20400/100000/1000000, 심연 주화 100/200/300/500/1000/2000 |
| 단계 연동 재화 | 3 | 단계별 최초 강화석, 10단계 간격 재료, 50단계 간격 강화석 |
| 장비 코어 | 9 | 부위별 8종과 부위 선택 1종. 10개씩 |
| 룬 | 4 | G0 1칸 5종 묶음, G4/G5/G6 5칸 룬 각 1개 |

전체 장비 랜덤 상자는 8개 부위를 각 12.5%로 뽑는다. 부위가 고정된 상자는 그 부위에서만 추첨한다. 무기 상자는 방패·보주·화살 등 보조 장비를 제외한다. 전설의 세부 효과는 기존 획득 가중치를 사용하며, 세트도 전설 안에 포함한다. 세트 전용 상자는 현재 직업의 출시된 몸통 세트 중 하나를 무작위로 지급한다. 미출시 확장 장비는 후보에 넣지 않는다.

장비 레벨은 수령한 균열 단계의 성장 곡선으로 고정하며 60을 넘지 않는다. 늦게 개봉해도 레벨이 오르지 않는다. 상자와 난수 상태를 저장하고, 개봉 결과는 저장 거래가 성공한 뒤에만 반영한다. 각성 상자는 각성을 확정하지만 상위 접사를 추가로 보장하지 않는다. 아래 품질 하한은 **접사 굴림**에 적용하며, 고정 기본 능력치를 임의로 재추첨하지 않는다.

## 모든 단계에 적용되는 최초 보상

- 모든 단계 R: 강화석 `2 + floor(R/50)`개 상자 1개.
- 10의 배수: 제작 재료 `20 + floor(R/20)`개 상자 1개 추가.
- 50의 배수: 강화석 `50 + floor(R/2)`개 상자 1개 추가.
- 아래 기념 단계에서는 지정 상자를 추가한다.

모든 **신규 상자 보상은 계정당 단계별 한 번**이다. 어떤 캐릭터든 해당 단계를 정상 완료한 최단 기록이 있어야 한다. 보스 처치 기록만 남긴 중도 귀환, 최고 클리어 단계로 건너뛴 구간, 소탕은 수령 근거가 아니다. 기존 저장의 정상 완료 기록은 그대로 인정하며, 기록이 없는 옛 단계는 다시 정상 완료하면 받을 수 있다.

기존 게임이 전투에서 자동 지급하는 캐릭터별 최초 골드 `1000+100R`와 재료 `10+floor(R/5)`는 상자 수령 때 다시 지급하지 않는다. 종합 밸런스 기획의 재료 축소안 `10+floor(R/10)` 및 전체 적·반복 드랍 수치는 기획안이다. R1~5 입문 난이도와 R30 전설·세트 제한은 [초반 성장 조정](HELLSCRIPT_Early_Rift_Balance.md)에 따라 적용한다.

1~1000단계를 한 번씩 완료해 모든 상자를 개봉하면 **장비 5개(희귀 1·전설 4), 보석 90개, 룬 8개, 코어 10개, 골드 1,030,400, 재료 6,250, 강화석 20,800, 심연 주화 5,600**을 얻는다. 기존 자동 보상·반복 드랍·분해·오프라인 보상은 이 합계에 포함하지 않는다.

하루 2시간·180일 기획은 심연 주화를 소비하지 않는 기준이다. 이 주화로 추가 피로도나 배속을 구매하면 시간·보상 경로가 달라진다. 보석 선택은 R10에서 금강석 10개와 홍옥 10개, 이후 상자는 금강석으로 배분해 기존 수급 검사를 다시 계산했다. 같은 선택 상자를 여러 색상에 중복 계상하지 않았다.

## 저장과 개봉

`AccountSave.rewardBoxes`가 소유·잔량·개봉 순번·난수·단계별 수령 기록을 보관한다. 저장 스키마는 12다. 예전 `Hero.riftProgress.claimed` 표시 예약 필드는 신규 지급의 소유자로 사용하지 않는다.

`GameStore.ClaimRiftFirstRewards`와 `GameStore.OpenRewardBox`가 복사본 검증 → 파일 저장 → 실제 상태 갱신을 담당한다. 요청 ID 재사용은 동일한 내용일 때만 성공으로 인정하며, 개봉 요청에는 캐릭터·상자·수량·선택 내용을 포함한다. 한 번에 1~10개를 개봉할 수 있다. 장비 가방이나 보석 보관함이 부족하면 전체 개봉을 취소하고 상자를 남긴다. 재화 한도 초과·저장 실패도 같은 원칙을 따른다. 전투 중에는 수령·개봉을 제한한다.

알 수 없는 상자 ID나 버전, 손상된 현재 스키마의 상자 상태는 원본을 보존하고 불러오기를 중단한다. 정상 저장을 오래된 백업으로 조용히 바꿔 상자를 잃게 하지 않는다. 검증은 [RewardBoxTests](../../Assets/HELLSCRIPT/Tests/Editor/RewardBoxTests.cs)와 [실행 검사](../../Assets/HELLSCRIPT/Runtime/Presentation/RuntimeRewardBoxSmoke.cs)에 있다.

## 리소스와 화면

96개 아이콘은 기존 균열 보상 상자의 금속 테두리·어두운 목재 표현을 확장한 **코드 작성 벡터 원본**이다. 장비 등급 색상은 `EquipmentGradePalette`를 읽는다. 이미지 생성 모델은 사용하지 않았다.

- 원본: `Docs/Art/RewardBoxes/*.svg`
- 게임 이미지: `Assets/HELLSCRIPT/Resources/Art/RewardBoxes/*.png`, 256×256 RGBA
- [리소스 검증 목록](../Art/RewardBoxes/manifest.json): 파일 해시와 완전 투명 픽셀 수
- [제작 도구](../../tools/generate_reward_boxes.py): 같은 벡터 도형으로 SVG와 투명 PNG 생성

화면은 `ContentWindowView`와 `StoreViewBinding`을 사용한다. 1000단계 목록은 보이는 행만 만들고, 상자 보관함은 분류 5개와 페이지당 8개를 보여 준다. 획득 장비는 `ItemDetailView`의 `RewardSnapshot`으로 표시한다. 공개 게시와 macOS·실기기 검증 범위는 [검증 기록](../Implementation/RewardBoxEvidence/Reward_Box_Verification.md)에 구분해 남긴다.
