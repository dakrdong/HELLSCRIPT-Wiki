기존 직업 전설 120종과 공용 3종을 전부 대응표에 연결했습니다. 새 기술의 전용 장비가 부족한 부분에는 **직업별 6종, 총 18종의 신규 전설 기획**을 추가했습니다. 기존 전설을 제거하거나 보유 아이템을 바꾸지 않으며 신규 기획의 드롭 가중치는 아직 정하지 않습니다. 전체 141개 장비 연결 기록의 실행 검증 상태는 [구현 기록](../Implementation/Class_Skill_Runtime.md)에서 확인합니다.

다른 작업에서 만든 세트 24종과 효과 60단계, 기존 세트 6종을 함께 대조했습니다. **세트 전체 + 일반 액티브 4개 + 패시브 3개 + 궁극기 1개**의 예시를 세트마다 작성하여 총 30개 빌드를 제공합니다. 각 예시의 전설은 세트와 부위가 겹치지 않습니다. 검사는 보수적으로 부위 분류당 한 개만 사용하므로 추가 반지·보조 무기 칸에 의존하지 않습니다. 새 일반 액티브 30개와 모든 패시브·궁극기는 적어도 하나의 예시에 등장합니다.

## 장착·해금·궁극기 선택 규칙

1. 일반 액티브는 최대 4개, 패시브는 기존처럼 최대 3개를 장착합니다. 기본 공격은 자원 고갈 시에도 쓸 수 있는 별도 행동입니다. 궁극기 전용 슬롯 하나를 추가하는 방안을 제안합니다. 이 전용 슬롯과 HUD 변경은 아직 구현하지 않았습니다.
2. 기존 기술의 해금 레벨과 포인트는 유지합니다. 새 일반 액티브는 직업별 22·26·30·34·38레벨에 두 개씩 해금합니다. 새 패시브는 22·26·30·34레벨에 세 개씩 해금합니다. 궁극기 두 개는 40레벨에 같은 최종 단계로 제시합니다. 40레벨 성장은 개발 검증용 계정에서 활성화합니다.
3. 전체 기술 화면은 일반 액티브 01~16, 패시브 17~34, 궁극기 35~36 순서입니다. 액티브만 보는 화면에서도 궁극기는 17·18번으로 항상 마지막에 둡니다. 이름·등급 정렬로 궁극기가 중간에 섞이지 않게 합니다.
4. 40레벨 전에는 궁극기를 선택할 수 없습니다. 이후에는 두 후보 중 하나만 선택하고 선택한 기술만 배우고 장착·시전할 수 있습니다. 선택 전에는 출발 화면에서 선택을 요구하며, 저장 불러오기 자체를 실패시키지는 않습니다.
5. 두 궁극기를 동시에 담은 프리셋, 다른 직업 궁극기, 일반 슬롯에 넣은 궁극기는 UI뿐 아니라 저장 적용·공유 코드 수신·전투 시작·시전 단계에서 거부합니다. 아이템·패시브·자동 발동도 선택하지 않은 궁극기를 시전할 수 없습니다.
6. 궁극기 변경은 마을에서만 허용합니다. 직업 공용의 다음 궁극기 사용 가능 시각을 유지하여 선택 변경·탈착·저장 복원으로 쿨타임을 초기화하지 않습니다. 기본 쿨타임은 두 기술 모두 60초이며 일반 감소를 적용해도 최소 45초입니다. 직접 쿨타임 환급 효과는 명시한 일반 기술에만 적용합니다.
7. 궁극기를 바꾸면 이전 궁극기의 임시 강화·소환·충전은 종료합니다. 포인트로 우회해 다른 궁극기를 동시에 유지하지 않습니다. 궁극기는 1등급 고정이며 다른 일반 기술처럼 추가 포인트를 받지 않습니다.

| 직업 | 전체 35번 / 액티브 17번 | 전체 36번 / 액티브 18번 | 선택의 차이 |
|---|---|---|---|
| 전사 | 선조의 전쟁 `W17` | 거인의 심판 `W18` | 지속 지원·피해 감소와 즉시 광역 강타 중에서 고릅니다. |
| 궁수 | 일제 소탕 `A17` | 그림자 추격 `A18` | 고정 지점의 광역 소탕과 이동 사격 보조 중에서 고릅니다. |
| 마법사 | 삼원소 붕괴 `M17` | 현자의 화신 `M18` | 짧은 시간의 원소 폭발과 보호막·자원 효율을 동반한 순환 강화 중에서 고릅니다. |

## 수치와 발동 판정

- `D`는 주능력과 공격측 보정의 기준이 되는 공격값입니다. D100%는 D×1이며 최종 피해 100%를 다시 복사하는 뜻이 아닙니다. 각 기술의 수치는 1등급 기준입니다. 기존 36개 기술은 `SkillEffects`의 현재 등급 계산을 유지합니다.
- 새 일반 기술은 최대 5등급이며 추가 등급마다 직접·지속 피해, 자원·HP 회복량, 보호막 생성량에 기준값의 10%를 더합니다. 새 패시브도 최대 5등급이며 피해·치명·방어·속도·회복·비용 감소의 수치 크기만 같은 방식으로 늘립니다. 사거리·범위·제어 시간·지속시간·쿨타임·발동 간격·대상 수·충전 수·임계값·고정 쿨타임 환급 초수는 등급으로 바꾸지 않습니다. 궁극기 분기 전용 패시브의 +2초·+2회 같은 구조 변경도 고정입니다.
- 자원 비용 감소 50%, 일반 쿨타임 감소 40%, 치명 확률 75%, 속도 증가 50% 등 기존 상한을 공유합니다. 전설 피해는 기존 전설 가산 풀, 세트·일반 패시브의 가산 피해는 기존 해당 풀에 한 번만 합산합니다. 보호막·회복은 최대치와 원천별 교체 규칙을 유지합니다. 신규 방어 확률은 기존 방어 판정·상한에 더하며 성공을 보장하지 않습니다.
- 원 기술 시전, 직접 적중, 원 장판 틱, 추가 피해를 구별합니다. 새 일반 기술과 궁극기도 실제 원 사건에는 조건이 맞는 기존 `*` 규칙을 적용할 수 있지만, 특정 스킬 ID를 요구하는 장비에는 그 ID를 실제 시전해야 합니다. 추가 타격·소환 사격·분열·잔영은 스스로 전설·세트·기본 공격·자원 적중 발동을 재생산하지 않습니다. 궁극기 장비·패시브가 명시적으로 요구하는 선조·잔영 사건만 지정된 상한 안에서 한 번 평가합니다.
- W07 표식은 전사 소유의 표식 상태를 제공하고 피해 증폭값은 0입니다. A05의 피해 증가를 몰래 받지 않도록 표식의 존재와 피해 증폭량을 분리합니다. A06 충전은 기존 기본 사격·A01·A02의 규칙을 유지하며 새 사격·쇠뇌·궁극기에 자동 확장하지 않습니다.
- 새 기술의 별도 표기가 없는 범위 추가 피해는 중심 3m 안의 시야가 확보된 적 최대 5명을 고릅니다. 거리, 같은 거리에서는 적 ID 순으로 선택합니다. W12 반격은 전방 90도입니다. M11 만료 폭발은 구체 중심 3m·최대 5명입니다. M18의 순환 폭발은 2.5m·최대 5명입니다.
- 장판·소환은 첫 주기가 지난 뒤 첫 틱을 실행합니다. A17만 명시된 첫 파동을 시전 시점에 실행하고 이후 0.5초마다 총 6회까지 실행합니다. 같은 종류의 설치물 상한을 넘기면 가장 오래된 같은 기술의 설치물을 교체합니다. 맹독 덫의 기존 2개 상한은 유지하며 A09·A10·A11·A15는 각각 1개입니다. 교체·장면 종료는 자연 만료 보상을 주지 않습니다.
- 지속 피해는 원천·대상별 장부로 보관하고 갱신해도 다음 틱을 뒤로 미루지 않습니다. W10은 W09 장부만 소비하고, 붉은 상흔의 W04는 해당 세트 장부만 소비합니다. 공격측 증폭은 저장 시 한 번, 대상 방어·저항은 실제 피해 시 한 번 적용합니다.
- 기절·빙결·속박·끌어오기는 보스의 기존 제압 규칙을 사용합니다. 제압만으로 빙결 전용 조건을 충족시키지 않습니다. MP10처럼 보스 제압도 인정하는 항목은 별도로 명시합니다. 표식·독·둔화 등 지속 조건도 서로 다른 상태이며 자동으로 다른 조건을 충족했다고 간주하지 않습니다.
- 시전당 효과는 발사 수·관통 대상 수·연쇄 방문 수만큼 중복 발동하지 않습니다. 한 충전의 여러 소비자가 있어도 최초 유효 시전 하나가 예약·소비합니다. 취소·빗나감·사망·최대치 초과·같은 시전에서 생긴 새 충전의 소급 소비를 각각 구분합니다. 세트의 기존 예약 정책은 해당 문서를 유지합니다.
- 기존 전설의 이미 생성된 추가 피해는 원래 스냅샷 정책을 유지합니다. 새 세트의 장비 수가 부족해지면 세트 소유 강화·예약·지속 피해를 지우는 정책도 유지합니다. 두 정책을 하나로 덮지 않습니다. 새 스킬·새 전설의 효과는 원천 ID를 저장하고, 탈착 시 활성 강화와 횟수는 제거하되 내부 대기시간은 보존합니다.

## 구현과 UI 연결의 경계

이 문서와 JSON은 `Docs/Design`의 기획 원본으로 보존합니다. 원본의 `runtimeEnabled=false`는 이 파일을 직접 실행하지 않는다는 뜻이며, 실제 정의는 별도의 `Resources/Data/ClassSkills.json`으로 생성합니다. 기존 0~17 인덱스는 호환 계층으로 유지하고 새로운 능력은 ID로 조회합니다. 구현 및 실행 증거는 [구현 기록](../Implementation/Class_Skill_Runtime.md)에 모읍니다. 아래 항목 중 아이콘·HUD와 일반 드롭 활성화는 UI 통합 단계의 일입니다.

1. 기술 저장과 조회를 안정된 문자열 ID 기준으로 확장합니다. 기존 액티브 전역 인덱스 0~17은 원 직업의 W01~W06·A01~A06·M01~M06에 그대로 대응시키고, 패시브 지역 인덱스 0~5와 기존 12개 등급 배열은 같은 기존 ID로 옮깁니다. 새 ID의 해금·등급은 별도로 초기화하며 잘못된 직업·중복·알 수 없는 ID를 묵살하지 않습니다.
2. 사냥 칙령·프리셋·공유 코드·전투 복원·쿨타임·아이콘·HUD가 같은 기술 정의를 읽게 합니다. 기존 칙령의 설정과 장착 상태를 보존하며 궁극기 선택이 비어 있는 오래된 저장은 마을에서 선택을 안내합니다. 기술 기획이 아이콘이나 애니메이션 구현 완료를 뜻하지 않습니다.
3. 전사 표식·독립 출혈, 새 덫·미끼·쇠뇌, 구체 충전·소환, 궁극기 공용 쿨타임과 원천별 장부를 구현합니다. 이동·충돌은 기존 월드 판정을 재사용하며 새 자동 사용 조건도 관측한 적·위험도만 읽습니다.
4. 신규 전설 18종은 이 연결이 끝난 뒤 실제 장비 정의·발동기·한국어/영어 문구·드롭·저장에 등록합니다. 기존 세트 6종은 보존하고 새 세트 24종은 별도 후보 ID로 유지합니다. 보유 장비를 자동 변환하거나 현재 장비 효과가 이미 새 기술을 지원한다고 표시하지 않습니다.
5. 같은 장비 레벨·품질·강화·사냥 시간에서 무장비 기준, 희귀 조합, 기존 전설 조합, 세트 조합의 처치 속도·자원 공백·생존·보스 제압·발동 횟수를 비교합니다. 지속 궁극기와 순간 궁극기의 기대 피해 및 자원 이득도 같은 시간 창에서 비교해야 합니다.

## 작성·검사

[관리 도구](../../tools/class_skills.py)는 원본 JSON에서 직업별 목록과 장비 대응표를 생성합니다. 수정 후 `python3 tools/class_skills.py build`와 `python3 tools/class_skills.py check`를 실행합니다. 공통 규칙을 바꾸면 이 문서와 영어판도 함께 갱신합니다.

검사는 직업별 수량, 전체 순서 1~36, 마지막 두 궁극기, 직업·슬롯·레벨 제한, 궁극기 중복·미선택·오배치 거부, 기존 기술 36개와 기준 파일의 보존, 장비 141개 참조, 세트 30종·신규 효과 60단계, 30개 빌드의 필수 기술과 장비 부위 충돌을 확인합니다. 이 검사는 **기획 데이터와 선택 규칙의 일관성 검사**입니다. 신규 스킬을 Unity에서 실행하거나 밸런스를 검증한 결과로 보고하지 않습니다.
